# Cox 모형별 진단 결과 재점검

Cox 다국어 검사 11개를 8개 언어로 실행했다. 최초 10개 통과, 동률 처리 검사 1개 실패 후 원인을 확인했다. 오래된 검사 가정을 보완한 재실행에서 모두 통과했다. 제품 코드와 번역 사전은 변경하지 않았다.

## 실패 원인과 검사 보완

`validate_cox_ties_i18n.R`는 부록의 모든 셀을 영어와 동일하게 요구했다. Exact 방식에서는 일본어의 정상 번역 `正確法`이 이 조건을 깨뜨렸다. 실제로 사건 수 50, 고유 사건시점 27, 동률 사건시점 17, 동률 시점 사건 수 40, 최대 동시 사건 수 3, 비율 80.0%는 보존됐다.

검사를 방법명과 수치로 분리했다. 방법명은 기존 언어별 번역을 확인하고, 나머지 셀은 영어와 동일한지 확인한다. 원본 결과·표 객체의 직렬화 동일성 검사도 추가했다. 한국어의 기존 Exact 표기는 유지한다. Efron/Breslow/Exact 세 모형을 실제 적합한 후 8개 언어 검사를 통과했다.

## 통과한 검사

아래 이름은 `scripts/validate_<이름>_i18n.R`에 대응한다.

| 이름 | 검증 범위 |
| --- | --- |
| cox_ph | 비례위험 진단표·주석·사용자 이름·영어 본표 |
| cox_spline | 자유도 3·4의 실제 자연 삼차 스플라인 적합, 제목·열·주석·수치 |
| cox_time_varying | 실제 시간가변 계수 모형과 시점별 위험비, 주석·열·사용자 이름 |
| cox_method | 기본·진입·시작/종료·층화·군집·스플라인·시간가변 방법 설명과 사용자 메타데이터 |
| cox_ties | 동률 처리 3종 실제 적합, 방법명·제목·주석·수치 및 원본 보존 |
| cox_residual_collinearity | 잔차·공선성 진단, 수치와 사용자 열 |
| cox_influence | 영향력 표의 상태·주석·수치·이름 |
| cox_sample_warnings | 사건/모수·군집 관련 경고의 경계값·심각도·수치 |
| cox_collinearity_warnings | VIF·조건수 경계와 경고 심각도 |
| cox_influence_strata_warnings | 영향력 건수·층별 사건 경계 및 사용자 이름 |
| cox_bootstrap_ties_warnings | 부트스트랩 유효 횟수·비율과 동률 경고 분기 |

각 스크립트의 영어 본표 보존 검사도 통과했다. 일부 경고 검사는 실제 적합 결과에 진단값을 주입하여 경계를 검사한다. 모든 경고를 원자료에서 자연 발생시키거나 부트스트랩을 모두 실제 재수행한 검증은 아니다.

## 근거와 범위

- 로그: `tmp/<위 검사 이름>-recheck.log`. 동률 로그는 최종 통과 결과이며 최초 실패와 원인은 이 문서에 기록했다.
- 제품 출력 변경이 없어 이번에는 5개 형식 저장을 재생성하지 않았다. 문서 앱별 수동 시각 검토 및 설치본 빌드는 수행하지 않았다.
- 전체 프로그램 번역 완료 판정은 아니다. 기존 매개·조절효과 패널 제외 원칙을 유지한다.
