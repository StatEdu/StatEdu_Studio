# 결과 저장 창 다국어 — 2026-09-17

HTML, PDF, Excel, Word, HWPX 경로 선택 함수의 제목과 파일 형식 안내를 현재 UI 언어로 표시하도록 변경했다. 기존 호출은 앱이 갱신하는 `statedu.app_language` 옵션을 호출 시점에 읽고, 명시적인 language 인자도 지원한다. 파일 확장자, 기본 파일명, 저장 기능 허용 조건, HWPX 버튼 표시 조건은 유지한다.

`validate_result_dialog_i18n.R`에서 8개 언어와 한국어 복귀를 검사했다. 5개 형식의 Windows 경계 제목·필터·확장자·사용자 경로 보존·취소·Tk 대체 경로가 통과했다. 기존 Excel/PDF/Word 저장 기능 허용 조건도 통과했다. CSV 저장 회귀 및 번역 카탈로그 검사도 통과했다.

검사는 OS 호출 경계를 대체한다. 실제 네이티브 창 표시와 RStudio/choose.files 실행 검증은 미완료다. 결과 본 표·보조표·스냅샷·파일 작성 함수는 이번에 변경하지 않았으며 현재/누적 보고서 전체 내보내기 검사를 새로 실행한 것은 아니다. 결과 이력 열기/저장 창의 고정 영어 문구는 후속 작업으로 남는다. 설치본은 생성하지 않았다.
