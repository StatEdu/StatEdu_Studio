# 일반 Cox 공선성 경고 번역

## 변경

일반 Cox의 `high_vif`, `elevated_vif`, `high_condition_number` 숫자 접두 문구를 다국어 처리에 연결했다. 접두 문구 2개, 유한하지 않은 VIF 설명 1개, 권고 4개를 6개 추가 언어에 번역했다. 기존 판정 기준과 영어·한국어 문구 및 분석 계산은 유지했다.

## 검증

`scripts/validate_cox_collinearity_warnings_i18n.R`는 실제 Cox 적합 결과에서 진단 메타데이터를 변경하여 경고 분기를 검사한다. 변경한 진단 사례를 별도로 재적합한 것은 아니다.

- VIF 4.99 / 5 / 10 / Inf / NA, 조건수 29.99 / 30의 6가지 조합.
- 8개 언어에서 경고 발생 여부, 심각도, 수치 정밀도 및 영어 잔존 검사 통과.
- 본 회귀표가 모든 UI 언어에서 동일한 영어 내용을 유지하는지 확인했다.
- 일본어 경고표 캡처를 현재·누적 결과로 저장한다. 저장 시 분석을 다시 실행하지 않는다.
- 산출물: `tmp/cox-collinearity-warnings-i18n/`.
- 현재 5개·누적 6개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서·시트 수도 확인했다.
- 기존 사건 수·군집 수 경고의 8개 언어 회귀 검증도 통과했다.

이번 범위는 일반 Cox의 공선성 경고이며 전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
