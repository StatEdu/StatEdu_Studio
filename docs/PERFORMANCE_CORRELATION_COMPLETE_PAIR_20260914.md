# 상관분석 완전 관측 쌍의 복사 생략 — 2026-09-14

`R/analysis_correlation.R`의 `correlation_complete_pair`에서 결측값이 없는 일반 숫자 벡터를 다시 부분 추출하지 않고 그대로 반환하도록 변경했다. `complete.cases`와 유효 관측 수 계산은 유지한다. 이름·클래스·차원 등 속성이 있는 자료, 비숫자 자료, 결측값이 있는 쌍은 기존 부분 추출을 사용한다. 수식, 관측 순서, 통계 검정은 변경하지 않았다.

## 전체 결과 준비 시간

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 3쌍을 순차 실행하고 두 번째 쌍은 순서를 반대로 했다. 같은 전역 함수 환경을 사용했다. 자료는 5만 행·15변수 숫자형이며 Pearson 분석, 정규성 검사 비활성 조건이다. 각 프로세스에서 완전 자료 후 결측 자료를 실행했다.

| 조건 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 모든 값 관측 | 0.37 | 0.36 |
| 첫 변수의 10% 결측 | 0.28 | 0.26 |

조건별 시각과 워밍업 상태가 다르므로 두 행끼리 비교해 결측 자료가 본질적으로 빠르다고 해석하지 않는다. 변경 전후 시간 차이는 작다. 결측 조건에서도 첫 변수를 포함하지 않는 완전한 쌍은 새 경로를 사용한다.

| 함수 | 10회 누적 할당 바이트 |
|---|---:|
| 변경 전 | 18,003,520 |
| 변경 후 | 2,000,480 |

이 조건의 함수 내부 누적 할당이 약 89% 감소했다. 프로그램 전체 메모리, 최고 사용량 또는 상주 메모리를 측정한 값이 아니다. 반환 벡터는 R의 값 의미와 수정 시 복사 동작을 따른다.

## 검증

- 6개 자료 조건 × 네 분석 방법 × 정규성 옵션의 48조건에서 전체 결과·진단·난수 상태가 정확히 일치했다.
- 빈 벡터, 정수, NA/NaN/무한값, 이름·임의 속성, factor, 행렬, Date, 논리·문자·복소수·리스트를 조합한 169쌍에서 반환 객체 또는 오류 메시지가 동일했다. 길이가 다른 입력도 포함한다.
- 성능 측정 결과 6쌍의 전체 결과·진단·난수 상태가 `identical(...,num.eq=FALSE)`로 일치했다.
- 추가 3조건에서 auto 결과와 HTML/의존성, 변환 진단이 동일했다. 기존 인자를 사용하는 numeric-data 직접 호출 비교도 통과했다.
