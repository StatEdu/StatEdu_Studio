# 현재 소스의 초기화·분석 통합 검증 — 2026-09-14

잠재 상관 캐시와 RMST 행 접근 개선까지 적용한 현재 소스를 실제 서버 함수의 모의 Shiny 세션에서 검증했다. 이번에는 실행 코드를 추가로 변경하지 않았다. 결과 동일성 검증과 현재 시간 기준선 갱신이며, 새 최적화의 단축률을 측정한 작업은 아니다.

## 서버 흐름

번들 R 4.5.3에서 새 프로세스 3개를 순차 실행했다. 기존 final_measure.R을 사용하고 STATEDU_TEST_VISIBILITY=selected, STATEDU_TEST_INIT_JIT=on, 기존 모듈 캐시를 지정했다. 모든 지연 UI를 동시에 표시하는 조건이 아니라 선택된 분석 화면을 표시하는 모의 세션이다.

72행 생존분석 검증 자료의 업로드·변수 선택, 상관분석, Kaplan–Meier 분석 및 같은 입력의 재실행을 포함한다. 다음 시간은 서버 작업과 반응형 출력 처리를 포함한다.

| 단계 | 중앙값(초) |
|---|---:|
| 서버 초기화 | 0.73 |
| 업로드·변수 선택 | 0.58 |
| 상관분석 설정 | 0.49 |
| 첫 상관분석 | 0.47 |
| 생존분석 설정 | 1.16 |
| 첫 생존분석 | 2.08 |
| 같은 입력의 생존분석 재실행 | 0.02 |
| 전체 시나리오 | 5.59 |

전체 시간 원자료는 5.59/5.52/5.60초다. 같은 입력의 상관 재실행은 0.00/0.00/0.02초로 기록됐다. 이는 측정 해상도와 기존 재사용 동작을 포함하며 실제 계산 비용이 0이라는 뜻이 아니다. 전체 시간의 중앙값은 각 단계 중앙값의 합과 반드시 같지 않다.

3회 모두 전체 상관/KM 결과, HTML·의존성, 경고, 알림이 output/startup-jit-20260914/current-final1.rds 기준과 identical(..., num.eq=FALSE)로 일치했다. 시나리오 내부에서도 첫 분석과 같은 입력 재실행 결과가 일치했다. 경고는 0건이다. 그래프 좌표계를 교체한다는 기존 메시지는 각 실행에서 출력됐으며 오류가 아니다.

## 별도 로딩 단계

별도의 새 프로세스 3개에서 패키지 로딩, 모듈 로딩, UI 구성과 HTML 생성 시간을 측정했다. 기존 모듈 캐시를 사용했고 OS 파일 캐시를 비우지 않았다.

| 단계 | 3회(초) | 중앙값(초) |
|---|---|---:|
| 패키지 로딩 | 0.24 / 0.22 / 0.23 | 0.23 |
| 모듈 로딩 | 0.65 / 0.66 / 0.67 | 0.66 |
| UI 구성 | 0.37 / 0.37 / 0.37 | 0.37 |
| HTML 생성 | 0.06 / 0.04 / 0.06 | 0.06 |

시작 화면의 무작위 탭 ID를 기존 방식으로 정규화한 HTML, 의존성 및 포함된 상관/생명표 분석 결과가 이전 캐시 적중 기준 스냅샷과 정확히 일치했다. 이 단계와 서버 흐름은 별도 프로세스·조건에서 측정했다. 합산해 실제 Electron 시작 시간으로 제시하지 않는다. 브라우저 첫 화면 표시, Electron 실행 및 실제 사용자 장치의 콜드 스타트는 이번에 측정하지 않았다.

## 별도 분석 경로 재검증

일반 서버 시나리오가 잠재 상관과 RMST 옵션을 직접 수행하지 않으므로 해당 검증도 순차 실행했다. 검증용 current.R 스냅샷과 현재 실행 모듈의 SHA256 일치를 먼저 확인했다.

- 잠재 상관: 전체 분석 24조건, 직접 호출 12조건, 변환 진단 계측 3조건, 연속 캐시 입력 26조건으로 총 65조건 통과. 전체 결과·쌍별 추정 정보·진단·난수 상태 및 HTML 3건의 기존 검증을 재실행했다.
- RMST: 직접 경계 입력 30조건, 실제 KM 기반 추정치 비교 1건, 전체 KM/RMST 분석 3건으로 총 34조건 통과. 전체 결과·진단·난수 상태 및 HTML 3건의 기존 검증을 재실행했다.

산출물은 output/performance-current-server-20260914/의 source-hashes.csv, 서버 로그, server-times.csv, summary.csv, startup.R, startup-summary.csv, compare.R, compare_startup.R 및 분석별 로그다. 서버 원자료는 output/startup-jit-20260914/current-cumulative-1~3.csv/rds에 있다. 재검증은 기존 output 디렉터리의 검증 스크립트와 스냅샷에 의존한다.

실행 코드 변경은 없으며 PDF/Word/HWPX/Excel 변환은 이번에 재검증하지 않았다. 설치 파일은 재빌드하지 않았다.
