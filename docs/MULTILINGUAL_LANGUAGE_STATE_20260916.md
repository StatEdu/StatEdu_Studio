# 언어 전환 후 옵션·분할 결과 유지

실제 Chrome/Shiny 검사에서 두 문제를 확인하고 수정했다.

1. 숨겨진 일원 반복측정 설정 출력이 언어 변경 때 갱신되지 않아 이전 옵션이 재전달될 수 있었다. `one_group_rm_anova_setup`의 `suspendWhenHidden`을 해제해 숨겨진 탭에서도 언어 변경을 반영한다. 옵션 변경마다 전체 설정 UI를 다시 생성하는 방식은 적용하지 않았다.
2. 분할 스냅샷에는 본표 4개가 모두 있었지만 상위 lazy 화면을 다시 만들면 화면에는 마지막 집단의 2개만 남았다. `analysis-scope.js`가 결과 출력 자체뿐 아니라 이를 포함하는 상위 출력의 갱신 후에도 완료된 분할 스냅샷을 재표시하도록 수정했다. 원본 스냅샷과 계산값은 변경하지 않는다.

`scripts/validate_language_analysis_state.cjs`는 60행에서 남성 30행을 선택하고 site A/B로 분할한다. 처치별 변수 2개씩을 배정하고 사후검정을 해제하며 Bonferroni를 선택한 뒤 실제 두 집단을 분석하고 결과에 추가한다. 8개 언어 왕복에서 변수 순서, 두 옵션, 선택/분할 상태, 본표 4개의 내용 및 누적 결과 iframe 스냅샷 동일성을 모두 확인했다. pageerror 없이 통과했다. 기존 WIDE/LONG 계산·Shiny 서버 검사도 통과했다.

브라우저에서 수집한 스냅샷 `tmp/language-state-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교, PDF 생성 및 실제 PDF 텍스트 검사도 통과했다. 분석을 다시 실행해 저장한 것이 아니다. 로그는 `tmp/language-state-test.log`, `tmp/language-state-regression.log`, `tmp/language-state-exports.log`다. 검증용 개발 서버를 종료했다.

검사 초안은 첫 집단 표가 나온 시점을 완료로 간주해 분할 실행 중 이동을 시도했다. 최종 검사는 완료 스냅샷과 중단 버튼의 숨김 상태를 기다린다. 환경설정 탐색 지연 시 한 번 재시도하고 로그에 남긴다. 이는 모든 클릭 타이밍/화면 이동 경로에 대한 보증은 아니다.

분할/누적 결과는 캡처된 원문을 보존한다. 이번 검사는 본표 및 저장 스냅샷 유지 검사이며, 이미 캡처된 보조표를 새 UI 언어로 다시 번역하는 동작은 구현하거나 완료 판정하지 않는다. 다른 분석·옵션·분할 조합도 별도 범위로 남긴다. 설치본은 만들지 않았다.
