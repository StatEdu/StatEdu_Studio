# 독립표본 비모수 분석의 중복 실행 확인 — 2026-09-14

## 확인 결과

`prepare_ttest_anova_results()`는 비모수 분석에서 중앙값/IQR와 추가 평균·표준편차 표를 함께 요청하면 `prepare_ttest_anova_results_core()`를 다시 호출한다. 계측으로 주 검정과 사후검정까지 각각 두 번 실행됨을 확인했다.

8집단·2만 행에서 추가 평균·표준편차 표를 끄면 전체 0.37~0.39초, 켜면 0.76~0.79초였다. 다음 검토 후보는 한 분석 실행 안에서 같은 검정 결과를 재사용하는 것이다. 두 표의 요약값·표시 조건은 달라야 하므로 두 번째 결과표 자체를 생략하거나 첫 번째 표로 대체하는 것은 요구사항에 맞지 않는다. 검정 선택·진단·RNG·결과 표시를 보존하는 재사용 후보의 구현 및 검증은 아직 수행하지 않았다. **이번 작업은 측정이며 제품 변경은 없다.**

## 조건

- 번들 R 4.5.3, 20,000행. 집단 수 2/4/8, 결측 없음.
- 데이터 seed 939. `g <- rep(seq_len(k), length.out=20000)`, `y <- rnorm(20000) + g * .3`. 집단은 factor, 종속변수는 연속형으로 지정했다.
- `force_nonparametric=TRUE`, `post_hoc=TRUE`, `add_mean_sd=FALSE/TRUE`. 기본 중앙값/IQR 요약을 사용한다. 효과크기 옵션은 이번에 켜지 않았다.
- 새 R 프로세스 3개를 순차 실행. 각 조건에서 예열 후 계측 없는 전체 실행을 측정했다. 두 번째 프로세스는 집단 수 및 추가 표 옵션 순서를 뒤집었다.
- 이후 별도 호출에서 연구 환경에 복사한 앱 함수와 그 stats 호출에 래퍼를 연결해 구간 시간과 호출 횟수를 측정했다. stats 네임스페이스와 제품 코드는 수정하지 않았다.

## 호출 횟수 및 주요 구간

세 프로세스에서 같은 호출 횟수가 관측됐다.

| 경로 | 추가 표 끔 | 추가 표 켬 |
|---|---:|---:|
| 전체 분석 core | 1 | 2 |
| 집단별 요약값 생성 | 1 | 2 |
| 2집단의 직접 Wilcoxon 호출 | 1 | 2 |
| 2집단의 별도 Mann–Whitney z 계산 | 1 | 2 |
| 4/8집단의 Kruskal–Wallis 호출 | 1 | 2 |
| 4/8집단의 pairwise.wilcox.test 호출 | 1 | 2 |

8집단의 별도 사후검정 계측은 추가 표 끔 0.30~0.32초, 켬 0.60~0.61초였다. 이 시간은 `stats::pairwise.wilcox.test` 전체이며 내부 각 쌍의 Wilcoxon 호출을 개별 계측한 것은 아니다. 따라서 CSV에서 4/8집단의 직접 `wilcox.test`가 0회라고 해서 사후검정 내부에 Wilcoxon이 없다는 뜻이 아니다.

앱의 `ttest_nonparametric_pairwise()`와 내부 `pairwise.wilcox.test` 시간은 포함 관계이고, 전체 core에도 포함된다. 중복 합산하지 않는다. 구간 계측은 계측 없는 전체 시간과 다른 호출이므로 두 측정의 합이나 차이를 분석 단계 비용으로 해석하지 않는다. 요약표의 0초는 타이머 해상도 미만이고, 효과크기 함수 0회는 옵션이 꺼져 호출되지 않은 경우다.

## 동일성 및 한계
