# 3수준 메타분석 연구 소속 행렬 재사용 — 2026-09-14

`meta_fit_three_level()`의 한 번의 적합 안에서 같은 연구 소속 행렬을 재사용하도록 적용했다. 기존에는 목적함수 평가 때마다 `outer(study_id, study_id, FUN = "==") * 1`을 다시 계산했다. 연구 소속은 최적화 매개변수와 무관하므로 일반 문자형 연구 ID에서는 한 번만 계산해 목적함수와 최종 성분 계산에 전달한다.

주변 공분산 행렬 구성, Cholesky 분해, 역행렬, 곱셈·합산 순서, 최적화 시작점·허용오차·수렴 판정은 바꾸지 않았다. 이름이나 클래스 등 속성이 있거나 결측값이 있는 ID, 숫자형·factor ID는 기존 계산을 유지한다. 캐시는 적합 함수의 지역 변수이며 다른 분석이나 데이터와 공유하지 않는다. 직접 호출하는 성분 함수의 기존 5개 인수 사용도 그대로 지원한다.

## 전체 3수준 적합 측정

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 2번째 프로세스에서는 기존/후보 측정 순서를 뒤집었다. 각 조건을 먼저 실행한 뒤 GC 후 시간 측정, 별도 Rprofmem 실행을 수행했다. 데이터 생성과 소스 로딩은 제외하고 4개 시작점 최적화와 최종 결과 생성은 포함했다.

| 효과크기 수 / 연구 수 | 기존 3회(초) | 후보 3회(초) | 중앙값 변화 |
|---|---|---|---|
| 120 / 40 | 0.22 / 0.22 / 0.22 | 0.14 / 0.14 / 0.14 | 0.22 → 0.14, 약 36% 감소 |
| 300 / 100 | 1.43 / 1.28 / 1.29 | 1.00 / 0.98 / 0.95 | 1.29 → 0.98, 약 24% 감소 |

시드 319, 연구당 효과크기 3개, 정규 효과값과 양의 균등분포 표집분산을 사용했다. 효과크기 300개를 개인 관측치 300행과 혼동하면 안 된다. 이는 3수준 모형 적합 시간이며 앱 로딩, 전체 메타분석 옵션, 화면·저장 시간의 개선율은 아니다.

Rprofmem의 **누적 할당량**은 120개에서 459,773,352 → 247,715,352바이트, 300개에서 1,768,181,640 → 948,713,640바이트로 약 46% 감소했다. 각 조건의 3회 값은 같았다. 최대 메모리 점유량이나 RSS를 측정한 값은 아니다. 지역 행렬은 적합이 끝날 때까지 유지된다.

## 검증

- 기존 소스 사본과 후보의 전체 반환값·경고/메시지 문자열·난수 상태를 `identical(..., num.eq=FALSE)`로 비교했다. 두 자료 크기 × 세 프로세스 모두 일치했다. 메모리 측정 실행 결과도 일치했다.
- 적용 후 실제 `R/analysis_meta.R`의 반환값과 난수 상태를 두 자료 크기의 기존 결과 사본 각 3개와 다시 비교해 모두 일치했다. 수치 허용오차나 공식 환경 정규화가 필요하지 않았다.
- `scripts/validate_meta_three_level_reuse.R`: g/r/OR × 일반 문자·factor·이름 포함·숫자·결측·한글/그리스 문자·독립 연구·연구 수 부족의 24개 조건, 연구 소속 변경 후 재실행 검증 통과. 경고/메시지·오류의 클래스와 문자열 및 난수 상태를 비교한다. 조건 객체의 호출 환경 자체는 비교하지 않는다.
- 기존 `validate_meta_analysis_model.R`, `validate_meta_analysis_input.R`, `validate_meta_analysis_ui.R` 모두 통과했다. 모형 검증에는 3수준·강건 추정·모형 표 등 기존 검증 범위가 포함된다.
- UI 테스트는 최근 서버의 공통 분석 모듈 의존성을 불러오지 않아 처음 실패했다. 테스트에 `analysis_scope.R`, `analysis_syntax.R`, `analysis_commands.R` 로딩을 추가한 뒤 통과했다. 서버의 실행·분할 동작은 변경하지 않았다.

`output/meta-three-level-reuse-20260914/`에 기존 소스, 비교 스크립트, 원시 메모리 기록, 시간 CSV, 결과 RDS, 적용 후 확인 스크립트를 보관했다. 표시·저장 내용 및 출력 형식은 변경하지 않았으며 PDF/Word/HWPX/Excel 전체 변환을 재생성하지 않았다. 설치 파일 빌드도 수행하지 않았다.
