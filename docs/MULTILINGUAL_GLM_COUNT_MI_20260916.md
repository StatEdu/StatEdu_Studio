- 포아송/음이항 분포와 log 링크가 모든 대치 자료에서 고정되는지 확인했다. 진단표 수치·논리값·사용자 항 이름이 유지되는지 검사했다.
- 실제 전체 출력의 본표 셀·주석과 영어 언어 속성이 언어 전환 후에도 동일한지 확인했다. 두 분포의 고정 안내가 보조표에서 영어로 남지 않는지도 검사했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 실제 대치별 진단표와 고정 안내를 저장 fixture로 구성했다. 현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성 및 실제 PDF 텍스트 비교를 통과했다.
