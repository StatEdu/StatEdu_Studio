# 결측 SEM 병렬 작업자 내부 프로파일

제품을 수정하지 않고 fixed-index 작업자 함수의 연구용 사본에 Rprof 시작/종료만 삽입했다. 부모의 병렬 대기 스택 대신 실제 작업자 재적합 블록을 측정했다.

## 조건

기존 결측 FIML 정확성 검사의 240행·9지표·3잠재변수 일반 SEM, 변수별 10% 결측, ML/FIML, 200회, seed 20260826, 4작업자, chunk 200이다. 기존 검사의 `run_path(FALSE)`를 사용하므로 해당 검사의 isolated worker/expected-information/fixed-index 설정을 유지한다. 제품지표 모형은 포함하지 않는다. 앞선 실제 백그라운드 전체 시간 측정의 chunk 100과는 다르므로 절대 시간을 직접 비교하지 않는다.

부모와 작업자에 번들 R 4.5.3 라이브러리를 일치시켰다. 새 부모 프로세스 3개에서 각각 비계측 실행 후 계측 실행을 순차 수행했다. 각 계측 블록은 10ms Rprof 파일을 별도로 남기고 종료 시 프로파일을 닫았다. 각 실행에 24개 파일, 총 72개 작업 블록 프로파일을 얻었다. 블록별 함수 시간을 합산한 뒤 전체 표본 시간으로 나눴다. 블록별 비율을 단순 평균하지 않았다.

## 작업자 표본 시간 비중

|포함 스택|1회|2회|3회|
|---|---:|---:|---:|
|lavaan::lavaan 전체 재적합|96.47%|96.11%|95.83%|
|lav_step11_estoptim 모형 최적화|64.93%|66.56%|65.53%|
|lav_step05_samp 표본 통계 준비|18.82%|18.15%|18.55%|
|lav_step13_vcov_boot 공분산 단계|5.52%|3.82%|4.81%|

전체 재적합 안에 나머지 단계가 포함되므로 비율을 더하지 않는다. 여러 작업자의 표본 시간 합은 15.57/15.70/15.58초였으며 **사용자 대기시간이나 단일 프로세스 경과 시간이 아니다.** 부모 조율·작업자 시작·최종 요약은 이 프로파일 범위 밖이다.

첫 실행에서는 `lav_model_grad`, `lav_model_objective_fiml`, `lav_model_omega` 및 행렬 역행렬 갱신 등이 최적화 경로 안에 관측됐다. 세 실행에서 최적화 단계가 가장 크고 표본 통계 준비가 다음으로 큰 패턴을 확인했다. 모든 입력에서 같은 분포라는 결론은 아니다.

## 동일성

각 프로세스에서 비계측/계측 반환값의 timings 속성만 제거하고, 전체 결과와 부모 RNG·부모에서 포착한 조건·표준 출력을 묶어 `identical(..., num.eq=FALSE)`로 정확 비교했다. 3회 모두 통과했고 유효 200/200, fixed-index 활성, fallback 0이었다. 재표집 인덱스·유효 마스크·원계수·표준화계수 및 요약이 비교에 포함된다. 수치 반올림이나 환경 정규화는 하지 않았다.

원래 run_path와 작업자 내부가 경고를 억제하므로 모든 자식 경고/메시지를 새로 수집해 비교한 검사는 아니다. timing 속성까지 원본 객체 전체가 동일하다는 주장도 하지 않는다. 프로파일 비용을 속도 개선으로 해석하지 않는다.
