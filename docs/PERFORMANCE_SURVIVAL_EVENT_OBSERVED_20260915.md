# 사건 관측 코드 검사에 준비된 문자열 재사용

`survival_preflight`의 미매핑 코드 검사에서 이미 준비한 `event_text`를 재사용한다. NA/NaN을 원래 사건 벡터의 `is.na`로 제외한 뒤 기존 순서대로 unique와 setdiff를 수행한다. 사건 매핑, 제외 사유, 행 순서와 분석 수식은 변경하지 않았다.

조건은 속성 없는 integer/double 사건 벡터, 클래스가 정확히 data.frame이고 모든 열이 속성 없는 문자인 입력 매핑, 속성 없는 문자 관심 사건값이다. 이외의 입력은 기존 변환을 유지한다. 자동 매핑은 기존의 관측 코드 재검사 생략 경로를 그대로 사용한다.

특수 매핑 열이나 관심 사건값의 사용자 정의 변환은 숫자 표시 옵션을 바꿀 수도 있다. 따라서 사건 벡터가 일반 숫자라는 조건만으로 재사용하지 않는다. 초기 후보에서 이 보호 조건을 추가한 뒤 최종 코드를 다시 측정했다.

## 검증

- `validate_survival_event_observed.R`: 이번 변경의 전체 전처리 168개 비교 및 숫자 표시 옵션을 바꾸는 사용자 정의 변환 2개 비교. 정수/실수/극소·극대/NA/NaN/Inf, 문자/factor/날짜/이름/특수 클래스, 자동/명시적/중복/불완전 매핑, 단일 기록·지연 진입·시작–종료 포함.
- 위 스크립트가 불러오는 이전 매핑 검사의 helper 294개와 전처리 36개도 통과한다. 이들은 별도 회귀 검사이며 이번 변경의 168개와 구분한다.
- 전처리 성능 스크립트는 프로세스마다 성공 결과·분석 행 수와 전체 결과 76개를 확인한다.
- Cox 성능 스크립트는 명시적 매핑에서 기본·층화·군집·스플라인 성공 모형과 유한 계수를 확인하고 프로세스마다 전체 결과 44개·보조 전처리 5개를 비교한다.
- 전체 값/속성·진단·stdout·RNG는 `identical(..., num.eq=FALSE)`로 비교한다. Cox에서만 수식의 `.Environment` 속성(call 내부 포함)을 제외한다. 수치 허용오차는 사용하지 않는다.
- 기존 `validate_survival_preflight.R` 종합 검사도 앱 bootstrap·모듈·환경설정 초기화 후 통과했다. KM/Cox, 사건 매핑·범위, 지연 진입·시작–종료, 경쟁위험 등 기존 검사 범위를 포함한다.

## 최종 측정 결과

각 칸은 기존→변경 중앙값(ms)이다. 두 독립 실행 모두 최종 보호 조건을 포함한다.

| 전처리 조건 | 실행 1 | 실행 2 |
|---|---:|---:|
| 명시적 매핑 100,000행 | 53.47 → 39.74 | 52.15 → 38.19 |
| 명시적 매핑 1,000행 | 2.71 → 2.69 | 2.92 → 2.70 |
| 자동 매핑 100,000행 | 52.80 → 53.07 | 53.66 → 53.12 |
| 자동 매핑 1,000행 | 2.71 → 2.61 | 2.39 → 2.77 |

100,000행 명시적 매핑 전처리는 약 26~27% 단축했다. 작은 명시적 매핑에서는 차이가 작다. 자동 매핑 경로는 변경하지 않았고, 작은 자료에서 실행별 변동이 있으므로 개선을 주장하지 않는다.

| 전체 Cox 옵션 | 실행 1 | 실행 2 |
|---|---:|---:|
| 기본 | 195.49 → 193.09 | 185.76 → 193.31 |
| 층화 | 190.48 → 190.96 | 194.45 → 195.07 |
| 군집 | 220.09 → 213.91 | 218.17 → 207.15 |
| 스플라인 | 291.02 → 289.62 | 294.30 → 282.53 |

전체 Cox는 군집·스플라인에서 단축됐지만 기본은 방향이 달랐고 층화는 미세하게 증가했다. 전체 분석의 일관된 개선율로 확대하지 않는다. 최종 코드 두 프로세스의 전처리 76개씩, Cox/보조 전처리 49개씩 비교는 모두 통과했다.

## 측정 방법과 산출물

번들 R 4.5.3, 실제 앱 모듈·초기 환경설정, 두 독립 프로세스와 양쪽 함수 컴파일. 기존/변경을 번갈아 실행한다. 전처리는 준비 후 9회 중앙값(1,000/100,000행), Cox는 준비 후 5회 중앙값(20,000행·공변량 6개). 진단/stdout 수집은 포함하고 비교·환경 정규화는 타이머 밖에서 수행한다.

최종 산출물은 `output/survival-event-observed-20260915/final/`의 `preflight-times-1.csv`, `preflight-times-2.csv`, `times-1.csv`, `times-2.csv`이다. 상위 디렉터리는 보호 조건 보강 전 후보 측정이므로 최종 성능 근거에서 제외한다. 초기 측정 중 실행 스크립트 수정으로 종료 시 구문 오류가 한 번 발생했고, 최종 검사는 실행 파일을 고정한 뒤 별도 경로에서 처음부터 재실행했다.

- 기준 함수: `scripts/fixtures/survival_event_observed_reference.R` (이번 변경 전 preflight). 이전 사건 매핑 개선은 양쪽에 유지한다.
- 제품 SHA256: `599435514555A40D2EBD96DD10B39C56F18E7762CC4564D145BBE27D0F90E500`.
- 기준 함수 SHA256: `F979529EE6216C367ACDD6979AB47F88DFB9B6B8BA4DFC4674D1AD58FCEC24F8`.

전체 앱 로딩·브라우저 렌더링·내보내기 성능을 측정한 것은 아니다. 출력 변경이 없으며 모든 파일 형식의 현재/누적 내보내기를 새로 검사한 것은 아니다.
