# HTMT 요인 내부 평균 재사용 — 2026-09-13

## 변경

`R/setup_custom_model_canvas_structural_validity.R`의 `structural_canvas_htmt()`에서 요인 내부 절대 상관계수 평균을 같은 함수 호출 안에서 재사용한다. 요인이 k개이면 모든 쌍이 유효한 경우 내부 평균 계산은 k(k−1)회에서 k회로 줄어든다. 내부 행렬을 중복 추출하던 부분도 한 번으로 줄였다.

캐시는 상관행렬 하나를 처리하는 호출에만 존재한다. 부트스트랩 재표집과 BCa 잭나이프마다 새로 계산한다. 각 쌍의 지표 수·교차부하·누락 검사를 먼저 거친 뒤 필요한 평균만 구하므로 진단 순서를 유지한다. `NaN`도 계산 완료 값으로 저장한다. 평균의 입력 순서, 절댓값, 결측 처리, 분모와 비율 산식, 표 작성 순서는 유지했다. 기존 `include_pairs` 최적화에 추가한 변경이며 이전 변경분을 이번 속도 개선에 포함하지 않았다.

## 성능

동봉 R 4.5.3, 300행·30지표·10요인 합성 자료. 변경 전후 순서를 번갈아 5회 측정한 중앙값이다. 단일 행렬은 회당 100회, 공개 표는 30회 묶음의 호출당 시간이다.

| 측정 범위 | 변경 전 | 변경 후 | 배속 |
|---|---:|---:|---:|
| HTMT 행렬만 | 1.60 ms | 1.10 ms | 1.45 |
| 공개 HTMT 표 포함 | 7.67 ms | 7.33 ms | 1.05 |
| HTMT 부트스트랩 500회 | 1.23초 | 1.00초 | 1.23 |

500회 HTMT 부트스트랩 시간은 이 자료에서 약 19% 감소했다. 전체 CFA 적합이나 앱 로딩 개선율은 아니다. 표 생성 비용이 큰 공개 함수의 개선 폭은 작다.

## 검증

- `scripts/validate_htmt_within_cache.R`: 209개 비교에서 값·속성·경고·메시지·오류·난수 상태를 `identical(..., num.eq = FALSE)`로 확인했다. 행렬/표, 결측·비유한 값·상수·지표 누락·교차부하·중복 이름·지표 순서·잘못된 행렬, 연속형/순서형 부트스트랩 percentile·BC·BCa를 포함한다. 진행률 및 취소 동작도 비교했다.
- 평균 호출 수 계측으로 요인당 재사용, 새 행렬에서 재계산, `NaN`의 재사용을 확인한다.
- `validate_result_preserving_fast_paths.R` 통과: 이전 HTMT 행렬 경로, ICC 난수, 번역 캐시/JIT, 단일 Shiny 로더.
- `validate_structural_screen_export_contract.R` 통과: HTML/PDF 페이지 계약 및 Word·Excel 저장.
- 측정 시 변경 직전 실제 파일을 별도 환경에 로드해 공개 표 및 100회 부트스트랩 반환값도 정확 비교했다.

표시·저장 내용은 변경하지 않았다. 모든 가능한 입력에 대한 증명은 아니며 위 시험 범위의 정확 일치 검증이다. 설치 파일은 재빌드하지 않았다.
