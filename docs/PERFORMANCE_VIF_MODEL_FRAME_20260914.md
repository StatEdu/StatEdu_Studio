# VIF 보조회귀의 모형 프레임 구성 생략 검토 — 2026-09-14

## 판단

후보는 적용하지 않았다. 이항과 순서형 입력의 다항 자동 전환 경로에서는 전체 분석 시간이 줄었지만, 명목형 다항 경로는 세 쌍 모두 조금 느려졌다. 공통 함수의 영향 범위와 추가 조건 관리를 고려할 때 일괄 적용할 근거가 충분하지 않다. 앞서 적용한 로지스틱 기준 모형 캐시는 유지한다.

## 후보

공통 `coefficient_collinearity()`는 예측변수마다 `stats::lm(y ~ ., data=others)`를 호출한다. 후보는 완전하고 유한한 일반 숫자 행렬에서 절편을 포함한 설계 행렬을 한 번 만들고, 열 순서를 유지해 `stats::lm.fit()`에 전달한다. 기존 `summary()`로 R²를 계산하며 QR 허용오차나 제곱합 계산식은 바꾸지 않는다. 필요한 terms와 lm 클래스를 구성한다.

고속 경로는 행이 2개 이상인 비객체 integer/double 행렬, 중복 없는 열 이름, 문법적으로 표준적인 예측변수 이름, 기본 `na.action='na.omit'`, 모든 원소 유한 조건에서만 사용한다. 예측변수 이름 `y`는 기존 수식의 반응 이름과 충돌할 수 있어 고속 경로에서 제외한다. 나머지는 기존 lm 경로를 유지한다. 동일한 이름이 중복된 열은 제외하지만, 값이 중복된 특이 행렬은 lm.fit의 기존 허용 동작을 사용하고 직접 비교했다.

이전 VIF 검토의 summary 생략이나 `.lm.fit` 후보는 포함하지 않았다. 번들 R 4.5.3의 `summary.lm` 소스를 로컬에서 읽고 이번 후보의 R² 계산 경로를 확인했다. 모든 lm 객체 사용처를 대체하는 구현은 아니다.

## 전체 로지스틱 분석 시간

5만 행, 연속 예측변수 6개를 두 개씩 추가하는 3단계 모형이다. 현재 로지스틱 기준 모형 캐시는 두 버전 모두 사용한다.

| 입력과 실제 분석 | 현재 3회(초) | 후보 3회(초) | 중앙값(초) |
|---|---|---|---|
| 이항 → 이항 | 1.04 / 1.03 / 1.02 | 0.92 / 0.92 / 0.93 | 1.03 → 0.92 |
| 순서형 → 다항 자동 전환 | 3.82 / 3.87 / 3.82 | 3.36 / 3.35 / 3.38 | 3.82 → 3.36 |
| 명목형 → 다항 | 2.91 / 2.90 / 2.94 | 2.98 / 2.99 / 3.00 | 2.91 → 2.99 |

이항 중앙값은 약 10.7%, 순서형 입력의 자동 전환 경로는 약 12.0% 감소했다. 명목형 다항은 약 2.7% 증가했다. 순서형 입력은 기존 평행선 검정에 따라 다항으로 전환된 자료이며 순수 순서형 회귀의 개선율을 뜻하지 않는다. 프로파일·GC 분석으로 차이의 내부 원인을 특정하지 않았으며 3회 측정으로 통계적 유의성을 주장하지 않는다.

각 버전은 새 프로세스 3개에서 순차 실행했고 두 번째 세트는 후보부터 실행했다. 각 프로세스의 조건 순서는 이항→순서형→명목형이다. 조건별로 같은 종류의 360행 자료를 준비 실행했다. 입력 생성·부트스트랩·모듈 로딩·사전 GC는 제외하고 전체 결과 준비, 진단/표준출력 수집 및 비교용 공식 환경 정규화는 포함했다. 각 조건의 실행 상태에는 앞선 조건 및 준비 실행의 영향이 있을 수 있으며 모형 종류별 완전한 첫 실행을 따로 측정한 것은 아니다. 다른 R 작업을 동시에 실행하지 않았다.

## 검증과 범위

- 직접 비교 160조건: 행 수 0/1/2/80 × 예측변수 0/1/3/8 × 일반·NA·Inf·상수·중복 값·y 열 이름·특수 열 이름·행 이름·1e100 배율·1e-100 배율. 조건에 따라 적합 결과 또는 오류/진단이 같음을 확인했다.
- 사용자 지정 결측 처리 함수가 내는 경고도 별도로 비교해 일치했다.
- 전체 로지스틱 결과 18조건이 일치했다: 이항·순서형·명목형 × 일반·결측·범주형 예측변수·상수·중복열·반올림 예측변수.
- 전체 시간 측정의 결과 9쌍도 일치했다. 반환값·진단·표준출력·난수 상태를 `identical(..., num.eq=FALSE)`로 비교했다. 전체 결과의 공식 환경만 `.GlobalEnv`로 정규화했고 수치 허용오차는 사용하지 않았다.
- 최초 직접 검사에서 0열 행렬에 열 이름을 넣는 시험 자료 생성 오류는 수정한 후 전체 160조건을 실행했다. 운영 함수의 오류가 아니다.

공통 함수는 로지스틱 외에 선형회귀, ANCOVA 및 일반화 모형에서도 사용된다. 이들의 전체 출력 경로와 다른 R 버전, 모든 사용자 정의 클래스/메서드를 이번에 검증하지 않았다. 메모리, 화면, 내보내기, 프로그램 로딩 시간도 이번에 측정하지 않았다.
