# 생존분석 시간·구간 제외 사유 다국어 점검

시간 값 형식 오류, 유효하지 않은 시간, 진입 시간 결측, 시간 순서 오류,
구간 시간 결측, 유효하지 않은 구간 시간, 대상자 ID 결측, 위험 구간 중복,
사건 발생 후 구간, 대상자별 다중 사건의 10개 내부 코드를 보조표에서 번역한다.
한국어와 6개 추가 언어를 지원하며 영어는 기존 코드 표시를 유지한다.
정확히 일치하는 알려진 코드만 번역하고 알 수 없는 사유는 보존한다.

## 검증

- `validate_survival_interval_i18n.R`: single-record, entry-exit, start-stop 자료를 실제
  `survival_preflight`에 전달하여 10개 사유가 생성되는지 확인했다.
  분석을 차단하는 오류 자료이므로 모형 적합을 시도하지 않고 실제 제외 집계 함수를 검증했다.
- 세 사전검사 표와 사용자 문구 표를 8개 언어로 검사했다. 제외 건수와 표시 정밀도,
  `Review`, `사용자 <&> %s` 보존을 확인했다.
- 기존 `validate_survival_inclusion_i18n.R` 통과: 결측 사유, 실제 Cox 본 표의 영어 유지.
- 일본어 결과 스냅샷으로 현재 4개 표, 누적 5개 표의 HTML/PDF/Word/HWPX/Excel
  내보내기를 확인했다. PDF 내용·표지, 표 순서 및 Excel 시트 수 검사를 통과했다.
  저장은 스냅샷 변환이며 분석을 다시 실행하지 않는다.

설치본은 만들지 않았다. 전체 다국어 완료를 의미하지 않으며, 사건 코드 관련 나머지
제외 사유와 기타 생존분석 보조표는 별도 점검 대상이다.
