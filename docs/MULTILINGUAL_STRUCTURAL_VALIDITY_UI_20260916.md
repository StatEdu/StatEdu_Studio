# 구조방정식 타당도 설정 다국어

- 타당도 탭의 AVE/CR 계산 방식, MI 표본분할, parcel 설정, PLS 중복성 분석 설명 등 18문구를 번역 경로에 연결했다.
- PLS 서버가 기준변수 목록을 갱신할 때도 ‘선택하지 않음’이 UI 언어를 따르도록 수정했다. 변수명 자체는 번역하지 않는다.
- 자료: `scripts/fill_structural_validity_ui_i18n.py`.

## 검증

- `validate_structural_validity_ui_i18n.R`: 3분석 × 8언어 통과. 타당도 라벨·선택지·설명·입력 힌트와 입력 ID/값/기본값/조건식을 검사했다.
- 실제 서버 소스의 기준변수 선택지 생성식을 실행하여, UI 문구가 번역되고 사용자 변수 `Normality`, `사용자 변수`와 내부 값이 보존됨을 확인했다.
- 수정 전/후 영어 HTML은 자동 생성 탭 ID 정규화 후 동일하다. 공통 사전 검사도 통과했다.
- 로그: `tmp/structural-validity-ui-i18n.log`, `tmp/structural-validity-ui-coverage.log`.

## 제한

- UI 설정 및 선택지 갱신 문구만 수정했다. 통계 계산/결과표/저장 내용은 변경하지 않아 이번 수정에는 5형식 결과 저장 검사가 해당하지 않는다.
- 실제 브라우저에서 요인/변수를 선택하고 언어를 바꾸는 검사 및 parcel/중복성 분석 실행은 이번 검사에 포함되지 않는다.
- 진단·공통방법 설정, 실제 모형별 결과 검증은 남아 있다. 이전 복합표본 사용자 모형의 HWPX 시간 초과는 미해결이며 설치본을 만들지 않았다.
