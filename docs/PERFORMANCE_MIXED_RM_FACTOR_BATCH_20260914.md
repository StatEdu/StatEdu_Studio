# 혼합 반복측정 범주형 공변량 일괄 회귀

2026-09-14. 기존 일괄 회귀의 적용 조건을 기본 대비 코딩의 일반 factor까지 확장했다. 회귀·공분산·기준 행렬·검정통계량 계산 코드는 그대로 사용한다. 전체 시점 비교에 내부적으로 포함되는 집단 변수도 이 조건을 만족하므로 숫자 공변량만 선택한 분석에도 효과가 있다.

## 적용 조건

- 정확히 `factor` 클래스인 변수이며 값과 수준 이름에 결측이 없어야 한다.
- 변수에 `contrasts` 속성이 없어야 하며, 전역 contrasts가 기본 `contr.treatment` / `contr.poly` 조합이어야 한다.
- 순서형 factor, 사용자 지정 대비 행렬·함수, 다른 전역 대비 옵션은 기존 개별 계산을 사용한다.
- 기존 유한 숫자 반응, 같은 행 수, 기본 NA 처리, 대비 행렬 원소 수 제한, 오류·경고 시 개별 경로 전환을 유지한다.

사용하지 않는 수준 제거 및 한 수준만 남은 공변량 제거는 기존 함수를 그대로 사용한다. 수준 순서나 대비 코딩을 새로 지정하지 않는다.

## 전체 분석 시간

2,000명, 4집단, 6시점, Holm 사후 비교, 가정 검정 비활성화. 각 조건에서 기존/변경 버전별 새 R 프로세스 3개를 순차 실행하고 두 번째 쌍의 순서를 뒤집었다. HTML 생성은 분석 시간에서 제외했다.

| 조건 / 중앙값 | 기존 | 변경 |
|---|---:|---:|
| 숫자 공변량 1개 / 첫 실행 | 0.78초 | 0.71초 |
| 숫자 공변량 1개 / 반복 실행 | 0.25초 | 0.20초 |
| 숫자 + 범주형 공변량 / 첫 실행 | 0.94초 | 0.74초 |
| 숫자 + 범주형 공변량 / 반복 실행 | 0.39초 | 0.24초 |

반복 실행 중앙값 기준 각각 약 20%, 38% 감소했다. 범주형 조건의 개별 반복 시간은 기존 0.39/0.42/0.39초, 변경 0.23/0.25/0.24초다. 이 데이터·환경에서의 측정으로 모든 분석의 같은 개선율을 보장하지 않는다. 가정 검정을 켰던 직전 병목 조사 수치와 합산하지 않는다.

## 검증

- `scripts/validate_mixed_rm_factor_batch.R`: 기본 factor, 수준 역순, 미사용 수준, 단일 수준, 복수 factor, 공선성, 결측 factor/반응, ordered factor, 대비 행렬·함수 지정, 전역 sum 대비, na.exclude의 13조건 × 5입력 = 65건. 반올림 전 검정 결과·조건·표준출력·난수 상태가 개별 계산과 정확히 일치했다. 제공된 공분산 450개도 표준 `vcov(lm)`과 정확히 일치했다. 지원 조건에서 일괄 경로를, 미지원 조건에서 개별 경로를 실제로 사용함을 확인했다.
- 기존 `scripts/validate_mixed_rm_batch_pairs.R` 64개 경계조건 통과.
- 전체 분석 12개 시나리오 및 숫자/범주형 성능 측정 각 3쌍: 허용오차 0, 환경 객체 제외 결과 비교 통과. 공선성과 단일 집단 시나리오는 기존과 같은 분석 오류 반환을 확인한 경우다.
- 일반 HTML 정확히 일치. 보고서 HTML은 생성 시각만 정규화해 일치. 현재·누적 HTML 및 Excel 패키지 내용 비교 통과(Excel 생성 타임스탬프 제외).
- 기존 `scripts/validate_mixed_rm_anova.R` 통과. 기존 singular fit 안내가 출력된다.
- 관련 파일 `git diff --check` 통과.
- 범주형 공변량을 포함한 현재·누적 결과의 HTML/PDF/Word/HWPX/Excel 총 10개 파일 생성 성공. Word/HWPX 셀 내용이 HTML과 각각 694/1,388개 일치. PDF는 기존 표지 포함 9/17페이지이며 이미지는 표지에만 존재한다. 현재 PDF 본문 첫 페이지를 시각 확인했다.
