# 경쟁위험 회귀 공선성 표 설명

원인별 Cox·Fine–Gray 공선성 제목과 조건수 설명의 4개 항목을 번역했다.
조건수를 먼저 문장에 넣지 않고 번역 템플릿을 선택한 뒤 기존 정밀도로 삽입한다.

## 검증

- `validate_competing_collinearity_notes_i18n.R`: 실제 원인별 Cox와 Fine–Gray를 모두
  적합하여 8개 언어의 표·설명을 검사했다.
- 수치·변수명, 조건수 값 및 결측 표시, 두 영어 계수 본 표 유지 확인.
- 검열분포 표 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 표·설명의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 다른 생존분석 제목·설명의 잔여 누락은 계속 점검해야 한다.
