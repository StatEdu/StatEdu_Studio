# 음이항 θ 중복 계산 최적화 제품 연결 — 2026-09-14

일반화 카운트 모형에서 검증한 θ 추정 최적화를 사용하도록 연결했다. `generalized_glm_nb()`는 MASS의 함수 사본에 전용 환경을 붙여 최적화된 `theta.ml`을 제공한다. 설치된 패키지 파일이나 MASS 네임스페이스 바인딩을 수정하지 않는다. 반환 모형에 저장되는 호출식의 함수명은 기존 `MASS::glm.nb`로 유지한다.

## 호환성 제한

- MASS 7.3.65 및 검증한 `theta.ml`·`glm.nb`의 인수와 함수 본문 서명이 모두 일치할 때만 변환한다. 버전·함수 본문이 다르거나 digest를 사용할 수 없으면 원래 glm.nb를 사용한다.
- 이름만 속성으로 가진 일반 숫자 벡터, 1,000개 이상, 유한한 비음수 정수, 고유값 수가 전체의 절반 이하인 카운트에서 특수함수를 재사용한다. 원래 순서와 이름을 복원한다. 조건 밖에서는 원래 특수함수 식을 평가한다.
- `digamma(theta+y)`·`trigamma(theta+y)`의 중복만 줄인다. 가중치·합산 순서·초깃값·반복 종료·표준오차·경고 계산은 유지한다.
- 함수 생성과 호환성 확인은 호출 시 수행한다. 패키지 업데이트 후 검증되지 않은 구현을 계속 사용하는 캐시는 두지 않았다.

처음에는 함수 표현식을 직접 직렬화한 해시를 사용했으나, 최초 적합 후 중첩 함수의 내부 컴파일 상태로 인해 해시가 달라졌다. 고정 폭으로 표현한 인수·본문 코드의 서명을 확인하도록 보완했고 최초/반복 실행에서 최적화 경로가 유지되는 것을 검증했다.

세 번 모두 빨라졌다. 직전 네임스페이스 교체 실험의 시간과 직접 비교한 개선율은 아니며, 같은 측정 내 기존/제품 연결 비교다. 중복이 적은 카운트 자료 전체 분석의 속도는 별도 측정하지 않았다.

## 검증

- `scripts/validate_generalized_theta_reuse.R`: 72개 카운트·가중치·경계 조건과 반복 제한 3개, 총 75개에서 θ·표준오차 등의 속성·오류/경고/메시지 클래스와 문자열·trace 출력·난수 상태가 정확히 일치했다.
- 일반/가중치/0 가중치/결측/오프셋/선형 종속의 6개 2,000행 음이항 모형에서 전체 반환 구조와 수치, 저장된 호출식을 비교했다. 비교 시 공식·terms의 환경만 통일하고 함수는 인수·본문으로 비교했다. 따라서 클로저 환경까지 원시 객체가 동일하다는 의미는 아니다.
- 지원하지 않는 버전, 변경된 θ 함수, 변경된 glm.nb의 기존 함수 반환과 최초 적합 후 최적화 활성화를 검증했다. 원본 MASS θ 함수도 유지됨을 확인했다.
- 전체 프로그램 비교의 두 자료 × 세 프로세스에서 반환 내용과 계수·적합값·잔차·deviance·weights·theta·SE.theta, 경고/메시지 문자열·난수 상태가 일치했다. 모형 객체를 제외한 반환 내용에서는 공식 환경만 통일했다.
- 수치 허용오차 없이 `identical(..., num.eq=FALSE)`를 사용했다. 조건 객체의 호출 환경 자체는 비교하지 않았다.
- 기존 `scripts/validate_generalized.R` 통과. 이 검증은 일반·이항·음이항 모형, 결측 처리와 MI/IPW 등 기존 검증 범위 및 설정 UI를 포함한다.
