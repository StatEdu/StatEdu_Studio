# 동일방법편의 진단 제목·안내 다국어 점검

- 범위: CFA/SEM 동일방법편의 진단의 제목, 판정 요약·모형 적합도 비교·모형 차이 비교·적재량 변화 소제목, 결과 없음 안내, 해석 주의문.
- 기존 한국어·영어 문구는 유지하고 일본어·중국어·스페인어·프랑스어·독일어·베트남어 사전 조회를 적용했다. 분석 계산과 숫자 형식은 변경하지 않았다.
- `scripts/fill_common_method_panel_i18n.py`로 6개 언어의 7개 문구를 등록했다.
- `scripts/validate_common_method_panel_i18n.R`: 실제 등록된 renderUI 표현식으로 8개 언어의 정상/빈 결과를 검증했다. 비활성화와 PLS 분기에서는 출력이 없는 것도 확인했다. 변수 이름, 특수문자, 수치 보존을 확인했다.
- `tmp/common-method-panel-i18n/entries.rds`의 표시 스냅샷으로 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 검증을 통과했다. 현재 6표, 누적 11표의 순서와 Excel 시트 수를 확인했다. PDF의 일본어 문구 및 표지를 별도로 검증했다. 분석 재실행 없이 변환했다.
- 빈 결과 안내는 실제 안내 HTML에 대표 본표를 함께 넣어 Excel 저장을 검증했다.
- 남은 범위: 동일방법편의 표 내부의 방법명·판정 사유·동적 해석 문구 및 사용자 문자열 보호는 후속 점검이 필요하다. 이번 검증은 이 영역 전체의 번역 완료를 의미하지 않는다.
- 설치본은 생성하지 않았다.
