# GEE QIC 내부 재적합 재사용 검토

## 결론

이번에 검토한 QIC 재적합 캐시 후보는 적용하지 않았다. 무조건 재사용하는 시제품은 실제 가중 이항모형의 경고 2회를 누락했다. 호출 객체의 동일성을 검사하는 제한형은 측정 자료에서 캐시가 적중하지 않아 계산량을 줄이지 못했다. 앞서 적용한 GEE 선택 모형 재사용은 그대로 유지한다.

이는 QIC 최적화 자체가 불가능하다는 결론은 아니다. 서로 다른 formula/family 객체가 이 앱의 특정 범위에서 같은 계산을 뜻한다는 별도의 계약과 검증 없이 객체 동일성 검사를 느슨하게 하지 않았다.

## 검토한 후보

현재 설치된 `geepack::QIC.geeglm` 메서드를 별도 환경으로 복사하고, 내부 `eval(object$call, envir = env)`만 실험용 재사용 함수로 바꿨다. QIC 산술식, 역행렬 선택, 계산 순서는 유지했다. 패키지 namespace와 제품 소스는 수정하지 않았다.

캐시 수명은 민감도 분석 한 번이다. 첫 QIC가 실행한 independence 모형을 다음 QIC에서 재사용하는 방식으로, 두 조건을 비교했다.

- 무조건 재사용: 뒤의 두 재적합을 생략한다. 안전성을 주장하지 않는 연구용 시제품이다.
- 호출 동일성 제한: 변형된 호출 객체가 `identical`일 때만 재사용하고, 경고·메시지 또는 RNG 변화가 있으면 캐시에 저장하지 않는다. 이 조건만으로 임의의 외부 평가 환경까지 안전하다고 주장하지 않는다.

## 실제 경고 누락 재현

seed 938, 100명 × 4시점, binomial, exchangeable, 두 공변량, 0.7–1.3의 비정수 sampling 가중치를 사용했다.

무조건 재사용 후보는 전체 반환 결과와 QIC 원값, 표준 출력, 최종 RNG가 비교상 일치했지만 경고/메시지 목록은 달랐다. 경고는 `non-integer #successes in a binomial glm!`이며 기존 7회가 후보에서는 5회로 줄었다. 따라서 수치가 같다는 이유만으로 적용할 수 없다.

## 호출 동일성 제한의 성능

번들 R 4.5.3, seed 936, 5,000명 × 4시점 = 20,000행, 두 공변량, 선택 상관구조 exchangeable, 기본 분석 옵션. 각 프로세스에서 워밍업 후 전체 분석을 측정했다. 독립 R 프로세스 3개를 순차 실행했고 두 번째 프로세스에서는 후보부터 측정했다. 로딩 시간은 제외했다.

| 분포 | 현재 코드 1 / 2 / 3 (초) | 제한형 후보 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| gaussian | 2.09 / 1.68 / 2.12 | 1.68 / 2.11 / 1.70 | 2.09 → 1.70 |
| binomial | 1.67 / 1.69 / 1.70 | 1.89 / 1.71 / 1.89 | 1.69 → 1.89 |

모든 측정에서 QIC 내부 재적합은 3회로 유지되어 캐시 적중이 없었다. Gaussian의 시간 감소를 재적합 제거의 효과로 해석할 수 없고, binomial은 세 번 모두 느려졌다. 이 후보의 유용한 전체 성능 개선을 확인하지 못했다.

실제 QIC 호출을 저장해 비교한 결과, corstr를 independence로 바꾼 뒤에도 첫 호출과 두 번째/세 번째 호출의 formula 및 family 객체가 `identical`하지 않았다. 이 차이는 수치 결과가 다르다는 의미는 아니지만, 객체 동일성을 기준으로 한 캐시는 사용할 수 없었다.

## 검증 범위

제한형의 2개 분포 × 3개 프로세스에서 워밍업 및 측정 결과를 현재 소스와 비교했다. 전체 반환 객체, 조건 클래스/본문/순서, 표준 출력, RNG, QIC 반환 벡터 3개가 `identical(..., num.eq = FALSE)`로 일치했다. 앞선 검증과 같이 formula/terms 환경 및 저장된 함수 표현만 정규화했고 수치 허용오차는 사용하지 않았다. 원시 환경·함수 객체의 동일성을 주장하지 않는다.

무조건 재사용의 초기 20,000행 시험은 한 프로세스에서만 수행했으므로 그 시간을 확정 개선율로 제시하지 않는다. 위 가중치 사례에서 진단 동등성이 실패하여 적용 대상에서 제외했다.
