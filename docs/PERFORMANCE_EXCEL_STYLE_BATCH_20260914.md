# Excel 서식 적용 호출 묶기 — 2026-09-14

`R/result_saved_ui.R`의 `add_screen_excel_table()`에서 같은 행에 연속된 일반 셀의 서식이 같으면 `openxlsx::addStyle()`을 한 번 호출하도록 변경했다. 행, 서식 또는 열의 연속성이 달라지면 대기 중인 구간을 먼저 적용한다. 병합 셀은 대기 구간을 먼저 적용한 뒤 기존처럼 개별 병합 및 서식 적용을 수행한다. 마지막 구간도 반드시 적용한다. 원래 적용 순서와 `stack = TRUE`를 유지한다.

앞선 값 쓰기 묶음 처리와 서식 객체 캐시는 비교 양쪽에 모두 포함된다. 통계 계산, 셀 값, 표시 정밀도, 표 순서, 주석, 너비·높이 및 인쇄 설정은 변경하지 않았다.
