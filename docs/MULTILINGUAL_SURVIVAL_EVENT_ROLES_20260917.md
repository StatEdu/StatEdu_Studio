# 사건 코드 매핑의 역할 표시

관심 사건·경쟁사건·검열·기타 상태·제외·미확인 6가지 역할에 보조표 전용 번역 키를
추가했다. 기존 event_of_interest 키는 입력 옵션의 코드값을 뜻하므로 재사용하지 않는다.
Raw value/Role/Label 구조의 사건 매핑 표에만 적용한다. 원자료 코드, 사용자 라벨과
알 수 없는 역할 문자열은 보존한다. 영어의 내부 코드 표시는 기존대로 유지한다.

## 검증

- `validate_survival_event_roles_i18n.R`: 실제 사전검사에서 만든 사건 매핑 표의 6개
  역할을 8개 언어로 검사. unknown/other_state를 포함하는 검사 자료는 모형 적합용이 아니다.
- 표시용 표에서 원자료 코드와 라벨이 번역 문구와 같거나 특수문자를 포함해도 보존됨을 확인.
- 기존 분석 대상/제외 사유 검사와 실제 Cox 본 표 영어 유지 검사 통과.
- 일본어 현재 2개 표 / 누적 3개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 분석 대상 개요의 다른 항목과 기타 생존분석 보조표는
추가 점검 대상이다.
