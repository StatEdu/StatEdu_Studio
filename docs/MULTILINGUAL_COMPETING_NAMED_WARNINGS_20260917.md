# 경쟁위험 경고의 단일 사용자 이름 보존

## 재현 및 수정

경고 대상 이름이 사전 단어 `Review` 하나인 경우 한국어 출력에서 이름이 재번역되는 문제를 재현했다. 여러 이름을 합친 기존 사례만으로는 드러나지 않는 결함이었다.

다음 네 경고의 조립된 근거 셀을 후속 번역에서 보호한다. 접두 설명은 기존 다국어 번역을 사용하고 사용자 이름은 유지한다.

- Fine–Gray 잔차 시간패턴 변수
- Fine–Gray 희소 검열층
- CIF 무결성 실패 집단
- Gray 검정 추정 실패 사건 코드

## 검증

`scripts/validate_competing_named_warnings_i18n.R`는 실제 Fine–Gray 적합 결과의 진단 메타데이터에 네 경고를 구성한다. 실패 사례를 새로 적합한 검증은 아니다.

- 이름 `Review`, `Normality`, `None`, `사용자 <&> %s`를 각각 단독 경고 대상으로 검사.
- 4개 경고 × 4가지 이름 × 8개 언어에서 원문 보존 통과.
- 경고가 없는 대상 이름이 근거에 포함되지 않는지 확인.
- 회귀 본 표의 동일한 영어 내용 유지 확인.
- 일본어 경고표 캡처로 현재·누적 결과 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/competing-named-warnings-i18n/`.
- 현재 4개·누적 5개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지와 표 순서·시트 수를 확인했다.
- 기존 Fine–Gray 잔차 경고의 8개 언어 회귀 검사도 통과했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
