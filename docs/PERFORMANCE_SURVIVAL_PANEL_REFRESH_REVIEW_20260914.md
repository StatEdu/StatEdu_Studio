# 생존 그래프 빌드 재사용과 최종 축 갱신 — 미적용

2026-09-14. 기존 JIT 최적화가 적용된 운영 코드를 기준으로 검토했다. 이전 빌드 재사용 후보의 y축 불일치를 해결했지만, 첫 분석 실행 이득이 작고 전체 측정 흐름의 단축이 관찰되지 않아 운영 코드에는 적용하지 않았다.

## 후보

첫 `ggplot_build`의 layer data와 학습된 가이드를 보관하고 최종 theme/labels/coordinates를 반영한다. 이어 layout의 coord/coord_params를 갱신하고 `setup_panel_params()` 및 `setup_panel_guides()`를 호출한 뒤 `ggplot_gtable()`로 주 곡선을 그린다. 위험집단 표는 기존 방식으로 생성한다.

번들에 설치된 ggplot2 4.0.2의 `ggplot_build`, Layout 및 CoordCartesian 함수 본문을 확인하여 후보를 작성했다. 첫 빌드의 축 범위를 그대로 사용했던 이전 후보와 달리, 최종 좌표에서 축과 축 가이드를 다시 계산한다. 별도 파일에만 구현했으며 패키지 namespace나 운영 파일은 변경하지 않았다.

## 동일성

- KM 생존/사건/누적위험/로그생존 × 컬러/흑백, CI·중도절단 표시 끔, 위험집단 표 없음, 캡션 없음, 경쟁위험 등 **12개 PNG 쌍이 바이트 단위로 일치**했다. 이전에 달랐던 7개 경우도 포함된다.
- 위 12개 경우의 조건(경고·메시지), 표준 출력, RNG 상태가 같았다.
- 별도 새 프로세스 그림 측정의 **18개 PNG 쌍**, 조건·표준 출력·RNG가 같았고 JIT 3 복원도 확인했다.
- 실제 MockShinySession의 **3개 전체 결과 스냅샷 쌍**이 `identical(..., num.eq=FALSE)`로 같았다. Pearson·KM 결과, 표 HTML/의존성, 경고 및 알림이 포함된다. 경고는 0개였다.

## 성능

번들 R 4.5.3, JIT 3, 모듈 표현식 캐시 사용, 패키지 설치 검사 생략. 각 버전의 handler 측정 3개와 별도 그림 측정 3개, 총 12개의 새 R 프로세스를 순차 실행했다. 두 번째 세트는 버전 순서를 뒤집었다.

handler는 survival_validation.csv 업로드, 변수 선택 및 Pearson 실행 후 첫 KM을 실행한다. 그림 시험은 저장된 동일 KM 결과와 사전 로딩한 survival namespace를 사용하며, 1000×800 PNG/120 dpi로 첫 그림 후 5회 반복 출력한다.

| 중앙값 | 기존(초) | 후보(초) |
|---|---:|---:|
| 첫 KM 실행 | 1.98 | 1.97 |
| 측정 단계 합계 + 모듈 로딩 | 6.84 | 6.88 |
| 별도 첫 그림 출력 | 0.53 | 0.51 |
| 별도 반복 그림 출력(각 버전 15회) | 0.23 | 0.20 |

첫 KM 원시 값은 기존 1.98/1.98/1.98, 후보 1.95/1.97/1.97초다. 반복 그림 출력은 약 0.03초(13%) 줄었으나 첫 KM 중앙값 차이는 0.01초(약 0.5%)다. 전체 흐름 0.04초 차이는 다른 단계의 변동도 포함하므로 후보가 반드시 전체 실행을 느리게 만든다는 근거로 해석하지 않는다. 다만 이번 조건에서는 전체 흐름 단축이 관찰되지 않았다.

위 합계에는 Electron/R 프로세스 시작, 패키지 로딩 및 실제 브라우저 DOM 표시가 포함되지 않는다. MockShinySession의 같은 입력 재실행과 독립적인 그림 반복 출력도 구분해야 한다.

## 판단

그림 일치 문제는 해결했으며 반복 그림 생성에는 소폭 이득이 있다. 그러나 초기 실행 단축은 작고, 빌드된 plot/layout의 내부 상태를 직접 갱신하는 코드가 추가된다. 현재 단계에서는 기존의 전체 빌드 경로를 유지한다. 반복 그림 생성이 실제 대량 내보내기의 병목으로 확인될 경우, 패키지 변경에 대한 호환성 검증과 전체 출력 검증을 포함해 다시 평가할 후보로 남긴다.

이번 PNG 시험만으로 모든 plot/패키지 버전/출력 장치에서의 동일성을 보장하지 않는다. 운영 변경을 채택하지 않았으므로 전체 형식 내보내기 및 설치 파일 재빌드를 진행하지 않았다.
