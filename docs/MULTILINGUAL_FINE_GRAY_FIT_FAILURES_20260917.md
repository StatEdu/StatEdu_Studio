# Fine–Gray 수렴·추정 상태 경고 번역

## 변경

Fine–Gray 수렴 실패와 계수·불확실성 추정 불가의 근거·권고 4개 문구를 일본어·중국어·스페인어·프랑스어·독일어·베트남어 번역표에 추가했다. 기존 영어·한국어 문구, 판정 로직과 통계 계산은 변경하지 않았다.

## 검증

`scripts/validate_fine_gray_fit_failures_i18n.R`는 실제 Fine–Gray 적합 결과의 상태 플래그를 변경하여 경고 분기를 검사한다. 실패 사례를 실제로 다시 적합한 검증은 아니다.

- 정상, 수렴 실패, 추정 불가, 동시 실패, 상태값 NA: 5가지 × 8개 언어 통과.
- 경고 코드와 심각도가 기존 조건에 맞게 유지되는지 확인했다.
- 본 회귀표가 동일한 영어 내용을 유지함을 확인했다.
- 일본어 경고표 캡처를 현재·누적 결과로 저장한다. 저장 시 재분석하지 않는다.
- 산출물: `tmp/fine-gray-fit-failures-i18n/`.
- 현재 4개·누적 5개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서·시트 수를 확인했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
