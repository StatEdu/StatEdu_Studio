# RMST 집단 비교의 행 접근 개선 — 2026-09-14

`R/analysis_survival.R`의 survival_rmst_contrasts에서 각 비교마다 두 개의 한 행 데이터프레임을 만들던 작업을 줄였다. 일반 데이터프레임이고 모든 열이 속성 없는 원자 벡터일 때 열 목록을 한 번 준비한 후 같은 행 인덱스로 값을 추출한다. 특수 클래스·factor·이름 등 열 속성이 있으면 기존 데이터프레임 접근을 유지한다. 차이, 표준오차, 신뢰구간, 비율, p값, Holm 보정의 계산 순서와 식, 결과표 구조는 그대로다.

## 시간

번들 R 4.5.3, 앱 설정 적용, 자동 설치 비활성화. 새 프로세스에서 기존/후보 3쌍을 순차 측정하고 두 번째 쌍은 순서를 반대로 했다. 각 프로세스에서 3집단 다음 100집단을 실행했다. 동일한 전역 환경에 연결한 RMST 집단 비교 함수의 전체 호출 시간을 측정했다. 생존 모형 적합·UI·앱 로딩·내보내기는 포함하지 않는다.

| 집단 수 | 기존 3회(초) | 개선 3회(초) | 중앙값 전→후 |
|---|---|---|---|
| 3 | 0.01 / 0.01 / 0.02 | 0.01 / 0.02 / 0.02 | 0.01→0.02 |
| 100 | 1.62 / 1.64 / 1.63 | 1.45 / 1.44 / 1.46 | 1.63→1.45 |

100집단·4,950쌍에서 약 11% 감소했다. 3집단은 중앙값이 0.01초 증가했으며 작은 작업의 측정값 범위가 겹친다. 소수 집단에서 개선을 주장하지 않는다. 100집단은 많은 비교를 수행하는 부하 조건이며 일반적인 사용 규모를 뜻하지 않는다.

## 검증 및 적용

- 빈 결과, 단일 집단, factor 열, 결측 SE, 0/무한 RMST, 데이터프레임 하위 클래스를 포함한 직접 호출 30조건의 전체 결과·진단·난수 상태가 정확히 일치했다.
- 실제 Kaplan–Meier 적합에서 산출한 RMST 추정치를 사용한 집단 비교 1건도 정확히 일치했다.
- 2·3·5집단의 전체 Kaplan–Meier/RMST 분석 3건에서 결과·진단·난수 상태, HTML 및 의존성이 정확히 일치했다.
- 시간 측정 6쌍의 결과·진단·난수 상태가 identical(..., num.eq=FALSE)로 일치했다.
- 검증 후 실행 모듈에 적용했다. 비교 후보와 실행 모듈의 텍스트 diff에 차이가 없음을 확인했으며 git diff --check도 통과했다. 후보 생성 과정의 줄바꿈 차이로 파일 해시가 달라 measured.R에 원본을 보존하고 current.R에는 최종 실행 모듈을 복사했다.
