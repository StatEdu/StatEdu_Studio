# 로지스틱 회귀 수렴 상태 번역 수정

2026-09-16. 설치본은 만들지 않았다.

- 보조표의 `Converged` 값이 공통 열 제목 번역을 먼저 거쳐 한국어 `수렴 여부`가 되던 문제를 수정했다.
- 원본 상태값에서 전용 키로 수렴함/수렴하지 않음/상태 불명을 번역한다. 공통 열 제목 번역은 그대로 유지하며 사용자 변수명·라벨은 공통 보호 함수로 복원한다.
- `scripts/validate_logistic_ui.R`: 이전에 실패했던 한국어 수렴 상태를 포함해 통과.
- `scripts/validate_logistic_status_i18n.R`: 8개 언어 통과. 실제 이분형 회귀 적합의 수렴 상태 및 본표 셀/주석/영어 속성을 검사했다. 비수렴/상태 불명은 fixture로 검사했다. 상태 문자열과 같은 사용자 값도 보존했다.
- i18n 계약 검사 통과.
- 일본어 실제 회귀 결과와 상태 fixture의 현재·누적 HTML/Word/HWPX/Excel 내용 비교, PDF 생성 및 실제 PDF 텍스트 비교 통과.
- 순서형/다항 분석의 다른 보조표 문구 및 다국어 누락 전체는 추가 점검 대상이다. 이번 검증은 전체 다국어 완료를 의미하지 않는다.
