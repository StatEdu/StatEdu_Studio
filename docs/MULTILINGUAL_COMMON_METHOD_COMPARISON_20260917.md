# 동일방법편의 모형 비교·적재량 변화 표 다국어 점검

- 모형 적합도 비교, 모형 차이 비교, 공통잠재요인 적재량 변화 보조표의 한국어 전용 분기를 공통 언어 조회로 변경했다.
- 연구모형·단일요인 CFA·공통잠재요인의 내부 식별자와 두 비교 이름, 두 해석 문구, 네 적재량 변화 열 이름에 6개 언어 번역을 등록했다. 차이 통계량은 Δχ²·Δdf·Δp·ΔCFI·ΔRMSEA·ΔSRMR 기호로 표시한다. 영어 원문과 기존 한국어 표시는 유지한다.
- 알려진 프로그램 값만 번역하고 모든 셀을 일반 테이블의 추가 번역으로부터 보호한다. 사용자 변수·라벨과 미등록 모형명·메모를 보존한다.
- 계산 및 수치 형식은 변경하지 않았다. 분석 본표는 영어를 유지하며 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_common_method_comparison_i18n.R`: 실제 renderUI 표현식에서 전체 표 및 각 표만 있는 4개 구성 × 8개 언어를 확인했다. 모형 차이는 실제 비교표 생성 함수를 사용했다.
- 각 숫자 셀과 p값 형식, 열 순서, `Review`·`Normality`·`Primary`·한글·특수문자 라벨 보존, 비어 있는 선택 표의 미표시를 검증했다. UI 언어 옵션을 실제로 바꿔 측정모형 본표의 영어 HTML이 동일한지도 확인했다.
- 기존 진단 요약·판정 조합 테스트 및 제목·안내 renderUI 테스트도 통과했다.
- 표시 스냅샷 `tmp/common-method-comparison-i18n/entries.rds`를 기준으로 현재·누적 HTML/PDF/Word/HWPX/Excel 변환을 검증했다. 현재 18표·누적 24표의 순서와 Excel 시트 수, PDF 일본어 문구와 표지를 확인했다. 저장 중 분석 재실행은 하지 않았다.

이 문서는 동일방법편의 진단 패널의 후속 세 표에 대한 검증 기록이며, 프로그램 전체의 다국어 완료 판정은 아니다.
