## 남은 작업 순서와 완료 기준

1. 전용 근거가 없던 화면의 최초 확인을 마쳤다. 구조방정식 자동화는 분석 추천 전용 UI이며 연결된 분석의 완료 근거를 대신하지 않는다. 복합표본 사용자 모형은 HWPX 재검증도 통과하여 대표 검증 근거로 분류한다. 이제 부분 검증 분석군의 실제 모형·오류·언어 왕복을 보완한다.
2. 로지스틱 잔여 분기, 규제회귀, 생존, 구조방정식, 복합표본 등에서 확인된 누락을 수정한다.
3. 모든 분석 화면을 본표/보조표/UI/사용자 데이터 보존으로 나누어 8개 언어를 비교한다. 경고 및 주요 옵션도 포함한다.
4. 언어 왕복·케이스 선택·분할·현재/누적 결과 상태를 확인하고, 출력 수정분의 HTML/PDF/Word/HWPX/Excel을 검증한다.
5. 분석 외 메뉴도 별도 목록으로 마감한다. 화면별 잔여 항목 0, 필요한 실행·저장 검사 통과 시에만 완료 판정한다.

시간 추정과 완료율은 아직 산출하지 않는다. 검증 공백은 확인됐지만 각 화면의 확정 결함 수와 수정 난이도는 아직 다르다. 설치본은 사용자가 요청할 때까지 만들지 않는다.
