# 벌점 회귀 보간의 희소행렬 열 곱셈 검토

## 결론

보간 가중치를 대각행렬로 만든 뒤 곱하는 대신 dgCMatrix의 저장된 값에 열별 가중치를 곱하는 후보를 시험했다. 정상 135개와 인위적 경계 84개, 총 219개 비교에서 원시 결과·진단·출력·RNG가 일치했다. 전체 분석도 세 번 빨라졌지만 중앙값 개선은 1.75→1.69초(약 3.4%)였다.

제품에는 적용하지 않았다. fold 예측 전체에 적용하려면 현재 시험 구조에서는 glmnet의 비공개 교차검증 함수와 예측 호출 경로를 복사·대체해야 한다. 이 구현 및 버전 호환성 부담에 비해 현재 전체 분석 이득은 작다. 수치 불일치나 모든 실행의 성능 악화를 이유로 탈락한 후보는 아니다. 커널 차원의 개선 가능성은 남겨 둔다.

## 시험 코드

기존 predict.glmnet의 보간은 왼쪽·오른쪽 계수 열에 각각 Diagonal 가중치를 곱한 뒤 더한다. 후보는 각 열 부분행렬을 그대로 추출하고 다음과 같이 저장된 값만 곱한 뒤 기존처럼 두 희소행렬을 더한다.

```r
out <- x[, columns, drop = FALSE]
out@x <- out@x * rep(weights, diff(out@p))
```

보간 위치, 가중치 산출, 덧셈, 최종 예측 행렬곱은 그대로다. dgCMatrix의 열 포인터와 값 저장 구조에 의존하는 연구용 구현이며 임의 Matrix 클래스용 일반 함수가 아니다.

정상 원시 검증에서는 설치된 predict.glmnet의 함수 복사본에서 해당 식만 대체했다. 전체 실행 시험에서는 cv.glmnet, cv.glmnet.raw, buildPredmat.default 복사본을 지역 환경으로 연결하고 gaussian fold 예측이 후보를 호출하게 했다. 제품 파일·패키지 namespace·전역 S3 등록은 수정하지 않았다. 제품 소스 스냅샷은 baseline.R에 보관했다.

## 동일성 검증

300행·20개 설명변수, 자료 seed 939/940/941, alpha 0/0.5/1의 모형에 다음 lambda 조합을 사용했다: 전체 경로, 인접 lambda의 기하평균, 0 및 최대값 밖, 반복 lambda, 이름 있는 lambda. coefficients/link/nonzero 세 반환 유형을 비교하여 135건을 완료했다.

후보와 원본의 전체 캡처를 `identical(..., num.eq=FALSE)`로 비교했다. 계수는 밀집 수치만 비교하지 않고 원시 희소행렬 객체까지 일치했다. 예측 행렬, 선택 변수, 조건 클래스·본문·순서, 표준 출력 및 RNG도 일치했다. 별도로 계수의 밀집 표현도 확인했다.

추가로 적합 객체의 첫 저장 계수를 0, -0, Inf, -Inf, NaN, NA, double.xmin으로 바꾼 인위적 경계 자료를 사용했다. 전체 경로/범위 밖/NA/Inf lambda × 세 반환 유형의 84건 모두 원본과 일치했다. 비유한 계수를 정상적으로 적합한 모형이라는 뜻은 아니며, 해당 입력에서의 오류·비유한 결과 보존도 포함한 비교다. 모든 사용자 클래스나 package 옵션을 검증한 것은 아니다.

## 전체 실행 성능

번들 R 4.5.3 및 glmnet 5.0, 자료 seed 939, 분석 seed 7731, 1,000행·설명변수 20개, Ridge/LASSO/Elastic Net, alpha_grid 0.25/0.5/0.75, 방법별 선택 부트스트랩 20회, 워커 1개다. 기본 500회 또는 병렬 실행의 측정은 아니다.

독립 프로세스 3개를 순차 실행했다. 각각 워밍업 후 비교하고 두 번째는 후보를 먼저 측정했다. 로딩은 제외하고 결과 캡처를 포함했다.

| 실행 | 현재(초) | 후보(초) |
|---|---:|---:|
| 1 | 1.84 | 1.45 |
| 2 | 1.72 | 1.67 |
| 3 | 1.75 | 1.69 |
| 중앙값 | 1.75 | 1.69 |

각 실행의 워밍업 및 측정에서 전체 분석 반환 객체·조건·표준 출력·RNG가 허용오차나 정규화 없이 일치했다. 정상 자료 한 종류의 반복 시험이다. 첫 실행의 큰 차이를 일반적인 개선율로 사용하지 않았다. 메모리 할당량과 peak heap은 이번에 측정하지 않았으므로 대각행렬 생성 생략을 메모리 감소율로 환산하지 않는다.
