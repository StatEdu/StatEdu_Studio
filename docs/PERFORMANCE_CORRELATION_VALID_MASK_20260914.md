# 상관분석 사전 점검의 결측 마스크 재사용 — 2026-09-14

`R/analysis_correlation.R`의 `prepare_correlation_results`에서 변수별 유효 관측 수와 고유값 수를 구할 때 중복하던 `!is.na(values)`를 한 번만 계산한다. 같은 마스크를 sum과 고유값 추출에 재사용한다. 변환, 합산, 고유값 계산 방식 및 변수 제외 기준은 유지한다.

## 시간과 할당량

번들 R 4.5.3과 기존 모듈 캐시를 사용해 새 프로세스에서 3쌍을 순차 측정했다. 두 번째 쌍은 순서를 반대로 했다. 변경 전후 함수는 같은 전역 환경으로 연결했다. 25만 행·4변수 숫자형, Pearson, 정규성 검사 비활성 조건이다.

| 입력 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 완전 자료 | 0.17 | 0.17 |
| 변수별 서로 다른 행에 약 10% 결측 | 0.10 | 0.10 |

실행 시간의 중앙값 개선은 확인되지 않았다. 각 프로세스에서 완전 자료 후 결측 자료를 실행했으므로 두 입력 조건의 시간을 직접 비교하지 않는다.

별도 Rprofmem 실험에서 완전 자료의 전체 결과 준비를 함수별 3회 실행한 뒤 1회 기록했다. 누적 할당 바이트는 변경 전 106,392,672, 변경 후 98,392,288로 8,000,384바이트(약 7.5%) 감소했다. 이는 해당 분석 호출에서 기록한 누적 할당량이며 최고 사용량·상주 메모리·프로그램 전체 사용량이 아니다. 작은 코드 변경으로 중복 배열 할당이 줄어 유지한다.

## 검증

- 6개 자료 조건 × 네 분석 방법 × 정규성 옵션의 48조건에서 전체 결과 객체·진단·난수 상태가 정확히 일치했다.
- 성능 측정 6쌍의 전체 결과·진단·난수 상태도 `identical(...,num.eq=FALSE)`로 일치했다.
- 변환 메시지를 내는 사용자 정의 숫자형, 결측, 문자형의 추가 3조건에서 auto 분석 결과 및 HTML/의존성이 같았다. 기존 numeric-data 직접 호출 비교도 통과했다.
