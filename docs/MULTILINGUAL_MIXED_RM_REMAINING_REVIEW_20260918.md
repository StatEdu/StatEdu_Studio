## 검증 범위

`validate_mixed_rm_levene_remaining_i18n.R`는 60명·2집단·3시점의 이분산 자료로 실제 혼합 반복측정 분석을 수행하고 `Levene: potential violation`을 포함한 안내가 번역되는지 확인한다. 영어 본표와 전체 결과 객체 보존도 검사한다.

검정 불가 분기는 한 집단의 사례가 1개인 자료를 `mixed_rm_levene_by_time`에 직접 전달했다. 이 자료는 전체 분석 진입점에서는 먼저 제외되므로, 검정 불가를 전체 앱 화면에서 재현했다고 주장하지 않는다. 진단 함수가 생성한 상태·상세를 기존 안내 형식으로 구성하여 부록 번역을 검사했다.

8개 언어 검사 모두 통과했다. 결과: `tmp/mixed-rm-levene-remaining-review/review.csv`.

## 프로그램 전체 정적 검사 갱신

333개 파일, 4,236개 문구 출현에서 누락 후보 고유 문구는 528개다. 이전 재점검의 543개에서 줄었지만, 영어 본표·별도 번역 키·예외 경로·사용 중단 화면까지 포함한 원시 후보이므로 실제 미번역 개수나 완료율로 해석하지 않는다. 기존 매개·조절효과 화면은 계속 작업 범위에서 제외한다.

제품 출력 변경이 없어 이번에는 저장 파일을 새로 생성하지 않았다. 앞선 가정 안내 수정의 현재/누적 5개 형식 검증 기록은 `MULTILINGUAL_MIXED_RM_ASSUMPTION_FRAGMENTS_20260918.md`에 있다. 나머지 별칭·예외 문구와 다른 분석 영역의 후보는 후속 점검 대상이며 전체 완료를 의미하지 않는다.
