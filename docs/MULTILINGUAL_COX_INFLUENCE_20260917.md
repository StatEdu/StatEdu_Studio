# Cox 영향력 검토 보조표

6개 추가 언어의 번역 사전에 8개 항목을 추가했다: 최대 절대 DFBETA/DFBETAS,
선별 임계값, 검토 신호, 분석 행, 뚜렷한 신호 없음, 영향력 검토 제목 및
2/sqrt(N) 선별 기준과 자동 삭제하지 않는다는 설명문. 기존 한국어/영어 처리와
공통 보조표 번역 경로를 사용하며 분석 코드는 변경하지 않았다.

## 검증

- `validate_cox_influence_i18n.R`: 실제 fixture의 Cox 적합 결과를 사용했다.
  별도의 표시용 복사본에서 검토 신호 TRUE/FALSE 두 경우와 변수명
  `Review`, `사용자 <&> %s`를 추가 검증했다. 복사본은 별도 적합 결과가 아니다.
- 8개 언어의 제목·열 이름·검토 신호·설명 번역, 수치와 행 번호의 동일 표시,
  사용자 변수명 보존 및 실제 본 표의 영어 유지 검사 통과.
- 기존 사건 제외 사유 8개 언어 회귀 검사 통과.
- 일본어 스냅샷 현재 2개 표 / 누적 3개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과.
  PDF 본문·표지, 표 순서, Excel 시트 수 확인. 저장 시 모형 재적합 없음.

설치본은 생성하지 않았다. 생존분석 전체 보조표의 번역 완료를 의미하지 않는다.
