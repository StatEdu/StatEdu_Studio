# Kaplan–Meier 전체 분석의 제외 사유 최적화 통합 검증

제품 코드는 변경하지 않았다. 최근 네 가지 제외 사유 최적화 이전 preflight와 현재 preflight를 사용하는 전체 Kaplan–Meier 분석을 비교한다. 이전의 생존시간·사건 매핑 등 개선은 기준/현재 양쪽에 유지한다. KM에는 공변량 역할이 없으므로 missing_covariate 중복 갱신 방지 경로 자체는 사용하지 않는다.

## 자료와 범위

`scripts/benchmark_km_reason_combined_large.R` 사용. 1,000/100,000행, 집단 3개, 사건 확률 0.7. 경과시간은 `1+floor(rexp(n,.01))`로 만든 양의 정수 일수이다. 사건 동률이 있는 자료이며, 서로 다른 연속 사건 시간이 매우 많은 자료의 성능을 대표하지 않는다. 앞선 Cox 실험의 연속시간 자료와 절대 시간을 비교하지 않는다.

표준 KM과 지연 진입 KM을 모두 실행한다. 진입 시간은 원래 경과시간의 0~50% 사이에서 생성한 정수로 종료보다 이르다. 평가 시점은 0/30/90/180일, RMST tau=180이다. 전체 호출에는 survfit, 로그순위 검정, 집단 간 사후 비교, 곡선 교차 진단, 생존 요약·중앙값·생명표·RMST 준비가 포함된다.

- 정상: 분석 행 1,000/100,000개.
- 중첩: 같은 절반의 행에서 시간·사건·집단·진입 시간이 모두 결측. 분석 행 500/50,000개.
- 분산: 시간·사건·집단의 결측이 서로 다른 행에 있음. 분석 행 499/49,999개.

지연 진입 검정과 RMST는 포함하지만 다른 가중 순위 검정 옵션, 다중 그룹 변수 분석, 브라우저 렌더링·파일 저장은 이번 시간 측정 범위에 포함하지 않는다.

## 검증과 측정 방법

번들 R 4.5.3, 실제 앱 모듈·환경설정 초기화, 동일 시드, 양쪽 모듈 함수 컴파일. 두 독립 프로세스에서 조건 순서를 반대로 실행한다. 각 조건 준비 후 기준/현재를 번갈아 3회씩 실행한 중앙값이다. 타이머는 `prepare_km_analysis_result` 전체와 진단/stdout 수집을 포함하며 결과 비교·환경 정규화는 제외한다.

각 조건에서 survfit 모형, 예상 분석 행 수, 유한하고 0~1 범위인 생존 추정값, 로그순위 결과와 세 집단 RMST 추정 표를 확인한다. 조건당 준비 1회+측정 6회, 12조건으로 프로세스당 전체 결과 84개를 비교한다. 전체 반환값/속성·진단·stdout·RNG는 `identical(..., num.eq=FALSE)`를 사용하며 수식의 `.Environment` 속성만 재귀적으로 제외한다. 수치 허용오차를 사용하지 않는다.

최초 두 실행의 전체 결과 비교 168개가 모두 통과했다. 측정 적합 144개에서 경고·메시지는 0개였다.

## 최초 100,000행 측정 결과

단위 초, 각 칸은 기준→현재 중앙값이다.

| 조건 | 실행 1 | 실행 2 |
|---|---:|---:|
| 표준·정상 | 0.1440 → 0.1564 | 0.1834 → 0.1885 |
| 표준·중첩 | 0.5223 → 0.2174 | 0.7264 → 0.3049 |
| 표준·분산 | 0.2760 → 0.1106 | 0.3815 → 0.3422 |
| 지연 진입·정상 | 0.1746 → 0.1771 | 0.1735 → 0.1849 |
| 지연 진입·중첩 | 0.8900 → 0.2962 | 0.7725 → 0.2839 |
| 지연 진입·분산 | 0.2791 → 0.0962 | 0.2975 → 0.1068 |

중첩 결측은 표준 약 58%, 지연 진입 약 63~67% 단축했다. 표준 분산 결측은 실행별 단축률이 약 10~60%로 크게 달랐고 정상 자료도 시간이 증가해, 정상/분산 조건을 별도 15회 반복으로 추가 확인했다. 최초 결과를 삭제하거나 유리한 반복만 선택하지 않았다.

1,000행의 표준 중첩은 17.11→14.37ms / 25.60→20.06ms, 지연 진입 중첩은 27.48→22.54ms / 26.08→21.89ms였다. 작은 자료와 100,000행의 단축률을 동일하게 보지 않는다.

## 정상·분산 조건 추가 측정

별도 두 독립 프로세스에서 100,000행 정상/분산 × 표준/지연 진입 조건을 각각 15회씩 측정했다. 프로세스당 전체 결과 124개, 총 248개 비교가 통과했다. 추가 측정 적합 240개에서 경고·메시지는 0개였다. 최초 검사와 합하면 전체 결과 비교 416개, 측정 적합 384개이다.

단위 초, 기준→현재 중앙값.

| 조건 | 추가 실행 1 | 추가 실행 2 |
|---|---:|---:|
| 표준·정상 | 0.1975 → 0.2001 | 0.1770 → 0.1783 |
| 표준·분산 | 0.3766 → 0.1327 | 0.3624 → 0.1313 |
| 지연 진입·정상 | 0.1814 → 0.1839 | 0.1819 → 0.1833 |
| 지연 진입·분산 | 0.3667 → 0.1278 | 0.3784 → 0.1338 |

분산 결측의 단축은 표준 약 64~65%, 지연 진입 약 65%로 추가 두 실행에서 확인됐다. 최초 표준 분산 조건의 변동을 숨기지 않으며, 서로 다른 프로세스의 절대 시간끼리 전후 비교하지 않았다.

정상 자료에서는 표준/지연 진입 모두 약 0.7~1.4%(약 1.3~2.7ms) 증가가 남았다. 정상 자료까지 빨라졌다고 주장하지 않는다. 이 비용은 후속 검토 대상으로 기록하며 이번 검증 중 제품 코드는 변경하지 않았다.

재현 인자: `scripts/benchmark_km_reason_combined_large.R 1 focused`, `2 focused`. 추가 원자료는 같은 출력 폴더의 `focused-times-1.csv`, `focused-times-2.csv`, 요약은 `focused-summary.csv`이다.
