# 독립표본 Wilcoxon 사후검정 동점 집계 개선

## 변경

`R/analysis_ttest_anova.R`의 비모수 사후검정에서 숫자로 변환·결측 제거한 자료를 전용 `pairwise.wilcox.test` 복사본으로 전달한다. 이 복사본 안에서만 `wilcox.test.default`의 비대응표본 동점 집계를 `table(r)` 대신 `tabulate(2 * r, nbins = 2 * length(r))`의 양수 빈도로 계산한다. 평균 순위는 정수 또는 반정수이므로 오름차순 동점 빈도와 기존 보정항 계산 순서를 유지한다. 원자료에 `table`을 적용하는 Mann–Whitney z 함수는 변경하지 않았다.

순위·검정통계량·연속성 보정·p값·다중비교 보정·신뢰구간 계산식은 원래 함수를 사용한다. 대응표본 분기는 기존 `table(r)`를 유지한다. `stats` 네임스페이스는 변경하지 않으며 앱의 숫자 사후검정 경로에서만 복사본을 사용한다. 범용 S3 검정 함수를 대체하는 용도는 아니다.

두 원본 함수의 전체 deparse 코드 SHA256과 정확한 교체 개수 2개를 확인한다. 불일치하면 원래 `stats::pairwise.wilcox.test`로 돌아간다. 엔진은 최초 사용 시 한 번 구성하고 이후 재사용한다. 기존 사후검정 결과 캐시도 유지한다.

- `pairwise.wilcox.test`: `5ad783c027c00d476f2928988882633c133d9a8c4ee8d6e0c173e8ccb5c85b0c`
- `wilcox.test.default`: `8fa00d3fa461cb114e013ebc13b4e70f9d67607618ef9f33d23f38a87eb9ea05`

## 최종 코드 성능

20,000행, 4/8집단, 연속값/반올림한 동점값, 결측률 0/0.1을 조합했다. 값과 집단에 독립적으로 결측을 적용했다. 비모수 분석·사후검정·추가 평균/표준편차 표·효과크기를 켰다. 새 R 프로세스 3개에서 기존/변경 코드를 예열한 뒤 순차 측정하고, 두 번째 실행은 측정 순서를 뒤집었다.

전체 분석 및 반환값·진단·stdout·난수 상태 수집을 포함한 경과 시간의 중앙값이다. 함수별 추적은 넣지 않았다. 최초 엔진 구성 시간은 예열에 포함되어 아래 시간에는 포함되지 않는다.

최종 코드의 24개 측정 모두 단축됐다. 8집단·연속값·결측 없음의 중앙값 감소는 약 60%다. 수치는 해당 자료와 환경의 측정 결과이며 다른 입력에서 같은 비율을 보장하지 않는다. 예비 후보의 24개 측정도 모두 단축됐고 최종 측정과 별도 보존했다.

## 정확성 검증

`scripts/validate_independent_wilcox_ties.R`에서 정규화·허용오차 없이 `identical(..., num.eq=FALSE)`로 원시 값, 경고/메시지/오류, stdout, 난수 상태를 비교했다.

- 원시 htest 264개: 크기 0/1/2/10/100/5,000, 비대칭 표본 크기, 일반·동점·상수·아주 가까운 실수·결측·무한대, 세 대립가설, 연속성 보정. 추가로 정확/근사 검정, 대응/독립, 신뢰구간, `digits.rank=5`를 포함했다.
- 동점 빈도 순서 및 원시 보정항 합 15개: 크기 1/100/20,000, 일반·동점·상수·가까운 실수·무한대.
- 원시 pairwise.htest 36개: 2/4/8집단, 6개 자료 유형, Holm/Bonferroni, 비어 있는 factor 수준 포함.
- 전체 분석 72개: 2/4/8집단, 6개 자료 유형, 추가 표 켜기/끄기, Holm/Bonferroni, 종속변수 2개. 참조는 현재 코드의 엔진 제공자만 원래 stats 함수로 되돌린 것이다.
- 원본 코드가 달라진 경우의 대체 경로, 실행 후 엔진 구성, 원래 stats 함수가 변경되지 않았음을 확인했다.
- 최종 성능 측정에서도 모든 기존/변경 반환값과 진단·stdout·난수 상태가 정확히 일치했다.

기존 사후검정·본검정·z값·효과크기 재사용 검증 스크립트 4개도 모두 재실행해 통과했다. 전체 결과는 각각 48/48/24/24개이며, 각 스크립트의 원시 값·진단 주입·캐시 수명 검증도 통과했다. UI·표 형식·내보내기 코드는 변경하지 않았으며 별도 UI/내보내기 실행 및 배포 빌드는 수행하지 않았다.

자료는 `output/independent-wilcox-ties-20260914/`에 있다. `baseline.R`은 변경 전 소스, `candidate.R`은 후보 엔진, `check.R`은 재현 스크립트다. `candidate-timing-*.csv`는 예비 후보, `product-timing-*.csv`는 최종 코드 측정이다. 스크립트 준비 중 함수 참조가 중복된 오타를 수정한 후 측정을 완료했다.
