# 일반 LMM 선택 모형 재사용

## 적용

`R/analysis_longitudinal.R`에서 같은 분석 안의 일반 Gaussian LMM 선택 모형을 민감도 분석에 재사용한다. `model_type = "lmm"`, `model_family = "gaussian"`이며 실제 모형이 `lmerMod`인 경우만 추가했다. 별도 반복측정 REML 모형은 이 조건에 포함되지 않는다.

준비 자료와 변수, 가중치, cluster, offset, exponentiate 및 무작위 효과 설정이 같은 선택 모형을 전달한다. 대안 무작위 효과 구조는 기존대로 새로 적합한다. 경고·메시지 또는 RNG 변화가 있으면 재사용하지 않는다. 전역 모형 캐시나 수치 계산식 변경은 없다. 기존 GEE 및 GLMM 재사용 범위는 유지한다.

## 측정

번들 R 4.5.3, seed 939, 500명 × 6시점 = 3,000행, 두 공변량, 연속형 반응, 기본 분석 옵션. 자료 생성에 무작위 절편과 기울기를 포함했다. 워밍업 후 독립 프로세스 3개를 순차 실행하고 두 번째 프로세스는 후보부터 측정했다. 로딩 시간은 제외했다.

| random_slope | 변경 전 1 / 2 / 3 (초) | 변경 후 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| FALSE | 0.55 / 0.33 / 0.58 | 0.28 / 0.50 / 0.29 | 0.55 → 0.29 |
| TRUE | 0.28 / 0.28 / 0.30 | 0.21 / 0.21 / 0.24 | 0.28 → 0.21 |

기울기 모형은 세 번 모두 빨라졌고 중앙값은 약 25% 감소했다. 절편 모형은 세 번 중 두 번 빨라졌지만 두 번째에서는 느려졌으므로 일정한 개선율을 보장하지 않는다. 측정 자료에서는 수집한 경고/메시지가 양쪽 모두 0개였다.

시제품은 현재 제품에 반영한 것과 같은 LMM 허용 조건을 사용한다. 전체 분석의 워밍업과 측정 결과를 변경 전 소스와 직접 비교했다.

## 검증

`scripts/validate_longitudinal_lmm_reuse.R`의 20개 조건이 통과했다. 무작위 기울기 FALSE/TRUE 각각에서 정상, 경고/메시지/RNG 소비/오류 주입, exponentiate FALSE, 가중치, 결측/역순, 이름 있는 행을 검사했고, 추가 군집 변수를 지정한 두 모형도 확인했다.

정상 재사용 12개(기울기 TRUE 6개), 재적합 유지 6개, 오류 2개였다. 정상 재사용의 앱 적합 호출은 3회에서 2회로 줄었다. 반올림 전 AIC/BIC, 특이성 판정, 진단 조건의 클래스/본문/순서, 표준 출력, RNG도 비교했다. 지속 검증에서 LMM 재사용을 끈 참조 경로와 비교했으며, 변경 전 소스를 직접 로드한 20개 조건도 별도로 통과했다.

merMod는 고정효과, 무작위효과, 공분산, 적합값, 잔차, logLik, theta, devcomp, optinfo, call, model frame을 추출해 비교한다. formula/terms 환경 및 함수 표현만 정규화하고 수치는 `identical(..., num.eq = FALSE)`로 허용오차 없이 비교한다. 모든 내부 슬롯·외부 포인터의 동일성까지 주장하지 않는다.

기존 이항/Poisson/Gamma GLMM 검증도 각각 20개, 총 60개 조건이 통과했다. 이 스크립트들의 참조 경로는 각각의 GLMM 재사용만 끄므로, 이제 양쪽에서 같은 LMM 재사용이 실행될 수 있다. 이에 따라 비대상 모형은 양쪽 호출 수가 같은지 검사하고, 대상 GLMM의 정상 재사용은 기존처럼 3→2회를 명시적으로 검사하도록 기대값을 갱신했다.

## 범위 및 증거

분석 출력 내용과 형식은 변경하지 않았다. 이전에 변경 전 코드에서도 재현된 종합 테스트의 Excel 셀 위치 비교 실패는 이번에 재실행하거나 해결하지 않았다. 관련 LMM/GLMM 검증을 수행하고 전체 형식 변환과 설치 파일 빌드는 실행하지 않았다. 기존 작업 트리의 다른 변경은 유지했다.

`output/longitudinal-lmm-reuse-review-20260914/`에 `baseline.R`, `candidate.R`, `applied.R`, `bench.R`, `normalize.R`, `timing-1/2/3.csv`, `validation.log`, `validation-old-source.log`, `binomial-regression.log`, `poisson-regression.log`, `gamma-regression.log`를 보관한다.
