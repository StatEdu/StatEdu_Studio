# 생존분석 추천 패널 다국어 점검

추천 상태 4종, 제목 2종, 추천 설명 제목 3종, 자료 요약 제목·문장, 추천 규칙 안내, 실행 버튼의 13개 문구를 일본어·중국어·스페인어·프랑스어·독일어·베트남어 사전에 연결했다. 한국어와 영어 표시를 유지한다.

자료 요약은 원본 137행 / 분석 112행 / 제외 25행 / 사건 43건으로 검사했다. 한국어·일본어·중국어에서는 원본 행 수를 먼저, 다른 언어에서는 분석 행 수를 먼저 표시한다. 사용자 문구와 추천 규칙 코드는 번역하지 않는다. 알 수 없는 상태 값도 그대로 보존한다.

검증:

- `validate_survival_recommendation_panel_i18n.R`: 8언어 × 상태 5종 × 사전검사 요약 유무 = 80개 생성 UI 검사 통과. 실행 버튼·설명 영역 조건, 숫자 순서, 원문 보존, NULL 입력 확인.
- 기존 추천 분석명 검사: 768개 설정에서 얻은 15개 추천 유형의 8언어 검사 재통과.
- 기존 추천 설명 검사: 7개 실제 추천 규칙과 미등록/빈 규칙의 기본 안내를 8언어로 재검사 통과.

범위와 한계:

- 분석 전 설정 패널만 수정했다. 분석 본표·보조표·저장 산출물 변경이 없어 이번에는 내보내기를 새로 생성하지 않았다.
- 상태별 검사는 생성 HTML을 대상으로 했으며 자료 요약은 합성 사전검사 객체다. 실제 브라우저의 언어 왕복과 실행 버튼 이동은 이번 검사의 범위가 아니다.
- 패널 안의 `survival_issue_text` 오류 안내는 별도 남은 항목이다. 추천 화면 전체 또는 다국어 전체 완료로 간주하지 않는다.
- 설치본을 만들지 않았다.
