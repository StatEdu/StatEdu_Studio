# 요인분석 대표 결과 다국어 보완

보조표의 Factor, Mardia skewness, Mardia kurtosis 문구를 8개 언어 사전에 연결했다. 계산 엔진과 본표 구성은 변경하지 않았다.

`scripts/validate_factor_i18n.R`는 실제 120행·6변수 자료에서 정규성 충족에 따른 최대우도 자동 선택/oblimin, 최대우도/Mardia/varimax, 순서형 다분상관/주축요인/무회전의 세 경로를 실행한다. 첫 경로는 주축요인을 요청했어도 정규성 옵션에 의해 실제로 최대우도가 선택되며, 실행된 방법을 검사한다. 8개 언어 모두 본표 셀·제목·주석 영어 동일성, 보조표 언어 및 수정 문구, 사용자 변수 라벨 보존을 확인했다. 변수 라벨 `Factor`, `Normality`, `Yes`, `Status`가 시스템 문구와 같아도 유지된다.

기존 PCA 다국어 검사와 번역 계약 검사도 통과했다. 일본어 세 결과 저장 fixture는 `tmp/factor-i18n/entries.rds`, 내보내기 로그는 `tmp/factor-i18n-exports.log`다.

현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성·실제 PDF 텍스트 검사를 통과했다.

요인 수 자동 선정, 경고·요인별 신뢰도 결합, 도표·설정·언어 왕복은 추가 확인 대상이다. 전체 문구가 모든 분기에서 번역됨을 보장하는 검사는 아니다. 대표 결과 근거는 18개 화면, 전용 결과 검증 공백은 12개로 갱신했다. 설치본은 만들지 않았다.
