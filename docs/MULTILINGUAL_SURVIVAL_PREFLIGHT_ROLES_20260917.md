# 생존분석 사전 점검 복합 오류 — 2026-09-17

필수 시간·사건·진입·시작/종료·대상자 ID 선택, 역할 충돌, 없는 변수 안내를 여러 오류가 동시에 발생할 때에도 UI 언어로 표시하도록 연결했다. 신규 번역 키 6개를 한국어·영어·일본어·중국어·스페인어·프랑스어·독일어·베트남어에 추가하고 기존 시간/사건 번역을 재사용했다.

`survival_preflight_stop`은 기존 영어 오류 메시지와 함께 차단 오류 행을 조건 객체에 전달한다. UI에서 각 오류를 번역한 뒤 순서대로 결합한다. 없는 변수 이름은 별도 인자로 삽입하여 사용자 문구 안에 영어 안내와 같은 문자열이나 `%s`가 있어도 그대로 보존한다. 검증 조건·계산·결과 표·저장된 보고서 내용은 변경하지 않았다.

검증:

- `validate_survival_preflight_i18n.R`: 실제 사전 점검 조합 4종을 8개 언어로 검사. 영어 오류 계약, 변수명, 오류 순서/중복 제거, 경고 제외, 외부 상세, 빈 오류 대체 안내 및 정상 반환 검사 통과.
- `validate_survival_input_errors_i18n.R`: 기존 53종 오류 및 세 분석 실패 콜백 검사 통과(기존 의존성 모의 검사 포함). 직접 Rscript 실행으로 확인했다.
- `validate_multilingual_coverage.R`: 번역 카탈로그와 기존 UI 회귀 검사 통과.
- `validate_survival_preflight.R`: 앱 부트스트랩으로 공통 모듈을 불러온 뒤 전체 사전 점검 회귀 검사 통과. 스크립트 단독 로딩에서는 기존 `analysis_save_edition` 의존성이 빠져 중단되었으므로 앱과 동일한 모듈 로딩으로 재검증했다.

이 작업은 사전 점검 전체 완료를 뜻하지 않는다. 사건 매핑·자료 값·구간 무결성 등 나머지 사전 점검 오류와 일부 내부 모형 오류는 후속 점검 대상이다. 실제 브라우저 조작이나 전체 내보내기 검증을 수행한 범위가 아니며 설치본은 만들지 않았다.
