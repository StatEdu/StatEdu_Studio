# Fine–Gray 검정 실패 경고 번역

## 변경

Fine–Gray 모형 전체 검정과 범주형 공동 검정의 추정 실패에 대한 근거·권고 4개 문구를 6개 추가 UI 언어에 번역했다. 범주형 검정의 실패 변수명은 조립된 근거 셀을 보존하여 재번역하지 않는다. 영어·한국어 문구와 판정 로직·분석 계산은 유지했다.

## 검증

`scripts/validate_fine_gray_test_failures_i18n.R`는 실제 Fine–Gray 적합 결과의 진단 메타데이터로 실패 분기를 검사한다. 추가 사례를 각각 재적합한 것은 아니다.

- 정상, 통계량 결측, 자유도 결측, p값 결측, 범주형 실패, 동시 실패: 6가지 × 8개 언어 통과.
- 무한 통계량도 동시 실패 사례에서 확인했다.
- 경고의 심각도 및 실패 변수명 `Review`, `사용자 <&> %s` 원문 유지 확인. 정상 변수 `Normality`는 경고에서 제외한다.
- 본 회귀표의 동일한 영어 출력 확인.
- 일본어 경고표 캡처를 현재·누적 결과로 저장한다. 저장 시 재분석하지 않는다.
- 산출물: `tmp/fine-gray-test-failures-i18n/`.
- 현재 5개·누적 6개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서·시트 수를 확인했다.
- 기존 Cox 추정 실패 경고의 8개 언어 회귀 검사도 통과했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
