# Cox 자연 삼차 스플라인 보조표

스플라인 자유도, 기준값, 비선형성 우도비 카이제곱, 선형/스플라인 AIC, 분석 제목 및
해석 설명의 7개 번역 항목을 6개 추가 언어에 보완했다. 한국어의 5개 열 이름도 추가했다.
분석 계산, 영어 본 표 및 도표는 변경하지 않았다.

## 검증

- `validate_cox_spline_i18n.R`: 실제 Cox 자연 삼차 스플라인 모형을 자유도 3과 4로
  적합하여 보조표와 전체 결과 패널을 8개 언어로 검사했다.
- 제목·열·설명 번역, 수치·변수명 보존, 본 표 영어 유지 통과.
  별도 표시용 표에서 `Review 사용자 <&> %s` 보존을 확인했다.
- 기존 공선성·잔차 다국어 검사 통과.
- 일본어 대상 보조표·설명 스냅샷의 현재 4개 표 / 누적 6개 표에 대해
  HTML/PDF/Word/HWPX/Excel 통과. PDF 내용·표지, 표 순서 및 Excel 시트 수 확인.
  이번 파일 검증에는 스플라인 도표가 포함되지 않았으며 저장 시 재적합하지 않는다.

설치본은 생성하지 않았다. 분석 개요의 동적 모형 설명 등 다른 출력 경로의 점검은 남아 있다.
