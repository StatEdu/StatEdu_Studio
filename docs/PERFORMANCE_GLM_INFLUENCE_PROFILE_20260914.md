# 일반화 모형 영향력 진단 비용 확인 — 2026-09-14

`generalized_influence_summary()`의 Cook 거리와 레버리지 계산이 영향력 계산을 각각 수행하는 것을 확인했다. 번들 R의 `cooks.distance.glm`은 기본값에서 `influence(model, do.coef=FALSE)`를 사용하고, `hatvalues.lm`은 `lm.influence(model, do.coef=FALSE)`를 사용한다. `influence.glm` 내부에도 `lm.influence`가 있다.

이번에는 현재 비용만 측정했다. 이 중복을 제거한 후보의 속도·예외 동작을 검증하지 않았으므로 운영 코드는 변경하지 않았다. 진단에는 중복 영향력 계산 외에 Pearson 잔차, 분산 추정, 최대값·임계값 집계도 포함되므로 진단 시간 전체가 제거 가능한 시간은 아니다.

## 측정 결과

| 행 수 / 모형 | 전체 분석 중앙값(초) | 영향력 진단 중앙값(초) |
|---|---:|---:|
| 20,000 / Gaussian | 0.11 | 0.01 |
| 20,000 / Binomial | 0.09 | 0.01 |
| 20,000 / Gamma | 0.13 | 0.00 |
| 200,000 / Gaussian | 1.22 | 0.08 |
| 200,000 / Binomial | 1.78 | 0.10 |
| 200,000 / Gamma | 2.15 | 0.25 |

20만 행의 전체 3회는 Gaussian 1.22/1.20/1.23초, Binomial 1.80/1.78/1.78초, Gamma 2.17/2.15/2.13초였다. 진단은 각각 0.10/0.08/0.08초, 0.10/0.10/0.10초, 0.14/0.25/0.25초다. 짧은 측정의 0.00초는 비용이 없다는 의미가 아니다. 2만 행에서 시간 분해능이 부족해 20만 행으로 확장했다.

20만 행에서 진단 중앙값은 전체의 약 6~12% 수준이다. 일부 중복을 제거하는 개선율은 이보다 작을 수 있다. 특히 Gamma 진단 시간은 변동이 있어 안정적인 후보 비교가 필요하다. 이 수치는 개선율이 아니다.

## 조건과 결과 확인

번들 R 4.5.3, 기존 모듈 캐시, 정규 예측변수 6개와 시드 915의 합성 반응을 사용했다. 가족을 명시하고 강건 표준오차와 가정 점검을 켰으며 VIF는 끈 완전 자료 분석이다. 결측 대치·IPW·카운트 모형·변수 선택은 이번 범위에 없다.

크기별 새 프로세스 3개를 순차 실행했다. 준비 실행 후 GC와 시간 측정을 수행했고 다른 R 작업을 동시에 실행하지 않았다. 전체 결과 준비와 비교용 스냅샷 구성·조건 수집을 포함하며 패키지/모듈 로딩·입력 생성·화면·저장은 제외했다. 진단 래퍼의 시간 계측 비용도 포함한다.

준비/측정 결과 및 새 프로세스 간 스냅샷은 정확히 일치했다. 비교 대상은 반환 결과에서 원래 모형 객체를 제외한 내용, 별도로 보관한 계수·적합값·잔차·deviance·weights, 경고/메시지 문자열·난수 상태다. 공식 환경만 `.GlobalEnv`로 통일했고 `identical(..., num.eq=FALSE)`를 사용했다. 모형 객체의 함수 클로저와 모든 내부 필드까지 동일하다고 주장하지 않는다. 코드 변경 전후 검증이 아닌 현행 실행의 재현성 확인이다.

`output/glm-influence-profile-20260914/`와 그 `n200000/`에 측정 코드·CSV·RDS를 보관했다. 전체를 확인하는 코드는 상위 `verify.R`이다. 메모리·출력 파일 변환은 측정하지 않았고 설치 파일도 재빌드하지 않았다.
