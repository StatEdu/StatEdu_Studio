# 동등성 제약 스코어 검정 보조표

2026-09-17

- 다집단 측정불변성 보조표의 알려진 6개 단계명을 문맥별 번역으로 표시한다. Metric은 일반 지표가 아니라 측정단위 불변성으로 번역한다. 미등록 단계명은 그대로 유지한다.
- 제약, 스코어 χ², 최대 절댓값 표준화 EPC, 원시 χ²·p·BH 보정 p 제목을 한국어 및 6개 추가 언어로 보완했다. 절댓값 기호를 포함한 제목은 공통 이중언어 구분자 처리를 거치지 않고 명시적으로 번역한다.
- Constraint 열을 사용자 데이터 보호 대상으로 지정했다. 제약식과 사용자 명칭을 사전 단어로 치환하지 않는다. 본 표 및 분석 계산은 변경하지 않았다.
- `scripts/validate_invariance_score_i18n.R`: lavaan의 HolzingerSwineford1939 자료에 실제 집단별 요인부하량 동일화 모형을 적합하고 기존 진단 생성기로 스코어 통계량을 생성했다. 이 진단표를 6개 알려진 단계와 사용자 단계의 표시 fixture로 사용했다. 각 단계별 모형을 새로 적합하는 검증은 아니다.
- 8개 언어에서 제목·수치·제약식·빈 결과를 확인했다. Review, Normality, 한글, <&>, %s가 포함된 사용자 값 보존을 검증했다. 기존 순열 민감도 검증도 통과했다.
- 일본어 스냅샷으로 현재 7표, 누적 14표를 HTML/PDF/Word/HWPX/Excel로 저장했다. 내용, PDF 표지, 표 순서, Excel 시트 수 검증 통과. 내보내기 과정에서 재분석하지 않는다.
- 산출물: `tmp/invariance-score-i18n/`. 설치본은 생성하지 않았다.

전체 다국어 감사는 진행 중이다. 집단별 잔차 요약 및 큰 잔차 보조표는 후속 점검 대상이다.
