# CIF 검사 실패 안정성 안내

실패 집단명 앞의 안내와 후속 조치 문장 2개를 6개 추가 언어에 보완했다.
알려진 실패 코드·접두문이 일치할 때만 번역하고 이후 집단명은 그대로 붙인다.
계산과 경고 발생 조건은 변경하지 않았다.

## 검증

- `validate_cif_failure_i18n.R`: 실제 경쟁위험 정상 결과에 실패 코드가 없음을 확인.
  곡선 CIF를 .8로 바꾼 실패 검사 자료를 실제 무결성/안정성 함수에 전달하여 경고 생성 확인.
- 8개 언어에서 실패 근거·안내 번역과 사용자 집단명, 알 수 없는 문구 보존 확인.
  실제 정상 결과의 영어 CIF 본 표 유지. 변형 자료는 새 적합 결과가 아니다.
- 기존 무결성 3가지 검사 × 8개 언어 회귀 검사 통과.
- 일본어 현재 1개 / 누적 2개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 다른 안정성 경고의 동적 설명은 추가 점검 대상이다.
