# Cox 보정 생존곡선의 동일 누적위험 계산 재사용 — 2026-09-14

`R/analysis_survival.R`의 `survival_adjusted_curve_once()`는 각 집단에서 모든 시점에 대해 `mean(exp(-hazard * risk), na.rm = TRUE)`를 계산했다. 누적위험이 같은 시점은 같은 값을 반환하므로 서로 다른 누적위험별로 한 번 계산하고 `match()` 인덱스로 원래 시점 순서에 배치하도록 변경했다.

곱셈, 지수함수, 평균 계산식과 연산 순서를 그대로 사용한다. 근사나 반올림, 평균의 재배열은 도입하지 않았다. 위험도 예측, 모델 적합, 부트스트랩 표본 추출, 분위수 신뢰구간과 대비 계산도 유지한다. 재사용은 함수 호출 내부에만 한정되며 다른 적합이나 부트스트랩 반복의 결과를 공유하지 않는다.

## 계산 시간

합성 자료 600건, 3집단, 연속 관찰 시간과 연속 공변량, 사건 생성 확률 0.45, 부트스트랩 60회, 선택 시점 0·10·20 조건이다. 번들 R 4.5.3의 새 프로세스에서 모듈과 설정을 로드하고 최초 Cox 모형을 적합한 뒤 `survival_adjusted_curve()` 전체를 측정했다. 이 시간에는 보정곡선 추정, 부트스트랩 재적합, 신뢰구간과 시점별 대비 계산이 포함된다. 최초 모형 적합과 화면/저장은 포함하지 않는다.

프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍은 순서를 뒤집었다. 변경 전후 함수는 같은 전역 도우미 환경을 사용했다.

| 반복 | 변경 전(초) | 변경 후(초) |
| --- | ---: | ---: |
| 1 | 2.38 | 1.05 |
| 2 | 2.36 | 1.05 |
| 3 | 2.38 | 1.06 |
| 중앙값 | 2.38 | 1.05 |

이 조건의 보정 생존곡선 계산은 **약 56% 단축**되었다. 같은 누적위험이 반복되는 정도에 따라 개선 폭은 달라진다. 기본 Kaplan–Meier, 보정곡선 없는 Cox, 다른 분석이나 프로그램 시작 시간의 개선을 의미하지 않는다.

## 정확성 검증

- `scripts/validate_survival_adjusted_hazard.R`: 총 60개 검사 통과. 2/3집단, 사건 생성 확률 0.25/0.8/1, 동률 시간 유무, 부트스트랩 0/25회, 중복·역순·NA·빈 선택 시점을 포함했다. 빈 시점의 기존 오류도 변경 전후 같았다.
- 전체 보정곡선, 신뢰구간, 시점별 차이·비율과 구간, 부트스트랩 성공 횟수 등 반환값을 `identical(..., num.eq = FALSE)`로 비교했다. 허용 오차를 사용하지 않았다.
- 정상 전체 계산의 경고·메시지 기록과 RNG 상태가 동일했다.
- 측정한 3쌍의 전체 결과·경고·RNG도 정확히 일치했다.
- `verify_integrated.R`: 180건·3집단·부트스트랩 25회로 실제 `prepare_cox_analysis_result()`를 호출해 보정 결과와 RNG를 비교했다. 전체 Cox 결과 패널 HTML이 동일했다.
- 개별 및 누적 Excel의 시트 이름과 셀 값, 모든 비-core 내부 파일이 동일했다. core 메타데이터도 생성·수정 시각만 정규화하면 동일했다.
- 호출 전 `.Random.seed`가 없을 때도 양쪽 모두 부트스트랩 종료 후 없는 상태로 복원했다.
- `git diff --check -- R/analysis_survival.R` 통과.

출력 내용과 통계 추정값이 유지되는 중복 계산 제거다. PDF/Word/HWPX 완성 파일과 그래프 이미지의 별도 렌더링은 이번에 수행하지 않았다. 설치 파일도 재빌드하지 않았다.
