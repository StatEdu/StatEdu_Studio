# 생존분석 보고 체크리스트 내부 번역

## 변경

- 체크리스트의 항목·상태와 자동 생성 근거 문구를 6개 추가 UI 언어로 표시한다.
- 사건 역할, 제외 인원, 생존/RMST, Cox 비례위험 진단, 경쟁위험 추정대상, Fine–Gray 검열분포 안내를 포함한다.
- 번역표에 11개 문구를 추가했다.
- 시간 원점·단위·사건 코드·검열층 변수명은 자동 문구와 분리하여 처리한다. 근거 셀 조립 후에는 재번역을 막아 사전 단어와 일치하는 사용자 입력도 보존한다.
- 기존 영어·한국어 생성 문구 및 분석 계산은 유지한다.

## 검증

`scripts/validate_survival_checklist_i18n.R`는 실제 Kaplan–Meier, Cox, 경쟁위험 모형과 추가 진단 메타데이터를 사용한다.

- 7가지 사례 × 8개 언어 검증 통과.
- 추가 사례: 검열층 이름, PH 신호 유무, 미확인 사건 역할. 이 사례는 메타데이터 분기 검사이며 별도 모형 적합을 의미하지 않는다.
- `Review`, `Normality`, `사용자 <&> %s` 등 사용자 입력 보존 확인.
- 현재·누적 일본어 결과 캡처를 사용해 5개 저장 형식을 검증한다. 저장 시 분석을 다시 실행하지 않는다.
- 산출물: `tmp/survival-checklist-i18n/`.
- 현재 5개·누적 6개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서 및 시트 수 확인을 포함한다.

표 밖의 공통 안내문 회귀 검증도 통과했다. 전체 다국어 완료를 의미하지 않으며, 해석 가이드 표 내부 문구는 별도 확인 대상이다. 설치본은 만들지 않았다.
