# 교차분석 백분율 문자열 일괄 생성

2026-09-15. Gamma와 추세 벡터 개선을 유지한 상태에서 표 셀의 백분율 문자열 생성 비용을 줄였다.

## 조사 결과와 적용

카이제곱 검정이 연관성 검정과 Cramer's V 계산에서 각각 실행되는 것은 호출 계수로 확인했다. 하지만 80×80 표의 현재 코드 프로파일에서는 표 생성이 포함 스택 표본의 91.44%, 그 안의 `crosstab_format_number`가 52.39%였다. 카이제곱 함수는 이번 표본 집계에 나타나지 않았다. 이는 비용이 0이라는 증거가 아니며 포함 스택 비중은 중첩되므로 합산하지 않는다. 계측은 별도 10회 호출, 간격 0.005초, 총 표본 시간 1.985초이며 실제 경과 시간과 구분한다.

따라서 카이제곱 재사용은 추가하지 않고 더 큰 비용인 백분율 형식 변환을 변경했다. 선택된 행/열/전체 백분율 행렬마다 `formatC(..., format = "f", digits = 1)`을 한 번 호출한다. 결측 셀은 기존처럼 빈 문자열로 둔다. 셀의 빈도 문자열, `row/col/total` 접두어, `%`, 줄바꿈, 합계와 열 이름 및 계산식은 유지한다. 모든 셀에 scalar `formatC`를 반복 호출하던 부분만 제거했다.

## 정확성 및 기존 검사

기존 표시 함수를 `scripts/fixtures/crosstab_display_reference.R`에 보존하고 `scripts/validate_crosstab_percent_format.R`를 추가했다.

768개 조합에서 전체 표시 데이터프레임(문자열·열 이름·행 이름·속성), 조건 클래스/내용/순서, 표준 출력 및 최종 RNG가 `identical(..., num.eq=FALSE)`로 정확히 일치했다. 1·2·3·8·20수준, 행/열 합계 0, 0/NA/NaN/Inf/-Inf/음수/소수/작고 큰 수, 백분율 및 합계 16가지 옵션, 소수점 구분자 `.`/`,`를 포함한다. 모든 가능한 입력의 전수 검증은 아니다.

별도 전체 분석의 준비 및 측정 결과에서도 반환 객체 전체와 진단/RNG가 정확히 일치했다. 기존 `scripts/validate_crosstabs.R`이 표 옵션·범주 이름과 HTML/Excel 저장 helper 검사까지 통과했다. 렌더러, 표 형식 및 내보내기 코드는 바꾸지 않았다. PDF/Word/HWPX의 새 교차 형식 검사나 설치 파일 빌드는 수행하지 않았으며, HTML/Excel helper 통과를 전체 형식 검증으로 해석하지 않는다.

## 전체 분석 성능

번들 R 4.5.3, 순서형 행/열 각각 4·12·40·80수준, 각 셀에 8명인 합성 완전자료다. 80×80은 51,200행이다. 추세 및 행/열/전체 백분율을 모두 켰다. 기대빈도가 충분해 Monte Carlo Fisher 경로는 사용하지 않는다.

기준은 Gamma 누적 합 및 추세 벡터 개선을 포함한 직전 소스다. 기준/현재를 별도 환경에 소싱하고 양쪽 분석 모듈의 함수를 동일하게 compiler::cmpfun으로 준비했다. 독립 프로세스 3개를 순차 실행하고 각 조건 준비 비교 후 3회씩 측정했다. 두 번째 프로세스는 순서를 뒤집었다. 타이머에는 전체 분석과 동일한 진단/출력 캡처가 포함되며 정확 비교는 타이머 밖이다.

|행×열 수준|기준 중앙값: 프로세스 1/2/3(초)|현재 중앙값: 프로세스 1/2/3(초)|
|---|---|---|
|4×4|0.01 / 0.00 / 0.02|0.00 / 0.00 / 0.02|
|12×12|0.02 / 0.02 / 0.02|0.02 / 0.01 / 0.00|
|40×40|0.14 / 0.15 / 0.15|0.06 / 0.08 / 0.08|
|80×80|0.56 / 0.54 / 0.57|0.28 / 0.27 / 0.26|

80×80의 대표 중앙값은 약 0.56→0.27초, 약 52% 감소했다. 작은 표의 0.00/0.01초 차이는 타이머 분해능에 가까워 개선율로 해석하지 않는다. R의 분석 반환값 생성까지의 시간이며 앱 로딩, 브라우저 HTML 배치, 문서 저장은 포함하지 않는다. 백분율을 끈 모든 조건에서 같은 개선율을 주장하지 않는다.
