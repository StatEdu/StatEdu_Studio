# 일원 반복측정 공변량·옵션 추가 점검

`scripts/validate_one_group_options_i18n.R`에서 48명의 실제 자료로 6개 경로를 실행했다: 범주형 공변량의 WIDE/LONG, 연속형과 범주형 공변량을 함께 넣은 WIDE/LONG, 복수 공변량을 사용한 2시점·Bonferroni, 사후검정·가정 검토를 생략한 경로다. 형식 간 ANOVA 표 동일성, 생략 옵션의 결과 테이블 비생성, Bonferroni 주석을 확인했다.

8개 언어 및 마지막 한국어·영어 복귀 렌더링에서 본표 영어 동일성, 보조표 언어 속성, 공변량/처치/시점 이름 보존을 확인했다. 이는 렌더러의 언어 복귀 검사이며 실제 앱 메뉴·케이스 선택 상태를 포함한 UI 왕복 검사는 아니다. mean_sd=FALSE도 입력했지만 해당 옵션의 표시 효과를 별도로 검증하지 않았으므로 완료 근거로 세지 않는다.

2시점의 `Only two repeated time points were selected.` 문장이 일본어 보조표에 영어로 남는 것을 확인하여 8개 언어에 추가했고 실제 셀 일치 검사를 통과했다. 이번 제품 변경은 이 번역 항목뿐이며 계산 코드는 변경하지 않았다. 번역 계약 검사도 통과했다.

출력이 바뀐 2시점 경로의 일본어 fixture `tmp/one-group-options-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교 및 실제 PDF 텍스트 검사를 통과했다. 저장 로그는 `tmp/one-group-options-exports.log`다. 나머지 다섯 경로의 5종 저장을 이번에 새로 검증한 것은 아니다.

추가 발견: 공변량 포함 결과의 보조표에서 `Normality x Time` 같은 공변량 상호작용이 나타난다. `one_group_rm_recommendation_table`은 ` x Time`으로 끝나는 첫 효과를 선택하므로 처치×시점 대신 공변량×시점을 핵심 효과로 선택할 수 있다. 핵심 효과 선택과 합성 효과명의 보조표 번역은 별도 후속 수정 대상으로 남긴다. 본표의 계산값이 틀렸다고 판정한 것은 아니다.

설치본은 만들지 않았다. UI 왕복, 다른 옵션·공변량 조합, 외부 오류 및 위 핵심 효과 선택 문제는 남아 있다.
