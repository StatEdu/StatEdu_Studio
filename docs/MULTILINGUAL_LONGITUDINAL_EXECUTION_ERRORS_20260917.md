# 종단 실행 환경·보정 GEE 조건 안내 — 2026-09-17

별도 R 프로세스에서 비구조적 GEE가 실패한 경우의 앱 설명, 필요한 패키지 안내, 보정 GEE의 설계행렬·분포 계열·ID/시점 결측·시점 쌍별 표본 수 조건 4종을 8개 언어로 연결했다. 프로세스 실패의 외부 상세는 접두어 뒤에서 원문 그대로 유지한다. 패키지 이름도 그대로 보존한다.

`validate_longitudinal_execution_errors_i18n.R`은 조건 오류 4종을 실제 함수에서 발생시키고, 실제 프로세스 실패 콜백에 외부 오류를 주입해 원문 보존을 확인했다. 프로세스 자체를 충돌시키거나 패키지를 제거하지 않았다. 패키지 문구는 실제 소스의 sprintf 식으로 검사했다. 8언어 및 한국어 복귀의 알림 호출, 줄바꿈·경로·한글·특수문자·수치 보존 검사가 통과했다. 기존 입력 오류와 동적 오류 회귀 검사도 통과했다.

계산 및 결과 표·저장은 변경하지 않았다. 실제 브라우저 알림 검증은 포함하지 않는다. 남은 내부 REML·분산·예측 제한 오류와 미점검 모형 분기는 별도 범위다. 메타분석은 제외하며 설치본은 만들지 않았다.
