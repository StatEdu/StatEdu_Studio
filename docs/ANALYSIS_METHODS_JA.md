<a id="scope"></a>

## 1. 1.3.0 の公開範囲

CFA、SEM、PLS-SEM、媒介・調整効果を公開メニューで提供します。メタ分析と同一対象内の処置の反復測定分散分析は公開インストーラーに含まれません。Pro は将来の版で予定されています。

<a id="data"></a>

## 2. データの準備

SPSS、SAS、Stata、Excel、CSV、DAT を読み込み、変数名・ラベル、測定水準、カテゴリ、参照値を確認します。分析ごとの使用標本数と欠測処理情報を確認できます。

<a id="descriptive"></a>

## 3. 度数・記述統計とクロス集計

度数、百分率、位置・散布の統計量と分割表を表示します。選択した設定に応じて関連の検定、効果量、診断を出力します。

<a id="group"></a>

## 4. 群間比較と共分散分析

独立標本 t 検定、ANOVA、ANCOVA、ノンパラメトリック群間比較を提供します。対応する設定で分散に応じた手法、事後比較、効果量を選択します。

<a id="paired"></a>

## 5. 対応・混合反復測定

対応標本、反復測定、混合反復測定 ANOVA、対応のあるノンパラメトリック分析を提供します。選択した計画の時点・群効果と比較を表示します。

<a id="correlation"></a>

## 6. 相関・信頼性・評価者間一致

相関、尺度の信頼性、評価者間一致を分析します。変数の種類と評価計画に合う相関法・一致度指標を選択します。

<a id="factor"></a>

## 7. 探索的因子分析と PCA

EFA と PCA で因子・成分数、抽出、回転、負荷量、説明分散を確認します。CFA は別項目で扱います。

<a id="ipa"></a>

## 8. 重要度–遂行度分析（IPA）

分析 → IPA で直接評価または導出重要度を選びます。直接評価は重要度と遂行度を同じ属性順に割り当て、導出重要度は遂行度と総合満足度を指定します。全体・独立群・対応前後を選択し、対応データは WIDE の対応列または LONG の ID・時点と2時点値を指定します。基準線・図を設定し、標本数、座標、区間、群・時点差を確認します。Word/HWPX は結果追加後の累積結果から保存します。

<a id="regression"></a>

## 9. 回帰・階層的回帰

OLS、HC3 頑健推論、ブートストラップ回帰を提供します。階層的分析はブロックごとのモデルと説明分散の変化を比較します。sr²、f²、共線性、残差診断は選択に応じて出力します。 階層的回帰は最大4ブロックに対応します。各段階では、それまでのブロックの変数を保持して次のブロックを追加します。

<a id="mediation"></a>

## 10. 媒介・調整効果

キャンバスで独立・従属・媒介・調整変数と共変量の役割および経路を指定し、直接・間接・総効果と条件付き効果を推定します。モデル番号を選ぶ方式ではありません。非対応の経路構造は実行前に確認して案内します。

<a id="generalized"></a>

## 11. ロジスティック・GLM・罰則付き回帰

ロジスティック回帰、一般化線形モデル、Ridge、LASSO、Elastic Net を提供します。結果の尺度、分布族、リンク、交差検証設定とともに係数・性能を示します。

<a id="longitudinal"></a>

## 12. 縦断・パネル・複雑標本

対応する計画で GEE、LMM、GLMM、固定・ランダム効果、複雑標本分析を提供します。個人・クラスタ ID、時間、重み、層、クラスタを確認します。

<a id="survival"></a>

## 13. 生存時間分析

Kaplan–Meier、ログランク、RMST、Cox、対応する競合リスク分析を提供します。入力形式とイベントコードを先に確認し、非対応の組合せは制限します。

<a id="cfa"></a>

## 14. 確認的因子分析（CFA）

ML、MLR、順序データ向け WLSMV/DWLS、負荷量、適合度、信頼性・AVE・HTMT、対応する測定不変性比較を提供します。Normal/Wishart は適用可能な ML 設定のみ選択できます。

<a id="sem"></a>

## 15. 構造方程式モデリング（SEM）

測定・構造経路、適合度、対応する直接・間接・条件付き効果を表示します。ブートストラップの既定値は 5,000 回で、BC またはパーセンタイル区間などの設定を反映します。

<a id="pls"></a>

## 16. PLS-SEM と PLSc

反映型 Mode A、形成型 Mode B、反映型 PLSc、経路・測定診断、対応する予測・群間比較を提供します。欠測は seminr::mean_replacement による指標平均代入で、各ブートストラップ標本で平均を再計算します。既定値は 5,000 回です。

<a id="planning"></a>

## 17. 標本数・検出力・効果量

対応する検定の標本数、検出力、効果量を計算します。有意水準、想定効果、群配分、検定の方向を記録します。

<a id="reporting"></a>

## 18. 表・図と保存

公開版 1.3.0 は HTML・画像、PDF・Word・Excel 保存を提供します。媒介・調整効果/CFA/SEM/PLS-SEM の HTML・PDF には結果モデル図を末尾に追加します。図は表示結果の配置を維持し、Free は 300 dpi、開発者・Pro は 600 dpi です。 現在の結果を確認し、結果追加で蓄積します。HTML・PDF・Word・Excel に保存できます。HWPX は韓国語 UI の累積結果画面のみで提供し、Word や Hancom を介さず直接作成します。Word/HWPX は主表・付録表・説明・図を選択でき、初期選択は主表です。保存時に再分析せず表示結果を使用します。画像は Free 300 dpi、開発者版 600 dpi です。HTML は表紙と表一覧リンクを含みます。

<a id="validation"></a>

## 19. 検証と報告の範囲

一般分析・回帰・縦断・生存時間分析を SPSS、CFA・SEM を AMOS、PLS-SEM・PLSc と CB-SEM を SmartPLS と比較しました。1.3.0 に反映した累積検証で、条件と残る差は検証ページに要約します。
