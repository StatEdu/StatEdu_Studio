# ANCOVA 영향력 진단 재사용 검토 — 미적용 — 2026-09-14

## 발견 및 결정

회귀모형 진단을 확인하던 중 `ancova_influence_diagnostics`의 학생화 잔차, 레버리지, Cook's D 계산이 동일한 `lm.influence(model, do.coef=FALSE)`를 각각 호출하는 것을 확인했다. 설치된 R 4.5.3의 `rstudent.lm`, `hatvalues.lm`, `cooks.distance.lm` 모두 공통 결과를 `infl` 인자로 받을 수 있다.

일반 lm 객체에서 공통 결과를 한 번 계산해 전달하는 후보를 구현했다. 공통 계산 중 오류·경고·메시지가 발생하거나 모형 클래스가 정확히 `lm`이 아니면 원래 진단 경로로 되돌린다. 제품에는 적용하지 않았다. 진단 함수만의 절감량은 작고 전체 분석 시간에서는 일관된 개선이 확인되지 않았다.

## 측정

2,000행, 4집단, 연속 공변량 2개, 종속변수 1개의 합성 자료를 사용했다. 시드 714, `auto_method='warn'`, `normality_enabled=FALSE`로 실행했다. 후보/기존 각 세 개의 새 R 프로세스를 순차 실행하고 두 번째 비교는 후보부터 실행했다. 준비 실행 후 전체 분석 5회를 묶어 측정했다. 별도로 동일한 적합 모형의 진단 함수 100회를 측정했다. 두 측정은 순차 수행했고 다른 R 작업을 동시에 실행하지 않았다. 로딩·자료 생성·화면·저장은 포함하지 않는다.

| 범위 | 기존 3회(초) | 후보 3회(초) |
| --- | --- | --- |
| 전체 ANCOVA 5회 | 0.14 / 0.16 / 0.16 | 0.16 / 0.14 / 0.15 |
| 진단 함수 100회 | 0.11 / 0.12 / 0.11 | 0.09 / 0.08 / 0.08 |

진단 함수의 중앙값 차이는 100회당 0.03초, 호출당 약 0.3밀리초다. 전체 분석에서는 첫 비교가 느려지고 나머지는 조금 빨라졌다. 짧은 측정의 변동을 고려하면 전체 속도 향상을 확정하기 어렵다. 더 큰 모형에서의 효과까지 일반화하지 않는다. 메모리 최고 사용량은 별도 측정하지 않았다.
