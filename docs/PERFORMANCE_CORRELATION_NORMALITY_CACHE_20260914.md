# 자동 상관분석의 변수별 정규성 판정 재사용 — 2026-09-14

`R/analysis_correlation.R`에서 자동 분석 시 변수별 정규성 논리값을 이름이 있는 벡터로 한 번 준비해 쌍별 방법 선택에 전달한다. 같은 변수의 정규성 표 조회를 반복하지 않는다. 이 벡터는 분석 호출 안에서만 사용하며 반환하는 정규성 표나 결과 객체에는 추가하지 않는다.

`correlation_pair_result`와 `correlation_method_for_pair` 끝에 선택 인자 `normality_lookup=NULL`을 추가했다. 기존 인자만 사용하는 호출은 원래 조회 경로를 따른다. 일반 data.frame이고 정확한 Name/normal 열, 클래스 없는 문자 이름, 속성 없는 논리 판정, 중복·결측·빈 이름이 없는 경우만 재사용한다. 그 외는 기존 조회를 유지한다. 잠재 상관 경로에서는 이 캐시를 만들지 않는다. 판정 기준과 방법 선택 설명문은 유지한다.

## 성능

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 최종 코드의 변경 전후 3쌍을 순차 측정했다. 두 번째 쌍은 순서를 반대로 했으며 관련 세 함수의 환경은 같은 전역 환경으로 연결했다. 100행의 숫자형 합성 자료에서 auto 분석을 실행했고 각 프로세스는 10변수 후 100변수를 실행했다.

| 변수 수 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 10 | 0.14 | 0.14 |
| 100 | 0.67 | 0.59 |

100변수의 전체 결과 준비 시간이 약 12% 감소했다. 원자료는 변경 전 0.67/0.67/0.68초, 변경 후 0.58/0.59/0.60초다. 이전 행 조회 개선 위에 추가로 적용한 효과이며 과거의 서로 다른 실험 수치를 합산하지 않았다. 화면 렌더링·앱 로딩·내보내기는 포함하지 않는다.

## 검증

- 48개 자료·분석 방법·정규성 옵션 조합에서 전체 결과·진단·난수 상태가 일치했다.
- 추가 3조건에서 auto 결과와 HTML/의존성·변환 진단이 일치했다. 기존 numeric-data 직접 호출 비교도 통과했다.
- 정규성 표를 결측 이름, 중복 이름, 빈 이름, normality라는 부분 일치 열, 사용자 정의 논리 클래스, NA 판정으로 변형한 6조건에서도 결과·진단·난수 상태가 일치했다. 기존 조회로 돌아가는 경우의 메시지 순서도 포함한다.
- 최종 시간 측정 6쌍의 전체 결과·진단·난수 상태가 `identical(...,num.eq=FALSE)`로 일치했다.
