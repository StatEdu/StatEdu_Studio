# ITT 검토에서 남긴 안내 보완

## 변경

직전 `MULTILINGUAL_MIXED_RM_ITT_GUIDANCE_20260918.md`에 남긴 실제 출력의 미번역 안내를 보완했다.

- 완전 사례가 최소 3개 필요하다는 경고.
- 적합된 LMM을 ITT 결과로 사용하라는 안내.
- 공변량을 선택하여 공변량×시점 항을 포함했다는 설명.

세 문구를 8개 언어 사전에 반영했다. 한국어 전용 처리에도 최소 사례 수 경고와 공변량×시점 설명을 반영했다. 기존 Gaussian 설명과 새 공변량×시점 설명을 결합한 셀이 번역되도록 혼합 반복측정의 문장 조각 처리 목록을 보완했다. 계산·결측 처리·모형 선택은 변경하지 않았다.

## 검증

`validate_mixed_rm_itt_remaining_i18n.R`는 직전 실제 ITT 검증 자료를 재사용한다. 완전 사례가 없는 40명·80개 관측 기록으로 LMM을 적합하고, 기존 6개 안내 검사 후 새 안내 및 결합된 설명 전체를 검사한다.

- 수정 전 한국어 사전 검사와 6개 외국어 사전·표시 검사 실패를 재현했다.
- 수정 후 8개 언어에서 두 단독 안내 및 Gaussian/공변량×시점 결합 설명 전체가 일치하는지 확인했다.
- 영어 계수 본표의 언어 간 동일성, 전체 결과 객체, 안내문과 철자가 같은 사용자 변수명 보존 검사 통과.
- 이번 LMM 안내는 실제 확인한 `Use the fitted LMM as the ITT result.` 표기이다. 다른 모형 이름 또는 완전 사례 ANOVA가 함께 나오는 ITT 안내 변형 전체를 검증했다는 의미는 아니다.

- 공통 16개 부록 변환 함수·8개 결과 렌더러의 8개 언어 회귀 검사 및 `validate_i18n_contract.R` 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 검사와 PDF 텍스트 보존 검사 통과. 두 언어 모두 현재 PDF 6쪽·누적 10쪽이다.
- 일본어 현재 PDF 3·4쪽을 Poppler로 렌더링하여 새 안내와 결합 설명의 표시·줄바꿈을 확인했다. 다른 문서 앱별 수동 시각 검토는 수행하지 않았다.
- `validate_longitudinal_count_exports.R` 및 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이고 실제 본문은 이번 ITT 결과 캡처다. 저장 단계에서 분석을 재실행하지 않았다. 산출물: `tmp/mixed-rm-itt-remaining-i18n/exports`.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드는 수행하지 않았다.
