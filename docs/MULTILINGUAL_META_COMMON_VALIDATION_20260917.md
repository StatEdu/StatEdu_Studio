# 메타분석 공통 입력 검증 — 2026-09-17

효과/표집분산 오류, 대상 효과 유형, 보고 형식, 연구 ID 필수 안내 및 출판연도 범위 안내를 8개 언어로 연결했다. 영어 원문은 유지하고 다른 언어의 효과/표집분산 설명은 실제 조건(효과가 유한하지 않거나 분산이 유한한 양수가 아님)에 맞췄다. 음의 효과를 금지하는 조건을 추가하지 않았다.

출판연도 안내의 상한은 오류에 포함된 네 자리 연도를 그대로 사용한다. 등록된 고정 안내와 연도 안내가 연속된 복합 오류를 번역하되, 알 수 없는 상세가 포함되면 원문 전체를 보존한다. 계산·입력 검증 조건·저장 메시지·분석 표 및 보고서는 변경하지 않았다.

`validate_meta_common_validation_i18n.R`: 실제 공통 오류, 출판연도 하한/상한/비정수 오류와 유효 경계, 다른 상한 연도, 3종 결합 오류 및 사용자 문구 보존을 8개 언어와 한국어 복귀로 확인했다. g/OR 복합 오류 회귀와 카탈로그 검사도 통과했다. 실제 브라우저 검사는 아니다.

모형 실행 오류와 종단분석 등 다른 화면의 최종 점검은 남아 있다. 설치본을 만들지 않았다.
