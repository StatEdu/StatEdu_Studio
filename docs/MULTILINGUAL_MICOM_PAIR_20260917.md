# MICOM 집단쌍 비교·PLS-MGA 유효성 보조표 다국어 보완

- MICOM 집단쌍 비교 허용표, PLS-MGA 집단별·집단쌍별 부트스트랩 유효성 표, 조절·조절된 매개효과 집단쌍 유효성 표의 상태·사유·열 이름을 UI 언어로 표시한다.
- 합성불변성 통과/실패, 순열 유효성 부족, MICOM 미평가, 집단 구성 불일치, 허용 기록 누락/중복, 필수 열 누락 등 알려진 사유를 번역한다. 미등록 오류와 사용자 집단명은 보존한다.
- 명시적으로 번역한 사유/상태 열을 일반 테이블 재번역에서 보호한다. 계산 및 본표 생성은 변경하지 않았으며 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_micom_pair_i18n.R`: 등록된 모든 상태·사유의 번역을 8개 언어에서 검증했다. 실제 부트스트랩 유효성 함수와 집단쌍 허용 함수를 사용한 자료로 네 보조표를 확인했다.
- 정상·사용자 문구·구형 중첩 위치·빈 결과의 네 경우를 검증했다. 집단명, 허용 여부, 반복 수·최소 유효 수·비율·집단쌍 seed의 보존을 확인했다.
- 기존 `validate_sem_micom.R` 및 집단 데이터 진단 다국어 회귀 검증 통과.
- `tmp/micom-pair-i18n/entries.rds` 표시 스냅샷 기반 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 검증 통과. 현재 8표·누적 12표의 순서와 Excel 시트 수, PDF 일본어 제목·내용·표지를 확인했다. 저장 시 분석은 다시 실행하지 않았다.

전체 다국어 완료 판정은 아니며, 다른 다집단 보조표의 개별 설명 문구는 추가 점검 대상이다.
