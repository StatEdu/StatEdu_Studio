# 지연 진입·시작/종료 추천 이동 검사

`scripts/validate_survival_structure_navigation_browser.cjs`는 개발 서버의 실제 Chrome에서 다음 세 경로를 검사한다.

- 지연 진입 자료 → KM: 종료 시간·진입 시간·사건·집단 배정
- 지연 진입 자료 → Cox: 종료 시간·진입 시간·사건·공변량 배정
- 시작/종료 자료 → 시간의존 Cox: 구간 시작·종료·대상자 ID·사건·공변량 배정

생성한 CSV를 사용한다. 검열 코드 `7`, 사건 코드 `9`를 명시적으로 매핑하고 추천 버튼으로 분석 화면에 이동한다. 자료 구조와 모든 배정값을 검사한 다음 진입 시간 또는 대상자 ID를 수정한다. 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어로 전환하며 수정한 입력이 유지되는지 검사한다.

검사 범위는 입력 전달과 언어 전환 시 유지이다. 분석 실행·통계 결과·내보내기는 변경하지 않는다. 번역문 자체의 전문 용어 검수, 모든 오류 분기, 네이티브 파일 대화상자, 추천 설계 파일 저장은 이 검사에 포함하지 않는다. 설치본은 만들지 않는다.

로그: `tmp/survival-structure-navigation-browser.log`, `tmp/survival-structure-navigation-server.log`.

세 경로 × 8언어 검사 모두 통과했고 페이지 오류는 없었다. 이번 검사에서 제품 소스 수정이 필요한 새 오류는 발견하지 않았다. 테스트 서버와 브라우저를 종료했다.
