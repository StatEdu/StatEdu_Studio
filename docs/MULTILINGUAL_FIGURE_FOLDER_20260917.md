# 그림 저장 폴더 선택 창 — 2026-09-17

한국어/영어로만 분기하던 폴더 선택 창 제목을 `file_dialog.figure_folder` 번역 키로 바꾸었다. 8개 언어를 지원하며 호출 시점의 앱 언어 옵션 또는 명시적인 language 인자를 사용한다. 반환 경로, 취소 처리, 폴더 선택 도구 및 그림 저장 동작은 유지한다.

`validate_figure_folder_i18n.R`에서 Windows·utils·RStudio·Tk 호출 경계를 대체하여 8개 언어 및 한국어 복귀를 검사했다. 네 경로의 제목, 취소 시 후속 창 호출 방지, 한글/공백/&/%s 폴더 경로 보존, 명시적 언어 인자 및 앱 언어 옵션 불변, 실제 Windows 도우미가 생성하는 PowerShell 문자열 인용을 확인했다. 모두 통과했다. 그림 오류 안내·결과 저장 창·번역 커버리지 회귀 검사도 통과했다.

이는 호출 인자와 반환 처리 검사다. 실제 네이티브 창 표시·사용자 클릭 검증을 완료한 것은 아니다. 보고서·그림 내용 및 설치본은 변경하지 않았다.
