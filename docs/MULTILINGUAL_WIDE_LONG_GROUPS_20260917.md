# 와이드→롱 다중 그룹 검사 — 2026-09-17

## 재현 및 수정

동일 대상의 집단·시점 구조를 두 개 설정하는 브라우저 검사에서, 입력한 변수명과 그룹 수가 이전 값으로 돌아가 그룹이 의도대로 생성되지 않는 문제를 재현했다. 설정 입력값 전체를 화면의 반응형 의존성으로 읽던 부분을 격리했다. 개별 입력 변경은 세션 상태에 저장하되 전체 설정 UI 재생성을 유발하지 않는다. 언어·선택 열·설정 그룹 변경에 따른 기존 화면 갱신은 유지한다.

추가 회귀 검사에서 화면을 떠났다 돌아올 때 오래된 설정 UI가 복원되는 경우도 확인했다. 설정 출력의 숨김 상태를 갱신 조건으로 읽고 숨겨진 동안에도 최신 상태를 렌더링하도록 보완했다. 이에 따라 입력 중 과도한 재생성과 화면 복귀 시 오래된 입력 복원을 함께 방지한다.

## 검사 범위

`validate_wide_long_groups_browser.cjs`는 합성 CSV에서 `측정A`, `측정B` 두 그룹을 각각 2집단 × 2시점으로 설정한다. 8언어에서 그룹 순서를 위/아래 버튼으로 변경하고, B 그룹을 삭제한 뒤 원본 열이 선택 목록에 돌아오는지 확인하고, 다시 생성한다. 단계마다 실제 미리보기의 열 순서, ID·집단·시점과 측정값을 검사한다. 포인터 드래그 동작 자체를 검사한 것은 아니다.

`validate_wide_long_status_i18n.R`, `validate_wide_long_errors_i18n.R`의 실제 서버 상태/오류 검사도 다시 통과했다.

최종 수정 후 `validate_wide_long_browser.cjs`의 기존 8언어 미적용 입력·옵션 탭·미리보기 검사와 `validate_data_editor_wide_long.R`도 통과했다.

로그: `tmp/wide-long-groups-browser.log`, `tmp/wide-long-status-i18n.log`, `tmp/wide-long-errors-i18n.log`.

최종 다중 그룹 브라우저 검사도 8언어 모두 통과했고 pageerror는 없었다.

## 범위 제한

같은 이름의 기존 그룹에 다른 원본 열을 덮어쓰는 갱신 경로, 자료 교체, 포인터 드래그 및 네이티브 저장 창의 종합 브라우저 검증은 별도로 남긴다. 분석 출력/내보내기 경로 변경과 설치본 생성은 없다.
