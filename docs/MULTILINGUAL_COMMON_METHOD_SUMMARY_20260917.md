# 동일방법편의 진단 요약표 다국어 점검

## 변경

- 방법명, 통계량 이름, 판정 상태, 해석 문구를 영어·한국어·일본어·중국어·스페인어·프랑스어·독일어·베트남어에 적용했다. 기존 한국어 전용 분기를 공통 조회로 바꿨다.
- 여러 검토 사유를 조합하는 판정 요약에도 개별 사유의 번역을 적용했다.
- 단일요인 CFA의 관측변수 부족 안내에 누락된 한국어 및 6개 언어 번역을 추가했다.
- 계산 실패 안내의 접두부만 번역하고 오류 상세 내용은 그대로 보존한다. 영어를 지정해도 한국어로 바꾸던 기존 guidance helper의 무조건 치환을 제거했다.
- 알려진 프로그램 문구만 번역하며, 미등록 값은 유지한다. 이미 번역한 요약표와 판정 요약의 셀은 일반 테이블 번역에서 다시 치환하지 않는다.
- 분석 계산, 수치 정밀도 설정, 본표 생성 로직은 변경하지 않았다. 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_common_method_summary_i18n.R`: 5종 라벨 함수의 모든 등록 문구, 21개 판정 조합 × 8개 언어, 두 계산 실패 접두부와 사용자 오류 상세 내용, 미등록 사용자 문자열, 소수점 3자리 수치 보존을 검증했다.
- `scripts/validate_common_method_panel_i18n.R`: 실제 renderUI 분기의 기존 제목·안내 검증도 통과했다.
- `tmp/common-method-summary-i18n/entries.rds` 스냅샷으로 현재·누적 HTML/PDF/Word/HWPX/Excel 변환을 검증했다. 현재 11표·누적 13표의 순서와 Excel 시트 수, PDF 일본어 문구·표지를 확인했다. 저장 중 분석 재실행은 하지 않았다.

## 남은 점검

이번 범위는 진단 요약표와 판정 요약이다. 별도 모형 적합도 비교·모형 차이 비교·적재량 변화 표의 내부 이름 및 사용자 변수 보호는 추가 점검 대상이다. 전체 다국어 완료를 의미하지 않는다.
