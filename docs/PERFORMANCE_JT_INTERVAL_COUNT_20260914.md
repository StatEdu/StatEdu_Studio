# Jonckheere–Terpstra 추세검정 비교 행렬 제거

## 변경

`R/analysis_ttest_anova.R`의 `ttest_jt_test`는 집단 쌍마다 `outer(later, earlier, "-")`로 모든 관측값 차이의 행렬을 만들고, 양수의 개수와 0의 개수에 절반 가중치를 주어 합산했다.

유효한 값이 모두 유한한 경우 각 집단을 한 번 정렬한 뒤 `findInterval`로 더 작은 값의 개수와 같거나 작은 값의 개수를 구한다. 두 개수의 차이가 동점 수다. 집단 쌍 순서와 `jt + greater + 0.5 * equal` 합산 순서는 유지한다. 분산·표준화·대립가설·p값·효과크기 공식은 바꾸지 않는다. 특히 기존 JT 분산식에 별도 동점 보정을 추가하지 않았다.

무한대가 하나라도 있으면 기존 `outer` 경로를 그대로 사용한다. `Inf - Inf` 및 `-Inf - -Inf`가 NaN이 되어 원래 집계에서 제외되는 동작을 보존하기 위해서다. 결측 제거, 집단 순서, 입력 변환, 반환 구조도 유지한다.

유한한 입력에서 집단 크기의 곱에 해당하는 행렬 할당을 제거했다. 예를 들어 각 2,000개인 두 집단은 기존에 차이 400만 개의 숫자 행렬을 만들었다. 이번 작업에서 실제 프로세스 최대 메모리는 측정하지 않았으므로 전체 메모리 절감률은 주장하지 않는다.

## 정확성

`scripts/validate_jt_interval_count.R`은 현재 함수에서 이번 분기만 원래 비교 행렬 코드로 복원한 참조와 비교한다. 정규화·허용오차 없이 `identical(..., num.eq=FALSE)`로 원시 반환값과 경고/메시지/오류, stdout, 난수 상태를 검사했다.

- 원시 JT 통계량·z·p·r 486개: 2/4/8집단, 표본 크기 0/1/4/20/100/1,000, 세 대립가설, 일반·동점·상수·인접 실수·큰 크기의 인접 실수·비정규화된 극소 실수·최대 크기의 양/음수와 부호 있는 0·결측·무한대.
- 전체 분석 72개: 2/4/8집단, 일반·동점·인접 실수·상수·결측·무한대, 추가 표 켜기/끄기, 연속형/순서형 종속변수 2개, 순서형 집단과 추세검정 활성화.
- 잘못된 대립가설, 빈 문자열/결측/미사용 수준을 포함한 집단 레이블 경계 사례.
- 기존 본검정 재사용 검증: 원시 htest 50개, 전체 결과 48개, 진단 주입 10개 통과.
- 기존 효과크기 재사용 검증: 효과크기 경계 84개, 전체 결과 24개, 원시 숫자 계측 12개, 진단 주입 10개 통과.

## 전체 분석 성능

4,000행, 2/4/8집단, 연속값/반올림한 동점값, 결측률 0/0.1. 값과 집단에 독립적으로 결측을 적용했다. 집단은 순서형으로 지정하고 비모수·사후검정·추가 평균/표준편차 표·효과크기·추세검정을 켰다.
