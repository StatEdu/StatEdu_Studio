# Fine–Gray 후보의 전체 분석·저장 통합 검증 — 2026-09-14

## 결과와 범위

별도 캐시 DLL을 검증용 R 프로세스에서 실제 `prepare_competing_risk_result(..., regression='both')` 경로에 연결했다. 2,000행·10공변량에서 CIF·Gray 검정, 원인별 Cox, Fine–Gray 및 진단을 포함한 분석 시간이 중앙값 2.02초에서 0.98초로 약 51.5% 감소했다. 화면 렌더링·저장·앱 시작 시간은 이 측정에 포함하지 않는다.

운영 소스와 설치된 cmprsk DLL은 수정하지 않았다. 테스트 프로세스 안에서만 `cmprsk`의 `crr` 바인딩을 후보 래퍼로 교체하고 `on.exit`로 복원한다. 다른 네이티브 루틴은 설치 버전을 사용하며 후보의 분산 루틴만 명시적 주소로 호출한다. 이 연결 방식은 운영 구현안이 아니다.

## 분석 정확성과 시간

정규 합성 공변량, 지수분포 시간, 사건 0/1/2, 시드 44, 세 집단 자료를 사용했다. 각 버전은 새 R 프로세스에서 한 번 측정했으며 두 번째 묶음은 순서를 뒤집었다. 입력 생성·모듈 로딩·파일 저장은 제외했다. 동일한 진단/표준출력 수집과 반환 객체 환경 정규화는 측정에 포함했다. 측정 중 프로파일링이나 다른 검증을 실행하지 않았다.

| 묶음 | 설치 버전(초) | 후보(초) |
|---|---:|---:|
| 1 | 2.02 | 0.99 |
| 2 | 2.01 | 0.97 |
| 3 | 2.02 | 0.98 |

측정 결과 3쌍과 별도의 300행 10조건(일반·동률·범주형 변수·결측·검열 집단 × Fine–Gray 단독/원인별 Cox 포함)을 비교했다. 전체 반환값, 오류 외 진단, 표준출력, 난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 이 검사는 오류가 발생하면 중단하므로 10조건 모두 정상 반환되었다. 실제 Fine–Gray 계수 수와 원인별 Cox PH 열 수를 검사하여 모델이 생략되지 않았음을 확인했다.

원인별 Cox의 formula/terms 및 존재할 경우 model terms에 저장된 환경 참조만 `.GlobalEnv`로 정규화했다. 숫자·모형 구조·진단에는 허용오차나 정규화를 적용하지 않았다. 범주형 조건은 더미 변수 확장으로 계수 수가 증가한다.

## 화면과 저장

2,000행 측정 결과의 설치 버전과 후보를 각각 렌더링했다. 화면 HTML과 저장 콘텐츠(그래프 PNG 포함)가 완전히 일치했다. 렌더링 전후 분석 객체 직렬화 값도 유지됐다.

현재 결과 1개와 누적 결과 2개 각각에서 HTML 파일 바이트가 일치했다. Excel은 시트 이름·읽은 셀 값과 내부 파일 바이트를 비교했다. `docProps/core.xml`의 생성/수정 시각만 정규화했고 나머지 파일은 원시 바이트가 일치했다.

후보의 동일한 저장 콘텐츠로 현재/누적 각각 HTML·PDF·Word·HWPX·Excel 총 10개 파일을 생성했다. HTML·Word·HWPX에 포함된 PNG의 SHA-256이 원본 4개 이미지와 일치했고 그림 참조 수도 현재 4개, 누적 8개였다. PDF는 현재 20쪽, 누적 40쪽이며 PH 그림은 각각 8쪽, 8/28쪽에서 확인했다. 현재 PDF 8쪽을 렌더링하여 10개 PH 패널과 하단 주석이 표시됨을 눈으로 확인했다.

PDF·Word·HWPX는 설치 버전과 파일 전체를 대조한 검사가 아니라, 이미 동일함을 확인한 저장 콘텐츠에서 생성하고 이미지 보존 및 참조 수를 검사한 것이다. Word/한글 앱 안의 전체 페이지 배치는 육안 검증하지 않았다. 결과는 `output/fine-gray-app-integration-20260914/export-status.csv` 및 `artifact-validation.json`에 기록했다.

## 의존성과 남은 작업

PE import 목록에는 Windows Kernel32와 UCRT API DLL만 나타났다. `PATH`를 Windows System32만 남긴 새 R 프로세스에서도 후보를 로드하고 100행·3공변량 적합 결과의 동일성을 확인했다. 개발 도구 경로가 필요하지 않다는 이 머신의 확인이며, 새 머신의 설치·실행 검증을 대체하지 않는다.

운영 로더의 버전/플랫폼 제한, 원본으로 돌아가는 처리, 재현 가능한 배포 패키지 구성, 새 머신 검증은 남아 있다. 모든 극단 입력에서의 비트 동일성을 보장하지 않으며 메모리 최대 사용량은 측정하지 않았다. 설치 파일은 재빌드하지 않았다.

재현 스크립트, 측정 RDS/CSV, 렌더링 콘텐츠, 내보낸 파일, 설치 DLL과 관련 소스 해시는 `output/fine-gray-app-integration-20260914/`에 보관했다. 후보 자체의 빌드와 직접 적합 61조건 검증은 [이전 보고서](PERFORMANCE_FINE_GRAY_NATIVE_CANDIDATE_20260914.md)를 참고한다.
