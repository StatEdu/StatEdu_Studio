# 신뢰도 순서형·KR-20·하위요인 경로 다국어 보완

## 변경

순서형 alpha/omega 문항 제거 열, KR-20 문항 제거 열, 전체 척도 문항 제거 열, 하위요인 제목 및 각 경로의 설명 등 10개 문구를 8개 언어 사전에 등록했다. 하위요인 통합 결과의 전체 문항 제거 설명도 사전을 사용하도록 연결했다. 통계 계산은 변경하지 않았다.

## 검증

- `scripts/validate_reliability_branches_i18n.R`: 120행·6문항 자료에서 순서형 alpha/omega, 순서형 alpha만, KR-20, 연속형 alpha만의 실제 분석을 실행했다. 실제 계산한 전체 척도 및 두 하위요인 결과를 서버와 같은 결과 구조로 조합하여 렌더러도 검사했다. Shiny에서 하위요인을 직접 조작한 검사는 아니다.
- 8개 언어에서 본표 셀·제목·주석의 영어 동일성, 보조표의 문항명·하위요인명·수치 보존 통과. 추가 6개 언어의 10개 번역 문구 렌더링 통과.
- 기존 연속형 신뢰도 다국어 검사 및 `validate_i18n_contract.R` 통과.
- 일본어 다섯 경로 전체 저장 fixture: `tmp/reliability-branches-i18n/entries.rds`. 내보내기 로그: `tmp/reliability-branches-exports.log`.
- 현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성 통과. 실제 PDF 텍스트 검사도 두 경로 모두 통과.

## 남은 범위

설정·입력 오류, 자동 생성 하위요인 이름의 보조표 표시 정책, 혼합 설정 하위요인, 브라우저 언어 왕복은 추가 확인 대상이다. 새로운 화면을 추가 검증한 차수가 아니므로 전용 결과 검증 공백은 15개를 유지한다. 설치본은 만들지 않았다.
