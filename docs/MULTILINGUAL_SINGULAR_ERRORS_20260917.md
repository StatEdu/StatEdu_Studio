# 수정지수·특이행렬 오류 안내 — 2026-09-17

- 수정지수 계산 실패(특이 정보행렬/기타), 특이 정보행렬, 수치적으로 거의 특이한 행렬의 오류 안내를 추가 6개 언어로 번역했다. 기존 영어/한국어 경로와 엔진 계산은 유지한다.
- 역조건수는 원문 문자열로 표시하며 다시 수치 변환하거나 반올림하지 않는다. 역조건수가 없는 오류에는 해당 값을 만들어 표시하지 않는다.
- `scripts/validate_singular_errors_i18n.R`: 실제 `solve()` 오류와 대표 메시지 6개를 8개 언어로 검사했다. `1.23456789e-18` 등 수치 원문과 미등록 오류 보존을 확인했다.
- 기존 선택 경로·PLS 오류 검사, 공통 다국어 사전 및 diff 공백 검사 통과.
- 로그: `tmp/singular-errors-{validation,coverage}.log` 및 기존 오류 검사 로그.
- 수정지수 오류는 시험 메시지이며 실제 lavaan MI 실패 모델을 적합한 것은 아니다. 실제 브라우저 오류 알림 검증도 별도로 남아 있다. 결과표/내보내기는 변경하지 않아 저장 검사를 재실행하지 않았다.

모형 식별성 코드별 안내 등은 남은 점검 대상이다. 전체 다국어 완료를 의미하지 않는다. 설치본은 생성하지 않았다.
