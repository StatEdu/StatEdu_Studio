# Gwet·Krippendorff 쌍 캐시 통합 검증

## 결과

최근 적용한 두 지역 캐시를 함께 검증했다. 두 개선 이전 소스와 현재 소스를 직접 비교했으며 이번에 제품을 추가로 변경하지 않았다. 결측 자료에서 전체 분석 시간이 세 번 모두 감소했고, 전체 반환 객체·진단·난수 상태 및 별도로 수집한 원시 Gwet/alpha 값이 일치했다.

기준은 `output/gwet-pair-cache-20260914/baseline.R`이다. 현재 제품과 스냅샷 SHA256은 `8391EC42E1F8D2ED44243E4F1B61041C5AA3135E1982615C7FB8A3482FD6CABA`로 일치했다. 두 소스는 이전 ICC 행 평균 차감 개선을 모두 포함한다.

## 측정 조건

번들 R 4.5.3, 자료 seed 939, 5,000행·8평가자·5범주다. 먼저 완전 자료를 만들고 별도 균등 난수 마스크로 결측률 0, 1/6, 0.6을 적용했다. 표의 결측률은 생성 확률이며 실현된 정확한 비율은 아니다. 앞선 개별 보고서의 NA를 범주처럼 표집한 자료와는 다르다.

명목형/순서형 × 결측률 3종의 6개 조건을 독립 프로세스 3개에서 순차 측정했다. 워밍업 후 두 번째 프로세스는 후보부터 실행하고 유형 순서도 반대로 했다. 로딩을 제외하고 전체 분석과 캡처를 포함한다.

| 결측 생성 확률 | 유형 | 기존 1 / 2 / 3 (초) | 현재 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|---|
| 0% | 명목형 | 0.19 / 0.09 / 0.19 | 0.13 / 0.09 / 0.12 | 0.19 → 0.12 |
| 0% | 순서형 | 0.08 / 0.10 / 0.08 | 0.08 / 0.18 / 0.08 | 0.08 → 0.08 |
| 약 17% | 명목형 | 0.20 / 0.20 / 0.21 | 0.13 / 0.11 / 0.11 | 0.20 → 0.11 |
| 약 17% | 순서형 | 0.18 / 0.19 / 0.19 | 0.11 / 0.11 / 0.13 | 0.19 → 0.11 |
| 60% | 명목형 | 0.14 / 0.14 / 0.14 | 0.10 / 0.08 / 0.10 | 0.14 → 0.10 |
| 60% | 순서형 | 0.12 / 0.14 / 0.12 | 0.09 / 0.08 / 0.10 | 0.12 → 0.09 |

결측이 있는 네 조건은 각각 세 번 빨라졌다. 약 17% 조건에서 중앙값은 약 45%/42%, 60% 조건에서 약 29%/25% 감소했다. 개별 개선의 이전 감소율을 합산한 값이 아니다.

결측이 없는 경우는 이미 직전 평가자 수 재사용이 가능하다. 명목형 시간 차이를 추가 캐시의 구조적 효과라고 단정하지 않는다. 순서형의 두 번째 실행은 느려졌으며 짧은 실행의 변동을 고려해야 한다. 모든 입력의 동일한 개선율이나 결측 증가에 따른 일반적 실행 시간 관계를 주장하지 않는다.

## 동일성

18개 측정 비교 및 대응하는 18개 워밍업 비교에서 전체 반환 객체, 조건 클래스·본문·순서, 표준 출력 및 RNG가 `identical(..., num.eq=FALSE)`로 일치했다. 같은 6개 자료 조건의 반복이며 36종 자료를 검사한 것은 아니다. 이 자료에서는 조건이 발생하지 않았다.

별도 6개 조건에서 Gwet와 Krippendorff 함수를 감싸 반올림 전 계수를 수집했다. 두 원시 계수와 전체 결과·진단·출력·RNG가 모두 일치했다. 허용오차나 정규화를 사용하지 않았다. 개별 개선의 192/147개 경계 검증을 이번에 다시 수행한 것으로 집계하지 않는다.

## 증거 및 제한

`output/interrater-pair-combined-20260914/`에 baseline.R, candidate.R, bench.R, timing-1/2/3.csv, 실행 로그, verify-raw.R 및 raw-validation.log를 보관했다. 초기 자료 생성의 data.frame 논리 인덱스 오류는 논리 matrix 인덱스로 수정한 뒤 측정을 다시 시작했다. 제품 오류가 아니다.

이번에는 제품·출력 변경이 없어 전체 형식 변환, 설치 파일 빌드 및 종합 회귀 테스트를 실행하지 않았다. 메모리 최고 사용량도 측정하지 않았다.
