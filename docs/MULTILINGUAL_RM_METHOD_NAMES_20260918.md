# 반복측정 분산분석·Wilks 분석명 번역

## 변경

실제 부록 분석 개요의 반복측정 분석명이 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남는 것을 재현했다. 아래 4개 표기를 8개 언어 사전에 반영하고 기존 영어·한국어 표현을 유지했다.

- RM ANOVA
- Standard RM ANOVA
- RM ANOVA + Wilks
- RM ANOVA + Wilks' lambda

계산·렌더링·저장 코드는 변경하지 않았다.

## 검증

- `validate_rm_method_names_i18n.R`: 시드 918로 생성한 100개 사례의 연속형 반복측정 자료를 사용했다. 가정 검토를 끈 표준 분석과 가정 검토를 켠 분석을 실제 실행했으며 후자는 구형성 검토에 따라 Wilks 방식이 선택된 것을 확인했다. 분석명만 주입한 검사는 아니다.
- 8개 언어의 전체 결과 패널에서 부록의 짧은 분석명, 별도 부록 표 함수에서 긴 분석명을 검사했다.
- 영어 본표 동일성과 원본 결과 객체 보존 검사 통과.
- `validate_paired_guards.R`, `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/rm-method-names-i18n/exports`. 실제 패널 캡처를 저장하며 저장 과정에서 분석을 재실행하지 않는다. 별도 긴 분석명 검사 표는 저장 캡처에 포함하지 않았다.

## 범위

이번 작업은 표준 반복측정 ANOVA와 Wilks 분석명에 한정한다. Greenhouse–Geisser 표기는 현재 분석 선택 경로와 저장된 결과 지원 여부를 확인한 뒤 별도 처리한다. 비모수 반복측정 분석명도 후속 점검 대상으로 남는다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면은 계속 제외한다.
