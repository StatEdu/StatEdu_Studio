# 用户指南 — StatEdu Studio 1.3.0

1.3.0 将 CFA、SEM、PLS-SEM/PLSc 加入公开分析范围，并提供生存分析的 RMST 和竞争风险流程。还可使用中介与调节画布、常规分析、纵向与面板、复杂抽样和样本量与效应量工具。版本历史区分既有功能改进与本次新增公开功能。

开发者安装包为 StatEdu Studio Dev 1.3.0-dev，使用独立应用名称并保留开发菜单。公开版排除元分析和同一对象内处理的重复测量 ANOVA，但保留混合重复测量 ANOVA 与配对检验。

## 1. 启动与数据准备

安装后从开始菜单打开 StatEdu Studio Dev。载入数据，核对变量名、测量水平、缺失值与类别编码。若启用了个案选择或数据拆分，先核对分析范围，再分配变量、设置选项并运行。切换界面语言会保留用户变量名和原始数据值。

## 2. CFA

在 CFA 中将观测指标分配给潜在因子并设置因子关系。根据数据选择支持的估计方法、缺失处理、标准化与自助法设置。先查看识别、收敛和不当解警告，再查看载荷、拟合、信度、AVE 与 HTMT。组间比较须核对测量不变性设置和约束。

## 3. SEM

在 SEM 画布上建立测量模型和结构路径，核对直接与间接效应所需路径。设置估计方法和自助法后运行，同时报告系数、置信区间、拟合和有效重复次数。修改路径或节点会使原结果失效，须重新运行。可保存布局和模型文件。

## 4. PLS-SEM / PLSc

分配构念与指标，选择反映型 Mode A 或形成型 Mode B。PLSc 用于支持的反映型模型。核对路径、自助法、预测和组间比较选项后运行。结合载荷或权重、共线性、信度、效度和结构路径进行判断。区分请求与有效重复次数，不要忽略估计拒绝或重复不足警告。

## 5. 生存分析

设置时间与事件变量、事件/删失编码、时间单位以及组别和预测变量。查看推荐方法和支持条件，再进入 Kaplan–Meier、生命表、RMST、Cox 或竞争风险。核对 RMST 限制时间 τ 和 Cox 比例风险诊断。区分关注事件和竞争事件，不应将 CIF、原因别 HR、Fine–Gray SHR 视为同一指标。

## 6. 查看、累积与保存结果

查看当前结果并添加到结果集中。支持 HTML、PDF、Word、Excel；HWPX 仅在韩语界面的累积结果页提供，直接生成而不经 Word 或 Hancom 转换。Word/HWPX 可选择主表、附录表、说明和图形，默认主表。保存使用已捕获的显示结果，不重新计算。Free 图像为300 dpi，开发者版为600 dpi。HTML 包含封面和表目录链接。

## 7. 文档与验证范围

在信息菜单打开概述、用户指南、分析、方法说明、验证和版本历史。统计主表保持英语，菜单与补充说明使用界面语言。验证仅适用于列明的数据和条件，不代表全部组合或母语审校。

## 重要性–表现分析（IPA）

打开分析 → IPA，选择直接评分或推导重要性。直接评分按相同属性顺序分配重要性和表现变量；推导重要性指定表现和总体满意度。选择总体、独立组或配对前后设计。配对资料使用 WIDE 对应列或 LONG 的 ID、时间及两个时间值。设置参考线和图形，运行后检查样本数、坐标、区间和组/时间差异。Word/HWPX 在添加结果后从累积结果保存。
