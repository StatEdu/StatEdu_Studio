# ユーザーガイド — StatEdu Studio 1.3.0

1.3.0 は CFA、SEM、PLS-SEM/PLSc を公開分析に追加し、生存時間分析で RMST と競合リスクの処理を提供します。媒介・調整効果のキャンバス、一般分析、縦断・パネル、複雑標本、標本数・効果量の機能も利用できます。既存機能の改善と新たな公開機能は変更履歴で区別します。

開発者版は StatEdu Studio Dev 1.3.0-dev です。公開版とは別のアプリ名で、開発用メニューを保持します。公開版はメタ分析と同一対象内の処置反復測定 ANOVA を除外しますが、混合反復測定 ANOVA と対応のある検定は利用できます。

## 1. 起動とデータ準備

インストール後、スタートメニューから StatEdu Studio Dev を起動します。データを開き、変数名、測定水準、欠測、カテゴリの符号化を確認します。ケース選択とデータ分割が有効なら適用範囲を確認し、変数とオプションを指定して実行します。UI 言語を変更してもユーザーの変数名とデータ値は保持されます。

## 2. CFA

CFA で観測指標を潜在因子に割り当て、因子間の関係を設定します。対応する推定法、欠測処理、標準化、ブートストラップを選びます。識別、収束、不適解の警告を確認してから、負荷量、適合度、信頼性、AVE、HTMT を読みます。群間比較では測定不変性の設定と制約を確認します。

## 3. SEM

SEM キャンバスで測定モデルと構造パスを構成し、直接・間接効果に必要なパスを確認します。推定とブートストラップの設定後に実行し、係数、信頼区間、適合度、有効反復数を併記します。パスやノードを変更すると旧結果は無効になるため再実行します。配置とモデルファイルを保存できます。

## 4. PLS-SEM / PLSc

構成概念と指標を割り当て、反映型 Mode A または形成型 Mode B を選択します。PLSc は対応する反映型モデルに適用します。パス、ブートストラップ、予測、群間比較の設定を確認し実行します。負荷量・重み、共線性、信頼性、妥当性、構造パスを併せて確認し、要求反復数と有効反復数を区別します。推定拒否や反復不足の警告を無視しないでください。

## 5. 生存時間分析

時間・イベント変数、イベントと打切りのコード、時間単位、群・説明変数を設定します。推奨と対応条件を確認し、Kaplan–Meier、生命表、RMST、Cox、競合リスクへ進みます。RMST の制限時点 τ と Cox の比例ハザード診断を確認します。関心イベントと競合イベントを区別し、CIF、原因別 HR、Fine–Gray SHR を同一視しないでください。

## 6. 結果の確認・追加・保存

現在の結果を確認し、結果追加で蓄積します。HTML・PDF・Word・Excel に保存できます。HWPX は韓国語 UI の累積結果画面のみで提供し、Word や Hancom を介さず直接作成します。Word/HWPX は主表・付録表・説明・図を選択でき、初期選択は主表です。保存時に再分析せず表示結果を使用します。画像は Free 300 dpi、開発者版 600 dpi です。HTML は表紙と表一覧リンクを含みます。

## 7. 文書と検証範囲

情報メニューから概要、ガイド、分析、方法論ノート、検証、変更履歴を開きます。統計主表は英語、メニューと補足説明は UI 言語を使用します。検証は記載したデータと条件に限られ、全組合せや母語話者による校閲を意味しません。

## 重要度–遂行度分析（IPA）

分析 → IPA で直接評価または導出重要度を選びます。直接評価は重要度と遂行度を同じ属性順に割り当て、導出重要度は遂行度と総合満足度を指定します。全体・独立群・対応前後を選択し、対応データは WIDE の対応列または LONG の ID・時点と2時点値を指定します。基準線・図を設定し、標本数、座標、区間、群・時点差を確認します。Word/HWPX は結果追加後の累積結果から保存します。
