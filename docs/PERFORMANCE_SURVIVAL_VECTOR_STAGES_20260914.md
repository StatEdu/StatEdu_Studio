# 생존확률 벡터 단계별 비용 — 2026-09-14

## 결론

보정 생존곡선의 익명 함수에 합쳐져 있던 비용을 다섯 단계로 구분했다. 2,000건 자료에서는 지수함수 계산이 가장 컸고, 평균 계산과 관측치 순서 복원이 뒤를 이었다. 결측 검사만 추가로 생략하는 변경은 우선순위가 낮다. 이번 작업은 계측이며 제품 코드를 변경하지 않았다.

## 측정 방법

번들 R 4.5.3에서 600/2,000건, 3집단, 연속 공변량 1개, 사건 생성 확률 0.45, 부트스트랩 60회, 선택 시점 0·10·20으로 실행했다. 자료 시드는 421이며 기존 최적화를 모두 유지했다.

`survival_adjusted_curve_once`의 로컬 복사본에서 시점별 계산만 이름 있는 함수 호출로 나눴다.

1. `-hazard * risk` 또는 `-hazard * distinct_risk`.
2. 앞 단계 결과의 `exp`.
3. 필요한 경우 고유 위험도 결과를 원래 관측치 순서로 복원.
4. 복원된 값의 `anyNA`.
5. 기존 `mean(values, na.rm=...)`.

각 단계 결과를 변수에 먼저 대입한 뒤 다음 단계에 전달했다. 따라서 R의 지연 평가 때문에 평균 단계에 곱셈·지수·복원 비용이 함께 잡히는 것을 피했다. 수식, 값의 순서, 결측 처리 및 평균 구현은 유지했다. 코드는 AST의 대상 본문 한 곳만 교체하며 NULL 인자를 삭제하지 않는다.

새 프로세스 세 개를 순차 실행했다. 각 자료 조건에서 원래 계산, 계측 함수의 준비 실행, Rprof 0.01초 간격의 계측 실행을 수행했다. 다른 R 작업을 동시에 실행하지 않았다.

## 2,000건 결과

| 단계 | 3회 누적 표본 시간(초) | 전체 프로파일 표본 중 비율 |
| --- | --- | --- |
| 곱셈 | 0.18 / 0.28 / 0.29 | 5.42 / 8.31 / 8.61% |
| 지수함수 | 0.97 / 0.98 / 0.91 | 29.22 / 29.08 / 27.00% |
| 관측치 순서 복원 | 0.35 / 0.27 / 0.34 | 10.54 / 8.01 / 10.09% |
| 결측 검사 | 0.03 / 0.03 / 0.03 | 0.90 / 0.89 / 0.89% |
| 평균 | 0.48 / 0.45 / 0.42 | 14.46 / 13.35 / 12.46% |

비율은 단계 다섯 개만을 분모로 한 것이 아니라 전체 계측 실행의 표본을 분모로 한다. 함수 분리의 호출 비용과 계측 영향이 포함되어 있다. 표본 시간은 실제 경과 시간이나 변경으로 절감할 수 있는 시간이 아니며, 앞선 비계측 6.24초에 곱해서 정확한 단계별 시간을 환산하면 안 된다.

600건의 표본 시간 중앙값은 곱셈 0.01초, 지수 0.04초, 복원 0.02초, 결측 검사 0.01초, 평균 0.05초였다. 표본이 적고 첫 실행의 변동도 커서 정밀한 우선순위 판단에는 2,000건 결과를 사용했다. 일부 단계의 표본 시간 0은 표본에 잡히지 않았다는 뜻이며 작업 비용이 없다는 뜻이 아니다.

## 판단

이전 `FUN` 자체 표본 전체를 지수함수 비용으로 해석할 수 없음을 확인했다. 지수 계산은 여전히 중요한 대상이지만 중복 위험도에 대한 재사용은 이미 적용되어 있다. 결측 검사를 무조건 생략하거나 평균을 가중합으로 바꾸는 방식은 선택하지 않았다. 전자는 측정상 이점이 작고, 후자는 합산 순서를 바꿔 정확한 수치 동일성을 깨뜨릴 수 있다.

후속 실험은 원래 관측치 순서와 개별 연산을 유지하면서 여러 시점의 벡터 처리를 제한된 크기로 묶는 방식이다. 다만 큰 중간 행렬의 할당이 이득을 상쇄할 수 있으므로 전체 실행 시간과 메모리 비용을 함께 검증해야 한다. 이번 측정은 해당 방식의 효과를 입증한 것이 아니다.
