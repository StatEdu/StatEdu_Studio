# Spearman 순위 캐시 운영 연결 — 2026-09-14

## 적용

`R/analysis_correlation.R`에 `correlation_rank_test()`를 추가하고 일반 상관분석 호출마다 독립적인 캐시를 만든다. 실제 Spearman 검정이 처음 필요할 때만 R의 기존 `cor.test.default` 복사본에 캐시 rank 함수를 연결한다. Pearson 등에는 원래 검정을 사용하고, 잠재 상관 경로에는 이번 캐시를 연결하지 않는다. 기존 자동 방법 선택에서 Spearman이 선택되는 경우도 지원한다.

입력이 속성 없는 integer/double 벡터이고 rank의 기본 인자를 사용하는 경우에만 순위를 캐시한다. 벡터가 `identical(..., num.eq=FALSE)`일 때 재사용하고 캐시 미적중 시 기존 `base::rank()`를 실행한다. 동률의 평균 순위, 검정 통계량, p값 및 기존 신뢰구간 계산은 바꾸지 않는다. stats 패키지 네임스페이스도 수정하지 않는다.

캐시 상한은 선택 변수 수이며 최근에 사용하지 않은 항목부터 제거한다. 분석 호출 간 캐시를 공유하지 않고 결과 객체에도 캐시를 넣지 않는다. 함수 복사본의 생성도 지연한다. 쌍별 결측으로 벡터가 달라지면 동일성이 확인되지 않은 순위를 사용하지 않는다.

## 실제 경로의 시간

1만 행·20변수·190쌍, 시드 33의 정규 합성 자료, `continuous_method='spearman'`, `normality=TRUE` 조건이다. 동률은 소수점 한 자리 반올림, 결측은 변수별 무작위 10%다. 새 프로세스에서 변경 전후 3쌍을 실행하고 두 번째 묶음은 순서를 뒤집었다. 각 프로세스의 조건 순서는 완전→동률→결측이다.

bootstrap·소스 스냅샷 로딩·입력 생성·gc·저장은 제외하고, 실제 `prepare_correlation_results`와 진단/표준출력 수집을 측정했다. 이전 실험 후보와 달리 실제 분석 함수 내부에서 캐시를 만든다. 다른 R 검증과 메모리 측정은 타이밍과 분리했다.

| 조건 | 변경 전 3회(초) | 변경 후 3회(초) | 중앙값 전→후 |
|---|---|---|---|
| 완전 자료 | 0.55 / 0.55 / 0.54 | 0.33 / 0.31 / 0.33 | 0.55→0.33 |
| 동률 자료 | 0.54 / 0.55 / 0.56 | 0.25 / 0.25 / 0.25 | 0.55→0.25 |
| 변수별 결측 10% | 0.41 / 0.42 / 0.42 | 0.41 / 0.41 / 0.41 | 0.42→0.41 |

완전 자료는 약 40%, 동률 자료는 약 54.5% 단축됐다. 서로 다른 결측 패턴에서는 의미 있는 개선을 확인하지 못했다. 전체 앱 로딩·화면·저장 시간의 개선율은 아니다.

## 메모리 비용

별도의 새 프로세스에서 10만 행·20변수의 완전 자료를 변경 전후 각각 3회 분석했다. 실제 R PID를 약 20ms마다 관측해 `PeakWorkingSet64`를 수집했다. 두 번째 묶음은 실행 순서를 뒤집었다.

| 묶음 | 변경 전(바이트) | 변경 후(바이트) |
|---|---:|---:|
| 1 | 309,731,328 | 326,479,872 |
| 2 | 309,395,456 | 353,083,392 |
| 3 | 309,534,720 | 328,925,184 |
| 중앙값 | 309,534,720 | 328,925,184 |

중앙값은 약 19.39MB(6.26%) 증가했다. 최댓값은 변경 후 약 353.08MB였다. 속도 개선에 순위와 입력 벡터 참조를 유지하는 비용이 따른다. 항목 수 제한이 바이트 단위 제한을 뜻하지는 않는다. 작업 집합은 bootstrap·입력·분석·저장을 포함하며 총 할당량/최대 커밋 메모리가 아니다. 종료 직전 표본을 놓칠 수 있다.

## 동일성 검증

- 240행·6변수 일반/동률/결측/혼합 측정 수준/상수/전체 결측 × Pearson/Spearman/Kendall/자동 24조건, 잠재 상관 2조건: 전체 결과·진단·표준출력·난수 상태 26조건 동일.
- 지연 생성, 캐시 항목 상한, 새 분석 캐시의 독립성을 확인했다.
- 영구 스크립트 `scripts/validate_spearman_rank_cache.R` 추가: 33조건에서 반복 호출 2회씩 원본 `stats::cor.test`의 전체 htest 반환값·오류/경고/메시지·표준출력·난수 상태와 동일했다. 결측·동률·비유한값·상수·완전 증가/감소·빈 입력·이름/클래스 속성 및 캐시 교체를 포함한다.
- 시간 측정 9쌍과 10만 행 메모리 측정 3쌍의 전체 결과도 동일했다.

모두 `identical(..., num.eq=FALSE)`로 비교했고 허용오차나 환경 정규화를 사용하지 않았다. 직접 검증 스크립트를 실험 후보에서 운영 함수용으로 옮길 때 남은 계수 조회 인터페이스를 수정한 뒤 운영 함수로 재실행했다.
