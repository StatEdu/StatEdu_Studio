# Fine–Gray 네이티브 캐시 후보 빌드·검증 — 2026-09-14

## 결과

설치된 cmprsk 2.2-12와 동일 버전의 원본 Fortran 및 별도 캐시 후보 DLL을 빌드했다. 2,000행·10공변량 직접 `crr()` 적합에서 설치 버전 중앙값 1.58초가 후보 0.60초로 약 62.0% 감소했다. 운영 패키지와 앱 코드는 교체하지 않았다.

## 빌드와 후보 범위

[공식 Rtools45 기본 도구 묶음](https://cran.r-project.org/bin/windows/Rtools/rtools45/files/)을 작업 폴더에 압축 해제했다. 시스템 설치는 하지 않았다. GCC/GFortran 14.3.0을 사용했고 두 DLL 모두 `-shared -O2 -mfpmath=sse -msse2 -mstackrealign -static-libgcc -static-libgfortran`으로 빌드했다. 압축 해제 중 터미널 정의 파일의 이름/링크 오류가 있었으나 사용한 컴파일러·어셈블러·링커는 정상 동작했다. 전체 Rtools 설치를 검증한 것은 아니다.

원본의 `crrvv`는 유지하고 후보 진입점 `crrvvc`를 추가했다. 시간불변 공변량일 때 원래 `covt` 순서로 각 행의 지수값을 한 번 계산한다. 반복문에서는 해당 값을 읽고, 수정될 수 있는 `xbt`는 매번 원래 공변량에서 복사한다. 검열 가중치·합산·분산 계산 순서는 유지한다. `ncov2 != 0`인 시간가변 공변량은 원래 `crrvv`로 넘긴다.

실험용 `crr` 함수 복사본에서 분산 루틴 호출만 해당 DLL의 명시적 네이티브 주소로 연결했다. 다른 적합 루틴은 설치 패키지를 사용한다. 패키지 네임스페이스나 등록 테이블을 수정하지 않았다.

## 정확성 검증

- 100행, 1/3/10공변량 × 일반·동률·여러 검열 집단·이진 변수·중복열·거의 중복열·시간가변 공변량: 21조건.
- 5개 시드 × 일반·동률·검열 집단·이진 조건에서 생성한 자료·시간가변·1e-50 배율·1e50 배율·결측: 40조건. 이 추가 검사는 원래 자료에 잡음을 더하므로 이진 조건도 최종 입력은 연속값이다. 이 중 5건은 미수렴 결과였으며 그 상태까지 동일했다.

각 조건에서 설치 버전, 재빌드 원본, 후보를 비교했다. 전체 반환값·오류/경고/메시지·표준출력·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 수치 허용오차나 환경 참조 정규화는 사용하지 않았다. 중복열 등에서 오류가 반환되는 조건도 포함하므로 61건 모두 성공적으로 적합됐다는 의미는 아니다.

## 실행 시간

정규 합성 자료, 시드 44, 10공변량, 사건 코드 0/1/2, `gtol=1e-6`, `maxiter=10`을 사용했다. 각 버전을 새 프로세스에서 3회 실행했고 두 번째 묶음은 후보→재빌드 원본→설치 버전 순서로 뒤집었다. 각 프로세스는 500행 다음 2,000행 순서로 실행했다. 입력 생성·저장·별도 비교는 제외하고 동일한 결과/진단 수집 래퍼를 포함했다. 표준출력 추가 검사는 타이밍과 분리해 수행했다.

| 행 수 | 설치 버전 3회(초) | 재빌드 원본 3회(초) | 후보 3회(초) |
|---|---|---|---|
| 500 | 0.05 / 0.05 / 0.05 | 0.05 / 0.05 / 0.05 | 0.03 / 0.03 / 0.03 |
| 2,000 | 1.58 / 1.59 / 1.58 | 1.62 / 1.64 / 1.64 | 0.59 / 0.60 / 0.60 |

2,000행 중앙값은 설치 1.58초, 재빌드 원본 1.64초, 후보 0.60초다. 동일 도구로 빌드한 원본 대비 약 63.4% 감소했다. 작은 자료의 짧은 시간은 측정 해상도를 고려해야 한다. 측정 결과의 설치 버전 대비 재빌드 원본/후보 12쌍도 전체 결과·진단·난수 상태가 일치했다.

이는 직접 `crr()` 적합의 측정이며 전체 앱 분석·로딩·저장 시간의 개선율이 아니다. 최대 메모리 사용량은 측정하지 않았다.

## 아직 남은 사항

운영 앱 연결, 전체 경쟁위험 분석·화면·저장 비교, 패키징 및 새 머신의 DLL 의존성 검증은 아직 수행하지 않았다. 컴파일러·플랫폼·극단 입력 전반의 동일성을 보장하지 않는다. 따라서 현재 후보는 실험 폴더에만 있으며 설치 DLL은 유지한다. 설치 파일도 재빌드하지 않았다.
