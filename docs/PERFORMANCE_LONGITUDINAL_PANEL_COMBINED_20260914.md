# 패널 분석 재사용 개선 통합 검증

## 범위

선택 모형, Hausman 검정, HC1 표준오차 재사용을 모두 적용한 현재 소스를 세 개선 이전의 소스와 비교했다. 이번 작업은 통합 검증과 잔여 병목 측정이며 제품 코드는 추가로 변경하지 않았다.

참조는 `output/longitudinal-panel-reuse-20260914/baseline.R`이고 현재 소스 스냅샷 SHA256은 `1A57B5CB6E504ED5A8A1392FF0B1C86485A1107D4357BCF50598302CBBCA45B8`이다. 실행 후 제품 파일과 스냅샷 해시 일치를 확인했다.

## 전체 실행 비교

번들 R 4.5.3, seed 939, 2,000명 × 6시점(12,000행), 두 공변량, 비가중 연속 반응, 기본 가정 검사와 민감도 분석을 사용했다. 독립 프로세스 3개를 순차 실행했다. 워밍업 후 측정하며 두 번째 프로세스는 현재 소스를 먼저 실행했다. 로딩을 제외하고 결과 캡처와 비교용 정규화를 포함한 시간이다.

| 모형 | 개선 전 1 / 2 / 3 (초) | 현재 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| FE | 3.69 / 3.67 / 3.75 | 2.70 / 2.83 / 2.72 | 3.69 → 2.72초, 약 26% 감소 |
| RE | 3.47 / 3.54 / 3.65 | 2.31 / 2.50 / 2.43 | 3.54 → 2.43초, 약 31% 감소 |

두 모형 모두 세 번 빨라졌다. 개별 개선의 과거 감소율을 합산하지 않고 같은 프로세스에서 개선 전 전체 소스와 직접 비교했다. 이 자료와 환경의 결과이며 일반적인 개선율 보장은 아니다.

워밍업과 측정 각각에서 전체 반환 객체, 조건 클래스·본문·순서, 표준 출력 및 RNG 상태를 `identical(..., num.eq = FALSE)`로 비교해 모두 통과했다. 측정 비교는 6건, 워밍업 비교도 6건이며 서로 다른 자료 12종을 검사한 것은 아니다. formula/terms 환경과 함수 표현을 정규화했고 원시 환경 객체 동일성은 주장하지 않는다. 오류나 생략 결과가 아닌 실제 모형 반환도 확인했다. 이번 정상 자료에서는 조건이 없었다. 진단 주입과 원시 HC1/DK 값 검증은 앞선 개별 검증 보고서에 있다.

## 현재 병목

별도 프로세스에서 현재 FE/RE를 각각 워밍업한 후 20ms 간격의 Rprof를 실행했다. 프로파일 실행 전후 정규화 결과·조건·출력·RNG도 일치했다.

| 호출 경로 | FE 표본 비중 | RE 표본 비중 |
|---|---|---|
| 민감도 분석 전체 | 55.10% | 56.96% |
| DK 요약(민감도 분석에 포함) | 26.53% | 32.91% |
| 개체 간 잔차 의존성 검사 | 22.45% | 18.99% |

이는 하위 호출을 포함하는 표본 비중이며 겹치는 행을 더하면 안 된다. 프로파일 표본 시간은 실제 경과 시간과 다르므로 위 전체 실행 시간의 구간별 초로 환산하지 않았다. 초기 5ms 탐색은 Windows 타이머 해상도의 영향을 고려해 최종 20ms 측정으로 대체했다. 단일 프로파일은 후보 선정용이며 성능 개선 입증용이 아니다.

다음 검토 후보는 `plm::vcovSCC` 내부의 반복 모형행렬 변환과 `plm::pcdtest`의 잔차 상관 계산이다. 현재 자료에서는 해당 경로가 남은 비용의 상당 부분을 차지한다. 서로 다른 FE/RE 모형의 공분산을 공유하거나 상관 계산 순서를 바꾸는 것은 이번 측정만으로 정당화할 수 없으므로 적용하지 않았다.

## 증거와 제한

`output/longitudinal-panel-combined-20260914/`에 baseline.R, candidate.R, normalize.R, bench.R, timing-1/2/3.csv, run-1/2/3.log, profile.R, profile.log, 모형별 Rprof 및 total/self CSV를 보관했다.

출력과 제품 코드 변경이 없어 전체 형식 변환 및 설치 파일 빌드는 수행하지 않았다. 기존 종합 longitudinal 검증의 Excel 셀 위치 실패는 이번에 해결하거나 재실행하지 않았다. 이전 개별 회귀 검증의 결과를 이번에 새로 실행한 것처럼 집계하지 않는다.
