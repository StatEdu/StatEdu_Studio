# 회귀분석 그리스 문자 표시

회귀계수 표의 표시 제목 `beta`를 `β`, 선형/위계적 회귀의 변화량 표시 `Delta R²`를 `Δ R²`로 변경했다. 내부 열 이름 `beta`와 추정 계산식은 유지한다. 공통 회귀계수 헤더와 위계적 가로형 헤더에 같은 기호를 사용한다.

`validate_regression_greek_symbols.R`: 일반형·가로형 화면과 저장 HTML의 전체 셀 일치, 렌더링 전후 분석 결과 일치(허용오차 0, 환경 참조 제외), 현재·누적 HTML/Word/HWPX/Excel의 β·Δ 표시를 확인했다. 최초 직렬화 비교는 렌더링 환경 변화까지 비교해 실패했으므로 최종 검사 범위를 명시한다. 내부 수치 변경은 없다.

현재·누적 PDF도 생성 후 `validate_regression_greek_pdf.py`로 기호 추출을 확인했다. 일반형 및 가로형 PDF 페이지를 렌더링하여 헤더 β와 변화량 행 Δ R²가 잘리지 않고 표시되는지 시각 확인했다. 원시 산출물: `output/regression-greek-20260915/`.

앞선 1.3.0 설치는 종료 코드 0으로 완료됐으며 설치된 app.asar가 당시 패키지와 일치했다. 이번 표시 수정은 그 이후의 소스 변경이다. 이번 수정이 포함된 설치 파일은 아직 재빌드/설치하지 않았다. 이미 저장된 결과 스냅샷도 자동으로 다시 작성하지 않는다.
