# CIF 무결성 점검 보조표

제목과 7개 검사 열의 번역을 보완했다. 유한성·범위·원인별 합·종합 통과 여부는
UI 언어의 예/아니요로 표시한다. 영어 보조표도 TRUE/FALSE 대신 Yes/No를 사용한다.
집단명 및 수치는 보존하며 실제 결과 패널에서 UI 언어를 전달한다.

## 검증

- `validate_cif_integrity_i18n.R`: 실제 경쟁위험 결과와 곡선의 CIF를 변경하여 만든
  합계 초과/음수 범위 위반 두 검사 자료를 실제 무결성 함수에 전달했다.
  변형 자료는 실패 표시 검사용이며 새로 적합한 결과가 아니다.
- 3가지 검사 × 8개 언어에서 판정 표시, 수치·사용자 집단명 보존 및 영어 CIF 본 표 유지 통과.
- 기존 사건 수 보조표 다국어 검사 통과.
- 일본어 현재 3개 / 누적 4개 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 무결성 실패의 별도 안정성 안내와 기타 경쟁위험 진단은
추가 점검 대상이다.
