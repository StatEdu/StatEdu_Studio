# GLMM 민감도 비교 실제 실행 — 2026-09-17

이항·Poisson·음이항·감마 분포마다 확률절편/기울기의 선택 상태를 바꾸며 실제 민감도 비교 함수를 실행했다. 4분포 × 선택 상태 2개 × 8언어, 총 64개 표시 검사가 통과했다. 각 실행은 두 모형을 적합하며 비교행 2개와 선택된 행 하나가 예상한 모형인지 확인한다.

분석 유형·비교명·적합 상태·설명 번역, AIC/BIC 문자열과 원본 표 보존을 확인했다. 이번 범위에서 새 번역 누락은 발견되지 않아 제품 코드와 번역 사전을 추가 수정하지 않았다. 검증 스크립트는 `scripts/validate_longitudinal_glmm_sensitivity_i18n.R`, 결과는 `tmp/longitudinal-glmm-sensitivity/tables.rds`다.

실제 적합에서 기울기 기준을 넘는 수렴 경고와 큰 고유값에 따른 식별성 경고가 발생했다. 검사 통과는 반환된 결과의 표시·보존을 확인한 것이며 적합의 통계적 타당성이나 수렴 보장이 아니다.

검증만 추가했으므로 이번에는 전체 결과 패널·5종 저장 검사를 재실행하지 않았다. 본 표·실제 브라우저·페이지별 시각 검토 및 다른 자료/옵션 조합을 전부 확인한 것은 아니다. 메타분석과 설치본은 변경하지 않았다.
