# 완전 사례 분석의 대체 모형 권고 번역

## 변경

혼합 반복측정의 완전 사례 분석에서 정규성 문제가 표시될 때 생성되는 다음 세 권고를 8개 언어 사전과 한국어 전용 변환에 반영했다.

- 주 분석 또는 민감도 분석으로 순서형 혼합모형 검토.
- 주 분석 또는 민감도 분석으로 계수형 GLMM 검토.
- 주 분석 또는 민감도 분석으로 Gamma GLMM 검토.

모형 선택 기준과 통계 계산은 변경하지 않았다.

## 검증

`validate_mixed_rm_alternative_guidance_i18n.R`는 순서형·계수형·양수 우측 편향 자료 각각 40명·2집단·3시점에 대해 실제 완전 사례 혼합 반복측정 분석을 수행한다. 정규성 문제가 표시되고 해당 대체 모형 권고가 실제 생성되는지 확인한다. 이번 검증에서 권고된 대체 모형을 추가 적합하지는 않았다.

- 보완 전 한국어 및 6개 외국어에서 3개 권고의 번역 누락 재현.
- 보완 후 3개 실제 결과 × 8개 언어의 권고 표 및 패널 표시 검사 통과.
- 영어 본표의 언어 간 동일성, 전체 결과 객체, 안내문과 같은 철자의 사용자 변수명 및 집단명 보존 확인.
- 공통 16개 부록 변환 함수와 8개 결과 렌더러의 8개 언어 회귀 검사, `validate_i18n_contract.R`, 변경 공백 검사 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 및 PDF 텍스트 보존 검사 통과. 한국어 현재 PDF 9쪽·누적 16쪽, 일본어 현재 9쪽·누적 17쪽이다.
- 저장 검증은 `validate_longitudinal_count_exports.R`와 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이며 본문은 이번 완전 사례 분석 결과 캡처다. 저장 단계에서 분석을 재실행하지 않았다. 산출물: `tmp/mixed-rm-alternative-guidance-i18n/exports`.

기존 매개·조절효과 화면은 제외했다. 프로그램 전체 번역 완료를 의미하지 않는다. 설치본 빌드 및 문서 앱별 수동 시각 검토는 수행하지 않았다.
