# 종단 모형 개요의 변수명 보존·분포명 — 2026-09-17

모형 개요는 결과변수 이름을 열 제목으로 사용한다. 이름이 `Warning`처럼 번역 사전에 있는 단어이면 열 제목·변수 셀도 번역되고, `Outcome`처럼 공통 보호 열 이름이면 분포 안내까지 원문으로 남을 수 있었다.

모형 개요 생성 시 사용자 열 제목과 결과변수·ID·시점·노출/오프셋·가중치·모형식 셀을 명시적으로 보호했다. 앱이 작성하는 행은 별도로 표시하여 공통 열 보호와 충돌해도 분포 표시를 번역한다. 계산과 원본 분석 결과는 변경하지 않는다. 정규·이항·감마 분포 식별자의 표시 번역도 8언어 사전에 연결했다.

`validate_longitudinal_overview_i18n.R`에서 Warning, Outcome, Value, 한국어 사용자 이름의 4사례 × 8언어 32개 검사를 수행한다. 각 표에는 동일 결과변수 이름의 열 두 개를 넣어 중복 열 이름도 확인한다. 사용자 셀·모형식·숫자 문자열·원본 표 보존과 분포명 번역을 검증했다. 이 검사는 합성 결과 객체를 사용하며 전체 실제 모형 적합 검증은 아니다.

실제 GEE/LMM/패널 고정효과의 기존 `validate_longitudinal_structural_i18n.R` 검사도 회귀 검증 대상으로 실행한다. 저장 검증에는 `tmp/longitudinal-overview/tables.rds`를 사용하며 저장할 때 분석을 다시 실행하지 않는다. 한국어/일본어 현재·누적 HTML·PDF·Word·직접 생성 HWPX·Excel 출력 경로는 `tmp/longitudinal-overview-exports`다.

다른 분포 식별자, 모든 모형·옵션 조합 및 브라우저·페이지별 시각 검토는 남아 있다. 메타분석과 설치본은 변경하지 않았다.

위 32개 검사와 실제 GEE/LMM/패널 고정효과의 8언어 기존 검사가 모두 통과했다. 본 표 영어 유지·진단 번역·원래 라벨 보존을 확인했다. 합성 LMM의 특이 적합 경고는 유지된다. 현재·누적 5종 저장 검사와 PDF 4개의 캡처 문구 검사도 통과했으며, 두 언어 모두 현재 4쪽/누적 7쪽이다. 변경 파일의 `git diff --check`도 통과했다.
