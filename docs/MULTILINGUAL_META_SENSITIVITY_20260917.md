# 메타분석 민감도·연구별 보조표 — 2026-09-17

연구 내 상관 민감도, 논문 단위 순차 제외, Trim-and-fill, 연구별 효과크기 보조표의 제목과 열 이름을 8개 언어로 연결했다. Trim-and-fill의 왼쪽/오른쪽도 UI 언어를 따른다. 연구 ID·연구명·사용자 변수 문자열은 원문을 유지하도록 사용자 데이터 열을 명시했다. 효과크기 기호와 통계값, 분석 계산은 그대로 유지한다.

약어 설명 10종을 번역 테이블에 연결했다. 이 네 표는 번역 전 열 이름을 별도로 보관하여 번역된 열 이름 때문에 CI·τ² 등의 설명이 사라지지 않게 했다. 본표는 기존대로 영어로 렌더링한다.

검사: `validate_meta_sensitivity_i18n.R`은 실제 적합 결과로 8개 언어 및 한국어 복귀, 제목용 번역 키와 열 이름, 양방향 누락 방향, 수치 보존, Normality/Status/Yes/한글 특수문자 사용자 값 보존, CI·τ² 설명을 확인한다. 제목은 공통 출력 통합 검사에서 렌더링 및 저장한다. `validate_meta_warning_exports_i18n.R`에 실제 민감도·순차 제외·Trim-and-fill 결과를 추가하여 한국어/일본어 현재·누적 HTML/PDF/Word/HWPX/Excel 내용 보존을 검사한다. PDF 텍스트와 문서 그림은 `validate_meta_warning_pdf.py`로 확인한다.

실제 브라우저 조작과 페이지별 시각 검토는 수행하지 않았다. 설치본을 만들지 않았다. 이 범위의 완료가 앱 전체 다국어 점검 완료를 의미하지 않는다.

위 자동 검사와 카탈로그·공통 표 주석 회귀 검사는 모두 통과했다. PDF는 한국어/일본어 각각 현재 15쪽·누적 29쪽이다. 산출물은 `tmp/meta-warning-i18n`에 있다.
