# GEE·반복측정 LMM 오류 안내 — 2026-09-17

실행 실패 알림의 GEE 작업상관 모수/행렬, 보정 비구조적 GEE 가중치, 비구조적 GEE 시점 중복/결측, 수렴 실패, 계수 분산 오류 6종과 반복측정 LMM 설계행렬·대상자/시점·결과 변동·시점 수 오류 4종을 8개 언어로 연결했다. 정확히 일치하는 앱 오류만 번역한다. 계산 함수 및 본표·보조표 출력은 변경하지 않았다.

`validate_longitudinal_model_errors_i18n.R`에서 GEE 조건 오류 4종은 실제 함수로 발생시켰다. 수렴/계수분산 2종은 시험용 함수 복제 환경에서 적합기 반환값만 모의 처리했다. LMM 4종은 의존 패키지 검사만 통과시키고 실제 자료 검증 분기를 실행했다. 실제 LMM 적합을 수행한 검사는 아니다.

8개 언어 및 한국어 복귀에서 번역, 실제 실패 콜백의 결과 초기화·알림 유형·표시 시간, 알 수 없는 외부 상세 원문 보존을 검증했다. 앞서 번역한 입력 오류 7종 회귀 검사 및 정상 GEE 상관 검사도 통과했다. 브라우저에서 직접 알림을 표시한 검증은 포함하지 않는다.

최소 고유값·반복 횟수 등을 포함한 동적 오류, 별도 R 프로세스 실패 상세, 다른 고급 모형 오류는 남은 점검 대상이다. 메타분석은 제외하며 설치본은 만들지 않았다.
