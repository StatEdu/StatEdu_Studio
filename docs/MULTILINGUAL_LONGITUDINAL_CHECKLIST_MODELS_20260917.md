# 종단 보고 점검표의 실행 상태·복합 권고 — 2026-09-17

실제 GEE의 가정 검사 미선택 경로와 가정 검사/IPW 민감도 실행 경로, 가중치 요약이 없는 빈 결과 경로를 비교했다. 여러 민감도 권고를 합친 문장이 그대로 영어로 남는 문제와 GEE 작업상관 비교·가중치 요약 미생성 안내의 번역 누락을 확인했다.

점검표에 원래 권고 문장 목록을 메타데이터로 보관하고 표시할 때 각각 번역한 뒤 연결한다. 원본 설명이 목록을 연결한 문장과 일치할 때만 적용한다. 임의 마침표 분할을 하지 않으며 기존 저장 스냅샷을 다시 쓰지 않는다. 작업상관 구조 비교와 가중치 요약 미생성 문구 두 개도 8언어로 연결했다.

`validate_longitudinal_checklist_models_i18n.R`는 3경로 × 8언어의 24개 점검표에서 항목·상태·설명, 권고 문장 각각의 번역, 연결 결과의 정확한 일치, 소프트웨어명/버전 및 원본 결과 보존을 검사한다. GEE 두 경로는 실제 적합이며 빈 결과는 점검표 생성 함수를 직접 호출한다. 모든 모형/권고 조합을 망라한 것은 아니다.

이 표들을 기존 `validate_longitudinal_error_exports.R`에 포함해 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel 저장을 검사한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 별도 확인한다. 산출물: `tmp/longitudinal-error-exports`.

추정 계산식·메타분석·설치본은 변경하지 않았다. 전체 브라우저·모형 조합·페이지별 시각 검토는 별도 남은 범위다.

위 검사와 기존 MI/IPW·가중치·사용자 이름 검사, 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 모든 캡처 텍스트도 통과했다. 한국어 현재 24쪽/누적 47쪽, 일본어 현재 25쪽/누적 48쪽이다. 변경 파일의 `git diff --check`도 통과했다.
