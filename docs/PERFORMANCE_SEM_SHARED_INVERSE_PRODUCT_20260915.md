# SEM 역행렬 공유 제품 통합

2026-09-15. 앞서 5,000회 후보 검증을 통과한 동일 기울기 내부 역행렬 공유를 제품 부트스트랩 경로에 통합했다.

## 변경

`R/setup_custom_model_canvas_structural_bootstrap.R`에 작업 적용 조건, 자기 완결적인 함수 사본 생성기, 작업자 설치/복구 함수를 추가했다. 외부 연구 스크립트를 읽지 않는다. isolated 작업의 fixed-index 경로가 실제 활성화된 경우에만 설치한다. 완전 수치자료, 200회 이상, 병렬 작업자 2개 이상, 단일 제품 명세의 전체 조합/짝별 DMC, 단일 그룹·단일 수준 ML/LISREL, std.lv=FALSE 등 앞선 조건을 유지한다.

번들 lavaan 0.7.2의 7개 함수 지문·환경을 확인하고, 각 기울기 호출의 지원 조건도 다시 검사한다. 작업자마다 한 번 함수 사본을 준비하고 같은 기울기 안에서 완전히 동일한 mlist에 대한 역행렬만 공유한다. 추정 옵션·표본 생성·계수 연산 순서를 바꾸지 않는다.

연구 후보의 블록별 설치/복구 대신 제품 작업자 수명 동안 설치하고 기존 worker cleanup에서 원래 바인딩·잠금 상태를 복구한다. 준비/컴파일 실패나 호환성 불일치는 원래 함수를 유지한다. 작업 취소의 기존 프로세스 트리 종료 경로를 유지한다. 내부 비교 옵션 `statedu.internal.disable_sem_shared_inverse`를 callr 작업에 전달한다. 설치 상태는 기존 timings 속성 안에만 기록한다.

## 검증

- 제품 생성기 기준 기존 호환성/진단/복구 28개, 작업 적용 조건 30개 통과.
- 직접 설치 후 정상/오류/재설치의 바인딩·잠금 복구, 호환성 거절/생성 오류/컴파일 오류의 미설치, 잠금 해제 상태 보존 및 중복 정리 통과.
- 변경 전 소스를 보관한 기준 엔진과 제품 엔진을 정상·반복·블록 실패·개별 적합 실패·취소·진행 콜백 오류·24회 짧은 작업에서 비교했다. 정상 및 실패 주입 작업은 200회, 작업자 4, 청크 100이다.
- 7개 경로 모두 timings만 제외한 전체 반환 결과·표본 인덱스·유효 마스크·원/표준화계수·부모 진단/stdout/RNG를 `identical(..., num.eq=FALSE)`로 비교해 일치했다. 오류 경로는 오류 클래스/메시지와 동일한 부모 상태를 비교했다.
- 실제 PSOCK 작업자 56개의 정리 후 원본 함수 지문·잠금·상태 제거 확인. 이 중 24개가 최적화를 설치한 작업자였으며 모두 복구됐다. 짧은 작업은 설치하지 않았다.
- 실제 앱 callr 작업에서 전체 조합/짝별 DMC 각 200회의 비활성/활성 결과와 부모 RNG가 정확히 일치하고 작업자 4개 설치를 확인했다. 이 경로는 개별 draw 배열을 반환하지 않으므로 표본별 비교는 위 prepared 엔진 검증에 해당한다.
- 실제 5,000회 작업을 재표집 진행 후 취소해 부모와 관측된 자식 프로세스 5개가 모두 종료됐음을 확인했다. 이어서 200회 작업을 새로 실행했고 취소 전 정상 작업과 결과/부모 RNG가 정확히 일치했다. 강제 종료에서는 namespace 복구 대신 격리 프로세스 자체가 제거된다.
