# 상관분석 대표 경로 다국어 보완

## 변경

정규성 표의 왜도·첨도, 제외 변수 제목/유효 N/고유값 수/두 제외 사유, 신뢰구간·p값 설명, Pearson·Spearman 약어 설명 등 10개 문구를 8개 언어 사전에 등록했다. 상관 방법 약어 설명이 한국어 외 언어에서도 사전 번역을 사용하도록 연결했다. 본표와 통계 계산은 변경하지 않았다.

## 검증

- `scripts/validate_correlation_i18n.R`: 실제 90행 자료에서 Pearson·Spearman 자동 선택과 상수/유효값 부족 변수 제외를 재현했다. 8개 언어의 본표 셀·제목·주석 영어 동일성, 보조표 4개 언어 및 10개 번역 문구, 행렬 축의 사용자 라벨 `Normality`, `Yes`, `사용자 결과` 보존 검사 통과.
- `validate_correlation_auto.R`: 자동 방법 선택 및 잠재반응 상관 추론의 기존 계산 검사 통과.
- `validate_correlation_method_labels.R`: 기존 방법/선정 근거 192개 비교 통과.
- `validate_i18n_contract.R`: 통과.
- 일본어 실제 결과 `tmp/correlation-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교 및 PDF 생성 통과. 실제 PDF 텍스트 검사도 두 경로 모두 통과. 로그: `tmp/correlation-i18n-exports.log`.

## 남은 범위

기타 상관 방법의 다국어 약어 설명, 잠재상관 제목·상세 주석, 도표, 옵션·오류 및 브라우저 언어 왕복은 추가 확인 대상이다. 기존 잠재상관 계산 검사 통과를 잠재상관 다국어 완료로 해석하지 않는다. 대표 결과 근거는 14개 화면, 전용 결과 검증 공백은 16개 화면으로 갱신했다. 전체 완료 판정은 하지 않았고 설치본은 만들지 않았다.
