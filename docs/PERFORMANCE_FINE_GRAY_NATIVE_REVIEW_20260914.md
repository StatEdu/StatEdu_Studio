# Fine–Gray 네이티브 분산 계산 검토 — 2026-09-14

## 발견한 후보

설치된 패키지와 같은 버전인 cmprsk 2.2-12의 [공식 CRAN 소스](https://cran.r-project.org/src/contrib/cmprsk_2.2-12.tar.gz)를 확보했다. `src/crr.f`의 `crrvv`는 중첩 반복문에서 `covt`와 `exp(wk)`를 반복 평가한다. 현재 앱은 `cov1`만 전달하므로 시간가변 공변량 수 `ncov2`는 0이다. 이 조건에서는 한 번의 분산 계산 동안 각 행의 선형예측값과 그 지수값이 변하지 않는다.

행별 지수값을 동일한 순차 합산으로 계산해 재사용하는 후보를 찾았다. 검열 가중치의 곱셈·나눗셈 순서, 위험집단의 순서, 합산 순서와 분산 공식을 바꾸지 않는 것이 조건이다. 시간가변 공변량에는 이 단순 캐시를 적용하면 안 된다. `xbt`는 일부 경로에서 중심화되어 수정되므로 작업 벡터를 그대로 공유하는 구현도 피해야 한다.

## 확인한 것과 미확인 사항

R에서 원래 순서대로 곱하고 더하는 모형 코드를 작성해, 반복 계산과 캐시 조회 4,349건의 숫자가 `identical(..., num.eq=FALSE)`로 일치함을 확인했다. 네이티브 코드처럼 숫자만 처리하도록 계수 이름을 제거했다. 이 자료에서는 행렬 곱 결과도 동일했지만 다른 입력이나 BLAS까지 보장하지 않으므로 행렬 곱 대체를 제안하지 않는다.

이 검사는 실제 Fortran `crrvv` 수정본과 설치 DLL의 동등성 검사가 아니다. 현재 PATH와 일반 Rtools/MSYS 설치 위치에서 사용 가능한 Fortran 컴파일러를 확인하지 못했다. 네이티브 후보를 컴파일하거나 속도를 측정하지 않았고, 패키지 DLL과 운영 코드를 변경하지 않았다.

적용 전에는 원본 소스를 동일 도구로 빌드해 설치 DLL과 먼저 비교하고, 이어 캐시 후보를 같은 옵션으로 빌드해 분산·계수·잔차·진단을 비교해야 한다. 동률, 여러 검열 집단, 시간가변 공변량의 기존 경로, 특이 모형, 극단값/오버플로 등의 조건을 포함해야 한다. 현재 결과만으로 운영 적용이나 예상 단축률을 주장하지 않는다.
