# Wilcoxon 0 차이 제외 건수 안내 번역

## 변경

실제 대응표본·비모수 대응표본 결과의 `1 zero difference(s) were omitted ...` 안내가 비한국어 UI에 영어로 남는 것을 재현했다. 건수를 분리하여 번역 템플릿에 넣고, 뒤에 동률 경고가 이어지는 경우 해당 문장도 번역하도록 보완했다.

8개 언어 사전에 건수 템플릿을 추가했다. 영어 원문 및 기존 한국어 동작은 유지하며, 새 처리는 나머지 6개 언어에 적용한다. 저장·복원 자료의 단수 `difference was`, 복수 `differences were`, 기존 `difference(s) were` 형태를 처리한다. 예상하지 못한 후속 문구는 임의로 재구성하지 않는다.

표에서는 Warning/Reason/Message 열의 해당 안내만 새 처리를 적용한다. 사용자 변수명 열과 다른 메시지의 기존 번역 경로는 유지했다. 분석 계산은 변경하지 않았다.

## 검증

- `validate_paired_zero_count_i18n.R`: 실제 차이 0 사례와 동률이 함께 있는 자료로 대응표본·비모수 대응표본 분석을 실행했다. 두 결과의 전체 경고 문장, 사용자 이름 Review/Normality, 영어 본표 및 원본 객체 보존을 8개 언어로 확인했다.
- 저장 문구 형태 3종 × 동률 경고 유무 2종 × 8개 언어 = 48개 헬퍼 사례에서 1·7·12건의 건수 보존을 확인했다. 7·12건은 문구 변형 검사이며 실제 분석 자료에서 발생시킨 건수는 아니다.
- `validate_paired_guards.R`, `validate_nonparametric_ties_warning_i18n.R`, `validate_i18n_contract.R`: 모두 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검사 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-zero-count-i18n/exports`. 캡처한 결과를 저장하며 저장 과정에서 분석을 재실행하지 않는다.

## 범위

이번 수정은 Wilcoxon의 0 차이 제외 건수와 결합 동률 안내에 한정한다. 대응표본의 다른 동적 안내·분석명 후보는 후속 점검 대상으로 남는다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면은 계속 제외한다.
