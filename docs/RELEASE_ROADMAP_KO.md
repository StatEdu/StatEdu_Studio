# StatEdu Studio 공개 버전 계획

2026-09-11 결정 기준.

## 1.3.0 공개판

- 일반 공개판에 PDF, Word, Excel 분석 결과 저장 기능을 제공한다.
- 세 저장 기능은 Pro 도입과 별개로 제공한다.
- 무료 공개판 PDF 표지의 버전 표시는 `FREE`, StatEdu 로고와 `Prepared with / StatEdu, Institute of Statistics`를 표시한다. 사용자·기관 정보(`Prepared by`, `Prepared for`)는 생략한다.
- 로고, 보고서 제목, 저장 일시, 프로그램 버전은 공통 표지 요소로 유지한다.
- 1.3.0 설치본에서는 PDF·Word·Excel 저장 기능 노출과 권한을 적용한다. 이전 1.2.x 공개판의 제한은 유지한다.
- 메타분석과 동일 대상 내 처치 반복측정 분산분석은 이번 공개 설치본 메뉴에서 제외한다.

## 1.3.1 — 출력 용지와 공통 문서 구조

2026-09-13 사용자 결정. 용지 선택은 **1.3.0 배포 완료 후 1.3.1에서 구현한다.** 2026-09-17 추가 요청으로 공통 문서 구조와 직접 HWPX 저장은 먼저 소스에 구현했다. 설치본 빌드·배포는 별도다.

**착수 우선순위:** 사용자가 “배포 후 1.3.1 구현하자”라고 요청하면 아래 두 작업부터 구현한다. 다른 1.3.1 기능보다 우선하며, 배포만으로 자동 착수하지 않는다.

1. **출력 용지 선택: B5·A4·Letter**
   - 환경 설정에서 선택하고 다음 실행에도 유지한다. 기본값은 기존 B5를 유지한다.
   - 현재 결과와 누적 결과의 표 폭·줄바꿈·페이지 나눔 및 PDF·HTML·Word·HWPX 저장에 같은 규격을 적용한다. Excel 인쇄 용지도 함께 연동·검증한다.
   - 기존 표별 가로·세로 방향 규칙과 결과 내용은 보존한다. 용지 변경을 위해 분석을 다시 실행하지 않는다.
   - 결과 보고서와 모형 캔버스 모두 B5·A4·Letter 세 가지 규격으로 통일하고, 선택 항목에 치수를 함께 표시한다: `B5 (176×250mm)`, `A4 (210×297mm)`, `Letter (215.9×279.4mm)`. 가로·세로 방향은 용지 종류와 별도로 관리한다.
   - 캔버스의 기존 `Large` 선택지는 새 용지 선택에서 제외한다. 기존 저장 모형의 B5(182×257mm)·Large·사용자 배치가 손상되지 않도록 불러오기 호환 정책을 구현 단계에서 마련하고 검증한다. 저장 파일의 치수를 이름만으로 무조건 치환하지 않는다.
2. **Word·HWPX 공통 문서 구조 후 각각 저장**
   - 2026-09-17 구현: `R/result_document_model.R`의 공통 스냅샷 모델에서 Word와 `R/result_hwpx_native.R`의 직접 HWPX 작성기가 각각 저장한다. HWPX 저장에는 임시 Word 파일·한글 자동화 변환을 사용하지 않는다. 기존 B5 및 표별 가로·세로 방향을 유지하며 용지 선택 기능은 별도 후속 작업이다.
   - 화면에 표시된 결과를 바탕으로 표·셀 병합·문단·주석·그림·용지·여백·섹션 방향을 담는 공통 문서 구조를 만든다.
   - 공통 구조에서 Word와 HWPX를 각각 생성한다. 현재의 임시 Word → HWPX 변환을 거치지 않는 직접 HWPX 저장을 구현한다.
   - 공통 문서 구조 + 형식별 저장기 + 검증된 기본 서식을 사용한다. 용지·여백·열 너비 비율·서식 정책은 공통 계층에서 계산하고, 기존 Word 작성 코드는 가능한 범위에서 재사용한다.
   - Word·HWPX의 표와 문단은 편집 가능하게 생성한다. 양쪽의 내용·표 너비·서식 일관성을 검증하되, 서로 다른 문서 엔진의 줄바꿈·페이지 나눔이 항상 같다고 보장하지 않는다. 확정된 인쇄 모양은 PDF를 기준으로 삼는다.
   - 분석값·표 순서·라벨·정밀도·주석·그림은 그대로 유지하며, 저장을 위한 분석 재실행이나 결과 재구성은 하지 않는다.
   - 용지별로 현재/누적 결과와 PDF·HTML·Word·HWPX·Excel의 일관성을 검증한다. HWPX 저장 버튼의 기존 노출 범위는 별도 변경 요청이 없는 한 유지한다.

구현 시 우선 확인할 파일: `R/result_table_ui.R`, `R/result_saved_ui.R`, `R/result_export_files.R`, `R/app_misc_ui.R`, `R/app_server.R`, `R/utils.R`, `www/style.css`, `www/model-canvas/canvas.css`, `www/model-canvas/dialogs.js`.

## 다음 버전 — CFA·SEM 캔버스 모형 저장 호환

2026-09-18 사용자 결정: **현재는 계획만 기록하며 구현하지 않는다.** 다음 버전에서 적용하고, 착수는 별도 요청에 따른다. 위의 1.3.1 착수 우선순위는 유지한다.

- CFA는 SEM의 측정모형에 해당하므로, 모형 파일을 저장한 분석 메뉴가 다르다는 이유만으로 불러오기를 차단하지 않는다.
- CFA·SEM은 공통 모형 저장 형식을 사용하고 서로의 모형을 불러올 수 있게 한다. 변수·잠재변수·측정경로·구조경로·공분산·사용자 배치를 보존한다.
- 기존 `.stcfa`와 `.stsem` 파일 모두 불러오기 호환성을 유지한다. 새 공통 확장자와 형식 버전은 구현 시 결정한다.
- 모형과 분석 실행을 구분한다. 불러온 모형은 현재 열린 CFA 또는 SEM 메뉴의 분석 설정으로 실행한다.
- SEM 구조경로 등 현재 분석 메뉴에서 지원하지 않는 요소는 분석 실행 단계에서 안내한다. 불러오기 단계에서 분석 종류만으로 거부하거나 경로를 임의로 삭제하지 않는다.
- 이 결정은 모형 캔버스의 저장·불러오기에 관한 것이다. CFA의 추정 결과를 SEM의 분석 결과로 재사용하는 것은 포함하지 않는다.
- 매개·조절 및 PLS-SEM까지의 교차 불러오기 허용 범위는 아직 확정하지 않았다.

현행 확인 사항: 네 캔버스는 `www/model-canvas/dialogs.js`의 공통 JSON 저장 코드를 사용하지만 확장자(`.streg`, `.stcfa`, `.stsem`, `.stpls`)와 `analysisType` 일치 검사가 구분되어 있다. CFA → SEM 불러오기는 파일 선택 필터와 분석 종류 검사에서 제한된다. 구현 시 이 두 지점을 함께 수정하고 기존 파일·배치 보존 및 분석 결과 초기화를 검증한다.

## Pro 버전

- 1.3.0 이후에 진행하며, 목표 시점은 1.5.0 전후로 잠정 계획한다.
- 세부 기능과 출시 시점은 추후 확정한다.
- 기존 코드의 Pro 관련 조건은 향후 구현을 위한 것으로, 현재 공개 제공을 의미하지 않는다.

PDF 표지의 공통 제목, 설명, 버전 구분과 정보 항목은 현재 UI 언어(ko/en/ja/zh/es/fr/de/vi)를 따른다. 로고와 정식 명칭 `StatEdu, Institute of Statistics`는 유지한다. 사용자 지정 제목·하단 문구는 그대로 보존한다.
