# GLM·로지스틱 회귀의 현재 분할 결과 언어 전환

## 변경 범위

- GLM과 로지스틱 회귀에 현재 분할 결과의 보조표 갱신 함수를 등록했다.
- 집단별 적합 결과가 확정될 때 변수 메타데이터와 표시 옵션을 함께 보관한다. 언어 변경 시 보조표 표시만 다시 구성하며 모델을 재적합하지 않는다.
- 캡처된 본표·사용자 라벨은 유지한다. 이미 누적한 결과의 스냅샷 정책은 변경하지 않는다.
- 공통 분할 처리에서 등록한 렌더러를 사용하는 결과의 종류를 `scope_renderer`로 일반화했다. 기존 회귀 검증용 `scope_regression`도 호환한다.

## 검증 근거

- `scripts/validate_split_glm_logistic_language.R`: 실제 GLM 연속형·이분형·계수형 및 로지스틱 이분형·순서형·다항형 결과. 6종 모두 8개 언어의 보조표 언어 속성과 본표 셀 보존 통과. 번역과 충돌하기 쉬운 변수 라벨 및 사용자가 편집한 본표 셀을 포함한다.
- 계수형 fixture의 자동 모형 비교 중 음이항 theta 추정 반복 제한 경고가 발생했다. 렌더링 검사는 통과했으며, 이 검사를 모든 계수형 적합의 수렴 검증으로 해석하지 않는다.
- `scripts/validate_split_glm_logistic_browser.cjs`: 실제 Chrome에서 120행을 A/B 두 집단으로 나누고 연속형 GLM 및 이분형 로지스틱 실행. 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 왕복. 두 집단 본표 셀 일치, 보조표 언어 갱신, 페이지 오류 없음.
- `validate_split_regression_language.R`, `validate_split_appendix_language.R`, `validate_analysis_scope.R` 재실행 통과. 기존 회귀·반복측정 변환, 케이스 선택, 분할 순서, 이전 캡처 거부, 비동기 완료 대기, 집단별 독립 적합 유지.
- 저장 검증 원본은 브라우저의 일본어 분할 결과를 합친 `tmp/split-glm-logistic-localized/entries.json`이다. GLM과 로지스틱 각각 두 집단을 포함한다.
- 현재·누적 HTML/PDF/Word/HWPX/Excel 생성 및 캡처 내용 대조 통과. PDF의 실제 추출 본문과 표지 검사도 통과했다. 로그: `tmp/split-glm-logistic-exports.log`.

## 제한

- 실제 브라우저 왕복은 연속형 GLM과 이분형 로지스틱으로 수행했다. MI/IPW, 다항·순서형 등의 모든 옵션을 브라우저에서 왕복한 것은 아니다.
- 다른 분석의 현재 분할 결과 갱신과 전체 다국어 검증 공백은 남아 있다. 전체 완료율을 의미하지 않는다.
- 설치본은 만들지 않았다.
