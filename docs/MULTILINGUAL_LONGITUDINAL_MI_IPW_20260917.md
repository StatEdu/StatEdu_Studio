# 종단 MI/IPW 복합 실패 안내 — 2026-09-17

MI의 `imputation n` 및 `imputation n weights` 뒤에 오는 등록된 앱 오류를 UI 언어에 연결했다. 단독 실패 목록과 Failed fits가 붙은 MI 설명에서 동일한 처리를 사용한다. IPW 관측모형 실패 문장 내부의 등록 오류도 번역한다. 대치 번호는 문자열 그대로 유지한다.

실패 목록은 전체가 알려진 형식과 등록 오류로 해석될 때만 번역한다. 미등록 오류, 사용자 문자열, 임의 번호/세미콜론 조각이 섞이면 목록 전체를 원문으로 보존한다. 패키지 상세를 문장 단위로 임의 분리하지 않는다. 사용자 데이터 열에 같은 문장이 있어도 기존 보존 규칙을 적용한다.

`validate_longitudinal_error_exports.R`에 MI 실패 목록, 복합 MI 설명, IPW 관측모형 실패의 표 시험 자료를 추가했다. 8언어에서 오류 상세·번호 번역 및 사용자 문장 보존을 확인하고 한국어·일본어 현재/누적 HTML·PDF·Word·HWPX·Excel의 텍스트를 검사한다. 실제 MI/IPW 적합 실패를 발생시킨 시험은 아니다. 기존 실제 GEE/LMM/패널 결과 및 외부 실패 문장 보존 회귀 검사도 수행한다.

브라우저 조작·페이지별 시각 검토는 포함하지 않는다. 계산과 저장된 원본 결과는 변경하지 않았다. 메타분석은 제외하고 설치본은 만들지 않았다.

위 자동 검사와 기존 결과 회귀 검사는 모두 통과했다. PDF는 한국어·일본어 각각 현재 5쪽, 누적 9쪽이다. 산출물: `tmp/longitudinal-error-exports`.
