# 생존 옵션 실제 브라우저 검증

현재 개발 소스를 격리 프로필 `tmp/survival-browser-profile-20260917`로 실행하고 Chrome headless에서 `scripts/validate_survival_options_browser.cjs`를 실행했다. 생성 CSV 4행을 사용했다. 종료 후 서버와 브라우저를 닫았다. 설치본·사용자 프로필은 변경하지 않았다.

## 발견과 수정

경쟁위험에서 회귀 추정량을 `both`로 설정한 뒤 일본어로 전환하면 `none`으로 돌아갔다. 변경 전 실제 DOM 입력값 검사도 통과한 상태에서 재현했다. 설정 렌더러가 입력을 모두 isolate하여 화면 캐시가 선택 변경을 반영하지 않는 경로가 있었다.

`R/server_survival.R`에서 경쟁위험 입력의 마지막 값을 세션 reactiveValues에 보존하고 렌더러가 이 상태 변경을 구독하도록 했다. 언어 전환 중 입력 연결이 해제되어 NULL이 되는 경우는 보존값을 덮어쓰지 않는다. 빈 문자열 등 명시적 선택 해제는 기록한다. 분석 실행·본표·보조표·내보내기 코드는 변경하지 않았다.

## 통과 범위

- 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 순환.
- 8언어 × KM/Cox/경쟁위험 3화면 = 24개 화면 검사.
- KM: 지연 진입·진입 변수·보고 시점·RMST 시점 유지.
- Cox: 지연 진입·진입 변수·정확법·스플라인 자유도·HR 보고 시점 유지.
- 경쟁위험: 두 추정량·검열분포 층화 변수·경쟁사건 코드 유지.
- 대표 옵션 라벨이 사전과 일치하며 해당 조건부 옵션이 실제 표시됨.
- Cox start–stop 전환 시 진입 변수 숨김/구간 시작 표시, 경쟁위험 none 전환 시 검열 층화 옵션 숨김.
- 페이지 JavaScript 오류 없음.

## 한계

초기 시도에는 KM 화면 초기화 전 값을 지정한 타이밍 문제와 테스트 선택자 오류가 있었다. 초기 준비 시간을 확보하고 설정 직후 값을 검증하며 실제 Shiny label ID로 수정했다. 이는 제품의 언어 전환 오류와 구분한다.

이번 검사는 같은 세션의 화면 재생성 후 옵션 복원이며, 설정 파일 저장·불러오기 검사는 아니다. 분석을 실행하거나 결과 저장물을 생성하지 않았다. 추천/사건 매핑 화면과 모든 오류 분기의 실제 브라우저 검증도 남아 있다. 앱 전체 완료를 뜻하지 않는다.
