# 생존분석 설계열·필수 패키지 안내 — 2026-09-17

Fine–Gray 추정 가능한 공변량 열 부족과 cmprsk/ggplot2 필요 안내 5종, 총 6종을 8개 언어로 추가했다. 분석 실패 알림과 ggplot2 관련 그림 내보내기 실패 알림에 연결했다. 패키지 이름·계산 조건·분석 표는 유지했다.

`validate_survival_input_errors_i18n.R`에서 패키지 확인 함수와 설계행렬 생성 경계만 대체해 해당 실제 오류 분기를 실행했다. 설치된 패키지는 제거/변경하지 않았다. 기존 포함 44종의 오류·실패 콜백·결과 초기화·외부 오류 보존 검사와 ggplot2 오류의 내보내기 번역 검사가 8개 언어에서 통과했다. 그림 오류와 번역 커버리지 회귀 검사도 통과했다.

44종 중 이번 6종은 격리한 의존성/행렬 경계를 사용한 검사이며 사용자 자료만으로 모두 재현한 것은 아니다. preflight 복합 오류, 추적 시점의 동적 오류와 일부 내부 모형 오류는 남아 있다. 실제 브라우저 조작 검증과 설치본 생성은 하지 않았다.
