# 생존분석 해석 가이드 번역

## 변경

해석 가이드 생성 함수에 UI 언어를 직접 적용했다. 기존 Kaplan–Meier 번역을 재사용하고 Cox·경쟁위험의 주제 및 설명 9개를 일본어·중국어·스페인어·프랑스어·독일어·베트남어 사전에 추가했다.

내용은 HR의 의미, Schoenfeld 진단 해석, 관찰자료의 인과해석 한계, CIF, 원인별 HR, sHR이다. 영어·한국어 원문과 통계 계산은 유지했다.

## 검증

`scripts/validate_survival_interpretation_i18n.R`는 실제 Kaplan–Meier·Cox·경쟁위험 분석으로 8개 언어를 검사한다.

- 각 분석의 설명 3행과 번역 대상 주제가 선택 언어로 표시됨을 확인했다.
- HR, CIF, sHR, Log-rank, RMST 표기는 유지했다.
- 전체 안내 패널의 마지막 표에 해당 번역이 적용됨을 확인했다.
- 회귀 본 표는 UI 언어와 관계없이 같은 영어 내용을 유지했다.
- 일본어 해석 가이드 캡처를 현재·누적 결과로 저장한다. 저장 시 재분석하지 않는다.
- 산출물: `tmp/survival-interpretation-i18n/`.
- 현재 3개·누적 4개 표의 HTML/PDF/Word/HWPX/Excel 검증을 통과했다. PDF 본문·표지와 표 순서·Excel 시트 수도 확인했다.
- 기존 공통 안내문 3개 분석 × 8개 언어 회귀 검증도 통과했다.

이번 범위는 해석 가이드 표이다. 전체 앱의 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
