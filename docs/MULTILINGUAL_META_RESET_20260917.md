# 메타분석 초기화 확인창 및 후속 범위 — 2026-09-17

입력 초기화 확인창의 제목과 질문에 남아 있던 한국어/영어 분기를 8개 언어 키로 변경했다. 취소/초기화 버튼은 기존 번역을 재사용한다. 초기화 동작 자체와 분석 출력은 변경하지 않았다.

`validate_meta_reset_i18n.R`에서 실제 확인창 observer의 HTML을 생성하여 제목·질문·버튼을 8개 언어 및 한국어 복귀로 검사했다. 창을 여는 단계에서 입력 자료를 수정하지 않는지도 확인했다. 카탈로그 검사 통과. 브라우저 실조작이나 설치본 생성은 수행하지 않았다.

후속 점검에서 확인한 중요 범위: `server_meta.R`의 다층/RVE 오류는 결과 객체에 보관되며, 의존성 민감도·leave-one-study-out 오류는 `result$notes`에 저장된다. 따라서 실패 알림 변환기에 문구만 등록해도 해당 결과 표시가 번역되는 것은 아니다. 이 경로는 본표 영어/보조표 UI 언어 구분과 현재·누적 결과의 HTML/PDF/Word/HWPX/Excel 검증을 함께 수행해야 한다. 이번에는 이 결과 경로를 수정하지 않았다.
