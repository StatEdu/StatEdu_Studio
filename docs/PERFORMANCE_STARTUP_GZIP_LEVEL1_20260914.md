# 모듈 식 캐시의 압축 수준 1 적용 — 2026-09-14

## 적용

`R/app_bootstrap.R`의 새 식 캐시 기록에 gzip 압축 수준 1을 적용했다. 기존처럼 같은 버전·매니페스트·식 객체를 RDS로 저장한다. 임시 파일의 gzip 연결을 `tryCatch(..., finally=close(connection))`로 닫은 뒤 최종 경로에 복사한다. 기록 실패는 이미 성공한 모듈 평가를 막지 않고 기존 임시 파일 정리 동작도 유지한다.

읽기와 캐시 유효성 검사는 변경하지 않았다. 유효한 기존 캐시를 강제로 재압축하지 않으며, 새 생성 또는 기존 무효화로 재생성이 필요할 때 새 압축 수준을 사용한다.

## 실제 초기화 측정

번들 R 4.5.3, JIT 3, UTF-8 환경에서 기존/후보 × hit/miss × 새 프로세스 3회, 총 12개 프로세스를 순차 실행했다. 두 번째 비교는 후보부터 실행했다. hit는 각 버전이 만든 유효 캐시를 사용하고 miss는 매번 새 디렉터리를 사용했다. 다른 R 작업을 동시에 실행하지 않았다.

| 조건 | 기존 모듈 로딩 3회(초) | 후보 3회(초) | 중앙값 기존→후보 |
| --- | --- | --- | --- |
| 유효 캐시 재사용 | 0.30 / 0.29 / 0.30 | 0.31 / 0.31 / 0.32 | 0.30→0.31 |
| 최초 캐시 생성 | 0.97 / 0.98 / 0.97 | 0.86 / 0.84 / 0.89 | 0.97→0.86 |

최초 생성의 모듈 로딩은 중앙값 기준 0.11초, 약 11.3% 단축됐다. 새 압축 형식의 hit는 세 비교에서 0.01~0.02초 더 걸렸으며 중앙값 차이는 0.01초다. 재사용까지 빨라졌다고 주장하지 않는다.

패키지 로딩 중앙값은 모두 0.25초, 초기 UI 구성은 0.36~0.38초, HTML 렌더링은 모두 0.06초였다. 서버 함수 생성은 타이머 해상도에서 0초였다. 실제 브라우저 렌더링·Electron 실행·R 프로세스 시작·사용자 Shiny 세션 초기화는 포함하지 않는다. 운영체제 파일 캐시를 비우지 않았으며 전체 설치 앱의 콜드 스타트 단축률이 아니다.

## 파일 크기와 판단

같은 객체를 담은 기본 압축 캐시는 1,607,030바이트, 수준 1은 2,258,031바이트였다. 약 0.65MB(40.5%) 증가한다. 두 파일에서 복원한 객체는 정확히 일치했다. 기존 무압축 후보와 달리 gzip을 유지하며, 이 파일 크기 증가와 작은 재사용 시간 차이를 감수하고 최초 생성 시간을 줄이는 선택이다. 최고 메모리 사용량은 이번에 측정하지 않았다.
