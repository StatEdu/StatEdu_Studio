# 최근 생존분석 제외 사유 최적화 통합 검증

이번 작업은 통합 검증이며 제품 코드는 변경하지 않았다. 네 가지 최적화가 모두 적용된 현재 preflight를 그 변경들 이전 기준 함수와 직접 비교했다. 개별 단축률을 합산하지 않았다.

검증 대상은 공변량 결측 사유의 중복 갱신 방지, 최초 사유 직접 기록, 새 사유 포함 여부 확인 후 추가, 단일 사유 문자열 일괄 추출이다. 앞서 적용한 생존시간·사건 매핑·사건 문자열 최적화는 기준과 현재 양쪽에 유지하므로 이번 누적 단축률에 포함하지 않는다.

## 기준과 검증

- 기준 함수: `scripts/fixtures/survival_reason_dedup_reference.R`. 현재 모듈 사본 중 기준 사본의 preflight만 교체한다.
- `validate_survival_reason_combined.R`: 0/1/30/120행, 정상/중첩/분산/전부 결측, 단일 기록/지연 진입/시작–종료, 변수 순서·중복 역할·집단/공변량 중첩의 전체 결과 96개, 사용자 정의 결측 검사 2개, 반복 시간/집단 사유 4개 비교 통과.
- 위 스크립트가 불러오는 기존 매핑 helper 294개와 전처리 36개 회귀 검사도 통과했다.
- 두 독립 성능 실행에서 각각 전체 전처리 88개 비교 및 성공 결과 확인.
- `validate_survival_reason_combined_cox.R`: 600행·공변량 6개, 정상/중첩/분산 결측 × 기본/층화/군집/스플라인 Cox 12조건의 성공 모형, 분석 행 수, 유한 계수 및 전체 결과 비교 통과.
- 같은 12조건의 한국어/영어 현재 Cox 패널 HTML과 의존성 24개 비교 통과. 실제 브라우저 픽셀이나 plotOutput의 그림 바이트를 비교한 검사는 아니다.
- 전체 결과/속성·진단·stdout·RNG는 `identical(..., num.eq=FALSE)`로 비교한다. Cox만 call 내부를 포함한 수식 `.Environment` 속성을 제외하며 수치 허용오차는 사용하지 않는다. HTML 비교에는 정규화를 적용하지 않았다.

## 통합 성능

번들 R 4.5.3, 실제 앱 모듈·환경설정 초기화, 양쪽 함수 컴파일, 동일 시드. 기존/현재 교대 실행, 준비 후 5회 중앙값. 타이머에는 전체 전처리와 진단/stdout 수집을 포함하며 결과 비교는 제외한다.

단위 ms, 변경들 이전 기준→현재 코드 중앙값.

| 조건 | 독립 실행 1 | 독립 실행 2 |
|---|---:|---:|
| 100,000행 중첩 | 1,604.64 → 267.40 | 1,595.87 → 256.07 |
| 1,000행 중첩 | 16.77 → 4.94 | 16.89 → 4.38 |
| 100,000행 분산 | 297.68 → 71.48 | 304.97 → 65.68 |
| 1,000행 분산 | 4.84 → 2.79 | 4.83 → 2.79 |
| 100,000행 sparse | 97.41 → 52.83 | 101.70 → 53.70 |
| 1,000행 sparse | 3.02 → 2.58 | 2.97 → 2.61 |
| 100,000행 정상 | 52.11 → 57.37 | 58.62 → 57.75 |
| 1,000행 정상 | 2.51 → 2.97 | 2.77 → 2.49 |

중첩은 같은 절반의 행에 사건·집단·공변량 6개 모두 결측이다. 분산은 공변량별 결측 행이 서로 겹치지 않는다. sparse는 사건 5%·집단 5%의 서로 다른 결측이다.

100,000행 전처리의 통합 단축은 중첩 약 83~84%, 분산 약 76~78%, sparse 약 46~47%였다. 1,000행 중첩도 약 71~74% 단축했다. 정상 자료는 최초 두 실행에서 방향이 달라 아래 추가 반복으로 확인했다.

### 정상 자료 추가 측정

별도 두 독립 프로세스에서 정상 조건만 각각 15회씩 측정했다. 프로세스당 전체 결과 62개 비교도 통과했다.

| 조건 | 추가 실행 1 기준→현재(ms) | 추가 실행 2 기준→현재(ms) |
|---|---:|---:|
| 100,000행 정상 | 57.07 → 57.76 | 55.46 → 54.65 |
| 1,000행 정상 | 2.58 → 2.52 | 2.52 → 2.43 |

100,000행의 차이는 약 +1.2% / -1.5%로 최초 측정의 증가가 지속 재현되지 않았다. 정상 자료의 개선율은 주장하지 않는다. 서로 다른 프로세스의 절대 시간끼리 비교하지 않고 각 프로세스 안의 짝 비교를 사용한다.

추가 데이터는 `focused-times-1.csv`, `focused-times-2.csv`이며 재현 인자는 `scripts/benchmark_survival_reason_combined.R 1 complete`와 `2 complete`이다.
