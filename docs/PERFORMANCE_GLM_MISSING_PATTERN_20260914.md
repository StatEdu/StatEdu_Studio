# GLM 결측 패턴의 완전 행 처리 단축 — 2026-09-14

`generalized_missing_pattern_summary()`가 결측 없는 행에도 매번 행별 함수를 호출해 변수명을 선택하던 처리를 줄였다. 결측 여부를 행별로 확인하고 기본값을 기존 문자열 `Complete`로 채운 뒤, 실제 결측 행에만 기존 변수명 조합 함수를 실행한다. 패턴 빈도표 생성·정렬·최빈 패턴 및 결측 수 계산은 유지했다. 제품에 반영했다.

선행 검토한 다중대치 Poisson 모형 캐시와 별개의 변경이며, 그 캐시는 적용하지 않았다. 이번 변경은 모형 적합·난수 생성·계수 및 표준오차 계산을 수정하지 않는다.

## 전체 분석 비교

| 입력 | 기존 3회(초) | 변경 후 3회(초) | 중앙값 |
|---|---|---|---|
| Gaussian, 완전 자료 200,000행 | 0.92 / 0.89 / 0.91 | 0.61 / 0.60 / 0.63 | 0.91 → 0.61, 약 33% 감소 |
| Gaussian, 일부 결측 200,000행 | 0.72 / 0.71 / 0.70 | 0.52 / 0.53 / 0.55 | 0.71 → 0.53, 약 25% 감소 |
| 음이항 MI, 10,000행 | 0.94 / 0.89 / 0.91 | 0.86 / 0.97 / 0.88 | 0.91 → 0.88, 일관된 개선 없음 |

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 각 입력에서 양쪽 준비 실행 후 GC 및 전체 분석 시간을 측정했으며 두 번째 프로세스에서는 비교 순서를 뒤집었다. 다른 R 타이밍 작업은 동시에 실행하지 않았다.

시드 916, 정규 예측변수 6개, 강건 표준오차 켬·VIF 끔이다. Gaussian y는 0.2*x1+정규오차, MI y는 size=0.5, mu=exp(0.2*x1-0.1*x2)인 음이항이다. 일부 결측과 MI 입력은 x1–x3 각각 15%를 결측으로 만들었다. Gaussian은 완전 사례 분석, MI는 대치 5개·반복 3회다. 분석 전 시드 713으로 초기화했다.

시간은 적합·결과 준비·비교용 스냅샷 구성을 포함한다. 입력 생성·모듈 로딩·화면 렌더링·파일 저장은 제외했다. 임시 행 마스크·문자 벡터 및 결측 행 부분 행렬이 필요하며, 메모리 사용량은 측정하지 않았다. 모든 행이 결측인 입력의 성능 개선을 주장하지 않는다.
