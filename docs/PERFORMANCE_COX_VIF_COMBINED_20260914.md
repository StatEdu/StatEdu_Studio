# 최근 VIF 최적화의 전체 Cox 분석 검증 — 2026-09-14

## 결론

절편 행렬 재사용과 완전한 설계 행렬의 전체 행 선택 생략을 함께 적용한 현재 코드를, 두 변경 직전과 비교했다. 이번 전체 분석 조건에서는 실행 시간 개선이 확인되지 않았다. 보조 함수에서 측정한 단축률을 전체 Cox 분석의 개선율로 제시하면 안 된다.

운영 코드를 추가로 변경하지 않았다. 전체 분석 결과와 화면 HTML은 일치했다. 10공변량에서는 그림을 포함한 저장 HTML과 Excel도 일치했다. 20공변량 저장에서는 변경 전후 모두 기존 그래프 여백 오류가 재현됐다.

## 전체 분석 시간

기준 사본은 `output/cox-vif-design-reuse-20260914/baseline.R`, 현재 사본은 이번 실행 시작 시의 `R/analysis_survival.R`이다. 동봉 R 4.5.3, 정규 공변량 20개, 시드 42, 첫 공변량에 의존하는 지수분포 생존 시간(소수 둘째 자리 반올림)과 사건 확률 0.7을 사용했다.

각 버전은 새 프로세스에서 3회 실행했고 두 번째 쌍은 현재 버전부터 실행했다. 각 프로세스에서 1천→1만→5만 행 순서로 전체 `prepare_cox_analysis_result()`를 측정했다. 입력 생성·패키지 로딩·HTML·파일 저장은 제외했으며 적합, 진단, 결과 테이블과 동일한 경고/메시지 수집 래퍼는 포함했다. 측정 중 프로파일러와 별도 검증은 실행하지 않았다. 첫 작은 분석은 초기 컴파일 비용의 영향을 받을 수 있다.

| 행 수 | 기존 3회(초) | 현재 3회(초) | 중앙값 기존 → 현재 |
|---|---|---|---|
| 1,000 | 0.82 / 0.80 / 0.81 | 0.80 / 0.81 / 0.82 | 0.81 → 0.81 |
| 10,000 | 0.54 / 0.55 / 0.54 | 0.53 / 0.53 / 0.54 | 0.54 → 0.53 |
| 50,000 | 1.95 / 1.92 / 1.92 | 1.96 / 1.94 / 1.93 | 1.92 → 1.94 |

0.01〜0.02초 차이로 실질적인 개선 또는 회귀를 단정하지 않는다. 이전 보조 함수의 10만 행 실험과 이번 전체 분석의 최대 5만 행 실험은 조건이 다르다. 다른 조건으로 확대 적용할 수 없으며 프로그램 로딩·실제 화면 대기 시간도 측정하지 않았다. 이번에 전체 분석의 메모리 사용량은 측정하지 않았다.

## 결과 검증

전체 결과·경고/메시지·난수 상태 9쌍과 각 행 수의 화면 HTML/의존성 3쌍이 `identical(..., num.eq=FALSE)`로 일치했다. Cox 공식·terms의 환경 참조 4곳만 `.GlobalEnv`로 정규화했다. 나머지 수치와 속성은 그대로 비교했다.

실제 분석 행 수는 1,000/10,000/50,000, 각 결과의 모수·영향력 진단·유한 DFBETAS·다중공선성 행 수는 모두 20이었다. 사건 수는 696/6,984/34,988이며 경고/메시지는 모두 0개였다.

## 저장 검증과 발견한 기존 오류

1천 행·20공변량 결과의 `saved_survival_results_html()`이 비례위험 진단 그래프 생성 중 `figure margins too large` 오류로 중단됐다. 기존/현재 결과를 각각 별도로 실행해 같은 오류를 확인했다. 이 조건의 저장 HTML 및 Excel 검증은 통과하지 못했다.

관련 코드는 `R/result_survival_ui.R`의 `survival_cox_ph_plot()`(약 1906행)과 저장 그림의 고정 높이 760 설정(약 2690행)이다. 변수 수에 따른 그래프 배치와 장치 크기를 별도로 검토해야 한다. 이번에는 그래프 레이아웃을 변경하지 않았고 오류가 해결됐다고 주장하지 않는다.

별도 1천 행·10공변량 자료를 같은 두 코드 버전으로 생성하여 저장 경로를 비교했다. 이 자료 생성의 단발 시간은 성능 비교에 사용하지 않았다. 그림이 포함된 저장 HTML, 생성 시 경고/메시지·난수 상태가 일치했다. Excel은 시트 이름·내용 및 압축 해제한 모든 파일을 비교했다. `docProps/core.xml`의 생성/수정 시각만 정규화했고 나머지는 바이트 단위로 일치했다.

PDF·Word·HWPX, 누적 결과 및 실제 서버 흐름은 재검증하지 않았다. 설치 파일은 재빌드하지 않았다.
