# GG 표기의 복원 결과 형식 번역

## 범위 확인 및 변경

`analysis_paired_rm.R`의 현재 연속형 분석 선택은 표준 반복측정 ANOVA, Wilks, Friedman으로 구성된다. GG 이름은 방법명 매핑과 결과 렌더링에 남아 있으며, 결과 렌더러는 GG epsilon·GG p를 처리한다. 현재 선택 경로에 GG를 새로 추가하지 않았다.

저장된 결과 형태를 모사한 객체에서 영어로 남던 `RM ANOVA + GG`, `RM ANOVA + Greenhouse-Geisser correction`의 2개 표기를 8개 언어 사전에 반영했다. 기존 영어·한국어 표현과 제품 계산·렌더링·저장 코드는 유지했다.

## 검증

- `validate_rm_gg_restored_i18n.R`: 실제 표준 반복측정 결과를 만든 뒤 Method와 GG epsilon=0.750, GG p=.123을 **검사용으로 설정**했다. RDS 저장·읽기 후 8개 언어에서 결과 패널의 짧은 분석명과 별도 부록 표 함수의 긴 분석명을 확인했다.
- 이 자료는 실제 과거 사용자 파일이나 실제 GG 적합 결과가 아니다. GG 추론 정확성, 앱 이력 복원 전체 흐름을 검증했다는 의미가 아니다.
- 영어 본표 동일성 및 저장된 결과 객체·GG 값 보존 검사 통과.
- `validate_rm_method_names_i18n.R`: 현재 표준·Wilks 실제 분석 결과의 8개 언어 회귀 검사 통과.
- `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/rm-gg-restored-i18n/exports`. 캡처를 저장하며 저장 단계에서 분석을 재실행하지 않는다. 별도 긴 분석명 검사 표는 저장 캡처에 포함하지 않았다.

문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 사용하지 않기로 한 기존 매개·조절효과 화면은 계속 제외하며, 이번 GG 결과 표기 점검과 구분한다.
