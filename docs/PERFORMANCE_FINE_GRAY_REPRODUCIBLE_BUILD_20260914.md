# Fine–Gray 소스 보관·재현 빌드 — 2026-09-14

## 구현

`native/fine_gray/`에 cmprsk 2.2-12 원본 Fortran, 캐시 후보 소스, 후보 생성기, 원본 패키지 메타데이터와 GPL v2 라이선스 전문을 보관했다. 원본 패키지의 라이선스 선언은 GPL (>= 2)이며 변경 내용과 날짜를 README에 기록했다. 기존 실험 폴더를 소스 입력으로 사용하지 않는다.

`scripts/build_fine_gray_native.ps1`은 명시한 Rtools45/GFortran 14.3.0 도구와 보관된 소스로 원본/후보 DLL을 만든다. 기존 출력 DLL/manifest를 덮어쓰지 않고 프로세스 PATH를 복원한다. 빌드 manifest에 컴파일러·소스·바이너리 해시 및 컴파일 옵션을 기록한다. 설치기와 연결하거나 시스템 환경을 변경하지 않는다.

처음에는 PE 타임스탬프만 제거했으나 두 출력 폴더에서 바이너리가 달랐다. GNU 링커가 출력 경로에 따라 preferred image base를 다르게 선택한 것을 확인했다. 최종 스크립트는 `--no-insert-timestamp`와 `--image-base,0x180000000`을 함께 사용한다. 수치 계산 컴파일 옵션과 Fortran 연산 순서는 기존 후보대로 유지했다.

## 재현성과 정확성

- 서로 다른 출력 폴더 `build-c`, `build-d`의 원본 및 후보 DLL SHA-256이 각각 동일했다.
- 별도로 모은 배포용 소스를 다른 경로에서 다시 빌드한 `bundle-rebuild`의 후보도 동일했다.
- 최종 후보 SHA-256: `E90C46F63FBD1ED2B60DF0CE62068A8765E149DE7C3876C67A3204D323C0CE3D`.
- 최종 후보 MD5 식별값: `cebd7c0594c1cd189cb9983d1df5e16e`.
- 원본 DLL SHA-256: `0F3BA3E881459C26AF807C02B0C2B92D7BAC2D40EA858CABA0FD2B874AE07681`.

이는 이 머신의 동일 도구 모음에서 서로 다른 출력/소스 위치로 재현한 결과이며 다른 컴파일러나 새 머신의 재현성 증거는 아니다. ZIP 전체의 바이트 재현성은 검사하지 않았다.

기존 21 기본·40 추가·100 극단 조건 검사를 영구 검증 스크립트로 옮겼다. 최종 빌드는 설치 cmprsk와 재빌드 원본 대비 전체 반환값·진단·표준출력·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 161건 모두 성공 적합이라는 뜻은 아니다. 극단 100조건에는 정상 반환 42건·오류 58건이 있고 분산 루틴 호출 진입은 65건이다. 시간가변 원본 복귀와 미수렴도 포함한다. 추가 40조건의 이진 자료는 잡음 추가 후 연속값이며, 실제 이진 자료는 기본 21조건에 포함된다.

수치 검증 후에만 새 식별값을 `survival_fine_gray_engine()` 허용 목록에 추가했다. 기존 검증 후보도 계속 허용한다. 최종 DLL로 `validate_fine_gray_native_loader.R`을 실행해 원본 복귀·반복 로드·패키지 네임스페이스 불변과 실제 전체 분석 10조건을 다시 통과했다. 전체 분석 비교는 원인별 Cox의 formula/terms 환경 참조만 정규화했다.

화면/저장 코드는 변경하지 않았다. 이번에는 내보내기를 재실행하지 않았으며, 5개 형식 검증 범위는 [로더 구현 보고서](PERFORMANCE_FINE_GRAY_LOADER_20260914.md)에 기록되어 있다. 새 빌드의 성능과 메모리를 다시 측정하지 않았다.

## 배포 준비물과 남은 사항

`output/fine-gray-repro-20260914/fine-gray-component.zip`에 후보 DLL, manifest, 원본·수정 소스, 생성기, 라이선스, 빌드/네이티브 검증 스크립트를 모았다. 이는 검토용 선택적 구성요소이며 앱 설치 파일이 아니다. 외부에 게시하지 않았다.

기본 활성화, 설치기 포함, 새 머신 실행 검증은 남아 있다. 운영 코드의 기본값은 계속 기존 cmprsk이며 환경 변수를 영구 설정하지 않았다. 설치 DLL SHA-256은 `870703DC72F849F4E8FD0B3EA867EB97EFA397B1E30CB5B8DE0CBA643083B21A`로 유지된다. 설치 파일은 재빌드하지 않았다.
