# GLM 입력 오류 다국어 안내

2026-09-16. 설치본은 만들지 않았다.

- 실행 실패 알림의 제목만 번역되고 오류 설명은 원문으로 남는 경로를 확인했다.
- 종속변수/독립변수 선택, 완전 사례 수, 감마 양수 조건, 카운트 정수 조건, 노출량 조건/유형, 종속변수 유형, 이항 수준 수의 9개 안내를 8개 언어 카탈로그에 등록했다. 이항 오류의 3가지 원문을 동일한 의미의 안내로 처리한다.
- `generalized_error_ui_text`를 실패 알림에 연결했다. 정확히 일치하는 앱 오류만 번역하며 미등록 외부 오류, 사용자 텍스트 및 영어 원문을 보존한다. 분석 엔진은 변경하지 않았다.
- `scripts/validate_glm_input_errors_i18n.R`: 8개 언어 통과. 실제 검증 함수와 분석 진입점에서 발생한 오류 7개, 전체 카탈로그 매핑, 이항 별칭, 외부 메시지 및 NA 보존을 확인했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 이번 변경은 실행 실패 알림에만 적용된다. 분석 결과 표/주석/저장 경로는 변경하지 않아 출력 파일 재검증 대상은 없다. 실제 데스크톱 알림의 시각 검증은 수행하지 않았다.
- MI 내부 실패 및 미등록 외부 라이브러리 오류 등은 이번 범위에 포함하지 않았다. 전체 다국어 점검 완료를 의미하지 않는다.
