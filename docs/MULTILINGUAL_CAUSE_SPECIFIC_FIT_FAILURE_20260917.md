# 원인별 Cox 추정 불가 경고 번역

원인별 Cox 계수·불확실성 추정 불가의 근거·권고 2개 문구를 6개 추가 언어에 번역했다. 기존 영어·한국어 문구와 판정 로직 및 분석 계산은 유지했다.

`scripts/validate_cause_specific_fit_failure_i18n.R`는 실제 원인별 Cox 적합 결과의 estimable 플래그를 TRUE/FALSE/NA/미포함으로 구성하여 8개 언어를 검사한다. 실패 사례를 별도로 적합한 것은 아니다.

- 4가지 상태 × 8개 언어의 경고 발생 여부·심각도·번역 검사 통과.
- 본 회귀표의 동일한 영어 내용 유지 확인.
- 일본어 경고표 캡처로 현재·누적 결과 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/cause-specific-fit-failure-i18n/`.

현재 3개·누적 4개 표의 HTML/PDF/Word/HWPX/Excel 검증을 통과했다. PDF 본문·표지와 표 순서·시트 수도 확인했다. 집단·원인별 희소 사건 경고의 8개 언어 회귀 검사도 통과했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
