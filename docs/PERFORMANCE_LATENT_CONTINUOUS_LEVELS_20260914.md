# 잠재 상관분석의 불필요한 연속형 범주 순서 계산 생략 — 2026-09-14

`R/analysis_correlation.R`의 `correlation_latent_pair_result`에서 연속형 점수에도 매번 범주 순서를 만들던 부분을 개선했다. 연속형 입력의 순서는 Pearson 계산에 사용되지 않으며, Polyserial에서는 순서형 쪽의 순서만 사용한다. 불필요한 문자 변환·고유값 추출·정렬을 생략한다.

연속형으로 지정되고 범주 설정표가 NULL이며, 속성 없는 숫자 벡터와 일반적인 단일 문자 변수명이 주어진 경우에만 생략한다. 순서형·이분형 값의 순서 계산, 범주 설정표가 있는 경우, 특수 자료형·변수명은 기존 처리를 유지한다. 계수 추정이나 신뢰구간 수식은 바꾸지 않았다.

## 성능

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 변경 전후 3쌍을 순차 측정하고 두 번째 쌍은 순서를 반대로 했다. 대상 함수를 동일한 전역 환경으로 연결했다. 두 조건 모두 latent_correlations=TRUE, continuous_method=auto, 정규성 검사 TRUE이며 범주 설정표는 없다.

| 자료 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 1만 행·연속형 8변수 | 1.72 | 0.16 |
| 2천 행·연속형 4 + 순서형 4변수 | 0.48 | 0.33 |

각각 약 91%, 31% 감소했다. 연속형 조건 원자료는 변경 전 1.72/1.72/1.70초, 변경 후 0.16/0.16/0.17초다. 혼합 조건은 변경 전 0.49/0.47/0.48초, 변경 후 0.33/0.33/0.33초다.

잠재 상관 옵션에서 전체 결과를 준비하는 시간을 측정했다. 연속형끼리 선택되는 추정법은 Pearson이며, 일반 상관 옵션의 Pearson 경로 개선률이 아니다. 각 프로세스는 연속형 조건 후 혼합 조건을 실행해 조건 간 직접 비교를 피한다. 화면 렌더링·앱 로딩·내보내기는 포함하지 않는다.

## 검증

- 실제 polycor 0.8.2를 사용한 잠재 상관 24조건에서 전체 결과와 쌍별 계수·표준오차·검정 통계량·p값·신뢰구간·추정 상태/이유·진단·난수 상태가 정확히 일치했다.
- Polyserial·Polychoric·Tetrachoric의 유한한 추정치와 추정 불가 반환도 확인했다. 대표 HTML/의존성 3건이 동일했다.
- 명시적 범주 순서 지정, 변환 메시지를 내는 숫자 클래스, 결측, 무한값, 전부 결측, 빈 입력의 추가 12조건에서 쌍별 반환값 또는 오류와 진단·난수 상태가 일치했다.
- 성능 측정 6쌍의 전체 결과·진단·난수 상태가 `identical(...,num.eq=FALSE)`로 일치했다.
