# 누적 결과 자동 복원

앱의 새 세션은 결과 저장소에서 기존 결과를 한 번 읽어 초기화한다. 결과 ID, 순서, HTML 스냅샷을 유지하며 분석을 다시 실행하지 않는다. 같은 세션에서 저장소 함수를 다시 호출해도 메모리 상태를 덮어쓰지 않는다. 전체 삭제는 빈 이력으로 저장되므로 재시작 후에도 빈 상태를 유지한다. 기존 설정 불러오기의 명시적인 결과 초기화 동작은 유지한다.

JSON 구문 오류나 다른 종류의 파일은 자동 복원 실패로 처리한다. 시작 시 원본 파일을 변경하지 않고 알림을 표시한다. 이후 새 결과 저장 등으로 해당 경로에 쓰기 전, 읽을 수 없는 파일의 원본 바이트를 같은 폴더의 `.unreadable-` 사본으로 보관한다. 백업에 실패하면 저장하지 않는다. 기존 결과 파일 불러오기와 개별 결과 삭제·이동·실행 취소도 유지한다.

검증: `validate_result_autorestore.R`에서 순서 복원, 세션 내 중복 읽기 방지, 실제 Shiny 세션 간 이동 상태 유지, 전체 삭제, 손상 파일 보존·백업과 잘못된 파일 종류를 확인했다. `validate_result_history.R`, `validate_result_collection_management.R`도 통과했다. 표시할 분석 표의 내용이나 저장 형식은 변경하지 않았다.

설치본 앱 재시작 검사에서도 결과 3개의 순서·HTML이 모두 일치했다. 복원된 결과의 현재·누적 HTML/PDF/Word/HWPX/Excel 저장과 PDF 제목·셀·주석·그림 검증을 통과했다. 설치본 포함 여부와 동시 작업 파일의 차이는 `output/INSTALLER_20260915.md`에 기록했다.
