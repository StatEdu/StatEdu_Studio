# MICOM 1단계 점검 보조표 다국어 보완

- 동일한 지표/모형 명세, 결측·표준화 처리, PLS 알고리즘/설정에 관한 점검 기준과 근거를 UI 언어로 표시한다.
- 구성개념 수·지표 수를 포함한 근거 문장은 전체 번역 템플릿으로 처리한다. 실행 함수 이름, 알고리즘 식별자 및 사용자 문구는 보존한다.
- `Passed` 열 이름의 6개 언어 번역을 추가했다. 다집단 보조표 공통 포매터의 논리값도 UI 언어의 예·아니요·산출 불가로 표시한다.
- 공통 포매터가 기존 사용자 열 보호 속성을 유지하도록 수정했다. MICOM 점검 기준·근거 중 미등록 사용자 문자열은 일반 번역에서 다시 치환하지 않는다.
- 계산 및 본표 생성 로직은 변경하지 않았다. 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_micom_audit_i18n.R`: 실제 MICOM 생성 코드의 점검표 표현식을 평가해 만든 자료로 정상·논리값 혼합·사용자 문구·빈 표를 8개 언어에서 검증했다. 숫자·함수 식별자·특수문자·통과 여부 보존을 확인했다. 다른 두 다집단 보조표 분기에서도 집단명과 N 보존을 확인했다.
- 기존 `validate_sem_micom.R` 통과.
- `tmp/micom-audit-i18n/entries.rds` 표시 스냅샷을 기반으로 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 검증 통과. 현재 3표·누적 4표의 순서와 Excel 시트 수, PDF 일본어 제목·내용·표지를 확인했다. 저장 시 분석을 다시 실행하지 않았다.

범위는 MICOM 1단계 점검표와 다집단 보조표의 공통 논리값 표시이며, 다집단 분석 전체의 번역 완료 판정은 아니다.
