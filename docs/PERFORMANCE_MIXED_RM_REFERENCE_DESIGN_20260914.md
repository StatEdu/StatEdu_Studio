# 혼합 반복측정 사후 비교 기준 행렬 재사용

2026-09-14. 일괄 회귀에서 모든 시점 대비에 공통인 공변량 기준 그리드와 설계행렬을 한 번만 계산하도록 변경했다. `mixed_rm_adjusted_pair_fit_test()`에 선택적인 `design` 인수를 추가하고, 일괄 경로에서만 같은 행렬을 전달한다. 기존 개별 계산 경로는 기존처럼 직접 행렬을 생성한다.

계수·공분산·추정 가능 항목 선별·평균·표준오차·자유도·p값의 계산식과 계산 순서는 유지한다. 이전 단계의 일괄 회귀 적용 조건과 오류 시 개별 계산으로 돌아가는 처리는 유지한다. 전역 캐시나 분석 간 캐시는 추가하지 않는다.

## 성능

2,000명, 4집단, 6시점, 숫자 공변량 1개, Holm 사후 비교. 버전별 새 R 프로세스 3개를 순차 실행하고 두 번째 쌍의 순서를 반대로 했다. 분석 시간에서 HTML 생성 시간을 제외했다.

| 전체 분석 시간 중앙값 | 기존 | 변경 |
|---|---:|---:|
| 첫 실행 | 0.77초 | 0.77초 |
| 반복 실행 | 0.27초 | 0.25초 |

반복 실행은 기존 0.27/0.27/0.26초, 변경 0.25/0.25/0.25초로 약 7% 감소했다. 작은 절대 시간 차이이며 다른 데이터에서도 같은 개선율이 나온다는 의미는 아니다. 이전 보고서의 측정값을 이어 붙여 누적 개선율을 계산하지 않았다.

6시점의 15개 대비를 처리하는 일괄 호출에서 기준 그리드 생성이 15회에서 1회로 줄었다. 데이터 변경 후 다음 호출에서는 새로 생성하며, 새 데이터의 개별 계산과 정확히 일치함을 검증했다.

## 검증

- `scripts/validate_mixed_rm_batch_pairs.R`: 48개 경계조건에서 반올림 전 검정 결과 목록, 경고·메시지·표준출력·난수 상태가 개별 계산과 `identical()` 일치. 기준 그리드 1회 생성 및 데이터 변경 후 재생성 검증 포함.
- 전체 분석 12개 시나리오, 성능 측정 3쌍의 결과는 허용오차 0, 환경 객체 제외 비교 통과. 공선성과 단일 집단 시나리오는 기존과 같은 분석 오류 반환을 확인한 경우다.
- 일반 HTML 정확히 일치. 보고서 HTML은 생성 시각만 정규화한 뒤 동일. 현재·누적 HTML 동일, Excel은 생성 타임스탬프를 제외한 패키지 내용 동일.
- 관련 파일 `git diff --check` 통과.
- 현재·누적 HTML/PDF/Word/HWPX/Excel 총 10개 파일 생성 성공. Word/HWPX의 비어 있지 않은 셀 내용은 HTML과 각각 680/1,360개 일치. PDF는 기존 표지를 포함해 9/17페이지이며 이미지는 표지에만 존재한다. 현재 PDF 본문 첫 페이지를 시각 확인했다.

기존 소스와 재현 스크립트, CSV, 결과 RDS 및 저장 산출물은 `output/mixed-rm-reference-design-20260914/`에 보관한다. 빌드·배포하지 않았다.
