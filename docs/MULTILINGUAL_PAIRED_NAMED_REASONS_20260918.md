# 대응표본·반복측정의 변수 포함 제외 사유 번역

## 변경

실제 대응표본·반복측정 결과에서 변수 누락 및 측정수준 불일치 안내가 비한국어 UI에 영어로 남는 것을 재현했다. 다음 동적 문구 4종에 8개 언어 템플릿을 추가하고, 기존 한국어·영어 동작은 유지했다.

- 대응표본: 활성 자료에 변수가 없어 제외.
- 대응표본: 두 변수의 측정수준이 달라 제외.
- 반복측정: 활성 자료에서 변수를 찾을 수 없음.
- 반복측정: 변수들의 측정수준이 서로 다름.

안내의 고정된 앞·뒤 문구만 인식하고 중간의 변수명·측정수준 상세 문자열을 그대로 템플릿에 전달한다. Warning/Reason/Message 열의 해당 문구에만 적용하며 분석 계산을 변경하지 않는다. 측정수준 상세 코드 자체를 새로 번역한 것은 아니다.

## 검증

- `validate_paired_named_reasons_i18n.R`: 정상 쌍/반복측정 행과 변수 누락·측정수준 불일치 행을 함께 실제 분석했다. 결과의 네 제외 사유가 8개 언어의 실제 표에 표시되는지 확인했다.
- 누락 변수명에 한글·HTML 특수문자·`%s`를 사용해 그대로 보존되는지 검사했다. 영어 본표 동일성과 원본 결과 객체 보존도 통과했다.
- `validate_paired_guards.R`, `validate_paired_zero_count_i18n.R`, `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검사와 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-named-reasons-i18n/exports`. 캡처한 결과를 저장하며 저장 과정에서 분석을 재실행하지 않는다.

## 범위

이번 검증은 대응표본·반복측정 결과 표의 제외 사유를 대상으로 한다. 분석 실행 전 알림 전체나 다른 분석명·이상치 동적 안내까지 검증한 것은 아니다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면은 계속 제외한다.
