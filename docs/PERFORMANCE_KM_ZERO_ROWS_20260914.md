# KM 곡선 시작점 일괄 생성 — 2026-09-14

`R/analysis_survival.R`의 `survival_km_plot_data`에서 집단별 시작점(시간 0, 생존확률 및 신뢰한계 1)을 생성하는 부분을 간결하게 바꿨다. 집단마다 한 행의 데이터프레임을 만든 뒤 rbind하는 대신, 기존과 같은 `unique(curve$Strata)` 순서로 하나의 데이터프레임을 생성한다. summary 호출, 추정치, 변환식, 검열 표시, 원래 곡선과의 결합 순서는 유지한다.

## 측정

번들 R 4.5.3의 새 프로세스에서 변경 전후 3쌍을 순차 실행했다. 두 번째 쌍은 실행 순서를 반대로 했다. 같은 전역 함수 환경을 사용했으며, 측정 전에 각 함수를 한 번 호출했다. 집단당 20행의 합성 자료에서 미리 계산한 survfit을 사용했다.

다음은 **곡선 데이터 준비 함수 10회 호출 합계**의 중앙값이다. 수치 분석과 그래프 렌더링을 포함하지 않는다.

| 집단 수 | 변경 전(초) | 변경 후(초) |
|---|---:|---:|
| 2 | 0.02 | 0.01 |
| 100 | 0.23 | 0.11 |
| 500 | 1.77 | 1.06 |

100집단은 약 52%, 500집단은 약 40% 감소했다. 많은 집단 조건은 확장성 확인용이며 일반적인 2집단 분석에서의 절대 이득은 작다. 전체 앱 또는 첫 KM 실행이 이 비율로 빨라진다는 의미가 아니다.

## 동일성 검증

- 1/2/8/64/512집단 × 두 시드 × 네 그래프 변환(생존확률, 사건확률, 누적위험, 로그 생존확률)의 40조건에서 반환 객체 전체, 경고·메시지, 난수 상태가 정확히 일치했다.
- 모두 사건/모두 검열, 단일 집단/진입 시간과 집단을 포함하는 조건 및 네 변환의 추가 16조건에서도 기존 반환값 또는 오류와 진단이 일치했다.
- 시간 측정에 사용한 9개 변경 전후 데이터 쌍도 정확히 일치했다. 행 이름과 순서를 포함한 객체 전체를 `identical(...,num.eq=FALSE)`로 비교했다.
- 검증된 72행 KM 결과로 네 그래프 유형 × 컬러/흑백의 PNG 8쌍을 만들었다. 위험집단 수 표를 포함한 모든 PNG가 바이트 단위로 같았고 경고·메시지도 일치했다. PNG 장치는 1000×800, res=100으로 고정했다.
- 전체 서버 하네스의 상관·KM 분석, 결과 HTML/의존성, 경고·알림이 이전 `output/startup-jit-20260914/current-final1.rds`와 정확히 일치했다. 검증 스냅샷은 같은 디렉터리의 `current-km-zero-rows.rds`다.
