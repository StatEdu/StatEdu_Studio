# 비가중 패널 FE·RE 선택 모형 재사용

## 적용 내용

`R/analysis_longitudinal.R`에서 비가중 Gaussian 패널 FE/RE의 선택 모형을 민감도 분석에 재사용한다. 같은 준비 자료와 변수, 옵션으로 적합한 선택 모형만 전달하고 대안 FE/RE 모형은 새로 적합한다. random_slope FALSE 및 가중치 NULL인 경우로 제한했다.

첫 적합에서 경고·메시지가 발생하거나 RNG가 달라지면 재사용하지 않는다. 정상 경로의 앱 적합 함수 호출은 3회에서 2회로 줄어든다. Hausman 검정의 직접 적합과 HC1/Driscoll–Kraay 비교는 변경하지 않았다. 기존 GEE/LMM/GLMM 재사용도 유지한다.

## 전체 성능

번들 R 4.5.3, seed 939, 2,000명 × 6시점 = 12,000행, 연속 반응, 공변량 2개, 기본 분석 옵션. 워밍업 후 독립 프로세스 3개를 순차 실행했고 두 번째 프로세스는 변경 후 코드부터 측정했다. 로딩은 제외하며 비교용 캡처와 정규화는 포함한다.

| 모형 | 변경 전 1 / 2 / 3 (초) | 변경 후 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| FE | 4.11 / 4.03 / 3.60 | 3.50 / 3.39 / 3.19 | 4.03 → 3.39초, 약 16% 감소 |
| RE | 4.00 / 3.53 / 3.44 | 3.64 / 3.34 / 3.26 | 3.53 → 3.34초, 약 5% 감소 |

두 모형 모두 세 번의 실행에서 빨라졌다. 해당 자료·환경의 결과이며 같은 개선율을 보장하지 않는다. 워밍업 및 측정의 반환 결과·조건·출력·RNG 비교도 통과했다.

## 검증

`scripts/validate_longitudinal_panel_reuse.R`은 22개 조건을 비교한다. FE/RE 각각에 정상, 경고/메시지/RNG 소비/오류 주입, exponentiate FALSE, 일부 결측·역순 자료, 대상자 전체 결측, 이름 있는 행, random_slope TRUE, sampling 가중치를 포함한다.

정상 재사용 9개에서 3→2회 적합을 확인한다. 재사용되는 선택 적합과 원래의 민감도 재적합은 반환 모형 및 계수표 전체를 정규화하여 수치 허용오차 없이 비교한다. 재사용하지 않는 적합도 같은 순서의 결과인지 확인한다.

두 종류의 기존 실패를 성공 분석으로 취급하지 않고 별도로 검사한다.

- 가중 FE/RE는 기존 공분산 구현 미지원으로 생략되며, 오류 문구와 skipped 결과를 그대로 비교한다.
- 일부 결측·역순 RE 시험 자료는 변경 전 코드에서 `Lapack routine dgesv: system is exactly singular: U[4,4] = 0`으로 생략된다. 이 결과를 보존하는지 검사한다. 별도로 대상자 전체가 결측인 정상 적합 자료도 비교한다.

지속 검증의 참조 경로는 패널 선택 모형 재사용만 끈다. 지속 검증 22개와 변경 전 소스를 직접 로드한 동일한 22개 비교가 모두 통과했다. GEE 48개와 LMM 20개 회귀 검증도 통과했다.

전체 반환 객체의 수치와 조건 클래스/본문/순서, 표준 출력, RNG는 `identical(..., num.eq = FALSE)`로 비교한다. formula/terms 환경과 함수 표현만 정규화하며 원시 환경·함수 객체의 동일성까지 주장하지 않는다. 수치 반올림이나 허용오차는 사용하지 않는다.

## 범위 및 증거

분석 출력 내용과 형식은 변경하지 않았다. 가중 공분산 미지원과 특이행렬 시험 자료의 기존 실패는 수정하지 않았다. 이전 종합 테스트의 Excel 셀 위치 비교 실패도 이번에 재실행하거나 해결하지 않았다. 관련 패널/GEE/LMM 검증을 수행하고 전체 형식 변환과 설치 파일 빌드는 실행하지 않았다.

`output/longitudinal-panel-reuse-20260914/`에 `baseline.R`, `candidate.R`, `bench.R`, `normalize.R`, `timing-1/2/3.csv`, `validation.log`, `validation-old-source.log`, `gee-regression.log`, `lmm-regression.log`, `diagnose.R`를 보관한다. 기존 작업 트리의 다른 변경은 유지했다.
