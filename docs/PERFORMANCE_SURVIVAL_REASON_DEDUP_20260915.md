# 같은 공변량 결측 사유의 반복 갱신 제거

`survival_preflight`의 지역 `add_reason`에서 missing_covariate를 기록한 행 번호를 호출 안에서 보관한다. 후속 공변량 결측 검사에서는 이미 기록된 행을 setdiff로 제외하고, 새 행에만 기존 `unique(c(existing, code))`를 실행한다. 각 변수의 `is.na` 검사와 인덱스 계산은 그대로 실행한다.

첫 사유 추가 시점과 사유 순서, 중복 제거, 다른 사유의 기록, 분석 행 선택과 사건 매핑을 유지한다. 기록 목록은 전처리 호출이 끝나면 사라지며 전역 캐시가 아니다. 추가 메모리는 공변량 결측이 있는 행 번호 수에 비례한다.

이전 `PERFORMANCE_SURVIVAL_REASON_BATCH_REVIEW_20260914.md`의 미적용 lapply/목록 대입 후보와 다르다. 이번 변경은 같은 결과를 얻기 위해 반복하던 행별 갱신 횟수를 줄인다. 같은 50,000행에 공변량 6개가 결측인 경우 missing_covariate의 행별 갱신은 300,000번에서 50,000번이 된다.

## 검증 방법

- `scripts/validate_survival_reason_dedup.R`: 0/1/30/120행 × 단일 기록/지연 진입/시작–종료 × 정상/겹친 결측/서로 다른 결측/전부 결측. 변수 순서 변경·중복 역할·집단과 공변량 역할 중첩을 추가해 전체 결과 96개 비교. 사용자 정의 `is.na`가 경고·메시지·난수를 발생시키는 조건 2개도 비교한다.
- 기존 매핑 helper 294개·전처리 36개 검사를 함께 불러온다. 이번 변경의 96개 검증과 별도 회귀 검사이다.
- `scripts/benchmark_survival_reason_dedup.R`: 정상/사건·집단 일부 결측/공변량 결측 중첩/공변량 결측 분산 × 1,000/100,000행. 두 독립 프로세스에서 성공 결과와 프로세스당 전체 결과 88개를 확인한다.
- `scripts/validate_survival_reason_dedup_cox.R`: 600행·공변량 6개, 정상/20% 중첩/50% 분산 결측 × Cox 기본/층화/군집/스플라인 12조건. 성공 모형, 분석 행 수, 유한 계수를 확인한다.
- 비교는 전체 값/속성·진단·stdout·RNG에 `identical(..., num.eq=FALSE)`를 사용한다. Cox만 call 내부를 포함한 수식 `.Environment` 속성을 제외한다. 수치 허용오차는 사용하지 않는다.
- 위 비교는 모두 통과했다. 기존 `validate_survival_preflight.R` 종합 검사도 실제 앱 초기화 후 통과했다.

## 측정 조건

번들 R 4.5.3, 실제 앱 모듈·환경설정 초기화, 두 사본 함수 컴파일, 동일 시드, 기존/변경 교대 실행. 각 조건 준비 후 5회 중앙값. 타이머는 전체 전처리와 진단/stdout 수집을 포함하며 결과 비교는 제외한다.

100,000행 중첩 조건은 같은 절반의 행에 사건·집단·공변량 6개의 결측이 겹친다. 분산 조건은 여섯 공변량의 결측 행이 서로 겹치지 않는다. sparse 조건은 사건 5%와 집단 5%의 결측이며 공변량은 완전하다. 따라서 이번 변경의 직접 수혜 조건과 그렇지 않은 조건을 구분한다.

### 분산 결측 추가 측정

별도의 두 독립 프로세스에서 분산 조건만 각각 15회 반복했다. 프로세스마다 전체 결과 비교 62개도 통과했다.

| 조건 | 추가 실행 1 기존→변경(ms) | 추가 실행 2 기존→변경(ms) |
|---|---:|---:|
| 100,000행 분산 | 292.09 → 295.84 | 290.63 → 294.10 |
| 1,000행 분산 | 5.17 → 5.31 | 5.21 → 5.30 |

100,000행에서는 약 1.2~1.3%(3.5~3.7ms), 1,000행에서는 약 1.8~2.8%(0.10~0.14ms)의 증가가 남았다. 사유가 겹치지 않으면 기록 횟수를 줄일 수 없고 행 번호 확인 비용만 더해진다. 모든 입력에서 빨라졌다고 주장하지 않으며, 중첩 조건의 큰 감소와 이 작은 비용을 함께 보고하고 변경을 유지했다.

추가 원자료는 `focused-times-1.csv`, `focused-times-2.csv`이며 재현 인자는 `scripts/benchmark_survival_reason_dedup.R 1 disjoint`와 `2 disjoint`이다.
