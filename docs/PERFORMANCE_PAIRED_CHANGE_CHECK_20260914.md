# 반복측정 내 변화 확인 최적화 — 2026-09-14

## 적용 내용

`R/analysis_paired_rm.R`의 `paired_rm_has_within_subject_change()`에서 결측치 없는 일반 double/integer 행렬은 첫 열과 다른 열을 비교한다. 하나라도 다르면 즉시 TRUE를 반환한다. 기존에는 모든 행마다 결측치를 제거하고 `unique()`를 호출했다. 행렬 변환은 한 번 수행하며, NA/NaN·문자·논리·복소수·객체 행렬은 기존 행별 검사로 처리한다.

숫자 행렬에서 각 행의 값이 모두 같은지 확인하는 논리만 변경했다. Friedman, Wilcoxon, ANOVA, 사후검정 및 효과크기의 계산식과 순서는 변경하지 않았다. 이 도우미는 비모수 반복측정뿐 아니라 일반 반복측정 및 혼합 반복측정에서도 사용된다.

## 전체 실행 시간

R 4.5.3 번들 런타임, 20,000행 × 6회 측정, 데이터 seed 939, 실행 capture seed 718. 연속형은 정규 난수, 순서형은 1~5 균등 표본, 이분형은 0/1 균등 표본이다. `prepare_nonparametric_paired_rm_single_result()` 전체를 사후검정·요약표 생성까지 측정했다. 3개의 별도 R 프로세스를 순차 실행했고 각 프로세스에서 양쪽을 예열했다. 두 번째 프로세스는 개선본을 먼저 측정했다. 시간 단위는 초다.

| 입력 | 기존 1/2/3 | 개선 1/2/3 | 중앙값 기존→개선 |
|---|---|---|---|
| 연속형 | 2.13 / 2.09 / 2.06 | 2.05 / 2.00 / 2.03 | 2.09→2.03 (약 2.9%) |
| 순서형 | 1.57 / 1.50 / 1.53 | 1.50 / 1.44 / 1.42 | 1.53→1.44 (약 5.9%) |
| 이분형 | 0.17 / 0.12 / 0.16 | 0.11 / 0.14 / 0.12 | 0.16→0.12 |

연속형·순서형은 각 3회 모두 단축됐다. 이분형은 앞 단계에서 문자로 변환되어 기존 검사 경로를 사용하므로 측정 차이를 이번 숫자 비교 최적화의 효과로 해석하지 않는다. 전체 실행의 개선 폭은 작으며 모든 자료 크기에서 같은 비율을 보장하지 않는다. 메모리 사용량은 측정하지 않았다.

## 동일성 검증

- 연구 스크립트: 경계 입력 164개, 각 프로세스의 예열 및 측정 전체 결과 모두 `identical(..., num.eq=FALSE)` 통과.
- 독립 기존 함수가 포함된 `scripts/validate_paired_rm_change_check.R`: 경계 입력 170개 통과. 빈 입력/행/열, 한 열, NA/NaN, Inf, 부호 있는 0, 인접 double, 정수, 문자, 논리, 복소수, factor 데이터 프레임, 전부 같은 행, 마지막 행·열에서만 달라지는 경우를 포함한다.
- 일반·비모수 반복측정 전체 경로 24개: 연속형/순서형/이분형 × 일반/결측/변화 없음/마지막 셀 변화 × 두 분석. 전체 반환값, 경고·메시지 및 오류의 클래스와 문구, 표준출력, RNG 상태가 정확히 일치한다.
- 혼합 반복측정 전체 경로 3개: 일반/결측/변화 없음에서 같은 비교를 통과했다. 정상·결측 시나리오는 오류 반환이 아님도 확인했다.
- 경계 테스트 반복 실행은 서로 다른 테스트 수로 합산하지 않았다. 변화 없음 등의 기존 오류도 그대로 비교하며, 정상 분석 성공과 구분한다.

반환 객체를 정규화하거나 수치 허용 오차를 적용하지 않았다. 검정 내부 원시 통계량을 별도 추적한 검증은 수행하지 않았으며, 변경된 함수의 논리 반환값과 전체 분석 반환값을 검증했다. UI/내보내기 코드 및 결과 구조는 바꾸지 않았고 문서 변환·패키징은 재실행하지 않았다.
