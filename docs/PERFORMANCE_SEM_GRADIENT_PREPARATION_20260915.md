# SEM 기울기의 불변 인덱스 준비 재사용 검토

2026-09-15. 후보 미적용, 제품 변경 없음. 기울기 함수에 모수와 무관한 인덱스 준비가 반복되지만, 이를 재사용한 연구 사본의 호출 시간은 세 실행에서 일관되게 줄지 않았다.

## 발견한 부분과 후보

번들 `lav_model_grad`를 확인했다. 그룹별 행렬 범위를 만드는 `1:nmat[g] + cumsum(c(0, nmat))[g]`는 같은 모형의 Hessian 차분 호출 사이에서 변하지 않는다. 함수 안에 이 식이 세 군데 있으며, 이번 일반 free-parameter 분기에서는 그룹별 미분 조립과 자유모수 추출에서 사용된다. 다른 하나의 단순 등식 제약 분기는 이번 fixture에서 실행되지 않는다.

연구용 함수 사본에서 이 식만 모형별 사전 계산 인덱스 조회로 대체했다. 인덱스 생성은 원래 식 그대로 사용했고 계산 순서, 행렬 계산, 반환 자료형은 바꾸지 않았다. 설치된 lavaan namespace와 제품 파일은 변경하지 않았다. 후보는 고정된 한 모형에만 묶인 연구용 함수로, 일반 입력용 제품 캐시가 아니다.

그룹 가중치 준비 또한 모수 벡터와 무관하지만 이번 후보에는 포함하지 않았다. 반면 sigma/mu/omega는 전달된 모수 행렬 glist를 사용하므로 결과 전체를 모형 구조만으로 재사용할 수 없다. 해당 내부 연산의 중복 여부는 별도 검토 대상이다.

## 검증 및 측정 범위

기존 안정적인 전체 조합 DMC의 240행·관측 지표 9개·제품지표 9개, ML/FIML, std_lv=FALSE 원모형을 사용했다. 수렴 및 허용 가능 여부를 확인하고 원모형의 57개 모수 각각에 -h/-2h/+h/+2h(h=1e-6)를 적용한 228개 입력을 만들었다.

이것은 원모형 점추정 주변의 직접 기울기 검사다. 이전 24개 부트스트랩 표본의 Hessian 전체를 재실행하거나 전체 부트스트랩 결과를 비교한 것은 아니다.

각 독립 프로세스에서 동일하게 컴파일한 기준/후보를 준비 실행한 뒤, 228개 입력 10순회 묶음을 각 버전 5회 측정했다. 버전 순서를 교차하고 각 측정 전 GC를 실행했다. 모형 적합, glist 생성, 캐시 준비, 함수 컴파일과 정확성 비교는 타이머 밖이고, 기울기 호출·결과 목록 보관·부모 진단/stdout/RNG 캡처는 안이다. 따라서 실제 적용보다 후보에 유리한 조건이다.

세 프로세스 모두 228개 입력의 기울기가 유한하며 모수 수와 길이가 맞았고, 준비 비교와 측정별 결과·속성·경고/메시지·stdout·RNG가 `identical(..., num.eq=FALSE)`로 일치했다. 프로세스 간 기준 캡처 두 쌍도 정확히 일치했다. 수치 허용오차나 환경 속성 제거는 사용하지 않았다. 특수 추정법·다집단·제약 모형 전체에 대한 검증은 아니다.

## 시간

228개 기울기 × 10순회 묶음의 5회 중앙값이다.

|---|---:|---:|---:|
| 1 | 0.484511 | 0.488993 | +0.93% |
| 2 | 0.485461 | 0.484716 | -0.15% |
| 3 | 0.490382 | 0.487629 | -0.56% |

준비 비용을 제외해도 뚜렷하고 일관된 이득이 없다. 따라서 제품 적용과 전체 부트스트랩 확대 검증으로 진행하지 않는다. 이 수치를 Hessian 전체 또는 5,000회 분석의 개선율로 환산하지 않는다.

이전 작업자 프로파일에서 cumsum의 포함 표본 시간은 첫 실행 전체의 약 0.05%로 작았다. 이는 모든 인덱스 준비 비용을 정확히 분리한 수치는 아니지만, 이번 제한된 이득과 모순되지 않는다.

## 이력과 다음 단계

최초 연구용 AST 치환기는 NULL 인자를 삭제하면서 준비 단계에 오류를 냈다. 빈 인자와 NULL을 보존하도록 수정한 최종 스크립트로 세 실행을 완료했다. 이 실패는 제품 계산 오류가 아니며 시간 자료에 포함하지 않았다.

인덱스 준비 재사용 후보는 미적용으로 종료한다. 다음은 기존 프로파일에서 큰 비중을 보인 sigma/mu 계산 안에서 같은 기울기 호출 중 공유 가능한 중간 계산이 있는지 확인하는 것이다. 서로 다른 모수 입력의 결과를 혼용하지 않고, 기존 보류 캐시를 새 근거 없이 재추진하지 않는다.
