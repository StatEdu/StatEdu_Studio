# 교차표·t 검정/분산분석 대표 결과 다국어 검사

## 확인 및 수정

실제 90행 자료로 교차표와 독립표본 t 검정·일원분산분석을 실행했다. 정규성 검토를 끈 대표 경로에서 보조표의 `Normality not checked`가 부분 번역되고 `Homogeneity`가 영어로 남는 것을 확인했다. 두 문구를 8개 언어 사전에 등록했다. 통계 계산과 본표 구성은 변경하지 않았다.

## 검증 근거

- `scripts/validate_group_comparison_i18n.R`: 8개 언어 모두 실제 본표 셀·제목·주석이 영어 기준과 동일함을 확인. t/ANOVA 보조표 2개의 언어 메타데이터, 두 번역 문구, 사용자 변수 라벨(한국어 및 `Status`) 보존 검사 통과.
- `validate_ttest_anova.R`, `validate_crosstabs.R`, `validate_i18n_contract.R` 통과. 기존 분석 검사 실행 시 모듈 캐시 쓰기 권한 경고가 있었지만 검사 자체는 성공했다.
- `tmp/group-comparison-i18n/entries.rds`: 일본어 실제 결과 저장용 fixture. 현재·누적 HTML/Word/HWPX/Excel의 첫 항목(t/ANOVA) 제목·셀 내용 비교 통과. 두 결과가 들어간 PDF 생성 및 첫 항목 예상 텍스트 검사 통과.

## 범위와 남은 사항

교차표의 현재 기본 렌더러는 본표를 출력한다. 별도 `crosstab_single_result_ui`의 기대도수 보조표는 이 경로에서 호출되지 않으며, 이번 검증으로 해당 보조표 완료를 주장하지 않는다.

정규성 활성화, 비모수 자동 선택, 사후검정 조합, 희소 교차표·추세검정, 실패/제외 경고, 옵션 및 브라우저 언어 왕복은 추가 확인 대상이다. 대표 결과 근거가 생긴 화면은 11개에서 13개로 늘었고, 전용 결과 검증 공백은 19개에서 17개로 줄었다. 완전 완료 판정 화면은 여전히 0개이며 설치본은 만들지 않았다.
