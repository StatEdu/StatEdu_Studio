# 다국어 작업 중간 점검

## 판단

개발 소스 기준으로 주요 분석군의 대표 UI·결과·저장 검증이 진행되어 있고, 최근에는 종단분석의 상세 진단 안내와 생존분석 부록을 보완했다. 전체 앱의 다국어 완료 또는 배포 준비 완료로 판단하지 않는다. 전체 실행 경로를 분모로 하는 최신 완료 체크리스트가 없어 신뢰할 만한 전체 완료율은 제시하지 않는다.

## 이번 재개 이후 확인된 성과

메뉴 첫 클릭 이동 45회 및 종단 분할 결과의 8언어 복귀 검증을 완료했다. 이후 연속 작업의 개별 보고서 기준 번역 보완은 16묶음이다.

| 영역 | 묶음 | 문구·템플릿 보완 건수 |
|---|---:|---:|
| 종단분석 | 13 | 105 |
| 생존분석 | 3 | 22 |
| 합계 | 16 | 127 |

이는 각 작업 보고서의 보완 건수를 합산한 값이며, 전체 앱 번역 키 수나 실제 미번역 순감소량과 동일하지 않다. 8언어에 대응하는 원문·템플릿 단위로 집계했다.

- 종단: 정규성, 이분산·과산포, 의존성, Hausman, 혼합모형 경고·구조, REML, 결측 요약, 적합도·모형 안내, GLMM/GEE 분포, 원고·소프트웨어 표제, 민감도 상태, 모형 이름.
- 생존: Cox 모형 개요, 층별·범주형 검정, 보정 생존곡선 개요.
- 각 묶음은 8언어 번역 검사와 한국어·일본어 현재·누적 결과의 HTML/PDF/DOCX/HWPX/XLSX 내용 검사 및 PDF 텍스트 검증을 완료했다. 실제 적합·안내 생성 함수·주입 상태 등 검사 방식의 차이는 개별 보고서에 기록되어 있다.
- 사용자 변수명·값과 영어 본표 보존을 검사했다. 사용자 이름 경계 보존 및 결측 시점 값 보호도 보완했다.

## 최신 정적 감사

이번 점검에서 `scripts/audit_multilingual_contract.R`를 다시 실행했다. 검사 파일 333개, 문구 출현 4,220건, 하나 이상 언어에서 사전 번역을 찾지 못한 고유 후보 582개다.

재개 시점 645개에서 63개 감소했다. 동적 문구는 정적 감사가 포착하지 못하고, 영어 본표·미사용 분기·다른 번역 경로는 후보에 포함되므로 이 수치로 번역 완료율을 계산하지 않는다.

| 우선 검토할 파일 영역 | 후보 수 |
|---|---:|
| 구조모형 측정불변성 결과 | 140 |
| 생존분석 결과 | 66 |
| 매개·조절 설정 | 50 |
| 대응표본 결과 | 35 |
| 사용자 모형 캔버스 번역 | 35 |
| 생존분석 설정 | 22 |
| 혼합 반복측정 ANOVA 결과 | 21 |

파일별 수치는 서로 중복되는 원문을 포함할 수 있어 합산해 고유 후보 수와 비교하지 않는다. 종단 결과 UI에 남은 정적 후보는 Direction(영어 본표)과 분포명이 없는 Generalized linear mixed model(실제 생성되는 분포 포함 명칭과 별도) 두 개다. 이것만으로 종단분석의 모든 동적 분기가 완료됐다고 판단하지 않는다.

## 남은 완료 조건

1. 생존분석 잔여 진단·경쟁위험·동적 안내를 실제 경로로 확인하고 보완한다.
2. 구조모형·매개조절 등 후보가 많은 영역을 같은 기준으로 재분류한다.
3. 37개 지연 분석 화면의 메뉴·옵션·오류·언어 왕복·분할·현재/누적 저장을 통합 체크리스트로 점검한다. 기존 통과 항목은 재사용하고 변경 영향 범위를 우선 재검증한다.
4. 분석 외 메뉴와 네이티브 파일 창의 실제 표시·조작, 문서 편집기 시각 검수를 완료한다.

최근 작업은 개발 소스에 적용됐다. 설치파일은 생성하지 않았으며 설치 앱 반영 여부를 이번 점검에서 확인한 것은 아니다. 과거 전체 범위는 MULTILINGUAL_STATUS_20260917.md와 개별 후속 보고서를 함께 참조한다.
