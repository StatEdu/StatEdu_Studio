# 복합표본 선형·로지스틱 회귀 다국어 검증

## 수정

- 분석 개요의 사례 수, 수정/유사 R 제곱, 모형 Wald/F, 분석명·개요 제목·사건 범주 등의 번역을 보완했다.
- 결측 사례 제외 안내는 번역한 문장에 건수를 삽입한다. 결과변수의 사용 가능한 값이 없거나 로지스틱 결과변수가 이분형이 아닌 경우의 안내도 연결했다.
- 로지스틱 사건 범주의 사용자 값 `Yes`가 일본어 `はい` 등으로 변환되는 문제를 수정했다. 사건 범주 값 셀을 원문 보존 대상으로 명시한다.
- 오류 패널의 제목과 이미 구성한 상세 안내를 보존하여 사용자 이름이 재번역되거나 사라지지 않게 한다. 알 수 없는 외부 오류는 원문을 유지한다.
- 모델 적합과 본표 수치는 변경하지 않았다. 번역 자료는 `scripts/fill_complex_regression_i18n.py`다.

## 검증

- `scripts/validate_complex_regression_i18n.R`: 120행, 3개 층, 30개 PSU, 가중치, 연속형/범주형 예측변수. 선형 회귀와 이분형 로지스틱, 예측변수 결측 2건, 전부 결측인 선형 결과변수와 단일 범주 로지스틱 결과변수.
- 8개 언어에서 정상 모형 2개와 실패 패널 2개 검사 통과. 본표 영역 전체(셀·제목·주석), 사용자 라벨, 사건 범주 `Yes`, 결측 건수 2 보존 및 실제 번역 문구 대조.
- 기존 `scripts/validate_complex_sample_analysis.R` 통과.
- 근거: `tmp/complex-regression-i18n`, `tmp/complex-regression-regression.log`.
- 일본어 결과 스냅샷의 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 및 내용 대조 통과. 실제 PDF 본문·표지도 검사했다. 로그: `tmp/complex-regression-exports.log`.

## 제한

- 다른 모형 적합 오류, 표기·설계 옵션, 결과변수 결측 처리의 모든 분기, 브라우저 언어 왕복/분할은 검증 완료를 뜻하지 않는다.
- 설치본을 만들지 않았다.
