# 일원 반복측정 LONG·공변량 다국어 검증

LONG 입력 요약의 대상자 ID·처치 집단·시점·결과변수 역할, 개체 내 요인 설명, 집단별 대응 사례 수를 8개 언어로 연결했다. 변수명과 역할명을 분리한 메타데이터를 계산 결과의 overview에 보관하며 렌더링할 때 선택 언어로 조합한다. 조합된 값에는 사용자 셀 보존 표시를 적용하여 `Normality`, `Yes` 같은 이름이 다시 번역되지 않게 했다. WIDE의 처치별 입력 변수 목록도 원문 그대로 보호한다.

WIDE가 일반 표 너비의 일본어 `幅広`로 표시되는 문맥 충돌도 발견하여 WIDE/LONG 입력 형식 전용 키로 분리했다. 두 형식 식별자는 유지하고 형식 안내를 현지화한다. 이번 추가 키는 총 8개다.

`scripts/validate_one_group_formats_i18n.R`는 40명 자료로 WIDE/LONG 각각 공변량 없음/연속형 공변량 1개 포함의 네 실제 분석을 실행한다. 동일 자료의 두 형식 간 ANOVA 표가 일치하며, 8개 언어에서 본표 영어 동일성, 보조표 언어 속성, 구조화된 입력 안내 및 사용자 이름 보존을 확인했다. 사용자 이름에는 한국어·번역 문구와 같은 영문·퍼센트 문자를 포함했다.

기존 대표 경로 및 유의한 상호작용·결측·정규성 문제·가정 검토 생략 검사와 번역 계약 검사가 통과했다. 저장 fixture는 `tmp/one-group-formats-i18n/entries.rds`로 네 분석의 일본어 결과를 한 항목에 모았다.

입력 형식 수정 후 최종 fixture로 현재·누적 HTML/Word/HWPX/Excel 내용 비교, PDF 생성 및 실제 PDF 텍스트 검사를 통과했다. 로그는 `tmp/one-group-formats-exports.log`다. 전체 화면의 시각적 배치를 검증했다는 뜻은 아니다.

범주형/복수 공변량, 다른 옵션·오류, 실제 UI 언어 왕복은 남아 있다. 기존 저장 결과 중 구조화된 입력 메타데이터가 없는 LONG 결과는 원래 입력 요약을 보존하며 자동 재분석하지 않는다. 이미 저장된 화면 스냅샷도 재번역하지 않는다. 대표 검증 범위를 넓힌 것으로 전체 완료 판정은 아니다. 설치본은 생성하지 않았다.

후속 오류 점검 대상: `server_one_group_rm_anova.R`의 계산 실패 처리는 `conditionMessage(e)`를 그대로 알림에 전달한다. LONG의 개체 내 공변량 불일치, 키/변수 누락, WIDE 처치별 시점 수 불일치, 최소 완전 사례 수 등 엔진 오류의 전용 번역 연결과 실제 재현이 필요하다. 이번 변경에는 오류 처리 수정은 포함하지 않았다.
