# 생존분석 분산 누적의 공통 스칼라 재사용

> 2026-09-15 재검증 정정: 아래는 최초 적용 당시 기록이다. 관련 함수의 컴파일 조건을 맞춘 재측정에서 약 8% 개선이 재현되지 않아 공통 스칼라 이동을 되돌렸다. 기존 위험집단·사건 수 사전 집계는 유지한다. 최종 판단은 [컴파일 조건 재검증](PERFORMANCE_SURVIVAL_RANK_SCALARS_AUDIT_20260915.md)을 따른다.

## 변경

`R/analysis_survival.R`의 가중 순위검정에서 집단 수 20 미만인 분산 행렬 루프의 공통 분모 `n_total^2 * (n_total - 1)`와 가중치 제곱 `weight^2`를 사건 시점마다 한 번 계산한다. 각 행렬 칸의 분자 곱셈, 나눗셈, 최종 덧셈 및 사건 시점 순서는 그대로다. 20집단 이상에 이미 적용된 벡터 경로는 변경하지 않았다.

정수 오버플로를 일으킬 수 있는 `d_total * (n_total - d_total)`와 부호가 있는 대응 곱셈은 기존처럼 각 칸에서 계산한다. 따라서 이 연산의 경고 횟수까지 유지한다. 새 캐시나 함수 복사 엔진은 추가하지 않았다.

## 정확성

- `scripts/validate_survival_rank_variance.R`에 실제 변경 전 소스를 전달했다. 384개 조건의 검정 결과 및 내부 분산 행렬·관측-기대 차이·진단·난수 상태가 정확히 일치했다. 지연 진입, 여러 사건 패턴, 2/3/4/10/19/20/21/30집단을 포함한다.
- `scripts/validate_survival_rank_scalars.R`: 2/4/19/20집단, 100/100,000행, 세 검정에서 반환값과 내부 분산·점수를 각각 비교한 48개 검증이 통과했다. 기존에 관측된 진단 총 2,298건과 stdout·난수 상태도 그대로 유지됐다.
- `scripts/validate_survival_rank_counts.R`: 원시 결과·진단·stdout·난수 상태 198개, 직접 집계 자료의 빠른 경로 33개/기존 경로 27개 및 행렬 크기 제한 검증 통과.
- 전체 Kaplan–Meier 결과 준비의 성능 측정 24개에서도 전체 반환값·진단·stdout·난수 상태가 일치했다.

모든 수치 비교는 `identical(..., num.eq=FALSE)`를 사용했고 정규화나 허용오차를 적용하지 않았다.

## 성능

5,000행, 4/16집단, 연속시간/동점 시간, Breslow/Tarone–Ware, 지연 진입 없음. 평가 시점 10/20, 기본 결과 표, 그림 제외 조건에서 결과 준비 전체를 측정했다. 새 R 프로세스 3개에서 기존/변경 코드를 예열한 뒤 순차 측정했고 두 번째 실행은 순서를 뒤집었다. 시간은 반환값·진단·stdout·난수 수집을 포함하며 함수별 계측은 없다.

24개 중 14개 단축, 6개 동일, 4개 증가했다. 16집단 연속시간은 두 검정 각각 3회 모두 단축됐다. Breslow의 기존 0.34/0.36/0.36초 대비 변경 0.33/0.33/0.31초로, 중앙값 감소는 약 8%다. Tarone–Ware는 0.34/0.34/0.36초 대비 0.33/0.33/0.32초였다.

4집단 연속시간 Breslow의 기존 실행은 0.29/0.08/0.32초로 변동이 커서, 이 행의 큰 중앙값 차이를 대표 개선율로 삼지 않는다. 동점 자료에서는 증가도 있었다. 4집단 Breslow는 0.03→0.04초, 0.03→0.25초, 0.03→0.01초였고, 4집단 Tarone–Ware 첫 실행은 0.01→0.04초, 16집단 Tarone–Ware 세 번째 실행은 0.10→0.11초였다. 작은 실행 시간의 해상도와 변동을 고려해야 하며 모든 조건에서 빨라진다고 보장하지 않는다.

단순한 공통 스칼라 이동으로 코드를 유지하면서 16집단 연속시간에서 반복적인 단축이 관측되어 반영했다. UI·그림 렌더링·내보내기·로딩 시간의 개선율은 아니다.

## 자료

`output/survival-rank-scalars-20260915/`의 `baseline.R`, `check.R`, `timing-1.csv`부터 `timing-3.csv`에 변경 전 소스와 재현 자료를 보존했다. 기존 위험집단·사건 수 사전 집계는 유지한다. 표 내용과 UI·내보내기 코드는 변경하지 않았으며 별도 그림/내보내기 실행 및 배포 빌드는 수행하지 않았다.
