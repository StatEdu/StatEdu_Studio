# 최초 모듈 캐시의 파싱·평가·압축 저장 비용 — 2026-09-14

## 결과

캐시 최초 생성에서는 파싱과 압축 저장이 주요 비용이었다. 압축 수준 1을 별도로 시험했을 때 저장 시간 중앙값이 약 29% 줄었고 반복 읽기 중앙값은 같았다. 파일은 약 41% 커졌다. 이번에는 제품 코드를 변경하지 않았으며 실제 초기화 흐름에 적용한 성능 비교는 후속 검증 대상이다.

## 초기화 단계 계측

번들 R 4.5.3, JIT 3, UTF-8 환경에서 hit/miss × 비계측/계측 × 새 프로세스 3회, 총 12개 프로세스를 순차 실행했다. hit 캐시는 사전 준비했고 miss는 매번 새 디렉터리를 사용했다. 다른 R 작업은 동시에 실행하지 않았다.

`source_cached_app_modules`의 로컬 복사본에만 `readRDS`, `parse`, `eval`, `saveRDS`, `file.copy` 기록 함수를 배치했다. 인수를 먼저 평가한 뒤 원래 함수를 호출했다. 식 평가는 기존처럼 명시적인 `.GlobalEnv`에서 수행했다. 계측 후 원래 로더를 복원했다.

| 경로/단계 | 3회 시간(초) |
| --- | --- |
| hit: readRDS | 0.25 / 0.26 / 0.23 |
| hit: eval | 0.01 / 0.00 / 0.02 |
| miss: parse | 0.49 / 0.48 / 0.48 |
| miss: eval | 0.01 / 0.00 / 0.02 |
| miss: saveRDS | 0.36 / 0.36 / 0.36 |
| miss: 최종 파일 복사 | 0.00 / 0.02 / 0.00 |

miss에서 존재하지 않는 식 캐시를 읽는 시도는 세 번 모두 타이머 해상도에서 0초였다. 0초는 작업 비용이 없다는 의미가 아니다. 표의 readRDS는 압축 해제와 역직렬화를 포함하고, saveRDS는 직렬화·압축·파일 쓰기를 포함한다. 세부 비용을 더 분해한 측정은 아니다.

비계측 모듈 로딩 중앙값은 hit 0.31초, miss 0.99초였으며 계측 중앙값은 각각 0.30초, 0.99초였다. 초기 UI 구성은 비계측 hit 0.38초, miss 0.39초였다. 패키지 로딩·모듈 로딩·UI 구성·HTML 렌더링은 별도 기록했으며, Electron/브라우저·R 프로세스 시작·실제 Shiny 세션은 포함하지 않는다. 운영체제 파일 캐시를 비우지 않았다.

## 압축 수준 1 실험

현재 생성된 실제 식 캐시 객체(버전 및 매니페스트 포함)를 읽어 기본 `saveRDS`와 `gzfile(compression=1)`에 대한 `saveRDS`를 비교했다. 두 방식 모두 저장을 준비 실행한 뒤 3회 저장 및 5회 읽기를 묶어 측정했다. 새 R 프로세스 세 개를 순차 실행하고 두 번째 프로세스에서는 후보를 먼저 실행했다. 이 실험은 전체 모듈 로더를 실행하는 측정이 아니다.

| 방식 | 3회 저장 묶음 시간, 3프로세스(초) | 5회 읽기 묶음 시간, 3프로세스(초) | 파일 크기(바이트) |
| --- | --- | --- | ---: |
| 기본 압축 | 1.01 / 1.31 / 1.01 | 0.77 / 0.67 / 0.75 | 1,607,030 |
| gzip 수준 1 | 0.82 / 0.66 / 0.72 | 0.75 / 0.84 / 0.69 | 2,258,031 |

저장 중앙값은 3회당 1.01→0.72초, 약 29% 감소했다. 1회당 환산 차이는 약 0.097초다. 읽기 중앙값은 두 방식 모두 5회당 0.75초였지만 두 번째 비교 등에서 변동이 있었다. 파일 크기는 651,001바이트, 약 40.5% 증가했다.

반복 읽기와 초기화 단계의 최초 읽기는 서로 다른 조건이므로 직접 비교하지 않는다. 이 저장 시간 감소를 전체 앱 시작 시간 감소율로 표현할 수 없다. 무압축 후보를 재도입한 것이 아니며, 현재 gzip 포맷 안에서 압축 강도만 낮춘 실험이다. 최고 메모리나 콜드 디스크 영향은 측정하지 않았다.

## 검증과 후속 범위

12개 초기화 스냅샷의 HTML·의존성·Pearson 결과·생명표 결과·분석 후 난수 상태·서버 함수 본문/인자가 정확히 일치했다. HTML 자동 생성 숫자 탭 ID만 정규화했다. 모듈 로딩의 경고·메시지는 없었다.
