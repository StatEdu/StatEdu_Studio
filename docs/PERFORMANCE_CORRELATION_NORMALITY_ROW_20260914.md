# 자동 상관분석 정규성 행 조회 개선 — 2026-09-14

`R/analysis_correlation.R`의 `correlation_normality_satisfied`에서 판정값 하나를 읽기 위해 정규성 표의 행 전체를 복사하던 작업을 줄였다. 일반 data.frame이고 normal이 속성 없는 논리 벡터이며 조회 이름이 하나 이하일 때, 원래 비교식을 계산하고 첫 해당 위치의 논리값만 읽는다. 다른 입력은 기존 행 추출 경로를 유지한다.

중복 이름은 첫 해당 행을 사용한다. 비교 결과의 NA가 실제 일치 행보다 앞서면 원래 행 추출에서도 NA 행이 먼저 생기므로 FALSE 판정을 유지한다. normal 열의 부분 일치는 빠른 경로에서 허용하지 않는다. 정규성 기준이나 Pearson/Spearman 선택 규칙은 변경하지 않았다.

## 성능

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 최종 코드의 변경 전후 3쌍을 순차 측정했다. 두 번째 쌍은 순서를 반대로 했다. 대상 함수를 같은 전역 환경으로 연결했다. 100행의 숫자형 합성 자료에서 auto 분석을 실행했다. 각 프로세스는 10변수 후 100변수를 실행했다.

| 변수 수 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 10 | 0.14 | 0.14 |
| 100 | 0.99 | 0.67 |

100변수에서 전체 결과 준비 시간이 약 32% 감소했다. 원자료는 변경 전 0.97/1.00/0.99초, 변경 후 0.69/0.67/0.67초다. 그래프·화면 렌더링, 앱 로딩 및 내보내기는 포함하지 않는다. 분석 방법을 고정하여 정규성 판정 조회를 사용하지 않는 경로의 개선률이 아니다.

- 중복/결측/빈/미존재 이름, NULL 및 복수 이름, 논리/숫자/문자 판정 열의 128조건에서 조회값 또는 오류·경고가 일치했다.
