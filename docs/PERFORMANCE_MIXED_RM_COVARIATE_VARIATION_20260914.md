# 혼합 반복측정 공변량 변동 검사 간소화

2026-09-14. `R/analysis_mixed_rm_anova.R`의 `mixed_rm_reduced_covariates()`에서 유한한 숫자의 전체 고유값 목록을 생성하던 부분을 첫 값과 다른 값의 존재 여부 검사로 바꿨다. 숫자 변환, 유한값 필터, 범주형 처리 및 모델 계산은 유지한다. 이전에 적용한 조정 평균 모형 재사용도 유지한다.

## 측정

기존 버전은 `output/mixed-rm-covariate-variation-20260914/baseline-analysis.R`에 보관했다. 분석은 2,000명, 4집단, 6시점, 숫자 공변량 1개, Holm 사후 비교 조건이다. 버전당 새 R 프로세스 3개를 순차 실행했고 두 번째 쌍은 순서를 뒤집었다. HTML 생성 시간은 분석 시간에서 제외했다.

| 분석 시간 중앙값(초) | 기존 | 변경 |
|---|---:|---:|
| 첫 실행 | 0.81 | 0.78 |
| 반복 실행 | 0.32 | 0.32 |

전체 분석의 확실한 속도 향상을 주장할 수준은 아니다. 검사 함수만 1,000회 호출한 시간의 3회 중앙값은 다음과 같다.

| 행 수 / 입력 | 기존(초) | 변경(초) |
|---|---:|---:|
| 2,000 / 난수 | 0.05 | 0.02 |
| 10,000 / 난수 | 0.16 | 0.07 |
| 100,000 / 난수 | 1.47 | 0.43 |
| 2,000 / 상수 | 0.05 | 0.03 |

국소적인 작업 감소와 코드 간소화로 적용한다. 메모리 사용량은 측정하지 않았다.

## 검증과 한계

- `check.R`: 빈 벡터, 결측, NaN, 무한대, 부호 있는 0, 매우 작은 값, 인접 부동소수점, 문자, 복소수, 범주형 및 무작위 입력 총 1,014건에서 반환 데이터프레임 `identical()` 통과.
- 실제 분석 3쌍에서 전체 결과는 허용오차 0(`check.environment=FALSE`) 비교 통과. HTML 문자열, 경고·메시지·표준출력 및 난수 상태도 동일.
- `validate.R`: 공변량 없음, 범주형, 공선성, 결측, 집단 순서, 두 시점, 단일 집단, 상수, 소수점 구분자, 영어, 보고서 모드를 포함한 12개 시나리오의 계산 결과 및 조건 동일. 공선성과 단일 집단은 기존과 같은 분석 오류가 반환된 경우이며 성공한 분석으로 세지 않는다.
- 보고서 모드는 변경 전후 모두 `saved_results_report_cover()`의 `saved_time` 미정의 오류가 발생했다. HTML 오류 문구의 동일성을 확인한 것이며 보고서 생성 성공을 의미하지 않는다. 이 파일은 이번 변경 대상이 아니다.
- 일반 현재·누적 HTML은 바이트 단위 동일. Excel은 패키지 타임스탬프를 제외한 내용 동일. 출력 생성 코드는 변경하지 않았으며 이번 단계에서 PDF/Word/HWPX는 재검증하지 않았다.

재현 스크립트, CSV, 결과 RDS는 `output/mixed-rm-covariate-variation-20260914/`에 있다. 빌드·배포는 하지 않았다.
