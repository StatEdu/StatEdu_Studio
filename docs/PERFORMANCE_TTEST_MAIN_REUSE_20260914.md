# 추가 요약표의 비모수 주 검정 재사용 — 2026-09-14

## 적용 결과

추가 평균·표준편차 표를 생성할 때 Mann–Whitney/Wilcoxon 또는 Kruskal–Wallis의 원시 검정 결과도 같은 분석 안에서 재사용하도록 적용했다. 사후검정 재사용이 이미 적용된 기준본 대비, 2만 행·4집단 연속값 자료의 전체 분석 중앙 시간은 **0.28→0.22초(약 21%)**, 8집단은 **0.46→0.40초(약 13%)**였다.

실제 제품 경로의 18회 중 17회가 단축됐고, 4집단 동순위 자료의 한 번은 0.10→0.11초로 증가했다. 여섯 조건의 중앙값은 모두 줄었다. 새 개선율은 이전 사후검정 최적화가 포함된 기준과의 비교다.

## 구현

`R/analysis_ttest_anova.R`의 재사용 로직을 `ttest_cached_nonparametric_test()`로 공통화하고 기존 사후검정용 생성 함수를 유지했다. `ttest_nonparametric_main_test()`는 기존 두 검정의 formula와 옵션을 그대로 호출한다. 선택적 함수 인수로 core와 개별 결과 생성에 전달한다.

비모수 분석·추가 평균/표준편차·중앙값/IQR 옵션이 켜진 경우에만 주 검정 캐시를 만든다. 사후검정 옵션을 꺼도 주 검정은 두 표에서 필요하므로 주 검정 재사용은 가능하다. 두 표의 요약값·표시·주석·사후표 생성은 원래 경로로 각각 수행한다.

값·집단·검정 종류가 `identical(..., num.eq=FALSE)`로 같은 경우에만 재사용한다. 경고·메시지나 RNG 변화가 있으면 저장하지 않으며 오류는 원래 처리로 전달한다. 주 검정과 사후검정은 별도 캐시이고 각각 16개 조합까지만 보관한다. 다음 최상위 분석에는 새 캐시가 만들어진다. 이 개수 제한은 바이트 제한이나 메모리 사용량 감소를 의미하지 않는다.

## 전체 실행 시간

R 4.5.3 번들. 20,000행, 2/4/8집단. `y=rnorm(20000)+g*.3` 또는 그 값을 반올림한 동순위 자료. 데이터 seed 939, capture seed 718. 비모수·사후검정·추가 평균/표준편차 옵션을 켜고 전체 분석을 측정했다.

3개의 새 R 프로세스를 순차 실행하고 각 조건에서 기존/현재를 예열했다. 두 번째 프로세스는 집단 수 및 기존/현재 순서를 뒤집었다. 단위는 초다.

| 집단 수 | 자료 | 기존 1/2/3 | 현재 1/2/3 | 중앙값 기존→현재 |
|---|---|---|---|---|
| 2 | 연속값 | 0.22 / 0.22 / 0.23 | 0.20 / 0.17 / 0.19 | 0.22→0.19 |
| 2 | 반올림 | 0.08 / 0.08 / 0.08 | 0.06 / 0.06 / 0.06 | 0.08→0.06 |
| 4 | 연속값 | 0.28 / 0.27 / 0.29 | 0.22 / 0.20 / 0.22 | 0.28→0.22 |
| 4 | 반올림 | 0.13 / 0.12 / 0.10 | 0.11 / 0.11 / 0.11 | 0.12→0.11 |
| 8 | 연속값 | 0.46 / 0.47 / 0.45 | 0.39 / 0.42 / 0.40 | 0.46→0.40 |
| 8 | 반올림 | 0.23 / 0.22 / 0.22 | 0.20 / 0.20 / 0.19 | 0.22→0.20 |

초기 후보 측정은 지역 환경의 함수 복사본을 이용한 별도 3개 프로세스에서 수행했다. 초기 18회에서는 단축 또는 동률이었고, 제품은 선택적 함수 인수로 연결한 후 위 표처럼 다시 측정했다. 초기·제품 측정값을 섞어 중앙값을 계산하지 않았다. 짧은 실행은 타이머 해상도와 환경 변동의 영향을 받으며 다른 자료에서 같은 비율을 보장하지 않는다. 메모리·앱 로딩 시간은 측정하지 않았다.

## 정확성 검증

`scripts/validate_ttest_main_reuse.R`:

- 원시 주 검정 50조건: 2/4집단 × n=0/1/4/100/20000 × 정규/동순위/상수/NA/Inf. 원래 formula 호출과 새 제공 함수의 전체 `htest` 또는 기존 오류를 비교했다. 통계량·자유도·p값·이름·클래스·진단이 일치했다.
- 전체 결과 48조건: 2/4/8집단 × 일반/동순위/결측/상수 × 추가 표 켬/끔 × 모수/비모수. 각 자료에 종속변수 2개와 효과크기 옵션을 포함했다. 주 검정 캐시만 끈 기준 경로와 비교했다. 정상 자료에서 결과가 생성됨도 확인했다.
- 실제 분석에 quiet/경고/메시지/RNG/오류를 넣은 통합 10조건: quiet일 때만 주 검정 호출이 **2→1회**, 나머지는 **2회 유지**됐다. 재사용된 원시 `htest`는 원래 두 결과와 정확히 같았다. 다음 분석에서 한 번 새로 실행되는 것도 확인했다.
- 모든 비교에 `identical(..., num.eq=FALSE)`를 사용했다. 반환 객체 정규화나 수치 허용 오차 없이 전체 결과, 진단 클래스·문구, 표준출력, RNG를 비교했다.

공통 캐시로 정리했으므로 `scripts/validate_ttest_pairwise_reuse.R`도 재실행했다. 기존 전체 48조건, 원시 p행렬 및 호출 2→1, 입력 키·16개 제한·경고/메시지/RNG/오류 처리를 모두 통과했다. 연구/제품 측정의 예열·실측 전체 결과도 기준본과 일치했다. 수정 파일 `git diff --check` 통과.

UI·결과 구조·내보내기는 변경하지 않았으며 문서 변환과 설치 파일 빌드는 재실행하지 않았다.
