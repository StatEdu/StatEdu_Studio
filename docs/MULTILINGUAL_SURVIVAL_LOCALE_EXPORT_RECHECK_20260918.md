# 생존분석 언어 재전환 및 그림 포함 저장 검증

제품 코드·번역 사전 변경 없이 결과 렌더링과 저장 경로를 재검증했다.

## 언어 전환

`validate_survival_dynamic_locale.R`의 기존 한국어·영어 Cox/시간가변 Cox/Fine–Gray 진단 검사를 통과했다. 최초에는 영어 본표 주석의 문장 끝 마침표를 요구하는 오래된 조건이 실패했다. 현재 공통 주석의 구분 방식에 맞게 말미 마침표 조건을 제거하되 문장 본문과 중복 방지 검사는 유지했다.

검사를 확장하여 한 번 적합한 기본 Cox, 시간가변 Cox, Fine–Gray 결과를 영어→한국어→일본어→중국어→스페인어→프랑스어→독일어→베트남어→한국어→영어 순으로 렌더링했다. 총 30개 패널에서 다음을 확인했다.

- 영어 본표의 언어 메타데이터와 전체 표 텍스트 동일성.
- 부록 표의 언어 메타데이터 및 분석 개요 제목 전환.
- 모든 단계에서 원본 적합 결과 객체 보존.

렌더링 함수와 앱 언어 옵션을 변경한 검사이며 실제 브라우저 언어 선택 메뉴를 클릭한 검사는 아니다. 기존 검사는 한국어·영어의 주석·진단 근거도 확인하지만, 새 8개 언어 순회가 모든 문장의 번역 품질을 검증한다는 의미는 아니다.

## 그림 포함 현재·누적 저장

`validate_survival_multilingual_exports.R`로 일본어 KM 결과와 실제 곡선 4개(생존, 사건, 누적위험, 로그생존)를 캡처했다. 현재 결과와 동일 결과를 두 번 담은 누적 결과를 HTML/PDF/DOCX/HWPX/XLSX로 저장했다.

- HTML/Word/HWPX/Excel에서 캡처한 제목·열·셀 값 보존 검사 통과.
- Word/HWPX/Excel 파일 안에 그림이 포함되는지 검사 통과.
- `validate_multilingual_pdf.py`: 현재·누적 PDF의 캡처 제목·셀 값 및 표지 검사 통과.
- 저장은 이미 생성한 결과와 그림을 사용하며 저장 단계에서 분석을 다시 실행하지 않는다.

저장 산출물은 `tmp/survival-multilingual/ja-current.*`, `ja-accumulated.*`이다. 로그는 `tmp/survival-multilingual-recheck.log`와 `tmp/survival-dynamic-locale-recheck.log`에 있다.

## 범위

이번 그림 포함 저장 검사는 일본어 KM 결과에 한정한다. 모든 언어·모형의 전체 저장 검증, PDF 그림의 픽셀 비교, 문서 앱별 수동 시각 검토는 수행하지 않았다. 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 패널 제외 원칙을 유지한다.
