# KR-20 문항 삭제 추정의 선택적 생략 — 2026-09-13

이분형 문항의 신뢰도 분석에서 문항-총점 상관만 요청해도, 표시하지 않는 문항 삭제 시 KR-20을 모든 문항에 대해 계산하던 부분을 제거했다. `method == "kr20"`이면서 `reliability_if_deleted`가 꺼진 경우에만 생략한다. 원래 전체 KR-20과 문항-총점 상관, 수정 문항-총점 상관은 같은 코드로 계산한다.

진단 함수의 새 인수는 기본값 TRUE이므로 기존 직접 호출을 유지한다. Pearson·ordinal 경로는 기존 추정 호출과 난수 동작을 유지한다. 문항 삭제 결과를 요청하면 KR-20도 그대로 실행한다.

## 측정

동봉 R 4.5.3, 앱처럼 설정을 적용한 2,000행 이분형 합성 자료, 문항-총점 상관만 선택. 변경 전후 순서를 교대로 5회 측정한 `prepare_reliability_results()` 전체 중앙값이다.

| 문항 수 | 변경 전 | 변경 후 |
|---|---:|---:|
| 20 | 0.03초 | 0.03초 |
| 50 | 0.14초 | 0.06초 |

50문항에서 약 57% 감소했다. 20문항에서는 측정 시간 차이가 없었다. 다른 측정 수준이나 문항 삭제 추정을 선택한 분석에는 이번 가속이 적용되지 않는다.

## 검증

- `validate_kr20_unused_deletion.R`: 변경 직전 실제 소스와 34개 전체 반환값·속성·경고·메시지·오류·난수 상태를 `identical(..., num.eq=FALSE)`로 비교해 통과했다.
- 숫자/문자/요인형 이분 자료, 2문항, 결측, 상수, 잘못된 세 범주, 빈 자료, 두 출력 옵션의 네 조합을 포함했다. 연속형·순서형의 문항-총점만 요청하는 사례도 정확 일치했다.
- 6문항 상관만 요청 시 신뢰도 값 계산 1회, 삭제 추정 요청 시 7회임을 계측했다.
- `validate_reliability.R` 통과.
- 화면·저장 HTML 정확 일치, Excel 모든 시트 내용 일치 확인.

표시·저장 내용 구성은 변경하지 않았다. 위 시험 범위의 정확 일치 검증이며 모든 입력에 대한 불변 증명은 아니다. 설치 파일은 재빌드하지 않았다.
