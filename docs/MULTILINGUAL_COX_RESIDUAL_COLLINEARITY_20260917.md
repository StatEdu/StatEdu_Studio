# Cox 잔차·공선성 보조표

6개 추가 언어에 8개 번역 항목을 추가했다. 설계행렬 열, 추정 불가, 공선성·잔차분포
검토 제목, 잔차 종류, 조건수 설명과 잔차 요약 설명이 대상이다. 한국어 잔차 종류도
보완했다. 조건수 설명은 번역 템플릿을 선택한 뒤 원래 표시 정밀도의 수치를 삽입한다.

공선성 표의 Design column 열에 사용자 데이터 보존 속성을 부여하여 변수명이
Review, Normality 등 번역 가능한 문구와 같더라도 변경되지 않도록 했다.

## 검증

- `validate_cox_residual_collinearity_i18n.R`: 실제 Cox 적합 결과와 표시용 복사본을
  8개 언어로 검증. 복사본은 사용자 변수명 및 4가지 검토 상태를 포함하며 별도 적합은 아니다.
- 수치·조건수·행 표시, 사용자 변수명 보존, 보조표 제목/설명 번역 및 본 표 영어 유지 통과.
- `validate_cox_influence_i18n.R` 회귀 검사 통과.
- 일본어 현재 4개 표 / 누적 6개 표의 HTML/PDF/Word/HWPX/Excel 내보내기 통과.
  PDF 본문·표지, 표 순서 및 Excel 시트 수 검사 통과. 저장 시 재적합하지 않는다.

설치본은 생성하지 않았다. 함수형태 도표 설명 및 비례위험 상세 진단 등 다른 생존분석
출력의 미점검 영역은 남아 있으며 전체 다국어 완료를 의미하지 않는다.
