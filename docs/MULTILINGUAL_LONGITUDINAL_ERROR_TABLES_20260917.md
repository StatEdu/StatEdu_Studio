# 종단 보조표 오류 상세 번역 — 2026-09-17

종단 보조표 텍스트 경로에서 등록된 실행 오류 번역 함수를 재사용하도록 연결했다. 알림에만 번역되던 오류가 보조표에 기록된 경우에도 UI 언어를 따른다. 사용자 데이터 열 보존은 기존 표 계약을 유지한다. 미등록 외부 오류는 원문 그대로다.

`validate_longitudinal_error_exports.R`은 실제 가중치 오류로 생성된 skipped 표와 등록된 고정 오류 상세 시험표를 렌더링한다. 오류 문장과 동일한 사용자 변수 문자열이 번역되지 않음, 상세만 번역됨, 영어 본표와 원본 객체 보존을 8언어에서 확인했다. 한국어·일본어 현재/누적 HTML·PDF·Word·HWPX·Excel의 캡처 텍스트 보존을 검사했다. PDF 현재 4쪽·누적 7쪽이며 그림 없는 표 시험이다.

`validate_longitudinal_error_pdf.py`의 PDF 추출 비교는 공백·Unicode NFKC와 전각 슬래시가 추출된 U+2215 표기를 정규화한다. 일본어 제목의 슬래시 표기 차이 외 텍스트 누락은 없었다. 페이지별 시각 검토와 실제 브라우저 조작은 수행하지 않았다.

기존 `validate_longitudinal_structural_i18n.R`의 실제 GEE/LMM/패널 고정효과 결과와 사용자 라벨 회귀 검사도 실행한다. 이번 범위는 오류 상세 연결이며 보조표의 모든 상태 셀·복합 경고 완료를 뜻하지 않는다. 메타분석은 제외하고 설치본은 만들지 않았다.

위 자동 검사와 기존 결과 회귀 검사는 모두 통과했다. 산출물: `tmp/longitudinal-error-exports`.
