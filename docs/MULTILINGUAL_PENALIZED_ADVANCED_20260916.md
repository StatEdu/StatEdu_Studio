# 규제회귀 고급 옵션 실제 실행

2026-09-16. 설치본은 만들지 않았다.

- 90행 범주형/연속형 자료에서 세 방법의 2회 반복 nested CV를 실행했다. LASSO/Elastic Net은 20회 표본 분할로 개별 대비 및 범주형 전체 검정을 실행했다. Ridge는 기존 동작대로 선택 후 검정을 적용하지 않았다.
- 진단표 항목 4개와 상태 6개를 번역했다. 프랑스어 `Tested` 상태가 공통 변환 후 `Test`로 바뀌는 문제를 발견해, 진단 Status 열의 알려진 값은 원본에서 직접 번역하도록 수정했다.
- `scripts/validate_penalized_advanced_i18n.R`: 8개 언어 통과. 모든 본표 셀/주석/영어 속성, 실제 진단표 7개, 각 검정 진단 분할 수 합계 20, 상태 번역, 사용자 종속변수 라벨 `Tested` 보존을 확인했다.
- 검정 완료 이외의 실패 상태는 문구 fixture로 검사했으며 실제 실패를 모두 유발하지는 않았다. bootstrap 2회·CV 2회는 출력 검증용이다.
- 기존 세 방법 기본 다국어 검사 및 i18n 계약 검사 통과.
- 실제 일본어 진단표와 드문 상태 fixture의 현재·누적 HTML/Word/HWPX/Excel 내용 비교, PDF 생성 및 실제 PDF 텍스트 비교 통과. 저장 fixture는 이번 변경 대상 진단표에 한정되며 전체 도표는 포함하지 않았다.
- 계산 및 검정 임계값은 변경하지 않았다. 엔진 심층 오류, 브라우저 언어 왕복·도표는 추가 점검 대상이다. 전용 검증 근거 필요 화면 수는 19개로 유지된다.
