# 다국어 재점검 — 본 표와 UI 언어 분리

## 적용 기준

2026-09-16 사용자 지시를 기준으로 재점검했다.

| 대상 | 언어 |
|---|---|
| 분석 결과 본 표의 제목·머리글·시스템 문구·주석 | UI와 관계없이 영어 |
| 분석 메뉴, 설정 블록, 옵션 | 선택한 UI 언어 |
| 보조표·진단표·민감도표와 해당 제목·설명 | 선택한 UI 언어 |
| 사용자 변수 이름·변수 라벨·범주/값 라벨 | 입력된 원문 유지 |

`Normality`, `Yes`, `Status`처럼 앱 번역 문구와 같은 사용자 라벨도 번역하면 안 된다. 기존 출판용 주그림 영문 규칙은 유지한다.

## 완료 여부

**전체 다국어 작업은 아직 완료되지 않았다.** 사전 키가 존재하거나 표에 `data-result-table-language="ja"`가 붙어 있다는 사실만으로 실제 문구의 번역을 보장할 수 없다.

328개 R 소스를 구문 분석하여 영어/한국어 문구 사용 위치 4,012개를 점검했다. 수정 후에도 6개 추가 언어 중 사전값이 없는 서로 다른 원문 후보가 2,203개 남는다. 이 수에는 본 표의 정상적인 영어, 비활성 분기, 별도 처리되는 문구도 포함되므로 **확정된 미번역 건수로 해석하면 안 된다.** 반대로 동적으로 조합되는 문장과 JavaScript 문구는 이 숫자에 모두 잡히지 않는다.

## 이번에 확인하고 수정한 문제

1. 공통 보조표 변환과 여러 분석별 후처리가 모든 문자열 셀을 번역하여, 사전 문구와 같은 사용자 변수명/범주값까지 바꿀 수 있었다. 열의 역할과 개요표의 행 역할에 따라 원자료를 보존하도록 수정했다. 숫자·논리값과 행렬의 사용자 축 이름도 보존한다. 특수한 표는 `result_user_columns`, `result_user_headers`로 사용자 데이터 위치를 명시할 수 있다.
2. 구조방정식 보조표는 한국어 이외에서 번역 경로를 건너뛰었다. 공통 번역 사전에 등록된 머리글·셀·제목·주석을 적용하도록 연결했다. 구조방정식의 상세 전문 문구 전체를 번역한 것은 아니다.
3. 메타분석 보조표는 추가 언어의 표시 언어 속성만 설정하고 내용 번역은 생략했다. 영어 원본에서 추가 언어로 번역하도록 연결하고 보조표 제목도 공통 사전을 사용하게 했다. 본 표는 이 경로에 들어가지 않는다.
4. ANCOVA 개요 보조표를 전치할 때 `Item` 머리글을 영어로 다시 만들었다. 보조표인 경우 UI 언어를 적용했다.
5. 실제 출력에서 확인한 연구·예측변수·CI 상하한·검열·분석 행·근거·안내·잔차 검정 등 공통 머리글과 보조표 제목 41개를 8개 언어의 사전에 보완했다.

## 실행 검증 범위

| 분석 | 본 표 제목·머리글·셀·공유 주석의 영문 기준 동일성 | 보조표 |
|---|---|---|
| 빈도/기술통계 | 8개 UI 언어 통과 | 테스트 대상은 본 표 |
| 대응표본 | 8개 UI 언어 통과 | 언어 속성 및 사용자 라벨 보존 검사 |
| 반복측정 | 8개 UI 언어 통과 | 상세 판정 문구에 남은 번역 후보 있음 |
| ANCOVA | 8개 UI 언어 통과 | 머리글 수정, 상세 진단 문장 추가 작업 필요 |
| 혼합 반복측정 | 8개 UI 언어 통과 | 상세 안내의 추가 문맥 검토 필요 |
| 생존분석(Kaplan–Meier) | 8개 UI 언어 통과 | 공통 머리글 보완, 안내·판정·추천 문구 남음 |
| 메타분석 | 8개 UI 언어 통과 | 공통 번역 연결, 상세 해석·민감도 문구 남음 |
| 회귀(3블록 fixture) | 8개 UI 언어 통과 | 공통 진단 및 라벨 충돌 검사 |

이 결과는 각 분석의 대표 fixture에 대한 결과이다. 모든 추정법·옵션 조합, 모든 오류/경고 경로, 모든 분석 모듈의 완성을 뜻하지 않는다.

- 16개 보조표 변환 함수에서 8개 언어로 사용자 변수명·범주값 충돌, 개요표의 변수 지정값, 숫자와 결측값 보존을 확인했다. 상태 문구 `Adequate`는 UI 언어로 번역되는 것도 별도로 확인했다.
- 구조방정식 공통 보조표 컴포넌트의 제목과 사용자 셀 보존을 검사했다. 이번 차수에서 실제 SEM/PLS 모델 전체를 언어별로 재실행하지는 않았다.
- 현재·누적 HTML/PDF/Word/HWPX/Excel로 본 표와 보조표를 함께 저장했다. 사용자 문자열과 번역 문구를 대조했으며 PDF 실제 텍스트와 표지도 검사했다.
- 사전 계약, 기존 다국어 검사, 생존/메타 설정 검사 및 `git diff --check` 통과.

## 추가 작업 목록

- 생존분석: 사건코드 매핑, 코드 확인 알림, 추천 근거, 사전검사/제외 사유, 상세 안내.
- ANCOVA·반복측정: 조합되는 가정 판정과 사후분석 문구. 예: `Sphericity met`, `not checked`, `No clear slope heterogeneity`.
- 종단·일반화·로지스틱: 모형 선택 이유, 진단·민감도 문장, 권장 보고문.
- SEM/PLS-SEM: 고급 추정 옵션, 불변성, 국소 적합도, 신뢰도/타당도, Bootstrap 상세 안내.
- 메타분석: 민감도 및 상세 해석·가정 안내.
- 아직 실제 화면에서 확인하지 않은 동적 메뉴/옵션·모달·오류 알림, 언어 왕복 후의 각 분석별 결과 상태.

표준 통계 기호(`VIF`, `Hedges' g`)와 사용자 라벨(`Yes`, `Normality`)은 미번역으로 분류하지 않는다. 본 표를 UI 언어로 번역하는 방식으로 누락을 없애서는 안 된다.
