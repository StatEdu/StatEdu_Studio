# 연속형 기술통계 세로 배치

연속형 기술통계 표와 외부 섹션에 세로 방향을 명시하고, 10개 열의 폭을 항목별로 배분했다. 계산 및 셀 내용은 유지한다. 표의 옵션에 따라 포함된 열의 가중치를 사용한다.

`scripts/validate_descriptive_portrait.R` 최종 실행: 저장소 HS100 9개 연속형 변수, 통계 10열. 화면/저장 HTML 셀 및 분석 직렬화 불변, 현재·누적 HTML/PDF/Word/HWPX/Excel 생성, 문서·Excel 내용과 방향 검사 통과. PDF의 전체 페이지가 세로임을 확인하고 표 페이지를 렌더링해 열 배치를 검토했다. 산출물: `output/descriptive-portrait-20260915/`.

초기 검증 자료 로딩 및 구분자 오류는 수정하고, 숫자 변수 9개·통계 열 10개 단언을 추가하여 재실행했다. 초기 산출물을 검증 근거로 사용하지 않는다.

이번 변경은 소스에 반영됐으며 아직 설치 파일에 재포장하지 않았다. 교차분석 글꼴은 변경하지 않았다. 교차분석 기본 본문은 12px, 머리글과 주석은 11px이며 화면 확대 설정이 실제 표시 배율에 영향을 준다.
