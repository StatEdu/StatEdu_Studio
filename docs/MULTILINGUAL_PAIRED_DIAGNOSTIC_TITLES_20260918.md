# 대응표본·반복측정 진단 부록 제목 번역

## 변경

실제 결과에서 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남던 제목 3개를 재현하고 8개 언어 사전에 반영했다.

- Warnings / skipped repeated-measures rows: 경고 / 제외된 반복측정 행
- Skipped pairs: 제외된 쌍
- Skipped repeated-measures rows: 제외된 반복측정 행

기존 영어·한국어 표현을 유지했다. 사전 외 제품 계산·렌더링·저장 코드는 변경하지 않았다.

## 검증

- `validate_paired_diagnostic_titles_i18n.R`: 반복측정, 비모수 대응표본, 비모수 반복측정의 정상 행과 변수 누락 행을 실제 분석했다. 세 결과에 제외 행이 있음을 먼저 확인하고 전체 결과 패널의 h3 제목을 8개 언어로 검사했다.
- 영어 본표 동일성과 원본 결과 객체 보존 검사 통과.
- `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용과 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-diagnostic-titles-i18n/exports`. 이미 생성한 캡처를 저장하며 저장 단계에서 분석을 재실행하지 않는다.

## 범위

이번 번역은 진단 부록 제목 3개에 한정하며, 다른 분석명 후보까지 완료됐다는 의미는 아니다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙을 유지한다.
