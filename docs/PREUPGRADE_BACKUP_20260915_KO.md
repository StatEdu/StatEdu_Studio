# 실제 설치 상태의 사전 백업 확인

현재 PC에 등록된 설치는 개발판 1.2.4-dev(사용자 설치)와 정식판 1.3.0(전체 사용자 설치)이다. 설치·제거 프로그램은 실행하지 않았다.

실제 설치 경로의 누적 이력 1파일과 기존 프로필의 설정 6파일을 `output/preupgrade-backup-20260915/`에 복사했다. 각 파일의 복사 전 원본, 복사본, 복사 후 원본 SHA256이 일치했다. 전체 경로·크기·해시는 백업 폴더의 `manifest.json`에 기록되어 있다. 데이터셋이나 사용자 지정 외부 모델 파일 전체의 백업은 아니다.

백업 이력은 현재 코드로 읽기 및 저장/재읽기가 정확히 일치했다. 이 파일의 결과 항목은 **0개**였다. 따라서 실제 사용자 분석 결과가 담긴 이력의 호환성 검사로 확대하지 않는다. 내용이 있는 합성 이력의 기본 프로필 복원 검사는 `UPGRADE_FIXES_20260915_KO.md`의 별도 증거다.

로컬 electron-builder NSIS 템플릿은 기존 버전 제거를 새 파일 설치보다 먼저 실행한다. 기본 제거 코드는 설치 디렉터리를 제거하므로 이전 설치 영역의 이력은 사전 보존이 필요하다. 새 앱 실행 후의 이관만으로 이미 제거된 파일을 보호하지 못한다.

이번에 추가한 `scripts/backup_installed_upgrade_state.ps1`은 지정된 설치/프로필의 이력·설정만 새 백업 폴더로 복사하고 해시를 확인한다. 기존 백업 폴더는 거부한다. 설치·제거·원본 수정 기능은 없다. `scripts/validate_preupgrade_backup.R`은 이번 백업의 읽기 및 재저장 검증이다.

남은 실제 설치 교체 시험에는 별도 Windows 환경이 필요하다. 이 PC에서 사용 중인 설치를 교체하지 않았고, 개발판과 정식판을 동일 업데이트 경로로 간주하지 않았다. 제품 코드와 배포 설치 파일은 이번 단계에서 변경하지 않았다.
