# 다국어 작업 현황 재정리 — 2026-09-17

## 판단

주요 분석군의 대표 UI·결과·저장 검증은 진행되어 있으나 전체 앱의 다국어 완료는 아니다. 최근 작업은 생존분석 상세 진단과 구조방정식 보조표·오류·상태 문구에 집중되었다. 과거 2026-09-16 현황표의 ‘Cox·경쟁위험 실제 결과 검증 필요’ 등은 현재 근거를 반영하지 못하므로 이 문서를 우선한다.

원칙은 본 표 영어(사용자 변수명·라벨 제외), 메뉴·블록·옵션·보조표 UI 언어, 사용자 데이터 원문 보존이다. 대상은 한국어·영어·일본어·중국어·스페인어·프랑스어·독일어·베트남어다. 설치본 생성 및 설치 앱 변경은 하지 않았다.

설정·데이터 파일 창의 영어 고정 제목/파일 형식 설명도 8언어로 연결했다. 현재 세션 언어 전달과 OS 경계 인자 검사는 통과했으나 실제 네이티브 창 표시·클릭 검증은 미완료다 (`MULTILINGUAL_FILE_DIALOGS_20260917.md`).

복합표본 설계 파일 열기·저장 및 기본 저장 폴더 선택 창도 같은 방식으로 8언어 연결과 인자·필터·취소 검증을 완료했다. 실제 네이티브 창 검증과는 구분한다.

ID 집계의 통계량·미리보기·완료 안내 등 15개 문구를 8언어에 연결하고 완료 문구가 현재 언어를 따르도록 수정했다. 실제 집계/서버 검사로 사용자 이름·값 보존과 언어 변경 시 데이터 재생성 없음도 확인했다. 조건식/집계 오류와 브라우저 입력 상태·DT 컨트롤은 별도 남아 있다 (`MULTILINGUAL_ID_AGGREGATE_UI_20260917.md`).

ID 집계 조건식/입력 오류 12개도 8언어로 연결했다. 실제 오류 발생 및 미리보기/생성 알림의 현재 언어 전달, 사용자 변수명·파서 상세 보존을 확인했다 (`MULTILINGUAL_ID_AGGREGATE_ERRORS_20260917.md`).

ID 집계의 언어 변경 시 값 변수가 초기화되는 문제도 수정했다. 8언어 브라우저 왕복에서 입력 6개·미리보기 데이터·사용자 출력 이름 유지와 DT 검색/페이지 문구를 확인했다. 일본어에서는 실제 검색·페이지 이동도 통과했다 (`MULTILINGUAL_ID_AGGREGATE_BROWSER_20260917.md`). 다른 데이터 편집 메뉴 전체 검증은 남아 있다.

## 작업한 범위와 남은 범위

데이터 병합의 7개 입력 오류와 교체 불가 안내를 8언어로 연결했다. 실제 오류 및 서버 알림, 사용자 변수명 보존, 정상 변수/케이스 병합 회귀 검사가 통과했다. 병합 설정·요약 표·DT·언어 왕복은 후속 범위다 (`MULTILINGUAL_MERGE_ERRORS_20260917.md`).

이어 병합 UI 29개 키·요약 표·DT·완료 안내의 현재 언어 표시와 파일/입력 보존을 수정했다. 케이스 병합의 선택 변수가 전체 선택으로 돌아가는 문제도 해결했다. 8언어 UI/서버 검사 및 합성 CSV를 이용한 대표 브라우저 언어 왕복을 검증했다 (`MULTILINGUAL_MERGE_UI_20260917.md`). 다른 파일 형식과 전체 병합 조합 검증은 남아 있다.

변수 병합의 left/inner/full 세 방식과 동일 파일명 자료 교체도 8언어 브라우저 검증 범위에 추가했다. 파일/설정 변경 시 이전 미리보기가 남는 문제를 수정하고, 언어만 변경할 때는 미리보기를 유지한다 (`MULTILINGUAL_MERGE_VARIABLES_20260917.md`). CSV 외 파일 형식별 실제 브라우저 검증은 남아 있다.

SAV·SAS7BDAT·XPT·DTA·XLSX와 DAT 공백/탭/쉼표의 8개 경로도 검사했다. 실제 읽기와 변수/케이스 병합 함수 검사, 8언어 × 8개 경로의 full 변수 병합 브라우저 검사 64개 조합이 통과했다 (`MULTILINGUAL_MERGE_FORMATS_20260917.md`). 구형 XLS·무헤더·인코딩/날짜/라벨 속성 등 다른 조합은 아직 별도 검증 범위다.

무헤더 CSV·DAT 4개 경로도 8언어 브라우저 검사 32개 조합을 통과했다. 헤더 옵션의 체크 해제 상태·첫 데이터 행·자동 변수명·상태 번역과 옵션 변경 후 복구를 확인했다 (`MULTILINGUAL_MERGE_HEADERLESS_20260917.md`). 병합 대표 경로 검증 뒤의 다음 대상은 와이드→롱 변환의 원문 오류 알림이다. 구형 XLS 및 날짜·인코딩·라벨 속성 전체 조합은 별도 미검증으로 남긴다.

와이드→롱 오류 8종을 8언어로 연결하고 실제 오류·서버 알림을 검증했다. 와이드→롱/병합 지시값에서 소문자 r/n을 잘못 나누던 문제와 수동 시점 줄바꿈도 수정했다 (`MULTILINGUAL_WIDE_LONG_ERRORS_20260917.md`). 와이드→롱 브라우저 언어 왕복·입력 상태·동적 완료 문구·표 컨트롤은 후속 범위다.

와이드→롱의 미적용 입력값이 언어 변경 후 이전 값으로 돌아가는 문제를 수정했다. 옵션 탭·직접 입력한 반복 횟수·설정 그룹을 보존하고, 상태 안내와 미리보기 검색 문구에 현재 UI 언어를 적용했다. 실제 서버의 8언어 상태 검사와 대표 브라우저 왕복을 검증한다 (`MULTILINGUAL_WIDE_LONG_BROWSER_20260917.md`). 다중 그룹 편집·동일 대상 구조·자료 교체·네이티브 저장 창은 별도 남은 범위다.

동일 대상 2집단×2시점의 두 그룹을 8언어에서 생성·순서 변경·삭제·재생성하고 실제 변환값을 확인했다. 입력마다 전체 화면이 재생성되어 값이 덮이는 문제와 화면 복귀 시 오래된 설정이 표시되는 문제를 함께 수정했다. 다중 그룹 검사와 기존 입력 유지 브라우저 검사 모두 통과했다 (`MULTILINGUAL_WIDE_LONG_GROUPS_20260917.md`). 같은 이름의 그룹 덮어쓰기, 포인터 드래그, 자료 교체 및 네이티브 저장 창은 별도 남은 범위다.

자료 교체 시 이전 와이드→롱 그룹과 미리보기가 남는 문제도 수정했다. 같은 이름/변수명의 새 값과 파일 경로 변경, 자체 변환 결과 연결을 구분하는 서버 검사 및 실제 업로드의 8언어 브라우저 검사가 통과했다 (`MULTILINGUAL_WIDE_LONG_DATASET_20260917.md`). 같은 이름의 그룹 덮어쓰기·포인터 드래그·네이티브 저장 창은 별도 남긴다.

같은 출력 변수명으로 기존 그룹의 원본 열을 바꾸는 경로도 8언어 서버·브라우저 검사에 통과했다. 그룹 수/ID 유지, 이전 열의 목록 복귀, 미리보기 초기화와 새 값 및 갱신/삭제 안내를 확인했다 (`MULTILINGUAL_WIDE_LONG_UPDATE_20260917.md`). 추가 제품 오류는 발견되지 않았다. 포인터 드래그·네이티브 저장 창은 별도 범위다.

포인터 드래그에서 사전 클릭 선택이 없으면 그룹 순서 변경이 무시되는 문제를 수정했다. 공통 순서 검증과 선택 동기화를 사용하며, 원본 열·설정 그룹의 실제 드래그와 변환값, 선택 표시·위/아래 버튼을 8언어에서 검증했다 (`MULTILINGUAL_WIDE_LONG_DRAG_20260917.md`). 다중 선택·긴 목록 자동 스크롤 전체 조합 및 네이티브 저장 창은 별도 범위다.

20열 목록에서 두 항목을 함께 드래그하고 하단 자동 스크롤로 이동하는 대표 경로도 8언어 모두 통과했다. 순서·다중 선택 유지와 40행의 실제 변환값을 확인했다 (`MULTILINGUAL_WIDE_LONG_LONG_DRAG_20260917.md`). 전체 스크롤/선택 조합을 망라한 것은 아니며 네이티브 저장 창은 별도 미완료다.
