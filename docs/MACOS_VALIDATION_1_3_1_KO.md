## 분석·파일 회귀

[수치 비교 결과 CSV](validation/macos-1.3.1/analysis_reference_comparison.csv)의 **66개 비교가 모두 PASS**입니다. 빈도·교차표·상관·신뢰도·회귀·로지스틱·GLM·CFA·SEM·PLS·종단·생존 등 18개 분석 메뉴의 대표 사례를 독립 기준 계산과 비교했습니다. 각 기존 허용오차를 유지했습니다.

추가로 혼합 반복측정 ANOVA, 복합표본 매개·조절모형, GEE 48개 전체 분석 사례와 462개 검증 경계, 구조모형 신뢰도·HTMT·정규성 지표 검증을 통과했습니다. CSV·Excel·SPSS·SAS·Stata·DAT 등 기존 데이터 입출력 검증, 프로젝트 재연결과 설정 선택창 계약, Word·HWPX·Excel·HTML 출력 구조·서식 검증을 실행했습니다.

PDF는 내장 Electron에서 생성한 4페이지를 이미지로 렌더링해 표지·한글·표·산점도·히트맵 배치를 확인했습니다. 실제 한컴오피스 한글 Viewer에서도 생성한 HWPX가 열리고 표와 그림이 표시되는 것을 확인했습니다. 모든 출력의 모든 페이지·분석 조합을 전수 검수한 의미는 아닙니다.

[실제 GUI 검사 요약](validation/macos-1.3.1/gui-summary.json)과 [네이티브 검사 요약](validation/macos-1.3.1/native-summary.json)을 함께 보관합니다.

맥 전용 Python 검사 38개와 JavaScript 6개 검증 스크립트가 통과했습니다. 합성 파일·모의 선택창 검사는 실제 Mac 실행·선택창 검사와 구분했습니다.

## 발견한 문제와 수정

- 내장 Rscript 버전 검사 옵션, `RHOME` 전달과 개인 R 환경 격리를 수정했습니다.
- 종료 시 저장하지 않은 변경 확인이 R을 먼저 종료하거나 앱을 막지 않도록 확인 순서를 수정했습니다.
- 파일 선택 결과의 원본 데이터 경로를 프로젝트와 저장 기본 폴더에 사용하도록 수정했습니다. 업로드 임시 파일이 없어져도 프로젝트의 포함 데이터를 복원하는 기존 동작을 유지했습니다.
- 맥 업데이트 안내가 Windows 다운로드를 가리키지 않도록 맥 브랜치·지정 HTTPS 배포 페이지로 연결합니다.
- `fs` 바이너리의 최소 OS 요구가 목표보다 높아 고정 버전을 소스로 빌드했습니다. 외부 Fortran 참조와 공식 프레임워크의 절대 심볼릭 링크도 재배치했습니다.
- 검증 기준 GLM·GEE의 수렴 옵션을 현재 앱의 기존 옵션과 맞췄습니다. 혼합 분석의 오래된 영문 기대값과 복합표본 검증의 번역 함수 로드를 보완했습니다. 제품 계산 알고리즘과 허용오차는 변경하지 않았습니다.
- Playwright가 Electron과 동시에 종료 확인을 처리하는 CDP 충돌을 피하도록 자동 시험에서 변경 플래그를 지우고 정상 종료를 검사합니다. 실제 변경 확인은 네이티브 조작으로 별도 확인합니다.

1.3.1의 기존 동작에서는 앱만 다시 시작하면 결과 모음을 복원하지만, 프로젝트를 열면 이전 분석·결과 모음을 초기화합니다. 프로젝트 파일은 데이터·설정을 복원하며 결과 모음 파일과 별도입니다. 이 동작을 변경하지 않습니다.

## 정식 배포 상태와 남은 확인

제품 기준과 앱 버전은 정식 **1.3.1**입니다. 현재 로컬 `.app`·DMG는 인증서 기반 서명·Apple 공증이 완료된 일반 배포 설치본이 아닙니다. `security find-identity`에서 유효한 코드 서명 인증서는 0개였습니다. 배포 도구를 실행했을 때 인증서·공증 프로필 누락을 확인하고 서명 없는 정식 배포 진행을 차단했습니다.

내장 R Mach-O 서명, Hardened Runtime, 앱·DMG 공증, 티켓 첨부와 Gatekeeper 검사를 수행하는 자동화는 구현했습니다. 유효한 Developer ID Application 인증서·개인 키와 Keychain 공증 프로필을 확보한 뒤 [빌드 안내](MACOS_BUILD_KO.md)의 배포 명령을 실행해야 합니다. 실제 서명·공증 성공은 아직 검증하지 않았습니다.

macOS 13 실기, 시스템 R이 없는 별도 깨끗한 Mac, 인터넷 다운로드 후 Gatekeeper 설치·실행은 미검증입니다. Intel 앱은 이번에 만들지 않았습니다. macOS 27.0.1에서의 실제 성공과 바이너리 감사를 근거로 하위 OS·Intel 지원 또는 일반 배포 완료를 선언하지 않습니다.
