# 상관분석 결과 목록 사전 할당 검토 — 2026-09-14

## 결론

변수 쌍의 결과 목록을 사전 할당하는 후보는 적용하지 않았다. 100변수에서 전체 분석 준비 시간의 중앙값 차이가 0.02초였고, 10변수에서는 차이가 없었다. 추가 인덱스 관리 코드를 유지할 만큼 충분한 이득으로 판단하지 않았다. 이번 후보만 원복하고 파일이 실험 직전과 SHA256 기준으로 동일함을 확인했다. 앞서 적용한 정규성 변환 재사용은 유지한다.

## 후보 및 측정

기존 `pair_results <- list()`와 목록 끝 추가를, `p*(p-1)/2` 크기의 목록 사전 할당 및 별도 인덱스로 대체했다. 쌍의 순서와 각 통계 계산은 변경하지 않았다.

번들 R 4.5.3과 기존 모듈 캐시를 사용해 새 프로세스에서 3쌍을 순차 실행했다. 두 번째 쌍은 순서를 반대로 했다. 변경 전후 함수 환경은 동일한 전역 환경으로 연결했다. 각 프로세스에서 100행·10변수 조건 후 100행·100변수 조건을 실행했다. Pearson, 정규성 검사 비활성 조건의 전체 결과 준비 시간이며 화면 렌더링은 포함하지 않는다.

| 변수 수 | 변경 전 중앙값(초) | 후보 중앙값(초) |
|---|---:|---:|
| 10 | 0.11 | 0.11 |
| 100 | 0.56 | 0.54 |

100변수 원자료는 변경 전 0.58/0.55/0.56초, 후보 0.56/0.54/0.54초다. 작은 감소는 관측됐지만 통계적 유의성이나 다른 환경의 효과를 입증한 실험은 아니다.

## 검증 및 자료

- 6개 자료 조건 × Pearson/Spearman/Kendall/auto × 정규성 검사 TRUE/FALSE의 48조건에서 전체 결과·진단·난수 상태가 정확히 일치했다.
- 성능 측정의 6개 결과 쌍도 `identical(...,num.eq=FALSE)`로 전체 결과·진단·난수 상태가 일치했다.
- `output/correlation-pair-allocation-20260914/`에 baseline.R, candidate.R, common.R, verify.R, measure.R, compare.R, summary.csv와 원자료를 보관했다. 원복 후 재현을 위해 common.R은 후보 파일을 명시적으로 읽는다.
