# Gamma·음이항·확률기울기 GLMM 점검표 검증 — 2026-09-17

`validate_longitudinal_checklist_models_i18n.R`에 실제 Gamma GLMM, 음이항 GLMM, 이분형 확률기울기 GLMM의 3경로를 추가했다. 각 모형에서 계수 표 반환을 확인하고 보고 점검표를 검사했다.

기존 8경로와 합쳐 11경로 × 8언어의 88개 검사가 통과했다. 점검표의 항목·상태·설명, 개별 권고와 연결된 설명, 소프트웨어명/버전 및 원본 결과 보존을 확인했다. 이번 대표 경로에서는 새로운 번역 누락을 발견하지 않았다. 시험 과정의 특이 적합 등 경고는 유지하며 정상 수렴·통계적 타당성 전체를 검증했다는 뜻은 아니다.

이번 변경은 검증 스크립트와 기록뿐이다. 제품 코드·번역 카탈로그·출력을 변경하지 않았으며 5종 저장 검사는 이번에 재실행하지 않았다. 직전 저장 검증 근거는 `MULTILINGUAL_LONGITUDINAL_GLMM_CHECKLIST_20260917.md`를 참조한다. 새 3경로의 개별 저장 파일 검증과는 구분한다.

자동 분포 선택, 다른 확률기울기/분포 조합, 점검표 외 보조표, 전체 브라우저·페이지별 시각 검토는 남아 있다. 메타분석과 설치본은 작업하지 않았다.
