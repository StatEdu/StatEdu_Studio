# Wilcoxon 사후검정과 JT 개선의 통합 검증

## 결과

Wilcoxon 독립표본 사후검정의 동점 집계 개선과 JT 추세검정의 비교 행렬 제거를 함께 적용한 현재 코드를 검증했다. 전체 분석 비교 36개가 정확히 일치했고 36개 측정 모두 빨라졌다. 이번 작업은 통합 검증으로, 프로그램 코드를 추가 변경하지 않았다.

먼저 `R` 폴더의 JT/Jonckheere 명칭과 `outer` 호출을 검색했다. 같은 JT 계산을 다른 파일에 중복 구현한 경로는 발견하지 못했다. 추세검정과 관련 효과크기 호출은 기존 공통 `ttest_jt_test`를 사용한다. 다른 목적의 공분산·거리 행렬 `outer` 호출은 이번 개선의 대상이 아니다.

## 비교 범위

변경 전은 `output/independent-wilcox-ties-20260914/baseline.R`에 보존된 소스이며, 두 개선을 모두 포함하지 않는다. 현재 소스와의 차이는 해당 두 개선뿐이다. 기존 본검정·사후검정·효과크기 재사용은 양쪽에 이미 포함되어 있다. 채택하지 않은 JT 결과 재사용 후보는 현재 코드에 없다.

현재 소스 SHA256: `BB7F3F0BA2058CEEFE03186436910EA1F36466854A8FB2B4EEF6190506A51EF4`.

## 측정 방법

4,000행, 2/4/8집단, 연속값/반올림한 동점값, 결측률 0/0.1을 조합했다. 값과 집단에 독립적으로 결측을 적용했다. 집단은 순서형으로 지정하고 비모수 분석·사후검정·추가 평균/표준편차 표·효과크기·추세검정을 켰다.

새 R 프로세스 3개에서 기존/현재 코드를 예열한 뒤 순차 측정했다. 두 번째 실행은 측정 순서를 뒤집었다. 전체 분석 및 반환값·진단·stdout·난수 상태 수집을 포함한 경과 시간이다. 함수별 계측이나 시간 합산을 사용하지 않았다.

예열·측정 반환값을 `identical(..., num.eq=FALSE)`로 비교했다. 숫자 정규화나 허용오차 없이 전체 반환값, 경고/메시지/오류 수집 결과, stdout, 난수 상태가 일치했다. 이번 통합 측정은 별도의 원시 htest 계측이나 오류 주입을 추가한 것은 아니다. 해당 세부 검증은 각 개선의 기존 검증 기록에 있다.
