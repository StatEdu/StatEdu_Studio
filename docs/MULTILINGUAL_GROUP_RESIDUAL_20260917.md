# 집단별 잔차 보조표 다국어 점검

2026-09-17

- 다집단 잔차 요약 및 큰 잔차 보조표에서 최대 절댓값 표준화 잔차, 기준 초과 잔차 수의 추가 6개 언어 번역을 보완했다. 기존 잔차 열 제목 사전을 명시적으로 적용해 절댓값 기호가 포함된 제목도 번역한다.
- 한국어 열 제목 및 표준화/상관잔차 대체 척도 설명을 적용했다. 미등록 척도 값은 원문을 유지한다.
- Indicator1/Indicator2를 사용자 데이터 보호 대상으로 추가했다. 집단명과 지표명이 사전 단어와 같더라도 변경하지 않는다. Flagged residuals는 개수이므로 정수로 표시한다. 분석 계산 및 본 표는 변경하지 않았다.
- `scripts/validate_group_residual_i18n.R`: 실제 lavaan 다집단 CFA와 기존 잔차 진단 생성기로 두 집단의 결과를 생성했다. 실제 결과, 상관잔차 대체 표시 fixture, 사용자 값 fixture, 빈 결과를 8개 언어에서 검증했다. 대체 fixture는 표시 경로 검증이며 대체 진단 계산을 유도한 것은 아니다.
- Review, Normality, 한글, <&>, %s 사용자 명칭과 미등록 척도 보존, 수치 일치, 정수 개수, TRUE/FALSE/NA 표시를 확인했다. 기존 불변성 스코어 검정 회귀 테스트 통과.
- 일본어 스냅샷으로 현재 6표, 누적 8표의 HTML/PDF/Word/HWPX/Excel을 검증했다. 내용·PDF 표지·표 순서·Excel 시트 수 검사 통과. 저장 시 재분석하지 않는다.
- 산출물: `tmp/group-residual-i18n/`. 설치본은 만들지 않았다.

전체 다국어 감사는 계속 진행 중이다. 집단별 신뢰도·수렴타당도 및 HTMT 보조표가 다음 점검 대상이다.
