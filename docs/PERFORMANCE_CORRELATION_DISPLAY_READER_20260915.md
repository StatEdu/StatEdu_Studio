# 상관분석 표시 라벨 병합 재사용

2026-09-15. `R/analysis_correlation.R`에 분석 호출별 `correlation_display_name_reader()`를 추가했다. 정규성 표, 결과 행렬의 표시 이름, 제외 변수 안내 표가 같은 조회기를 공유한다. 정상 문자형 범주 라벨 표와 일반 문자 라벨 재정의 값에서는 범주 라벨 조회 및 병합을 첫 사용 때 준비해 재사용한다.

실제 이름 선택은 기존 `display_variable_name_static()`을 사용한다. 범주 라벨·재정의 라벨·변수 정보·원래 이름 사이의 우선순위와 빈 라벨 처리를 유지한다. 특수 클래스/속성이 있는 입력은 기존 표시 이름 함수로 돌아가며, 경고나 메시지를 발생시키는 병합은 캐시하지 않아 진단 반복을 유지한다. 캐시는 분석 호출에 한정된다.

## 병목 확인

변경 전 `scripts/profile_correlation_display_labels.R`로 1,000행·선택 20변수·190쌍의 Pearson 분석과 정규성 표를 측정했다. 측정수준 정보는 20개로 고정하고 범주 라벨 표만 20/10,000행으로 달리했다. 두 독립 실행에서 중앙값은 작은 표 0.037~0.038초, 큰 표 0.114~0.117초였다. 큰 표 프로파일에서 표시 이름 함수 경로가 표본 시간의 약 72~75%였다. 표본은 0.24/0.25초로 짧아 세부 백분율은 대략적인 경로 확인용이다.

초기 프로파일 자료는 `output/correlation-display-label-profile-20260915/`에 있다. 해당 스크립트는 현재 제품을 호출하므로 적용 후 재실행 결과는 이 변경 전 기록과 달라진다. 변경 전 소스는 아래 fixture에 보존했다.

## 최종 코드 성능

`scripts/benchmark_correlation_display_reader.R`에서 서버 환경설정을 초기화하고, 변경 전/후 상관 모듈 함수를 같은 방식으로 컴파일했다. 독립 R 프로세스 3개, 사전 호출 후 순서를 교대해 조건별 3회 중앙값을 측정했다. 시간에는 전체 분석 준비와 진단/stdout 수집이 포함되며 데이터 생성과 명시적 GC는 제외된다. 모든 측정 결과도 정확히 비교했다.
