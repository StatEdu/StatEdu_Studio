# Spearman 캐시 검색 방향 검토 — 2026-09-14

후보는 적용하지 않았다. 최근 사용 항목부터 검색하면 100변수 완전 자료에서 약 0.03초 줄었지만, 결측 자료에서는 약 0.05초 늘었다. 일반적인 개선으로 판단할 근거가 부족해 현재 코드를 유지한다.

## 후보

`R/analysis_correlation.R`의 `correlation_rank_test()`에서 `seq_along(entries)`를 `rev(seq_along(entries))`로 바꿨다. 현재 캐시는 최근 사용 항목을 끝으로 이동시키므로 역순 검색은 최근 항목을 먼저 확인한다. 동일성 비교, 순위 계산, 검정식, 캐시 상한과 퇴출 순서는 그대로다. 입력 참조 재사용을 시도했던 이전 미적용 후보는 포함하지 않았다.

## 측정

번들 R 4.5.3을 사용했다. 조건별 기준/후보를 새 프로세스로 각각 3회 순차 실행했으며 두 번째 세트는 실행 순서를 뒤집었다. 입력 생성·부트스트랩·모듈 로딩·사전 GC는 시간에서 제외했다. 전체 `prepare_correlation_results()`와 결과/진단 수집을 측정했으며 Spearman, 정규성 검사 활성, 잠재 상관 비활성 조건이다. 시드 33 정규 자료, 소수 첫째 자리 반올림 동률 자료, 변수별 독립 10% 결측 자료를 사용했다.

| 규모 및 자료 | 기준 3회(초) | 후보 3회(초) | 중앙값(초) |
|---|---|---|---|
| 10,000행·20변수 완전 | 0.33 / 0.33 / 0.32 | 0.33 / 0.32 / 0.33 | 0.33 → 0.33 |
| 10,000행·20변수 동률 | 0.25 / 0.25 / 0.25 | 0.27 / 0.30 / 0.26 | 0.25 → 0.27 |
| 10,000행·20변수 결측 | 0.41 / 0.41 / 0.41 | 0.42 / 0.42 / 0.42 | 0.41 → 0.42 |
| 1,000행·100변수 완전 | 1.33 / 1.31 / 1.33 | 1.31 / 1.30 / 1.30 | 1.33 → 1.30 |
| 1,000행·100변수 동률 | 1.20 / 1.20 / 1.20 | 1.17 / 1.17 / 1.17 | 1.20 → 1.17 |
| 1,000행·100변수 결측 | 1.72 / 1.73 / 1.72 | 1.76 / 1.77 / 1.77 | 1.72 → 1.77 |

20변수는 190쌍, 100변수는 4,950쌍의 반환을 확인했다. 짧은 실행 시간의 3회 측정이므로 통계적 유의성이나 다른 환경에서의 효과를 주장하지 않는다. 역순 검색이 줄이는 비교 횟수와 역순 인덱스 생성 비용은 별도로 측정하지 않았으며, 관측된 차이의 원인으로 확정하지 않는다.

## 검증 및 적용 상태

- 전체 결과·진단·표준출력·난수 상태 26조건 일치: Pearson/Spearman/Kendall/자동 및 잠재 상관 경로 포함.
- 직접 검정 33조건 일치: 반복 호출, 오류/진단과 캐시 상한 포함.
- 실측 결과 18쌍을 `identical(..., num.eq=FALSE)`로 전체 비교해 일치. 수치 허용오차를 사용하지 않았다.
