# 계산기 입력 오류 번역 — 2026-09-17

두 작업의 병행 범위를 분리했다. 기존 다국어 작업은 종단 분석을 맡고,
IPA 작업은 분석 외 메뉴 중 계산기 입력 오류부터 점검했다. 공용 사전은
기존 작업이 `scripts/fill_calculator_errors_i18n.py`를 실행해 병합했다.

HINT8, EQ-5D, FRS, ASCVD10, 대사증후군, 대사증후군 중증도 계산기의
알림 처리기 6곳에서 등록된 앱 입력 오류를 현재 세션 언어로 변환한다.
문항 열 수, 서로 다른 변수 선택, 불러온 데이터에서 변수 누락, 필수 변수
선택의 4개 템플릿을 8언어로 연결했다. 등록되지 않은 외부 오류는 정확히
원문을 유지한다. 계산식과 데이터 값, 생성 변수명, 저장 결과는 변경하지 않았다.

검증:

- `validate_calculator_errors_i18n.R`: 실제 오류 11개 경로, 소스에서 추출한
  알림 처리기 6개 × 8언어 및 한국어 복귀 검사 통과. 외부 오류의 줄바꿈,
  사용자 이름, 기호, 정밀 숫자 보존 확인.
- `validate_calculators.R`: 6종 계산기 수치 회귀 검사 통과.
- 알림 처리기 검사는 격리된 환경에서 실행했으며 실제 브라우저 클릭/팝업
  시각 검증은 아직 수행하지 않았다. 출력 문서 내용은 이번 변경 범위가 아니다.

계산기 전체 완료를 의미하지 않는다. 문항/변수 라벨, 동적 완료 요약,
언어 전환 시 입력 유지, 표본수/효과크기 메뉴는 후속 점검 범위다.
공용 현황 문서와 종단 소스는 이쪽에서 변경하지 않았다. 설치본을 만들거나
실행 중인 웹 서버를 재시작하지 않았다.
