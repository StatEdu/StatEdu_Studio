# GEE 반복 상관행렬의 고유값 검증 재사용

## 적용 내용

`R/analysis_longitudinal.R`의 `longitudinal_gee_check_simple_correlation`에서 직전에 검증을 통과한 상관행렬과 완전히 같은 행렬이면 고유값 계산을 생략하도록 변경했다. 비교는 `identical(..., num.eq = FALSE)`로 부호 있는 0까지 구분한다.

상관행렬 생성, 유한값 검사, 고유값 계산식, 특이성 판정 임계값과 오류 문구는 유지했다. 실패한 행렬은 저장하지 않는다. 검증 함수 호출 안에서 직전 성공 행렬 하나만 보관하며 전역 캐시는 없다. exchangeable과 ar1 모두 적용되고, 행렬이 다르면 기존 검증을 실행한다. 앞서 적용한 선택 모형 재사용도 유지했다. 검토 후 거절한 QIC 내부 재적합 캐시는 도입하지 않았다.

## 성능 측정

번들 R 4.5.3, seed 936, 5,000명 × 4시점 = 20,000행, 공변량 2개, 선택 상관구조 exchangeable, 기본 분석 옵션으로 측정했다. 워밍업 후 독립 프로세스 3개를 순차 실행했으며 두 번째 프로세스는 후보부터 측정했다. 로딩 시간은 제외했다. 아래 표는 최종의 엄격한 행렬 비교 코드를 측정한 결과다.

| 전체 분석 | 변경 전 1 / 2 / 3 (초) | 변경 후 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| gaussian | 1.92 / 1.69 / 2.11 | 1.58 / 2.03 / 1.56 | 1.92 → 1.58 |
| binomial | 1.72 / 1.74 / 1.71 | 1.66 / 1.80 / 1.63 | 1.72 → 1.66 |

각 분포에서 세 번 중 두 번 빨라졌으나 두 번째 실행에서는 느려졌다. 전체 실행의 변동이 있으므로 모든 자료에서 같은 개선율을 보장하지 않는다.

별도로 5,000개의 동일한 4×4 상관행렬을 검증하는 함수만 10회 반복한 평균을 측정했다. 이 부분 시간은 전체 분석 측정과 별도이며 더하거나 빼서 전체 기여도를 계산하지 않는다.

| 검증 함수 | 변경 전 1 / 2 / 3 (초) | 변경 후 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| exchangeable | 0.053 / 0.051 / 0.053 | 0.019 / 0.019 / 0.017 | 0.053 → 0.019 |
| ar1 | 0.060 / 0.058 / 0.056 | 0.022 / 0.022 / 0.022 | 0.058 → 0.022 |

검증 함수는 모든 실행에서 빨라졌다. 별도 호출 계수 검증에서도 동일 행렬 1,000개에 대한 고유값 계산이 두 상관구조 모두 1,000회에서 1회로 줄었다.

## 동일성 검증

`scripts/validate_longitudinal_gee_matrix_reuse.R`에서 변경 전 함수를 독립 fixture `scripts/fixtures/longitudinal_gee_correlation_reference.R`로 복원하여 비교했다.

- 전체 분석 48개 조건 통과: 4개 분포, 3개 상관구조, 가중치 유무, exponentiate, Poisson offset, 경고/메시지/RNG 소비/오류 주입, random_slope TRUE, 결측 및 역순 자료를 포함한다.
- 직접 검증 함수 462개 경계 조건 통과: 유효/무효 alpha, 0과 -0, underflow, 1 근방, 특이행렬, 빈 입력, 단일 관측, 동일/변경 행렬, 결측/무한 시점, 결측 ID, factor/이름 있는 시점을 포함한다.
- 반환값의 가시성, 오류 클래스와 문구, 경고/메시지 순서, 표준 출력, RNG 상태를 비교했다. 실제 계산한 행렬 및 고유값 반환 객체도 원본 계산과 수치 허용오차 없이 비교했다.
- 전체 분석에서는 반환 객체와 함께 반올림 전 QIC의 6개 통계량 × 3개 상관구조를 비교했다.

수치 비교는 `identical(..., num.eq = FALSE)`를 사용했다. 전체 모형의 formula/terms 환경과 함수 표현만 정규화했으며 원시 환경·함수 객체의 동일성까지 주장하지 않는다. 직접 상관행렬 검증 비교에는 이러한 정규화가 필요하지 않았다.

기존 `scripts/validate_longitudinal_gee_reuse.R`도 다시 실행하여 앞선 선택 모형 재사용과 예외 처리의 48개 조건을 확인했다. 전체 성능 측정 역시 변경 전 소스와 최종 후보의 반환 객체/조건/출력/RNG 비교를 통과했다.

## 제한과 증거

이전에 변경 전 코드에서도 재현된 종합 테스트의 Excel 셀 위치 비교 실패는 이번에 해결하거나 재검증하지 않았다. 이번 변경에 관련된 위 GEE 검증을 수행했다. 분석 출력 형식은 변경하지 않았으며 전체 PDF/Word/HWPX/Excel 변환과 설치 파일 빌드는 실행하지 않았다.

`output/longitudinal-gee-matrix-reuse-20260914/`에 `baseline.R`, `candidate.R`, `bench.R`, `timing-1/2/3.csv`, `kernel-*.csv`, `validation.log`, `selected-fit-regression.log`를 보관한다. 기존 작업 트리의 다른 변경은 유지했다.
