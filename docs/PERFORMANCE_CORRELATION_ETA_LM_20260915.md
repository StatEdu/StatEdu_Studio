# Eta 상관의 단일 요인 적합 준비 단축

> 후속 검증: 집단 직접 집계까지 포함한 현재 제품의 통합 효과와 사용자 정의 대비의 진단·난수 보존은 [통합 검증 기록](PERFORMANCE_CORRELATION_ETA_COMBINED_20260915.md)을 참고한다. 개별 개선율은 합산하지 않는다.

## 변경

`correlation_eta_result`의 `aov(values ~ groups)` 호출을 `lm(values ~ groups)` 적합과 `c("aov", "lm")` 클래스 지정으로 바꿨다. 고정된 단일 요인 모형에는 Error 항이 없고, 번들 R 4.5.3의 이 조건에서 `aov`는 `lm`을 호출한 후 aov 클래스를 지정한다. 이 추가 모형식 검사·호출 준비를 생략한다. 이후 `summary(fit)`는 계속 기존 `summary.aov`를 사용한다.

Eta 계수 계산, 설계행렬/QR 적합, ANOVA 요약 및 p값 산식은 바꾸지 않았다. 적합 객체는 외부로 반환하지 않는다. 내부 객체의 호출 기록 등까지 기존 aov 객체와 같다는 뜻은 아니며, 사용하는 원시 ANOVA 요약표와 최종 반환값을 비교했다. 다른 ANOVA 분석이나 Error 항이 있는 모형으로 확장하지 않았다.

## 정확성

- `scripts/validate_correlation_eta_lm.R`: 실제 제품 함수에서 이전 aov 호출을 복원하여 비교한다. treatment/sum/Helmert 대비, 2/3/6집단, 3/12/100행, 일반·인접 실수·동점·큰 수·결측·무한대·상수·ordered 입력의 216개 전체 수집 결과가 정확히 일치했다. 이 중 153개는 원시 ANOVA 요약 객체도 비교했다.
- 별도 100개 입력 조합에서 기존/후보 Eta 함수 반환값·진단·stdout·난수 상태를 비교했다. 빈 입력이나 잘못된 입력의 오류도 수집했다. 같은 사례 집합을 각 실험에서 반복했다.
- 최초 단일 호출 실험 및 5회 묶음 실험에서 각각 4조건 × 3프로세스의 전체 상관분석 결과가 일치했다. 묶음 실험은 각 반복 결과도 확인했다.
- 제품 반영 후 이전 소스와 실제 제품 소스를 비교한 4개 전체 분석 및 100개 입력 조합 검증도 통과했다.

모든 결과 비교는 `identical(..., num.eq=FALSE)`이며 수치 정규화·반올림·허용오차를 적용하지 않았다. 진단, stdout 및 난수 상태를 포함한다. 사용자 정의 대비 함수 등 모든 확장 동작을 포괄하는 검증은 아니다.

## 성능 근거와 한계

10,000행·20변수, 명목형 또는 연속형 10개/명목형 10개 혼합, 변수별 무작위 결측 0/10%다. 혼합형에는 Eta 100쌍이 있다. Pearson 지정, 정규성 및 잠재상관 비활성화 조건이다. 두 소스 환경의 상관분석 함수들을 명시적으로 컴파일하고 새 R 프로세스 세 개를 순차 실행했다. 양쪽 예열 후 두 번째 프로세스의 조건·기존/후보 순서를 뒤집었다.

최초 단일 호출 혼합형은 0.35→0.46초, 0.46→0.34초, 0.31→0.44초였다. 측정 순서에 따라 두 번째 쪽이 느려지는 패턴이 있어 이 차이를 변경의 고유 비용이나 개선율로 해석하지 않았다. 이후 각 측정 구간에서 전체 분석과 동일성 검증을 5회 반복하고 총 경과 시간을 5로 나눈 추가 실험을 수행했다.

아래는 **결과·진단 수집 및 반복별 동일성 검사까지 포함한 5회 묶음의 호출당 평균 시간**이며, 세 프로세스 값을 모두 제시한다. 프로파일러는 사용하지 않았다.

| 자료 | 기존 3회 값(초) | 변경 3회 값(초) |
|---|---|---|
| 명목형 | 0.266 / 0.222 / 0.234 | 0.264 / 0.222 / 0.232 |
| 명목형, 결측 10% | 0.244 / 0.212 / 0.216 | 0.250 / 0.234 / 0.218 |
| 혼합형 | 0.388 / 0.346 / 0.366 | 0.360 / 0.360 / 0.342 |
| 혼합형, 결측 10% | 0.344 / 0.350 / 0.338 | 0.330 / 0.312 / 0.312 |

결측 혼합형은 세 번 모두 단축됐으며 중앙값 0.344→0.312초로 약 9% 감소했다. 결측 없는 혼합형은 두 번 단축, 한 번 증가했으며 중앙값 0.366→0.360초다. 명목형에는 Eta 호출이 없어 변경 경로를 사용하지 않지만 그 조건에서도 변동이 관측됐다. 메모리/GC 및 실행 상태의 영향을 완전히 분리한 실험은 아니다.

고정된 모형에서 기존 적합·요약을 재사용하는 작은 변경이고 결측 혼합형의 반복 측정에서 이득이 확인되어 반영했다. 모든 자료나 단일 호출에서 빨라진다는 보장은 하지 않는다. 단일 호출 실험과 묶음 실험은 측정 범위가 다르므로 시간을 직접 합치거나 비율을 섞지 않는다. 제품 반영 후 실행한 `product.R`의 시간은 재컴파일 조건을 동일하게 맞춘 성능 근거로 사용하지 않고 결과 검증으로만 사용한다.

표 구성·출력 코드 및 UI는 변경하지 않았다. 결과 준비·검증 시간만 측정했으며 화면·내보내기·로딩 속도에 대한 수치는 아니다. 별도 내보내기 생성 및 배포 빌드는 수행하지 않았다.
