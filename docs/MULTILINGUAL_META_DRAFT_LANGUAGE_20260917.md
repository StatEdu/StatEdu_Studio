# 메타분석 미저장 숫자 입력 보존 — 2026-09-17

`meta_effect_fields`가 언어 변경 시 저장된 행으로 숫자 입력을 다시 만들던 경로를 수정했다. 같은 모달 세대·효과크기 계열·입력 형식·편집 행이면 현재 입력값을 isolate로 읽어 재사용한다. 빈 숫자 입력(NA)도 유지한다. 새 모달을 열거나 입력 형식/행이 바뀌면 이전 draft를 재사용하지 않는다. 입력값 변경 자체가 전체 입력 영역을 재생성하지 않는다.

`validate_meta_draft_language.R` 실제 Shiny 서버 검사에서 14개 형식 × 8개 언어 및 한국어 복귀, 빈칸 유지, 효과 데이터 불변, 새 창 초기화, 저장된 행 편집·재열기를 확인했다.

`serve_meta_draft_language.R`의 로컬 최소 앱과 `validate_meta_draft_language.cjs`를 사용하여 실제 Chromium에서 평균/SD/표본 수 입력, 빈칸, 사용자 연구명 보존을 8개 언어 전환으로 확인했다. 언어 변경 이벤트는 Shiny 입력으로 전달하고 DOM의 번역된 레이블과 실제 입력값을 검사했다. 취소 후 새 창의 초기화도 통과했다. 전체 설치 앱의 언어 메뉴 조작이나 모든 입력 형식의 브라우저 검증은 아니다. 상위 모달 정적 제목/버튼의 열린 상태 실시간 번역은 별도 점검 대상이다.

분석 결과 출력·계산은 변경하지 않았다. 설치본을 만들지 않았다.
