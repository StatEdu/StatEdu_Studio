# 概述 — StatEdu Studio 1.3.0

StatEdu Studio 是用于数据准备、统计分析、模型可视化、样本量规划和结果报告的 Windows 统计应用。通过界面指定变量和选项，并结合结果查看方法、假设、诊断与解释。本概述介绍当前应用的全部功能，而非仅介绍1.3.0新增功能。

## 数据编辑、分析范围与计算器

导入 SPSS、SAS、Stata、Excel、CSV 和 DAT 数据，检查变量名、标签、测量水平、类别及参考值。查看每项分析实际使用的样本量及缺失值处理信息。

管理变量名、标签、测量水平和类别；进行重新编码、变量计算、缺失处理、数据合并、按ID汇总以及WIDE–LONG转换。通过个案选择和数据拆分指定分析范围。另提供EQ-5D、HINT-8、Framingham、ASCVD及代谢相关计算器。

## 支持的分析

### 频数、描述统计与交叉表

提供频数、百分比、位置与离散统计量及列联表。根据选项输出关联检验、效应量和相关诊断。

### 组间比较与协方差分析

提供独立样本 t 检验、ANOVA、ANCOVA 和非参数组间比较。支持的选项包括根据方差选择方法、事后比较及效应量。

### 配对与混合重复测量

提供配对、重复测量、混合重复测量 ANOVA 及配对非参数分析。输出所选设计的时间、组别效应与比较结果。

### 相关、信度与评定者一致性

提供相关、量表信度和评定者一致性分析。根据变量类型及评定设计选择相关方法与一致性指标。

### 探索性因子分析与 PCA

在 EFA 和 PCA 中检查因子或成分数量、提取、旋转、载荷及解释方差。CFA 单独说明。

### 重要性–表现分析（IPA）

打开分析 → IPA，选择直接评分或推导重要性。直接评分按相同属性顺序分配重要性和表现变量；推导重要性指定表现和总体满意度。选择总体、独立组或配对前后设计。配对资料使用 WIDE 对应列或 LONG 的 ID、时间及两个时间值。设置参考线和图形，运行后检查样本数、坐标、区间和组/时间差异。Word/HWPX 在添加结果后从累积结果保存。

### 回归与分层回归

提供 OLS、HC3 稳健推断与自助法回归。分层分析比较逐步加入的区块和解释方差变化。按选择输出 sr²、f²、共线性与残差诊断。 分层回归最多支持4个区块。每一步保留前面区块的变量，并加入下一个区块。

### 中介与调节效应

在画布中指定自变量、因变量、中介、调节变量及协变量的角色和路径，估计直接、间接、总效应及条件效应。这不是选择模型编号的流程。不支持的路径结构会在运行前检查并提示。

### 逻辑回归、GLM 与惩罚回归

提供逻辑回归、广义线性模型、Ridge、LASSO 和 Elastic Net。结合结果尺度、分布族、连接函数及交叉验证设置报告系数与性能。

### 纵向、面板与复杂抽样

在支持的设计中提供 GEE、LMM、GLMM、固定或随机效应及复杂抽样分析。检查个体或群集标识、时间、权重、分层和群集设置。

### 生存分析

提供 Kaplan–Meier、对数秩、RMST、Cox 及支持的竞争风险分析。先检查输入格式与事件编码；不支持的组合限制运行。

### 验证性因子分析（CFA）

提供 ML、MLR、适用于有序数据的 WLSMV/DWLS、载荷、拟合度、信度、AVE、HTMT 及支持的测量不变性比较。Normal/Wishart 选择仅适用于相应 ML 设置。

### 结构方程模型（SEM）

报告测量与结构路径、拟合度及支持的直接、间接和条件效应。自助法默认 5,000 次，结果反映 BC 或百分位区间等所选设置。

### PLS-SEM 与 PLSc

提供反映式 Mode A、形成式 Mode B、反映式 PLSc、路径与测量诊断及支持的预测和组间比较。缺失值通过 seminr::mean_replacement 用指标均值替代，每次自助重抽样重新计算均值。默认 5,000 次。

### 样本量、功效与效应量

计算支持检验的样本量、功效与效应量。同时记录显著性水平、假设效应、组别分配和检验方向。

## 查看、累积与保存结果

查看当前结果并添加到结果集中。支持 HTML、PDF、Word、Excel；HWPX 仅在韩语界面的累积结果页提供，直接生成而不经 Word 或 Hancom 转换。Word/HWPX 可选择主表、附录表、说明和图形，默认主表。保存使用已捕获的显示结果，不重新计算。Free 图像为300 dpi，开发者版为600 dpi。HTML 包含封面和表目录链接。

## 文档与验证范围

在信息菜单打开概述、用户指南、分析、方法说明、验证和版本历史。统计主表保持英语，菜单与补充说明使用界面语言。验证仅适用于列明的数据和条件，不代表全部组合或母语审校。

开发者安装包为 StatEdu Studio Dev 1.3.0-dev，使用独立应用名称并保留开发菜单。公开版排除元分析和同一对象内处理的重复测量 ANOVA，但保留混合重复测量 ANOVA 与配对检验。
