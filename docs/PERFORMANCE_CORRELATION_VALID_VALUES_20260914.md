# 상관분석 사전 점검의 완전 자료 복사 생략 — 2026-09-14

`R/analysis_correlation.R`의 사전 점검에서 모든 값이 유효하고 속성이 없는 변환 벡터는 그대로 unique에 전달한다. 기존에는 결측이 없어도 `values[valid]`로 벡터를 다시 만들었다. 결측 또는 속성이 있는 경우에는 기존 부분 추출을 유지한다. 유효 관측 수, 고유값 수, 변수 제외 기준과 진단 내용은 유지한다.

## 메모리와 시간

번들 R 4.5.3과 기존 모듈 캐시, 25만 행·4변수의 숫자 자료에서 Pearson 분석을 정규성 검사 없이 실행했다. 새 프로세스에서 변경 전후 3쌍을 순차 측정하고 두 번째 쌍은 순서를 반대로 했다. 각 프로세스의 완전 자료 후 결측 자료 순서를 유지했다.

| 입력 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 완전 자료 | 0.19 | 0.19 |
| 변수마다 약 10% 결측 | 0.10 | 0.08 |

완전 자료에서는 시간 개선을 확인하지 못했다. 모든 변수에 결측이 있는 두 번째 조건은 새 복사 생략 경로를 사용하지 않는다. 이 조건의 작은 차이를 복사 생략 효과로 해석하지 않는다. 조건 간 시간 차이에는 실행 순서와 워밍업 효과가 포함된다.

별도 Rprofmem 실험에서 완전 자료의 분석 결과 준비를 함수별 3회 실행한 뒤 1회 기록했다. 누적 할당은 98,392,288바이트에서 82,391,680바이트로 16,000,608바이트(약 16.3%) 감소했다. 작은 코드 변경으로 임시 할당이 줄어 유지한다. 이는 해당 호출의 누적 할당량이며 프로그램 전체 메모리나 최고 사용량의 감소치는 아니다.

## 검증

- 48개 자료·분석 방법·정규성 옵션 조합에서 전체 결과·진단·난수 상태가 일치했다.
- 성능 측정 결과 6쌍도 `identical(...,num.eq=FALSE)`로 전체 결과·진단·난수 상태가 일치했다.
- 사용자 정의 변환 메시지, 결측, 문자형의 추가 3조건에서 auto 결과 및 HTML/의존성이 일치했다. 기존 인자의 numeric-data 직접 호출도 동일했다.
- 0/1/2/3/10행 × 숫자/전부 결측/상수의 추가 15조건에서 반환값 또는 오류와 진단·난수 상태가 동일했다.
