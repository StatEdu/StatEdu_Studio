# 계산기 미리보기와 FRS 안내 — 2026-09-17

6종 계산기 DT 미리보기에 `with_datatable_language`를 연결하고 현재 세션
언어를 반응형 의존성으로 추가했다. 검색·페이지 이동·표시 건수·빈 검색 안내가
언어 전환 후 갱신된다. 기존 50행 미리보기 제한, 열 이름과 데이터 값은 유지한다.

FRS의 성별/이진 코딩, 지질, 점수, 10년 위험도, 위험군, 심장 나이 설명을
공통 필드 번역으로 연결했다. 7개 새 문구는 기존 다국어 작업에서
`fill_calculator_frs_options_i18n.py`로 사전에 병합했다. 숫자 코딩, 단위와
생성 변수명은 그대로 유지한다.

검증:

- `validate_calculator_status_i18n.R`: 6종 실제 Shiny 서버 × 8언어 및 한국어
  복귀. DT language 객체, 입력 라벨/선택값, 완료 안내, 계산값 및 재계산 없음.
  FRS는 기본값이 아닌 mmol/L 선택과 단위 변환 안내의 보존도 검사했다.
- 기존 계산기 수치 회귀 검사 통과.
- `calculator_preview_browser_app.R`: 별도 localhost:7903 합성 자료 60행을
  사용하는 FRS 검증 앱. 실제 브라우저에서 8언어와 한국어 복귀를 수행했다.
  일본어 다음 페이지에서 11~20/50행 안내를 확인하고, 99999 검색 후 0건
  문구 및 필터 건수 안내를 확인했다. 마지막에 변수 8개 배치가 유지됨을
  DOM으로 확인했다. 임시 탭/서버는 종료했다. 생산 서버는 변경하지 않았다.

이번 브라우저 검증은 FRS 대표 경로다. 다른 5종의 실제 브라우저, 언어 전환
시 검색어/현재 페이지 유지, 열 정렬 접근성 안내, 다른 계산기 옵션/참조표와
표본수/효과크기는 별도 후속 범위다. 계산식과 저장 CSV 데이터, 분석 보고서
출력은 변경하지 않았다. 설치본은 생성하지 않았다.
