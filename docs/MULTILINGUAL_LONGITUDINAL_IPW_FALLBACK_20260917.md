# 종단 IPW 대체 처리 안내 — 2026-09-17

관측 상태의 변이가 없어 단위 가중치를 사용하는 안내와 완전히 관측된 예측변수가 없어 절편만 사용하는 안내를 종단 보조표 번역에 연결했다. 기존 7개 언어 카탈로그의 공통 키를 재사용하고 빠진 한국어 두 항목을 추가했다. 실제 검사에서 한국어 안내가 영어로 남는 것을 먼저 확인했다.

`validate_longitudinal_ipw_fallback_i18n.R`는 실제 IPW 함수에 완전 자료와 종속변수 일부 결측·상수 예측변수 자료를 전달한다. 모의 함수를 사용하지 않는다. 두 경로 × 8언어의 16개 검사에서 안내·진단 표의 동일한 번역, 단위 가중치, 확률 및 절단 건수 보존, 사용자 열 원문과 입력 결과 불변을 확인했다.

`validate_longitudinal_error_exports.R`에 실제 진단 표 두 개를 포함했다. 기존 MI/IPW 오류 70개 검사와 함께 8언어 본표/사용자 원문 보존, 한국어·일본어 현재/누적 HTML·PDF·Word·직접 생성 HWPX·Excel을 검사한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 별도 확인한다. 산출물은 `tmp/longitudinal-error-exports`다.

계산 코드와 저장 원본은 변경하지 않았다. 전체 옵션·브라우저·페이지별 시각 검토를 완료한 것은 아니다. 메타분석과 설치본은 작업하지 않았다.

위 검사와 5종 저장 검증이 모두 통과했다. PDF 네 개의 캡처 텍스트도 통과했으며 각 언어 현재 16쪽, 누적 31쪽이다. 변경 파일의 `git diff --check`도 통과했다.
