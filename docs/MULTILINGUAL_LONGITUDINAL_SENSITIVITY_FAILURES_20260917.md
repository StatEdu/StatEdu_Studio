# 민감도 비교의 지표명·실패 안내 — 2026-09-17

강건 표준오차, 집단 군집 HC1 표준오차, HC1 대비 표준오차 비율, p값의 4개 지표명을 8언어 사전에 연결했다. QIC와 AIC/BIC는 통용 표기를 유지한다. 숫자 문자열은 변경하지 않는다.

민감도 비교표의 실패 Note가 일반 문구 번역을 거치면서 외부 오류의 `Warning`, `Failed` 같은 단어까지 바뀌는 문제를 수정했다. 해당 표의 실패 행은 등록된 앱 오류 번역 함수만 사용하며, 나머지 외부 오류는 줄바꿈·사용자 이름·정밀 숫자를 포함해 그대로 보존한다.

`validate_longitudinal_sensitivity_failures_i18n.R`에서 GEE/LMM/패널 비교 함수의 적합 함수를 격리된 환경에서 시험용 오류로 대체했다. 등록 오류와 외부 오류 2종 × 3경로 × 8언어 48개 검사 및 지표표 8개 검사가 통과했다. 이 검사는 실패 처리 시험이며 48개 실제 실패 적합을 의미하지 않는다. 원본 표·실패 상태 번역·원문 오류 보존을 확인했다.

실제 정상 GEE/LMM/패널 민감도 비교의 기존 24개 검사도 통과했다. 전체 결과 패널 검사는 이번에 재실행하지 않았으며, 저장 검사에 포함한 영어 본 표는 계수 시험 표다. 저장 입력은 `tmp/longitudinal-sensitivity-failures/tables.rds`, 출력은 `tmp/longitudinal-sensitivity-failure-exports`다. 저장 시 분석을 다시 실행하지 않는다.

다른 모형·실패 조합과 실제 브라우저·페이지별 시각 검토는 남아 있다. 메타분석과 설치본은 변경하지 않았다.
