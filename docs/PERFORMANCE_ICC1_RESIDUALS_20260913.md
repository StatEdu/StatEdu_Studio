# ICC(1) 불필요한 잔차 행렬 계산 제거 — 2026-09-13

`interrater_icc_complete_value()`에서 ICC(1)이 사용하지 않는 열 평균제곱과 두 방향 잔차 평균제곱 계산을 생략했다. ICC(1)의 행 평균제곱·집단 내 평균제곱·최종 산식은 그대로다. 두 번의 `sweep()` 및 잔차 제곱 집계를 건너뛴다. ICC(2)·ICC(3)는 기존 경로를 유지한다.

## 측정

동봉 R 4.5.3, 1,000행·10평정자·1,000회 재표집, 단일 측정 기준. 변경 전후 순서를 교대로 5회 측정한 부트스트랩 신뢰구간 함수 전체 중앙값이다.

| 모형 | 변경 전 | 변경 후 |
|---|---:|---:|
| ICC(1) | 0.27초 | 0.14초 |
| ICC(2) | 0.26초 | 0.27초 |

ICC(1)은 약 48% 감소했다. ICC(2)의 작은 차이는 측정 변동을 고려해야 하며, 개선 대상으로 보지 않는다. 기존 완전 사례 전용 함수 최적화가 반영된 파일과 비교했다.

## 검증

- 변경 직전 실제 파일과 `validate_icc1_unused_residuals.R`의 156개 비교 통과: ICC(1/2/3), 일치도/일관성, 단일/평균, 임의 값·동률·상수·작은/빈 행렬·결측·무한대·큰/작은 규모 자료, 부트스트랩 CI.
- 값·속성·경고·메시지·오류·난수 상태를 `identical(..., num.eq=FALSE)`로 비교했다.
- `validate_interrater.R` 통과.
- ICC(1) 부트스트랩을 포함한 전체 분석 객체와 난수 상태, 화면 및 저장 HTML, Excel 모든 시트가 정확 일치했다.
- `git diff --check` 통과.

표시·저장 내용은 변경하지 않았다. 명시한 시험 범위의 정확 일치 검증이며 모든 입력에 대한 불변 증명은 아니다. 설치 파일은 재빌드하지 않았다.
