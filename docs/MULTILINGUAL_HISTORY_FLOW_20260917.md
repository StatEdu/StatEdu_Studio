# 누적 결과 안내·저장·불러오기 흐름 점검 — 2026-09-17

빈 결과 안내, 결과 없는 상태의 저장 오류, 저장/열기 취소, 저장 완료 경로, 빈 파일 열기 오류, 결과 비우기, 불러오기 완료 안내를 확인했다. 해당 문구는 기존 번역 키를 사용하고 있어 제품 코드나 번역을 추가 수정하지 않았다.

`scripts/validate_result_history_flow_i18n.R`를 추가해 8개 언어 및 한국어 복귀를 Shiny 서버에서 검증했다. 파일 선택 경계만 대체하고 실제 결과 이력 파일을 저장·읽었다. 모든 흐름에서 현재 언어의 안내가 표시되고 취소/빈 파일 열기는 기존 결과를 보존한다. 비우기는 저장 이력에도 반영되며 다시 열면 원래 ID·사용자 제목·HTML 스냅샷이 복원된다. 한글·공백·&·%s가 포함된 유효한 Windows 경로도 보존된다.

초기 테스트 작성 중 HTML 공백 비교와 Windows에서 금지된 파일명 문자 때문에 실패했으며 테스트 입력/비교를 바로잡은 뒤 전체 통과했다. 제품 결함으로 판정하지 않았다.

실제 브라우저 클릭이나 네이티브 창 표시는 검증하지 않았다. 분석 보고서 출력/내보내기 내용은 변경하지 않았고 설치본도 생성하지 않았다. 앱 전체 다국어 완료를 의미하지 않는다.
