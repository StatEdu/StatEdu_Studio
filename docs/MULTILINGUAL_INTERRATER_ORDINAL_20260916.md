# 순서형 일치도·ICC 부트스트랩 다국어 검사

선형/이차 가중치 설명, 순위 거리 제곱에 기반한 순서형 알파 설명, 가중 Cohen 카파 명칭의 네 문구를 8개 언어 사전에 등록했다. 계산 엔진은 변경하지 않았다.

`scripts/validate_interrater_ordinal_i18n.R`에서 실제 80행 자료로 2명/3명 평가자의 선형/이차 가중치 네 경로와 ICC 부트스트랩(검사용 50회, 고정 시드)을 실행했다. 8개 언어 모두 본표의 셀·제목·주석 영어 동일성, 보조표 언어 및 표시된 가중치·순서형 알파 설명을 확인했다. ICC 정규성 보조표의 사용자 평가자 라벨도 보존했다.

3명 경로에서 가중치 설명은 권장 본표에 있으므로 영어가 맞다. ICC 부트스트랩 설명 역시 본표에서 영어를 유지한다. 보조표에 실제로 표시되는 문구에 대해서만 UI 언어 번역을 요구했다. 가중 Cohen 명칭의 사전 등록을 해당 명칭이 보조표로 이동하는 모든 추천 분기의 검증 근거로 삼지는 않는다.

기존 명목형/ICC 다국어 검사와 번역 계약 검사도 통과했다. 일본어 다섯 경로를 하나로 묶은 저장 fixture는 `tmp/interrater-ordinal-i18n/entries.rds`, 내보내기 로그는 `tmp/interrater-ordinal-exports.log`다.

현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성 및 실제 PDF 텍스트 검사를 모두 통과했다.

결측·범주 불균형에 따른 추천 변경 전체, 나머지 ICC 모형 조합·옵션·입력 오류·브라우저 언어 왕복은 남아 있다. 전용 결과 검증 공백은 14개를 유지한다. 설치본은 만들지 않았다.
