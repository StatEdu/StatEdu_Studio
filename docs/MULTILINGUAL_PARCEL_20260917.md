# CFA Parcel 계획 점검 다국어 보완

- Parcel 계획 결과의 제목·소제목·상태·목적 미기록 안내·미리보기 불가 사유·적합 성공/실패 안내·안전성 설명·보조표 열 이름을 UI 언어로 표시한다.
- 필요한 지표 수와 Parcel 수를 포함한 문장은 전체 번역 템플릿에 숫자를 넣는다. 구성개념명·하위요인명·문항명·사용자 목적·오류 상세 내용은 번역하지 않는다.
- 연속된 알려진 경고 문장만 번역하며 뒤에 추가된 적합 오류 및 공백은 보존한다. 배정표와 요약표의 모든 셀을 일반 번역의 재치환으로부터 보호한다.
- 계산·배정 방법은 변경하지 않았다. 본표는 영어를 유지하며 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_parcel_i18n.R`: 실제 CFA 적합 결과로 3개·4개 Parcel 배정을 만들었다. 요청·적용·적합 실패·목적 미기록·7개 미리보기 사유·두 지표 수 안내·사용자 오류 등 14개 경우 × 8개 언어를 검증했다.
- 배정 순서, 문항 목록, 수치, 사용자 목적과 특수문자, 본표 영어 HTML 불변, 비CFA 및 비활성화 상태의 미출력을 확인했다.
- `validate_sem_parcel_safety.R` 기존 안전성 검증 통과.
- 표시 스냅샷 `tmp/parcel-i18n/entries.rds` 기반 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 검증 통과. 현재 22표·누적 25표의 순서와 Excel 시트 수, PDF 일본어 문구·표지를 확인했다. 저장 중 분석 재실행은 하지 않았다.
- 안내문만 있는 경우에는 실제 안내 HTML과 대표 영어 본표를 함께 넣어 Excel을 포함한 저장 검증을 수행했다.

프로그램 전체의 다국어 검증 완료를 의미하지 않으며, 이 기록의 범위는 Parcel 계획 결과 화면이다.
