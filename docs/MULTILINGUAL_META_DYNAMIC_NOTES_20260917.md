# 메타분석 동적 연구 수·중심화 안내 — 2026-09-17

다중 효과를 제공한 연구 수, 조절변수 결측으로 제외된 연구 행 수, 연속형 조절변수 중심화 평균 안내를 8개 언어로 연결했다. 연구 수 문장은 전체 형식이 일치할 때 숫자 부분을 보존하여 번역한다. 중심화 평균은 기존 `meta_format_number`의 정밀도를 유지한다. 사용자 문장이 덧붙은 미등록 문구는 원문을 보존한다.

`validate_meta_warning_exports_i18n.R`에 실제 연속형 조절효과 분석(결측 제외 1행, 평균 22.000)을 추가했다. 수치 0/1/12345, 외부 상세, 8개 언어 결과 보조 안내, 영어 본표 동일성 및 결과 객체 불변을 검사한다. 현재/누적 HTML/PDF/Word/HWPX/Excel에 중심화 문구도 포함해 비교하며 PDF 텍스트는 `validate_meta_warning_pdf.py`로 확인한다.

위 검사는 모두 통과했다. 내보내기는 한국어/일본어를 검증했으며 PDF는 현재 9쪽·누적 17쪽이었다. 카탈로그 회귀 검사도 통과했다. 페이지별 시각 검토나 모든 언어의 내보내기 검사를 완료한 것은 아니다.

계산·저장된 원본 결과 객체·본표 언어는 변경하지 않았다. CR2 고유 오류 상세 및 전체 화면 최종 점검은 남아 있다. 설치본을 만들지 않았다.
