# ICC 행 평균 차감의 보조 배열 제거

## 적용

`interrater_icc_complete_value()`의 첫 잔차 계산을 `sweep(matrix, 1L, row_means, "-")`에서 `matrix - row_means`로 변경했다. 입력은 완전 관측 numeric matrix이고 row_means의 길이는 행 수다. R의 열 우선 저장과 벡터 반복에 따라 각 열에서 같은 행 평균을 뺀다. sweep이 행 평균을 전체 크기로 확장하는 처리를 줄이면서 뺄셈 피연산자와 순서를 유지한다.

열 평균 차감, 평균제곱, ICC 산식, 재표집 순서와 분위수 계산은 변경하지 않았다. ICC(1)은 이 잔차 계산을 실행하지 않으므로 직접적인 개선 대상이 아니다. 패키지 내부 함수 변경은 없다.

## 부트스트랩 계산 성능

번들 R 4.5.3, 자료 seed 939, 2,000행·20평가자, 1,000회 재표집, seed 7731, 절대 일치·단일 측정 기준이다. 독립 프로세스 3개를 순차 실행했으며 워밍업 후 두 번째 프로세스는 후보부터 측정했다. 로딩을 제외한 CI 함수와 비교용 캡처 시간이며 전체 화면 생성·저장 시간은 아니다.

| 모형 | 기존 1 / 2 / 3 (초) | 변경 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| ICC(2) | 0.72 / 0.63 / 0.70 | 0.56 / 0.66 / 0.56 | 0.70 → 0.56초, 약 20% 감소 |
| ICC(3) | 0.63 / 0.61 / 0.63 | 0.57 / 0.55 / 0.55 | 0.63 → 0.55초, 약 13% 감소 |

ICC(2)는 세 번 중 두 번, ICC(3)는 세 번 모두 빨라졌다. ICC(2)의 두 번째는 0.03초 증가했으므로 모든 실행의 개선을 주장하지 않는다. 별도 메모리 계측은 하지 않아 보조 배열 제거를 peak 메모리 감소율로 환산하지 않는다.

각 워밍업과 측정에서 CI 반환 값·조건 클래스/본문/순서·표준 출력·RNG가 `identical(..., num.eq=FALSE)`로 일치했다.

## 검증

`scripts/validate_icc1_unused_residuals.R`의 독립 참조가 첫 잔차 계산도 원래 sweep을 사용하도록 확장했다. 기존 ICC(1) 잔차 및 ICC(2/3) 집단 내 평균제곱의 이전 계산 참조도 유지한다.

- 변경 직전 실제 소스를 참조로 지정한 ICC 값·CI·조건·RNG 비교 156건 통과.
- 파일 인수 없는 독립 참조 검증도 동일 156개 조건 통과. 별개 자료 312종으로 합산하지 않는다.
- `scripts/validate_interrater.R` 통과.
- 별도 전체 결과 검증에서 ICC(1/2/3) × 일치/일관성 × 단일/평균의 12개 분석을 비교했다. 결측이 있는 100행·4평가자 자료에 정규성 검사와 부트스트랩 100회를 포함했다. 전체 결과·진단·출력·RNG가 정확히 일치했다.
- 각 분석의 점추정 1개와 재표집 추정 100개를 원값으로 수집하여 총 1,212개의 ICC 값도 비교했다. CI가 같다는 이유만으로 부트스트랩 원값을 같다고 간주하지 않았다.
- 제품 커널 본문이 측정한 후보와 동일함을 확인했다.

156개 조건은 세 ICC 모형, 일치/일관성, 단일/평균, 결측·상수·무한대·큰/작은 수치·작은/빈 입력 등을 포함한다. 모든 사용자 정의 matrix 클래스에 대한 증명은 아니다.

## 증거와 범위

`output/icc-row-subtraction-20260914/`에 baseline.R, candidate.R, bench.R, timing-1/2/3.csv, 실행 로그, baseline-validation.log, validation.log, regression.log, verify-results.R 및 results.log를 보관했다.

표시·출력 내용과 형식은 변경하지 않았다. 전체 파일 형식 변환 및 설치 파일 빌드는 실행하지 않았다. 기존 작업 트리의 다른 변경은 유지했다.
