# 생존분석 사전 점검 오류 알림 연결 — 2026-09-17

설정 화면의 `survival_issue_text`에는 사건 매핑·시간 자료·구간 무결성 오류 번역이 있었지만, 분석 실행 실패 알림은 영어 원문을 그대로 사용했다. `survival_input_error_text`에서 기존 입력 오류 번역으로 처리되지 않는 구조화된 오류를 이 공통 번역 함수로 연결했다. 새 번역 사전을 중복 생성하지 않았다.

기존 필수 변수 안내와 없는 변수 이름 삽입 처리를 보존했다. 영어에서는 원래 오류 메시지를 유지하며 알려지지 않은 외부 오류도 그대로 전달한다. 분석 조건·계산·본표·보조표·저장 스냅샷은 변경하지 않았다.

검증 결과:

- `validate_survival_preflight_notifications_i18n.R`: 기존 전체 사전 점검/생존분석 회귀 검사를 실행한 뒤 실제 차단 사례 15개를 8개 언어에서 검사했다. 시간값 형식, 사건 매핑, 미지원 다상태, 진입/종료 순서, 시작/종료 순서, 구간 중복, 사건 이후 구간, 복수 사건, 대상자 ID 결측 오류가 포함되었는지 확인했다. 원래 점검 객체와 외부 사용자 문구 보존도 통과했다.
- `validate_survival_preflight_i18n.R`: 기존 필수 역할 복합 오류와 사용자 변수명 보존 검사 통과.
- `validate_survival_input_errors_i18n.R`: 기존 53종 오류와 세 실패 콜백 검사 통과(의존성 경계 모의 검사 포함).
- `validate_survival_setup_issues_i18n.R`: 설정 화면 24종 안내의 8개 언어 회귀 검사 통과.

이 검증은 실제 브라우저 클릭이나 모든 내부 모형 오류의 완료를 뜻하지 않는다. 이번 변경은 실패 알림에 한정되며 설치본을 만들지 않았다.
