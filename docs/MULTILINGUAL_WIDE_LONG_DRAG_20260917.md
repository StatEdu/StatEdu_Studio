# 와이드→롱 포인터 드래그 검사 — 2026-09-17

## 발견 및 수정

그룹을 미리 클릭하지 않고 바로 드래그할 때, 서버가 기존 선택 입력의 공백을 이유로 순서 변경을 무시했다. 실제 마우스 이동/누름/놓기를 사용하는 브라우저 검사에서 재현했다.

공통 `register_analysis_reorder`/`analysis_reorder_items` 경로를 유지하면서, 드래그 요청의 검증된 순서와 선택 항목을 반영한다. 반복 열과 설정 그룹의 선택 표시를 화면 재생성 시 유지하도록 연결했다. 그룹 순서 변경의 미리보기 초기화·설정 변경 표시는 기존 동작을 유지한다.

## 검증

- `validate_wide_long_drag.R`: 사전 선택 없는 드래그 요청이 실제 그룹 순서와 변경 상태를 갱신함을 확인. 중복 ID와 다른 ID를 포함한 요청은 순서·변경 상태를 바꾸지 않는다.
- `validate_wide_long_drag_browser.cjs`: 실제 포인터 조작으로 원본 열 4개를 `4,1,2,3` 순서로 바꾸고, 두 설정 그룹을 앞뒤로 드래그한다. 8언어에서 표시 순서뿐 아니라 집단·시점에 대응하는 실제 변환값과 결과 열 순서를 확인한다. 드래그 후 선택 표시 및 기존 위/아래 버튼도 검사한다.
- `validate_wide_long_status_i18n.R`: 상태 안내 회귀 검사 통과.

로그: `tmp/wide-long-drag.log`, `tmp/wide-long-drag-browser.log`, `tmp/wide-long-status-i18n.log`.

선택 표시·위/아래 버튼 검사를 포함한 최종 브라우저 검사도 8언어 모두 통과했고 pageerror는 없었다.

## 한계

다중 항목 동시 드래그와 긴 목록의 자동 스크롤을 망라한 검사는 아니다. 네이티브 저장 창은 별도 미완료다. 분석 출력/내보내기 경로 변경 및 설치본 생성 없음.
