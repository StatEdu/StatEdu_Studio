# 메타분석 완료 알림 — 2026-09-17

메타분석의 입력 검증 완료 및 분석 완료 알림이 한국어/영어 분기만 사용하고 있었다. 두 알림을 8개 언어 카탈로그로 연결했다. 검증 알림의 분석 가능·확인 필요·오류 건수와 기존 알림 등급/표시 시간은 유지했다. 계산·본표·보조표·저장 스냅샷은 변경하지 않았다.

`validate_meta_notices_i18n.R`에서 실제 소스의 검증 observer와 완료 알림 호출을 추출해 실행했다. 효과 자료 재검증/요약 경계는 격리하고, 8개 언어 및 한국어 복귀, 정상/경고/오류/빈 자료 건수, 결과 초기화, 사용자 연구 이름 보존을 확인했다. `validate_multilingual_coverage.R`도 통과했다. 실제 브라우저 전체 메타분석 실행 검사는 아니다.

확인된 후속 대상: 메타분석 가져오기 오류와 일부 분석 실패 상세, 입력 상태 라벨의 한국어/영어 분기, 종단분석의 원문 오류 전달 경로. 상태 라벨은 화면/내보내기 사용 범위를 먼저 확인해야 한다. 설치본은 만들지 않았다.
