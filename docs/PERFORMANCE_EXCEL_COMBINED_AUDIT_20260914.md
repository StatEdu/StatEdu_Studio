# Excel 최적화 통합 검증 — 2026-09-14

Excel 최적화 시작 전 구현과 현재 구현을 같은 저장 입력으로 직접 비교했다. 개별 개선율을 합산하지 않았다. 이번 작업은 통합 검증이며 실행 코드를 추가 변경하지 않았다.

기준은 `output/excel-row-batch-20260914/baseline.R`에 보관된 값 쓰기 묶음 적용 전 구현이다. 현재 구현에는 값 쓰기 묶음, 서식 캐시와 적용 묶음, 표 해석 재사용, Excel의 불필요한 Word 변환 생략, HTML 문서 재사용, 셀 텍스트의 행 단위 처리, 위첨자 없는 행의 검색 생략이 포함된다. 미적용으로 판정한 후보는 포함하지 않는다.

## 전체 저장 시간

번들 R 4.5.3을 사용해 총 3쌍을 순차 실행했다. 두 번째 쌍은 변형의 순서를 뒤집었다. 각 변형·반복은 새 프로세스에서 모듈과 설정을 로드한 뒤 세 작업을 같은 순서로 실행했다. 프로파일러 없이 전체 저장을 측정했고 검증은 측정 밖에서 수행했다. 변경 함수 여섯 개는 동일한 전역 도우미 환경을 사용했다.

| 저장 대상 | 시트 | 최적화 전 중앙값(초) | 현재 중앙값(초) | 감소율 |
| --- | ---: | ---: | ---: | ---: |
| 30변수 상관분석 | 3 | 45.06 | 1.69 | 약 96% |
| Kaplan–Meier 결과 | 12 | 1.30 | 0.76 | 약 42% |
| 소규모 상관분석 + Kaplan–Meier 누적 결과 | 15 | 1.49 | 0.91 | 약 39% |

| 반복 | 상관 전/후(초) | 생존 전/후(초) | 누적 전/후(초) |
| --- | --- | --- | --- |
| 1 | 44.30 / 1.67 | 1.30 / 0.76 | 1.51 / 0.89 |
| 2 | 45.06 / 1.69 | 1.33 / 0.77 | 1.47 / 0.91 |
| 3 | 45.10 / 1.69 | 1.30 / 0.74 | 1.49 / 1.00 |

상관 입력은 기존 30변수 HTML이다. 생존 및 소규모 상관 입력은 실제 서버 모의 실행에서 보관한 결과 패널 HTML을 사용했다. 누적 결과는 30변수 상관표가 아니라 해당 소규모 상관 결과와 생존 결과를 합친 것이다. 이 측정은 보관된 패널의 표와 설명을 대상으로 하며 분석 재실행, 프로그램 시작, 생존 곡선 이미지 렌더링 성능을 측정하지 않는다.

## 결과 보존

총 9쌍, 18개 Excel 파일을 비교했다.

- 모든 시트 이름과 읽어 들인 셀 값이 동일했다.
- 상관 파일의 비-core 내부 파일 16개, 생존 파일 43개, 누적 파일 52개가 각 반복에서 모두 바이트 단위로 동일했다.
- core 메타데이터도 생성·수정 시각만 정규화하면 동일했다.
- 각 저장의 경고 기록과 저장 후 RNG 상태도 동일했다.
- 실행 소스가 검증 시작 시점의 현재 스냅샷과 같은 SHA-256임을 확인했다.

이번 검증은 Excel 저장 경로의 통합 비교다. HTML/PDF/Word/HWPX 완성 파일이나 설치 파일을 새로 생성하지 않았다.
