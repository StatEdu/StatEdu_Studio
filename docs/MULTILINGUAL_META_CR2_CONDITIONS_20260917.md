# CR2 보조 오류 조건 안내 — 2026-09-17

완전한 효과 수/양의 표집분산, 비음수 잔여 연구 간 분산, 최소 독립 연구 군집 수, 계수 수 대비 군집 수, 설계행렬 계수 조건 오류 5종을 8개 언어로 결과 하단의 CR2 보조 안내에 연결했다. 본표의 영어 오류 셀·계산·원본 결과 객체는 변경하지 않았다.

`validate_meta_warning_exports_i18n.R`에서 실제 `meta_cluster_robust_wls` 입력으로 각 오류를 발생시켜 저장 주석 형태와 화면 번역을 검사한다. 기존 민감도/해석/동적 안내와 함께 8개 언어 렌더링 및 한국어·일본어 현재/누적 5개 내보내기를 검사한다. PDF 내용과 문서 그림 포함은 `validate_meta_warning_pdf.py`로 추가 확인한다.

위 검사와 카탈로그 회귀 검사는 모두 통과했다. PDF는 한국어/일본어 각각 현재 10쪽, 누적 18쪽이었다. 산출물은 `tmp/meta-warning-i18n`에 있으며 페이지별 시각 검토나 모든 언어의 내보내기 검사를 수행한 것은 아니다.

입력 길이·신뢰수준·행렬 보정·분산/자유도 추정 실패 등 나머지 내부 오류 상세와 전체 화면 최종 점검은 남아 있다. 설치본을 만들지 않았다.
