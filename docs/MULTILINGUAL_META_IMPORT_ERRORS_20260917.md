# 메타분석 가져오기 오류 — 2026-09-17

파일 형식, readxl 의존성, 대상 효과 유형 불일치, All_Input 시트 누락, 입력 유형 시트 누락, 지원하지 않는 entry_mode 안내 6종을 8개 언어로 연결했다. 가져오기 실패 알림에서 구조화된 오류의 키와 값을 사용한다. 기존 영어 conditionMessage는 유지하고 외부 오류는 그대로 전달한다. 통합 문서의 효과 유형/모드 값은 번역 대상에서 제외했다.

`validate_meta_import_errors_i18n.R`에서 실제 Excel 파일을 생성해 읽기 오류와 정상 가져오기를 검사했다. readxl 부재만 함수 환경의 패키지 확인 경계를 모의 처리했으며 패키지는 제거하지 않았다. 8개 언어와 한국어 복귀, 사용자 값의 따옴표/%s/한글 보존, 파일 바이트 불변, 정상 자료의 연구 이름/값 보존을 확인했다. 기존 메타분석 알림 및 카탈로그 회귀 검사도 통과했다.

실제 브라우저 파일 선택 검증은 수행하지 않았다. 계산·분석 본표·보조표·내보내기 내용은 변경하지 않았으며 설치본을 만들지 않았다. 메타분석 입력 상태 라벨과 분석 실패 상세, 종단분석 오류 안내는 후속 점검 대상이다.
