# 분석 표 주석 공통 규칙 적용 및 검증

2026-09-13. 기준: `table_output_rules.md`의 회귀분석 주석 규칙과 `RESULT_EXPORT_CONTRACT.md`의 화면 원본 저장 규칙.

## 적용

- 모든 분석의 표 주석은 공통 정규화 함수를 사용한다. `Note.`/`주.` 접두어를 생략하고, 통계량 정의를 방법·보정·설명보다 먼저 표시한다. 숫자 주석 표지, 첨자, 기호, 설명 내용은 보존한다.
- 로지스틱 회귀의 B/SE/분리 신뢰구간, 신뢰도의 alpha/omega, 구조모형의 VIF/f² 등 선택 열과 정의를 함께 처리한다. 메타분석은 실제 표 머리글에 해당하는 정의를 사용한다.
- 위계적 회귀는 결과변수별 마지막 모형 뒤에 공통 주석을 한 번 표시하는 기존 예외를 유지한다.
- 평가자 간 일치도와 벌점회귀의 표 너비를 주석과 맞추고, 구조모형의 표 너비가 저장 HTML에서도 유지되도록 명시한다.

## 검증 범위

- `scripts/audit_all_analysis_notes.R`: 22개 분석군, 177개 사례, 1,140개 표 및 452개 주석. 렌더링 실패 및 주석 형식 불일치 0건. 표별 기록은 `tmp/all-analysis-notes/tables.csv`, 주석별 기록은 같은 폴더의 `notes.csv`; 분석군별 집계는 `analysis_note_audit_20260913.csv`.
- 별도 실제 출력 검증: 벌점회귀 8개 표, 메타분석 8개 표, 복합표본 46개 표. CFA·SEM·PLS는 실제 적합 객체로 주 출력 패널 10개를 검증한다.
- 회귀·위계적 회귀 선택 열, 매개·조절 주석, 일반화선형모형, 빈도분석 및 공통 표 계약의 기존 검증과 선택 열 조합 검증을 함께 실행한다.
- `scripts/validate_analysis_note_exports.R`: 28개 분석군에서 주석이 있는 실제 출력 표를 추출하고 상위 레이아웃을 유지한 검증 자료를 사용한다. 현재 결과 및 누적 결과의 HTML·Word·Excel·PDF·HWPX를 실제 생성하고 주석 텍스트를 다시 읽어 비교한다. Excel은 해당 표의 시트에서 주석을 검사한다. HWPX는 한컴의 실제 변환 결과를 검사한다.
- `scripts/validate_analysis_note_layout.cjs`: 저장 HTML의 주석 본문 30개에 대해 표 너비 일치와 가로 넘침을 검사한다. PDF도 이미지로 렌더링하여 확인한다.

이 검증은 위 사례와 선택 열 조합에 대한 재현 가능한 회귀 검증이며, 가능한 모든 데이터·모형·옵션 조합의 전수 통계 검증을 의미하지 않는다. 주석이 불필요한 표에 빈 주석이나 다른 표의 정의를 강제로 추가하지 않는다.

앞으로 출력 표를 추가·수정할 때에도 같은 주석 및 다섯 저장 형식 규칙을 적용한다. 설치 파일 재빌드는 이 변경의 검증 범위에 포함하지 않는다.
