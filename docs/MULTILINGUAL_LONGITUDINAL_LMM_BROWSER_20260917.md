# LMM 설정 언어 전환 브라우저 검사 — 2026-09-17

기존 합성 데이터 Shiny 시험 화면과 실제 종단 서버/UI를 이용해 Chrome에서 LMM ML, 반복측정 UN(REML), 반복측정 AR(1)(REML)을 선택했다. 각 구조에서 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어 전환을 검사했다.

3구조 × 8언어 24개 검사가 통과했다. 시간 고정효과 해제, 잔차 정규성 점검 해제, 활성 Checks 탭, 선택한 구조, 서버 설정 전체와 변수 배치를 확인했다. ML에서는 확률기울기 선택이 유지되고, 반복측정 REML에서는 해당 옵션이 표시되지 않는 것도 확인했다. 구조 선택의 표시 문구는 각 언어 사전과 일치했고 JavaScript 오류는 없었다.

근거는 `scripts/validate_longitudinal_lmm_language_browser.cjs`와 `scripts/serve_longitudinal_language_test.R`다. 추가 제품 오류는 발견되지 않아 검증만 추가했다. 결과 분석을 실행한 검사는 아니며 결과표·저장 검사는 재실행하지 않았다. 전체 앱 환경설정 메뉴 왕복과 다른 변수 이동·데이터 교체·IPW·가중치 조합은 남아 있다. 검사 후 시험 서버와 Chrome을 종료했다.

계산기 담당 작업이 준비한 `scripts/fill_calculator_labels_i18n.py`도 검토·실행하여 필드 설명 29개를 8언어 공용 사전에 병합했다. 계산기 기능 검증은 담당 작업 범위다. 메타분석과 설치본은 변경하지 않았다. 변경 파일의 `git diff --check`가 통과했다.
