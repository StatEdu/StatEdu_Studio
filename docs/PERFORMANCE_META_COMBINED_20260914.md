# 메타분석 누적 개선 통합 검증 — 2026-09-14

최근 메타분석 개선을 함께 적용한 상태에서 입력부터 모형·추가 분석·결과표 생성까지 기존 소스와 비교했다. 이번에는 운영 코드를 추가로 수정하지 않았다. 개별 개선율을 합산하지 않고 동일 작업 묶음 전체를 다시 측정했다.

## 검증 범위

12개 연구, 연구당 효과크기 2개, 총 24개 효과값을 사용했다. 시드 217의 정규 효과값과 양의 표준오차를 생성하고 g, Fisher z 입력의 상관계수, log OR 입력의 오즈비를 각각 검증했다. 각 실행에서 다음 작업을 순서대로 수행했다.

- 입력 정규화, 기본 랜덤효과 REML 모형
- 3수준 모형, CR1/CR2/CR3 강건 추정
- 연속형·범주형 조절효과와 강건 비교
- 연구 내 상관 가정별 민감도, 연구별 제외, Trim-and-fill
- 조절변수 목록 및 한글·영문 결과표 18개

전체 모형 객체·정규화된 입력·조절변수 목록·결과표를 반환값에 포함해 비교했다. 기본 모형·이질성·연구별 결과·조절효과 계수·강건 비교·하위집단·상관 가정 민감도·연구별 제외·Trim-and-fill 표를 두 언어로 생성했다.

## 전체 작업 묶음 시간

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 각 효과 유형을 준비 실행 후 GC와 함께 측정했고 두 번째 프로세스는 기존/현재 순서를 뒤집었다. 다른 R 작업을 동시에 실행하지 않았다. 위 목록의 분석·입력 생성·표 생성·조건 수집을 포함하고 소스 로딩·화면 렌더링·그림·파일 변환은 제외했다. 실제 앱에서 선택한 옵션 조합에 따라 시간은 달라지며 앱 전체 속도나 로딩 속도의 개선율은 아니다. 메모리는 측정하지 않았다.

## 동일성
