# 일원 반복측정 대표 결과와 사용자 라벨 보존

처치명 `Normality`와 시점명 `Yes`, `Status`가 보조표에서 번역되는 문제를 재현하여 수정했다. 정상성 표의 첫 열과 평가 열 제목을 사용자 데이터로 지정하고, 가정 표의 처치/시점 상세 셀도 원문 위치에 따라 보존한다. 공통 표 보존 함수는 명시된 `result_user_cells` 좌표를 처리하도록 확장했다. 미지정 표의 기존 동작은 유지한다.

입력 형식·입력 변수·처치 수준·처치×시점·상호작용·분석명 6개 문구를 8개 언어에 등록했다. 긴 해석/추천 문구 전체를 번역한 것은 아니다.

## 검증

- `scripts/validate_one_group_i18n.R`: 실제 36명·2처치·3시점 WIDE 분석에서 본표 셀·제목·주석 영어 동일성, 보조표 메타데이터, 사용자 처치명·시점명, 주요 제목의 8개 언어 검사 통과.
- 기존 WIDE/LONG 계산 비교 검사 통과. LONG 다국어 렌더링까지 검사한 것은 아니다.
- 일본어 실제 결과 fixture: `tmp/one-group-i18n/entries.rds`. 내보내기 로그: `tmp/one-group-i18n-exports.log`.
- 번역 계약 검사, 현재·누적 HTML/Word/HWPX/Excel 내용 비교 및 PDF 생성·실제 PDF 텍스트 검사 통과.

## 확인된 잔여 누락

두 개체 내 요인 설명, 모든 처치·시점의 완전 사례 조건, 처치×시점 상호작용 해석, 처치별 변화 양상 해석, 각각의 구형성 검토, 제외 대상자 설명, 혼합모형 권고 등 여러 문장이 아직 영어로 남는다. 다음 보완 대상으로 유지한다. 입력 형식 값과 자동 생성 집단 요약 등 동적 문구도 추가 점검해야 한다.

대표 결과 근거는 19개 화면, 전용 결과 검증 공백은 11개 화면으로 갱신했다. 이는 완료율이 아니며 이번 화면 역시 미완료다. 설치본은 만들지 않았다.
