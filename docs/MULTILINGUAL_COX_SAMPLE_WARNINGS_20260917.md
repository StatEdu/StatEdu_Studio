# Cox 사건 수·군집 수 경고 번역

## 변경

`low_events_per_parameter`와 `few_robust_variance_clusters`의 숫자 접두 문구를 다국어 처리에 연결했다. 근거 접두어 2개와 권고 설명 2개를 6개 추가 언어 번역표에 추가했다. 숫자 접미부와 기존 영어·한국어 출력 및 경고 판정 로직은 유지했다.

## 검증

`scripts/validate_cox_sample_warnings_i18n.R`는 실제 Cox 적합 결과를 기반으로 진단 메타데이터를 바꾸어 경계값을 검사한다. 추가 사례는 해당 표본을 다시 적합한 결과가 아니라 경고 발생·표시 분기 검사이다.

- 모수당 사건 수: 0, 4.99, 5, 9.99, 10.
- 군집 수: 1, 9, 10, 29, 30.
- 5가지 조합 × 8개 언어에서 경고 개수·심각도·숫자 보존 및 영어 잔존 여부 검증 통과.
- 본 회귀표가 모든 UI 언어에서 동일한 영어로 유지됨을 확인했다.
- 일본어 경고표 캡처로 현재·누적 결과를 저장한다. 저장 시 재분석하지 않는다.
- 산출물: `tmp/cox-sample-warnings-i18n/`.
- 현재 4개·누적 5개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지와 표 순서·시트 수 확인을 포함한다.

이번 범위는 두 경고이다. 다른 안정성 경고의 모든 분기나 전체 앱 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
