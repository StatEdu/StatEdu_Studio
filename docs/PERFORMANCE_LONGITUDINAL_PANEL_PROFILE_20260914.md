# 패널 FE/RE 분석 반복 적합 프로파일

## 확인한 구조

패널 고정효과(FE)·확률효과(RE) 분석에서 앱 적합 함수는 3회, `plm::plm`은 7회 호출된다. 선택 모형 1회, 민감도 분석 FE/RE 2회, 민감도 Hausman 검정용 FE/RE 2회, 가정 검토 Hausman 검정용 FE/RE 2회로 구성된다. 설치된 plm 함수의 trace 집계와 소스의 호출 위치를 함께 확인했다.

다음 후보는 선택 모형 재사용과 반복되는 Hausman 모형/검정의 재사용이다. 이번 작업은 프로파일링이며 제품 코드는 변경하지 않았다. 재사용의 결과 동일성이나 실제 개선율을 입증한 것은 아니다.

## 방법

번들 R 4.5.3, seed 939, 연속 반응과 공변량 2개, 대상자당 6시점. 대상자 500명/2,000명으로 3,000행/12,000행을 만들었다. FE와 RE를 모두 기본 가정 검토가 켜진 상태로 실행했다. 최종 성능 측정은 비가중 분석이다.

워밍업 후 독립 R 프로세스 3개를 순차 실행하고 두 번째 프로세스는 RE부터 실행한다. trace 없는 전체 실행을 측정하고, 별도 실행에서 앱 적합/민감도/가정 검토 함수 시간을 기록하며 plm 호출 수를 계수한다. 로딩은 제외하고 결과 캡처 및 비교용 정규화는 전체 측정에 포함한다. 부분 시간은 다른 실행이며 민감도 시간에 해당 적합 시간이 포함되므로 합산하지 않는다.

## 측정 결과

단위는 초이며 각 셀은 실행 1 / 2 / 3이다.

| 모형 | 행 수 | 전체 실행 | 민감도 분석 | 가정 검토 |
|---|---|---|---|---|
| FE | 3,000 | 0.69 / 0.65 / 0.70 | 0.64 / 0.42 / 0.64 | 0.14 / 0.14 / 0.14 |
| RE | 3,000 | 0.70 / 0.75 / 0.71 | 0.44 / 0.45 / 0.42 | 0.16 / 0.14 / 0.14 |
| FE | 12,000 | 3.66 / 3.73 / 3.67 | 2.11 / 2.11 / 2.11 | 0.89 / 0.92 / 0.91 |
| RE | 12,000 | 3.25 / 3.44 / 3.26 | 2.11 / 2.14 / 2.17 | 1.06 / 1.08 / 1.10 |

12,000행의 전체 실행 중앙값은 FE 3.67초, RE 3.26초다. 첫 프로세스에서 민감도 분석의 선택 모형 재적합은 FE 0.22초, RE 0.39초였다. 재사용 구현이 이 시간을 그대로 절약한다고 확정한 것은 아니다.

모든 12개 조건(2개 모형 × 2개 크기 × 3개 프로세스)에서 plm 호출 7회가 확인됐고, 워밍업/전체 측정/계측 실행의 결과 비교가 통과했다. 민감도에는 Hausman 검정뿐 아니라 HC1/Driscoll–Kraay 공분산 비교도 포함되므로, 민감도 시간 전체를 중복 적합 비용으로 해석하지 않는다.

## 가중 자료 확인

초기에 sampling 가중치를 포함한 FE 분석을 시도했으나 `vcovXX functions not implemented for weighted panel regressions` 오류로 결과가 생략됐다. 기존 함수는 이 오류를 skipped 결과로 반환했다. 이를 빠른 성공 실행으로 집계하지 않고, 비가중 자료의 크기를 늘려 측정했다. `skipped.rds`에 해당 결과를 보관했다.

현재 소스의 Hausman용 직접 적합은 가중치를 전달하지 않는다. 따라서 주모형의 가중 적합을 그대로 Hausman 적합 대신 사용해서는 안 된다. 본 검토에서 이 기존 동작을 변경하지 않았다.

## 동일성 범위

각 조건에서 워밍업, trace 없는 전체 측정, 계측 실행의 반환 결과를 비교한다. 모형을 포함한 list 반환 객체의 수치, 조건 클래스/본문/순서, 표준 출력, RNG를 `identical(..., num.eq = FALSE)`로 비교한다. formula/terms 환경과 함수 표현만 정규화하며 수치 허용오차는 사용하지 않는다. 원시 환경·함수 객체의 동일성까지 주장하지 않는다.
