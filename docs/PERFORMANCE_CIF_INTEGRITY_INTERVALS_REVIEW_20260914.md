# CIF 무결성 검사에서 미사용 보간 생략 검토 — 2026-09-14

누적발생률(CIF) 무결성 검사에서 사용하지 않는 Lower/Upper 보간을 생략하는 후보를 시험했다. 일반 데이터프레임과 속성 없는 유한 숫자 열일 때만 생략하고, 나머지는 기존 계산으로 돌아가도록 구성했다. CIF 보간 자체와 무결성 판정식은 유지했다.

절대 시간 개선이 작아 후보는 적용하지 않았다. 이번 변경만 있는 diff를 확인한 뒤 시작 시점 스냅샷으로 복원했으며 SHA256 일치를 확인했다. 이전 RMST 개선은 유지한다.

## 측정

번들 R 4.5.3, 앱 설정 적용, 자동 설치 비활성화. 새 프로세스에서 기준/후보 3쌍을 순차 실행하고 두 번째 쌍은 순서를 반대로 했다. 두 대상 함수를 함께 전역 환경에 연결해 CIF 무결성 검사 전체 호출을 측정했다. 각 프로세스는 곡선당 100시간점 다음 1만 시간점을 실행했다. 자료는 3집단·3원인의 9개 곡선으로 각각 총 900행과 9만 행이다. 실제 경쟁위험 추정·UI·내보내기·앱 로딩 시간은 포함하지 않는다.

| 곡선당 시간점 | 기존 3회(초) | 후보 3회(초) | 중앙값 기존→후보 |
|---|---|---|---|
| 100 | 0.03 / 0.03 / 0.01 | 0.03 / 0.03 / 0.04 | 0.03→0.03 |
| 10,000 | 0.22 / 0.22 / 0.22 | 0.21 / 0.20 / 0.20 | 0.22→0.20 |

큰 조건에서 약 9%, 절대 0.02초 감소했으나 작은 조건의 중앙값은 같았다. 이 정도 이득으로 보간 함수의 추가 인자와 예외 입력별 분기를 유지할 필요는 낮다고 판단했다. 추정기나 보간 알고리즘을 대체하지 않았다.

## 검증

- 27조건에서 전체 결과·진단·난수 상태가 정확히 일치했다. 시간점 1/2/20개, 빈 입력, 결측 CIF/Time/Group/Lower, 무한 Upper, 누락 열, 숫자 열 특수 클래스를 포함했다.
- 실제 600행 경쟁위험 분석 1건의 전체 결과·진단·난수 상태와 HTML/의존성이 정확히 일치했다.
- 시간 측정 6쌍의 결과·진단·난수 상태가 identical(..., num.eq=FALSE)로 일치했다.
- 초기 후보의 NULL 열 구성 오류는 검증에서 발견해 수정했고, 최종 후보로 검증 및 시간 측정을 수행했다.

산출물은 output/cif-integrity-intervals-20260914/의 baseline.R, current.R(미적용 후보), run.R, compare.R, summary.csv 및 결과 객체다. 실행 모듈은 기준 스냅샷으로 복원했다. 전체 서버와 PDF/Word/HWPX/Excel 변환은 재검증하지 않았으며 설치 파일도 재빌드하지 않았다.
