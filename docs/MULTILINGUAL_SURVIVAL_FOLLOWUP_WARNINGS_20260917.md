# 생존분석 추적관찰·검열 경고 번역

## 변경

추적관찰 말단 위험집단 수와 검열률의 숫자 접두어, 높은 검열률 권고, 주요 경고 없음의 근거·권고 등 5개 문구를 6개 추가 언어에 번역했다. 기존 판정·계산과 영어·한국어 문구는 유지했다.

## 검증

`scripts/validate_survival_followup_warnings_i18n.R`는 실제 Kaplan–Meier 적합 결과에 추적관찰 진단 메타데이터를 주입하여 경고 분기를 검사한다. 주입한 진단값은 새로 적합한 표본의 결과가 아니다.

- 말단 위험집단 9·10명, 검열률 .8·.801·.9와 결측값의 5가지 조합 × 8개 언어 통과.
- 경고 발생 여부와 주요 경고 없음 분기, 진단 수치 정밀도 보존 확인.
- 지정 시점 생존확률 본 표의 동일한 영어 출력 확인.
- 일본어 캡처로 현재·누적 경고표 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/survival-followup-warnings-i18n/`.
- 현재 5개·누적 6개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지와 표 순서·시트 수를 확인했다.

전체 앱 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
