# 현재 분할 결과의 보조표 언어 갱신

일원 반복측정의 성공한 분할 분석에 대해 집단별 계산 결과와 원래 캡처를 세션 메모리에 보관한다. UI 언어가 바뀌면 계산 함수를 호출하지 않고 보조표 렌더러만 호출하여 현재 캡처의 보조표 섹션(제목·표·주석)을 교체한다. 본표·그림·집단 라벨은 원래 캡처를 보존한다. 서버의 현재 저장 대상과 브라우저 분할 스냅샷을 함께 갱신한다.

이미 결과 추가로 누적된 항목은 당시의 화면 스냅샷을 유지한다. 저장할 때 새 분석을 실행하거나 결과를 다시 구성하지 않는다. 새 분석을 시작하면 이전 계산 결과 캐시도 지운다. 다른 분석, 실패한 집단이 포함된 분할, 대응하는 보조표 구성이 일치하지 않는 이전 캡처는 이번 자동 갱신 대상이 아니다.

검증 결과:

- `validate_split_appendix_language.R`: 8개 언어 및 한국어 복귀에서 보조표 언어·실제 문구와 본표 셀 보존을 확인했다. 본표에 넣은 사용자 편집 문구도 보존됐다.
- `validate_language_analysis_state.cjs`: 60행 중 30행 선택, A/B 두 집단의 실제 분할 분석에서 8개 언어를 왕복했다. 변수 배정·옵션·본표 4개 및 셀 값·누적 스냅샷은 유지됐고 현재 보조표의 언어 속성은 매번 새 언어로 갱신됐다. pageerror 없이 통과했다.
- `validate_analysis_scope.R`, `validate_one_group_rm_anova.R`: 필터·분할 순서·오래된 캡처 배제·비동기 대기·회귀 집단별 실행 및 반복측정 계산/서버 검사를 통과했다.

브라우저의 본표 비교는 표별 th/td 배열을 사용한다. XML 재직렬화로 달라진 HTML 들여쓰기와 연속 공백만 정규화하며 값·열·행·표 순서는 비교한다. 이 검사에서 언어 변경 중 설정 화면이 재생성되는 동안 기다리도록 동기화도 보완했다.

일본어로 갱신된 실제 분할 스냅샷 `tmp/language-state-localized/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교 및 실제 PDF 텍스트 검사를 통과했다. 로그: `tmp/split-appendix-language.log`, `tmp/language-state-localized.log`, `tmp/split-appendix-regression.log`, `tmp/split-appendix-exports.log`. 검증용 개발 서버는 종료했다.

설치본은 만들지 않았다. 다른 분석의 현재 분할 보조표에도 같은 지원을 확대하는 작업은 남아 있다.
