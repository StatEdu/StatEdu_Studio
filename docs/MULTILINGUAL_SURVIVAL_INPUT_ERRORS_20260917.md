# 생존분석 기본 입력 오류 — 2026-09-17

시간 변수, 사건 변수, Cox 시간 또는 시작/종료 변수, 공변량, 동률 처리 방법, 양수 RMST 제한 시간의 검증 오류 6종을 8개 언어로 추가했다. Kaplan–Meier/Cox/경쟁위험 실패 알림에서 정확히 일치하는 앱 오류만 번역한다. 외부 오류와 사용자 경로는 그대로 유지한다. 분석 함수의 검증 조건·계산·출력 표는 수정하지 않았다.

`validate_survival_input_errors_i18n.R`에서 실제 검증 실패 6종을 발생시키고, 3개 실제 실패 콜백을 소스에서 읽어 실행했다. 8개 언어의 상세 안내, 실패 시 기존 결과 초기화, 외부 상세 보존을 확인했다. `validate_survival_notices_i18n.R` 및 `validate_multilingual_coverage.R` 회귀 검사도 통과했다.

이번 범위는 기본 오류 6종이다. 사전 점검(preflight)의 복합 오류, Cox 고급 옵션 조합 및 경쟁위험 고유 검증 오류는 후속 점검 대상이다. 실제 브라우저 클릭 검증이나 전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
