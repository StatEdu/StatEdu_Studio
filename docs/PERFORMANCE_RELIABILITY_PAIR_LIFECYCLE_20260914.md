# 신뢰도 캐시의 16문항 성능 및 반복 실행 수명 검증 — 2026-09-14

운영 코드 변경 없이, 현재 캐시 적용 범위의 상한인 16문항에서 성능과 반복 실행 후 R의 생존 객체 사용량을 확인했다. 비교 기준은 캐시 통합 직전 실제 코드다. 이전에 미채택한 최적화 함수 중간값 캐시 후보는 사용하지 않았다.

## 16문항 전체 분석 시간

2,000건·16문항, 동일 확률의 5범주 완전 자료를 사용했다. 시드 719로 공통 정규 성분 0.6과 문항별 독립 정규 성분 0.8을 합성했다. 분석 시드 941, omega·normality·문항 삭제 신뢰도·문항-전체 상관 옵션을 요청했다.

번들 Windows R 4.5.3에서 버전별 새 프로세스 3개를 순차 실행하고 두 번째 쌍은 역순이었다. 조건별 준비 실행 후 GC하고 전체 `prepare_reliability_results()`를 측정했다. 준비 실행 캐시는 다음 호출로 전달되지 않는다. 캐시 검사/생성, 결과·진단·표준출력 수집을 포함하고 패키지/앱 초기화, 입력 생성, UI와 저장은 제외한다.

| 반복 | 캐시 도입 전 | 현재 |
| --- | ---: | ---: |
| 1 | 9.57초 | 1.47초 |
| 2 | 9.55초 | 1.42초 |
| 3 | 9.53초 | 1.42초 |
| 중앙값 | 9.55초 | 1.42초 |

중앙값은 **8.13초, 약 85.1% 단축**됐다. 세 쌍의 전체 반환값·경고/메시지·표준출력·난수 상태가 `identical(..., num.eq = FALSE)`로 일치했다. 각 준비/측정 결과도 같았고, 16행 문항 진단과 유한한 신뢰도 추정치를 확인했다. 이번에 17문항 성능을 새로 측정하지는 않았다. 17문항 우회 검사는 앞선 통합 기록에 있다.

## 반복 실행 후 생존 객체

시간 측정과 별개로 새 프로세스 3개에서 현재 분석을 각각 10회 실행했다. 호출마다 같은 시드와 입력을 사용하고 기준 결과와 정확히 비교한 뒤 해당 호출의 반환 객체를 제거하고 `gc()`를 실행했다. 비교용 기준 결과와 입력 자료는 프로세스 내에 계속 보관했다. 사전 할당한 기록 행렬에 R의 사용 중인 Ncells/Vcells 수를 기록했다.

| 프로세스 | 2회 후 Ncells / Vcells | 10회 후 Ncells / Vcells | 3~10회 범위 폭 |
| --- | --- | --- | --- |
| 1 | 1,803,606 / 1,705,279 | 1,803,606 / 1,705,279 | 9 Ncells / 15 Vcells |
| 2 | 1,803,605 / 1,705,279 | 1,803,605 / 1,705,279 | 9 Ncells / 15 Vcells |
| 3 | 1,803,611 / 1,705,279 | 1,803,611 / 1,705,279 | 9 Ncells / 15 Vcells |

세 프로세스 모두 2회와 10회 후 사용량이 같았다. 3회째에 작은 일시적 증가가 있었고, 두 번째 프로세스는 5회째에도 더 작은 증가 후 원래 수준으로 돌아왔다. 이 실험 범위에서 계속 누적되는 생존 객체 증가는 관측되지 않았다.

전체 30회 결과가 캐시 도입 전 기준 결과·조건·표준출력·난수 상태와 정확히 같았다. 팩토리 호출을 계수해 프로세스마다 10회 분석에 10개 새 엔진이 만들어짐을 확인했다. 엔진 객체를 검사 목적으로 계속 보관하지 않아 그 자체로 캐시 수명을 늘리지 않았다.

이는 **명시적 GC 후 R 생존 객체 사용량**의 검사다. 운영체제로의 메모리 반환, 순간 최고 작업 집합, 장시간 앱 세션 전체의 누수 부재를 증명하지 않는다. 앞선 통합 실험의 최고 메모리 증가 약 32.86 MB를 취소하거나 감소시킨 결과도 아니다. 시간 실험과 수명 실험의 프로세스는 분리했다.

## 변경 및 재현 범위

실제 운영 소스와 측정 사본의 SHA-256이 동일하다: `8F412C7A5DD4EA8535EF548DB11562A3CA6B9A059FCE807764134907EE81DFEF`. 추가 코드·화면·저장 구현 변경은 없었고, 이 자료의 내보내기를 새로 검증하거나 설치 파일을 재빌드하지 않았다.

자료는 `output/reliability-pair-lifecycle-20260914/`에 있다. `measure.R baseline|current <1..3>`이 시간과 전체 결과를 기록하고, `lifecycle.R <1..3>`가 각각 10회 수명 검사를 실행한다. `compare.R`가 전체 결과 동일성과 시간/생존 객체 기록을 집계한다.
