# 음이항 MI에 한정한 Poisson 선별 모형 재사용 검토 — 2026-09-14

직전 전체 카운트 MI 재사용 후보를 좁혀, 공통 family가 negative_binomial로 결정된 경우에만 재사용하도록 구현했다. 반복 측정에서도 일관된 개선이 없고 임시 모형 보관 비용이 발생해 제품에 반영하지 않았다. 현재 입력 범위에서는 이 선별 모형 보관 방식의 검토를 종료한다.

## 후보

선별 단계에서 조용히 수렴한 Poisson 모형을 대치 자료별로 보관한다. 경고·메시지는 억제하지 않고 관찰하고, 발생한 경우 해당 모형을 재사용하지 않는다. 공통 family가 Poisson이면 보관 리스트를 비우고 기존대로 재적합한다. 음이항으로 고정된 경우만 기존 후보의 재사용 인수를 전달받아 Poisson 재적합을 생략한다. 가중치가 있으면 기존 적합을 사용한다. 음이항 적합·공통 family 결정·표준오차·풀링은 유지한다.

공통 family는 모든 대치 자료의 과산포 중앙값을 구한 뒤 결정된다. 따라서 재사용을 음이항에 한정해도 선별 단계의 임시 보관 비용은 Poisson 입력에도 발생한다.

## 전체 분석 측정

| 입력 | 기존 3회(초) | 제한 후보 3회(초) | 중앙값 |
|---|---|---|---|
| Poisson, 2,000행 | 0.32 / 0.30 / 0.31 | 0.30 / 0.33 / 0.30 | 0.31 → 0.30 |
| Poisson, 10,000행 | 0.82 / 0.82 / 0.83 | 0.98 / 0.81 / 0.99 | 0.82 → 0.98 |
| 음이항, 2,000행 | 0.27 / 0.23 / 0.25 | 0.24 / 0.25 / 0.23 | 0.25 → 0.24 |
| 음이항, 10,000행 | 1.07 / 1.10 / 0.91 | 0.99 / 0.84 / 1.00 | 1.07 → 0.99 |

10,000행 Poisson은 세 번 중 두 번 느렸고, 음이항도 두 크기 각각 한 번 느렸다. 직전 후보 실험과 비교해 개선율을 계산하지 않고 이번 실험 내부의 기준/후보만 비교했다. 실행 시간 변동이 있으므로 이 결과가 보관 비용만의 인과적 측정이라는 뜻은 아니다. 다만 제품 도입에 필요한 일관된 전체 개선 근거는 얻지 못했다.
