# Cox 비례위험 상세 진단 및 함수형태 설명

상세 진단 제목, 검토 상태 열과 두 상태 문구, Schoenfeld 검정 설명, 평활 잔차도 설명,
Martingale loess 함수형태 설명의 7개 번역 항목을 6개 추가 언어에 보완했다.
한국어/영어 전용 제목 및 검정 설명 분기를 공통 번역 경로로 바꿨다.
PH 표의 Term 열은 공통 번역기에 전달하기 전에 이름을 변경하지 않아 사용자 변수명
보존 처리가 적용되도록 했다. 계산과 본 표는 변경하지 않았다.

## 검증

- `validate_cox_ph_i18n.R`: 실제 Cox 적합과 전체 결과 패널을 8개 언어로 렌더링하여
  상세 제목과 대상 설명의 영어 잔존 여부를 검사했다.
- 표시용 복사본에서 p=.001/.7과 사용자 변수명 Review 및 사용자 <&> %s로
  두 검토 상태, 변수명 보존을 확인했다. 복사본은 별도 적합 결과가 아니다.
- PH 수치와 본 표의 영어 유지 확인. 잔차/공선성 기존 검사 재실행 통과.
- 일본어 대상 보조표·설명 스냅샷 현재 4개 표 / 누적 6개 표의
  HTML/PDF/Word/HWPX/Excel 통과. PDF 본문·표지, 표 순서와 Excel 시트 수 확인.
  이번 내보내기 검증은 대상 표와 설명에 한정하며 전체 패널의 도표 내보내기 검증은 아니다.
  저장 시 재적합하지 않는다.

설치본은 생성하지 않았다. 시간가변 계수 확장 전 동반 모형 설명 등 다른 분기는
추가 점검 대상이며 전체 다국어 완료를 의미하지 않는다.
