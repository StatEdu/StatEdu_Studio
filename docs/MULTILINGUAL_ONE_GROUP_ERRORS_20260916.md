# 일원 반복측정 입력 오류 및 알림

엔진이 직접 발생시키는 입력/환경 오류 20종과 실행 전 블록 안내 2종, 분석 완료 알림 1종을 8개 언어에 연결했다. 알려진 오류는 키와 원래 매개변수를 보관하는 `one_group_rm_input_error` 조건으로 전달한다. 서버에서 현재 언어의 문장에 매개변수를 삽입하며 원문 오류를 정규식으로 분해하지 않는다. 엔진의 영어 오류 메시지는 기존과 동일하게 유지한다. 알 수 없는 외부 오류는 원문을 보존한다.

`scripts/validate_one_group_errors_i18n.R`는 변수/키 누락, 중복 대상자·처치·시점 조합, 대상자 내 공변량 불일치, 처치 수준/시점 수, WIDE 변수 수·중복 배정, 최소 완전 사례 및 개체 내 상수값 등 19종을 실제 엔진/입력 함수 호출로 재현했다. 모두 8개 언어에서 정확한 문장과 매개변수 보존을 확인했다. 변수명과 ID에는 `Normality`, 한국어, `%`, `for subject`를 포함했다. car 패키지 미설치 오류 1종은 조건 객체 fixture 검사이며 패키지를 제거하거나 실제 미설치 상태를 재현하지 않았다.

서버의 오류 처리 및 알림 키 연결은 소스 검사로 확인했다. 3개 알림의 번역도 검사했지만 모든 언어에서 실제 알림 팝업을 조작한 검사는 아니다.

번역 계약 검사, WIDE/LONG·공변량 유무 네 경로의 8개 언어 결과 검사, 기존 `validate_one_group_rm_anova.R`의 계산 및 Shiny 서버 회귀 검사를 모두 통과했다. 로그는 `tmp/one-group-errors.log`, `tmp/one-group-errors-regression.log`, `tmp/one-group-errors-server.log`다.

이번 변경은 오류/알림 UI에 한정되며 성공한 분석의 표·주석·그림·저장 스냅샷은 변경하지 않았다. 따라서 5종 내보내기는 재생성하지 않는다. 직전 LONG·공변량 결과 저장 검증 근거는 `MULTILINGUAL_ONE_GROUP_FORMATS_20260916.md`에 있다. 설치본은 만들지 않았다.

범주형/복수 공변량과 다른 옵션, 외부 오류, 실제 UI 언어 왕복은 남아 있다. 앱 전체 또는 일원 반복측정의 모든 분기가 완료됐다는 판정은 하지 않는다.
