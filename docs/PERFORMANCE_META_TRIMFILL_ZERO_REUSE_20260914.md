# Trim-and-fill 무보완 모형 재사용 — 2026-09-14

`meta_trimfill()`에서 보완 연구 수 `k0`가 0이면 `adjusted_fit`에 이미 계산한 `original_fit`을 사용하도록 적용했다. 이 경우 `augmented`는 원래 집계 자료이고 모형 옵션도 같아 마지막 적합이 중복된다. 보완 연구가 추가되면 기존과 같이 확장 자료를 새로 적합한다. 보완 연구 수·방향 판정, 반복 중 적합, 수렴 조건, 수치 연산은 변경하지 않았다.

## 전체 Trim-and-fill 측정

| 연구 수 | 기존 3회(초) | 후보 3회(초) | 중앙값 변화 |
|---|---|---|---|
| 40 | 0.33 / 0.33 / 0.32 | 0.23 / 0.23 / 0.22 | 0.33 → 0.23, 약 30% 감소 |
| 120 | 1.34 / 1.37 / 1.36 | 0.92 / 0.92 / 0.91 | 1.36 → 0.92, 약 32% 감소 |

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 두 번째 프로세스는 기존/후보 순서를 뒤집었고 각 조건은 준비 실행 후 GC와 경과 시간 측정을 수행했다. 연구당 효과크기 하나, -0.6부터 0.6까지 대칭인 효과값, 표집분산 0.1, g, 랜덤효과 REML, 신뢰수준 95%를 사용했다. 모든 측정에서 실제 `k0 == 0`을 확인했다.

시간에는 연구별 집계·최초 적합·보완 수 추정 반복·최종 반환값 생성 및 경고/메시지 수집을 포함한다. 소스 로딩·자료 생성·화면·저장은 제외한다. 이 개선율은 **보완 연구가 없는 해당 입력의 Trim-and-fill 시간**이며, 보완 연구가 있는 경우나 전체 메타분석의 개선율은 아니다. 메모리는 측정하지 않았다.

## 결과 검증

- 크기 2개 × 새 프로세스 3개에서 기존/후보의 준비 및 측정 결과를 `identical(..., num.eq=FALSE)`로 비교했다. 전체 모형을 포함한 반환값, 경고/메시지 문자열, 난수 상태 모두 일치했다.
- 적용 후 실제 소스로 저장된 기존 결과 6개를 다시 비교해 모두 일치했다.
- 신규 `scripts/validate_meta_trimfill_reuse.R`: g/r/OR × 고정효과/REML/PM/DL × 대칭/양·음 비대칭 자료의 36개 정상 조건에서 전체 반환값과 한글·영문 결과표가 정확히 일치했다. 실제 무보완 24개, 보완 발생 12개로 두 분기를 모두 확인했다.
- 반복 횟수 0, 연구 수 부족, 출판연도 결측·오류, 분산 결측, 잘못된 rho, 연구 내 복수 효과의 7개 조건도 일치했다. 합계 43개 조건에서 오류/경고/메시지 클래스·문자열, 표준출력, 난수 상태를 함께 비교했다. 조건 객체의 호출 환경은 비교하지 않는다.
- 기존 `validate_meta_analysis_model.R`, `validate_meta_analysis_ui.R` 통과. 앞선 3수준 및 연구별 제외 최적화 코드는 유지했다.
