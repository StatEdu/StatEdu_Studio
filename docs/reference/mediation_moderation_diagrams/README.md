# Mediation / Moderation Diagram Reference

This folder stores review-only reference materials for mediation and moderation
model diagram positioning.

Files:

- `mm_implemented_positions_reference.png`: visual reference for the implemented
  result-diagram position rules.
- `mm_implemented_positions_reference.svg`: SVG source for the same reference
  image.
- `generate_mm_diagrams.R`: ad hoc script used to generate a full diagram
  preview from the current app functions.
- `mm_diagrams_preview.html`: generated preview output for model and variable
  count combinations.

Notes:

- These files are not loaded by the application at runtime.
- The preview script and HTML may contain legacy encoding artifacts in Korean
  text. Treat them as development reference material, not user-facing content.
