# Historical technical records

The four `ANALYSIS_METHODS_*` / `METHOD_NOTES_*` documents and two `CHANGELOG_ARCHIVE_*` documents in this directory preserve the earlier Korean/English technical content and release history. Their old version labels and availability statements describe the records at the time of preservation, not the current public release.

For the current 1.3.0 scope, use `docs/ANALYSIS_METHODS_<LANG>.md`, `docs/METHOD_NOTES_<LANG>.md` and the current root changelog. These current documents cover eight UI languages. The historical formula/reference material is available only in Korean and English.
