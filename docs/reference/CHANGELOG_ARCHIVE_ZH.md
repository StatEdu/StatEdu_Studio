# 版本历史

## v1.2.0 - 2026-08-06

### 新增

- 将评定者间一致性分析加入公开版，优先显示推荐指标，同时保留辅助指标。
- 新增用于前后测及多时间点组间比较的混合重复测量 ANOVA，支持 PP/ITT 分析、协变量调整摘要、假设检查、事后比较及 HTML/PDF/Excel 导出。
- 在公开版的回归/模型工作流组中新增中介/调节自定义模型画布。

### 变更

- 将 1.1.3 之后已稳定的开发成果纳入正式版 `1.2.0` 元数据。
- 将重复测量 ANOVA 整合到组间比较菜单，并使设置布局、假设检查选项、球形性/Levene 检验、正态性指引和建议措辞与 StatEdu Studio 的引导式分析流程一致。
- 扩大统计验证范围，覆盖相关、信度、评定者间一致性、因子分析/PCA、t 检验/ANOVA、配对重复测量、回归、逻辑回归、纵向/面板、惩罚回归、样本量、效应量、数据编辑、自定义模型和混合重复测量工作流。
- 修改韩语自定义模型菜单名称，使公开版导航更清晰。

### 修复

- 修复打包的 Electron 公开版启动器，使 1.2.0 安装包默认启用中介/调节自定义模型画布。
- 清理重复使用已拟合自定义模型结果时产生的重复结果行。

- 为新增潜变量分析项目文件夹标签、数据文件占位提示、DAT 分隔符选项和共用分析控件添加多语言支持。

### 修复

- 将 Latent Mplus 设置保存改为打开保存对话框，以便选择文件名。

## v0.9.39 - 2026-06-18

### 新增

- 新增独立的 `Analysis > Longitudinal / Panel Models`，支持 GEE、LMM、GLMM、面板固定效应及随机效应模型。
- 为纵向/面板结果新增模型专属假设检查、推荐替代方法、自动敏感性比较、可发表估计值、论文文本、SCI 报告清单和软件版本报告。
- 为纵向/面板新增缺失选项卡，支持主要缺失数据处理、实际 MI/IPW/WGEE 敏感性引擎及报告级缺失数据方法跟踪。
- 新增纵向分析权重，支持单一权重变量目标、抽样/纵向/IPW/组合权重类型、截尾、最终权重标准化及有效样本量报告。
- 为纵向计数/发生率模型新增可选暴露量/偏置项处理，包括主分析及敏感性拟合中的 `log(exposure)` 偏置项。
- 新增计数模型零膨胀筛查详情，比较观测零值比例与 Poisson 期望零值比例。
- 新增可执行的 `Analysis > GLM`，支持 Gaussian、二元逻辑、Gamma 和计数 GLM，并复用 GEE 计数分布筛查方式选择 Poisson 或负二项模型。
- 为 GLM 新增面向 SCI 的报告详情，涵盖完整案例缺失处理、Poisson/负二项选择、逻辑回归 EPV/分离/稀疏单元格筛查、观测独立性检查、影响诊断、发表表注、报告清单和建议论文文本。
- 新增选项卡式 GLM 设置，其中缺失选项卡支持完整案例、多重插补及逆概率加权缺失处理。
- 在韩语用户指南、分析方法和方法说明中新增 GLM 文档，涵盖分布/链接选择、缺失数据敏感性、稳健 SE 选项、计数过度离散及 SCI 报告要求。
- 新增 GLM 输出的 HTML、PDF、Excel 及已保存结果集合支持，包含发表说明、SCI 清单、论文文本和软件版本工作表。
- 新增纵向/面板模型输出的 HTML、PDF、Excel 和已保存结果集合支持。
- 新增纵向/面板模型拟合、GLM 拟合、设置 UI 结构、假设检查目录、HTML/Excel 导出、敏感性比较和 SCI 报告部分的验证。

### 变更

- 使纵向/面板设置采用现有 t 检验/ANOVA 式传送布局，并按条件仅显示相关模型选项。
- 合并纵向/面板的模型和项选项，在同一选项卡设置模型类型、固定时间项和随机效应项。
- 将 GEE 默认工作相关结构改为可交换，并在 AR(1) 拟合时向 `geepack::geeglm` 传递受试者/时间波次顺序。
- 由于 geepack 不原生提供负二项 GEE，将其负二项拟合标为采用受试者聚类稳健 SE 的边际负二项 GLM。
- 明确可选 Cluster ID 用作 LMM/GLMM 的额外随机截距分组变量，不用于所选 GEE/面板主拟合。
- 明确 LMM/GLMM 缺失处理为使用可用重复测量的基于似然的 MAR 分析，MI/IPW 保留为敏感性分析而非默认主拟合。
- 为避免增加较重的可选包依赖，默认纵向/面板模块不纳入零膨胀及障碍计数模型；过多零值作为筛查提示报告。
- 将旧 Generalized 框架替换为可运行的 GLM 设置、执行处理、系数表、拟合统计、稳健 SE 选项、过度离散检查和可选 VIF 诊断。
- 使 `run_app.R` 与 `R/app_bootstrap.R` 一致，让启动器安装包时使用与应用运行时相同的必需包清单。
- 将 Electron 运行时固定版本更新为 39.8.6，并在软件包审计后刷新锁定文件。
- 强化 Electron 测试版构建脚本，使其可在 PATH 外找到 Rscript，且不会因打包应用排除的可选潜变量 Mplus 模块而失败。
- 针对新增纵向/面板和 GLM 工作流更新 README、韩语用户指南、分析方法及方法说明。
