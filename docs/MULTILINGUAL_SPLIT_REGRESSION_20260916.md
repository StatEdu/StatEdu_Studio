# 회귀 분할 결과의 언어 전환 검증

## 변경

- 일반·위계 회귀의 집단별 결과가 확정될 때 모델, 변수 메타데이터, 표시 옵션을 보관한다.
- UI 언어 변경 시 저장한 모델에서 보조표 표시만 다시 만들고 현재 분할 결과의 보조표 영역을 교체한다. 재적합하지 않는다.
- 본표와 잔차 그림은 캡처한 원본을 유지한다. 누적 결과는 기존 저장 스냅샷을 유지한다.
- 현재 지원 범위는 동일 대상 내 처치 반복측정 분산분석과 회귀다. 다른 분석의 현재 분할 결과 언어 전환까지 완료했다는 의미가 아니다.

## 검증

- `validate_split_regression_language.R`: 실제 2블록 회귀를 8개 언어로 변환, 보조표 언어와 사용자가 편집한 본표 셀 보존 통과.
- `validate_split_regression_browser.cjs`: 실제 Chrome에서 80행을 두 집단으로 분할하고 일반 회귀 실행. 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 왕복 후 보조표 언어, 본표 셀, 잔차 그림 4개의 원본 데이터 일치. 페이지 오류 없음.
- 기존 `validate_split_appendix_language.R`의 반복측정 결과 변환과 본표 편집 보존 통과.
- `validate_analysis_scope.R`: 케이스 선택, 분할 순서, 이전 캡처 거부, 비동기 완료 대기, 일반·위계 회귀의 집단별 독립 적합 통과. Windows UTF-8 locale을 먼저 설정하여 실행했다.
- 일본어 브라우저 캡처 `tmp/split-regression-localized/entries.json`에서 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 통과. PDF 추출 본문과 표지 검사 통과.
- `validate_split_regression_images.py`: Word/HWPX/Excel의 그림 파일은 캡처 PNG와 SHA-256 일치. 현재 4개, 누적 8개의 그림 배치와 PDF 그림 수 확인.

## 남은 범위

- 위계 회귀는 이번에 2블록 모델의 변환 검사로 확인했으며, 실제 브라우저 분할 왕복은 일반 회귀로 수행했다.
- Bootstrap 등 모든 회귀 옵션·오류 분기의 언어 왕복을 확인한 것은 아니다.
- 다른 분석의 분할 결과와 전체 화면 검증 공백은 기존 상태표대로 남는다. 설치본을 만들지 않았다.
