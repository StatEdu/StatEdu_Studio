# GLM 변수 코딩·결측자료 설명 다국어 보완

2026-09-16. 설치본 생성 없이 소스만 변경.

## 변경

- 변수 코딩 5개 및 결측자료 처리 10개 고정 설명을 일본어·중국어·스페인어·프랑스어·독일어·베트남어로 추가했다. 기존 한국어 설명은 유지했다.
- 기준 수준 확인 실패, 순서형 대비, 이분형 사건 코딩, 연속형 계수, 코딩 요약 부재를 포함한다.
- 종속변수 결측 제외/대치, 결측 없는 MI/IPW 처리, 역확률가중, 절편만의 관측모형, 단위 가중치, 양성성 및 가중치 절단 안내를 포함한다.
- 모델 계산, 선택 값, 영어 본표 및 사용자 이름·라벨을 변경하지 않는다.

## 검증

- `scripts/fixtures/glm_i18n_missing_coding.json`의 15개 설명을 GLM 검사에 추가했다.
- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 번역 설명과 같은 사용자 Variable 값의 보존, Gaussian/binomial/count 실제 분석 본표 영어 유지, 옵션 값 보존을 확인했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 보조표 fixture의 현재/누적 HTML·Word·HWPX·Excel 내용 비교와 PDF 생성 통과. PDF 실제 텍스트 비교도 통과했다.
- 합성 카운트 데이터에서 기존 음이항 추정 반복 한도 경고가 발생했다. 출력 검증은 통과했으며 이번 변경은 추정 코드를 건드리지 않았다.

## 남은 점검

이번 변경은 고정 설명에 한정한다. 실제 범주명·수치가 삽입되는 변수 코딩 및 MI 설명, 분포 선택 사유, 원고 문장 등은 추가 점검이 필요하다. MI/IPW의 모든 계산 분기를 새로 실행한 것은 아니며 설명 문장은 보조표 fixture로 검증했다. 내보내기 검증은 일본어 기준이다.
