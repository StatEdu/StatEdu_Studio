SEM 기준 완료: 200회/4작업자의 완전자료·10% 결측을 각 3회 측정(중앙값 3.908초/7.487초). 결측 경로의 별도 100회 기준 비교에서 인덱스·유효 마스크·계수와 요약이 timing 속성 제외 후 정확 일치했다. `PERFORMANCE_SEM_COMPLETE_MISSING_CURRENT_20260915.md` 참조. 5,000회 및 제품지표 모형은 미측정이며 다음은 결측 재적합 내부 프로파일이다.

결측 작업자 프로파일 완료: 실제 재적합 약 96%, 그 안의 모형 최적화 약 65~67%, 표본 통계 준비 약 18~19%를 3회 관측했다. `PERFORMANCE_SEM_MISSING_WORKER_PROFILE_20260915.md` 참조. 계측 전후 결과는 timing 속성 제외 후 정확 일치했다. 다음은 표본 통계 준비의 입력 변환/결측 패턴 비용 검토다.

표본 준비 검토: 비용 대부분이 결측 평균·공분산 EM(전체 약 17%)이고, 패턴 구성은 약 0.6~1.1%였다. mp/yp 전달과 NULL일 때만 준비하는 구조를 확인했다. `PERFORMANCE_SEM_MISSING_PREPARATION_REVIEW_20260915.md` 참조. 전체 준비 캐시를 적용할 근거가 없으며, 추가 검토 시 최적화/행렬 연산의 동일 입력 중복 여부를 먼저 확인한다.

행렬 호출 감사: 재표집 3개 직접 적합에서 역행렬 갱신 함수의 전체 인자 재호출 약 13~14% 확인. LRU 모의계산상 64개 용량에서 해당 반복을 포함했다. `PERFORMANCE_SEM_MATRIX_REPEAT_AUDIT_20260915.md` 참조. 캐시는 아직 구현/성능 검증하지 않았으며 다음 후보는 적합 내 제한된 재사용이다.

64개 캐시 후보 보류: 실제 적중(첫 표본 380/2812)을 확인했으나 재적합 시간 9개 비교 모두 증가했다. `PERFORMANCE_SEM_MATRIX_CACHE64_REVIEW_20260915.md` 참조. 제품 미반영. 다른 입력/구현의 이득을 뒷받침할 새 근거 없이 이 후보를 반복 검토하지 않는다.

## 이번 정리의 범위

기존 성능 문서 388개와 R 모듈 226개의 목록을 생성하고, 최근 작업 기록 및 과거 종합 감사에서 다음 측정 후보를 대조했다. 388개 문서의 모든 실험을 재검증한 것은 아니다. 주요 분석은 이미 검토 기록이 있으므로 분석 이름만 보고 ‘미검토’로 분류하지 않는다. 이번 작업은 검토 목록과 후속 측정 범위를 정리했으며 실행 코드는 변경하지 않았다.

`scripts/inventory_performance_reviews.ps1`은 문서 제목·해시와 R 파일별 해시·정확한 파일명 언급 문서 목록을 생성한다. 초회 검색에서 172개 모듈은 성능 문서에 파일명 그대로 등장하지 않았지만, UI 분리 모듈이거나 함수명·분석명으로 검토됐을 수 있다. **172개 미검토 모듈이라는 뜻이 아니다.** 성능 문서 외의 기능·정확성 검증 기록도 별도로 확인해야 한다.

## 측정·동일성 기준

- 함수 소싱 환경과 하위 함수 컴파일 상태를 맞춘다. 첫 호출 비교는 각각 새 프로세스로 하고, 반복 호출은 동일한 준비 후 비교한다.
- 성능 측정은 순차 실행하고 순서를 교차한다. 프로파일은 별도 실행한다. 경과 시간에 포함된 준비/캡처/검증 비용을 명시한다.
