# 추가 추천 분기와 진행 제한 안내

검증 대상은 원인별 Cox, Fine–Gray, CIF/Gray 집단 비교, 추정량 미선택의 확인 필요, 예측 모형의 현재 미지원 상태다. 생성 CSV로 실제 사전검사와 추천을 실행한다.

`validate_survival_remaining_recommendations.R`는 추천 엔진이 반환한 이름·확인 안내·지원 제한 이유의 8언어 기대값을 만든다. `validate_survival_remaining_recommendations_browser.cjs`는 실제 Chrome에서 각 추천을 실행하고 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어로 전환하여 해당 번역문과 버튼 유무를 검사한다. 실행 가능 세 분기는 버튼을 눌러 분석 화면의 회귀 추정량·시간·사건·집단·공변량·경쟁사건 코드가 전달되었는지 확인한다. 브라우저 기대값은 앱 번역 함수를 사용하므로 번역 연결 검증이며 독립적인 번역 품질 감수는 아니다.

`validate_survival_recommendation_names_i18n.R`도 재실행하여 768개 설정 조합의 15개 서로 다른 추천 유형에 대한 8언어 생성 화면 검사와 사용자 문구 보존을 확인한다. 모든 768개 조합을 실제 브라우저에서 실행한 것은 아니다.

로그: `tmp/survival-remaining-browser.log`, `tmp/survival-remaining-all-rules.log`. 분석 적합·결과·내보내기를 변경하지 않고 설치본은 만들지 않는다.

5개 분기 × 8언어 브라우저 검사 및 15개 추천 유형의 생성 화면 재검사가 모두 통과했다. 확인 필요·미지원 상태에서 이동 버튼이 없었고, 실행 가능한 세 분기는 대상 변수와 추정량이 정확했다. 페이지 오류가 없었으며 이번 범위에서 제품 수정이 필요한 새 문제는 발견하지 않았다. 테스트 브라우저와 서버를 종료했다. 그 밖의 반복 사건·다상태·구간 검열·지연 진입 경쟁위험·시간의존 확인 안내는 생성 화면 검증까지이며 실제 브라우저 검증과 구분한다.
