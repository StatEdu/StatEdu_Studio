# VIF 보조회귀 요약 생략 후보 검토 — 2026-09-13

## 결론

운영 코드는 변경하지 않았다. `coefficient_collinearity()`에서 보조회귀의 R²만 사용하지만 `summary(fit)`는 표준오차·검정값과 공분산 역행렬도 만든다. 정상적인 무가중 절편 모형에서 이 계산을 생략하는 후보를 시험했으나 절대 절감량이 작아 적용하지 않았다.

## 후보와 측정

동봉 R 4.5.3의 `summary.lm` 소스를 읽고 동일한 적합값·잔차 제곱합 연산 순서로 R²를 계산했다. 가중치·offset·절편 없음·작은 rank·잔차 자유도 부족·비유한 QR·거의 완벽한 적합은 원래 `summary()`로 되돌리는 조건을 두었다. 후보는 출력 디렉터리 안의 실험 코드에만 존재한다.

500행 정규 합성 자료, 절편 포함, 변경 전/후 순서를 교대하여 3회 측정한 중앙값:

| 예측변수 수 | 기존 | 후보 |
|---|---:|---:|
| 10 | 0.00초 | 0.01초 |
| 30 | 0.05초 | 0.04초 |
| 60 | 0.19초 | 0.17초 |

10변수의 짧은 시간은 측정 해상도와 변동 때문에 성능 차이로 해석하기 어렵다. 60변수에서도 절감량은 0.02초다. 세 정상 자료의 VIF·Tolerance·경고·난수 상태는 `identical(..., num.eq=FALSE)`로 일치했다. 예외 입력 전반과 R 버전별 동등성을 검증한 것은 아니다.

이 변경은 R의 내부 수치 요약 규칙을 별도로 유지해야 하므로, 현재 관측된 이득만으로 운영 코드에 추가하지 않았다. 보조회귀 적합 자체는 그대로여서 큰 가속을 기대하기 어렵다. 공분산 역행렬에서 VIF를 직접 얻는 다른 공식은 부동소수점 결과나 특이 모형 처리에 영향을 줄 수 있어 구현하지 않았다.

선형회귀 부트스트랩에는 이미 `stats::.lm.fit`를 사용하는 전용 적합 함수가 있으므로 이를 새 최적화 성과로 계산하지 않았다.
