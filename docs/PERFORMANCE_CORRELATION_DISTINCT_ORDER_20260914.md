# 순서형 상관의 고유 범주 변환 — 2026-09-14

## 적용 결과

`R/analysis_correlation.R`의 `correlation_ordered_vector()`에 고유 범주를 먼저 변환한 뒤 관측치 순서로 복원하는 경로를 적용했다. 1만 행·20변수의 변수별 결측 10% 조건에서 전체 잠재 상관분석 중앙값이 4.48초에서 2.67초로 약 40.4% 줄었다.

기존 캐시 적중 여부를 먼저 확인한다. 캐시 사용이 허용된 속성 없는 숫자 벡터 중 길이 128 이상인 integer/double 입력만 고유값을 확인한다. 고유값이 64개 이하이고 모두 유한하면 `ordered(distinct, levels=levels)[match(values, distinct)]`를 사용한다. 나머지는 원래 `ordered(values, levels=levels)` 경로다. 지정 범주 순서와 사용하지 않는 범주 수준을 유지하며 polycor 추정기·표준오차·검정 설정은 바꾸지 않는다. 경고/메시지 발생 시 결과를 캐시에 넣지 않는 기존 동작도 유지한다.

## 실행 시간

번들 R 4.5.3, polycor 0.8.2, 시드 33, 1만 행·20변수, 190쌍에서 측정했다. `latent_correlations=TRUE`, `continuous_method='auto'`, `normality=TRUE` 조건이다. 순서형은 세 범주, 이분형은 두 범주, 결측 조건은 순서형 각 변수에 서로 다른 무작위 결측 10%를 넣었다.

새 프로세스에서 변경 전후 3쌍을 순차 실행하고 두 번째 묶음은 순서를 반대로 했다. 각 프로세스는 순서형→이분형→결측 순서다. 전체 `prepare_correlation_results`와 진단 수집을 측정했으며 입력 생성·로딩·화면·저장은 제외했다. 다른 R 검증이나 프로파일링을 시간 측정과 동시에 실행하지 않았다.

| 조건 | 변경 전 3회(초) | 변경 후 3회(초) | 중앙값 전→후 |
|---|---|---|---|
| 순서형 완전 자료 | 3.03 / 3.00 / 3.00 | 2.87 / 2.87 / 2.91 | 3.00→2.87 |
| 이분형 완전 자료 | 1.61 / 1.61 / 1.60 | 1.52 / 1.55 / 1.55 | 1.61→1.55 |
| 순서형, 변수별 결측 10% | 4.50 / 4.45 / 4.48 | 2.67 / 2.67 / 2.67 | 4.48→2.67 |

표본별 개선율이며 모든 입력에서 같은 개선을 보장하지 않는다. 많은 고유값을 가진 입력에서는 추가 unique 검사 후 원본으로 복귀하는 비용이 있고, 그 경우의 성능은 이번에 측정하지 않았다. 최대 메모리 사용량도 측정하지 않았다.

## 결과 검증

- `scripts/validate_correlation_distinct_order.R` 추가: 입력·범주 목록·scipen 조합 297조건을 기본 `ordered()`와 비교했다. 첫 호출·반복 호출·역순 입력의 891개 비교 모두 반환값·오류/경고/메시지·표준출력·난수 상태가 동일했다. 정수/실수, 서로 가까운 소수, 매우 작거나 큰 값, 비유한값, 중복 수준, 미사용 수준, 빈 입력, 이름 속성, 고유값 64/65 경계를 포함한다. 실제 적용된 소스로 재검사했다.
- 전체 잠재 상관분석 24조건과 쌍별 추론·진단·난수 상태가 동일했다. 240행으로 변경해 충분한 관측치가 있는 조건은 새 경로를 실행하게 했으며, 분리된 결측 패턴 등은 원본 복귀/추정 불가 경로도 검사한다.
- 범주 순서·클래스·비유한값·빈 입력 12조건 및 연속 호출 26조건에서 동일했다.
- 경고/메시지 주입 검사에서 호출 수·진단 순서·결과·난수 상태가 동일했다. 기존 테스트의 '이전 최적화보다 ordered 호출 횟수가 감소한다'는 단언은 이번 방식에 맞지 않아 '호출 횟수가 유지된다'로 고쳤다. 이번 개선은 호출 수보다 한 호출에서 변환하는 원소 수를 줄인다. 해당 입력도 240행으로 높여 재실행했다.
- 시간 측정 결과 9쌍의 전체 반환값·진단·난수 상태가 동일했다.

동일성은 `identical(..., num.eq=FALSE)`로 확인했으며 수치 허용오차나 환경 정규화는 사용하지 않았다.
