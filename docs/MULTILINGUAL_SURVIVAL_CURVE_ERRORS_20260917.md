# 조정 생존곡선·RMST 안내 — 2026-09-17

조정 생존곡선 집단 변수의 부재·범주형 요구·관측 수준 부족, 생명표의 지연 진입 제한, RMST 제한 시간의 집단별 추적 기간 범위 오류 등 5종을 8개 언어로 추가했다. 기존 UI 오류 번역 함수에 연결했으며 계산/검증 조건은 변경하지 않았다.

`validate_survival_input_errors_i18n.R`에서 실제 함수에 조건별 자료를 전달하여 추가 오류를 발생시켰다. 기존 항목 포함 31종의 실제 오류, 3개 실패 콜백, 결과 초기화와 외부 오류 보존 검사가 8개 언어에서 통과했다. 번역 커버리지 검사도 통과했다.

사전 점검의 복합 오류와 경쟁위험 고유 오류는 남아 있다. 분석 결과 본 표·보조표·저장 내용은 변경하지 않았으며 실제 브라우저 검증과 설치본 생성은 하지 않았다.
