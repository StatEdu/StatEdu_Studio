# 반복측정 최적화 3종 통합 검증 — 2026-09-14

## 결론

변화 여부 검사, Friedman 동순위 빈도 계산, Wilcoxon 사후검정 동순위 빈도 계산을 함께 적용한 현재 코드를 세 변경 전 기준본과 비교했다. **12개 자료 조건 × 독립 실행 3회 = 36회 모두 전체 실행 시간이 단축됐다.** 전체 반환값·진단·표준출력·RNG가 정확히 일치했고, 별도 원시 검정 348개도 일치했다.

이번에는 제품 코드를 추가 수정하지 않았다. 이미 적용한 세 최적화가 함께 동작하는지와 자료 조건을 넓혔을 때의 성능을 확인한 작업이다. 이전 개별 보고서의 개선율을 더하거나 곱한 수치가 아니다.

## 자료 및 측정 방법

- 번들 R 4.5.3, 각 자료 생성 seed 939, 결과 capture seed 718.
- 입력 5,000행, 측정 횟수 3/6/12, 연속형 정규 난수 또는 순서형 1~5 균등 표본.
- 결측률 0 또는 셀별 독립 확률 10%. 완전 사례만 분석하는 기존 처리를 그대로 사용한다. 결측률 10%가 행의 10% 제거를 뜻하지 않는다.
- 10% 조건의 완전 사례 수는 3회 측정 연속형/순서형 3,636/3,625명, 6회 2,676/2,653명, 12회 1,358/1,403명이다. 결측 없는 조건은 모두 5,000명이다.
- `prepare_nonparametric_paired_rm_single_result()` 전체: 중앙값/IQR 요약, Holm 사후 조정, 표시표 생성 포함. 사후검정 쌍은 측정 횟수별 3/15/66개다.
- 3개의 새 R 프로세스를 순차 실행. 각 조건에서 기존/현재를 예열한 후 전체 경과 시간을 측정. 두 번째 프로세스는 측정 횟수·측정 수준 순서와 기존/현재 실행 순서를 뒤집었다.
- 첫 프로세스의 각 조건에서 전체 실행 측정이 끝난 후 원시 검정을 별도로 비교했다. 이 추가 검증 시간은 전체 실행 시간에 포함하지 않는다.

## 결과 동일성

- 36개 실행 조건에서 기존/현재 예열과 실측의 전체 반환값을 `identical(..., num.eq=FALSE)`로 비교했다. 경고·메시지와 오류의 클래스/문구, 표준출력, RNG도 비교했다. 각 기존 분석은 오류 반환이 아님을 명시적으로 확인했다.
- 원시 검정 348개: 12조건의 Friedman 결과 12개와 해당 조건의 모든 Wilcoxon 사후검정 336개. 원시 통계량·p값·자유도·이름·클래스를 포함한 전체 `htest`와 진단·표준출력·RNG가 정확히 일치했다.
- 반환 객체 정규화나 수치 허용 오차를 적용하지 않았다. 원시 검정 비교는 첫 프로세스에서만 수행했으며 후속 실행의 `raw htest: 0`은 검증 실패가 아니라 반복하지 않았다는 뜻이다.

이번 자료는 정상 분석과 무작위 결측을 중심으로 한다. 영 차이·상수·Inf·작은 표본·오류 경계 및 코드 서명 불일치 시 원래 함수 복귀 검증은 앞선 개별 보고서와 `validate_paired_rm_change_check.R`, `validate_friedman_ties.R`, `validate_wilcoxon_ties.R`에 있다. 이번 작업에서 해당 검사를 불필요하게 재실행하거나 테스트 수에 더하지 않았다.
