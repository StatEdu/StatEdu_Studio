# 반복측정 비모수 분석의 현재 병목 — 2026-09-14

## 결론

앞선 변화 여부 검사 최적화를 포함한 현재 코드에서는 Friedman 검정이 가장 큰 구간이다. 20,000행 × 6회 측정에서 별도 계측한 Friedman 호출은 1.20~1.27초, Wilcoxon 사후검정 15회는 연속형 0.74초, 순서형 0.26~0.30초였다. 요약표 생성은 0.01~0.03초였다.

이번 작업은 병목 위치를 좁히는 측정이다. 제품 코드를 추가 수정하지 않았다. 성능 개선을 새로 적용했다거나 전체 실행 시간이 단축됐다는 의미는 아니다.

## 재현 조건

- 번들 R 4.5.3, 현재 앱 모듈과 환경설정 로드.
- 데이터 seed 939, 20,000행 × 6열. 연속형: `rnorm()`, 순서형: 1~5 균등 표본. 결측치 없음.
- `prepare_nonparametric_paired_rm_single_result()`를 기본 옵션으로 호출. 전체 결과에 Friedman 검정, 15쌍 Wilcoxon 사후검정, 요약표와 표시표를 포함.
- 3개의 별도 R 프로세스를 순차 실행. 각 조건에서 예열 후 계측 없는 전체 실행 시간을 측정. 두 번째 프로세스는 순서형부터 실행.
- 다음 별도 호출에서 앱 함수 래퍼로 구간별 경과 시간과 호출 횟수를 기록. 연구 환경에 로드한 함수에서만 Friedman/Wilcoxon 호출을 계측 래퍼로 연결했다. 제품이나 stats 네임스페이스는 수정하지 않았다.
- 첫 번째 프로세스에서 추가 별도 호출로 `Rprof(interval=.01)` 샘플링. 샘플링 시간과 비율은 전체 경과 시간과 다르다.

## 측정 결과

| 구간 | 연속형 1/2/3 (초) | 순서형 1/2/3 (초) |
|---|---|---|
| 계측 없는 전체 실행 | 2.00 / 1.89 / 1.98 | 1.39 / 1.53 / 1.41 |
| 별도 계측 Friedman 1회 | 1.21 / 1.27 / 1.25 | 1.22 / 1.20 / 1.22 |
| 별도 계측 사후검정 전체 | 0.77 / 0.75 / 0.77 | 0.31 / 0.31 / 0.31 |
| 위 사후검정에 포함된 Wilcoxon 15회 | 0.74 / 0.74 / 0.74 | 0.28 / 0.26 / 0.30 |
| 별도 계측 요약표 | 0.02 / 0.01 / 0.01 | 0.02 / 0.03 / 0.01 |

구간 계측은 전체 시간과 다른 호출에서 수행되므로 합산해서 전체와 비교하거나 비중을 산출하지 않는다. 사후검정 전체와 Wilcoxon 시간도 포함 관계라 합산하지 않는다. 변화 여부 검사와 표시표는 이번 조건에서 타이머 해상도 미만이었다. 0초는 실행되지 않았다는 뜻이 아니며 호출 횟수는 각각 1회다.

## 내부 병목 근거

Rprof의 Friedman 누적 샘플 비중은 연속형 62.41%, 순서형 78.90%였다. `tapply`는 각각 48.94%, 63.30%였고, `factor`는 60.28%, 40.37%였다. 이들은 중첩된 호출이므로 비율을 합산하지 않는다. 샘플링 기록 길이는 각각 1.41초, 1.09초로, 위의 계측 없는 전체 경과 시간과 동일하지 않다.

설치된 `stats:::friedman.test.default` 소스를 직접 확인했다. 순위 행렬 `r`을 만든 뒤 `TIES <- tapply(c(r), row(r), table)`로 각 행의 동순위 빈도표를 만들고, `sum(unlist(lapply(TIES, function(u) u^3 - u)))`를 보정항에 사용한다. 현재 관측은 이 범주화·빈도표 구간을 다음 후보로 검증할 근거다. 순위 계산 전체를 교체하거나 동순위를 무시해도 된다는 근거는 아니다.

다음 후보는 동순위 보정항 생성 비용을 줄이되 기존 통계량의 계산 순서와 값이 그대로인지 확인하는 것이다. 특히 연속형의 동순위 없는 입력뿐 아니라 순서형의 다수 동순위, 모든 값이 같은 행, 결측 행 제거, Inf와 작은 표본을 함께 검증해야 한다. 아직 후보 구현·성능 비교를 수행하지 않았으므로 적용 여부는 결정하지 않았다.
