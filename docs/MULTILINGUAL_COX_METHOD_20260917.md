# Cox 동적 방법 설명

Cox의 추가 6개 언어에서 방법 설명을 번역 템플릿으로 구성한다. 시간 원점·단위,
변수명, 스플라인 자유도, 동률 처리 방식은 번역 후 삽입하여 사용자 입력을 보존한다.
기존 영어/한국어 분기는 유지했다. 번역 템플릿 10개를 추가했다.

## 검증

- `validate_cox_method_i18n.R`: 실제 기본 Cox 결과를 바탕으로 기본/지연진입/
  시간의존/층화/군집/스플라인/시간가변의 7가지 표시 메타데이터 조합을 8개 언어로 검사.
  각 조합을 새로 적합한 검사가 아니라 동적 설명 조합 검사다.
- 시간 원점·단위·변수명의 특수문자 및 서식 토큰 보존, 설정값 보존, 빈 값 기본 문구,
  영어 본 표 유지 확인.
- 기존 실제 스플라인 자유도 3/4의 전체 패널 다국어 검사 통과.
- 일본어 설명을 포함한 현재 7개 / 누적 8개 표 스냅샷의
  HTML/PDF/Word/HWPX/Excel 내용 검사 통과. PDF 본문·표지, 표 순서·시트 수 확인.
  파일 저장 시 재적합 없음.

설치본은 생성하지 않았다. 경쟁위험 및 Kaplan–Meier/생명표의 동적 방법 설명은
이번 변경 범위에 포함되지 않았으며 다음 점검 대상이다.
