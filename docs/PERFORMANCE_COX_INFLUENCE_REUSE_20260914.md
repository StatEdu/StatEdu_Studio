# Cox 영향 잔차의 제한적 재사용 — 2026-09-14

> 검증 범위 정정 (2026-09-14): 아래의 경쟁위험/Fine–Gray 전체 결과 검증 표현은 당시 `integration.R`이 `regression`을 지정하지 않아 기본 CIF/Gray 경로만 실행한 것을 잘못 기술한 것이다. 그 검증은 원인별 Cox 또는 Fine–Gray 회귀 검증으로 볼 수 없다. 직접 함수 및 Cox 검증 결과는 별개다. 이후 `regression="both"`를 명시한 600행·20공변량 자료에서 초기 Cox 최적화 전과 현재 모듈 전체의 결과·진단·난수 상태를 비교해 통과했다. 상세 내용은 [원인별 Cox 저장·통합 검증](COMPETING_PH_EXPORT_VALIDATION_20260914.md)을 참고한다.

`R/analysis_survival.R`에 survival_cox_influence_residuals를 추가하고 일반 Cox 및 원인별 Cox 진단의 DFBETA/DFBETAS 계산에 연결했다. DFBETA 계산을 마친 후 안전한 조건에서 원본과 같은 행렬 곱 `dfbeta %*% diag(sqrt(1 / diag(covariance)))`으로 DFBETAS를 계산한다. 반복되는 점수 잔차 계산을 줄인다.

## 적용 범위

- 정확한 coxph 클래스, 명시적 가중치와 na.action이 없는 모형, 두 열 이상의 일반 DFBETA 행렬에 적용한다.
- DFBETA와 공분산이 유한하고 공분산 크기가 맞으며 대각 원소가 양수여야 한다. naive.var가 있으면 이를 선택하고 아니면 var를 사용한다.
- 첫 잔차 계산에서 경고·메시지가 발생하면 재사용하지 않는다. 단일 공변량, 가중치, 결측 보정, 특수 클래스 등 조건을 벗어나면 기존 residuals(..., type='dfbetas') 호출과 오류 처리를 유지한다.
- 기존 함수를 수정하거나 단순 나눗셈으로 표준화하지 않았다. 이번 경로에서는 가중치가 없으므로 원본의 단위 가중치 곱셈이 중간 결과를 바꾸지 않는 조건에서 같은 행렬 연산을 재사용한다.

## 시간 측정

번들 R 4.5.3과 설치된 survival을 사용했다. 새 프로세스에서 변경 전후 3쌍을 순차 실행했고 두 번째 쌍은 순서를 반대로 했다. 모형 적합은 측정 밖에서 수행했다. 각 프로세스에서 1,000행 다음 100,000행, 공변량 10개, 가중치 없는 Efron 모형의 두 영향 잔차 계산을 측정했다.

| 행 수 | 변경 전 3회(초) | 변경 후 3회(초) | 중앙값 전→후 |
|---|---|---|---|
| 1,000 | 0.00 / 0.00 / 0.00 | 0.01 / 0.02 / 0.01 | 0.00→0.01 |
| 100,000 | 3.60 / 3.58 / 3.58 | 1.75 / 1.75 / 1.76 | 3.58→1.75 |

큰 조건에서 약 51% 감소했다. 작은 조건에서는 추가 가드·함수 호출/초기 컴파일 비용을 포함해 약 0.01초 증가했다. 0.00초는 측정 해상도 안에서 기록된 값이며 실제 비용이 없다는 뜻이 아니다. 전체 Cox 분석이나 앱 로딩 시간의 감소율로 해석하지 않는다. UI·내보내기·모형 적합은 측정 범위 밖이다.

## 검증

- 600행, 공변량 1/3/10개, 일반·가중·결측 보정 모형, Efron/Breslow 조합 18조건에서 두 잔차의 값·속성·진단·난수 상태가 identical(..., num.eq=FALSE)로 일치했다.
- 층화, 군집 강건분산, 시작–종료 자료, exact 방법, 진단 메시지를 발생시키는 하위 클래스의 추가 5조건도 일치했다.
- 시간 측정 6쌍에서 두 잔차 전체·진단·난수 상태가 정확히 일치했다.
- 실제 전체 Cox 및 공변량을 포함한 경쟁위험/Fine–Gray 결과, 두 HTML/의존성이 일치했다. Cox 비교는 실행마다 달라지는 네 수식/terms의 `.Environment` 참조만 검증용 복사본에서 정규화했다. 숫자에는 허용오차를 적용하지 않았다. 경쟁위험 결과는 원본 객체 그대로 비교했다.
- 시작 스냅샷과 후보의 diff를 확인했고 실행 파일이 시작 스냅샷과 같은 해시임을 확인한 뒤 검증된 후보를 적용했다. git diff --check 통과.
