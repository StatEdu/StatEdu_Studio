# 요인분석 전체 척도·하위요인 신뢰도 재사용 — 2026-09-14

단일 요인에 모든 문항이 배정되면 전체 척도와 하위요인의 신뢰도를 같은 자료·문항·옵션으로 두 번 계산했다. 전체 신뢰도 결과가 있고 문항 순서까지 정확히 같으며, 첫 계산에서 경고·메시지가 없고 난수 상태가 변하지 않았을 때만 그 결과를 재사용하도록 반영했다.

전체 척도의 Total 표기와 하위요인의 이름·배정 문항은 각각 기존대로 설정한다. 문항 순서가 다르거나 오류·경고·메시지·난수 변화가 있으면 기존 계산을 유지한다. 전체 결과는 원래도 반환 구조에 보관되므로 별도 전역 캐시나 분석 간 캐시는 추가하지 않았다. 난수 상태 확인은 기존 상태를 읽기만 하며 생성·복원하지 않는다.

## 전체 요인분석 시간

| 2,000행·12문항 | 기존 3회(초) | 변경 후 3회(초) | 중앙값 |
|---|---|---|---|
| 단일 요인 | 0.41 / 0.37 / 0.41 | 0.23 / 0.25 / 0.21 | 0.41 → 0.23, 약 44% 감소 |
| 두 요인 대조군 | 0.87 / 0.84 / 0.88 | 0.85 / 0.89 / 0.86 | 0.87 → 0.86, 일관된 개선 없음 |

단일 요인은 세 번 모두 빨라졌다. 두 요인에서는 문항 집합이 달라 재사용하지 않았으며 작은 시간 차이를 개선으로 주장하지 않는다. 하위요인 신뢰도 옵션을 켠 조건의 결과이며, 꺼진 분석의 개선율이 아니다.

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 각 조건 양쪽 준비 실행 후 GC 및 전체 분석 시간을 측정했고 두 번째 프로세스는 후보를 먼저 실행했다. 다른 R 타이밍 작업은 동시에 실행하지 않았다. 시드 933, 각 요인의 정규 잠재값에 표준편차 0.5 정규 오차를 더한 연속형 자료다. 두 요인에서는 문항 6개씩 서로 다른 잠재값을 사용했다. Pearson·주축요인법·고정 요인 수·정규성 검사 끔·하위요인 신뢰도 켬이며, 단일 요인은 회전 없음, 두 요인은 Varimax다. 분석 전 시드 718로 초기화했다.

시간은 적합·신뢰도·결과표 준비와 비교용 스냅샷 구성을 포함한다. 입력 생성·모듈 로딩·그림 렌더링·저장은 제외했다. 메모리는 측정하지 않았다.
