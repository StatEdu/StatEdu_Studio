# 자동 카운트 선별 실패·영값 과다 안내 — 2026-09-17

자동 카운트 분포 선택의 Poisson 선별 실패, 분산 계산 불가, 음이항 선별 실패 안내 3개를 8언어 번역 사전에 연결했다. 영값 과다 양성 안내는 기존 번역으로 정상 표시되어 추가 변경하지 않았다. 분포 선택 규칙과 추정 계산은 변경하지 않았다.

`scripts/validate_longitudinal_auto_count_i18n.R`의 6경로 × 8언어, 총 48개 검사에서 항목·안내 번역, 숫자 문자열과 원본 표 보존을 확인했다.

- Poisson/음이항 정상 선택은 실제 GEE 분석과 계수 표 반환을 확인했다.
- Poisson 실패는 음수 응답을 선별 함수에 직접 전달해 재현했다. 일반 분석 입력 검증을 거친 사용자 경로 검증과는 구분한다.
- 분산 계산 불가와 음이항 선별 실패는 격리된 시험 환경에서 해당 함수 반환값만 대체했다.
- 영값 과다는 실제 합성 자료의 선별 함수로 확인했다. 해당 적합의 theta 반복 한도·NaN 경고는 유지되며 수렴 보장을 의미하지 않는다.

`scripts/validate_longitudinal_count_exports.R`에서 이번 영향을 받는 표를 캡처해 한국어/일본어 현재·누적 HTML, PDF, Word, 직접 생성 HWPX, Excel 저장을 검증했다. HTML·문서 XML·Excel 셀의 캡처 문구 일치와 원본 표 보존 검사를 통과했다. `scripts/validate_longitudinal_error_pdf.py tmp/longitudinal-count-exports`의 PDF 4개도 모든 캡처 문구를 포함한다. 두 언어 모두 현재 7쪽, 누적 13쪽이다. 산출물은 `tmp/longitudinal-count-exports`에 있다.

저장 검사의 본 표는 영어 계수 표 시험 자료이며 모든 실제 분석 본 표 검증을 대신하지 않는다. 기존 전체 종단 저장 묶음은 이번에 재실행하지 않았다. 실제 브라우저 언어 왕복과 페이지별 시각 검토, 다른 자동 분포·모형 조합은 남아 있다. 메타분석과 설치본은 작업하지 않았다.
