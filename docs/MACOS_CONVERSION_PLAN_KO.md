# StatEdu Studio 1.3.1 맥용 변환 계획서

작성: 2026년 10월 2일. 기준 확정 및 구현 상태 갱신: 10월 3일. 저장소 `StatEdu/StatEdu_Studio`, 브랜치 `macos`, 기준 태그 `v1.3.1` (`782ce64`).

변환 대상은 **정식 공개판 1.3.1**입니다. 앱 버전은 `1.3.1`, 앱 ID는 `com.statedu.studio.mac`으로 유지합니다. 분석 알고리즘과 공개 기능 범위를 보존하며 사용자가 R을 따로 설치하지 않아도 실행할 수 있는 Apple Silicon 앱을 만듭니다. 각 단계의 검증과 수정이 끝나면 다음 단계로 이어갑니다.

## 단계와 완료 기준

| 순서 | 구현 내용 | 완료 기준 및 현재 상태 |
| --- | --- | --- |
| 1 | 누락 맥 실행기·패키징 복원, 격리 빌드 환경 | Electron·builder 잠금 파일, 아이콘, 빌드 검사, 소스 무결성 검사 구현·통과 |
| 2 | 내장 R 4.5.3과 고정 의존성 구성 | 전체 251개 버전·입력 체크섬 고정, 독립 재구성, arm64·외부 경로 감사 및 실제 로드 통과 |
| 3 | 맥 실행과 파일 처리 | 프로세스 시작·종료, 파일 연결, 공개 메뉴, 네이티브 선택창, 프로젝트·결과 저장과 복원 구현 |
| 4 | 분석 및 출력 회귀 | 수치 비교 66개, 추가 혼합·복합표본·종단 검증, GUI·다국어·문서 출력 검사. 세부 결과는 검증 보고서에 기록 |
| 5 | 앱 패키징과 배포 준비 | 이동한 실제 `.app` 실행 검사, 라이선스 포함, 서명·공증 자동화 구현. 인증서 기반 배포 및 별도 Mac 실기 검증은 자격 증명·환경 확보 후 수행 |

1단계부터 6단계까지 순서대로 진행하고, 오류를 발견하면 해당 단계에서 수정·재검증합니다. 1.3.1 개발자판으로 변경하지 않습니다. 로컬 패키징의 서명 상태와 제품 버전은 별도로 기록합니다.

## 구현 원칙

R·Shiny 분석 코드를 유지하고 맥 전용 Electron 실행기를 제공합니다. 사용자 R 설정과 개인 패키지에 의존하지 않으며 앱 첫 실행에 패키지를 내려받지 않습니다. 내부 라이브러리 참조는 재배치하고 설정·캐시·로그는 사용자 데이터 경로에 저장합니다.

데이터·프로젝트·결과 파일은 실제 macOS 선택창과 연결합니다. 취소, 한글·공백 경로, 덮어쓰기, 확장자, 앱 이동, 저장하지 않은 변경 확인과 종료 후 R 프로세스 정리를 검사합니다. PDF는 내장 Electron으로 생성합니다. Windows 기존 동작도 공통 코드 회귀 검사로 보존합니다.

공개판 메뉴와 언어 8개를 유지합니다. 메타분석과 동일개체 내 처치 반복측정 분산분석은 공개 메뉴에 포함하지 않으며 외부 Mplus 모듈은 맥 검증 범위에서 비활성화합니다. 맥 업데이트 안내는 맥 브랜치 또는 별도 지정한 HTTPS 맥 배포 페이지를 사용합니다.

수치 검증은 고정 패키지와 독립 기준 계산을 사용합니다. 실패를 숨기기 위해 허용오차를 확대하지 않습니다. 오래된 검증 스크립트가 현재 앱의 수렴 설정·번역·의존성 로드를 반영하지 못하는 경우 실제 앱 기준에 맞춰 수정하고 이유를 기록합니다.

## 최종 전달과 외부 환경 조건

[빌드 안내](MACOS_BUILD_KO.md)에 새 체크아웃의 재현 절차를, [검증 보고서](MACOS_VALIDATION_1_3_1_KO.md)에 실행 환경과 검사 결과를 기록합니다. Git에는 소스와 증거 요약을 포함하고 R.framework·node_modules·개인 데이터·대형 앱은 포함하지 않습니다.

현재 실기 환경은 Apple Silicon, macOS 27.0.1입니다. macOS 13은 바이너리 최소 OS 목표이며 실기 지원 검증은 남아 있습니다. Intel은 별도 런타임과 실기 검증 후 확장합니다.

Developer ID Application 인증서와 Apple 공증 프로필이 확보되면 내장 실행 파일 서명, Hardened Runtime, 앱·DMG 공증, 티켓 첨부, Gatekeeper 검사를 자동 실행합니다. 별도 깨끗한 Mac과 다운로드 설치 검증까지 통과해야 일반 사용자 배포 완료로 표시합니다. 해당 자격 증명·환경 부재를 구현 실패나 개발자판 전환으로 처리하지 않습니다.
