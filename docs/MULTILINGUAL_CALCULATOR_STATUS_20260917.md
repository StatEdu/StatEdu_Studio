# 계산기 상태·항목 라벨 번역 — 2026-09-17

계산기 6종(HINT8, EQ-5D, FRS, ASCVD10, 대사증후군, 대사증후군 중증도)의
파일 로드 안내 및 계산 완료 요약 6개 템플릿을 8언어로 연결했다.
파일명, 사용자 출력 변수명, 행 수, 결측/무효 행 수와 진단 수는 그대로 보존한다.

공통 필드 설명 29개를 추가하여 변수 입력 라벨 48곳에 적용했다.
HINT8/EQ-5D는 LQ/EQ 코드와 괄호 구조를 보존하고 설명만 번역한다.
SBP/DBP는 통용 약어 그대로 사용한다. ASCVD 선택 입력의 optional도 번역한다.
이는 계산기 인터페이스 항목 설명 번역이며 설문 도구의 공식 번역본이나
검증된 문화적 타당화 버전을 제공한다는 의미는 아니다.

검증: `scripts/validate_calculator_status_i18n.R`

- 기존 6종 계산기의 수치 회귀 검증 통과.
- 실제 Shiny 서버 6종에서 계산 후 8언어 및 한국어 복귀 검증.
- 생성 HTML의 48개 입력 라벨과 선택 option/서버 입력값 보존 확인.
- 파일명 및 출력 변수명에 한글, `<&>`, `%s`를 넣어 원문 보존 확인.
- 언어 전환 전후 계산값과 변수 추가 호출 횟수가 동일하여 재계산 없음 확인.
- 이전 입력 오류 11종/6개 알림 처리기 번역 검사도 재실행해 통과.

생성된 일본어 라벨 목록은 `tmp/calculator-status/japanese-variable-label-audit.csv`.
이번 검증은 Shiny 서버와 생성 HTML 기반이며 실제 브라우저 입력 동작과
시각적 잘림/배치 검사는 아직 별도다. DT 제어 문구와 계산기 내 나머지 옵션,
표본수/효과크기는 후속 범위다. 계산식·CSV 데이터·분석 결과 보고서는 변경하지 않았다.

공용 사전은 기존 다국어 작업에서 `fill_calculator_status_i18n.py`와
`fill_calculator_labels_i18n.py`로 병합했다. 이쪽에서는 종단 소스와 공용
현황 문서를 변경하지 않았다. 서버 재시작/설치본 생성은 하지 않았다.
