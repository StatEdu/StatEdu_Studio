# SEM SCI 수준 잔여 공백 감사

검토일: 2026-08-16

## 판정 기준

- `완료`: 계산, 실행 차단, 결과 해석 경계와 감사기록이 함께 구현됨.
- `다음 구현`: 일반적인 SCI 논문 심사에서 재현성 또는 해석 타당성에 직접 영향을 주며 현재 입력·결과 구조로 구현 가능함.
- `제한 유지`: 별도 추정 엔진이나 연구설계가 필요하므로 자동 근사하지 않고 실행 차단 또는 제한 문구를 유지함.
- `장기 확장`: 유용하지만 모든 SEM 분석의 필수조건은 아니며 별도 모듈이 적절함.

## 핵심 영역별 판정

| 영역 | 현재 상태 | 판정 | 남은 작업 |
|---|---|---|---|
| 공통요인·합성변수 구분 | 선언 유형, 측정 방향, 요청/실제 가중, 엔진 표현과 estimand 분리 | 완료 | 없음 |
| 구형 모형 호환성 | 원값 보존, 안전한 추론, 고급 검토 자동 활성화, 마이그레이션 이력 | 완료 | 없음 |
| CFA·CB-SEM 명세 | 반영형 공통요인만 허용; 합성변수의 묵시적 요인 변환 차단 | 완료 | 없음 |
| PLS·PLSc 명세 | Mode A/B 실제 적용, 적격 공통요인 블록별 PLSc 보정, composite 비보정 범위 및 보정 상태 기록, 표준 PLS 점수 대리변수 한계 | 완료 | SmartPLS/cSEM/ADANCO 수치 benchmark는 별도 검증 필요 |
| 식별·허용성 | 지표 수, 단일지표 오차, 고차요인, 수렴, Heywood 및 행렬 진단 | 완료 | 없음 |
| 추정량 선택 | 자료형·분포·구성개념·목적 기반 안내; 작은 표본만으로 PLS 선택 금지; PLS/PLSc 규칙 기반 추천은 사용자 확인 전 실행 차단 | 완료 | 없음 |
| 결측자료 | FIML/listwise/pairwise 조건, 사례손실·최소 pairwise N·MAR 한계, 대안 처리·MNAR 이탈 민감도 방법과 결론 기록 | 완료 | 외부 분석 기록은 소프트웨어가 그 계산의 정확성을 자동 검증하지 않음 |
| 반영형 측정평가 | 적재량, 잔차, CR/omega/AVE, HTMT CI, 경쟁·국소 적합도 | 완료 | 절단값은 참고값으로만 유지 |
| 반영형 합성변수 | 점수 진단으로 한정하며 공통원인·오차분리 주장 차단 | 완료 | 없음 |
| 형성형 합성변수 | weight bootstrap, item VIF, 별도 전역준거 redundancy, 지표 영역·포함 근거·내용타당도 절차의 구성개념별 기록과 Review 상태 | 완료 | 없음 |
| 판별타당도 | HTMT/Fornell–Larcker를 반영형 구성개념끼리만 적용 | 완료 | 기준 미만을 확립 판정으로 사용하지 않음 |
| 구조효과 | 직접·간접·총효과, 조절된 매개, 표준화 bootstrap CI, BH 보정 | 완료 | 없음 |
| 인과해석 | 시간선행성·교란·처치정의 등 식별 가정 부재를 명시 | 완료 | 관측자료에서 자동 인과판정하지 않음 |
| 집단비교 | CB-SEM 측정불변성 gate 후 구조경로 비교; PLS MICOM 최소 부분불변성 gate 후 양측 permutation PLS-MGA와 경로군 BH 보정 | 완료 | 없음 |
| 예측평가 | 측정·구조모형을 훈련 접기별로 재추정하는 반복 PLSpredict와 선형 기준모형 비교; 정보 누출 score-CV Q² 폐기 | 완료 | 별도 Q²는 전용 blindfolding/교차검증 estimand가 확립될 때만 재도입; 외부표본 검증은 사용자가 별도로 수행·보고 |
| 모형수정 | MI 다중성, 실질적 근거, 탐색적 표기, holdout 검증 | 완료 | 없음 |
| 보고·감사 | 명세 hash, 데이터 지문, seed, 패키지/환경, 명세·엔진 매핑 | 완료 | 없음 |
| 복합표본·군집·종단 | 잘못된 독립관측 SEM 실행 차단 | 제한 유지 | survey-aware, multilevel, longitudinal SEM 전용 엔진 필요 |
| 순서형 합성변수 | 현재 엔진에서 실행 차단 | 제한 유지 | ordinal composite 전용 추정·검증 절차 필요 |
| PLS 잠재조절 | 캔버스 경로를 조용히 누락하지 않고 차단 | 제한 유지 | two-stage/orthogonalizing 등 전용 구현과 선택 규칙 필요 |
| 요인점수 개인 의사결정 | 결정성 및 사용 한계 표시 | 장기 확장 | 분류정확도·공정성·검사재검사·외부준거 모듈 필요 |
| 방법편향 | Harman, 단일요인, 공통잠재방법요인을 screening으로 제한 | 장기 확장 | 설계단계 절차적 통제와 marker-variable 정보를 구조화해 기록 가능 |
| 검정력 | 사용자가 근거와 세부내용을 선언하고 감사기록에 보존 | 장기 확장 | Monte Carlo 기반 사전 검정력·정밀도 설계 모듈 없음 |

## 구현 우선순위

현재 일반 단일수준 횡단 SEM의 필수 안전장치 가운데 즉시 구현으로 분류된 잔여 항목은 없다. 아래 `제한 유지`와 `장기 확장` 항목은 전용 엔진 또는 별도 연구설계 모듈에서 다룬다.

## SCI 투고 전 수동 확인이 계속 필요한 항목

- 이론에 의한 구성개념 영역과 지표 선택의 정당화
- 표본틀, 비응답, 대표성 및 자료수집 절차
- 사전등록된 주가설과 탐색적 분석의 구분
- 동일 자료·동일 변수·동일 추정량 조건을 충족하는 경쟁모형 비교
- 연구설계에 기반한 시간적 선행성과 교란 통제
- 독립 표본 또는 외부 자료에서의 재현성

소프트웨어의 적합도, 유의성, 신뢰도 또는 예측지표만으로 위 항목을 자동 충족한 것으로 판정하지 않는다.
