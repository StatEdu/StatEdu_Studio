# 생존분석 자동 사건 매핑의 중복 코드 검사 생략 — 2026-09-14

사건 매핑을 지정하지 않으면 `survival_normalize_event_map()`이 관측된 모든 비어 있지 않은 사건 코드로 기본 매핑을 만든다. `survival_preflight()`가 직후 같은 코드 목록을 다시 만들어 매핑 누락을 찾던 부분을 생략했다.

적용 조건은 `settings$event_map`이 NULL이고 사건 자료가 클래스·차원이 없는 일반 atomic 벡터인 경우다. 사용자 지정 매핑, factor, Date 및 사용자 정의 클래스 등은 기존 검사를 수행한다. 중복 매핑·잘못된 역할·unknown 역할 검사는 유지한다. 사건 분류와 제외 규칙은 변경하지 않았다.

## 전체 입력 검증 시간

10만 행의 시간·정수 사건·집단·연령 자료를 사용했다. 결측 조건은 연령 10%를 NA로 지정했다. 번들 R 4.5.3의 새 프로세스에서 모듈·설정 로딩 후 정상 자료, 결측 자료 순서로 측정했다. 프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍의 변형 순서를 뒤집었다. 함수는 같은 전역 도우미 환경을 사용했다.

| 반복 | 정상 전/후(초) | 결측 전/후(초) |
| --- | --- | --- |
| 1 | 0.35 / 0.33 | 0.26 / 0.25 |
| 2 | 0.36 / 0.35 | 0.26 / 0.25 |
| 3 | 0.36 / 0.35 | 0.25 / 0.23 |
| 중앙값 | 0.36 / 0.35 | 0.26 / 0.25 |

개선 폭은 작다. 기본 경로의 중복 작업을 제거했으나 큰 속도 개선이나 전체 분석·시작 시간의 감소율을 주장하지 않는다. 사용자 지정 매핑과 클래스가 있는 사건 자료에는 이 생략 경로가 적용되지 않는다.

## 검증

- `scripts/validate_survival_auto_event_map.R`: 48개 입력 검증 사례에서 전체 결과/오류, 경고·메시지 및 RNG 상태가 정확히 동일했다.
- `verify_events.R`: 사건 자료형과 자동/사용자 지정/잘못된 매핑을 조합한 24개 사례 통과. factor, Date, 사용자 정의 형식의 변환과 결측 메서드 진단 순서·횟수도 유지했다.
- 대용량 측정 6쌍의 분석 자료, 행별 제외 사유, 건수, 이슈와 매핑 등 전체 결과가 `identical(..., num.eq = FALSE)`로 일치했다.
- 실제 서버의 자료 업로드·선택·상관분석·Kaplan–Meier 실행을 완료했다. 직전 기준과 전체 결과 객체, HTML/의존성, 경고 및 알림이 정확히 같았고 분석 실행 경고는 0개였다.
- `git diff --check -- R/analysis_survival.R` 통과.

출력 내용과 분석 결과는 유지한다. 내보내기 완성 파일과 설치 파일은 이번에 재생성하지 않았다.
