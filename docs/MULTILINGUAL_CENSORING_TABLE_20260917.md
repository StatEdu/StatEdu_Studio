# Fine–Gray 검열분포 표

표 제목·열 이름·검토 사유·통합/층별 설명의 번역 9개 항목을 보완했다.
복합 검토 사유는 알려진 항목만 번역하며, 사용자 층 이름과 이미 번역한 상태는 보호한다.
층별 설명은 번역 후 변수명을 삽입한다. 실제 결과 패널에 UI 언어를 전달한다.

## 검증

- `validate_censoring_table_i18n.R`: 실제 검열 집계 함수로 통합 및 3개 층 자료를
  생성하여 8개 언어에서 검사했다. 검열 없음/5개 미만/정상 및 관측치 10개 미만 포함.
- 숫자·비율 정밀도, 사용자 층 이름(일반 문구와 일치하는 경우 포함), 변수명 특수문자 보존.
- 실제 Fine–Gray 잔차 및 영어 계수 본 표 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 표와 설명의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 다른 생존분석 보조표와 설명의 잔여 점검은 계속 필요하다.
