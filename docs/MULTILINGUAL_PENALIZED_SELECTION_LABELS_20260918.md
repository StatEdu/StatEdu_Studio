# 규제 회귀 선택 변수명과 상태 안내 구분

## 재현 및 수정

사용자가 예측변수 라벨을 `None`으로 지정한 실제 LASSO 분석에서, 해당 변수가 선택되었는데도 한국어 부록의 선택 변수 목록에 `없음`으로 표시되는 문제를 재현했다. 프로그램 안내와 사용자 라벨이 같은 열에서 문자열 번역을 거쳤기 때문이다.

분석 결과의 선택 변수 요약표에 `penalized_selection_status` 속성을 추가하여 사용자 변수 목록·선택 없음·Ridge의 전체 유지 상태를 구분했다. 부록 렌더러는 사용자 목록을 원문으로 보존하고 확인된 자동 생성 안내만 기존 번역 사전으로 번역한다. 계산식과 영어 본표는 변경하지 않았다.

구분 정보가 없는 기존 저장 결과는 사용자 변수명을 보호하기 위해 해당 열을 원문으로 유지한다. 따라서 이전 결과의 자동 안내에도 영어가 남을 수 있으며 문자열만으로 임의 판별하지 않는다.

## 검증

- 실제 80명 자료에서 강한 효과의 LASSO가 사용자 라벨 `None`을 선택하는 경우, 무관한 결과변수의 LASSO가 아무 변수도 선택하지 않는 경우, Ridge가 모든 변수를 유지하는 경우를 각각 검증했다.
- 8개 언어에서 사용자 `None`은 보존되고 자동 생성 상태는 번역되는지 확인했다. 영어 본표의 동일성과 전체 결과 객체 보존도 확인했다.
- 표시 속성을 제거하고 직렬화 왕복한 결과에서도 사용자 라벨을 보존했다. 실제 과거 파일 대신 만든 복원 호환성 사례이다.
- 검증 설정은 부트스트랩 2회, 검증 반복 1회로 출력 검사용이며 통계적 안정성을 보증하지 않는다.

## 회귀 및 저장 검사

기존 `validate_penalized_i18n.R`의 Ridge·LASSO·Elastic Net × 8개 언어 검사, `validate_i18n_contract.R`, 변경 경로의 `git diff --check`를 통과했다.

한국어·일본어 현재/누적 결과의 HTML·PDF·DOCX·HWPX·XLSX 생성과 표·제목 텍스트 보존 검사를 통과했다. PDF 텍스트 검사도 통과했으며 두 언어 모두 현재 20쪽, 누적 39쪽이다. 산출물은 `tmp/penalized-selection-labels-i18n/exports`에 있다. 실제 결과 캡처를 저장에 사용했으며 내보내기 중 재적합하지 않았다.

공용 `validate_longitudinal_count_exports.R` 재사용으로 검증용 표지 제목은 Longitudinal이지만 본문은 이번 규제 회귀 결과이다. 영어 본표의 언어 간 동일성은 전용 검사에서 확인했다.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드와 문서 앱별 수동 검토는 수행하지 않았다. 전체 프로그램 번역 완료를 의미하지 않는다.
