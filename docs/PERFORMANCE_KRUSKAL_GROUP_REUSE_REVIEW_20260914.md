# Kruskal–Wallis 집단 분할 재사용 후보 검토

## 결정

원시 결과는 일치했지만 전체 실행 시간의 이득이 일관되지 않아 적용하지 않았다. 8집단·연속값·결측 자료는 3회 모두 느려졌다. 프로그램 소스는 이전 그대로이며 `R/analysis_ttest_anova.R` SHA256은 `B18C774BF8A020F251EDF9EC398B2C8FD5A053F3ED83017D3699F614D5F947E4`다.

## 후보

Kruskal–Wallis 원본의 `sum(tapply(r, g, sum)^2 / tapply(r, g, length))`는 집단별 순위 합과 표본 수를 구할 때 각각 집단 분할을 수행한다. 검토용 지역 복사본에서 해당 문장만 다음과 같이 바꿨다.

```r
grouped_ranks <- split(r, g)
STATISTIC <- sum(vapply(grouped_ranks, sum, numeric(1))^2 /
                 lengths(grouped_ranks))
```

기존 `table(x)` 동점 처리와 이후 검정통계량·p값 계산은 그대로 유지했다. 앱의 본검정과 epsilon squared 경로를 검토용 formula 함수 복사본을 통해 연결했다. 원래 stats 네임스페이스는 수정하지 않았다. 제품용 엔진이나 버전 검사 코드는 추가하지 않았다.

## 정확성

2/4집단 × 표본 크기 0/1/4/20/100/20,000 × 일반·동점·상수·가까운 실수·큰 크기의 가까운 실수·결측·무한대의 84개 조건에서 원시 htest, 경고/메시지/오류, stdout, 난수 상태를 비교했다. 정규화나 허용오차 없이 `identical(..., num.eq=FALSE)`로 모두 일치했다. 유효한 관측값이 있는 사례에서는 집단별 순위 합의 제곱/표본 수를 합산한 원시 중간 통계량도 정확히 일치했다.

전체 분석의 기존/후보 비교 36개도 모두 일치했다. 앞서 순위 기반 동점 집계에서 발생한 인접 실수의 결과 변경은 이 후보에서는 발생하지 않았다.
