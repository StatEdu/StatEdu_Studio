# 현재 초기 UI 구성 병목 — 2026-09-14

운영 코드를 변경하지 않고 최근 소스의 첫 UI 구성을 추적했다. 다음 검토 대상은 번역표 초기화의 남은 이름 조회 비용이다. 현재 증거만으로 페이지 전체 캐시나 요청별 설정 확인 생략을 적용하지 않는다.

## 측정 방법

번들 Windows R 4.5.3, JIT 3, 패키지 자동 설치 비활성, 기존 유효 모듈 캐시를 사용했다. 실제 초기 순서에 맞춰 패키지·모듈을 로드하고 서버 함수를 만든 뒤 `app_ui(version, NULL)`의 첫 호출을 측정했다. 각각 별도 새 프로세스 3개에서 일반 측정, 함수별 경과 시간 추적, 10ms Rprof를 수행했다. 분석 난수 시드는 941이다.

일반 측정은 UI 구성과 조건/표준출력 수집을 포함한다. 초기 HTML 렌더링은 시간 측정 후에 수행했다. 패키지·모듈 로딩, 서버 세션 실행, 실제 브라우저 DOM 렌더링이나 Electron 시작 시간은 포함하지 않는다.

## 관측 결과

계측 없는 첫 UI 구성은 **0.37 / 0.36 / 0.37초**, 중앙값 **0.37초**였다. 함수 래퍼 추적을 붙인 UI는 세 번 모두 0.41초였으므로 추적 자체의 비용을 구분해야 한다.

| 추적 구간 | 3개 프로세스의 관측 범위 |
| --- | ---: |
| 데이터 탭 | 0.15~0.17초 |
| 분석 탭 | 0.05~0.06초 |
| head 구성 | 0.05~0.06초 |
| 정적 언어 스크립트 | 0.04~0.06초 |
| 전체 `statedu_t` 호출 합계 | 0.14~0.18초 |

번역 호출은 탭 구성에 포함되고, 정적 언어 스크립트는 head 구성에 포함된다. 위 값을 합산해 전체 시간을 구성하면 안 된다. 0초로 기록된 도우미도 실제 비용이 없다는 의미가 아니다.

GC를 제외한 수정된 UI Rprof에서 번역표 초기화 `statedu_translation_table`은 **36% / 40% / 36%**, `compiler:::tryCmpfun`은 **32% / 20% / 40%**의 total 표본 비중을 차지했다. 각각 전체 표본이 약 25개뿐이므로 정밀한 비율 추정이 아니라 우선순위 근거다. 두 비율을 합산하지 않는다.

컴파일 호출자는 언어 정규화, 데이터/분석 탭, 분석별 UI 문구, 결과 배율 정규화 등으로 분산되어 있었다. 상위 `navbarPage`와 bslib 함수의 큰 total 비중에는 지연 평가되는 탭 인수 계산이 포함된다. 이를 곧바로 외부 패키지 내부의 불필요한 비용으로 해석하지 않는다.

## 다음 후보의 구체적 위치

`R/labels.R`의 번역표 초기화는 locale overlay의 키를 `seq_along(keys)`로 순회한다. 현재 대상 번역표의 행 위치는 이미 한 번 `match()`하여 재사용하지만, 원본 overlay 값은 반복마다 `translations[[key]]`로 다시 이름 조회한다.

키가 유효하고 중복이 없는 일반 목록에서는 알고 있는 정수 위치를 사용할 여지가 있다. 다만 이름 중복 시 기존 `[[key]]`의 첫 항목 선택, 빈/NA 키, 목록 객체의 사용자 정의 접근, 새 키 삽입 순서와 언어별 fallback 처리의 동작을 보존해야 한다. 따라서 단순히 모든 이름 조회를 인덱스로 치환한 변경은 아직 적용하지 않았다. 이 후보의 실제 속도 이점도 이번에는 측정하지 않았다.

## 검증과 보관

- 일반·추적·프로파일의 총 9개 스냅샷에서 UI HTML, 의존성, 경고/메시지, 표준출력, 난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. HTML은 Shiny의 자동 생성 숫자 탭 ID만 정규화했다.
- 최초 프로파일이 `system.time()`의 사전 GC를 포함한 것을 확인해 프로파일 시작을 GC 이후로 옮기고 프로파일용 세 프로세스를 다시 실행했다. 위 비중은 수정 후 기록이다. 일반/래퍼 측정은 재사용했고, 수정한 프로파일 스냅샷의 동일성을 다시 확인했다.
- `R/ui_helpers.R`와 측정 사본의 SHA-256은 `7D82C5AB8707320AF2D9596B41ACD0A8AE94B8B9E28B3074C7C9BDECE7815E5D`로 동일하다.
- 화면·분석·내보내기 구현을 변경하지 않았다. 실제 서버 흐름, 메모리, 저장 파일 및 설치 파일은 이번에 재검증하거나 재빌드하지 않았다.
