# RMSEA 가설검정 보조표 다국어

## 변경

- 표 2의 RMSEA 가설검정 보조 제목·열 이름과 검정 해석 안내를 UI 언어에 연결했다.
- 근접 적합/비근접 적합의 귀무가설 방향, .05/.08 기준, p값 해석과 표본크기 민감성 설명을 유지했다. 모형 채택을 단독으로 결정하는 규칙이 아니라는 안내도 번역했다.
- 프로그램 기본 모형명은 UI 언어를 따르고, 사용자가 지정한 비교 모형 이름 및 RMSEA 계산 출처 코드는 보존한다.
- 계산 함수와 영어 본표는 변경하지 않았다.

## 검증

- `validate_structural_rmsea_i18n.R`: 실제 ML·MLR 적합과 비교 모형 표시 fixture에 대해 8개 언어 × 3개 사례 검사 통과.
- RMSEA·귀무가설 기준·p값·출처 셀을 원시 계산값의 기존 표시 형식과 비교했다. 비교 모형 이름 `Review 사용자 <&>`의 원문 보존을 확인했다.
- 비교 fixture는 동일 적합 객체를 두 모형 위치에 넣어 표시·라벨 계약을 검사한다. 모형 수정의 통계적 효과를 검증한 것은 아니다.
- 기존 품질 요약/영어 본표 검증 및 번역 사전 검사도 통과했다.
- 로그: `tmp/structural-rmsea-validation.log`, `tmp/structural-rmsea-coverage.log`.
- 일본어 현재·누적 HTML/PDF/Word/HWPX/Excel의 제목·셀·해석 문구 보존 검사를 통과했다. 현재 3개·누적 4개 표의 순서/시트 수가 일치하며 PDF 본문·표지도 확인했다. 저장 시 재적합하지 않는다.
- 저장 fixture: `tmp/structural-rmsea-i18n`; 로그: `tmp/structural-rmsea-exports.log`.

## 범위 제한

이번 범위는 RMSEA 가설검정 보조표다. 기준 기반 적합도 안내, 추가 적합도 지수, 정보기준과 Bollen–Stine 보조표의 고정 문구는 별도 점검 대상이다. 전체 다국어 완료가 아니며 설치본은 만들지 않았다.
