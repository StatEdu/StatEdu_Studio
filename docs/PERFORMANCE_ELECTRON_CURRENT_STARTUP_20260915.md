# 최신 소스의 실제 Electron 시작 시간

## 결과

현재 소스를 Electron 43.4.0과 번들 R 4.5.3으로 실행했다. 새 사용자 프로필·모듈 캐시에서 첫 실행은 3.652초, 동일 프로필을 재사용한 후속 3회는 2.860 / 2.847 / 2.774초로 중앙값 2.847초였다. 종료 시점은 파일 선택 버튼의 사용 가능 상태를 자동화로 확인한 시각이다. 제품 코드나 설치 패키지 변경은 없다.

|구간|첫 실행(초)|후속 3회 중앙값(초)|
|---|---:|---:|
|실행 요청 → createWindow 로그|0.318|0.176|
|startShiny → 포트 준비|1.633|1.006|
|포트 준비 → 문서 로드 완료|0.699|0.642|
|문서 로드 완료 → 사용 가능 확인|0.927|0.918|
|실행 요청 → 사용 가능 확인 전체|3.652|2.847|

각 구간의 중앙값은 전체 중앙값에 합산하지 않는다. createWindow와 startShiny 사이의 짧은 구간도 전체 시간에 포함된다. 네 실행 모두 연결 이후 수집한 페이지 오류 및 확인 시점의 표시 오류가 없었고, 측정 후 해당 창을 닫아 프로세스 종료를 확인했다.

## 실행 환경

지난 검토에서 개발용 Electron 실행 파일은 없었지만, 캐시 하위 디렉터리까지 확인하니 프로젝트가 지정한 43.4.0 ZIP이 있었다. 로컬 설치 패키지의 `checksums.json`과 SHA256 `EF0709CFA719739ACCE73DE6F9B684304BAF38C6454376638A70D34A7CECFFE0`이 일치함을 확인하고 연구 폴더에만 풀었다. 다운로드나 설치 파일 재빌드는 하지 않았다.

`packaging/electron/main.js`, `preload.js`, `package.json`을 연구 launcher에 그대로 복사하고 app/runtime 디렉터리를 현재 저장소 및 기존 R 런타임에 junction으로 연결했다. 실제 시작 로그에서 Electron 43.4.0, Chrome 150.0.7871.224, R 4.5.3과 연구 launcher 경로를 확인했다. 실행 후 junction 두 개는 재귀 삭제 없이 제거했다. 재현 스크립트는 실행 시 이를 다시 만들고 정상 종료 후 제거한다.

프로필과 모듈 캐시는 전용 `output/electron-current-startup-20260915` 아래에 둔다. 첫 실행 전 없던 결합 소스·manifest·expression 캐시가 종료 후 생성됐다. OS 디스크 캐시는 비우지 않았으므로 PC 재부팅 직후의 완전한 cold start를 뜻하지 않는다. 재현 스크립트를 다시 실행하면 기존 프로필/캐시를 재사용하므로 해당 첫 실행을 새 캐시 측정으로 취급하면 안 된다.

## 비교 해석과 한계

이전 보관 패키지는 재실행 중앙값 6.536초, 이번 현재 소스는 2.847초였다. 그러나 포함된 소스와 R 라이브러리 위치, ASAR 패키징 여부, 초기 프로필 조건 등이 달라 통제된 전후 성능 비교가 아니다. 이 차이를 이번 작업에서 구현한 개선율로 보고하지 않는다. 최신 소스의 설치 패키지 자체 시작 시간은 아직 측정하지 않았다.

계측 기준은 이전 패키지 실험과 같다. 숨김 시작 요청 직전 시각부터 CDP 연결, Shiny 소켓 연결, 파일 input 존재, 파일 버튼 trial 클릭 가능 여부, shiny-busy 해제를 확인한다. 실제 파일 선택은 하지 않는다. Node/Playwright 준비 및 관측 지연이 포함되며 최초 페인트나 최초 상호작용 가능 이벤트의 정확한 발생 시각이 아니다. 연결 전 페이지 오류 전체를 검증한 것은 아니다. R 분석 수치, 내보내기 내용, RNG의 새 검증은 이번 범위가 아니다.

현재 병목 후보는 약 1초의 R 시작과 문서 로드 후 약 0.9초의 관측 구간이다. 후자는 자동화 확인 비용도 포함하므로 실제 초기 UI 처리와 계측 지연을 구분한 후에 변경을 판단한다. 이전에 효과가 없던 언어 동기화 제거를 이 숫자만으로 다시 적용하지 않는다.

증거: `output/electron-current-startup-20260915`의 `run.ps1`, `observe.cjs`, `summarize.cjs`, `run.log`, `launch-*.json`, `result-*.json`, `startup-through-*.log`, `stages.json`, `source-hashes.json`. 주요 시작 소스의 해시를 저장하고 종료 후 동일함을 확인했다.
