# 측정수준 한국어 문구의 반복 UTF-8 변환 제거

## 적용

`R/utils.R`의 statedu_measurement_choices에서 한국어 이름 네 개를 매번 16진수 문자열로부터 복원하던 작업을 제거했다. 기존과 동일한 이분형·범주형·순서형·연속형을 Unicode escape 문자열 상수로 정의했다. 소스 파일 인코딩에 의존하지 않으며 호출 간 가변 캐시도 없다.

측정수준 선택 상자는 선택지와 title을 위해 이 함수를 행마다 여러 번 사용한다. 반복 변환 제거로 전체 변수 표의 준비 비용도 줄었다. 측정수준 코드, 별칭 처리, 선택 상태, HTML escaping 및 onchange 이벤트 코드는 변경하지 않았다.

## 검증

변경 전 선택지 함수를 scripts/fixtures/measurement_choices_reference.R에 보존했다. scripts/validate_measurement_choice_constants.R에서 언어 9종과 정상/별칭/알 수 없는/빈/NA/NULL/벡터 측정수준, 일반·특수문자 변수 이름을 비교했다. 선택지와 HTML 문자열·진단·표준 출력·RNG 207개 비교가 정확 일치했고 선택지 이름의 Encoding도 일치했다.

기존 일반 변수 표의 108개 상태 및 고정 ID의 한·영 DT HTML 2개 비교, 데이터 IO, UI layout contract, 사례 선택·분할 변수 제외 검사도 통과했다. 일반 변수 표 검사는 기존 역할 조회 회귀 검사이며, 이전 한국어 변환 구현과의 직접 비교 근거는 새 207개 검사 및 연구 전체 표 비교다. 실제 브라우저 편집 이벤트와 저장 형식별 신규 검사는 이번 범위에 포함하지 않는다.

초기 연구 후보에서 문구를 약칭으로 잘못 적은 것은 첫 정확 비교에서 실패했다. 원래 hex 값을 직접 해독해 정확한 네 문구로 수정한 후 전체 실험을 재실행했고 제품에 반영했다. 최종 로그는 수정 후 실행이며 잘못된 문구는 제품에 적용되지 않았다.

## 성능

번들 R 4.5.3, 기존과 후보의 관련 함수들을 동일하게 바이트 컴파일한 조건에서 일반 변수 표의 전체 표시 상태를 측정했다. 1,000/3,000행, 한·영 조건마다 준비 비교 후 각 3회 실행하며 순서를 교대했다. 독립 프로세스 3개는 순차 실행했다. 각 측정 결과도 기존과 정확 비교했다.

|한국어 3,000행 중앙값(초)|실행 1|실행 2|실행 3|
|---|---:|---:|---:|
|기존|1.9740|1.9435|1.9622|
|개선|0.5419|0.5504|0.5617|

이 조건의 준비 시간은 약 71~73% 감소했다. 한국어 1,000행은 기존 0.639~0.689초, 후보 0.179~0.191초였다. 영어도 별도 측정·정확 비교를 했으며 기록은 CSV에 있다. 이번 핵심 개선은 한국어 문구 복원 비용 제거이고 전체 앱 로딩이나 회귀 계산의 개선율은 아니다. 표 상태와 체크박스/선택 상자의 HTML 문자열 준비 및 진단 캡처까지 포함하며 DT 직렬화·브라우저 페인트는 제외된다.
