# 일치율의 평정자 쌍 위치 재사용 — 2026-09-13

`interrater_percent_agreement()`에서 각 행마다 동일한 `combn(seq_along(values), 2)`를 만들던 부분을 개선했다. 직전 행과 유효 평정자 수가 같으면 위치 조합을 재사용한다. 결측 등으로 수가 달라지면 다시 만든다. 한 크기의 위치 행렬만 저장한다.

일치 여부 비교, 전체 쌍 수와 일치 쌍 수의 누적 순서, 최종 비율은 그대로다. Gwet·Krippendorff의 직전 최적화가 반영된 파일을 기준으로 이번 변경만 비교했다.

## 측정

동봉 R 4.5.3, 1,000행·5개 범주·결측 없는 합성 자료, 변경 전후 순서를 교대로 5회 측정한 일치율 함수 중앙값.

| 평정자 수 | 변경 전 | 변경 후 |
|---|---:|---:|
| 5 | 0.03초 | 0.03초 |
| 20 | 0.13초 | 0.08초 |
| 50 | 0.50초 | 0.16초 |

50평정자에서 약 68% 감소했다. 전체 일치도 분석의 실행시간 감소율은 아니다. 유효 평정자 수가 매 행 바뀌면 재사용 효과가 작을 수 있다.

## 검증

- `validate_percent_agreement_pairs.R`: 변경 직전 실제 소스와 35개 일치율·전체 쌍 수·속성·경고·메시지·오류·난수 상태를 `identical(..., num.eq=FALSE)`로 비교해 통과했다.
- 1/2/3/10/30평정자, 결측·전체 결측 행·상수·빈 자료, factor 열과 행렬 입력을 포함한다. 파일 인수 없는 독립 기준 함수 검증도 통과했다.
- `validate_interrater.R` 외부 기준값 검증 통과.
- 명목형·순서형 전체 분석 객체와 난수 상태, 화면·저장 HTML, Excel 모든 시트 정확 일치 확인.
- `git diff --check` 통과.

표시·저장 내용은 변경하지 않았다. 명시한 시험 범위의 정확 일치 검증이며 모든 입력에 대한 불변 증명은 아니다. 설치 파일은 재빌드하지 않았다.
