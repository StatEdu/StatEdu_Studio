# 자동 카운트 분포 선택 보조표 — 2026-09-17

실제 카운트 자료에서 자동 선택이 Poisson과 음이항을 각각 선택하는 두 경로를 실행했다. 선택 사유, 음이항/log 표시, 카운트 판정, 영과잉 비율/선별/음성 안내, 두 분포의 선별 AIC/BIC 등 11개 문구를 8언어로 연결했다. 분포 선택 규칙이나 추정 계산은 변경하지 않았다.

`validate_longitudinal_auto_count_i18n.R`에서 자동 가족 판정이 count인지, 실제 최종 모형의 분포가 예상한 Poisson/음이항인지, 계수 표가 반환되는지 확인한다. 두 경로 × 8언어의 16개 적합 세부정보 표에서 항목·문구 번역과 숫자 문자열 및 원본 표 보존을 검사했다. AIC/BIC 같은 통용 기호는 유지한다.

추가 표를 기존 `validate_longitudinal_error_exports.R`에 포함해 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel 저장을 검사한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 확인한다. 산출물: `tmp/longitudinal-error-exports`.

영값 과다 경고의 양성 경로, 선별 적합 실패, 다른 자동 분포·모형 조합과 전체 브라우저·페이지별 시각 검토는 남아 있다. 메타분석과 설치본은 작업하지 않았다.

위 검사와 기존 MI/IPW·가중치·보고 점검표·사용자 이름 검사, 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 모든 캡처 텍스트도 통과했으며 두 언어 모두 현재 35쪽/누적 69쪽이다. 변경 파일의 `git diff --check`도 통과했다. 기존 합성 모형의 특이 적합·수렴 등 경고는 유지되며, 검증 통과는 해당 경고가 없다는 의미가 아니다.
