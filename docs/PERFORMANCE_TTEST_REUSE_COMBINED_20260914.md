# 주 검정·사후검정 재사용 통합 검증 — 2026-09-14

## 결과

최근 두 최적화를 함께 적용한 현재 코드를, 두 변경 전 기준본과 비교했다. **12개 자료 조건 × 독립 실행 3회 = 36회에서 전체 결과가 정확히 일치**했다. 시간은 34회 단축·1회 동률·1회 증가였으며 각 조건의 중앙값은 모두 줄었다.

2만 행·8집단 연속값 자료에서 중앙 시간은 무결측 **0.78→0.42초**, 결측 포함 **0.64→0.34초**였다. 이번에는 제품을 추가 수정하지 않고 통합 효과와 결측·동순위 조건을 검증했다. 개별 최적화의 개선율을 합산한 결과가 아니다.

## 조건

- 번들 R 4.5.3, 데이터 seed 939, capture seed 718.
- 20,000행, 2/4/8집단. `y=rnorm(20000)+g*.3` 또는 반올림한 자료.
- 결측 없음 또는 y와 g 각각에 독립 확률 10%로 결측 부여. 후자는 완전 사례 16,171행이다. 행의 10%만 제외하는 조건이 아니다.
- 비모수 검정, 사후검정, 추가 평균·표준편차 표를 켜고 Holm 조정을 사용했다. 전체 결과에는 원래 중앙값/IQR 표와 추가 표가 함께 포함된다.
- 새 R 프로세스 3개를 순차 실행했다. 각 조건에서 기존/현재를 예열하고 측정했으며 두 번째 프로세스는 집단 수와 기존/현재 실행 순서를 뒤집었다.

이 결과는 해당 입력과 실행 환경의 관측이다. 다른 자료에서 동일한 개선율을 보장하지 않으며 메모리나 앱 로딩 시간도 측정하지 않았다.

## 정확성 및 범위

모든 조건에서 예열·실측 반환값, 경고/메시지 및 오류의 클래스·문구, 표준출력, RNG를 `identical(..., num.eq=FALSE)`로 비교했다. 기준 분석이 오류가 아니고 결과가 생성됐는지도 검사했다. 정규화나 수치 허용 오차는 사용하지 않았다.

이번에는 새 자료 조건의 전체 결과를 비교했다. 원시 htest·p행렬, 경고·메시지·난수·오류 시 재실행, 16개 저장 한도 및 분석별 수명 검증은 앞선 `validate_ttest_main_reuse.R`, `validate_ttest_pairwise_reuse.R`에 있으며 이번 전체 검증 횟수에 더하지 않았다. 새 원시 검정 추적을 수행했다고 주장하는 검증은 아니다.

기준본은 `output/independent-pairwise-reuse-20260914/baseline.R`에서 가져왔다. 주 검정·사후검정 재사용 전 소스이며 이전의 다른 최적화는 포함한다. 현재 및 기준본 스냅샷, 검증 스크립트, 각 실행 CSV는 `output/independent-reuse-combined-20260914/`에 있다. 나머지 앱 모듈은 실행 시 작업 공간에서 로드한다.
