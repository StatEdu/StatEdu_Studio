# 대응분석의 미사용 표준편차 계산 검토 — 2026-09-14

## 결정

왜도·첨도 계산에서 사용하지 않는 표준편차 계산을 건너뛰는 후보를 시험했다. 검증한 결과는 정확히 같았지만, 결측 자료의 전체 실행 개선이 일관되지 않아 **제품에는 반영하지 않았다**. 검토 시작/종료의 `R/analysis_paired.R`은 기준본과 동일하다.

## 후보 범위

앱의 `paired_diff_assumption()`은 `psych::skew(..., type=2)` 및 `psych::kurtosi(..., type=2)`를 사용한다. 설치된 함수의 벡터 경로에서는 `sdx <- sd(x, na.rm=na.rm)`가 계산되지만 type 2 결과 식에 쓰이지 않는다.

연구 환경의 함수 복사본에서 그 문장만 `if (!identical(type, 2)) sdx <- sd(x, na.rm=na.rm)`로 바꿨다. 가정검사 함수의 두 psych 호출을 연구 복사본으로 연결했다. 원래 평균·중심화·거듭제곱·합산·보정식, Shapiro-Wilk, 이상치 검사, 검정 선택을 유지했다. 제품 함수와 psych 네임스페이스는 수정하지 않았다. 후보는 앱의 type 2 벡터 경로를 시험한 것이며 다른 모든 psych 사용 방식에 대한 일반적인 최적화 검증은 아니다.

## 전체 실행 측정

10만 행 × 16열의 8개 대응쌍. 정규 또는 로그정규 난수, 셀별 결측 확률 0/10%. 데이터 seed 939, capture seed 718. R 4.5.3 번들로 가정검사와 중앙값/IQR 옵션을 켠 `prepare_paired_results()` 전체를 측정했다. 정규 자료는 대응 t 검정, 로그정규 자료는 Wilcoxon으로 선택됐다.

3개의 새 R 프로세스를 순차 실행하고 각 조건에서 양쪽을 예열했다. 두 번째 프로세스는 분포 및 기존/후보 순서를 뒤집었다. 원시 가정검사 추가 검증은 시간 측정 이후 별도로 수행했다. 단위는 초다.

| 분포 | 셀별 결측률 | 기존 1/2/3 | 후보 1/2/3 | 중앙값 기존→후보 |
|---|---|---|---|---|
| 정규 | 0% | 0.25 / 0.21 / 0.25 | 0.22 / 0.20 / 0.22 | 0.25→0.22 |
| 정규 | 10% | 0.19 / 0.17 / 0.18 | 0.19 / 0.27 / 0.17 | 0.18→0.19 |
| 로그정규 | 0% | 0.47 / 0.37 / 0.46 | 0.34 / 0.49 / 0.34 | 0.46→0.34 |

무결측 정규 자료는 3회 모두 단축됐고 무결측 로그정규는 2회 단축·1회 증가했다. 결측 자료는 각 분포에서 단축·증가·동률이 한 번씩 나타났으며, 정규 결측 조건의 중앙값은 증가했다. 일부 조건의 이득은 있지만 전체 대상 경로에 대한 재현성이 충분하지 않다. 이를 위해 psych 함수 복사본 유지·버전 검증을 제품에 추가하는 것은 이번 측정으로 정당화하지 않았다. 특정 한 번의 시간 차이를 결정적인 원인 분석으로 해석하지 않는다.
