# 전체 화면 후보 분류 및 측정불변성 재검증

## 남은 화면 후보 47개 분류

앞선 전체 화면 감사에서 확인된 5개 누락 문구를 수정한 후 원문 반환 후보 47개 조합이 남았다. `classify_multilingual_panel_candidates.R`로 출처를 대조했다.

| 분류 | 문구/언어 조합 | 근거 |
|---|---:|---|
| 이미 번역된 사전값 | 22 | 대상 언어 사전값과 일치하고 영어값과 다름 |
| 이미 번역된 제목 함수 반환값 | 20 | 실제 제목 함수의 대상 언어 반환값과 일치하고 영어 반환값과 다름 |
| 통계 메뉴 이름 | 5 | t-test / ANOVA라는 분석명 유지 |
| 미분류 | 0 | 위 분류에 모두 해당 |

따라서 이번 47개 조합에서는 새 번역 누락을 확인하지 않았다. 기존 함수가 이미 번역된 제목을 다른 번역 함수에 다시 전달하면서 '입력과 출력이 같다'는 조건에 잡힌 경우가 대부분이다. 언어별 제목을 무조건 제외하는 방식이 아니라 원문·사전·함수 반환값을 대조한다. 원시 후보 목록은 보존한다.

## 측정불변성 검증

- `audit_invariance_appendix_titles.py`: 측정불변성 부록 제목 14개의 일본어·중국어·스페인어·프랑스어·독일어·베트남어 사전 누락 0개.
- `validate_invariance_score_i18n.R`: 실제 lavaan 다집단 CFA의 요인부하량 제약 모형에서 score 진단을 계산했다. 알려진 단계 제목 6개, 사용자 단계 이름, 사용자 제약 이름, 수치 및 빈 결과 표시를 8개 언어로 검증해 통과했다. 모든 불변성 단계 모형을 각각 적합했다는 의미는 아니다.
- 사용자 단계·제약 문자열과 통계값 보존을 확인했다. 기존 작업의 유효한 번역을 재확인한 것이며 이번에 번역을 새로 추가하지 않았다.

## 범위와 다음 단계

이번 검사는 기본 화면에서 수집한 47개 후보와 측정불변성 부록 제목·score 진단에 한정한다. 전체 프로그램의 모든 동적 안내·모형 옵션·오류에서 미번역이 없다는 뜻은 아니다. 정적 후보가 많은 구조모형의 집단 비교·측정불변성 결과를 실제 사용되는 본표/부록/안내 경로로 계속 분류해야 한다.

기존 매개·조절효과 패널은 제외 상태를 유지한다. 사용자 모형 캔버스와 구조방정식 기능은 점검 대상이다. 제품 사전·출력 코드는 수정하지 않았으며 저장 파일 재생성·설치본 빌드는 수행하지 않았다.
