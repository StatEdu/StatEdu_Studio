# 종단 보고 점검표 항목·상태·설명 — 2026-09-17

보고 점검표의 비영어 표시를 검사하여 `Needs review`, 자료 구조 요약, 가중치 설명, 결측 민감도 실행, 권고 대안, 민감도 제안/비교 및 자료 구조·결측·계수·주석·원고 작성 설명 등 12개 문구의 누락을 보완했다. 각 문구를 8언어 카탈로그에 연결했다.

`validate_longitudinal_weight_checklist_i18n.R`에서 생성된 13행 점검표의 항목명과 상태, 가중치 외 고정 설명이 비영어 언어에서 원문으로 남는지 검사한다. 가중치 설명은 기존 번역 표와 정확히 일치하는지 확인하고 사용자 변수명 원문 보존 검사를 유지한다. 소프트웨어명/버전은 번역 대상에서 제외한다. 8언어 검사가 통과했다.

이 시험은 준비됨·검토 필요·미선택·사용 불가가 포함된 대표 점검표를 대상으로 한다. 모든 실제 모형에서 생성되는 동적 설명의 전체 조합을 검사한 것은 아니다.

동일 점검표를 포함한 `validate_longitudinal_error_exports.R`로 기존 MI/IPW·가중치·사용자 이름 검사 및 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel 저장을 검증한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 확인한다. 산출물: `tmp/longitudinal-error-exports`.

계산 코드·메타분석·설치본은 변경하지 않았다. 전체 브라우저·모형 조합·페이지별 시각 검토는 별도 남은 범위다.

위 검사와 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 모든 캡처 텍스트도 통과했으며 각 언어 현재 21쪽, 누적 41쪽이다. 변경 파일의 `git diff --check`도 통과했다.
