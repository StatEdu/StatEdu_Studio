# StatEdu Studio 생존분석 v1 분석 선택 흐름

상태: 1단계 확정안
범위: 분석 목적과 자료 구조를 확인하여 적절한 생존분석 화면으로 안내하는 공통 진입 흐름
후속 문서: 데이터 입력 규격, 분석별 상세 명세, 자동 추천 규칙표

## 1. 설계 원칙

- 분석법보다 연구질문과 추정대상(estimand)을 먼저 정한다.
- 데이터에서 확인 가능한 사실과 연구자가 확인해야 하는 의미를 구분한다.
- 추천은 이유, 대안, 주의사항을 함께 제시한다.
- 통계적 유의성은 분석 품질의 합격 기준으로 사용하지 않는다.
- 기존 Kaplan–Meier 및 Cox 메뉴는 유지하되 공통 분석 설계 화면에서도 접근할 수 있게 한다.
- 체크 표시(✓)는 `평가 또는 확인 완료`를 뜻하며 `가정이 자동으로 충족됨`을 뜻하지 않는다.

## 2. 공통 진입 화면

생존분석 메뉴의 첫 화면 이름은 `분석 설계(Analysis Setup)`로 한다. 사용자는 안내형 흐름을 이용하거나 기존 분석으로 바로 이동할 수 있다.

### 2.1 진입 선택

1. 분석 설계 안내 시작
2. Kaplan–Meier 바로 열기
3. Cox 회귀분석 바로 열기

바로 열기를 선택해도 실행 전 필수 데이터 검사는 동일하게 적용한다.

### 2.2 분석 목적

필수 단일 선택 항목:

| 값 | 사용자 표시 | 주된 결과 |
|---|---|---|
| `group_comparison` | 집단 간 생존 경험 비교 | 생존곡선, 생존확률, RMST 차이 |
| `association` | 위험요인·연관성 평가 | HR 또는 원인별 HR, 95% CI |
| `prediction` | 개인의 사건 위험 예측 | 절대위험, calibration, discrimination |
| `recurrent` | 반복사건 분석 | 사건률 또는 반복사건 모형 효과 |
| `competing` | 경쟁사건별 발생 분석 | CIF, 원인별 HR 또는 sHR |
| `state_transition` | 상태 전이 분석 | 전이위험, 전이확률, 상태점유확률 |

v1에서 직접 실행하는 목적은 `group_comparison`, `association`, `competing`이다. `prediction`, `recurrent`, `state_transition`은 요구사항을 저장하고 지원 범위와 예정 기능을 명확히 안내한다.

## 3. 필수 확인 순서

질문 순서는 아래와 같이 고정한다. 뒤 질문의 노출 여부는 앞선 응답에 따라 달라진다.

### 3.1 시간 구조

1. 시간 원점(time origin)은 무엇인가?
2. 분석 시간은 한 개의 종료시간인가, 시작–종료 구간인가?
3. 관찰 도중 늦게 위험집단에 진입하는 대상자가 있는가?
4. 사건시점은 정확히 관측되는가?

분기:

- 단일 종료시간 + 정확한 사건시점 → 표준 right-censored 구조 후보
- entry와 exit 존재 → delayed entry/left truncation 구조
- start와 stop이 행별로 존재 → counting-process 구조
- 사건이 두 검사시점 사이에서만 알려짐 → interval-censored 구조
- 사건이 특정 시점 이전에 발생한 것만 알려짐 → left-censored 구조

interval/left-censored 자료에는 표준 K–M 또는 표준 Cox를 기본 추천하지 않는다.

### 3.2 사건 구조

1. 관심 사건은 무엇인가?
2. 한 대상자가 관심 사건을 두 번 이상 경험할 수 있는가?
3. 관심 사건의 발생을 영구적으로 막는 다른 사건이 있는가?
4. 사건 코드가 여러 개인 경우 각 코드의 의미와 상호배타성을 사용자가 확인했는가?

분기:

- 단일 최초 사건 → K–M/Cox 후보
- 반복 가능 → recurrent-event 경로
- 상호배타적 경쟁사건 존재 → competing-risks 경로
- 여러 상태와 방향성 있는 전이 존재 → multi-state 경로

사건 코드가 여러 개라는 사실만으로 경쟁위험을 확정하지 않는다.

### 3.3 공변량 구조

1. 공변량이 기저시점에 고정되어 있는가?
2. 추적 중 값이 변하는 공변량이 있는가?
3. 공변량 효과가 시간에 따라 달라질 가능성을 분석하려는가?
4. 기관·가구·대상자 등 군집 구조가 있는가?

반드시 구분할 개념:

- time-dependent covariate: 공변량 값 자체가 시간에 따라 변함
- time-varying coefficient: 공변량의 효과가 시간에 따라 변함
- robust/clustered Cox: 분산 추정을 군집에 맞게 보정
- frailty model: 관측되지 않은 군집 이질성을 모형에 포함

### 3.4 분석 목표 상세

`association`에서는 다음 질문을 추가한다.

- 관심 효과는 전체 사건의 hazard인가?
- 경쟁위험이 있다면 원인별 순간위험인가, 실제 누적발생과 연결된 효과인가?
- 공변량은 연구설계·선행지식에 따라 지정했는가?

`competing`에서는 다음 선택을 필수화한다.

| 연구질문 | 기본 결과 | 회귀 확장 |
|---|---|---|
| 시간에 따른 실제 원인별 발생확률 | CIF | Fine–Gray를 선택적으로 병행 |
| 특정 원인의 순간 발생률과 요인 | 원인별 hazard | Cause-specific Cox |

Fine–Gray의 sHR을 일반 HR 또는 상대위험으로 표시하지 않는다. Cause-specific Cox에서 경쟁사건 시점의 censoring은 해당 estimand 정의의 일부임을 안내한다.

## 4. v1 추천 경로

```text
분석 목적 확인
  ├─ 집단 비교
  │    ├─ 경쟁사건 없음 → K–M + log-rank + RMST
  │    └─ 경쟁사건 있음 → CIF + Gray 검정
  ├─ 연관성
  │    ├─ 경쟁사건 없음 → Cox PH
  │    └─ 경쟁사건 있음
  │         ├─ 원인별 순간위험 → Cause-specific Cox
  │         └─ 누적발생과 연결 → CIF + Fine–Gray
  ├─ 경쟁사건 분석 → CIF를 공통 기본 출력으로 제공
  ├─ 예측 → v1.1 Prediction 경로 안내
  ├─ 반복사건 → v1.2 Recurrent-event 경로 안내
  └─ 상태 전이 → v1.2+ Multi-state 경로 안내
```

다음 조건은 위 경로보다 먼저 처리한다.

- interval/left censoring → 전용 분석이 필요하다는 차단 안내
- delayed entry → entry를 반영할 수 있는 분석만 허용
- time-dependent covariate → start–stop 입력이 없으면 실행 차단
- 사건 없음 → 실행 차단
- 시간값 오류 또는 사건 후 위험시간 역전 → 실행 차단

## 5. PH 가정 이후의 안내

Cox 실행 후 PH 평가는 단일 p-value로 자동 합격 판정하지 않는다. 전역·변수별 Schoenfeld 검정, 잔차 도표, 효과크기와 연구 맥락을 함께 제시한다.

잠재적 비례위험 위반이 있을 때 선택 가능한 경로:

1. 층화 Cox: 해당 변수의 HR 자체가 주 관심이 아닐 때
2. time-varying coefficient: 시간별 효과가 관심일 때
3. RMST: 집단 간 제한평균 생존시간 차이가 연구질문에 부합할 때
4. flexible parametric model: v1.1 고급 분석으로 안내

PH 검정이 유의하다는 이유만으로 특정 대안을 자동 실행하지 않는다.

## 6. 자동 확인과 사용자 확인의 경계

### 자동 확인 가능

- 변수 존재 여부와 자료형
- 결측 개수 및 complete-case 분석 N
- 음수·무한 시간, `entry >= exit`, `start >= stop`
- 사건 코드의 고유값과 빈도
- 대상자별 반복 행 및 반복 사건 후보
- 군집 ID별 관측 수
- 사건 수와 모형 파라미터 수

### 사용자 확인 필수

- 시간 원점과 임상·실질적 의미
- 어떤 코드가 검열, 관심 사건, 경쟁사건인지
- 여러 사건이 실제로 상호배타적인지
- 검열이 비정보적이라고 볼 수 있는 근거
- 분석 목적과 estimand
- 교란변수 선정 근거
- RMST 제한시간 `tau`의 연구적 정당성
- 연관성 결과의 인과적 해석 가능 여부

## 7. 추천 결과 카드

분석 실행 전에 다음 구조의 카드를 표시한다.

```text
추천 분석
  Kaplan–Meier + log-rank + RMST

추천 이유
  단일 최초 사건, 경쟁사건 없음, 두 집단 비교 목적

주 결과
  시점별 생존확률과 95% CI, 생존곡선, RMST 차이와 95% CI

검토할 사항
  검열기전, 추적기간, RMST tau, 집단별 위험집단 수

대안
  공변량 보정이 필요하면 Cox 또는 marginal adjusted survival 검토
```

사용자는 `추천 분석 열기`, `다른 분석 선택`, `설정 수정` 중 하나를 선택한다.

## 8. 현재 구현과의 연결

| 현재 기능 | v1 흐름에서의 위치 | 변경 원칙 |
|---|---|---|
| Kaplan–Meier 메뉴 | 집단 비교 추천 결과 | 기존 직접 진입 유지 |
| Cox Regression 메뉴 | 연관성 추천 결과 | 기존 직접 진입 유지 |
| `time` + `event` | 표준 right-censored 입력 | 2단계에서 입력 구조 확장 |
| 단일 `event_value` | 관심 사건 이진화 | 사건 역할 매핑으로 확장 |
| complete-case 처리 | 기본 결측 처리 | 제외 건수와 변수별 사유 출력 추가 |
| `cox.zph` | PH 진단 | 자동 PASS 대신 검토 결과로 표시 |

## 9. 1단계 완료 기준

- 분석 목적 여섯 가지가 상호 구분되어 있다.
- 시간·사건·공변량 구조 질문의 순서가 정해져 있다.
- v1 지원 경로와 후속 버전 안내 경로가 구분되어 있다.
- Cause-specific Cox와 Fine–Gray의 estimand가 구분되어 있다.
- 자동 확인과 사용자 확인의 경계가 정의되어 있다.
- 기존 K–M/Cox 직접 진입과의 호환 원칙이 정해져 있다.

이 기준을 충족하므로 분석 선택 흐름을 1단계 확정안으로 사용한다.
