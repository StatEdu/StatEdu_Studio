# 구조방정식 추정 옵션 다국어

- CFA·SEM·PLS의 추정 탭에서 추정법, 분석 목적, 분석계획/사전등록 상태와 참조 입력 안내, 결측 처리 설명을 공통 번역 함수에 연결했다.
- PLS/PLSc 추천 확인 및 평균 대체 정책 설명도 번역했다. 실제 추천/결측 처리 정책은 변경하지 않았다.
- 부트스트랩 공통 선택지의 '계산하지 않음'과 재표집 횟수 단위를 번역했다. 횟수 값·기본값과 각 분석 실행 조건은 유지한다.
- 추가 언어 사전 자료: `scripts/fill_structural_estimation_i18n.py`(22문구).

## 검증

- `validate_structural_estimation_i18n.R`: 3분석 × 8언어 통과. 추정 탭의 라벨·선택지·설명·입력 힌트, 모든 재표집 횟수 표시를 확인했다.
- 버튼/입력/선택지의 ID·값·기본 선택·조건식 속성이 영어 기준과 동일함을 검사했다. 수정 전/후 영어 HTML도 자동 생성 탭 ID만 정규화하여 동일함을 확인했다.
- 공통 `validate_multilingual_coverage.R` 통과. 로그: `tmp/structural-estimation-i18n.log`, `tmp/structural-estimation-coverage.log`.
- UI만 수정하여 실제 분석 계산·결과 본표/보조표·저장 내용은 바뀌지 않았다. 이번 변경에는 5형식 내보내기 재검사가 해당하지 않는다.

## 남은 범위

- 부트스트랩 탭의 나머지 상세 설명/종류별 라벨, 고급 옵션·다집단·타당도·진단·공통방법 탭은 별도 점검이 필요하다.
- 브라우저에서 옵션을 바꾼 뒤 언어 왕복하는 검사와 실제 모델 실행 검사는 이번 렌더링 검사에 포함되지 않는다.
- 이전 복합표본 사용자 모형의 HWPX 시간 초과는 여전히 미해결이다. 설치본을 만들지 않았다.
