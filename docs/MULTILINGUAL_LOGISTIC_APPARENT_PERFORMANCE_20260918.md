# 로지스틱 회귀 표본 내 성능 표 번역

## 변경

실제 이분형 로지스틱 회귀 결과에서 6개 문구가 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남는 것을 재현하고 8개 언어 사전에 반영했다.

- 표본 내 모형 성능 제목.
- 추정 표본의 성능이 내부 검증·홀드아웃 검증·외부 검증을 대신하지 않는다는 설명.
- AUC, Brier 점수, Tjur R²의 표본 내 지표명.
- Basis 열 제목.

한국어 지표명의 괄호 앞 공백은 사전 표기에 맞춰 정리되었다. 통계 계산·결과 렌더링 코드는 변경하지 않았다. Accuracy는 이분형 성능 표에 생성되지 않으므로 이번 대상에서 제외했다.

## 검증

`validate_logistic_apparent_performance_i18n.R`는 80명의 이분형 결과와 연속형 예측변수로 실제 모형을 적합한다. 성능 블록 안에서 제목·설명·지표명·열 제목 전체가 번역되었는지 검사한다.

- 보완 전 6개 외국어 사전 누락 재현, 보완 후 8개 언어 실제 표시 검사 통과.
- 영어 본표의 언어 간 동일성, 전체 결과 객체 및 번역 문구와 같은 사용자 변수명 보존 확인.
- `validate_logistic_status_i18n.R`의 기존 수렴 상태·실제 적합 회귀 검사와 `validate_i18n_contract.R` 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 검사 통과. 표 아래 설명은 `validate_logistic_performance_note_exports.py`로 4개 형식에서 별도로 검사하고 PDF 기대 문구에도 추가했다.
- PDF 텍스트 보존 검사 통과. 두 언어 모두 현재 4쪽·누적 7쪽.
- 공용 저장 검증기 `validate_longitudinal_count_exports.R` 및 PDF 검사기를 재사용했다. 표지 제목은 Longitudinal이고 본문은 실제 로지스틱 결과 캡처다. 저장 시 분석을 재실행하지 않았다. 산출물: `tmp/logistic-apparent-performance-i18n/exports`.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드 및 문서 앱별 수동 시각 검토는 수행하지 않았다. 로지스틱 결과 전체 번역 완료를 의미하지 않는다.
