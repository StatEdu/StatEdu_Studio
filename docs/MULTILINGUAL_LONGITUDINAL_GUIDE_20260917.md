# 모형 해석 보조표 — 2026-09-17

고정효과·확률효과, 확률절편, 확률절편/기울기, REML 잔차 공분산 안내의 5개 문구 유형을 8언어 사전에 연결했다. 표 생성 시 안내 유형과 변수명을 따로 보관하여, 번역할 때 문장 안의 사용자 이름을 추측해서 분리하지 않는다. 원본 셀과 저장된 안내가 일치할 때만 표시 번역을 적용한다. 원본 결과와 계산은 변경하지 않는다.

`validate_longitudinal_guide_i18n.R`에서 5개 모형의 기울기 옵션 조합 10개와 REML UN/AR(1) 2개, 총 12개 표시 사례를 8언어로 확인했다. 이는 합성 결과 객체의 표시 검사이며 12개 실제 모형 적합을 의미하지 않는다. 번역 단어·마침표·한글을 포함한 ID/시점 이름과 패키지 버전 문자열 및 원본 표를 보존한다.

기존 실제 GEE/LMM/패널 고정효과 검사는 `validate_longitudinal_structural_i18n.R`로 실행한다. 현재·누적 5종 저장은 `validate_longitudinal_count_exports.R tmp/longitudinal-guide/tables.rds tmp/longitudinal-guide-exports`로 수행하며 PDF 캡처 문구도 별도 검사한다. 저장할 때 분석을 다시 실행하지 않는다.

다른 분포 식별자·상관구조와 브라우저·페이지별 시각 검토는 남아 있다. 메타분석과 설치본은 변경하지 않았다.

12개 표시 사례 × 8언어와 기존 실제 GEE/LMM/패널 고정효과의 8언어 검사가 모두 통과했다. 실제 본 표 영어 유지·진단 번역·원본 라벨 보존을 확인했으며 합성 LMM의 특이 적합 경고는 유지된다. 한국어/일본어 현재·누적 HTML·PDF·Word·직접 생성 HWPX·Excel 저장 및 PDF 캡처 문구 검사도 통과했다(두 언어 모두 현재 3쪽/누적 5쪽). 변경 파일의 `git diff --check`가 통과했다.
