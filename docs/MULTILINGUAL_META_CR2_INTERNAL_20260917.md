# CR2 내부 오류 보조 안내 — 2026-09-17

정방행렬, 양의 준정부호, CR 유형, 입력 길이, 신뢰수준, CR3 특이 보정행렬, CR2 분산 추정 실패, Satterthwaite 자유도 추정 실패의 상세 8종을 8개 언어로 연결했다. 본표 영어 셀은 유지하고 결과 아래 CR2 실패 보조 안내에서만 번역한다.

`validate_meta_warning_exports_i18n.R`에 실제 오류 분기 7종과 자유도 계산 경계 모의 검사 1종을 추가했다. 모의 처리는 시험용 함수 복제 환경에 한정되며 원래 분석 함수는 변경하지 않았다. 기존 조건 오류 5종과 함께 화면 번역/영어 본표/결과 객체 불변, 한국어·일본어 현재/누적 HTML/PDF/Word/HWPX/Excel 내용 검사를 수행한다. PDF 텍스트와 문서 그림은 `validate_meta_warning_pdf.py`로 확인한다.

위 검사와 카탈로그 회귀 검사는 모두 통과했다. PDF는 한국어/일본어 각각 현재 11쪽·누적 20쪽이었다. 산출물은 `tmp/meta-warning-i18n`에 있다.

외부 라이브러리의 미등록 오류는 원문을 보존한다. 이번 범위가 전체 앱 다국어 완료를 의미하지 않으며 실제 브라우저 조작/페이지별 시각 검토는 수행하지 않았다. 설치본을 만들지 않았다.
