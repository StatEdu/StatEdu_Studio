# 작은 자료의 Kendall 경로 선택 조정

## 변경

빈도 집계 빠른 경로의 최소 입력 길이를 3에서 512로 높였다. 511개 이하의 완전 관측치 쌍은 기존 stats::cor 계산을 사용한다. 전체 데이터 행 수가 아니라 기존 쌍별 결측 제거 후 길이를 기준으로 한다. 최대 10,000행·축별 64범주, 버전·플랫폼·함수 소스 조건은 유지했다.

128행·64범주에서는 빈도 집계가 세 번 모두 느렸고, 512/1,000행에서는 모든 측정이 빨랐다. 이에 따라 측정한 범위에서 보수적으로 512를 선택했다. 가능한 모든 자료에 대한 최적 임계값을 찾았다는 뜻은 아니다.

## 측정 방법

128/512/1,000행 × 2/16/64범주, 6변수·15쌍, 시드 33 정수 범주 자료다. 각 열의 첫 k개 행에 모든 범주를 넣어 지정 범주 수를 보장했다. Kendall 지정, 정규성 및 잠재상관은 비활성화했다.

두 실험 모두 빠른 경로 도입 전 소스를 기준으로 비교했다. 첫 실험은 최소 길이 3인 소스, 두 번째는 최소 길이 512인 제품이다. 각각 새 R 프로세스 세 개에서 소스별 함수를 명시적으로 컴파일하고 양쪽 예열 후 순차 측정했다. 두 번째 프로세스는 범주 수 순서와 기존/변경 순서를 뒤집었다.

시간은 전체 결과 준비·진단 수집·동일성 검사를 5회 반복한 총시간을 5로 나눈 값이다. 프로파일러는 없으며 입력 생성·앱 로딩·화면·내보내기는 제외한다. 별개 실험 간 시간을 직접 합치지 않는다.

## 발견과 재측정

첫 실험의 128행·64범주는 기존 0.008/0.008/0.010초, 제한 전 새 경로 0.012/0.016/0.014초였다. 차이는 작지만 세 번 모두 증가했다. 128행·2/16범주는 단축·동일·증가가 섞였다. 512행과 1,000행은 총 18회 모두 단축됐다.

최소 512행으로 조정한 뒤의 중앙값은 다음과 같다(초).

| 행 수 | 범주 수 | 기존 계산 | 조정한 제품 |
|---:|---:|---:|---:|
| 128 | 2 | 0.010 | 0.006 |
| 128 | 16 | 0.012 | 0.010 |
| 128 | 64 | 0.010 | 0.010 |
| 512 | 2 | 0.040 | 0.016 |
| 512 | 16 | 0.056 | 0.020 |
| 512 | 64 | 0.056 | 0.026 |
| 1,000 | 2 | 0.118 | 0.024 |
| 1,000 | 16 | 0.186 | 0.028 |
| 1,000 | 64 | 0.172 | 0.038 |

128행·64범주는 세 실행 모두 0.010→0.010초였다. 512/1,000행은 다시 18회 모두 단축됐다. 128행은 모두 같은 기존 계산 커널을 사용하므로 작은 중앙값 차이를 계산 알고리즘의 개선으로 주장하지 않는다. 모든 호출의 시간을 보장하는 측정도 아니다.

## 결과 보존

두 실험 각각 9조건 × 3프로세스에서 예열과 5회 묶음의 모든 반복 결과·진단·stdout·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 수치 정규화·반올림·허용오차는 적용하지 않았다.

영구 회귀 검증에 511행 복귀·512행 활성화·128행 다범주 복귀를 추가하고 기존 빠른 경로 입력 길이를 조정했다. 전체 검증을 다시 실행해 cor 경계/복귀 19개, 방법·exact 조합 18개, 원시 검정 720개, 확대 사례 96개가 통과했다. 확대 사례 중 128행의 45개는 이제 기존 경로를 사용하고 나머지 51개는 빠른 경로를 사용함을 확인한다.

## 자료

`output/correlation-kendall-small-20260915/`에 도입 전 baseline.R, 제한 전 source.R, 조정 후 gated-source.R, 각 setup/check 스크립트와 timing/gated CSV 세 개씩을 보존했다. 측정 후 재현 스크립트는 같은 내용의 저장 소스를 읽도록 고정했다. 번들 Windows R 4.5.3, 영어 UTF-8 로캘, 기존 모듈 캐시와 패키지 설치 비활성화 환경이다.

출력 구성과 UI는 변경하지 않았고 별도 내보내기 생성·배포 빌드는 수행하지 않았다.
