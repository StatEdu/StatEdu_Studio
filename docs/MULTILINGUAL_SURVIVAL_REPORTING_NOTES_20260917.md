# 생존분석 보고 안내문 다국어화

## 변경

`survival_reporting_guidance_panel`의 공통 제목 1개와 안내문 3개를 `statedu_localized_text`에 연결했다. 한국어·영어 문구를 유지하면서 일본어·중국어·스페인어·프랑스어·독일어·베트남어 번역을 추가했다.

- 보고 체크리스트와 해석 가이드 제목
- 경험적 임계값은 자동 품질 판정 기준이 아니라는 설명
- 역 Kaplan–Meier 추적기간 추정 및 검열기전 검토 설명
- 체크리스트가 연구 설계 타당성·인과성을 자동 판정하지 않는다는 설명

## 검증

`scripts/validate_survival_reporting_notes_i18n.R`에서 실제 Kaplan–Meier, Cox, 경쟁위험 분석을 수행하여 8개 언어를 검증했다.

- 제목과 설명이 번역표 및 공통 주석 포맷에 맞게 출력된다.
- 기존 4개 보조표 생성 함수의 표 내용과 렌더링 결과가 동일하다.
- Cox 및 원인별 Cox의 본 표는 UI 언어와 무관하게 영어로 유지된다.
- 일본어로 캡처한 세 분석의 안내 패널을 현재·누적 결과로 저장한다. 저장은 캡처를 사용하며 재분석하지 않는다.
- 검증 산출물: `tmp/survival-reporting-notes-i18n/`.
- 현재 12개 표·누적 16개 표의 HTML/PDF/Word/HWPX/Excel 검증을 통과했다. PDF 본문·표지와 HTML/Word 표 순서 및 Excel 시트 수도 확인했다.

이번 범위는 공통 제목·안내문이다. 체크리스트의 동적 근거 문구와 해석 가이드 표 내부 번역의 완전성은 별도 점검 대상이다. 설치본은 생성하지 않았다.
