# 생존분석 정상 행의 제외 사유 문자열 처리 생략 — 2026-09-14

`survival_preflight()`는 모든 행의 제외 사유 목록에 `paste(..., collapse = ";")`를 호출했다. 이제 빈 문자열 벡터를 만들고 실제로 제외된 행에 대해서만 기존 문자열 결합을 수행한다. 정상 행의 기존 결과인 빈 문자열은 그대로 유지한다.

검증 규칙, 제외 마스크, 사유의 중복 제거와 순서, 분석 자료 구성, 사건 매핑 및 안내 메시지는 변경하지 않았다. 수치 연산과 분석 모형도 변경하지 않았다.

## 입력 검증 전체 시간

합성 자료 10만 행, 시간·사건·집단·연령 변수로 측정했다. 결측 자료는 연령의 정확히 10%를 NA로 지정했다. 번들 R 4.5.3의 새 프로세스에서 모듈과 설정을 로드한 뒤 `survival_preflight()` 전체를 측정했다. 각 프로세스는 정상 자료, 결측 자료 순서로 실행한다. 프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍의 변형 순서를 뒤집었다. 함수 환경은 같은 전역 도우미 환경을 사용했다.

| 조건 | 변경 전 중앙값(초) | 변경 후 중앙값(초) | 감소율 |
| --- | ---: | ---: | ---: |
| 정상 자료 | 0.47 | 0.36 | 약 23% |
| 연령 결측 10% | 0.39 | 0.28 | 약 28% |

| 반복 | 정상 전/후(초) | 결측 전/후(초) |
| --- | --- | --- |
| 1 | 0.45 / 0.36 | 0.39 / 0.27 |
| 2 | 0.47 / 0.36 | 0.38 / 0.28 |
| 3 | 0.47 / 0.38 | 0.39 / 0.28 |

각 조건의 변경 전후를 비교한 값이다. 정상/결측 조건 사이의 시간 차이는 같은 프로세스 안의 실행 순서에도 영향을 받으므로 직접 비교하지 않는다. 모형 적합, 전체 분석 실행, 프로그램 시작 또는 저장 시간의 감소율은 아니다.

- 0/1/30/120행, 결측 0/10/100%, 시간 결측·음수·무한대, 사건·집단 결측, 지연 진입, start-stop 자료의 누락 ID와 겹치는 구간을 포함했다.
- 10만 행 측정의 6쌍에서도 분석 자료, 포함/제외 행, 제외 사유, 건수, 이슈 및 변환 정보 전체가 정확히 동일했다.
- 실제 서버 모의 실행으로 자료 업로드·변수 선택·상관분석·Kaplan–Meier 분석을 완료했다. 보관된 기준과 전체 결과 객체, HTML/의존성, 경고 및 알림이 정확히 같았다. 분석 실행 경고는 0개였다.
