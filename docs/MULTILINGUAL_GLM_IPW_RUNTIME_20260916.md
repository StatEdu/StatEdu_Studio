# GLM 실제 IPW 분기 점검

2026-09-16. 설치본은 만들지 않았다.

## 변경

- IPW 상세 진단 항목과 상태 12개를 6개 언어에 추가했다.
- 관측모형 변수와 보조변수가 번역 대상 문구와 같더라도 원문을 유지하도록 사용자 값 행 정보를 생성·전달한다. 실제 절편만 모형을 뜻하는 상태 문구는 번역한다.
- 실제 IPW 적합에서 `Model-based` 같은 비표준 변수명이 수식의 뺄셈으로 해석되어 절편만 모형으로 대체되는 오류를 발견했다. 수식 생성 시 변수명을 R 심벌로 인용하도록 수정했다.

## 검증

- 결측값을 넣은 120행 자료로 Gaussian IPW를 실제 적합하는 검증을 추가했다.
- 비표준 보조변수명과 동일 데이터를 단순 변수명으로 바꾼 경우의 IPW 가중치가 일치하며, 관측모형 실패 대체 경로로 가지 않는지 검사한다.
- `Intercept only`라는 실제 변수명은 보존되고, 실제 절편만 상태와 구분되는지 검사한다.
- 기존 8개 언어 GLM 검사에서 본표 영어, 사용자 라벨, 내부 옵션 값 검사도 유지한다.
- 실제 IPW를 포함한 8개 언어 검사와 i18n 계약 검사가 통과했다. 일본어 실제 IPW 상세표를 저장 검증 fixture에도 추가했다.
- 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교와 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.
- 기존 합성 count 분석의 음이항 반복 한도 경고는 별도로 발생한다.

## 남은 범위

전체 앱의 다국어 완료를 의미하지 않는다. MI 실제 계산 분기 및 다른 분석 화면/옵션은 추가 점검 대상이다. 이전 결과에는 사용자 행 정보가 없을 수 있다.
