## 후보와 측정 범위

현재 `R/analysis_correlation.R`의 순위 캐시는 그대로 기준으로 사용했다. 후보는 순위 계산 시 `cor.test.default`가 만든 부분집합 복사본과 입력 벡터가 정확히 같으면 캐시 키로 원본 입력 참조를 보관한다. 임시 입력 목록은 성공과 오류 모두에서 정리한다. 순위 계산 및 검정식은 변경하지 않았다.

실험 파일은 `output/spearman-rank-reference-20260914/`에 보관했다. `baseline.R`은 운영 코드, `current.R`은 미적용 후보이다. 각 버전을 새 R 프로세스에서 3회 실행했고 두 번째 세트는 순서를 뒤집었다. R 실행은 순차 수행했다. 시간 측정에서 초기 부트스트랩, 소스 로딩, 입력 생성과 사전 GC는 제외했다. 메모리는 별도 프로세스로 측정했다.

- 전체 결과·진단·표준출력·난수 상태 26조건 일치. Pearson, Spearman, Kendall, 자동 선택 및 잠재 상관 경로를 포함한다.
- 직접 검정 33조건에서 전체 htest/오류·진단·표준출력·난수 상태 일치. 조건별 반복 호출과 캐시 항목 상한도 확인했다.
- 시간 및 메모리 측정에서 저장한 전체 결과 12쌍은 수치 허용오차 없이 `identical(..., num.eq=FALSE)`로 일치했다.
- `references.R`에서 입력과 일치하는 캐시 키를 찾아 `tracemem` 주소 공유를 확인했다. 성공/오류 후 임시 입력 해제와 이후 원본 수정 시 기존 키 보존도 통과했다. 최초 검증은 첫 캐시 항목이 x라고 가정하여 실패했으며, 실제 저장 순서에 의존하지 않도록 입력 내용으로 항목을 찾는 검사로 수정했다.

운영 코드와 기준 스냅샷은 동일하다. 출력 변경이 없어 내보내기를 다시 실행하지 않았으며 설치 파일도 재빌드하지 않았다. 앞서 적용한 Spearman 순위 캐시는 유지한다.
