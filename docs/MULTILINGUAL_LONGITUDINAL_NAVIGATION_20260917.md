# 실제 앱 종단 메뉴·언어 왕복 — 2026-09-17

독립 종단 UI 시험에서는 나타나지 않았던 가중치 절단값 초기화를 실제 앱에서 재현했다. IPW 및 가중치 절단 5–95%를 설정하고 환경설정에서 일본어로 바꾼 뒤 종단 메뉴로 복귀하면 절단값이 `none`으로 돌아갔다. 전환 직전 DOM 및 Shiny 입력값이 `p05_95`인 것을 확인했다.

종단 설정 출력에 `suspendWhenHidden = FALSE`를 지정했다. 언어 변경 시 상위 lazy 탭이 다시 생성되더라도 숨겨진 하위 설정 화면이 최신 상태로 갱신되어 이전 기본값을 다시 전달하지 않게 한다. 분석 계산과 결과 출력은 변경하지 않았다.

검증은 별도 시험 프로필·localhost:43923·합성 CSV를 사용하는 실제 앱에서 수행했다. 설치 앱과 사용자 자료를 사용하지 않았다.

- `validate_longitudinal_navigation_browser.cjs`: 한국어 그대로 메뉴 왕복 및 ja/zh/es/fr/de/vi/en/ko 전환 후 복귀. 종속변수·ID·시간·독립변수, AR(1), 가중치 변수/유형/절단, IPW와 보조변수, 활성 Missing 탭, 번역된 독립변수 개수 제목 및 동일 브라우저 세션을 검사한다.
- `validate_longitudinal_auxiliary_clear.R`: 설정 복원, 명시적 해제, 재선택 및 숨겨진 보조변수 보존 통과.
- 범위 내 `git diff --check` 통과.

이번 범위는 GEE/IPW 설정의 메뉴 왕복이다. 모든 모형·옵션 조합, 실제 파일 교체 후 전체 앱 왕복, 분석 실행 후 결과·내보내기까지 검증한 것은 아니다. 메타분석 제외, 설치본 생성 없음.
