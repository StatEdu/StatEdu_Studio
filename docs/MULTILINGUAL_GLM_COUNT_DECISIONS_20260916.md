# GLM 카운트 최종 결정 사유

2026-09-16. 설치본은 생성하지 않았다.

## 변경

한국어 및 6개 다국어 카탈로그에 결정 사유 6개를 추가했다. MI 통합 전 음이항/포아송 고정, 과산포 기준 초과와 음이항 적합 가능, 산포 계산 불가, 음이항 적합 불가, 과산포 기준 미초과를 구분한다. 원래 선택 규칙·통계 계산·본표 영어는 변경하지 않는다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 모든 결정 사유를 보조표 fixture에 추가했으며 실제 카운트 분석의 결정 사유가 영어로 남지 않는지 검사했다. 사용자 라벨·수치·본표 영어 보존 검사도 유지했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 합성 count 분석의 기존 음이항 반복 한도 경고가 발생했으나 출력 검사는 통과했다.
- 각 실패 상황을 실제로 유발한 계산 시험이 아니라 해당 문장 번역과 실제 정상 카운트 결과 표시를 검사했다.
- 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교와 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.
