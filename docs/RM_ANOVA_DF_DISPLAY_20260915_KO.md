# RM ANOVA 자유도 표시 복구

공통 `result_cell_content()`가 `F (df1, df2)`를 괄호 앞에서 나누는 과정에서 `strsplit`의 영폭 구분 결과 중 두 번째 조각만 사용해 자유도 나머지를 버렸다. 괄호의 실제 위치를 찾아 앞/뒤 문자열을 추출하도록 수정했다. 줄바꿈 허용 위치와 주석 마커는 유지한다.

정수·소수·음수 통계량·0·주석 마커 검사, 공변량 포함 및 8시점 보관 RM ANOVA 결과의 화면/저장 셀 일치(공백 제외), 분석 결과 직렬화 불변 검사를 통과했다. 현재·누적 HTML/PDF/Word/HWPX/Excel의 F와 자유도 전체 문자열을 확인했다. PDF도 렌더링하여 자유도와 닫는 괄호가 표시되는지 확인했다.

검사: `scripts/validate_rm_df_display.R`, `scripts/validate_rm_df_pdf.py`. 산출물: `output/rm-df-display-20260915/`. 첫 검사에서 HTML 렌더러의 공백 차이를 확인하고 공백 정규화 후 재실행했다.

제품 계산식·F·p·자유도 값은 변경하지 않았다. 소스 수정 완료이며, 최근 회귀 β/Δ 및 기술통계 세로 배치 변경과 함께 설치 파일 반영은 아직 남아 있다.
