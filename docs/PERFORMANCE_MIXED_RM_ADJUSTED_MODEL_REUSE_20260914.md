# 혼합 반복측정 보정평균 모형 재사용 — 2026-09-14

## 적용 결과

`mixed_rm_descriptives`의 보정평균 계산에서 같은 시점의 전체 자료 모형을 집단마다 다시 적합하던 작업을 줄였다. 모형 적합은 시점별 한 번으로 하고, 집단별 참조 자료·설계행렬·추정값·표준오차 계산은 기존 순서대로 수행한다. 4집단·6시점에서는 보정평균용 적합이 24회에서 6회로 줄어든다.

관측치 2,000개·집단 4개·시점 6개·연속 공변량 1개의 전체 분석 준비 시간:

| 버전 | 최초 3회(초) | 반복 3회(초) | 최초 중앙값 | 반복 중앙값 |
|---|---|---|---:|---:|
| 변경 전 | 0.85, 0.86, 0.82 | 0.51, 0.55, 0.44 | 0.85 | 0.51 |
| 변경 후 | 0.78, 0.91, 0.78 | 0.36, 0.47, 0.41 | 0.78 | 0.41 |

반복 분석 중앙값은 **약 19.6% 감소**했다. 최초 중앙값은 약 8.2% 감소했지만 두 번째 실행에서는 변경 후가 더 느렸다. 작은 시간 구간과 3회 측정의 변동을 고려해야 하며 모든 데이터에서 같은 개선율을 보장하지 않는다.

독립 프로세스 3쌍을 순차 실행했고 두 번째 쌍은 순서를 반대로 했다. 번들 R 4.5.3, 완전 자료 PP 경로, 가정 검사 비활성화, 사후 비교 활성화/Holm 설정이다. 시간은 분석 준비만 포함하며 HTML 생성·파일 변환·앱 시작은 제외한다. 최초 분석 후 HTML을 생성한 다음 반복 분석을 측정하는 흐름은 양쪽에서 동일하다.

## 구현과 동작 보존

- `R/analysis_mixed_rm_anova.R`: 기존 적합 코드를 `mixed_rm_adjusted_model`로 분리했다. `mixed_rm_adjusted_cell`은 기본적으로 직접 적합하며, 내부 호출에서는 준비된 모형을 선택적으로 받는다.
- 모형 목록은 요약표 함수 호출 안에서만 사용한다. 다른 분석이나 세션과 공유하지 않는다.
- 모형 적합 중 경고·메시지·난수 상태 변경이 있으면 재사용하지 않는다. 오류도 저장하지 않아 기존 셀별 오류 처리와 조건 발생 횟수를 유지한다.
- 수치 알고리즘, 계수·공분산 계산, 집단별 설계행렬과 평균/SE 산식, 표·주석 구성은 변경하지 않았다.
- 시점 수만큼 모형을 일시적으로 유지한다. 실제 프로세스 최대 메모리는 이번에 측정하지 않았으므로 메모리 절감은 주장하지 않는다.

3. **측정 결과**: 3쌍의 최초/반복 및 변경 전후 전체 결과와 HTML 동일성 확인.

5. **종합 회귀 검증**: 기존 `scripts/validate_mixed_rm_anova.R` 통과. 일부 기존 혼합모형 사례에서 singular-fit 알림은 발생했으며 검증은 완료됐다.
