# 프로그램 전체 다국어 점검 — 3일 누적 작업 반영

> 후속 갱신: 아래 점검 당시 확인한 활성 화면의 영어 문구 5개는 `MULTILINGUAL_PROGRAM_UI_FIXES_20260918.md` 작업에서 보완했다. 73개 화면 × 8언어 재검사를 통과했고 해당 5개 문구의 잔존 조합은 0개다. 아래 내용은 발견 당시의 근거를 보존하며, `tmp/multilingual-program-audit`의 화면·후보 집계 파일은 후속 검사 결과로 갱신됐다.

> 추가 분류: 남은 화면 원문 반환 후보 47개는 사전 번역값 22개·제목 함수 번역값 20개·통계 메뉴 이름 5개로 확인했다. 이 후보에서는 새 누락이 없었다. 측정불변성 부록 제목 14개 및 실제 CFA score 진단의 8언어 재검증도 통과했다. 상세 근거는 `MULTILINGUAL_PANEL_CANDIDATE_REVIEW_20260918.md`에 기록했다.

## 결론

9월 16~18일의 기존 작업을 제외하거나 처음부터 다시 집계하지 않았다. 해당 날짜가 파일명에 있는 다국어 Markdown 보고서 416개를 근거 목록으로 수집했다(16일 104개, 17일 274개, 18일 38개). 보고서에는 상태 요약·중복 검증·후속 수정도 포함되므로 416개 기능 완료로 해석하지 않는다. 전체 문서를 새로 실행 검증한 것이 아니라 누적 근거를 보존하고 최신 소스에서 대표 검사를 다시 실행했다.

현재 프로그램은 주요 번역 체계·화면 생성·사용자 데이터 보존·대표 저장 검증을 통과했지만 전체 번역 완료 상태는 아니다. 현재 메뉴 화면에서 5개 영어 잔존 문구를 추가 확인했다. 사용자 지시에 따라 기존 매개·조절효과 패널은 향후 사용하지 않는 화면으로 점검·번역 대상에서 제외했다. 사용자 모형 캔버스와 복합표본 사용자 모형은 계속 포함한다. 전체 분기·모든 실제 사용자 자료의 검증을 완료한 것은 아니므로 전체 완료율을 제시하지 않는다.

## 전체 화면 범위

`R/app_server.R`의 lazy_ui 등록을 파싱해 실행 함수 자체를 8개 언어로 호출했다. 앱 버전·기본 세션 값·추천 기본값을 제공했으며 실제 Shiny 서버 이벤트나 저장된 사용자 세션을 재현한 검사는 아니다. 각 결과를 HTML로 렌더링하고 오류와 비한국어 화면의 한국어 표제 후보를 수집했다.

| 등록 영역 | 패널 수 | 8언어 생성 검사 |
|---|---:|---:|
| 분석 | 38 | 304 |
| 데이터 편집 | 13 | 104 |
| 계산기 | 6 | 48 |
| 안내·설정·정보 | 11 | 88 |
| 도움 요청 | 4 | 32 |
| 잠재모형 모듈 | 1 | 8 |
| 합계 | 73 | 584 |

최초 74개 등록 패널을 확인한 뒤 기존 매개·조절효과 패널을 제외해 73개로 범위를 조정했다. 남은 584개 조합 모두 생성 오류 없이 통과했다. 검사한 label/button/heading/option 노드에서 비한국어 화면의 한국어 후보는 0개였다. 이는 영어 잔존 없음, 도움말 본문 전체 번역, 모든 메뉴 클릭 통과를 의미하지 않는다. 38개 분석 등록에는 조건부 패널이 포함되므로 기존 ‘37개 분석 화면’과 같은 분모가 아니다.

## 최신 실행 검사

- 대표 R 검사 30개를 실행했다. 최초 29개 통과, 1개 실패였으며 원인을 확인해 검사 절차를 갱신한 후 해당 검사도 통과했다.
- 포함 영역: 공통 사전·번역 계약·전체 앱 UI 생성, 16개 부록 번역 함수, 대표 분석 결과, 설정·파일 창 인자, 이력, 자료 병합·ID 집계·와이드→롱, 현재·누적 저장 오류, 그림 오류, 구조모형 옵션·툴바·다집단, GLM·상관·요인·복합표본·생존·종단.
- 16개 부록 번역 함수 × 8개 언어에서 번역 단어와 충돌하는 사용자 변수명·범주 및 수치를 보존했다. 8개 대표 분석 결과 렌더러 × 8개 언어에서 영어 본표 내용과 부록 언어 메타데이터를 확인했다.
- Chrome 브라우저 검사: 비한국어 7개 언어에서 상단 메뉴·범주 라벨 언어 보존, 일본어 캔버스 속성 및 앵커 조작부 겹침 검사 통과. 이 검사는 생성한 로컬 HTML과 실제 JS를 사용하며 전체 앱의 로그인·메뉴 클릭 왕복 검사는 아니다.
- 공통 결과표의 일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 및 PDF 텍스트·표지 검증 통과. 최근 각 번역 묶음의 한국어·일본어 저장 근거도 기존 기록으로 유지했다. 이번 한 번에 모든 분석의 5형식을 다시 저장한 것은 아니다.

### 최초 실패의 원인

`validate_collection_export_errors_i18n.R`는 Word 버튼 클릭 직후 파일 저장 오류가 발생한다고 가정했다. 현재 구현은 내용 선택 모달 → 확인 → 문서 캐시 저장 순서다. 검사에 확인 이벤트 및 현재 캐시 저장 경계의 오류 주입을 추가했다. 제품 동작은 수정하지 않았다. 수정 후 8개 언어의 9개 오류 사례 × 4개 형식 알림과 원본 스냅샷 보존 검사가 통과했다. 최초 실패 로그를 삭제하지 않았다.

## 확인된 잔존 영어

원문 반환을 추적한 뒤 실제 HTML 텍스트에 남는지 대조했다. 동일 철자를 사용하는 정상 번역과 통계 약어를 수동으로 구분했다.

| 화면 | 문구 | 분류 |
|---|---|---|
| ID 집계 | Create data | 현재 메뉴의 누락 |
| 변수 변환 | ID conditional statistic | 현재 메뉴의 누락 |
| 변수 변환 | Number of missing values | 현재 메뉴의 누락 |
| 변수 변환 | Complete case flag | 현재 메뉴의 누락 |
| 복합표본 사용자 모형 | Draw paths on the shared canvas. The design variables set under Complex Samples are applied automatically. | 현재 메뉴의 누락 |

각 문구가 일본어·중국어·스페인어·프랑스어·독일어·베트남어에서 남아 총 30개 문구/언어 조합을 확인했다. 제외한 기존 매개·조절 패널의 안내 1개는 미완료 목록에 포함하지 않는다. 전체 미번역 건수로 집계하지 않는다. 이번 요청은 점검이므로 이 문구를 번역하거나 제품 소스를 수정하지 않았다.

## 정적 감사와 남은 점검

최근 정적 감사는 R 및 모듈 333개 파일, 문구 출현 4,220건, 고유 검토 후보 582개다. 이는 제외 결정 전 원시 집계로, 기존 매개·조절 코드도 포함하므로 현재 범위의 잔여 건수로 사용하지 않는다. 재개 시 645개보다 감소했지만 본표 영어 유지·미사용 분기·다른 번역 경로를 포함한다. 이 감사는 모든 JS·HTML 문자열 및 모든 동적 조합을 포괄하지 않는다.

후속 우선순위:

1. 현재 메뉴의 확인된 누락 5개를 보완한다. 기존 매개·조절효과 패널은 처리 대상에서 제외한다.
2. 구조모형 측정불변성·생존분석·사용자 모형 캔버스 등 정적 후보가 많은 영역을 실제 결과 경로로 대조한다. 공유 함수는 실제 사용 경로를 확인하며 기존 매개·조절 기능 전체를 이유로 일괄 제외하지 않는다.
3. 이번 기본 상태 렌더링을 넘어 저장된 입력·자료 교체·모든 언어 왕복·분할·오류 조건을 전체 메뉴 체크리스트로 확장한다.
4. 네이티브 파일 창은 인자 검사와 실제 OS 표시·클릭을 구분한다. 후자는 이번 실행 범위가 아니다.
5. Word·한컴 등 실제 편집기 시각 검수, 원어민 검수, 설치본 검증은 별도 남아 있다. 설치파일은 생성하지 않았다.
