# 종단 가중치 상태 값 — 2026-09-17

가중치 요약 표의 값 열까지 검사 범위를 넓혀 평균 1 정규화 상태, IPW 양성성·가중치 안정성 검토 안내, 1–99 및 5–95백분위 절단 범위의 네 문구를 8언어로 연결했다. 기존 한국어와 다른 언어의 번역 누락을 실제 반환 표로 확인한 뒤 보완했다.

`validate_longitudinal_weight_summary_i18n.R`는 5개 가중치 설정 × 8언어의 실제 요약 표에서 항목명뿐 아니라 가중치 유형·절단·정규화·IPW 진단 설명을 확인한다. 종단 가중치는 5–95%, 나머지는 1–99% 절단으로 실행하며 세 절단 선택값(없음 포함)의 비영어 표시도 별도로 검사한다. 수치 문자열, 사용자 변수명 `Warning`, 원본 결과 보존 검사는 유지한다.

기존 MI/IPW 오류 70개와 대체 처리 16개 검사를 포함한 `validate_longitudinal_error_exports.R`로 한국어·일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel 저장을 검사한다. PDF의 캡처 텍스트 검사는 `validate_longitudinal_error_pdf.py`를 사용한다. 산출물: `tmp/longitudinal-error-exports`.

계산 코드는 변경하지 않았다. 본표 영어 원칙을 유지하며 전체 브라우저·모형 조합·페이지별 시각 검토를 완료한 것은 아니다. 메타분석은 제외하고 설치본은 만들지 않았다.

위 검사와 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 캡처 텍스트도 통과했으며 각 언어 현재 19쪽, 누적 37쪽이다. 변경 파일의 `git diff --check`도 통과했다.
