# Fine–Gray 수렴·정보행렬 경고

수렴 점수 기준, 정보행렬 계수 부족/조건수, 공분산 및 표준오차 오류의 근거·안내
8개 항목을 6개 추가 언어로 보완했다. 점수 기준 문장은 두 숫자를 보존하여 번역한다.
기존 계산, 한국어/영어 및 경고 발생 조건은 유지했다.

## 검증

- `validate_fine_gray_optimizer_i18n.R`: 실제 경쟁위험 결과에 진단 메타데이터를 넣어
  정상, 점수 기준 경계, 계수 부족, 조건수 30, 공분산 오류, 표준오차 오류의
  6가지 상태를 8개 언어로 검사했다. 각 실패 모형을 직접 적합한 검사는 아니다.
- 경고 선택·수치 표시, 실제 영어 CIF 본 표 유지 확인.
- Fine–Gray 공선성 회귀 검사 통과.
- 일본어 현재 5개 / 누적 6개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. Fine–Gray 잔차·검열분포 경고는 추가 점검 대상이다.
