# HTMT 상세 보조표 다국어 점검

2026-09-17

## 수정

- 번호가 있는/없는 상세표 제목, 부트스트랩 횟수·seed가 포함된 제목, 일반 해설 및 BCa/순서형 조건부 설명을 UI 언어로 표시한다.
- 판정·계산 불가 사유 4종·부트스트랩 상태·CI 방법·상한 판단 셀을 명시적으로 번역하고, 사용자 요인 이름은 보호한다.
- 계산 결과의 `Factor1/Factor2`와 표시 쪽의 `Factor 1/Factor 2` 불일치로 빠지던 두 요인 열을 복원했다. 부트스트랩 표에도 동일한 사용자 라벨을 적용한다. 라벨이 다른 요인 원래 이름과 같은 경우 중복 변환하지 않는다.
- 문장 결합 대신 완성된 번역 문장과 조건부 문단을 사용한다. 통계 계산과 HTMT 본표의 영어 출력은 유지한다.
- 공통 키 정규화에서 β가 제거되어 일반 `95% CI` 열에 β가 붙던 충돌을 수정했다. 고차요인 β 구간은 표시 단계에서 기호를 붙이고 공통 CI 번역은 기호 없이 유지한다.

## 검증

`scripts/validate_htmt_details_i18n.R`는 기존 7개 상태 × 8개 언어 검사를 포함한다. 실제 lavaan 적합의 HTMT 점추정과 부트스트랩 표시 fixture로 제목·설명·표 열·수치·사용자 라벨 보존 및 언어별 본표 HTML 동일성을 검사했다. 부트스트랩 순서형/BCa 설명은 메타데이터 fixture이며 실제 순서형 BCa 재표집 검증은 아니다. 계산 불가 사유 4종도 표시 fixture로 검사했다.

고차요인 표의 8개 언어 검사를 다시 실행했다. 검증 로그와 산출물은 `tmp/htmt-details-*`, `tmp/higher-display-*`에 저장한다. 설치본은 생성하지 않았다.

공통 다국어 커버리지 검사 통과. HTMT 상세표는 일본어 현재 결과 7개 표/누적 8개 표, 고차요인 표는 현재 7개/누적 9개 표의 HTML/PDF/Word/HWPX/Excel 내보내기 내용 검사를 통과했다. 양쪽 모두 실제 PDF 텍스트, HTML/Word 표 순서 및 Excel 시트 수를 재확인했다.

범위는 일차요인 HTMT 상세 렌더러다. 별도 고차요인 HTMT 렌더러와 전체 분석의 모든 분기 완료를 의미하지 않는다.
