# 원인별 Cox 잔차·영향력 진단 다국어 검증

## 변경

- 일본어·중국어·스페인어·프랑스어·독일어·베트남어 번역표에 제목 3개와 설명 2개를 추가했다.
- 대상: 원인별 잔차 분포, 연속 공변량 함수형태 검토, 영향력 검토.
- Martingale 잔차 평활선의 해석과 표준화 DFBETAS의 민감도 검토 설명도 UI 언어를 따른다.
- 기존 영어·한국어 문구와 분석 계산은 변경하지 않았다.

## 검증

`scripts/validate_cause_specific_residual_panel_i18n.R`는 생존분석 fixture로 경쟁위험 모형을 실제 적합하고 전체 결과 패널을 렌더링한다.

- 8개 언어에서 해당 제목과 설명의 표시를 확인했다.
- 잔차 요약 및 영향력 수치의 언어 간 동일성을 확인했다.
- 사용자 변수명 `Review`, `사용자 <&> %s` 보존을 확인했다.
- 원인별 회귀계수 본 표가 영어로 동일하게 유지됨을 확인했다.
- 일본어 패널의 변경 구간을 캡처하여 현재 2개 표, 누적 4개 표를 HTML/PDF/Word/HWPX/Excel로 저장하고 내용·순서를 검증했다. PDF 표지와 본문 검사도 통과했다.
- 저장은 캡처한 결과를 사용하며 분석을 다시 실행하지 않았다.

산출물: `tmp/cause-specific-residual-panel-i18n/`.

이번 저장 검증은 변경된 보조표·제목·설명 구간에 한정하며, 변경하지 않은 잔차 그래프 위젯은 제외했다. 전체 분석 기능의 다국어 검증 완료를 의미하지 않는다. 설치본은 생성하지 않았다.
