# Fine–Gray 공선성 경고

VIF 중간/높음, 비유한 VIF, 높은 조건수 경고의 근거·안내 7개 항목을 6개 추가 언어로
번역했다. 한국어/영어, 수치 정밀도와 경고 조건은 변경하지 않았다.

## 검증

- `validate_fine_gray_collinearity_i18n.R`: 실제 경쟁위험 결과에 Fine–Gray 진단
  메타데이터를 넣어 VIF 4.99/5/10/Inf와 조건수 29.99/30을 8개 언어로 검사했다.
  각 조건의 Fine–Gray 모형을 새로 적합한 검사는 아니다.
- 경고 선택, 수치 표시 및 실제 영어 CIF 본 표 유지 확인.
- 원인별 Cox 공선성 회귀 검사 통과.
- 일본어 현재 4개 / 누적 5개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. Fine–Gray의 수렴·정보행렬·잔차 관련 경고는 점검이 남아 있다.
