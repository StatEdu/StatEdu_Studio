# GLM 보고 점검표 모형 설명·복합 요약

2026-09-16. 설치본은 만들지 않았다.

## 변경

- 보고 점검표가 모형 설명의 원문과 구성 정보를 유지하도록 했다. 번역 시 종속변수와 독립변수 라벨을 원본 그대로 삽입한다. 사용자 수정 문장은 구성 정보로 덮어쓰지 않는다.
- 6개 언어에 분석 행 수 복합 요약 2종, 분포/링크 복합 요약, 역수 링크 명칭을 추가했다.
- 모형 전체 설명은 기존 Methods 문장 번역을 재사용한다. 숫자·본표·추정 알고리즘을 변경하지 않는다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 검사. 실제 3개 분석의 보고 점검표 모형 설명이 영어로 남지 않는지, `Model-based` 사용자 라벨과 수정한 설명이 보존되는지 확인했다.
- 실제 보조표에서 `was fitted for dependent variable` 및 `; analyzed … of …` 형식의 영어 잔존을 검사한다. 기존 본표 영어·옵션 값 검사도 유지한다.
- `scripts/validate_i18n_contract.R`: 통과.
- 합성 count 자료의 기존 음이항 반복 한도 경고가 발생했지만 출력 검사는 통과했다.
- 실제 3개 분석의 일본어 보고 점검표도 저장 검증 fixture에 포함했다.
- 8개 언어 검사 통과. 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교 및 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.
- 일본어 실제 출력의 영문 연속 단어 후보를 재추출했다. 이번에 대상으로 삼은 모형 설명과 복합 요약의 영어 잔존은 해소되었고, 후보에는 사용자 라벨 및 통계 명칭이 포함된 번역 문장이 남았다. 짧은 문자열이나 실행하지 않은 분기까지 완료했다는 뜻은 아니다.

## 남은 범위

구성 정보가 없는 과거 저장 결과에 동일한 번역이 적용된다고 보장하지 않는다. 다른 분석 화면 및 GLM의 아직 실행하지 않은 옵션/오류 분기는 추가 점검 대상이다. 저장 시 재분석하지 않는다.
