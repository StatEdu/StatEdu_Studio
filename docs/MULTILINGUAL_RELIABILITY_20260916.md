# 신뢰도 연속형 문항 경로 다국어 보완

문항 분석 제목, 문항 제거 시 alpha/omega 및 문항-총점 상관 열 제목, 정규성·문항 제거·추정 불가 설명과 기호 정의 등 12개 문구를 8개 언어에 등록했다. 한국어 외 UI에서 열 제목과 설명을 사전으로 번역하도록 연결했다. 한국어의 기존 전용 표기와 영어 본표는 유지한다.

## 검증

- `scripts/validate_reliability_i18n.R`: 실제 100행·연속형 4문항으로 alpha/omega, 문항 제거, 문항-총점 상관, 정규성 옵션을 실행했다. 8개 언어에서 본표 내용 영어 동일성, 문항 분석 보조표 언어, 문항명 및 수치 보존을 확인했다. 추가 6개 언어에서는 등록한 12개 문구의 실제 렌더링도 모두 검사했다.
- 사용자 문항명 `Normality`, `Yes`, `Status`, `사용자 문항`을 보존했다.
- 기존 `validate_reliability.R`, `validate_i18n_contract.R` 통과.
- 일본어 실제 결과 `tmp/reliability-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성 및 실제 PDF 텍스트 검사 통과.

## 남은 범위

순서형 문항, KR-20, 하위요인 통합, omega를 끈 문항 제거 설명, 설정·오류·언어 왕복은 추가 확인 대상이다. 대표 결과 근거는 15개 화면, 전용 결과 검증 공백은 15개 화면으로 갱신했다. 전체 완료 판정은 하지 않았으며 설치본은 만들지 않았다.
