## 후보와 검증

이전 순위 기반 후보와 달리 원자료의 `factor(x, exclude = c(NA, NaN))` 변환을 유지했다. 지역 복사한 `kruskal.test.default`에서 `TIES <- table(x)` 문장 하나만 다음으로 대체했다.

```r
bins <- factor(x, exclude = c(NA, NaN))
TIES <- tabulate(bins, nbins = nlevels(bins))
```

앱의 본검정과 epsilon squared 계산에만 후보를 연결했다. formula 함수도 지역 복사해 내부 숫자 검정을 후보로 연결했으며, stats 네임스페이스는 수정하지 않았다. 이는 검토용 코드로, 제품용 버전 검사나 범용 S3 대체 함수를 구현한 것은 아니다.

2/4집단 × 표본 크기 0/1/4/20/100/20,000 × 일반·동점·상수·가까운 실수·큰 크기의 가까운 실수·결측·무한대의 84개 조건을 검증했다. 원시 htest, 경고/메시지/오류, stdout, 난수 상태를 정규화나 허용오차 없이 `identical(..., num.eq=FALSE)`로 비교했다. 오름차순 빈도 값과 원시 `sum(TIES^3 - TIES)`도 모두 일치했다. 앞서 문제가 됐던 인접 실수의 기존 동점 처리도 유지됐다.
