# θ 재사용 적용 조건 밖의 성능 확인 — 2026-09-14

직전 제품 연결의 미측정 범위인 작은 자료와 고유 카운트 자료를 확인했다. 이번에는 제품 코드를 변경하지 않았다.

## 전체 분석 시간

| 자료 | 기존 3회 평균 시간(ms/분석) | 제품 연결 3회 평균 시간(ms/분석) | 각 프로세스 평균의 중앙값 |
|---|---|---|---|
| 100행 과산포 | 20.5 / 19.5 / 19.0 | 21.5 / 21.0 / 21.5 | 19.5 → 21.5 |
| 999행 과산포 | 34.5 / 32.0 / 32.5 | 36.5 / 34.5 / 34.0 | 32.5 → 34.5 |
| 5,000행, 모든 카운트 고유 | 76.7 / 83.3 / 76.7 | 83.3 / 76.7 / 76.7 | 76.7 → 76.7 |

번들 R 4.5.3, 새 프로세스 3개를 순차 실행했으며 두 번째는 비교 순서를 뒤집었다. 각 조건 양쪽 준비 실행 후 GC를 수행했다. 작은 자료는 20회, 5,000행은 3회 전체 분석을 반복해 경과 시간을 반복 수로 나눴다. 표의 세 값은 독립된 세 프로세스에서 구한 평균이다. 입력 생성과 모듈 로딩은 제외하고, 적합·강건 표준오차·결과 준비·비교용 스냅샷 구성은 포함한다. 화면 렌더링·저장·메모리는 측정하지 않았다.

시드 915의 정규 예측변수 6개, VIF 끔, count 자동 선택을 사용했다. 작은 자료는 mu=exp(0.2*x1-0.1*x2), size=0.5인 음이항 표본이다. 고유 카운트는 1:5000의 무작위 순열에 10을 곱했다. 모든 조건에서 음이항 모형이 선택됐다. 기준은 `output/theta-integration-20260914/baseline.R`의 θ 최적화 전 일반화 적합 함수이며 나머지는 현재 프로그램을 사용했다.

## 동일성 및 판단

모든 조건·프로세스의 준비 실행과 측정 마지막 결과가 기준과 `identical(..., num.eq=FALSE)`로 일치했다. 비교 범위는 모형 객체를 제외한 반환 내용(공식 환경만 통일), 계수·적합값·잔차·deviance·weights·theta·SE.theta, 경고/메시지 문자열과 난수 상태다. 모형의 모든 내부 환경이나 조건 객체 자체까지 비교했다는 뜻은 아니다. 반복 측정의 중간 반환값은 개별 비교하지 않았다.

작은 자료에서 약 2ms의 중앙값 증가가 확인됐다(100행 약 10%, 999행 약 6%). 따라서 모든 입력에서 빨라졌다고 말할 수 없다. 고유 카운트 자료에서는 일관된 차이가 없었다. 이번 전체 분석 측정만으로 증가분을 서명 확인·함수 생성·적용 조건 확인 각각에 배분할 수는 없다.

현재 측정에서 절대 증가량은 작다. 별도 입력 우회 분기나 함수 캐시는 추가하지 않고 기존 호환성 확인을 유지한다. 작은 자료를 대량 반복하는 용도에서는 이 비용을 고려해야 한다. 50,000행 중복 카운트에서 확인한 개선은 직전 제품 연결 보고서를 참조한다.

재현 코드·시간 CSV·기준 결과 RDS는 `output/theta-fallback-review-20260914/`에 보관했다. 제품 코드와 출력 형식 변경이 없으므로 기존 전체 검증 및 문서 변환을 재실행하지 않았으며 설치 파일도 재빌드하지 않았다.
