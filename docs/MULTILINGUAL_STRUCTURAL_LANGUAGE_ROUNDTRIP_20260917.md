# 구조방정식 언어 왕복 재검증

## 실제 개발 앱

- `validate_structural_options_browser.cjs`를 현재 소스로 실행했다.
- 한국어에서 설정한 뒤 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 순으로 전환했다.
- CFA·SEM·PLS 각각의 추정법, 부트스트랩 설정, 선택형/체크박스 옵션, 사용자 메모를 검사했다. 8개 언어 × 3개 화면, 24개 검사 통과.
- 개발용 격리 프로필과 localhost 앱을 사용했으며 설치본과 실제 사용자 프로필은 변경하지 않았다.
- 로그: `tmp/structural-options-browser-20260917.log`.

## 결과 렌더링 검증 화면

- `scripts/fixtures/structural_result_language_app.R`에서 160행 데이터로 실제 CFA·SEM·PLS를 적합하고 제품의 본표·보고 맥락·품질·측정 보조표 렌더러를 호출한다.
- `validate_structural_result_language_browser.cjs`는 같은 브라우저 세션에서 8개 언어를 순환한다. 영어 본표의 텍스트 동일성, 보조표의 언어 속성, 보고 체크리스트 제목, 사용자 라벨·집단 이름 보존을 검사했다. 24개 검사 통과.
- 한국어 복귀 시 각 분석의 전체 결과 텍스트가 최초 한국어 화면과 동일했다. 브라우저 JavaScript 오류도 없었다.
- 로그: `tmp/structural-result-language-browser-20260917.log`.

## 한계 및 변경 범위

이번 턴은 검증 코드와 기록 추가이며 제품 출력 코드는 변경하지 않았다. 앞서 수정한 출력의 5개 저장 형식 검증 결과는 각 변경 문서에 기록되어 있다.

결과 화면 검증은 실제 적합 결과를 사용하는 별도 Shiny fixture다. 제품 화면에서 캔버스를 편집하고 분석 버튼을 눌러 결과를 만드는 전체 흐름이나, 케이스 선택·파일 분할을 결합한 모든 분기를 검증한 것은 아니다. 이번 통과를 전체 다국어 완료로 간주하지 않는다. 설치본은 만들지 않았다.
