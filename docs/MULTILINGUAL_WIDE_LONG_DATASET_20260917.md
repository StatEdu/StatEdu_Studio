# 와이드→롱 자료 교체 검사 — 2026-09-17

## 수정

같은 변수명을 가진 새 자료로 교체해도 이전 변환 그룹이 남는 문제를 실제 서버 검사에서 재현했다. 데이터와 원본 파일 정보의 변경을 감지해 선택 열·설정 그룹·미리보기·상태 안내를 초기화한다. 언어만 변경하면 해당 상태를 유지한다.

와이드→롱 명령이 직접 만든 결과를 현재 자료로 연결한 경우에는 해당 자료 상태를 기록해, 방금 만든 결과와 완료 안내가 다시 초기화되지 않도록 했다. 외부 자료 교체와 자체 결과 연결을 구분한다.

## 검증

- `validate_wide_long_dataset_change.R`: 8언어에서 같은 이름/변수명의 값 변경, 값은 같고 파일 경로만 변경한 경우의 그룹·안내 초기화를 확인했다. 실제 반응형 자료를 바꾸는 교체 콜백으로 자체 변환 결과의 완료 안내 유지도 검사했다. 저장 대화상자는 테스트 함수로 대체했다.
- `validate_wide_long_dataset_browser.cjs`: 격리된 전체 앱에서 파일명·열 이름이 같은 합성 CSV를 매 언어마다 새 값으로 교체한다. 언어 전환 시 그룹 보존, 업로드 후 그룹/미리보기/안내 제거, 재설정 후 새 자료의 정확한 변환값을 검사한다.
- 기존 상태 안내·오류·변환/저장 연결 검사도 통과했다.

로그: `tmp/wide-long-dataset-change.log`, `tmp/wide-long-dataset-browser.log`, `tmp/wide-long-status-i18n.log`, `tmp/wide-long-errors-i18n.log`, `tmp/wide-long-regression.log`.

브라우저 검사도 8언어 모두 통과했고 pageerror는 없었다.

## 범위

제품 변경은 데이터 편집 상태 관리이며 분석 결과/내보내기 경로는 변경하지 않았다. 설치본 생성 및 설치 앱 변경 없음. 네이티브 저장 창, 포인터 드래그 및 같은 이름의 그룹 덮어쓰기의 종합 브라우저 검증은 별도 범위다.
