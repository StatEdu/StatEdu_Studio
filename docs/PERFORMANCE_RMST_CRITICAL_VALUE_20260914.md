# RMST 신뢰구간 임계값 재사용 — 2026-09-14

`survival_rmst_contrasts`에서 반복 호출하던 `stats::qnorm(.975)`를 비교 시작 전에 한 번 계산하고 재사용하도록 적용했다. 반올림한 상수를 넣지 않고 기존 함수의 반환값을 그대로 사용한다. 차이·비율 신뢰구간의 곱셈·덧셈·로그·지수 연산 순서와 분기, 표 구조 및 Holm 보정은 유지했다.

이전 RMST 결과표 일괄 조립 변경까지 적용된 소스를 기준으로 비교했다. 정상적인 100집단·4,950쌍 자료에서 임계값 계산을 19,800회에서 1회로 줄인다. 빈 입력/단일 집단의 기존 조기 반환은 유지한다.

## 시간

번들 R 4.5.3, 앱 설정 적용, 자동 설치 비활성화. 새 프로세스에서 변경 전후 3쌍을 순차 실행했고 두 번째 쌍은 순서를 반대로 했다. 각 프로세스는 3집단 다음 100집단을 실행했다. 동일한 전역 환경에 연결한 RMST 비교 함수의 전체 호출을 측정했으며, 검증은 시간 측정 후 실행했다.

| 집단 수 | 변경 전 3회(초) | 변경 후 3회(초) | 중앙값 전→후 |
|---|---|---|---|
| 3 | 0.02 / 0.02 / 0.03 | 0.03 / 0.02 / 0.01 | 0.02→0.02 |
| 100 | 0.11 / 0.10 / 0.11 | 0.10 / 0.08 / 0.08 | 0.11→0.08 |

큰 비교에서 약 27%, 절대 0.03초 감소했다. 표 생성 일괄 처리에 비해 작은 추가 개선이다. 적은 집단에서는 개선이 없었다. 생존 모형 적합·앱 로딩·화면 렌더링·내보내기 시간은 포함하지 않는다. 짧은 실행이므로 다른 데이터나 환경에서 같은 감소율을 보장하지 않는다.

- 자료형·누락 열·0/NaN SE·진단 클래스·중복 집단명 등 추가 24조건 통과.
- 전체 KM/RMST 분석 3건의 전체 결과·진단·난수 상태 및 HTML/의존성 정확 일치.
- 시간 측정 6쌍의 전체 결과·진단·난수 상태 정확 일치.
