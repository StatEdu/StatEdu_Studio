# 와이드→롱 입력 상태·동적 안내 — 2026-09-17

## 수정

브라우저에서 언어 변경 후 미적용 변수명이 이전 값으로 돌아가는 문제를 재현했다. 설정 입력을 세션에 보관하고, 화면을 다시 만들 때 해당 값을 사용하도록 수정했다. 직접 입력한 반복 횟수와 선택한 옵션 탭도 복원한다. 일시적인 목록 선택은 기존 방식대로 격리해 읽는다.

그룹 설정/수정/제거, 미리보기, 저장/임시 연결 상태를 메시지 키와 삽입 값으로 보관하고 표시 시 현재 언어를 적용한다. 사용자 그룹 이름과 경로는 번역하지 않는다. 미리보기 DT에 공통 다국어 컨트롤을 적용했다. 이 표는 기존대로 페이지 이동을 사용하지 않는다.

## 검증

- `validate_wide_long_status_i18n.R`: 그룹 설정·미리보기·저장 연결·임시 연결의 8언어 표시를 실제 서버에서 확인. 언어만 바꿀 때 데이터 교체 재호출 없음. 저장 함수는 테스트에서 대체했으며 실제 OS 창을 열거나 파일을 저장하지 않았다.
- `validate_wide_long_browser.cjs`: 합성 CSV로 그룹을 만든 뒤 8언어를 왕복한다. 미적용 변수명·지시값·그룹/시점 이름·반복 횟수·옵션 탭·고정 변수 선택·설정한 그룹 유지, 미리보기 행/수치/사용자 지시값과 상태·검색 문구를 검사한다. 브라우저 실행 전에 상태 검사 스크립트로 기본 영어/한국어를 포함한 예상 문구를 생성한다.
- `validate_wide_long_errors_i18n.R`, `validate_data_editor_wide_long.R`: 오류 및 기존 변환/저장 연결 회귀 검사 통과. 과거 소스 문자열 모양만 검사하던 취소 안내 단언은 실제 서버 상태 검사로 대체했다.

로그: `tmp/wide-long-status-i18n.log`, `tmp/wide-long-browser.log`, `tmp/wide-long-errors-i18n.log`, `tmp/wide-long-regression.log`.

최종 브라우저 8언어 검사 모두 통과했고 pageerror는 없었다.

## 남은 범위

동일 대상의 다집단·다시점 실제 변환, 그룹 여러 개의 편집/삭제/순서 변경, 자료 교체와 네이티브 저장 창의 종합 브라우저 검증은 별도 범위다. 이번 변경은 데이터 편집 UI이며 분석 출력/내보내기 경로를 변경하지 않았다. 설치본 생성 및 설치 앱 변경 없음.
