# 혼합 반복측정 ITT 안내 번역

## 변경

완전 사례 반복측정 ANOVA를 계산할 수 없고 ITT 혼합모형을 적합하는 실제 결과 경로에서 안내 6개가 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남는 것을 재현했다.

- 이용 가능 대상자 정의
- ITT에 사용한 장형 관측 결과 행 설명
- 완전 사례 ANOVA 결과 미생성 안내
- 선택 변수로 완전 사례 ANOVA 계산 불가 안내
- ITT의 이용 가능한 반복측정 기록 사용 설명
- 대상자 임의절편 혼합모형 적합 설명

8개 언어 사전에 반영했다. 기존 영어·한국어 표기와 계산·렌더링 코드는 유지했다. ITT 분석 대상이나 결측 처리 규칙을 변경한 작업은 아니다.

## 검증

`validate_mixed_rm_itt_guidance_i18n.R`는 40명·2집단·연속형 공변량·3시점 자료에서 각 대상자의 한 시점 값을 결측 처리한다. 완전 사례는 없고 관측 반복 기록은 80개다. 실제 ITT LMM 적합 성공, ANOVA 본표 미생성, 6개 안내의 실제 출현을 확인했다.

- 보완 전 6개 언어 사전 검사 실패, 보완 후 8개 언어 실제 패널 검사 통과.
- 영어 혼합모형 계수 본표의 언어 간 동일성 및 전체 결과 객체 보존 확인.
- 대상자 40명·반복 기록 80개 표시와 안내문과 같은 철자의 사용자 변수명 보존 확인.
- 기존 공변량·상호작용 안내 회귀 검사 통과.
- `validate_i18n_contract.R` 및 사전 변경 공백 검사 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 검사 및 PDF 캡처 텍스트 보존 검사 통과. 두 언어 모두 PDF 현재 6쪽·누적 10쪽.
- 일본어 PDF의 長가 추출 시 U+2ED1로 반환되어 초기 PDF 검사가 실패했다. Poppler로 현재 PDF 3·6쪽을 이미지화하여 글자가 정상 표시되는 것을 확인했다. PDF 검사기의 기존 문자 정규화에 U+2ED1→長만 추가했고 제품 출력은 변경하지 않았다.
- 저장 검증은 `validate_longitudinal_count_exports.R` 및 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이고 본문은 이번 ITT 결과 캡처다. 저장 단계에서 분석을 재실행하지 않았다. 산출물: `tmp/mixed-rm-itt-guidance-i18n/exports`.

## 남은 확인 대상

이번 PDF 검토에서 `At least three complete cases are required for mixed repeated-measures ANOVA.`, `Use the fitted LMM as the ITT result.`, 혼합모형 개요의 결합된 Gaussian·공변량×시점 설명이 일본어에서 영어로 남는 것도 확인했다. 이번 6개 고정 안내 보완과 별도로 다음 번역 대상으로 남긴다. ITT 전체 안내 번역 완료를 의미하지 않는다.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드 및 문서 앱별 수동 시각 검토는 수행하지 않았다.
