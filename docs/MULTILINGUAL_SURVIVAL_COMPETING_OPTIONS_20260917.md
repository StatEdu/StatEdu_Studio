# 경쟁위험 옵션 및 추가 설정 오류

경쟁위험 설정의 블록 제목·추정량·검열분포 층화·안내 등 11개 문구를 6개 추가 언어에 연결했다. 영어·한국어 선택 구조를 유지하고 내부 옵션 값은 변경하지 않았다.

기존 생존 설정 오류 24종 외에 `missing_columns`, `invalid_time_encoding`, `competing_event_requires_competing_risk`, `unsupported_other_state`를 추가했다. 변수 없음 메시지는 접두부만 번역하며 뒤의 변수명을 그대로 보존한다. 예상하지 못한 메시지 형식과 미등록 코드는 원문을 유지한다. 벡터 호출과 개별 호출에서 동일하게 처리한다.

검증:

- `validate_survival_competing_options_i18n.R`: 8언어 × 추정량 4종의 생성 HTML에서 컨트롤 ID·값·선택값·다중선택 속성·조건부 표시식을 영어 화면과 비교했다. 사용자 변수명 `Review`, `Normality`, `None`, `사용자 <&> %s`가 유지된다.
- 실제 사전검사로 변수 없음과 잘못된 시간 문자열 오류를 발생시켜 번역 및 변수명 보존을 확인했다. 추가 경쟁사건/다상태 오류 2종은 함수 문구 검사다.
- 기존 24종 오류의 8언어 검사도 재통과했다.

한계: 브라우저의 실제 조건부 표시·언어 왕복·설정 복원 동작은 이번에 검증하지 않았다. 모든 오류를 실제 자료로 발생시킨 것은 아니다. 분석 전 설정 UI 변경으로 본표·보조표·저장 산출물은 변경하지 않았고 내보내기를 새로 생성하지 않았다. 설치본도 만들지 않았다.
