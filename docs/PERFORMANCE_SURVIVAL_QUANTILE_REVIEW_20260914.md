# 보정 생존곡선 신뢰구간 분위수 계산 검토

2026-09-14. 신뢰구간 분위수 계산의 병목과 `apply()`를 열별 `vapply()`로 바꾸는 후보를 검토했다. 제품 코드는 변경하지 않았다.

## 실제 계산 구간

600/2,000건, 3집단, 부트스트랩 60회, 선택 시점 0·10·20으로 준비 실행 후 각 조건에서 3회 분석했다. 기존 `apply(values, 2, stats::quantile, probs=c(.025,.975), na.rm=TRUE, names=FALSE)`의 입력을 평가한 뒤 실행 시간을 측정했다. 집단 3개의 분위수 계산 합계다.

| 데이터 | 계측 포함 전체 중앙값 | 분위수 구간 중앙값 |
|---|---:|---:|
| 600건 | 0.89초 | 0.05초 |
| 2,000건 | 4.49초 | 0.17초 |

조건별 하나의 R 프로세스 안에서 측정한 값이며 이전 독립 프로세스 비교와 합산하지 않는다. 계측 전후 전체 결과·경고·메시지·표준출력·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 각 분석에서 부트스트랩 60회가 성공했다.

## 후보 실험

분위수의 기본 type 7, 확률 .025/.975, 결측 제거와 이름 설정을 유지하고 열 추출 반복만 바꿨다. 빈 행렬은 기존 경로를 사용하고 열 이름을 보존했다.

0/1/2/25/60/2,000행 × 0/1/3열 × 난수/결측/상수/행열 이름의 총 72개 경계 행렬에서 기존과 정확히 일치했다. 추가로 2,001열의 큰 행렬 2개에서도 일치했다.

고정 합성 행렬의 5회 호출을 버전별 3회 측정했고 두 번째 쌍의 순서는 반대로 했다. 각 열의 처음 5개 표본은 결측으로 두었다.

| 행 수(부트스트랩 표본 수에 대응) | 기존 5회 중앙값 | 후보 5회 중앙값 |
|---|---:|---:|
| 60 | 0.37초 | 0.39초 |
| 2,000 | 0.95초 | 0.75초 |

60행에서는 후보가 약 5% 느렸고 2,000행에서는 약 21% 빨랐다. 이는 분위수 함수만의 측정이다. 행 수 2,000의 미세 실험을 실제 부트스트랩 2,000회 전체 분석 개선율로 해석하지 않는다. 실제 기본 반복수의 전체 분석 시간이나 최고 메모리 사용량은 이번에 측정하지 않았다.

## 결정

모든 조건에서 유리하지 않고, 현재 측정 조건의 전체 시간에 대한 이득도 입증하지 못했으므로 적용하지 않는다. 큰 부트스트랩 행렬에서 조건부 사용을 검토할 수 있는 실험 후보로 보관한다. 조건부 적용 전에는 전체 분석에서의 실측과 추가 표본 규모 검증이 필요하다.
