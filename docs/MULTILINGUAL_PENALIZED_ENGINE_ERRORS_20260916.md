# 규제회귀 엔진 오류 안내 다국어 검증

## 변경

- `R/analysis_penalized.R`의 명시적인 오류 원문 14종을 `penalized_error_ui_text`에 연결했다. 계산 엔진의 오류와 계산 방식은 유지하고, 메뉴에서 사용자에게 표시할 때 UI 언어로 변환한다.
- 대상: 작업자 수, glmnet 설치/작업자 사용, 분석 방법, 교차검증 최소 사례 수, 학습 자료, 튜닝 실패, 중첩 CV 사례 수·예측·반복 횟수·지표, 선택 후 검정 방법·사례 수·반복 횟수.
- 영어·한국어·일본어·중국어·스페인어·프랑스어·독일어·베트남어 사전에 등록했다. 알 수 없는 외부 오류 상세는 그대로 보존한다.

## 검증

- `validate_penalized_engine_errors_i18n.R`: 엔진 AST에서 오류 14종을 추출하여 누락 여부와 8개 언어의 정확한 사전 연결을 검사했다. 작업자 수, 상수 결과변수, 중첩 CV 사례 수/반복 횟수, 선택 후 검정 방법/사례 수/반복 횟수의 7가지 오류는 실제 함수 호출로 발생시켰다. 통과.
- `validate_penalized_setup_i18n.R`: 실제 설정 화면의 8개 언어 렌더링, 컨트롤 값 보존, 기존 입력 오류 4종을 다시 검사했다. 통과.
- `validate_i18n_contract.R`: 통과.
- 이번 변경은 오류 알림에 한정된다. 분석 본표·보조표·저장 내용은 변경하지 않아 내보내기 재검증은 수행하지 않았다. 앞선 결과 변경의 내보내기 근거는 `MULTILINGUAL_PENALIZED_ADVANCED_20260916.md`에 있다.

## 남은 범위

14종 모두 실제 실패 상황을 재현한 것은 아니다. 패키지 부재, 작업자 실패, 튜닝/예측 실패 등은 원문 연결 검사까지이며, 외부 라이브러리의 모든 오류를 번역한다는 뜻은 아니다. 전체 화면 언어 왕복과 도표 점검도 남아 있다. 전체 다국어 작업의 완료 판정은 하지 않는다. 설치본은 만들지 않았다.
