# 복합표본 요약 후보의 제품 통합 비교 및 미반영 결정

2026-09-15. 이전의 제한 조건 후보에 메서드 변경 감지를 추가하고 실제 제품 함수 형태로 구현하여 비교했다. 최종적으로 후보를 제거하고 제품 소스를 작업 전 그대로 복원했다.

## 정확성 및 변경 감지

연구 후보는 R 4.5.3과 summary/residuals/vcov/coef의 svyglm 메서드 본문 해시 및 namespace 환경을 확인했다. 기본 Gaussian 함수도 실제 자유 심벌 바인딩을 검사했다. 메서드 본문 변경뿐 아니라 동일한 본문의 환경 변경도 기존 summary 경로로 복귀했다. survey 전체 내부 함수의 모든 변경을 감지하는 장치는 아니다.

제품 형태의 후보에서 21개 검사 조건이 원시 계수 표, 조건 클래스·내용·순서, 표준 출력, 최종 RNG의 `identical(..., num.eq=FALSE)` 비교를 통과했다. Gaussian/하위모집단/자유도 0·음수/메서드 복원은 빠른 경로, 다른 분포·복제 가중치·결측·na.exclude·FPC·alias·단일 PSU 정책·사용자 함수 및 메서드 변경은 기존 경로였다. 전체 내부 fit 객체 비교는 아니다.

실제 앱 함수의 전체 분석 비교는 이전과 같은 완전자료 10,000행, 10층, 200 PSU, 불균등 가중치, 예측변수 4개와 Gaussian 종속변수 6개 조건이다. 원시 표에 추가하여 계수, 공분산, 신뢰구간, 잔여 자유도와 최종 HTML, 진단 및 RNG를 비교했다. 프로세스마다 기준 준비 결과와 후보 준비·워밍업·측정 결과가 정확히 일치했다. 프로세스 사이의 전체 객체 비교는 하지 않았다.

## 측정 정정과 최종 제품 비교

초기 연구용 통합 계측은 빠른 경로 사용 여부를 확인하려고 후보에만 조건 검사를 한 번 더 수행했다. 이를 호출 카운터로 고친 후 독립 R 프로세스 3개를 순차 실행했고, 연구용 함수 구성에서는 9회 모두 빨라 중앙값 0.63→0.54초였다. 초기 중복 검사 수치는 적용 판단에서 제외했다.

그러나 제품 함수의 로컬 클로저로 옮긴 **실제 코드 형태**를 다시 측정한 결과는 다음과 같았다. 비교 기준은 수정 전 제품 소스에서 읽은 원래 함수다. 각 프로세스에서 양쪽 준비 호출과 3회씩의 워밍업을 수행한 뒤 3회 측정했고 두 번째 프로세스의 측정 순서를 뒤집었다. 숫자는 분석+HTML 생성+동일한 원시 값 캡처 비용을 포함한다. 앱 시작/브라우저 배치는 제외한다.

|프로세스|기준 3회(초)|제품 형태 후보 3회(초)|
|---|---|---|
|1|0.53 / 0.52 / 0.50|0.50 / 0.50 / 0.67|
|2|0.50 / 0.52 / 0.69|0.51 / 0.51 / 0.50|
|3|0.52 / 0.52 / 0.52|0.50 / 0.48 / 0.50|

9회 중앙값은 0.52→0.50초(약 3.8%), 합계는 4.82→4.67초였다. 7회 빨랐고 2회 느렸다. 큰 지연의 원인을 GC 등으로 단정하지 않는다. 연구용 함수에서 관측한 개선율을 제품 적용 효과로 보고하지 않는다. 함수 구성/환경에 따라 결과가 달라졌으므로 요약 단독 측정도 제품 개선율의 근거로 사용하지 않는다.

## 결정과 복원 확인

최종 제품 형태에서 보인 중앙값 0.02초 차이를 얻기 위해 약 100줄의 조건·메서드·바인딩 검사와 별도 수치 경로를 유지하는 것은, 코드 단순화와 결과 보존을 함께 요구한 목적에 비해 이득이 작다고 판단했다. 충분한 조건에서 이득이 전혀 없다는 결론은 아니지만 **이번 후보는 미반영**으로 종료한다. 같은 조건의 단독 요약 벤치마크만 반복하여 재추진하지 않는다.

복원 전에 함수 밖의 앞/뒤 텍스트가 작업 전 파일과 동일함을 확인해 다른 변경을 덮어쓰지 않았다. `R/setup_complex_sample_ui.R`의 최종 SHA256은 작업 전과 같은 `2DDEDF6A46A822053E8F6D57FD083C0E783C47033579E9A2645CFA93D40B8D15`다. 원래 작업 트리의 수정 상태를 그대로 유지했다. 임시 회귀 스크립트는 연구 출력 디렉터리로 옮겨 미반영 후보를 검증하도록 했고, 복원한 제품의 `scripts/validate_complex_sample_analysis.R`은 다시 끝까지 통과했다. 제품 및 출력 형식의 최종 변경이 없어 전체 내보내기와 빌드는 수행하지 않았다.
