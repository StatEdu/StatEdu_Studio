# 상관분석 측정수준 조회표 재사용

2026-09-15. `R/analysis_correlation.R`에 분석 호출별 `correlation_measurement_reader()`를 추가했다. 사전 검사, 숫자 자료 준비, 정규성 요약이 같은 조회기를 공유한다. 일반 data.frame의 속성 없는 문자형 이름·측정수준 열은 첫 조회에서 만든 변환 결과를 재사용한다. 분석 호출이 끝나면 조회기도 폐기되므로 다음 분석의 변수 정보 변경을 가로막는 전역 캐시는 없다.

기존 `correlation_measurement()`와 조회표 생성 함수는 유지했다. factor, 사용자 정의 클래스 및 기타 특수 형식은 기존 개별 조회로 돌아간다. 일반 형태여도 조회 중 경고나 메시지가 발생하면 캐시하지 않아 원래 호출 위치에서 진단이 반복된다. 중복 이름의 첫 일치, 누락/미지원 측정수준의 기본값, ordinal 별칭 처리는 기존 규칙을 유지한다. 계산식, 추정법, 결측 처리, 난수 순서, 결과 표시 형식은 바꾸지 않았다.

## 검증

기준: `scripts/fixtures/correlation_measurement_lookup_reference.R`(변경 직전 소스).

`scripts/validate_correlation_measurement_reader.R`에서 결과 객체 전체·속성, 경고/메시지/오류, stdout, RNG를 `identical(..., num.eq=FALSE)`로 비교했다. 환경 속성 제거 등 결과 정규화는 하지 않았다.

- 전체 분석 80개 조건: Pearson/Spearman/Kendall/auto, 정규성 표 켜기/끄기, 일반·중복·결측·알 수 없는 측정수준·factor·빈 표·NULL·누락 열. 사용자 정의 변환에서 경고·메시지·난수를 발생시키는 경우도 포함.
- 숫자 자료/정규성 요약 함수 단독 호출 6개.
- 결측 유무와 잠재상관 활성화 유무 4개. 성공 결과 생성도 확인.
- 정상 형태의 조회 함수가 진단을 발생시키도록 한 반복 진단 비교 1개.
- 한글/영문 현재 결과 HTML 2개 정확 비교.
- 기존 `validate_correlation_vector_reuse.R` 44개 및 변환 횟수/진단 복귀 검사 통과.
- `validate_correlation_auto.R`, `validate_scope_variable_exclusion.R` 통과.

출력 내용 변경 없이 조회 준비만 수정했다. 이번에는 누적 결과 및 PDF/Word/HWPX/Excel 내보내기를 새로 검증하지 않았으며, 현재 HTML 검사를 모든 내보내기 검증으로 확대해서 주장하지 않는다.

## 성능

`scripts/benchmark_correlation_measurement_reader.R`에서 실제 서버의 환경설정 초기화를 적용했다. 독립 R 프로세스 3개, 구/신 버전의 상관 모듈 함수를 같은 방식으로 컴파일하고 사전 호출한 뒤 순서를 교대했다. 조건별 3회 중앙값이다.
