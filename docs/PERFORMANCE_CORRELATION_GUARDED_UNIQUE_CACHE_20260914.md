# 결측 조건을 제한한 Spearman 고유값 캐시 — 2026-09-14

## 적용

`R/analysis_correlation.R`의 기존 분석 단위 순위 캐시에 고유값 벡터 재사용을 추가했다. 유지된 분석 변수 모두에서 기존 전처리의 유효 관측치 수가 전체 행 수와 같을 때만 활성화한다. 조건 판정을 위해 자료를 다시 순회하지 않는다. 결측이 하나라도 있는 유지 변수는 고유값 검사에 기존 경로를 사용한다. 제외된 상수/전체 결측 변수는 이 판정에서 제외한다.

`correlation_rank_test(limit, cache_unique=FALSE)`의 기본값은 기존 동작이다. Spearman 실행 환경에서만 고유값 래퍼를 등록하며, 속성 없는 integer/double 입력과 추가 인자 없는 호출만 재사용한다. 입력은 `identical(..., num.eq=FALSE)`로 비교한다. 기존 순위 캐시의 변수 수 제한을 공유하고 분석 호출이 끝나면 캐시도 해제된다. `cor.test`의 검정 계산·정밀도·동률 처리·난수 동작은 변경하지 않는다.

## 실행 시간

번들 R 4.5.3, 10,000행·20변수·190쌍, 시드 33, Spearman 및 정규성 검사 활성화 조건이다. 완전 자료는 정규 난수, 동률 자료는 이를 반올림한 값, 결측 자료는 각 변수에 서로 다른 무작위 결측 10%를 넣었다.

기존/후보 각 세 개의 새 R 프로세스를 순차 실행했다. 두 번째 비교는 후보부터 실행했다. 각 조건을 준비 실행한 뒤 전체 분석 10회를 측정했다. 입력 생성·로딩·화면·저장은 제외했다. 다른 R 작업을 시간 측정과 동시에 실행하지 않았다.

| 조건 | 기존 3회(초, 각 10분석) | 후보 3회(초, 각 10분석) | 중앙값 기존→후보 |
| --- | --- | --- | --- |
| 완전 자료 | 2.00 / 1.82 / 1.91 | 1.61 / 1.60 / 1.97 | 1.91→1.61, 약 16% 감소 |
| 동률 자료 | 1.85 / 1.88 / 2.75 | 1.56 / 1.60 / 2.25 | 1.88→1.60, 약 15% 감소 |
| 변수별 결측 10% | 4.48 / 4.45 / 5.65 | 4.58 / 4.50 / 5.66 | 4.48→4.58, 약 2% 증가 |

세 번째 비교 등에서 시간 변동이 있었고, 완전 자료가 모든 비교에서 빨라진 것은 아니다. 수치는 해당 반복 분석 조건의 중앙값이며 프로그램 전체 속도 개선율이 아니다. 결측 자료에서 앞선 무조건 캐시 후보의 약 29% 저하는 해소됐지만, 작은 실행 시간 차이가 전혀 없다는 의미는 아니다.

## 메모리 비용

동일한 완전 자료 190쌍 실행 후 캐시 항목은 기존/후보 모두 20개였다. R `object.size(entries)`는 3,209,168→4,811,888바이트로 약 1.60MB 증가했다. 이는 캐시 객체의 계산상 크기이며 프로세스 RSS나 최대 메모리 사용량이 아니다. 고유값 벡터 추가 보관에 따른 비용이며, 변수 수와 관측치 수가 커지면 증가할 수 있다. 결측 조건에서는 고유값 벡터를 추가 보관하지 않는다.
