# 고차요인 HTMT 계산 불가·진행 상태 다국어

2026-09-17

고차요인 HTMT 계산 불가 사유 10종, 평가하지 않음 안내, 원문항/하위척도 방식 제목, 부트스트랩 미요청·진행 중·중단·실패 안내를 한국어와 추가 6개 언어로 연결했다. 원문항 방식의 계산 불가 화면에도 하위척도 제목이 고정되어 나오던 문제를 수정했다. 모르는 사유는 원문을 보존한다. 통계 계산과 영어 본표는 변경하지 않았다.

`scripts/validate_higher_htmt_state_i18n.R`는 표시용 계산 결과 fixture를 사용해 10개 사유와 알 수 없는 사유, 4개 부트스트랩 상태를 두 표시 방식 × 8개 언어에서 검사했다. 모든 통계적 실패를 실제로 재현하는 검사는 아니다. 상세 표시를 요청하지 않으면 기존처럼 계산 불가 화면을 표시하지 않는 동작과 언어별 본표 HTML 동일성을 확인했다. 한글·특수문자·리터럴 `%s`가 포함된 외부 상세도 유지된다.

공통 다국어 커버리지 검사 통과. 내보내기 fixture는 상태별 실제 렌더링과, 계산 불가 안내를 모아 대표 본표 뒤에 캡처한 결과를 사용한다. 로그와 산출물은 `tmp/higher-htmt-state-*`에 저장한다.

일본어 현재 결과 9개 표와 누적 결과 11개 표의 HTML/PDF/Word/HWPX/Excel 내용 검사, 실제 PDF 텍스트, HTML/Word 표 순서 및 Excel 시트 수 검사를 통과했다.

이번 범위는 계산 불가 및 진행 상태 안내다. 고차요인 HTMT의 지표 구성·판정·부트스트랩 상세표 및 일반 해설은 추가 점검이 필요하다. 설치본은 생성하지 않았다.
