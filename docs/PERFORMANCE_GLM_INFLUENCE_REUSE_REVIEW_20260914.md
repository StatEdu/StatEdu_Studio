# GLM 영향력 재사용 후보 검토 — 2026-09-14

영향력을 한 번 구해 Cook 거리와 레버리지에 전달하는 후보를 검토했지만 **적용하지 않았다**. 정상 모형의 수치는 일치했으나 전체 시간 이득이 일관되지 않았고, 직접 치환한 후보는 영향력 계산 실패 시 기존 오류 처리와 달랐다. 운영 `R/analysis_generalized.R`이 기준 사본과 같은 해시임을 확인했다.

## 전체 분석 시간

| 200,000행 모형 | 기존 3회(초) | 후보 3회(초) | 중앙값 |
|---|---|---|---|
| Gaussian | 1.33 / 1.24 / 1.34 | 1.19 / 1.33 / 1.24 | 1.33 → 1.24 |
| Binomial | 1.80 / 1.78 / 1.80 | 1.73 / 1.75 / 1.86 | 1.80 → 1.75 |
| Gamma | 2.07 / 2.18 / 2.07 | 2.14 / 2.01 / 2.15 | 2.07 → 2.14 |

모든 모형에서 느려진 실행이 있었고 Gamma는 중앙값도 증가했다. 중복 연산만 제거하면 전체 분석이 반드시 빨라진다고 볼 수 없다. 오류 처리 보완과 적용 범위 제한까지 추가할 근거가 충분하지 않아 이 후보는 보류한다. 이 표를 적용된 개선 성과로 계산하지 않는다.

번들 R 4.5.3의 새 프로세스 3개를 순차 실행하고 두 번째에서는 기존/후보 순서를 뒤집었다. 각 조합은 준비 실행 후 GC와 시간 측정을 수행했다. 20만 행, 정규 예측변수 6개, 강건 표준오차·가정 점검 켬, VIF 끔의 완전 자료이며 시드와 생성식은 직전 프로파일과 같다. 다른 R 작업을 동시에 실행하지 않았다. 모듈 로딩·입력 생성·화면·저장은 제외하고 전체 결과 준비·비교용 스냅샷 구성·조건 수집을 포함한다. 메모리는 측정하지 않았다.

## 동일성 및 예외

- 세 모형 × 세 프로세스의 정상 자료에서 준비/측정 결과가 `identical(..., num.eq=FALSE)`로 일치했다. 비교 대상은 모형 객체를 제외한 반환 결과와 별도 계수·적합값·잔차·deviance·weights, 경고/메시지 문자열, 난수 상태다. 공식 환경만 `.GlobalEnv`로 통일했다. 모형 내부 클로저 등 모든 내부 필드의 동일성을 주장하지 않는다.
- 세 분포 × 일반/가중치/0 가중치/결측 제외/선형 종속의 15개 소형 모형에서 원시 Cook 거리·레버리지 벡터 및 전체 영향력 요약값이 정확히 일치했다. 요약 호출의 조건 클래스·문자열·난수 상태도 일치했다.
- 잘못된 모형 객체에서는 기존 함수가 Cook 거리와 레버리지 오류를 각각 처리해 요약을 반환하는 반면, 후보는 앞선 공통 영향력 계산에서 오류로 종료했다. 이 차이는 제품 결함 발견이 아니라 **실험 후보의 비호환성**이다. 실제 제품은 기존 처리를 유지한다.
- 후보를 적용하려면 알려진 모형에 대한 범위 제한, 영향력 계산 오류 및 경고·메시지 발생 시 기존 동작 보존을 별도로 검증해야 한다. 이번 검토에서는 추가 구현하지 않았다.
