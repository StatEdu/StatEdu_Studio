# ID 집계 화면 표시 문구

통계량 선택 항목 8개, 화면 설명, 출력 변수 이름, 빈 미리보기 안내/열 제목, 미리보기·데이터 생성 완료 문구 및 데이터 교체 불가 안내의 15개 키를 8언어 사전에 추가했다. 완료 메시지는 번역된 문자열 대신 메시지 키와 행/변수 수를 보관하고 현재 UI 언어로 다시 표시한다.

`validate_id_aggregate_ui_i18n.R`는 실제 집계와 서버 핸들러로 8언어 통계량 선택의 표시명/내부 코드, 설명/출력 변수 라벨, 미리보기·생성 완료 문구의 언어 전환을 확인했다. 생성 결과의 사용자 ID `사용자 <&> %s`, `Normality`와 변수명 `Review`, 평균값 3과 9를 보존했다. 언어를 바꿔도 데이터 교체는 추가 실행되지 않았다. 테스트의 초기 action 버튼 및 서버 상태 계수 처리 오류를 바로잡은 뒤 모두 통과했다. 공통 다국어 검사도 통과했다.

로그: `tmp/id-aggregate-ui-i18n.log`, `tmp/id-aggregate-coverage-regression.log`. 실제 브라우저의 전체 입력 상태 유지, DT 검색·페이지 컨트롤, 조건식 파서 및 나머지 집계 오류 안내는 이번 검증 범위 밖이다. 집계 계산 코드는 변경하지 않았고 분석 본표/내보내기도 변경하지 않았다. 설치본을 만들지 않았다.
