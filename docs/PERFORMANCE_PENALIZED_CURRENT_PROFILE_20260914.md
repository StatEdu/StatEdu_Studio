# 벌점 회귀 현재 병목 측정

## 결과

Ridge·LASSO·Elastic Net 분석으로 범위를 옮겨 현재 실행 비용을 측정했다. 주요 비용은 선택 안정성 부트스트랩의 재적합이었다. 계수 추출 중복만 줄이는 작업은 이번 조건에서 전체 실행에 미치는 영향이 작으므로 우선하지 않는다. 이번 작업은 기준 측정이며 제품 코드를 변경하지 않았다.

현재 `R/analysis_penalized.R`은 이미 부트스트랩 교차검증에서 keep=FALSE를 사용하고, 워커 선택 및 재사용 처리가 있다. 이를 새 개선으로 주장하거나 다시 구현하지 않았다. 제품과 스냅샷 SHA256은 `502C3EC1E0A2D9C2F8E6932A9E255B195D8E86618DD702837D2DC7EADCE1BAD2`이다.

## 자료와 측정

번들 R 4.5.3, 자료 seed 939, 분석 seed 7731, 1,000행·연속 설명변수 20개·연속 반응을 사용했다. 세 방법 모두 실행하고 Elastic Net alpha_grid는 0.25/0.5/0.75, 선택 부트스트랩은 방법별 20회, 워커는 명시적으로 1개로 지정했다. 기본 500회나 자동 병렬 실행을 측정한 것은 아니다.

독립 프로세스 3개를 순차 실행했다. 각 프로세스에서 워밍업 후 비계측 전체 실행을 측정하고 별도 실행에서 호출 횟수와 시간을 계측했다. 첫 프로세스에서는 trace를 해제한 뒤 Rprof 20ms 표본도 수집했다. 로딩 시간은 제외하고 결과 캡처를 포함한다.

| 항목 | 1회 | 2회 | 3회 |
|---|---:|---:|---:|
| 전체 실행(초, 비계측) | 1.47 | 1.50 | 1.47 |
| cv.glmnet 호출 수 | 45 | 45 | 45 |
| cv.glmnet 누적 시간(초, 별도 계측) | 1.42 | 1.46 | 1.41 |
| 부트스트랩 함수 호출 수 | 40 | 40 | 40 |
| 부트스트랩 누적 시간(초, 별도 계측) | 1.30 | 1.33 | 1.35 |
| cv.glmnet 객체 계수 추출 횟수 | 90 | 90 | 90 |
| 해당 계수 추출 누적 시간(초) | 0.02 | 0.04 | 0.07 |

교차검증 45회는 기본 Ridge 1 + LASSO 1 + Elastic Net alpha 후보 3 + LASSO 부트스트랩 20 + 선택된 Elastic Net alpha의 부트스트랩 20으로 설명된다. 각 cv.glmnet 호출 내부의 fold별 적합 횟수를 뜻하는 것은 아니다. 90회 계수 추출은 부트스트랩의 두 lambda 기준 80회와 전체 모형의 선택/요약 처리 10회다.

부트스트랩 시간에는 cv.glmnet과 계수 추출 시간이 포함되므로 행을 합산하지 않는다. 별도 계측 시간을 비계측 전체 실행 시간에서 빼거나 나눠 정확한 구간 비중을 추정하지 않는다. Rprof의 selection_stability_table 표본 비중은 86.67%였고 단일 짧은 실행의 후보 선정용 근거다. 표본 시간은 경과 시간과 다르다.

초기 coef.cv.glmnet namespace trace는 실제 S3 호출을 포착하지 못해 0회로 나타났다. 이를 호출이 없다는 근거로 사용하지 않고 stats::coef generic에서 cv.glmnet 객체만 집계하도록 수정한 뒤 독립 프로세스 3개를 모두 다시 측정했다. 위 표는 수정된 최종 계측이다.

## 동일성 확인

각 프로세스에서 워밍업 대비 비계측·계측 결과, 첫 프로세스에서 프로파일 결과가 모두 `identical(..., num.eq=FALSE)`로 일치했다. 비교 대상은 전체 반환 객체(계수·CV 곡선·선택 안정성 등), 조건 클래스·본문·순서, 표준 출력, RNG다. 반환 객체는 별도 정규화나 허용오차를 사용하지 않았다. 자료에서는 조건이 발생하지 않았다. 예외 주입이나 다양한 자료 조건을 검증한 것은 아니다.

## 다음 검토 범위

계수 추출만 묶기보다 반복 cv.glmnet 내부의 객체 생성과 fold 예측 비용을 살펴볼 근거가 생겼다. 부트스트랩 횟수·fold 수·alpha 후보·난수 시드를 줄이거나 바꾸는 것은 결과 보존 최적화가 아니므로 후보에 포함하지 않는다. 이번 20회 측정을 기본 500회 실행 시간으로 단순 외삽하지 않는다.

`output/penalized-current-profile-20260914/`에 baseline.R, profile.R, timing-1/2/3.csv, run 로그, result-1/2/3.rds, Rprof 및 total/self CSV, 프로세스 간 결과 비교 스크립트를 보관했다. 출력 변경이 없어 전체 형식 변환이나 빌드, 종합 회귀 테스트는 재실행하지 않았다.
