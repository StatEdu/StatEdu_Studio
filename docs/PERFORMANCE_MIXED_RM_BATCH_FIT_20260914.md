# 혼합 반복측정 사후 비교 일괄 회귀 적용

2026-09-14. 숫자 공변량을 사용하는 보정 사후 비교에서 같은 설계행렬을 사용하는 시점 대비를 다중 반응 회귀로 함께 적합한다. 각 대비의 계수·잔차·적합값·effects를 추출한 뒤 기존 검정통계량 및 p값 계산 함수를 그대로 사용한다. 집단별 사후 비교 표, 전체 시점 비교 표, 유의 순서 표기에 적용했다. 보정 방법과 표시 순서는 바꾸지 않았다.

## 적용 조건

유한한 숫자 반응행렬과 일반 숫자 공변량 데이터프레임, 같은 행 수, 기본 `na.action="na.omit"`에서만 적용한다. 시점 대비가 둘 미만이거나 대비 행렬이 100만 원소를 넘으면 기존 개별 계산을 사용한다. 범주형·특수 클래스 공변량, 결측값·무한대, 차이 계산 중 오버플로, 사용자 지정 결측 처리, 상수 공변량만 있는 경우에도 기존 계산을 사용한다. 일괄 경로에서 경고·메시지·오류가 발생하면 개별 계산으로 돌아가 기존 조건을 전달한다.

반응열마다 결측 행이 다를 때 일괄 회귀가 관측행과 자유도를 바꾸는 문제를 이 제한으로 피한다. 캐시를 유지하지 않으며 매 분석마다 현재 데이터로 계산한다. 행렬 원소 제한은 작업 크기 제한이며 실제 최대 메모리 사용량을 뜻하지 않는다.

## 성능

2,000명, 4집단, 6시점, 숫자 공변량 1개, Holm 사후 비교. 기존/변경 각각 새 R 프로세스 3개를 순차 실행했고 두 번째 쌍의 실행 순서는 뒤집었다. 분석 시간만 측정했으며 HTML 생성은 제외했다.

| 전체 분석 시간 중앙값 | 기존 | 변경 | 감소 |
|---|---:|---:|---:|
| 첫 실행 | 0.78초 | 0.74초 | 약 5% |
| 반복 실행 | 0.30초 | 0.25초 | 약 17% |

개별 반복 시간은 기존 0.31/0.30/0.29초, 변경 0.25/0.25/0.25초다. 이 데이터와 환경에서의 측정이며 모든 분석에 같은 개선율을 보장하지 않는다. 처음에는 순서 표기에만 적용해 차이가 작았고, 표 계산까지 확장한 최종 버전을 다시 측정한 수치다.

## 검증

- `scripts/validate_mixed_rm_batch_pairs.R`: 숫자·정수·범주형·공선성·거의 공선성·상수·결측 반응·결측 공변량·무한대·오버플로·완전 적합·공변량 없음 × 4가지 NA 정책, 총 48건. 반올림 전 statistic/df/p 목록, 경고·메시지·표준출력·난수 상태가 기존 개별 경로와 `identical()` 일치. 실제 다중 반응 적합 경로 사용도 확인.
- 전체 분석 12개 시나리오와 성능 측정 3쌍: 전체 결과는 허용오차 0, 환경 객체 제외 비교 통과. 공선성과 단일 집단 시나리오는 기존과 같은 분석 오류이며 성공한 분석으로 세지 않는다.
- 일반 HTML은 정확히 일치. 보고서 HTML은 생성 시각만 정규화한 뒤 동일. 이전 단계의 `saved_time` 미정의 오류는 현재 작업 트리에서 재현되지 않았으며 이 작업에서 표지 코드를 수정하지 않았다.
- 현재·누적 HTML 동일, Excel 패키지 내용은 생성 타임스탬프 제외 동일.
- HTML/PDF/Word/HWPX/Excel 현재·누적 총 10개 파일 생성 성공. Word/HWPX 셀 내용은 HTML과 각각 680/1,360개 일치. PDF는 기존 표지를 포함해 9/17페이지, 이미지는 표지에만 존재. 현재 PDF 본문 첫 페이지를 시각 확인했다.
- 기존 `scripts/validate_mixed_rm_anova.R` 통과. 기존 singular fit 안내가 출력된다.
- 관련 파일 `git diff --check` 통과. 빌드·배포하지 않았다.
