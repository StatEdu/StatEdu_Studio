# 범주형 대응표본·반복측정의 고정 제외 안내 번역

## 변경

실제 결과 패널에서 다음 3개 안내가 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남는 것을 재현하고 8개 언어 사전에 반영했다. 기존 한국어와 영어 표현은 유지했다.

- 범주형 대응검정에 필요한 완전 사례 및 관측 범주가 부족함.
- 반복측정에 필요한 완전 사례가 최소 2개보다 적음.
- 각 대상자 내 반복측정값이 모두 같아 검정을 수행하지 않음.

번역 사전만 변경했으며 분석 계산·결과 렌더링·저장 코드는 변경하지 않았다.

## 검증

- `validate_paired_remaining_guards_i18n.R`: 정상 분석 행과 범주 1개인 대응자료, 완전 사례 1개인 반복측정 자료, 대상자 내 값이 같은 반복측정 자료를 실제 분석했다. 제외 사유 원문 3개가 예상과 일치하는지 먼저 확인한 뒤 전체 결과 패널에서 8개 언어 표시를 검사했다.
- 영어 본표 동일성과 원본 결과 객체 보존 검사 통과.
- `validate_paired_guards.R`, `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검사 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-remaining-guards-i18n/exports`. 캡처한 결과를 저장하며 저장 과정에서 분석을 재실행하지 않는다.

## 범위

이번 검증은 위 고정 제외 사유 3개에 한정한다. 대응표본·반복측정의 분석명, 이상치 안내 등 다른 후보까지 완료됐다는 의미는 아니다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙은 유지한다.
