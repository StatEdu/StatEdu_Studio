# 번역 overlay 원본 값의 위치 조회 재사용 — 2026-09-14

`R/labels.R`의 번역표 초기화에 적용했다. locale overlay 키를 순회할 때, 유효하고 중복이 없는 키를 가진 일반 목록에서는 이미 알고 있는 정수 위치로 값을 읽는다. 기존 대상 번역표 위치 재사용은 유지하며, 원본 목록의 반복 이름 조회를 추가로 줄인다.

중복 키, 빈/NA 키 또는 객체 목록은 기존 `translations[[key]]` 경로를 유지한다. 중복 키의 첫 항목 선택과 사용자 정의 `[[` 동작을 보존하기 위한 조건이다. 번역 문구, 새 키 삽입 순서, 언어별 대체 문구, 요청별 언어·권한·설정 확인과 기존 번역표 캐시 정책은 바꾸지 않는다.

## 첫 UI 구성 시간

번들 Windows R 4.5.3, JIT 3, 기존 모듈 캐시와 패키지 자동 설치 비활성 조건이다. 기준/후보별 새 프로세스 3개를 순차 실행하고 두 번째 비교는 후보부터 실행했다. 패키지·모듈을 로드한 뒤 해당 labels 소스를 읽어 초기화 전 번역표 함수를 만들고, 서버 함수를 생성한 다음 첫 `app_ui(version, NULL)`를 측정했다.

| 반복 | 기존 | 변경 후 |
| --- | ---: | ---: |
| 1 | 0.37초 | 0.34초 |
| 2 | 0.38초 | 0.34초 |
| 3 | 0.37초 | 0.35초 |
| 중앙값 | 0.37초 | 0.34초 |

중앙값은 **0.03초, 약 8.1% 단축**됐고 모든 쌍에서 빨랐다. UI 구성과 조건/표준출력 수집을 포함하며, R 프로세스 시작·패키지/모듈 및 labels 소싱·서버 함수 생성·HTML 태그 렌더링은 시간 밖이다. HTML 태그 렌더링은 결과 비교를 위해 이후 실행했다. 실제 Electron 시작 시간이나 첫 서버 세션 전체가 8.1% 빨라졌다는 의미는 아니다. 메모리는 별도로 측정하지 않았다.
