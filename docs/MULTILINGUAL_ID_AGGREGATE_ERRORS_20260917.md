# ID 집계 조건식·입력 오류

ID 집계의 고정 오류 9개와 동적 안내 3개를 8언어에 연결했다. 실제 계산 함수의 오류 발생·검증 동작은 유지하고 미리보기/데이터 생성 알림 경계에서만 번역한다. 동적 오류는 알려진 접두사만 바꾸며 변수명·함수명·파서 상세는 원문 그대로 남긴다. 등록되지 않은 외부 오류도 원문을 보존한다.

범위는 조건식 개수·결과 길이, 통계량 코드, 빈 데이터, ID/값 변수, 유효 ID 부재, 직접 함수 호출 제한, 지원하지 않는 수식 요소, 파싱 실패, 알 수 없는 변수/함수, 사용 불가 함수다.

`validate_id_aggregate_errors_i18n.R`에서 실제 함수로 12개 오류를 발생시켜 8언어 번역과 원문 보존을 확인했다. 지원하지 않는 수식 요소는 검증기에 pairlist를 전달한 단위 검사이며 일반 UI 입력으로 재현한 것은 아니다. 실제 서버 핸들러의 미리보기/생성 알림이 현재 언어를 사용하는지, 잘못된 조건식으로 데이터 교체가 호출되지 않는지도 확인했다. 기존 UI/집계 보존 검사와 공통 다국어 검사도 통과했다.

로그: `tmp/id-aggregate-errors-i18n.log`, `tmp/id-aggregate-ui-i18n.log`, `tmp/id-aggregate-errors-coverage.log`. 실제 브라우저에서의 입력 보존과 DT 검색·페이지 컨트롤은 별도 미검증이다. 분석 결과·내보내기는 변경하지 않았다. 설치본은 만들지 않았다.
