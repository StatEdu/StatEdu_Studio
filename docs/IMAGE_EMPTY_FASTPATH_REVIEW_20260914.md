# 그림 없는 HTML 조기 반환 후보 검토 — 2026-09-14

## 결론

운영 코드는 변경하지 않았다. `result_node_html()`에서 이미지 노드가 없으면 속성 조회·길이·정규식 검사를 거치지 않고 즉시 직렬화하는 후보를 시험했다. 혼합 누적 저장에서 개선이 확인되지 않아 채택하지 않았다. 기존 큰 그림 URI 오류 수정은 유지한다.

## 측정

직전 공통 HTML 회귀 검증의 고정 입력을 재사용했다. 150행 자료의 상관분석 9/30변수, 200행 병합·주석·스타일 표, 기존 4항 PH 그림, 이 네 항목을 합친 누적 결과다.

동봉 R 4.5.3에서 기존/후보를 각각 새 프로세스로 3회 실행했고 두 번째 쌍은 후보부터 실행했다. 각 프로세스의 조건 순서는 아래 표 순서다. 저장 HTML과 PDF용 원본 HTML 생성 두 작업을 함께 측정했다. 분석, 실제 PDF 변환, Excel 쓰기, 별도 검증은 측정에 포함하지 않았다.

| 조건 | 기존 3회(초) | 후보 3회(초) | 중앙값 기존 → 후보 |
|---|---|---|---|
| 상관분석 9변수 | 0.11 / 0.11 / 0.11 | 0.11 / 0.11 / 0.13 | 0.11 → 0.11 |
| 상관분석 30변수 | 0.29 / 0.30 / 0.30 | 0.30 / 0.30 / 0.30 | 0.30 → 0.30 |
| 주석·병합 표 | 0.08 / 0.08 / 0.08 | 0.07 / 0.07 / 0.08 | 0.08 → 0.07 |
| 기존 그림 | 0.03 / 0.05 / 0.03 | 0.05 / 0.03 / 0.04 | 0.03 → 0.04 |
| 혼합 누적 결과 | 0.42 / 0.42 / 0.42 | 0.42 / 0.42 / 0.44 | 0.42 → 0.42 |

짧은 조건의 0.01초 차이는 측정 해상도와 변동을 고려해야 한다. 전체 저장 시간의 뚜렷한 개선으로 판단하지 않았다. 메모리는 별도로 측정하지 않았다.

## 동일성과 범위

5조건×3쌍의 저장 HTML·PDF 원본 HTML, 경고/메시지·난수 상태가 `identical(..., num.eq=FALSE)`로 모두 일치했다. 미채택 후보이므로 실제 PDF·Word·HWPX·Excel은 이번에 재생성하지 않았다. 이전에 검증한 큰 그림 저장 경로를 대체하거나 축소하지 않았다.
