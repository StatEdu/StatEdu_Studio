# Fine–Gray 잔차 보조표

고유 사건시점 수, 탐색적/보정 p값, 검토 상태 2종, 제목과 설명의 7개 번역 항목을
6개 추가 언어에 보완했다. 기존 공통 보조표 번역 경로를 사용한다.

## 검증

- `validate_fine_gray_residual_table_i18n.R`: 실제 age/sex Fine–Gray 적합의 잔차 진단을
  8개 언어로 검사했다. 별도 표시용 복사본에서 신호 TRUE/FALSE와 사용자 변수명을 확인했다.
- 변수명·상관계수·p값 정밀도 보존, 실제 Fine–Gray 계수 본 표 영어 유지 확인.
- 수치 안정성 보조표 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 표와 설명의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.
  이번 파일 검증에 잔차 도표는 포함하지 않았다.

설치본은 생성하지 않았다. 검열분포 보조표 등 나머지 점검은 남아 있다.
