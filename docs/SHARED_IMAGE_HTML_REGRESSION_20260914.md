# 공통 그림 HTML 처리의 기존 결과 회귀 검증 — 2026-09-14

## 결론

큰 그림 URI 저장 오류를 해결한 공통 HTML 처리 변경이 기존 상관분석·주석 표·작은 그림의 내용을 바꾸지 않는지 검증했다. 저장 HTML과 PDF용 원본 HTML은 기존과 동일했고, 혼합 결과 Excel도 동일했다. 운영 코드는 추가 변경하지 않았다.

## 조건과 시간

수정 전 `output/cox-ph-height-20260914/baseline-saved.R`과 현재 `R/result_saved_ui.R`에서 변경된 두 경로(`result_entry_body_html`, `saved_result_sheet_document`)를 각각 사용했다. 현재 경로는 `result_node_html`을 호출한다.

150행 정규 합성 자료의 Pearson 상관분석 9변수/30변수(CI 포함), 200행·6열의 병합 셀/주석/스타일 표, 기존 4항 PH 그림, 이 네 결과를 합친 누적 자료를 사용했다. 분석과 화면 표 생성은 미리 수행하여 고정된 입력을 저장했다.

동봉 R 4.5.3에서 기존/현재를 각각 새 프로세스로 3회 실행하고 두 번째 쌍은 현재부터 실행했다. 각 프로세스의 순서는 9변수→30변수→주석 표→그림→혼합이다. 저장 HTML과 PDF 원본 HTML 생성 두 작업을 함께 측정했으며 분석·브라우저 PDF 변환·Excel 쓰기는 제외했다. 별도 검증은 시간 측정 후 수행했다.

| 조건 | 기존 중앙값 | 현재 중앙값 |
|---|---:|---:|
| 상관분석 9변수 | 0.11초 | 0.11초 |
| 상관분석 30변수 | 0.30초 | 0.30초 |
| 주석·병합 표 | 0.08초 | 0.07초 |
| 기존 그림 | 0.03초 | 0.03초 |
| 혼합 누적 결과 | 0.41초 | 0.43초 |

혼합 조건은 기존 0.41/0.40/0.42초, 현재 0.42/0.43/0.44초로 세 쌍 모두 소폭 증가했다. 중앙값 차이는 0.02초(약 4.9%)다. 나머지 짧은 시간의 차이는 측정 해상도와 변동을 고려해야 한다. 큰 그림 오류 수정이 일반 저장을 가속했다고 주장하지 않는다. 이번 결과는 전체 앱 로딩이나 실제 PDF 저장 완료 시간을 뜻하지 않는다.

## 동일성 및 관리 기능

- 5조건×3쌍의 저장 HTML·PDF 원본 HTML, 경고/메시지·난수 상태가 `identical(..., num.eq=FALSE)`로 모두 일치했다. 기존 표·주석·그림 URI와 페이지 구성 입력을 보존한다.
- 혼합 HTML을 Excel로 저장한 뒤 시트 이름·셀 내용·압축 해제 구성 파일을 비교했다. 생성/수정 시각만 정규화했으며 나머지는 바이트 단위로 일치했다.
- `scripts/validate_result_collection_management.R`가 통과했다. 결과 전체 단위 삭제·순서 변경, ID, 되돌리기, 저장 상태와 한국어 HWPX 제어를 검사한다.

실제 PDF·Word·HWPX 파일은 이번에 다시 생성하지 않았다. 직전 Cox/경쟁위험의 다섯 형식 검증과 구분하며, 이번에는 기존 콘텐츠의 공통 HTML 경로와 Excel을 확인했다. 모든 분석·모든 크기의 성능을 보장하는 결과는 아니다.
