# 규제 회귀 사용자 라벨 보존 추가 점검

## 범위와 결과

이전 선택 변수명 수정 후, 번역 사전의 일반 문구와 같은 사용자 라벨이 다른 부록에서도 보존되는지 점검했다. 이번에는 제품 코드와 번역 사전을 변경하지 않았고 검증 스크립트와 기록만 추가했다.

`validate_penalized_user_labels_review.R`에서 실제 90명 자료로 Ridge·LASSO·Elastic Net 분석을 수행했다. 예측변수 라벨은 Yes·No·Status, 결과변수 라벨은 Tested, 범주값은 None·Yes·No로 지정했다. 연속형 예측변수 2개와 3수준 범주형 예측변수를 사용했다. 고급 옵션은 부트스트랩 2회, 표본 분할 20회, 검증 반복 2회로 출력 검사용이다.

분석이 생성한 다음 부록 중 존재하는 표에서 Outcome·Predictor·Variable·Factor·Selected predictors 열을 원본과 비교했다.

- 모형 성능 요약, 계수 비교, 선택 변수 목록, 교차검증 설정
- 선택 안정성, 표본 분할 진단, 범주형 변수 검정 진단, 반복 중첩 교차검증 변동성

언어별 96개 셀, 8개 언어 합계 768개 셀 비교를 통과했다. 이는 언어별로 같은 자료를 반복 확인한 수이며 고유 번역 문구 768개라는 의미가 아니다. 자동 생성 절편 및 선택 상태는 표시 정보에 따른 번역을 기대값으로 사용하고, 사용자 라벨은 원문과 일치하는지 확인했다. 영어 본표의 언어 간 동일성과 전체 결과 객체 보존도 통과했다.

이번 실제 분석 범위에서는 추가 오류가 발견되지 않았다. 모든 입력·고장 상태를 검사한 것은 아니며 프로그램 전체 번역 완료를 뜻하지 않는다. 기존 매개·조절효과 화면은 제외했다.
