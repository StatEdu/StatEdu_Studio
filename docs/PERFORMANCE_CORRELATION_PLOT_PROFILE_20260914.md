# 다른 분석으로의 PNG 초기화 최적화 확장 검토

2026-09-14. 생존분석의 새 PNG 초기화 생략을 상관분석·PCA·요인분석에 그대로 확장할 수 있는지 확인하고 상관분석 저장 경로를 측정했다. 운영 코드는 변경하지 않았다.

## 코드 검토

상관 산점도·히트맵, PCA 스크리·성분 그림, 요인분석 스크리 그림은 `graphics::plot`, `image`, `plot.new` 등 기본 그래픽 함수를 사용한다. 생존분석의 명시적 `grid::grid.newpage()`를 제거했던 경로와 다르다.

특히 산점도 행렬은 `graphics::layout`으로 패널을 나누며, 위쪽 삼각형의 빈 셀에서도 `plot.new()`로 다음 패널로 이동한다. 이 호출은 단순히 불필요한 전체 화면 초기화로 간주할 수 없다. 따라서 생존분석 옵션을 공통 PNG 함수에 일괄 적용하지 않았다.

## 상관분석 저장 측정

번들 R 4.5.3/JIT 3, 모듈 표현식 캐시 및 현재 설정을 사용하고 패키지 설치 검사는 생략했다. seed 714의 정규분포 2,000행 × 8개 연속변수에 Pearson 분석을 수행하고, 산점도 행렬과 상관 히트맵을 포함한 저장 HTML을 생성했다. 정규성 검사와 잠재 상관은 끄고 두 그림을 켰다. 분석 준비는 측정 밖이다.

계측 없는 새 프로세스 3개와 프로파일링용 새 프로세스 3개를 순차 실행했다. 각 프로세스에서 첫 저장과 같은 결과의 반복 저장을 측정했다. 프로파일링은 첫 저장에만 Rprof 0.01초를 사용했으며 system.time의 사전 GC 이후에 시작했다.

| 3회 중앙값 | 첫 저장(초) | 반복 저장(초) |
|---|---:|---:|
| 계측 없는 전체 HTML 생성 | **2.46** | **1.87** |
| 프로파일링 포함 전체 HTML 생성 | 2.50 | 1.86 |
| 산점도 행렬 그리기 | 0.65 | 0.61 |
| 히트맵 그리기 | 0.05 | 0.03 |
| 두 그림의 plot_data_uri 합계 | 1.80 | 1.72 |

helper 값은 계측 실행에서 얻었으며, plot_data_uri에 그림 그리기 시간이 포함되므로 합산하지 않는다. HTML에서 디코딩한 두 PNG는 각각 **5625×5625픽셀**이며 파일 크기는 643,015 및 220,699바이트였다. 현재 600 dpi 출력 설정을 유지했다.

## 병목 판단

첫 저장의 표본 시간은 1.65/1.65/1.64초로 실제 경과 시간보다 짧았다. 표본 안의 누적 비율은 다음과 같다.

- PNG 장치 종료·저장 완료 `grDevices::dev.off`: 38.79/38.79/39.02%
- 점·선 그리기 `plot.xy`: 21.21/21.21/21.95%
- 평활선 계산 `stats::lowess`: 1.21/3.03/3.05%

이를 전체 벽시계 시간의 정확한 분할로 해석하지 않는다. dev.off 수치는 순수 디스크 쓰기 시간만을 뜻하지 않는다. 현재 자료에서는 평활선 계산보다 점 그리기와 고해상도 PNG 출력의 비중이 크다. lowess 변경이나 빈 패널 초기화 생략을 우선 적용할 근거가 부족하다.

산점도는 8개 대각선 히스토그램, 28개 하위 삼각형 산점도, 28개 상위 삼각형 빈 패널을 구성한다. 상위 패널 초기화를 임의로 없애거나 점을 줄이는 방법은 배치 또는 표시 내용에 영향을 줄 수 있으므로 시도하지 않았다. 더 큰 자료에서는 계산 비중이 달라질 수 있다.

## 보존 검증 및 범위

6개 프로세스의 전체 저장 HTML(두 PNG 포함), 경고·메시지, 표준 출력, RNG 상태가 `identical(..., num.eq=FALSE)`로 같았다. 각 프로세스의 첫/반복 저장도 같았으며 원래 상관분석 결과의 직렬화 바이트가 저장 전후 유지됐다.

이번 결과는 상관분석 저장 HTML 경로의 기준 측정이며 속도 개선 수치가 아니다. PCA·요인분석은 코드 구조만 확인했고 별도로 성능을 측정하지 않았다. 프로그램 시작, PDF/Word/HWPX 변환, Excel 작성 및 최대 메모리 사용량은 측정하지 않았다. 운영 변경이 없어 전체 형식 내보내기나 설치 파일 재빌드도 하지 않았다.
