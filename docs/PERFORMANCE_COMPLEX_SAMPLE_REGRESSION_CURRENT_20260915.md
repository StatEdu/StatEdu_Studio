# 복합표본 회귀 현재 기준 및 프로파일

2026-09-15. 과거 메뉴/UI 측정과 구분하여 현재 복합표본 회귀의 분석부터 HTML 문자열 생성까지 측정했다. 제품 코드는 수정하지 않았다.

## 조건과 결과

번들 R 4.5.3과 번들 라이브러리, seed 20260915. 합성 완전자료 10,000행, 10개 층, 200개 PSU, 불균등 양의 가중치, 연속형 예측변수 4개와 Gaussian 종속변수 6개다. 하나의 호출에서 여섯 회귀를 실행한다. 앱 전체 시작 및 브라우저 배치는 포함하지 않는다. 기본 출력 옵션을 사용했다.

독립 R 프로세스 3개를 순차 실행했다. 각 프로세스에서 준비 호출 1회 후 3회를 측정했다.

|프로세스|경과 시간 3회(초)|
|---|---|
|1|0.70 / 0.69 / 0.52|
|2|0.71 / 0.67 / 0.53|
|3|0.70 / 0.69 / 0.52|

9회 중앙값은 0.69초다. 각 프로세스의 후반 호출이 더 빨랐으므로 완전히 안정화된 반복 실행 시간으로 해석하지 않는다. 캡처 및 성공 표제 검사 비용도 타이머에 포함된다. 이전 버전과의 개선 비교는 아니다.

## 별도 프로파일

각 프로세스의 시간 측정이 끝난 후 5회 호출을 0.01초 간격 Rprof로 별도 관측했다. 표본 시간은 2.03 / 2.01 / 2.02초다. 이는 위 경과 시간과 다른 프로파일 표본 합계다.

|포함 호출 스택|프로세스 1 / 2 / 3 비중|
|---|---|
|계수 원시 표 생성|20.69 / 23.88 / 19.80%|
|그 안의 summary.svyglm|20.20 / 23.88 / 19.31%|
|조사설계 구성|14.78 / 13.93 / 11.39%|
|survey::svyglm 적합|10.34 / 9.45 / 13.86%|
|htmltools::renderTags|11.33 / 10.95 / 11.88%|

스택 비중은 중첩되므로 더하지 않는다. 계수 요약이 다음 조사 후보다. 요약 계산을 생략하거나 조사설계를 캐시한 실험은 하지 않았다. 조사설계 구성 함수에는 선택 변수 처리가 포함되고 종속변수마다 완전관측치 처리가 이어지므로, 단순 공통화가 안전하다고 확정할 수 없다.

## 검증 및 한계

기존 `scripts/validate_complex_sample_analysis.R`이 끝까지 통과했다. 여기에는 빈도·교차·평균비교·상관·회귀·로지스틱의 기존 실패 분리 및 출력 계약 검사가 포함된다. 모든 수치 조합을 검증한 것은 아니다.

측정 스크립트는 각 호출에 여섯 성공 결과 표제가 모두 있는지 확인한다. 프로세스별 준비 호출과 시간 측정 3회 및 계측 5회의 HTML 문자열, 조건 클래스/본문/순서, 표준 출력, 최종 RNG를 `identical(..., num.eq=FALSE)`로 비교해 모두 통과했다. 조건은 0개였다. **비교 대상은 렌더링된 HTML이며 원시 계수·공분산·전체 적합 객체의 정확 일치 검사가 아니다.** 프로세스 간 결과 객체 비교는 하지 않았다. 결측·복제 가중치·하위모집단·로지스틱 대규모 조건으로 일반화하지 않는다.

제품 변경이 없어 전체 내보내기 및 설치 파일 빌드는 실행하지 않았다. 증거는 `output/complex-sample-current-20260915/`의 `validation.log`, `measure.R`, `measure.log`, `run-2.log`, `run-3.log`, 각 실행의 `times.csv`, `reference.rds`, `regression.Rprof`, `by-total.csv`, `by-self.csv`다.
