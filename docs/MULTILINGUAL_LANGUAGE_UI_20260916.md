# 실제 브라우저 언어 왕복·케이스 선택 검사

개발 소스를 별도 R/Shiny 서버(127.0.0.1:43873)로 실행하고, 사용자 저장 자료와 분리한 `tmp/language-ui-profile`을 사용했다. 설치본은 만들거나 교체하지 않았다. Chrome의 실제 브라우저 엔진을 headless 모드로 제어했다.

`scripts/validate_language_switch_session.cjs`에 서버 URL 환경변수와 일원 반복측정 화면 진입, 상단 데이터 메뉴 및 일원 반복측정 메뉴의 번역 사전 일치 검사를 추가했다. 6행 CSV를 올리고 남성 3행을 선택한 뒤 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 순서로 전환한다.

각 언어에서 같은 세션 유지, 활성 언어, 케이스 선택 3/6, 회귀와 일원 반복측정의 실제 화면 및 실행 버튼 표시, 데이터 단계 제목, 비어 있는 결과 화면의 안내, 상단/분석 메뉴 문구를 검사한다. JavaScript pageerror도 수집한다.

메뉴 문구 검사 초안은 JSON에 없는 영어·한국어 기본 라벨을 읽어 타임아웃이 발생했다. 실제 추가 6개 언어의 표시값은 일치했다. `R/labels.R`의 영어·한국어 기본 문구를 검사에 반영했다. 이 실패를 제품의 메뉴 번역 결함으로 분류하지 않는다.

최종 검사 전체 통과. 세션 유지, 3/6 케이스 선택, 회귀·일원 반복측정 화면 표시, 메뉴 및 데이터/결과 안내 문구가 일치했고 pageerror는 없었다. 로그: `tmp/language-ui-test.log`. 이번에 새로운 제품 결함은 확인하지 않았다.

한계: 일원 반복측정의 분석을 이 브라우저 검사에서 실행한 것은 아니다. 변수 배정·옵션 유지, 파일 분할, 이미 계산한 현재/누적 결과의 언어 왕복은 별도 검사 대상이다. 모든 메뉴의 글자와 시각적 배치를 검사한 것도 아니다. 제품 코드를 바꾸지 않고 검증 범위만 확대했으므로 5종 내보내기는 재생성하지 않는다.
