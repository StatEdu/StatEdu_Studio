# 생존 설정 화면 점검 시작

## 후보 목록

기존 정적 검사에서 생존 설정 파일의 후보 사용 위치를 함수별로 정리했다. 목록은 `MULTILINGUAL_SURVIVAL_SETUP_CHECKLIST_20260917.csv`이다. 합계는 사용 위치 기준이며 고유 원문 후보 138개와 동일한 집계가 아니다. 후보가 모두 실제 누락이라는 뜻도 아니다.

사건 코드 매핑은 한국어 외 언어에 영어를 직접 반환하는 경로를 확인해 수정했다. 다른 8개 항목은 후보 분류·실행 확인 전이므로 미완료로 표시했다.

## 수정 및 검사

- 사건 코드 매핑의 안내 6개를 추가 6개 언어 사전에 등록했다.
- 역할 선택지는 기존 사건 역할 번역을 재사용했다.
- `scripts/validate_survival_event_map_ui_i18n.R`: 8개 언어 통과.
- 빈 화면 안내, 제목, 역할 선택지, 라벨 placeholder, 확인 문구를 검사했다.
- 내부 역할 값과 컨트롤 ID, 0/1의 기본 역할, 미확인 체크 상태를 보존했다.
- 원자료 값·입력 라벨 `Review`, `Normality`, `None`, `사용자 <&> %s` 보존 확인.

이번 검사는 생성 UI 검사이며 실제 브라우저에서 편집 후 언어를 왕복한 검사는 아니다. 분석 출력은 변경하지 않았으므로 새 결과 저장 파일을 만들지 않았다. 설치본은 만들지 않았다.
