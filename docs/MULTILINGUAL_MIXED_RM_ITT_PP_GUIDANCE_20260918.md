# ITT와 PP 참고 결과가 함께 나오는 안내 번역

## 변경

완전 사례 반복측정 ANOVA와 ITT LMM이 함께 산출되는 경우의 안내 3개를 8개 언어에 반영했다.

- 적합된 LMM을 ITT 혼합모형 결과로 사용한다는 안내.
- 이용 가능한 반복 기록은 ITT 혼합모형에 사용하고 완전 사례 ANOVA는 PP 참고 결과로 남긴다는 설명.
- 하나 이상의 반복측정 셀에서 정규성 문제가 표시되었다는 설명.

한국어 전용 변환과 외국어 결합 문장 처리도 보완했다. 분석 대상, 결측 처리, 통계 계산은 변경하지 않았다. 여기서 ITT·PP는 기존 프로그램의 분석 경로 명칭을 그대로 따른다.

## 검증

`validate_mixed_rm_itt_pp_guidance_i18n.R`: 60명·2집단·공변량·3시점 자료에서 6개 관측값을 결측으로 설정했다. 실제 완전 사례 ANOVA와 ITT LMM이 모두 산출되고 정규성 문제가 표시되는지 확인한 뒤 3개 안내의 출현을 검사했다.

- 보완 전 한국어 및 6개 외국어 사전 검사 실패를 재현했다.
- 보완 후 8개 언어에서 두 단독 안내와 결합된 정규성 설명의 표시 확인.
- 영어 본표의 언어 간 동일성, 결과 객체, 안내문과 같은 철자의 사용자 변수명 보존 검사 통과.
- 기존 완전 사례가 없는 ITT 결과의 6개 안내 및 추가 안내·결합 설명 회귀 검사 통과. `validate_i18n_contract.R` 및 변경 공백 검사 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 검사와 PDF 텍스트 보존 검사 통과. 두 언어 모두 현재 PDF 7쪽·누적 13쪽이다.
- `validate_longitudinal_count_exports.R` 및 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이고 본문은 이번 ITT·PP 참고 결과 캡처다. 저장 단계에서 분석을 재실행하지 않았다. 산출물: `tmp/mixed-rm-itt-pp-guidance-i18n/exports`.
- 문서 앱별 수동 시각 검토는 수행하지 않았다.

기존 매개·조절효과 화면은 제외했다. 이번 검증은 LMM 경로이며 다른 GLMM 안내 전체의 완료를 의미하지 않는다. 설치본 빌드는 수행하지 않았다.
