# Start-stop 단일 구간 대상자의 불필요한 비교 생략 — 2026-09-14

`survival_preflight()`의 대상자별 start-stop 구간 검사에서 비교 가능한 구간이 하나뿐이면 정렬·겹침·사건 이후 구간·다중 사건 검사를 건너뛰도록 변경했다. 해당 검사는 비교할 구간이 둘 이상일 때만 이슈를 추가할 수 있다.

앞서 수행하는 시간 유효성, 시작/종료 순서, 대상자 ID, 사건 매핑 검사는 유지한다. 복수 구간 대상자의 검사와 전체 분석 자료 정렬도 그대로 수행한다. 제외 규칙이나 안내 내용은 변경하지 않았다.

## 전체 입력 검증 시간

대상자 1만 명의 합성 start-stop 자료를 사용했다. 대상자당 구간은 1개 또는 2개이며 조건별 총 행 수는 각각 1만·1만5천·2만이다. 번들 R 4.5.3의 새 프로세스에서 모듈·설정 로딩 후 각 조건을 같은 순서로 측정했다. 프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍의 변형 순서를 뒤집었다. 함수는 같은 전역 도우미 환경을 사용했다.

| 대상자 구성 | 변경 전 중앙값(초) | 변경 후 중앙값(초) | 감소율 |
| --- | ---: | ---: | ---: |
| 모두 단일 구간 | 0.50 | 0.29 | 약 42% |
| 단일/복수 구간 각 50% | 0.45 | 0.34 | 약 24% |
| 모두 복수 구간 | 0.52 | 0.52 | 차이 없음 |

| 반복 | 모두 단일 전/후 | 혼합 전/후 | 모두 복수 전/후 |
| --- | --- | --- | --- |
| 1 | 0.50 / 0.28 | 0.45 / 0.34 | 0.52 / 0.51 |
| 2 | 0.50 / 0.30 | 0.45 / 0.35 | 0.52 / 0.53 |
| 3 | 0.50 / 0.29 | 0.44 / 0.34 | 0.53 / 0.52 |

위 값은 입력 검증 전체 시간이다. 최초 실행 비용과 조건별 행 수가 다르므로 조건끼리의 시간 차이를 해석하지 않고 각 조건의 변경 전후만 비교한다. Cox 모형 적합, 일반 단일기록 생존분석 및 프로그램 시작 시간의 개선율은 아니다.

## 검증

- `scripts/validate_survival_single_interval.R`: 48개 기존 입력 검증 사례의 전체 결과/오류, 조건 및 RNG 상태 일치.
- `verify_intervals.R`: 단일/혼합/복수 구간, 잘못된·겹치는·원래 순서가 뒤섞인 구간, 사건 및 공변량 결측을 포함한 40개 추가 사례의 전체 결과, 경고·메시지와 RNG 일치.
- 대용량 9쌍의 전체 입력 검증 반환값을 `identical(..., num.eq = FALSE)`로 비교하여 통과했다.
- `verify_integrated.R`: 150명 혼합 구간 자료의 실제 start-stop Cox 분석에서 입력 검증, 모든 데이터프레임 결과, 회귀계수·분산·로그우도, 조건과 RNG가 정확히 동일했다.
- 전체 Cox 결과 패널 HTML과 개별·누적 Excel을 비교했다. 시트 이름과 값, 모든 비-core 내부 파일이 동일했고 core도 생성·수정 시각만 정규화하면 동일했다.
- `git diff --check -- R/analysis_survival.R` 통과.

분석 결과와 출력 내용은 유지한다. PDF/Word/HWPX 완성 파일과 설치 파일은 이번에 재생성하지 않았다.
