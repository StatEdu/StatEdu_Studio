# 상관분석 그래프 오류 안내 번역

## 변경

상관분석 그래프 함수의 영어 고정 안내 3개를 8개 언어 사전에 연결했다.

- 연속형 변수가 2개 미만인 산점도
- 상수 변수를 제외한 뒤 그릴 변수가 부족한 산점도 행렬
- 행렬 자료가 없는 히트맵

통계 계산과 정상 그래프의 축·제목·변수 라벨은 변경하지 않았다. 12개 표시 제한 안내인 `Showing first …`는 확인했으나 이번 수정 범위에는 포함하지 않았다.

## 검증

`validate_correlation_plot_errors_i18n.R`에서 각 조건을 만족하는 최소 입력을 실제 그리기 함수에 전달했다. 8개 언어 × 3개 분기에서 graphics::text.default에 전달된 문구를 확인하고 PNG를 생성했다. 입력 객체가 보존되는지도 확인했다. 정상 분석 성공 사례가 아니라 오류 표시 분기 검증이다.

최초 테스트의 사용자 지정 글꼴 이름 경고는 테스트를 기본 sans 글꼴로 수정해 해소했다. 제품의 글꼴 설정은 변경하지 않았다. 기존 그래프 이미지 캐시 검사, 번역 계약 검사, 변경 경로의 git diff --check도 통과했다.

## 저장 검사

실제로 그린 한국어·일본어 PNG 3개를 캡처하여 현재/누적 HTML·PDF·DOCX·HWPX·XLSX로 저장했다. `validate_correlation_plot_error_images.py`에서 HTML의 원본 이미지 데이터 일치와 PDF 본문·DOCX·HWPX·XLSX의 포함 이미지 RGB 픽셀 해시 일치를 확인했다. 모두 통과했다. 단순 PDF 텍스트 검색으로 이미지 내부 글자를 검증했다고 주장하지 않는다.

한국어·일본어 현재 PDF의 2쪽을 렌더링하여 세 안내 문구가 잘리지 않고 보이는 것도 직접 확인했다. 문서 앱별 수동 검토는 수행하지 않았다. 산출물은 `tmp/correlation-plot-errors-i18n/exports`에 있다.

공용 저장 검사 재사용으로 표지 제목은 Longitudinal이며 본문 영문 소제목은 검증 사례 식별자이다. 이는 테스트 구성이고 제품의 제목 변경이 아니다. 내보내기 중 그래프를 다시 그리지 않고 캡처한 PNG를 사용했다. 기존 매개·조절효과 화면은 제외했으며 설치본 빌드는 하지 않았다.
