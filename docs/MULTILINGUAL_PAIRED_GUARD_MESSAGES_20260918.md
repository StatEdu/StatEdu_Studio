# 대응표본 제외 사유 표시 및 번역 보완

후속 해결: 아래 별도 발견 항목은 `MULTILINGUAL_NONPARAMETRIC_TIES_WARNING_20260918.md`에서 원인을 확인하고 수정했다. 중복 값 번역으로 경고 문장이 검정명으로 바뀌던 문제였으며, 대응표본 회귀 검사도 최종 통과했다.

## 수정

실제 대응표본 결과에서 비한국어의 경고·제외 사유가 빈칸으로 표시되는 문제를 재현했다. `paired_appendix_localize_values`가 값뿐 아니라 Warning/Reason 등의 열 이름도 먼저 번역해, 이후 진단 행 정규화 함수가 해당 열을 찾지 못했다. 값 번역 단계에서는 원래 필드 이름을 유지하고 최종 렌더링 단계에서 열 이름을 번역하도록 수정했다.

다음 제외 사유 3개를 8개 언어 사전에 추가했다.

- 완전한 대응 사례가 최소 2개 필요함.
- 모든 대응 차이가 0이어서 검정을 수행하지 않음.
- 대응 차이의 분산이 0이어서 대응표본 t 검정을 수행하지 않음.

계산 코드는 변경하지 않았다. 다른 정적 번역 후보 전체를 이번에 처리한 것은 아니다.

## 통과한 검증

- `validate_paired_guard_messages_i18n.R`: 정상 쌍과 각 제외 쌍을 함께 실제 분석한 결과 3종을 사용했다. 8개 언어의 전체 결과 패널에서 사유 문구 표시, Review/Normality 사용자 이름, 영어 본표 동일성, 원본 결과 객체 보존을 확인했다.
- 수정 전 일본어 진단 메시지 빈칸을 재현했고 수정 후 통과했다.
- `validate_i18n_contract.R`: 통과.
- 세 결과 패널을 캡처해 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검사를 통과했다. 저장 중 분석은 재실행하지 않았다.
- PDF 캡처 텍스트 보존 검사 통과. 산출물: `tmp/paired-guard-messages-i18n/exports`.

## 별도 발견한 미해결 항목

범위를 넓혀 실행한 `validate_paired_guards.R`는 비모수 대응표본의 한국어 Wilcoxon 동률 경고 검사에서 실패했다. 렌더링된 셀에는 비모수 검정명은 있지만 동률 경고 문장이 없었다. 이 경로는 `result_nonparametric_paired_ui.R`에서 경고를 별도 coefficient 표로 출력한다. 이번에 수정한 비한국어 필드 이름 보존 분기와 다른 한국어 출력 경로이며, 전체 대응표본 회귀 검사가 통과했다고 보고하지 않는다. 후속 작업에서 이 비모수 경고 표시 문제를 우선 처리한다.

문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙은 유지한다.
