- 추가 적합도 표의 언어를 기존 한국어/영어 분기에서 명시적인 UI 언어 전달로 변경했다. 기존 함수의 `ko` 인수 호출은 호환된다.

- 공통 내보내기 내용 검사에 h6 지표군 제목을 추가했다.

- 지표군 제목, 보정/강건/신뢰구간 열 이름의 번역과 보조표 언어 속성, 증분/RMSEA/잔차 지표군의 가로 방향 패널 설정을 확인했다.
