# 경쟁위험 분석 개요

Value 열에서 사용자 원점·단위·사건 코드·집단 변수·검열분포 층 변수·수치·패키지를
보존한다. 프로그램이 생성하는 미선택/통합 표시와 방법명만 미리 번역한다.
관심 사건 수, 검열분포 층, 통합, CIF 방법명 두 종류의 번역 5개 항목을 보완했다.
실제 결과 패널에서 개요 생성 함수에 UI 언어를 전달한다.

## 검증

- `validate_competing_overview_i18n.R`: 실제 경쟁위험 분석을 집단 없음/sex 집단 두
  경우로 수행하고 8개 언어로 개요를 검사했다.
- 표시용 복사본에서 Review, Normality, None, Pooled, 사용자 <&> %s 설정값 보존 확인.
  본 표의 시점별 CIF 출력은 영어 및 동일 값 유지.
- 기존 Kaplan–Meier·생명표 개요 회귀 검사 통과.
- 일본어 현재 4개 / 누적 5개 개요 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서 및 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 기타 경쟁위험 보조표 전체를 검증한 것은 아니다.
