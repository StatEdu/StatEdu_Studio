# 회귀 모형 요약 재사용 검토 — 미적용 — 2026-09-14

## 검토 및 결정

`prepare_single_regression_result`는 R² 등을 위해 `summary(model)`을 계산한 직후 `regression_model_test` 안에서 같은 요약을 다시 계산한다. 두 번째 호출에 이미 구한 요약을 전달하는 후보를 시험했다. 결과는 동일했지만 전체 시간에서 일관된 개선이 없고 요약 함수 자체의 비용도 작아 제품에는 적용하지 않았다.

후보는 `regression_model_test`의 기본 요약 동작을 유지하면서 선택적 요약 인자를 받도록 한다. 첫 요약에서 경고/메시지가 발생하면 기존처럼 두 번째 요약도 실행하여 완전 적합 등의 조건 발생 횟수를 유지한다. 효과크기 함수나 패키지 내부의 다른 요약 호출까지 통합한 변경은 아니다.

## 전체 분석 시간

번들 R 4.5.3, 2,000행, 예측변수 12개, 종속변수 4개, 시드 714, 일반 OLS, 잔차 진단 활성화 조건이다. 자동 강건 추정은 끄고 부트스트랩 작업이 없음을 확인했다. 단일 모형 비교는 종속변수 하나를 사용했다. 공통/개별 결측은 종속변수당 200행이다.

버전별 새 프로세스 세 개를 순차 실행했고 두 번째 비교는 후보부터 실행했다. 조건별 준비 실행 후 전체 분석 5회를 측정했다. 로딩·자료 생성·화면·저장은 제외했다. 다른 R 작업을 동시에 실행하지 않았다.

| 조건 | 기존 3회(초, 각 5분석) | 후보 3회(초, 각 5분석) |
| --- | --- | --- |
| 완전 자료 | 1.03 / 0.89 / 0.88 | 0.95 / 0.94 / 0.88 |
| 공통 결측 | 1.31 / 1.09 / 1.09 | 1.22 / 1.17 / 1.10 |
| 서로 다른 결측 | 1.87 / 1.59 / 1.56 | 1.61 / 1.73 / 1.58 |
| 단일 종속변수 | 0.47 / 0.37 / 0.40 | 0.44 / 0.43 / 0.41 |

첫 비교에서는 후보가 빨랐지만 이후 비교에서는 대체로 같거나 조금 느렸다. 각 조건의 후보 중앙값도 기존보다 작지 않았다. 환경 변동을 고려해 안정적인 성능 저하율을 주장하지 않지만, 이번 후보를 적용할 시간상의 근거는 확인하지 못했다.

## 요약 함수의 개별 비용

전체 시간 측정 후 별도 고정 모형(2,000행·예측변수 12개)의 `summary`를 준비 실행한 뒤 1,000회씩 세 번 측정했다. 0.15/0.12/0.12초, 중앙값 기준 호출당 약 0.12밀리초였다. 이는 고정 모형의 반복 측정이며 전체 분석 절감량을 직접 측정한 값은 아니다. 4개 모형에서 한 번씩 생략할 수 있는 작업의 규모도 작다. 메모리 최고 사용량은 별도로 측정하지 않았다.
