# 로지스틱 회귀 설정 다국어 점검

2026-09-16. 설치본은 만들지 않았다.

- 직접 영어를 출력하던 모형 옵션 제목, 미선택 안내, 이분형/순서형/다항 모형 종류 설명을 번역했다. 여러 유형을 동시에 선택한 경우 각각 번역해 결합한다.
- 종속변수 및 블록 1 미선택의 실제 분석 검증 오류를 실패 알림에서 UI 언어로 변환한다. 미등록 외부 오류는 그대로 보존한다.
- 모형 종류 함수는 기존 기본 호출의 영어 반환을 유지하고 설정 화면에서만 언어를 명시한다. 선택값, 변수명 및 분석 결과 생성 코드는 변경하지 않았다.
- `scripts/validate_logistic_setup_i18n.R`: 8개 언어의 생성 HTML, 혼합 모형 설명, 사용자 변수명/선택값 보존, 실제 미선택 오류 검사 통과.
- `scripts/validate_i18n_contract.R`: 통과.
- 기존 `scripts/validate_logistic_ui.R`는 설정 UI 검사 이후 한국어 보조표의 수렴 상태 검사에서 실패했다. 기대 문구는 `수렴함`, 실제 문구는 `수렴 여부`다. 이번에 수정하지 않은 보조표 번역 경로이며 후속 수정 대상이다. 기존 검사 전체 통과로 보고하지 않는다.
- 이번 변경은 설정 UI/실패 알림만 대상으로 하므로 결과 내보내기는 재검증하지 않았다. 본표 영문 계약과 보조표의 실제 출력·내보내기 검증은 후속 점검이 필요하다.
