# 범주 라벨 스냅샷의 기준 라벨 갱신

2026-09-15. `R/data_category_labels.R`의 `apply_category_label_snapshot()`에서 저장 표의 기준값을 범주값과 대조하는 처리를 일괄화했다. 개별 편집값 적용과 새 변수 추가는 기존 코드로 실행한 뒤, 아직 일치하지 않은 행만 다음 범주 열과 비교한다. 첫 번째 일치 범주의 라벨을 사용하며 일치하지 않거나 기준값이 비어 있으면 빈 라벨을 사용한다. 실제 라벨이 달라진 행만 갱신하고 `changed`에 반영한다.

속성 없는 일반 문자 벡터이며 결측값이 없는 기준값·기준 라벨·범주값·범주 라벨 열, 일반 data.frame, 정상적인 양의 정수 범주 쌍 개수에만 적용한다. 나머지는 기존 행별 반복문으로 처리하여 변환과 진단 순서를 유지한다. 분석 수식과 스냅샷의 반환 구조는 변경하지 않았다.

## 검증

기준 코드: `scripts/fixtures/category_snapshot_reference.R`.

`scripts/validate_category_snapshot_batch.R`에서 저장 표 전체와 속성, `changed`, `var_label_updates`, 경고/메시지/오류, stdout, RNG를 `identical(..., num.eq=FALSE)`로 비교했다.

- 294개 조건 통과: 0/1/12/100행, 범주 쌍 1/3/11개, 편집 및 새 변수 추가 유무, 중복 범주값, 결측값, factor/numeric/named/list/matrix 열, 기존 라벨 일치, 빈 기준값, 비정상 쌍 개수.
- 같은 표 재저장 1개 및 UTF-8/Latin-1 혼합 비교 4개 통과. 최종 블록 정리 후 총 299개 재검증 통과.
- `validate_codebook_import.R`: 코드북 Excel 읽기·변수 매칭·범주 표 구성·라벨 조회 및 잘못된 코드북 오류 검사 통과.
- `validate_category_label_role.R`: 표 반환/진단 240개 및 한영 고정 ID HTML 2개 통과.

## 성능

`scripts/benchmark_category_snapshot_batch.R`를 독립 R 프로세스 3개에서 순차 실행했다. 양쪽 함수를 동일하게 컴파일하고 사전 호출 후 순서를 교대하여 조건별 3회 중앙값을 기록했다. `Sys.time()`으로 스냅샷 처리 전체와 진단 수집 시간을 측정하고 모든 측정 반환값도 기준과 정확히 비교했다.

입력은 11개 범주 쌍을 가진 표이며 기준값은 첫 범주, 마지막 범주, 불일치, 빈 문자열을 반복한다. incoming은 빈 목록으로 고정해 기존 표의 기준 라벨 정리 비용을 측정했다. 변경 조건에서는 기준 라벨을 비워 두고, 무변경 조건에서는 기존 함수로 이미 정리한 표를 사용했다.

이 조건에서는 약 99% 이상 단축됐다. 실행별 절대 시간 차이가 있어 범위와 모든 중앙값을 함께 기록했다. 500행 측정도 CSV에 포함했다. 이는 메모리 안의 저장 데이터 정리 시간이며 브라우저 이벤트, 실제 파일 쓰기, 전체 로딩, 분석 계산 또는 내보내기 시간의 개선율은 아니다. 실제 브라우저 저장 상호작용과 PDF/Word/HWPX 검사는 이번 변경에 포함하지 않았다.
