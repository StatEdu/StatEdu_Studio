# 비모수 반복측정 방법 안내의 한국어 누락 수정

## 변경

비모수 반복측정 개요에서 측정수준을 삽입하는 `%s nonparametric repeated-measures test` 호출에 한국어 기본 문구가 빠져 있었다. 한국어 사전 값은 존재하지만 해당 번역 함수의 한국어 경로는 전달된 기본 문구를 사용하므로 영어가 섞일 수 있었다. 호출에 `%s 비모수 반복측정 검정`을 명시했다.

사전과 분석 계산은 변경하지 않았다. 다른 언어는 기존 번역을 유지한다.

## 검증

- `validate_nonparametric_rm_guidance_i18n.R`: 연속형·순서형·이분형 자료를 각각 실제 비모수 반복측정 분석에 입력했다. 결과의 측정수준이 Continuous/Ordinal/Binary인지 확인했다.
- 3개 측정수준 × 8개 언어 = 24개 전체 결과 패널에서 방법 안내가 실제 부록 셀에 있는지 검사했다.
- 영어 안내 잔존 방지, 사용자 변수명 Review/Normality, 영어 본표 동일성 및 원본 결과 객체 보존 검사 통과. Ordinal처럼 원문과 동일한 철자가 정상인 언어는 오류로 분류하지 않았다.
- `validate_paired_guards.R`, `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/nonparametric-rm-guidance-i18n/exports`. 실제 패널 캡처를 저장하며 분석을 재실행하지 않는다. 언어별 안내 목록은 같은 상위 폴더의 `guidance.csv`에 기록했다.

## 범위

이번 작업은 측정수준별 방법 안내에 한정한다. 서로 다른 측정수준을 한 결과에 합친 모든 조합이나 복원 결과 전체를 검증한 것은 아니다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙을 유지한다.
