## 그대로 적용하면 안 되는 경우

반응열마다 결측 행이 다르면 일괄 `lm`은 결측 행의 합집합을 제거한다. 20행의 두 반응에서 각각 첫째·둘째 행만 결측으로 둔 재현 예는 개별 분석 자유도 17을 일괄 분석에서 16으로 바꾼다. 따라서 무조건적인 일괄화는 결과 불변 조건을 만족하지 않는다. 실제 분석 호출 경로의 완전 사례 처리도 적용 전에 확인해야 한다.

제품 통합 전에는 공통 관측행 조건을 검증하고, 조건 미충족 시 기존 개별 경로를 사용해야 한다. 경고·오류·난수 상태 및 사용자 지정 contrasts/na.action 처리, 전체 결과와 실제 분석 시간도 별도 검증해야 한다. 현재는 이 검증을 마친 제품 최적화가 아닌 실험 후보로 보관한다.
