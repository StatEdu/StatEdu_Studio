# 원인별 Cox 비례위험·영향력 경고

Schoenfeld 검토 대상과 영향력 검토 계수 행 수의 근거·안내 4개 항목을 6개 추가
언어로 번역했다. 변수명과 건수는 번역 후 원문 그대로 유지한다. 경고 기준은 변경하지 않았다.

## 검증

- `validate_cause_specific_diagnostics_i18n.R`: 실제 경쟁위험 결과의 진단 정보를
  표시 검사용으로 구성했다. p=.05/.01/NA 및 영향력 신호 없음/2건을 8개 언어로 검사했다.
  이 조건별 회귀 모형을 새로 적합한 검사는 아니다.
- 경고 대상 변수 선택, 특수문자·건수 보존, 실제 CIF 본 표 영어 유지 확인.
- 원인별 검정 실패 경고 회귀 검사 통과.
- 일본어 현재 1개 / 누적 2개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 원인별 Cox 공선성과 Fine–Gray 안정성 경고는 점검이 남아 있다.
