# 생존분석 입력·실행 전 알림 재점검

최근 번역 보완 이후 기존 입력·알림 검증 8개를 다시 실행했다. 모두 종료 코드 0으로 통과했으며 이번 범위에서 새 번역 누락은 발견되지 않았다. 제품 코드와 번역 사전은 변경하지 않았다.

## 검사 결과

모든 검사는 영어·한국어·일본어·중국어·스페인어·프랑스어·독일어·베트남어를 대상으로 한다.

| 검사 스크립트 (`scripts/`) | 검증 내용 |
| --- | --- |
| `validate_survival_preflight_notifications_i18n.R` | 실제 차단 자료 사례 15개, 차단 알림 번역, 원본 점검 결과 및 외부 문구 보존 |
| `validate_survival_setup_issues_i18n.R` | 등록된 설정 문제 24개, 미등록 문구 보존, 실제 시간·사건 역할 누락과 렌더링된 권고 패널 |

## 해석과 한계

- 실행 알림 검사는 Shiny 테스트 서버에서 분석·파일 저장 함수를 대체해 알림 전달과 경로 보존을 검사한다. 실제 파일 저장 또는 전체 GUI 클릭 검증은 아니다.
- 입력 오류 검사는 실제 검증 오류와 소스의 실패 콜백을 사용한다. 설정 UI 검사는 생성된 HTML 및 조건부 표시 식을 비교하며 브라우저 상호작용 전체를 검증하지 않는다.
- 제품 출력 변경이 없으므로 이번에는 5개 형식 저장을 재생성하지 않았다. 전체 프로그램 번역 완료를 의미하지 않는다.
- 기존 매개·조절효과 패널은 계속 제외한다. 설치본 빌드는 수행하지 않았다.

## 근거와 다음 범위

각 로그는 `tmp/survival-<검사명>-recheck.log`에 저장했다. 검사명은 위 파일의 `validate_survival_`와 `_i18n.R` 사이 문자열이다.

직전 결과 안내·오류 재점검은 `MULTILINGUAL_SURVIVAL_GUIDANCE_RECHECK_20260918.md`에 기록되어 있다. 후속 작업은 생존분석 결과 표의 동적 셀·모형별 진단 분기를 중심으로 범위를 넓힌다.
