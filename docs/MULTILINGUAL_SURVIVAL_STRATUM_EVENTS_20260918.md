# KM 진단 근거의 사건 수 번역과 집단명 보존

## 재현 및 수정

사건이 5건 미만인 집단의 안정성 표에서 안내 문장은 번역됐지만, 근거 셀의 `집단명: events = 3`은 한국어 외 비영어 언어에서 영어로 남았다. 또한 한국어의 첫 번째 문자열 치환 방식은 사용자 집단명에 `: events = `가 들어 있으면 이름 내부를 바꿀 수 있었다.

`survival_stability_evidence_text`에서 마지막에 붙은 사건 수 접미사만 분리하고, 집단명과 수치를 번역 템플릿의 인자로 전달하도록 수정했다. 8개 언어에 `%s: events = %s` 번역을 추가했다. 형식이 맞지 않는 외부 문구는 그대로 유지한다. 분석 계산은 변경하지 않았다.

## 검증

- 수정 전 집단명 충돌 검사 실패를 재현했다.
- `validate_survival_sparse_km_i18n.R`를 확장했다. 집단별 사건 3건의 실제 KM 결과로 8개 언어의 사건 수 접미사 번역, 실제 렌더링 셀, 전체 결과 패널, 영어 본표 동일성 및 원본 결과 보존을 확인했다.
- 실제 집단명 `Review: events = 99`를 사용해 마지막 접미사만 번역되는지 확인했다. 헬퍼 검사에는 Normality, 한글·HTML 특수문자·`%s`·개행이 포함된 이름과 미등록 외부 문구도 포함했다.
- `validate_i18n_contract.R`: 통과.
- `validate_cox_estimability_warnings_i18n.R`: 진단 신호를 설정한 Cox 추정 가능성 경고 분기 및 사용자 이름·영어 본표 보존 검사 통과.
- `validate_fine_gray_optimizer_table_i18n.R`: 실제 Fine–Gray 적합과 상태 플래그 변경 사례에서 8개 언어의 진단표 제목·상태·수치·영어 계수표 보존 검사 통과.
- 한국어·일본어 안정성 표의 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검증 통과. PDF는 각각 현재 2쪽, 누적 3쪽에서 모든 캡처 텍스트 보존을 확인했다.
- 저장 산출물: `tmp/survival-stratum-events-i18n/exports`. 화면 캡처 HTML을 사용하며 저장 과정에서 분석을 재실행하지 않는다.

## 범위

저장 검사는 수정한 안정성 표와 제목에 한정한다. 전체 생존분석의 그림·모든 모형별 분기를 이번에 다시 검증한 것은 아니다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 패널 제외 원칙은 유지한다.
