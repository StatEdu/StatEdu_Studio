# 별도 분석·분할 결과 저장 오류 — 2026-09-17

일반/위계적 회귀, 상관, 교차표, 요인분석, 빈도, 평가자 간 일치도, 비모수, PCA, 신뢰도, t검정/ANOVA의 10개 서버 파일에서 HTML/PDF/분석 저장 실패 알림 33곳에 기존 오류 번역 함수를 연결했다. 분할 결과 저장의 공통 오류 알림 1곳에도 연결했다. 이 연결은 기존 7종 앱 오류 및 PDF 로그 첫 줄을 번역하며 외부 오류 상세와 경로를 유지한다. 계산·보고서 작성 함수는 변경하지 않았다.

검증:
- `validate_separate_export_errors_i18n.R`: 소스 AST에서 실제 tryCatch 오류 콜백 34개를 찾아 실행했다. 8개 언어에서 앱 오류 7종, PDF 상세 로그, 외부 오류 알림을 검사했다. 저장 버튼부터의 전체 통합 실행 검사는 아니다.
- `validate_current_export_errors_i18n.R`, `validate_collection_export_errors_i18n.R`: 통과.
- `validate_analysis_scope.R`: UTF-8 로캘로 실행하여 케이스/분할의 원본 보존, 그룹별 계산·순서·비동기 대기, 일반/위계적 회귀 그룹별 기울기 회귀 검사 통과.

별도의 오류 처리기를 가진 다른 분석 화면, 그림 저장 관련 고유 오류, 분할 결과의 '저장할 그림 없음' 및 미지원 형식 안내는 이번 7종 번역 연결만으로 해결되지 않으므로 후속 점검 대상이다. 전체 화면 또는 실제 내보내기 전수 검증 완료가 아니다. 설치본은 생성하지 않았다.
