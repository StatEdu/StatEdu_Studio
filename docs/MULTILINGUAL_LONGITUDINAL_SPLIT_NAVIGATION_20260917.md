# 종단 파일 분할 결과의 언어 갱신

두 집단으로 분할한 GEE 결과가 언어 변경 후에도 한국어 보조표를 유지하는 문제를 실제 앱에서 재현했다. 일반 결과와 달리 분할 결과는 공통 스냅샷을 표시하므로 종단 모듈을 `scope_localization_factories`에 연결했다.

집단별로 이미 적합된 결과와 당시 변수표·라벨·범주 정보를 캡처한다. 언어 변경 시 기존 공통 경로가 보조표 섹션만 교체한다. 분석 재실행, 본표 재작성, 기존 누적 결과 변경은 하지 않는다.

검증:

- `STATEDU_TEST_SPLIT=1`로 `validate_longitudinal_result_navigation_browser.cjs` 실행. 별도 프로필 실제 앱에서 합성 CSV 120행을 A/B 두 집단으로 분할하고 GEE Gaussian 실행.
- 8언어에서 본표 2개 셀 전체가 초기 영어 본표와 동일함을 확인. 각 집단의 가정 점검·상세 계수·권고 분석 제목이 해당 언어로 바뀌고 기존 누적 iframe 스냅샷은 그대로 유지됨을 확인. JavaScript 오류 없음.
- 언어 변경 중 상위 메뉴 재생성으로 일시적으로 활성 메뉴와 결과 루트가 없어져 첫 복귀가 실패할 수 있었다. 검사에서는 재구성 대기 후 최대 4회 재방문한다. 이것을 메뉴 전환 문제 자체의 수정으로 주장하지 않는다.
- 캡처는 `tmp/longitudinal-split-navigation/captured.json`. 내보내기 검사는 이 HTML을 재사용하며 모형을 다시 적합하지 않는다.
- 한국어·일본어의 현재/누적 결과 모두 HTML·PDF·Word·직접 HWPX·Excel 내용 보존 검사 통과. PDF 4개도 캡처 텍스트 검사 통과(현재 각 21쪽, 누적 각 41쪽). 페이지별 시각 검수는 하지 않았다. 기존 보조변수 복원/해제 서버 회귀 검사와 범위 내 `git diff --check`도 통과했다.

범위는 GEE 두 집단의 분할 결과다. 다른 모형·케이스 선택과의 결합 및 첫 클릭 메뉴 전환 안정성은 별도 범위다. 기존 factor 연산 경고는 관찰됐으나 통계 계산은 변경하지 않았다. 메타분석 제외, 설치본 생성 없음.
