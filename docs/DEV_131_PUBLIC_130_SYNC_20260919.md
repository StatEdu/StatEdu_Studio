# 1.3.1-dev: public 1.3.0 baseline synchronization

Reference: https://chatgpt.com/s/cx_6aae7807bc8c8191a9b72724190856bc

The developer edition continues public 1.3.0 and includes its fixes and documents.
Windows developer packaging reads `VERSION_DEV`; public packaging continues to
read `VERSION`. A developer build must preserve published public installers.
This synchronization does not publish a new public release or change the website.

## Inherited changes verified

- Eight-language overview, user guide, analysis methods, methodology notes,
  validation and version history (48 documents).
- Whole-program overview, four-block hierarchical regression documentation and
  public 1.3.0 release date of 2026-09-20.
- Language switching after loading data preserves the session, data, canvas
  models and source directory.
- Settings restoration preserves the original data filename and excludes old
  R session temporary directories from file-dialog defaults.
- Mediation/moderation, CFA, SEM and PLS-SEM canvas/result dialogs share the data
  directory; result export dialogs use the same directory resolver.
- Word/HWPX content options use one row when space permits and an aligned 2×2
  arrangement otherwise; selection and Select All still work.
- Information-page links, including IPA, resolve within the displayed document
  with headings visible below the navigation bar.
- Public-only restrictions on meta-analysis and one-group repeated measures
  ANOVA remain public-only. Developer features are retained.

## Additional developer fixes included

- When the `.studio` file and external data file are in different folders, use
  the actual data folder first. For embedded data with a temporary extraction
  path, fall back to the settings folder.
- Canvas exports omit validation badges, produce with/without-covariate figures,
  and omit covariate covariance/residual clutter while retaining outcome effects.
- Fit measures visible nodes, error terms, paths, labels and statistics, scales
  large models into the paper margins, and fits both paper dimensions to the view.
