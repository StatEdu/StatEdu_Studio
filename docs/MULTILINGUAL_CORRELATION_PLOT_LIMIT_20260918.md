# 상관분석 산점도 표시 제한 안내 번역

영어 고정 문구 `Showing first %s of %s plottable variables.`를 8개 언어의 `analysis.correlation.scatter_display_limit` 키로 연결했다. 한국어는 전체 변수 수를 먼저 표시하도록 위치 지정 서식을 사용한다. 기존의 처음 12개 변수 표시 규칙과 계산·그래프 내용은 변경하지 않았다.

## 검증

`validate_correlation_plot_limit_i18n.R`는 40행·13개 연속형 변수의 고정 난수 자료를 실제 산점도 함수에 전달한다. 8개 언어별로 12개 변수일 때 안내가 없고, 13개일 때 12/13 수치가 포함된 번역 안내가 그려지는지 graphics::mtext 호출과 PNG 생성으로 확인했다. 입력 데이터와 사용자 라벨 보존도 통과했다.

기존 그래프 오류 안내 3개 × 8개 언어 검사, 번역 계약 검사, 변경 경로의 git diff --check도 통과했다.

한국어·일본어 현재/누적 HTML·PDF·DOCX·HWPX·XLSX에 캡처 PNG를 저장하고 원본 이미지 데이터/픽셀 해시 보존을 확인했다. 공용 이미지 검사에 예상 이미지 수 인수를 추가했으며 기존 기본값 3개는 유지했다. 두 언어의 현재 PDF 2쪽을 직접 렌더링하여 12개 산점도 행렬과 상단 안내가 잘리지 않고 표시되는 것도 확인했다. 이미지 내 문구를 PDF 텍스트 추출로 검증했다고 주장하지 않는다.

산출물은 `tmp/correlation-plot-limit-i18n/exports`에 있다. 내보내기 중 그래프를 다시 그리지 않고 캡처 이미지를 사용했다. 공용 내보내기 검사 재사용으로 검증용 표지 제목은 Longitudinal이며 제품 제목 변경은 아니다. 문서 앱별 수동 검토 및 설치본 빌드는 하지 않았다. 기존 매개·조절효과 화면은 제외했고 전체 프로그램 번역 완료를 의미하지 않는다.
