# 메타분석 조절변수 문자열 처리 병목 — 2026-09-14

새 개선 후보는 동일한 범주형·연속형 조절변수 문자열 쌍의 해석 결과를 한 함수 실행 안에서 재사용하는 것이다. 이번에는 현재 비용을 측정했으며 운영 코드를 변경하지 않았다.

1,000개 연구에 범주형 문자열 `region=Asia`, `region=Europe`를 번갈아 배치하고 연속형 문자열은 `age=40`으로 고정했다. 실제 문자열 조합은 두 개다.

| 기능 | 경과 시간 3회(초) | 중앙값 | 문자열 해석 호출 |
|---|---|---:|---:|
| 조절변수 목록 생성 | 1.14 / 1.15 / 1.16 | 1.15초 | 매번 1,000회 |
| region 변수 추출 | 1.41 / 1.41 / 1.32 | 1.41초 | 매번 1,000회 |

첫 프로세스의 Rprof에서 `meta_parse_moderators`의 하위 호출 포함 비중은 목록 생성 약 71%, 추출 약 99%였다. 표본 비율은 실제 경과 시간 비율과 다르며 하위 함수 비율을 더하면 안 된다. 목록 생성은 해석 외에 긴 형식 표 생성도 수행한다.

번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 각 기능은 준비 실행 후 GC, 경과 시간 측정, 별도 0.01초 간격 프로파일을 수행했다. 다른 R 작업을 동시에 실행하지 않았다. 호출 횟수 계측 래퍼 비용은 포함했고 소스 로딩·자료 생성·화면·모형 적합·내보내기는 제외했다.

준비/측정/프로파일 결과와 세 프로세스 간 저장 결과가 `identical(..., num.eq=FALSE)`로 일치했다. 전체 반환값·경고/메시지 문자열·난수 상태를 비교했으며 허용오차는 사용하지 않았다. 이는 기존 코드의 반복 실행 동일성 검증이며 아직 최적화 후보의 동일성 검증은 아니다.

다음 후보 검증에서는 정확히 같은 두 문자열을 하나의 키로 취급하되, 단순 구분자 결합으로 다른 문자열 쌍이 충돌하지 않게 해야 한다. 결측·잘못된 문법·대소문자·중복 이름·문자 인코딩·비문자 입력의 동작과 행 순서를 보존해야 한다. 반복이 없는 자료에서는 재사용 준비 비용이 추가되므로 중복이 많은 자료와 모두 다른 자료를 함께 측정해야 한다. 전역 캐시를 추가하는 안은 검토하지 않았다.

현재 측정은 중복이 많은 합성 자료 한 조건이며 실제 사용자 자료의 분포를 대표한다고 가정하지 않는다. 아직 후보 개선율은 제시하지 않는다. `output/meta-moderator-profile-20260914/`에 재현 코드, 시간·프로파일 CSV, 원시 Rprof, 결과 RDS, 교차 비교 코드를 보관했다. 운영 소스·출력·설치 파일은 변경하지 않았다.
