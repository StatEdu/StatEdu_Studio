# 규제 회귀 부록 절편 번역

## 변경

규제 회귀의 부록 계수 비교표에서 `(Intercept)`가 영어로 남는 것을 보완했다. 분석 결과를 만들 때 사용자 예측변수 라벨과 충돌하지 않는 자동 생성 절편 행에 `penalized_intercept_rows` 속성을 기록한다. 부록 렌더러는 이 속성이 지정한 행에만 8개 언어 번역을 적용한다. 한국어 표기는 `(절편)`이다. 수치 계산식과 영어 본표는 바꾸지 않았다.

사용자 라벨이 `(Intercept)`와 같으면 자동 판별을 생략한다. 구분 속성이 없는 기존 저장 결과 역시 문자열만 보고 번역하지 않는다. 이 호환성 정책에 따라 일부 기존 결과에는 영어 표기가 남을 수 있다.

## 검증

`validate_penalized_intercept_i18n.R`는 60명·연속형 예측변수 2개의 실제 Ridge·LASSO·Elastic Net 분석을 8개 언어로 확인한다. 부트스트랩 2회와 검증 반복 1회는 출력 검사 목적이다.

- 실제 세 분석의 절편 행 표시 정보와 번역 확인.
- 영어 본표의 언어 간 동일성, 사용자 라벨 Gaussian·사용자 변수·Tested, 결과 객체 보존 확인.
- 구분 속성을 제거한 복원 결과의 원래 절편 표기 보존 확인. 실제 과거 저장 파일 검사는 아니며 직렬화 왕복 검증이다.
- 별도 사용자 행에 동일한 `(Intercept)` 라벨을 넣은 합성 충돌 사례에서 자동 생성 행만 번역하는지 확인. 이 합성 사례는 모형을 다시 적합한 결과가 아니다.

## 저장 결과

한국어·일본어 현재/누적 결과의 HTML·PDF·DOCX·HWPX·XLSX 저장과 표·제목 텍스트 보존 검사를 통과했다. PDF 텍스트 검사도 통과했으며 각 언어 현재 20쪽, 누적 39쪽이다. 산출물은 `tmp/penalized-intercept-i18n/exports`에 있다. 캡처한 실제 세 분석 결과를 사용했으며 저장 중 재적합하지 않았다.

공용 `validate_longitudinal_count_exports.R`를 재사용하여 검증용 표지 제목은 Longitudinal이지만 본문은 규제 회귀 결과이다. 영어 본표 동일성은 전용 검사에서 확인했다. `validate_i18n_contract.R`와 변경 경로의 `git diff --check`도 통과했다. 문서 앱별 수동 시각 검토는 하지 않았다.

기존 매개·조절효과 화면은 제외했다. 전체 프로그램 번역 완료를 의미하지 않으며 설치본 빌드는 수행하지 않았다.
