# 구조방정식 캔버스 공통 표시 다국어

## 수정

- CFA·SEM·PLS 화면/메뉴 제목, 관측·잠재변수 표기, 모형 작성 설명, 관측/잠재/고차요인 배치 및 공분산 모드, 오류·경고 개수의 11문구를 6개 추가 언어 사전에 연결했다.
- 초기 R 렌더링과 JavaScript 동적 표시 모두 같은 캔버스 번역 데이터를 사용한다. 오류·경고 개수는 이름 있는 자리표시자로 전달하며 기존 오류 강조 클래스를 유지한다.
- 본표에서 사용하는 `structural_analysis_title(type, 'en')`은 UI 언어와 무관하게 영어를 반환한다. 사용자 변수 이름·라벨 JSON은 변경하지 않는다.

## 검증

- `validate_structural_canvas_shell_i18n.R`: 3분석 × 8언어 렌더링, 실제 번역/초기 개수 표시, 사용자 변수 JSON 동일성, 영어 결과 제목 불변 검사 통과.
- `validate_structural_canvas_shell_js.cjs`: 실제 state/toolbar 모듈을 VM에 로드하여 8언어 배치/공분산 모드와 오류 2·경고 3 및 0·0의 동적 표시, 오류 클래스 갱신 검사 통과. private handler는 테스트 VM에서만 노출하며 제품 API를 추가하지 않았다.
- 공통 `validate_multilingual_coverage.R` 및 JavaScript 구문 검사 통과.
- UI 공통 표시만 수정했다. 본표 렌더링·통계 계산·내보내기 내용은 변경하지 않아 이번 수정에는 결과 5형식 저장 검사가 해당하지 않는다.

## 남은 범위

- 이번 검사는 R 렌더링과 JS 처리 함수 검사이며 실제 브라우저 전체 캔버스 편집 검사는 아니다.
- 도구모음 도움말, 선택 개수/용지 안내, 고급 옵션, 모형별 실제 분석/오류/언어 왕복은 추가 확인이 필요하다.
- 복합표본 사용자 모형 HWPX 시간 초과도 미해결이다. 설치본을 만들지 않았다.
