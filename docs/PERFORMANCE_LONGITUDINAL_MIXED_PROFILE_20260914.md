# 종단 LMM/GLMM 중복 적합 프로파일

## 결론

LMM과 GLMM 모두 선택 모형 1회와 민감도 분석 2회로 앱 적합 함수가 총 3회 호출된다. 민감도 분석의 첫 적합은 선택 모형과 같은 무작위 효과 구조를 사용한다. 이번 측정에서는 GLMM의 중복 적합이 LMM보다 비용이 커서 다음 재사용 검증 대상으로 선정했다. 이번에는 제품 코드를 변경하지 않았다.

무작위 기울기 GLMM에서 실제 singular fit 메시지가 발생했다. 따라서 단순 재사용으로 중복 메시지를 제거해서는 안 된다. 재사용 후보는 경고/메시지 및 RNG 변화가 없는 선택 모형부터 검증해야 한다. 기존 GEE 최적화는 유지한다.

## 측정 방법

번들 R 4.5.3, seed 939, 500명 × 6시점 = 3,000행, 연속 공변량 2개. 자료 생성에는 무작위 절편과 무작위 기울기를 포함했다. LMM에는 연속 반응, GLMM에는 이항 반응을 사용하고 각 분석에서 random_slope FALSE/TRUE를 비교했다. 그 외 기본 분석 옵션과 가정 검토를 사용했다.

독립 R 프로세스 3개를 순차 실행했고 두 번째 프로세스에서는 GLMM부터 실행했다. 워밍업 이후 계측하지 않은 전체 분석 시간을 측정했다. 별도 실행에서 앱의 적합 함수, 민감도 분석, 가정 검토 함수를 감싸 부분 시간을 기록했다. 로딩 시간은 제외했다. 부분 시간과 전체 시간은 다른 실행이며, 민감도 시간에는 해당 적합 시간이 포함되므로 합산하지 않는다.

## 결과

단위는 초이며 각 셀은 실행 1 / 2 / 3이다.

| 분석 | random_slope | 전체 분석 | 민감도 분석 | 가정 검토 |
|---|---|---|---|---|
| LMM | FALSE | 0.28 / 0.25 / 0.28 | 0.11 / 0.11 / 0.12 | 0.09 / 0.10 / 0.08 |
| LMM | TRUE | 0.29 / 0.28 / 0.28 | 0.11 / 0.11 / 0.11 | 0.08 / 0.10 / 0.08 |
| GLMM | FALSE | 1.03 / 1.08 / 1.03 | 0.65 / 0.67 / 0.66 | 0.08 / 0.08 / 0.08 |
| GLMM | TRUE | 1.19 / 1.19 / 1.20 | 0.67 / 0.67 / 0.67 | 0.08 / 0.08 / 0.07 |

모든 조건에서 앱 적합 함수는 3회 호출됐다. 예를 들어 첫 프로세스의 GLMM은 다음과 같다.

- random_slope FALSE: 선택 적합 0.25초, 같은 구조 재적합 0.25초, 무작위 기울기 대안 0.40초.
- random_slope TRUE: 선택 적합 0.41초, 같은 구조 재적합 0.41초, 절편만 있는 대안 0.26초.

이 시간은 제거 가능한 전체 비용을 확정한 것이 아니다. 재사용 구현의 결과 동일성과 실제 전체 속도 개선은 아직 검증하지 않았다.

## 메시지와 동일성 확인

LMM은 두 설정 모두 수집한 경고/메시지가 0개였다. GLMM은 FALSE에서 1개, TRUE에서 2개였고 세 프로세스에서 같았다. 모두 `boundary (singular) fit: see help('isSingular')` 메시지였다. TRUE 설정을 단순히 재사용하면 진단 메시지 반복을 바꿀 가능성이 있으므로 이를 유지하는 경로가 필요하다.

12개 조건(2개 분석 × 2개 기울기 설정 × 3개 프로세스)에서 워밍업, 전체 측정, 부분 계측 결과를 비교했다. 반환 결과표와 진단, 조건 클래스/본문/순서, 표준 출력, 최종 RNG가 일치했다. 모형은 고정효과, 무작위효과, 계수 공분산, 적합값, 잔차, logLik, theta, devcomp, optinfo, call, model frame을 추출해 비교했다.

수치 비교는 `identical(..., num.eq = FALSE)`로 허용오차 없이 수행했다. formula/terms 환경과 저장된 함수 표현은 정규화했다. merMod의 모든 내부 슬롯이나 외부 포인터를 비교한 것은 아니다. 초기 반복 비교는 model frame의 formula 환경에서 차이가 나서 해당 속성을 정규화한 후 전체 프로세스를 다시 실행했다.
