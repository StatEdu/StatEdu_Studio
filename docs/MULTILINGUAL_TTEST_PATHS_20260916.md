# t 검정/분산분석 정규성·비모수 경로 다국어 보완

## 확인한 문제와 변경

- Shapiro–Wilk/K–S 결과에서 모형 선택 근거가 한국어로 생성되어 다른 UI 언어에도 남았다. 해당 내부 문구를 영어 기준으로 생성하고 보조표에서 UI 언어로 번역하도록 수정했다. 통계 계산은 변경하지 않았다.
- 분석 메뉴에서 지정한 비모수 검정의 선택 근거 및 Mann–Whitney 검정 설명 등 정적 문구 6개를 8개 언어 사전에 연결했다.
- 왜도·첨도·기준의 동적 문구는 수치를 그대로 넣는 언어별 템플릿으로 표시한다.
- 보조표의 종속변수 열 제목과 독립변수 라벨을 원본 위치에 따라 보존한다. `Homogeneity`, `Normality met`와 같이 시스템 문구와 같은 사용자 라벨이 번역되는 문제를 수정했다.

## 검증

`scripts/validate_ttest_paths_i18n.R`는 실제 90행 자료에서 왜도·첨도, Shapiro–Wilk, K–S, 비모수 지정의 네 경로를 실행한다. 각 경로는 두 집단 및 세 집단 분석을 포함한다. 8개 언어 모두 본표 영어 내용 동일성, 보조표 언어, 수치가 포함된 번역, 시스템 문구와 충돌하는 사용자 라벨 보존을 통과했다.

기존 `validate_group_comparison_i18n.R`, `validate_ttest_anova.R`, `validate_i18n_contract.R`도 통과했다.

일본어 네 경로 전체를 하나의 항목으로 묶은 `tmp/ttest-paths-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성 검사를 통과했다. `validate_multilingual_pdf.py`의 실제 PDF 텍스트 검사도 두 저장 경로 모두 통과했다. 내보내기 로그는 `tmp/ttest-path-exports.log`에 있다.

## 남은 범위

이번 실제 자료는 정규성이 충족되는 경우다. 불충족에 따른 자동 비모수 선택, 집단별 정규성 검사, 상수·소표본·계산 실패 경고, 모든 사후검정 및 옵션 조합은 추가 확인 대상이다. 정적 사전에 등록된 문구 모두가 이번 실제 경로에서 발생한 것은 아니다. 새로운 분석 화면을 추가로 검증한 차수가 아니므로 전용 결과 검증 공백은 17개를 유지한다. 설치본은 만들지 않았다.
