# Mann–Whitney z의 순위 기반 동순위 계산 검토 — 2026-09-14

## 결정

이미 계산한 순위를 이용해 z값의 동순위 보정 빈도를 만드는 후보를 시험했다. **18조건 중 6조건에서 원시 z값이 달라져 반영하지 않았다.** 결과 보존 기준을 충족하지 못했으므로 성능 측정은 진행하지 않았다. 제품 코드는 유지했다.

## 후보

`ttest_mann_whitney_z()`는 `rank(data$y)`를 계산한 뒤 별도로 `table(data$y)`를 만든다. 연구 복사본에서 후자만 `tabulate(2 * ranks, nbins=2 * length(ranks))`의 0이 아닌 빈도로 대체했다. 평균 순위가 정수 또는 반정수인 성질을 이용한 후보다. 나머지 U·동순위 보정·분산·z 공식은 변경하지 않았다.

## 불일치 원인과 예

현재 런타임의 원자료 `table()` 범주화와 순위 계산은 매우 가까운 숫자에서 서로 다른 구분을 할 수 있다. 다음 네 값에서 직접 확인했다.

```text
1.0000000000000002
1.0000000000000004
1.0000000000000007
1.0000000000000009
```

기존 원자료 빈도표는 표시 범주 `1`에 빈도 4를 반환했다. 순위 빈도표는 순위 1/2/3/4에 각각 빈도 1을 반환했다. 앞의 두 값을 첫 집단, 뒤의 두 값을 둘째 집단으로 지정하면 기존 z는 NA이고 후보는 약 -1.5491933이었다.

이 결과는 모든 `table()` 입력이 잘못 처리된다는 주장이나 후보가 제품에 적용 가능한 수정이라는 뜻이 아니다. 숫자 범주화까지 포함한 기존 계산과 원시 순위 기반 계산의 동작 차이를 확인한 것이다. 기존 수치 동작을 바꾸는 수정은 이번 결과 불변 성능 최적화에 포함하지 않았다.
