# 100,000행 전체 Cox 분석에서 제외 사유 최적화 통합 검증

제품 코드는 변경하지 않았다. 최근 네 가지 제외 사유 최적화를 적용하기 전 preflight와 현재 preflight를 각각 사용하는 전체 Cox 분석을 비교했다. 전처리 단축률을 전체 분석에 대입하거나 개별 개선율을 합산하지 않았다.

## 측정 범위

`scripts/benchmark_cox_reason_combined_large.R` 사용. 번들 R 4.5.3, 실제 앱 모듈·환경설정 초기화, 양쪽 모듈 함수 컴파일, 같은 자료와 난수 시드. 두 독립 프로세스에서 조건 순서를 반대로 실행하고, 각 조건 준비 후 기존/현재를 번갈아 3회씩 측정한 중앙값을 사용한다.

타이머는 `prepare_cox_analysis_result` 전체와 진단/stdout 수집을 포함한다. 전처리, 모형 적합, 진단과 결과 객체 준비가 포함되며 결과 동일성 비교·수식 환경 정규화는 제외한다. 앱 로딩·브라우저 렌더링·저장 시간은 포함하지 않는다. 조정 생존곡선과 부트스트랩은 사용하지 않는다.

100,000행, 연속 공변량 6개, 사건 확률 0.7, 집단 3수준, 군집 10,000개(원자료 기준 각 10행), 스플라인 x1의 df=4. 기본 Efron 동률 처리를 유지한다.

- 정상: 분석 행 100,000개.
- 중첩: 같은 절반의 행에서 사건·집단·공변량 6개 모두 결측. 분석 행 50,000개.
- 분산: 공변량별 결측 행이 서로 겹치지 않음. 분석 행 49,998개.

각 자료에서 기본·층화·군집 보정·스플라인 네 옵션을 실행한다. 기준은 `scripts/fixtures/survival_reason_dedup_reference.R`이며 사건 문자열/매핑·생존시간 등 이전 개선은 양쪽에 유지한다.

## 검증 방법

각 조건에서 성공 coxph 모형, 예상 분석 행 수, 유한 계수를 확인한다. 준비 비교 1회와 측정 비교 6회, 12조건으로 프로세스당 전체 결과 84개를 비교한다. 전체 값/속성·진단·stdout·RNG는 `identical(..., num.eq=FALSE)`로 비교한다. 수식에 사용되는 `.Environment` 속성만 call 내부까지 재귀적으로 제외하며 수치 허용오차는 사용하지 않는다.

두 독립 프로세스의 총 168개 비교가 모두 통과했다. 측정된 144개 적합에서 경고·메시지는 0개였고 계수 수는 기본/층화/군집 6개, 스플라인 9개로 확인됐다.

## 전체 Cox 실행시간

단위 초, 각 칸은 최적화 이전 기준→현재 코드 중앙값이다.

| 자료 | 옵션 | 실행 1 | 실행 2 |
|---|---|---:|---:|
| 정상 | 기본 | 0.986 → 0.970 | 0.991 → 0.982 |
| 정상 | 층화 | 1.041 → 1.031 | 1.049 → 1.034 |
| 정상 | 군집 | 1.175 → 1.176 | 1.403 → 1.210 |
| 정상 | 스플라인 | 1.617 → 1.655 | 1.619 → 1.618 |
| 중첩 | 기본 | 1.827 → 0.648 | 1.834 → 0.699 |
| 중첩 | 층화 | 1.992 → 0.708 | 1.995 → 0.720 |
| 중첩 | 군집 | 1.915 → 0.818 | 1.950 → 0.779 |
| 중첩 | 스플라인 | 2.083 → 0.972 | 2.088 → 0.939 |
| 분산 | 기본 | 0.803 → 0.558 | 0.789 → 0.538 |
| 분산 | 층화 | 0.782 → 0.527 | 0.791 → 0.570 |
| 분산 | 군집 | 0.847 → 0.615 | 0.920 → 0.678 |
| 분산 | 스플라인 | 1.033 → 0.798 | 1.058 → 0.821 |

중첩 결측의 전체 Cox 단축률은 옵션/실행별 약 53~65%, 분산 결측은 약 22~33%였다. 모든 결측 자료·옵션에서 두 실행 모두 단축됐다. 앞선 전처리만의 개선율(중첩 약 83~84%, 분산 약 76~78%)보다 작으며 모형 적합과 다른 결과 준비 비용을 포함한 실제 전체 분석 측정값이다.

정상 자료는 대부분 비슷했다. 군집 보정의 두 번째 실행에는 큰 차이가 있었지만 첫 실행에는 없었고, 정상 스플라인도 실행별 방향이 달랐다. 정상 자료에 대한 일관된 개선율로 일반화하지 않는다. 각 프로세스 안의 기준/현재 짝 비교만 사용한다.
