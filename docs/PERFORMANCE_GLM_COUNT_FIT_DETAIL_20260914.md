# 카운트 GLM 적합 내부 비용 — 2026-09-14

음이항 모형의 과산포 모수 θ를 추정하는 `MASS::theta.ml()`을 다음 검토 대상으로 좁혔다. 이번에는 측정만 수행했으며 운영 소스를 변경하지 않았다.

| 자료 / 선택 모형 | 전체 중앙값(초) | glm 호출 합계 | glm.nb | theta.ml 호출 합계 |
|---|---:|---:|---:|---:|
| Poisson / Poisson | 1.25 | 0.24 | 0.74 | 0.50 |
| 과산포 / 음이항 | 1.14 | 0.17 | 0.73 | 0.37 |

각 단계 값은 한 분석의 해당 함수 호출을 모두 합산한 후 구한 3회 중앙값이다. `theta.ml`은 `glm.nb`에 포함되므로 두 시간을 합산하면 안 된다. `glm`은 분석당 2회로, 사전 모형과 귀무모형 등의 호출을 포함한다. 두 glm 호출의 용도별 시간은 별도로 분리하지 않았다. `glm.nb`는 분석당 1회였다. `theta.ml` 호출 수는 Poisson 자료 2회, 과산포 자료 4회이며, 이는 함수 호출 횟수이지 함수 내부 반복 횟수가 아니다.

전체 시간은 Poisson 자료 1.23/1.25/1.25초, 과산포 자료 1.16/1.10/1.14초였다. θ 추정 합계는 각각 0.50/0.52/0.50초와 0.36/0.37/0.37초였다. 두 자료에서 θ 추정은 음이항 적합 시간의 상당 부분을 차지했다.

## 다음 후보의 근거

설치된 `theta.ml` 소스를 확인했다. 각 반복에서 관측별 `digamma(theta + y)`와 `trigamma(theta + y)`를 계산한다. 카운트 자료에 동일한 y가 많으면 같은 특수함수 계산을 반복한다. 서로 다른 y에 대해서만 계산하고 원래 관측 순서로 복원하는 방식을 후보로 검토할 수 있다. `sum`의 순서·가중치·초깃값·반복 종료 기준을 유지해야 한다.

이 방식의 속도와 정확한 동일성은 아직 검증하지 않았다. 특히 결측·음수·비정수·비유한 입력, 경고·수렴 실패, 특수함수 경계값 및 값이 모두 다른 자료의 추가 비용을 검증해야 한다. 패키지 구현을 복제하거나 연결하는 유지보수 비용도 고려해야 한다. 현재 보고서는 후보의 개선율을 제시하지 않으며 패키지를 수정하지 않았다.
