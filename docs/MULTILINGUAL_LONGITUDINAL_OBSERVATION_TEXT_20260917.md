# 종단 관측모형 설명의 줄바꿈 보존 — 2026-09-17

IPW 관측모형 설명에 줄바꿈이 포함된 변수명을 넣으면 기존 줄 단위 번역에서 문장 구조가 깨져 영어 설명이 남는 문제를 재현했다. 알려진 관측모형 설명 전체를 줄 분리 전에 해석하도록 수정했다. 기존 8언어 번역을 재사용하며 변수명과 가중치 범위 숫자는 문자열 그대로 삽입한다.

`validate_longitudinal_ipw_names_i18n.R`에 마침표·세미콜론·한글·`<&>`·`%s`·줄바꿈을 포함한 이름을 추가했다. 기존 변수명/안내 구분 24개 검사와 추가 설명 8언어 검사가 통과했다. 설명 시험은 앱의 생성 형식으로 만든 문자열이며 해당 복잡한 변수명으로 실제 IPW 모형을 적합한 시험은 아니다. 실제 `Warning` 변수 모형 검사는 그대로 유지한다.

추가 설명 표가 기존 저장 검사에 포함되어 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel의 표시 내용과 원문 보존을 검증한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 별도 검사한다. 산출물: `tmp/longitudinal-error-exports`.

계산 코드·메타분석·설치본은 변경하지 않았다. 모든 변수명 조합, 브라우저 및 페이지별 시각 검토를 완료한 것은 아니다.

위 검사와 기존 MI/IPW·가중치 검사, 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 모든 캡처 텍스트도 통과했으며 각 언어 현재 21쪽, 누적 41쪽이다. 변경 파일의 `git diff --check`도 통과했다.
