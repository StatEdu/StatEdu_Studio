# Cox 영향력·층별 사건 수 경고

## 변경

영향력 계수 행 수, 사건이 없는 층, 사건이 5건 미만인 층의 근거 접두어와 권고 6개 문구를 6개 추가 UI 언어에 번역했다.

검증 과정에서 `Review`라는 사용자 층 이름이 한국어로 재번역되는 결함을 확인했다. 두 층별 경고의 조립된 근거 셀을 후속 자동 번역에서 보호하여 접두 설명은 UI 언어, 층 이름은 원문으로 유지한다.

## 검증

`scripts/validate_cox_influence_strata_warnings_i18n.R`는 실제 Cox 적합을 기반으로 진단 메타데이터를 구성한다. 추가 경고 사례는 별도로 적합한 모형이 아닌 분기 검사이다.

- 신호 없음, 혼합 신호, 5건 경계의 3가지 사례 × 8개 언어 통과.
- TRUE/FALSE/NA 영향력 플래그에서 TRUE 2건만 집계되는지 확인.
- 0건 층과 1·4건 층의 구분, 5건 층의 경고 제외 확인.
- `Review`, `Normality`, `사용자 <&> %s` 층 이름 보존 확인.
- 본 회귀표의 영어 유지 확인.
- 일본어 경고표 캡처로 현재·누적 결과 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/cox-influence-strata-warnings-i18n/`.
- 현재 1개·누적 2개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지와 표 순서·시트 수를 확인했다.
- 기존 Cox 공선성 경고의 8개 언어 회귀 검사도 통과했다.

전체 앱의 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
