# 일원 반복측정 조건별 안내 번역

유의한 상호작용의 후속 비교, 목록별 제외, 정규성 문제와 민감도 분석 권고, Shapiro–Wilk 기준, 가정 검토 생략, 해석 전 ANOVA 표 확인, 핵심 p값 산출 불가 등 7개 문장을 8개 언어 사전에 등록했다. 계산 엔진과 본표 렌더링은 변경하지 않았다.

`scripts/validate_one_group_branches_i18n.R`는 40명의 WIDE 자료에 처치별 시간 변화, 극단값, 결측 1건을 포함한다. 가정 검토 사용/생략의 두 실제 분석으로 앞의 5개 문장과 제외 대상자 1명 표시를 검증했다. 모든 언어에서 본표가 영어 기준 결과와 동일하다. 해석 불가 문장 2개는 보조표 렌더러 fixture 검사이며 실제 계산 실패 재현은 아니다.

기존 `validate_one_group_i18n.R`의 대표 결과·사용자 처치/시점 라벨 보존 및 `validate_i18n_contract.R`도 통과했다. 이번 저장 fixture는 `tmp/one-group-branches-i18n/entries.rds`로 두 실제 분석의 일본어 결과를 한 항목에 모았다.

현재·누적 HTML/Word/HWPX/Excel의 내용 비교 및 PDF 생성, 실제 PDF 텍스트 검사를 모두 통과했다. 저장 로그는 `tmp/one-group-branches-exports.log`다. 이 검사는 내용 보존 검증이며 모든 화면의 시각적 배치 검증을 의미하지 않는다.

동적 입력/집단 요약, LONG·공변량·추가 옵션·언어 왕복 및 실제 해석 불가 경로 검증은 남아 있다. 전용 다국어 결과 검증 공백 11개는 변경하지 않는다. 설치본은 만들지 않았다.
