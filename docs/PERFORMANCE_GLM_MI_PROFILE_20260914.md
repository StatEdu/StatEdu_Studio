# 카운트 GLM 다중대치 단계별 측정 — 2026-09-14

θ 최적화 연결 후의 일반화 카운트 모형에서 다중대치(MI) 경로를 측정했다. 제품 코드 변경 없이 다음 최적화 후보의 비용을 확인한 작업이다.

## 측정 결과

| 자료 | 프로파일러 없이 전체 분석 3회(초) | 중앙값 |
|---|---|---|
| 2,000행 | 0.30 / 0.25 / 0.27 | 0.27 |
| 10,000행 | 1.11 / 1.14 / 0.91 | 1.11 |

| 단계 | 2,000행 프로파일 표본 비중(3회 범위) | 10,000행 표본 비중(3회 범위) |
|---|---|---|
| mice 결측값 대치 | 31.7–34.9% | 28.5–34.6% |
| 대치 후 generalized_fit_model | 46.5–52.8% | 48.7–56.0% |
| 별도 Poisson 선별 적합 | 5.7–7.0% | 9.4–9.8% |
| 계수 풀링 | 0–2.3% | 0–0.6% |

표의 단계는 이 코드 경로에서 서로 겹치지 않는다. 결과 준비·진단·대치 자료 완성 등의 나머지 비용은 별도다. 모형 적합 단계에는 Poisson/NB 적합과 계수표 계산 등이 포함된다. 선별 단계는 `generalized_fit_mi` 아래 `stats::glm` 표본 중 `generalized_fit_model`이 없는 표본으로 구분했다.

표본 비중은 경과 시간 자체나 보장되는 개선율이 아니다. 특히 작은 자료의 프로파일 표본 수가 적어 오차가 크며 0%는 비용이 없다는 뜻이 아니다. 10,000행에서 선별 적합이 약 10%를 차지하므로 재사용 검토의 근거는 되지만, 제거 시 전체 시간이 정확히 10% 감소한다는 결론은 아니다.

## 재현 조건 및 검증

- 번들 R 4.5.3, 기존 θ 최적화를 포함한 현재 모듈을 사용했다. 일반화 소스 SHA256: `4C25B0F1E85E3925CFC59615E020CDD7F943831E8E6AEBDD602B3C53B6A43AB2`.
- 새 프로세스 3개를 순차 실행하고 두 번째는 자료 크기의 실행 순서를 뒤집었다. 각 자료에서 준비 실행 후 GC, 프로파일러 없는 전체 분석 1회, 별도의 Rprof 20ms 요청 간격으로 전체 분석 5회 반복을 수행했다. 로딩·입력 생성·화면·파일 저장은 전체 시간에서 제외했다.
- 시드 916, 연속 예측변수 6개, 음이항 y(size=0.5, mu=exp(0.2*x1-0.1*x2)), x1–x3 각각 15% 결측, 대치 5개·반복 3회, 강건 표준오차 켬·VIF 끔이다. 분석 호출 전 시드 713으로 초기화했다.
- 프로파일 표본 수는 2,000행 60/43/53개, 10,000행 204/191/193개다. Windows의 샘플링 간격 및 프로파일러 오버헤드 때문에 Rprof 추정 시간을 벽시계 시간으로 해석하지 않았다. 초기 5ms 시험은 폐기하고 최종 코드를 20ms 및 5회 반복으로 재실행했다.
- 각 자료·프로세스에서 준비 실행과 시간 측정 결과, 프로파일링 마지막 결과가 `identical(..., num.eq=FALSE)`로 일치했다. 비교 대상은 모형을 제외한 반환 내용(공식 환경만 통일), 계수·적합값·잔차·deviance·weights·theta·SE.theta, 경고/메시지 문자열과 난수 상태다. 프로파일링 중간 4회 결과는 개별 비교하지 않았다. 모형 내부의 모든 환경이나 조건 객체 전체를 비교한 것은 아니다.

## 다음 후보와 보존 조건

`generalized_fit_mi`는 각 대치 자료의 Poisson을 먼저 적합해 중앙 과산포에 따라 공통 family를 결정한다. 이후 `generalized_fit_model`에서 동일 자료의 Poisson을 다시 적합한다. 선별 적합 결과를 대치 실행 내부에서 재사용하는 것이 후보이다.

다만 단순히 두 번째 적합을 생략하면 원래 반복 발생하던 경고/메시지의 횟수와 순서, 저장된 모델 호출식이 바뀔 수 있다. 실제 도입 전 조용히 성공한 일반 모형에 제한한 재사용, 수렴 실패 및 경고 발생 시 기존 재적합, 결과·조건·호출식 동일성, 전체 분석 개선량 및 추가 메모리를 검증해야 한다. 이 보고서는 재사용을 제품에 적용하거나 효과를 확인한 보고서가 아니다.

측정 코드·프로파일 원본·요약 CSV·결과 RDS는 `output/glm-mi-profile-20260914/`에 보관했다. 출력 내용과 형식을 변경하지 않았으므로 문서 변환이나 설치 파일 빌드는 수행하지 않았다.
