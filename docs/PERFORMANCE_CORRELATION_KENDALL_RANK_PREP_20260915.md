# Kendall 첫 분석의 불필요한 순위 준비 생략

## 변경

`R/analysis_correlation.R`의 `prepare_correlation_results()`에서 비잠재 상관분석이며, 명시적으로 Kendall을 선택했고, 유효성 검사 후 남은 변수가 모두 연속형인 경우 Spearman용 `correlation_rank_test()` 생성만 생략했다. 순서형 등 혼합 변수, 자동 선택, Pearson, Spearman의 준비 경로는 유지한다. 제외된 상수 순서형 변수는 생략 판단에 영향을 주지 않는다.

Kendall 검정, 계수 계산, 결과 표와 반환 구조는 변경하지 않았다. 함수 생성과 그에 따른 첫 실행 준비를 줄이는 변경으로, 프로그램 시작 시간 자체의 개선으로 해석하지 않는다.

## 정확성

- `scripts/validate_correlation_kendall_rank_prep.R`: 기존 조건을 AST로 복원한 기준 함수와 실제 수정 함수를 비교. 4개 방법 × 4개 측정 수준 구성 × 결측 유무 × 제외되는 상수 변수 유무 = 64개 전체 결과가 `identical(..., num.eq=FALSE)`로 일치했다. 경고, 메시지, 오류, 표준 출력, 난수 상태도 포함했다. 이 입력들은 오류 없이 완료됐다.
- 준비 함수 호출 횟수: 연속형 Kendall에서 1→0, 다른 구성에서는 1→1. 특히 혼합 순서형에서 Spearman 경로가 유지되는 것을 확인했다.
- 독립 R 프로세스의 기준 6개, 후보 3개, 실제 코드 3개 전체 캡처 12개가 정확히 일치했다.
- 기존 `scripts/validate_correlation_kendall_engine.R` 통과: 경계 19개, 원시 검정 18개 및 720개, 추가 스트레스 96개. 작은 표본 등 기존 폴백 조건을 유지했다.

## 첫 실행 측정

Windows 번들 R 4.5.3, JIT 3, 모듈 로딩 및 환경설정 완료 후 분석 호출을 측정했다. 각 조건은 독립 R 프로세스이며 순차 실행했다. 두 번째 쌍의 기준/수정 실행 순서를 반대로 했다. 입력은 n=2,000, 연속형으로 지정한 6개 반올림 정규 난수 변수, Kendall, 정규성 검사 및 잠재 상관분석 비활성화다.

|실험|기준 첫 호출(초)|수정 첫 호출(초)|중앙값|
|---|---|---|---|
|후보 함수|0.26 / 0.27 / 0.27|0.25 / 0.25 / 0.25|0.27→0.25|
|실제 코드|0.27 / 0.25 / 0.26|0.23 / 0.25 / 0.23|0.26→0.23|

실제 코드의 첫 호출 중앙값은 약 12% 줄었으며 3쌍 중 2쌍이 단축되고 1쌍은 같았다. 절대 차이가 수십 ms인 소규모 측정이며 모든 데이터에 같은 효과를 보장하지 않는다. 실제 코드의 두 번째 호출은 기준 0.03 / 0.05 / 0.05초, 수정 0.03 / 0.03 / 0.05초로, 반복 실행의 별도 개선율은 주장하지 않는다. UI, Electron, 프로세스 시작 및 패키지 로딩은 측정에서 제외했다.
