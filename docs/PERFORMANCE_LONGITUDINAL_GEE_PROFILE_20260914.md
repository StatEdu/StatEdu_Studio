# 종단분석 GEE 반복 적합 프로파일

## 결론

GEE 기본 exchangeable 모형에서 분석 한 번당 `geeglm`이 7회 호출된다. 선택 모형 1회, 민감도 분석의 exchangeable/independence/ar1 모형 3회, 각 QIC 내부 independence 재적합 3회이다. 선택 모형 재사용을 다음 검증 대상으로 선정한다. 이번 작업은 측정만 수행했으며 제품 코드는 변경하지 않았다. 속도 개선이나 재사용의 결과 동일성을 아직 입증한 것은 아니다.

## 방법과 범위

- 번들 R 4.5.3, 현재 앱 모듈과 환경설정 사용. 실행 중 패키지 설치 금지.
- seed 936, 500명 또는 5,000명 × 4시점, 두 공변량, 연속형 gaussian 및 이항형 binomial 반응. 선택 상관구조 exchangeable, 그 외 기본 분석 옵션.
- 각 크기마다 독립 R 프로세스 3개를 순차 실행하고 두 번째 프로세스에서는 반응 분포 순서를 반대로 했다.
- 워밍업 후 추적 없는 전체 실행을 측정했다. 별도 실행에서 앱 적합 함수와 민감도 분석 함수의 시간을 측정하고, geepack namespace의 geeglm을 trace하여 호출 수를 집계했다. 로딩 시간은 아래 분석 시간에 포함하지 않았다.
- 전체 실행과 계측 실행은 서로 다른 실행이다. 민감도 시간은 적합 시간을 포함하므로 두 값을 더하지 않는다. 짧은 적합의 0초 표기는 측정 해상도 한계다.

## 측정 결과

단위: 초. 괄호는 세 실행의 중앙값.

| 행 수 | 분포 | 전체 실행 1 / 2 / 3 | 민감도 분석 1 / 2 / 3 | geeglm 호출 수 |
|---|---|---|---|---|
| 2,000 | gaussian | 0.25 / 0.20 / 0.24 (0.24) | 0.14 / 0.09 / 0.13 (0.13) | 모두 7 |
| 2,000 | binomial | 0.22 / 0.25 / 0.22 (0.22) | 0.11 / 0.12 / 0.11 (0.11) | 모두 7 |
| 20,000 | gaussian | 2.03 / 1.85 / 2.05 (2.03) | 1.12 / 0.87 / 1.11 (1.11) | 모두 7 |
| 20,000 | binomial | 1.93 / 2.36 / 1.93 (1.93) | 1.11 / 1.17 / 1.12 (1.12) | 모두 7 |

앱의 `longitudinal_fit_model` 호출은 모두 4회다. 설치된 `QIC.geeglm`의 본문에서 `object$call$corstr <- "independence"`, `object$call$zcor <- NULL` 후 `eval(object$call, envir = env)`를 실행하는 것도 확인했다. 따라서 추가 3회는 QIC 내부 재적합으로 설명된다.

## 결과 검증

12개 조건(2개 크기 × 2개 분포 × 3개 프로세스)에서 워밍업 결과, 추적 없는 측정 결과, 계측 결과를 비교했다. 반환 객체의 수치와 속성, 경고·메시지의 클래스/본문/순서, 표준 출력, 실행 후 RNG 상태를 `identical(..., num.eq = FALSE)`로 비교하여 모두 통과했다. 수치 허용오차는 사용하지 않았다.

비교용 정규화는 formula/terms 환경과 함수 객체 표현을 통일한다. 모형 call 안에 직접 저장된 함수는 호출 머리만 고정 심벌로 바꾸며 호출 인자는 보존하고 재귀적으로 정규화한다. 이는 반복 실행에서 생성되는 환경 및 trace가 변경하는 함수 본문을 제외하기 위한 것이다. 원시 환경·함수 객체까지 동일하다는 뜻은 아니다. 초기 비교 실패는 model/call 및 model/geese/call에서 발생했고 `all.equal`은 TRUE였다. 정규화를 보완한 뒤 전체 측정을 다시 실행했다.

## 후속 검증 조건

선택 모형의 민감도 분석 재사용부터 검토한다. 원래 적합과 민감도 적합의 데이터·공변량·가중치·offset·상관구조·옵션이 같은지 확인하고, 경고/메시지/RNG를 바꾸는 경우에는 재사용하지 않아야 한다. 전체 분석의 실제 시간 이득과 수치 동일성을 검증한 뒤 적용 여부를 결정한다.

QIC 내부 재사용은 별도 후보이다. 설치된 메서드는 자체 call을 수정해 적합하고 MASS 로딩 여부에 따라 역행렬 구현도 선택한다. independence 모형이 있다는 이유만으로 이 경로를 대체하지 않는다.
