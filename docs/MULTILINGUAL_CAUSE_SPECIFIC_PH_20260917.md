# 원인별 Cox 비례위험 진단 다국어 검증

## 변경 범위

원인별 비례위험 진단 제목과 Schoenfeld 검정·잔차도 해석 설명을 일본어, 중국어, 스페인어, 프랑스어, 독일어, 베트남어 번역표에 추가했다. 기존 한국어·영어 문구 및 분석 계산은 변경하지 않았다.

## 검증

`scripts/validate_cause_specific_ph_i18n.R`:

- 생존분석 fixture의 실제 경쟁위험 모형을 적합하고 전체 결과 패널에서 해당 구간을 추출한다.
- 영어·한국어 및 6개 추가 언어에서 제목과 설명, 진단 수치의 동일성을 검사한다.
- 별도 진단 메타데이터로 p=.001/.05/.7/NA 및 사용자 항목명 `Review`, `Normality`, `None`, `사용자 <&> %s` 보존을 확인한다. 이 추가 사례는 별도로 모형을 적합한 결과가 아니다.
- 회귀계수 본 표는 모든 UI 언어에서 동일한 영어 표로 유지된다.
- 일본어 캡처의 현재 2개 표와 누적 3개 표를 HTML/PDF/Word/HWPX/Excel로 저장하여 내용과 순서를 확인한다. 저장 시 재분석하지 않는다.

산출물은 `tmp/cause-specific-ph-i18n/`에 저장한다. 변경하지 않은 잔차 그래프 위젯은 이번 저장 검증 범위에서 제외한다. 설치본은 생성하지 않는다.

## 남은 확인 사항

`survival_reporting_guidance_panel`의 보고 체크리스트 제목 및 일부 안내문은 한국어·영어 분기만 사용하고 있다. 해당 구간은 이번 변경에 포함하지 않았으며, 전체 다국어 완료로 판단하지 않는다.
