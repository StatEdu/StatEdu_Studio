# Cox 추정 실패 경고 번역

## 변경

계수가 유한하지 않은 경우와 범주형 전체 검정 추정 실패의 근거·권고 4개 문구를 6개 추가 UI 언어에 번역했다. 범주형 검정의 변수명 접미부는 후속 자동 번역에서 보호한다. 기존 영어·한국어 문구 및 분석 계산은 유지했다.

## 검증

`scripts/validate_cox_estimability_warnings_i18n.R`는 실제 Cox 적합 결과의 진단 메타데이터를 변경하여 다음 분기를 검사한다. 추가 사례는 해당 조건의 모형을 다시 적합한 결과가 아니다.

- 정상, 무한 계수, 결측 계수, 범주형 검정 실패, 동시 실패: 5가지 × 8개 언어.
- 경고 발생 여부·심각도 및 영어 잔존 검사 통과.
- 실패한 변수 `Review`, `사용자 <&> %s`가 원문으로 남고 추정 가능한 `Normality`는 경고에 포함되지 않음을 확인.
- 본 회귀표가 모든 UI 언어에서 동일한 영어 내용을 유지함을 확인.
- 일본어 경고표 캡처로 현재·누적 결과 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/cox-estimability-warnings-i18n/`.
- 현재 4개·누적 5개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서·시트 수를 확인했다.
- 기존 영향력·층별 사건 수 경고의 8개 언어 회귀 검사도 통과했다.

전체 앱의 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
