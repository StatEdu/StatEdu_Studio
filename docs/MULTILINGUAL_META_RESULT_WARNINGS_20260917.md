# 메타분석 결과 보조 오류 안내 — 2026-09-17

결과 하단의 의존성 민감도·연구 단위 순차 제외·Trim-and-fill·조절효과 CR2 불가 접두어, 연구 내 상관 범위/최소 연구 수 상세 3종, 해석 및 가정 제목을 8개 언어로 연결했다. 저장된 결과 객체는 영어 원문을 유지하고 화면 생성 시 번역한다. 미등록 외부 상세는 원문 그대로 표시한다.

다층/RVE 오류가 들어가는 Dependent-effect analysis 등은 본표이므로 영어를 유지한다. 이번 변경은 본표의 오류 셀을 번역하지 않는다. CR2의 고유 오류 상세 및 다른 해석 문구는 후속 대상이다.

검증:

- `validate_meta_warning_exports_i18n.R`: 실제 민감도 오류 3종과 외부 상세를 포함한 결과를 8개 언어로 렌더링. 보조 안내 번역, 본표 영어 동일성, 결과 객체 불변을 확인했다.
- 한국어/일본어 각각 현재 결과 1건·누적 결과 2건을 동일한 캡처 HTML에서 HTML/PDF/Word/HWPX/Excel로 저장했다. 표 제목/셀/보조 안내와 그림 포함을 검사했다. 내보내기 중 분석 재실행은 하지 않았다.
- `validate_meta_warning_pdf.py`: PDF의 본표 및 보조 문구 전체를 텍스트 추출로 확인했다. 합자와 공백은 Unicode NFKC로 정규화했다. Word/HWPX/Excel의 그림 포함도 확인했다. PDF는 현재 7쪽, 누적 12쪽이었다.
- 카탈로그 회귀 검사 통과. PDF 첫 실행은 샌드박스의 Chrome 실행 제한으로 실패했으며 승인된 외부 실행으로 재검증했다.

산출물은 `tmp/meta-warning-i18n`에 있다. 페이지별 시각 검토나 모든 언어의 내보내기 검증까지 수행한 것은 아니다. 설치본은 만들지 않았다.
