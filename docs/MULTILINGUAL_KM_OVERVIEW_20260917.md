# Kaplan–Meier·생명표 분석 개요

개요의 Value 열을 사용자 데이터로 보호했다. 프로그램이 생성하는 방법명과 해당하는
미선택 표시는 사전에 번역하고, 시간 원점·단위·변수·사건 코드·패키지·수치는 보존한다.
실제 결과 패널 두 경로가 명시적으로 UI 언어를 넘기도록 했다.
진입 시간 변수 항목의 6개 추가 언어 번역을 보완했다.

## 검증

- `validate_km_overview_i18n.R`: 실제 Kaplan–Meier와 생명표 결과 및 표시용 사용자
  설정 복사본을 8개 언어로 검사했다. Review, Normality, None, 사용자 <&> %s 등
  번역 문구와 같은 입력도 원문 유지. 실제 본 표 영어 유지 확인.
- 기존 비-Cox 방법 설명 19개 조합의 8개 언어 회귀 검사 통과.
- 일본어 현재 4개 / 누적 5개 개요 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 다른 생존분석 개요 및 보조표의 점검 완료를 뜻하지 않는다.
