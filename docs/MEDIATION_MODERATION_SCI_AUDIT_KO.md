# 매개·조절 분석 SCI 수준 검증 기록

검토일: 2026-08-20
검증 스크립트: `scripts/validate_mediation_moderation.R`

## 결론

회귀 기반 매개·조절 엔진의 핵심 추정식, bootstrap 추론, 결측 처리, 재현성, 화면 및 내보내기 연결을 독립 기준식과 비교했으며 현재 검증 범위는 통과했다. 이 기록은 수치 구현의 정확성을 뒷받침하지만, 횡단자료의 인과적 매개효과나 누락 교란 부재를 보증하지는 않는다.

## 독립 검증 범위

- 공변량을 포함한 단순매개에서 `M ~ X + C`, `Y ~ X + M + C`의 OLS 계수와 직접효과, `a*b`, 총간접효과, 총효과를 직접 `stats::lm` 결과와 비교했다.
- 동일 seed와 사례 재표집 순서를 사용하되 앱의 bootstrap 요약 함수를 호출하지 않고, 수동 OLS 적합과 type-6 quantile 식으로 BC 및 percentile 95% CI를 계산해 비교했다.
- bootstrap SE, plus-one 양측 p값, 요청/유효 반복수와 판정 상태를 비교했다.
- 조절모형 `Y ~ X*W + C`의 계수와 단순기울기 `b_X + b_XW W`, 그리고 공분산 행렬을 사용한 단순기울기 SE를 독립 계산했다.
- 순차매개에서 `a1*b1`, `a2*b2`, `a1*d21*b2`와 그 합을 독립 회귀식으로 검증했다.
- 완전사례 표본수, 동일 seed 재현성, 결과 HTML의 p 열·bootstrap 진단, Excel용 표 목록을 확인했다.
- 사용자정의 캔버스의 경로 매핑 회귀검증도 함께 통과했다.

## 발견 및 보완

1. 간접효과 표에 bootstrap p값이 없던 문제를 보완했다. p값은 유효 재표집 분포의 0 이하/이상 비율에 plus-one 보정을 적용한다.
2. 요청 반복수에 비해 유효 재표집이 지나치게 적어도 CI가 표시될 수 있던 문제를 보완했다. 80% 이상은 `Adequate`, 50% 이상 80% 미만은 `Caution`, 50% 미만 또는 20회 미만은 `Unreliable`로 구분하고 Unreliable에서는 CI와 p값을 억제한다.
3. 일부 간접경로가 추정 불가능할 때 `sum(..., na.rm=TRUE)`가 해당 경로를 0처럼 누락할 수 있던 문제를 보완했다. 구성 간접효과 중 하나라도 비유한이면 총간접효과와 총효과를 `NA`로 전파한다.
4. 화면과 내보내기에 bootstrap 요청/유효 반복수, 유효 비율과 상태를 추가했다.

## SCI 리뷰어 대응 경계

- BC 기본값은 간접효과 분포의 비대칭과 bootstrap 편향을 고려한 선택이다. 그러나 BCa가 아니며 모든 조건에서 percentile보다 우월하다고 주장하지 않는다. 필요하면 percentile 결과를 민감도 분석으로 함께 제시한다.
- bootstrap은 표본분포 추론을 돕지만 누락변수, 역인과, 측정오차, 비독립 관측, 함수형태 오류를 해결하지 않는다.
- 횡단자료에서는 `causal effect` 대신 이론에 근거한 간접 연관성 또는 통계적 매개로 표현하고, 시간 순서와 교란 통제의 한계를 명시한다.
- 조절효과는 상호작용 계수와 함께 단순기울기 또는 Johnson-Neyman 결과를 보고하되 관측된 조절변수 범위 밖으로 외삽하지 않는다.
- 공변량은 어떤 방정식에 투입했는지 명시해야 하며, 자료 기반 공변량 선택은 계수와 유의확률의 선택 편향을 만들 수 있다.
- 군집·반복측정·복합표본 자료는 독립 OLS 사례 재표집이 적절하지 않을 수 있으므로 해당 설계용 분석을 사용해야 한다.

## 남은 한계

- 검증은 연속형 결과의 회귀 기반 PROCESS 유형 모형에 대한 것이다. 잠재변수 매개, 범주형 결과, 다층 매개와 종단 인과매개는 별도 엔진이 필요하다.
- 앱의 `StatEdu diagnostic-based` 경로는 진단에 따라 HC3 또는 계수 bootstrap을 추가할 수 있다. PROCESS와 숫자를 직접 비교할 때는 `PROCESS-compatible OLS` 설정, 동일 결측 표본, 동일 중심화 및 동일 bootstrap 방식을 사용해야 한다.
- 수치 회귀검증은 자동화됐지만 배포 설치본의 시각적 배치와 장시간 5,000회 이상 작업의 취소 UX는 릴리스 수동 QA에서 별도로 확인한다.
