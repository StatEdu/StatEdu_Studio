# Cox 보정 생존 부트스트랩·동률 경고 번역

## 변경

부트스트랩 유효 반복 수, 유효률, Breslow 동률 사건 비율의 근거 접두 문구와 권고 6개를 6개 추가 언어로 번역했다. 숫자와 백분율 접미부, 기존 영어·한국어 문구, 경고 로직은 유지했다.

## 검증

`scripts/validate_cox_bootstrap_ties_warnings_i18n.R`는 실제 Cox 적합 결과에 진단 메타데이터를 구성하여 7가지 사례 × 8개 언어를 검사했다.

- 부트스트랩 79/100, 80/100, 89/100, 90/100 및 비활성 상태.
- 신뢰구간 가용 플래그에 따른 부족 경고와 유효률 90% 미만 검토 경고.
- 동률 비율 9.9%·10%, Breslow·Efron 방법 분기.
- 경고 발생 여부, 심각도, 숫자·백분율 표시 보존.
- 모든 UI 언어에서 회귀 본 표의 동일한 영어 내용 유지.

추가 사례는 경고 표시 분기 검사이며 부트스트랩을 해당 횟수만큼 재실행한 결과가 아니다. 일본어 캡처로 현재·누적 결과를 저장하며 저장 시 분석을 다시 실행하지 않는다. 산출물은 `tmp/cox-bootstrap-ties-warnings-i18n/`에 있다.

현재 4개·누적 5개 표의 HTML/PDF/Word/HWPX/Excel 검증을 통과했다. PDF 본문·표지, 표 순서·시트 수를 확인했다. 기존 영향력·층별 사건 수 경고의 회귀 검사도 통과했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
