# 대응표본 왜도·첨도 요약 번역

## 변경

정규성 검토의 `skew=수치, kurtosis=수치` 문구가 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 영어로 남는 것을 실제 결과에서 재현했다. 8개 언어 템플릿을 추가하고, 비한국어 부록의 Item=Normality인 Result 셀에 적용했다.

표시된 왜도·첨도 수치 문자열을 그대로 전달해 정밀도와 부호를 보존한다. 영어·기존 한국어 표현과 Shapiro–Wilk 통계 기호는 유지했다. 분석 계산은 변경하지 않았다.

## 검증

- `validate_paired_normality_values_i18n.R`: 40개 완전 사례에서 왜도·첨도 분기, 12개 사례에서 Shapiro–Wilk 분기를 실제 분석했다. 두 분기가 예상한 방법을 사용하는지 확인한 뒤 8개 언어의 전체 결과 패널을 검사했다.
- 왜도·첨도 수치 문자열, Shapiro–Wilk 요약 원문, 사용자 이름 Review/Normality, 영어 본표와 원본 결과 객체 보존 검사 통과.
- `validate_paired_guards.R`, `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 및 PDF 캡처 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-normality-values-i18n/exports`. 저장은 캡처한 결과를 사용하고 분석을 재실행하지 않는다.

## 범위

이번 수정은 대응표본 정규성 검토의 왜도·첨도 요약에 한정한다. 분석명 등 다른 번역 후보는 후속 점검 대상으로 남긴다. 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙을 유지한다.
