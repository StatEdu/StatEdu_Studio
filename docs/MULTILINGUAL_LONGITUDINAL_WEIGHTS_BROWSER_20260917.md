# GEE 가중치·IPW 언어 전환 브라우저 검사 — 2026-09-17

별도 합성 데이터 화면에서 실제 종단 서버/UI를 사용해 Chrome 검사를 수행했다. 표본·종단·결합 가중치 3종 × IPW/WGEE 2종 × 8개 언어 전환, 총 48개 검사가 통과했다.

가중치 변수 wt, 5–95백분위 절단, 보조변수 aux를 선택했다. 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어로 바꿔도 가중치 변수·유형·절단·결측 전략·보조변수·활성 Missing 탭이 유지됐다. 서버 설정 전체가 기준 스냅샷과 동일했고, IPW 보조변수 설명은 현재 언어 사전과 일치했다. 브라우저 JavaScript 오류는 없었다.

근거는 `scripts/validate_longitudinal_weights_language_browser.cjs`와 `scripts/serve_longitudinal_language_test.R`다. 시험 자료에 wt 열을 추가했다. 추가 제품 오류는 발견되지 않아 검증만 추가했고, 분석 실행·결과표·5종 저장 검사는 재실행하지 않았다. 전체 앱 메뉴 왕복, 보조변수 다중 선택·제거, 가중치 해제와 자료 교체 등 다른 조합은 남아 있다. 검사 후 시험 서버와 Chrome을 종료했다.

계산기 담당 작업의 상태·필드 번역 검증 완료 보고와 `MULTILINGUAL_CALCULATOR_STATUS_20260917.md`를 확인했다. 계산기 검증 수치는 이 종단 브라우저 검사에 포함하지 않는다. 메타분석과 설치본은 변경하지 않았다.
