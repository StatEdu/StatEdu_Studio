# 상관행렬 재사용 후 PCA 단계별 측정 — 2026-09-14

현재 PCA의 다음 병목을 확인했다. 연속형 난수 자료에서는 입력의 문자→숫자 변환을 포함한 숫자 자료 준비가 가장 큰 비중이었다. 이번에는 제품 코드를 변경하지 않았다.

## 전체 분석과 프로파일

20,000행·60변수, Pearson 상관행렬, 고정 3성분·회전 없음 조건이다.

| 입력 | 프로파일러 없는 전체 분석 3회(초) | 중앙값 |
|---|---|---|
| 연속형 정규 난수 | 2.59 / 2.37 / 2.62 | 2.59 |
| 정수 저장형의 1–5 값 | 0.34 / 0.61 / 0.34 | 0.34 |

| 단계 | 연속형 프로파일 표본 비중(3회 범위) | 정수형 표본 비중(3회 범위) |
|---|---|---|
| 숫자 입력 준비 `pca_numeric_matrix` | 72.9–80.5% | 12.9–17.9% |
| 분석용 상관행렬 | 3.7–5.1% | 19.4–21.4% |
| 성분 적합 `pca_principal` | 14.6–18.2% | 50.0–54.8% |
| 적합성 검사 | 0% 표본 | 0% 표본 |

각 단계는 이 호출 경로에서 서로 겹치지 않는다. 성분 적합 내부의 상관·표준화·점수 계산 등은 성분 적합 비중에 포함된다. 나머지는 자료 정리·결과표 준비 등이다. 적합성 검사에서 표본이 없었다고 비용이 없다는 뜻은 아니다. 특히 정수형 프로파일은 표본 수가 작아 세부 비중의 오차가 크다. 두 입력의 값 분포와 저장형이 모두 다르므로 전체 시간 차이를 저장형만의 인과 효과로 해석하지 않는다.

## 입력 변환을 그대로 제거할 수 없는 이유

공통 함수 `factor_analysis_numeric_matrix()`는 열마다 `as.numeric(as.character(values))`를 실행하고 PCA는 이 함수를 사용한다. 이미 double인 열을 바로 반환하면 빨라질 수 있지만 기존 문자 변환의 반올림 효과가 사라진다.

번들 R에서 시드 923의 정규 난수 10,000개를 검사했을 때 원본과 문자 왕복 변환은 `identical(..., num.eq=FALSE)`가 거짓이었고, `x != converted`인 값은 9,373개였다. 이는 미세한 값 차이이며 분석 결과가 9,373개 달라졌다는 뜻은 아니다. 입력 숫자가 달라지므로 사용자가 요구한 기존 결과의 정확 보존을 검증하지 않고 변환을 생략할 수 없다.

반면 정수 1:10000은 직접 double 변환과 문자 왕복이 정확히 같았다. 다음 후보는 일반 double을 그대로 통과시키는 방식이 아니라, **클래스 없는 integer 열에 한정한 문자 변환 생략**이다. 아직 구현하지 않았으며 NA·정수 경계·이름/속성·범주형 구분과 공유 함수의 요인분석/PCA 전체 결과를 검증해야 한다. 이 작은 정수 표본만으로 모든 입력의 안전성을 주장하지 않는다.

## 방법과 검증 범위

- 번들 R 4.5.3의 새 프로세스 3개 순차 실행. 두 번째 프로세스는 입력 순서를 뒤집었다. 다른 R 타이밍 작업은 동시에 실행하지 않았다.
- 시드 922로 정규 난수 또는 1–5 정수를 생성했다. 양쪽 모두 변수 메타데이터를 continuous로 지정해 Pearson PCA를 실행했다. 실제 순서형 상관 PCA를 측정한 것은 아니다.
- 각 입력에서 준비 실행, GC 후 프로파일러 없는 전체 분석 1회, 별도 Rprof 요청 간격 20ms로 전체 분석 2회를 실행했다. 연속형 프로파일 표본은 176/164/177개, 정수형은 28/31/28개다. Windows 샘플링 특성과 오버헤드를 고려해 표본 비중을 벽시계 시간으로 환산하지 않았다.
- 준비 실행과 시간 측정 실행, 프로파일링 마지막 실행의 전체 반환 객체·경고/메시지 클래스와 문자열·순서·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 결과 정규화나 수치 허용오차는 적용하지 않았다. 프로파일링 첫 번째 결과는 별도 비교하지 않았다.
- 시간은 분석·결과표 준비 및 비교용 스냅샷 구성을 포함한다. 로딩·입력 생성·그림 렌더링·저장은 제외한다. 메모리는 측정하지 않았다.
