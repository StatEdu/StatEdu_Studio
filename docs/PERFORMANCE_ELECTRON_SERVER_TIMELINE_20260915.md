# Electron 연결 후 초기 서버 처리와 출력 순서

이전 실제 Electron 3회 실행의 서버 로그와 페이지 이벤트를 대조했다. 새 실행이나 제품 수정 없이 기존 증거에서 서버 초기화 구간과 출력 순서를 추출했다.

|서버 로그 구간(ms)|실행 1|실행 2|실행 3|
|---|---:|---:|---:|
|데이터 작업공간 초기 설정|146|143|141|
|지연 실행 모듈 등록|13|15|15|
|나머지 출력 등록|6|5|7|
|서버 초기화 전체|166|164|164|
|최초 raw_dataset 실행|10|11|10|
|최초 data_steps 생성|38|39|37|

작업공간 설정 등 세 등록 구간은 전체 초기화에 포함된다. 이를 전체와 더하면 안 된다. raw_dataset과 data_steps는 반응형 작업의 개별 계측이며 초기화 전체와 다른 구간이다. 로그 시간은 1ms 단위로 반올림돼 있다.

페이지의 연결 이벤트 이후 첫 출력 이벤트는 402.6 / 396.0 / 397.7ms, data_steps 이벤트는 451.2 / 442.1 / 442.7ms였다. 첫 출력 이후 data_steps까지의 간격은 48.6 / 46.1 / 45.0ms다.

세 실행 모두 첫 이벤트는 download_regression_syntax였고, data_preview_table, category_label_table, variable_table, data_view 관련 출력, data_loaded_message, Excel 안내/미리보기 등을 거친 뒤 data_steps 이벤트가 관측됐다. 번들 Shiny의 values 처리 코드는 각 receiveOutput을 await하며 순회하므로 앞선 출력의 처리 지연이 뒤 출력 이벤트 시각에 포함될 수 있다. 이 순서는 클라이언트 이벤트 순서이며 서버의 계산 시작 순서나 원시 네트워크 프레임 순서를 뜻하지 않는다.

## 판단

약 0.44초 전체를 data_steps 생성이나 전송 한 구간의 비용으로 취급하지 않는다. 서버 초기 설정 중에서는 데이터 작업공간 설정 약 0.143초가 가장 크다. `R/app_server.R`의 이 계측 범위는 서버 상태 생성, 기본 설정, lazy UI 등록, 자료/변수/복원용 반응형 함수와 관찰자 등록, 데이터 표 출력 등록 등을 포함한다. 파일을 읽는 시간만을 의미하지 않는다.

다음 후보는 이 설정 범위 안의 함수별 비용이다. 첫 화면에 필요한 의존성을 확인하지 않고 초기 설정을 일괄 지연시키거나, 클라이언트 출력 순서를 바꾸지는 않는다. 약 0.045초의 클라이언트 출력 간격도 관측됐지만, 특정 표의 처리 비용을 개별 측정한 것은 아니므로 표 렌더링을 원인으로 확정하지 않는다.

이번에 만든 재현 자료는 `output/electron-output-stages-20260915/server-timeline.cjs` 및 `server-timeline.json`이다. 입력은 기존 result-1/2/3.json과 startup-through-1/2/3.log다. 서로 다른 시계의 절대 시각을 빼서 미측정 구간을 계산하지 않았다. 제품 변경, 추가 성능 개선, 수치 결과·RNG·내보내기의 신규 검증은 없다.
