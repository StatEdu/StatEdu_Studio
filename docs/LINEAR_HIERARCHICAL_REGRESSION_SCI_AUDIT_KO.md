# 선형·위계적 회귀 SCI 수준 검증 기록

검토일: 2026-08-21
검증 스크립트: `scripts/validate_linear_regression_sci.R`

## 결론

선형·위계적 회귀의 OLS, HC3, bootstrap, 결측 표본, 증분 설명력, 진단, UI 및 내보내기를 독립 기준식과 비교했으며 현재 자동화 검증 범위는 통과했다. 수치 구현의 정확성은 확인했지만 회귀계수의 인과적 해석, 누락 교란 부재, 측정오차 부재 또는 관측 독립성을 보증하지 않는다.

## 독립 검증 범위

- OLS의 B, SE, beta, R², adjusted R², 전체 F와 p값을 직접 `stats::lm`과 비교했다.
- 각 계수의 sr²와 f²를 해당 열을 제외한 축소모형으로 다시 적합해 검증하고, VIF는 보조회귀식으로 독립 계산했다.
- Durbin-Watson d를 잔차 차분제곱합 공식으로 확인했다.
- 이분산 자료에서 `sandwich::vcovHC(type="HC3")` 계수 SE와 HC3 공분산 기반 전체 Robust Wald F를 직접 계산했다.
- 동일 seed의 사례 재표집을 수동 `lm.fit`으로 수행해 BC·percentile CI, Boot SE, plus-one bootstrap p값과 재현성을 비교했다.
- 위계모형의 최종 블록 완전사례 표본 고정, ΔR², 고전적 F-change와 짝지은 bootstrap ΔR² BC CI를 검증했다.
- rank-deficient 모형 차단, 결과 HTML bootstrap 진단 및 일반·위계 Excel 진단 시트를 확인했다.

## 발견 및 보완

1. HC3 계수 추론을 선택해도 전체 모형은 일반 OLS F를 표시하던 불일치를 수정했다. HC3 적용 시 전체 비절편 계수 공동검정은 `Robust Wald F`로 표시한다.
2. 계수와 ΔR² bootstrap에 유효 반복수 판정이 없던 문제를 수정했다. `Adequate`(80% 이상), `Caution`(50~80% 미만), `Unreliable`(50% 미만 또는 20회 미만)을 표시하고 Unreliable CI와 p값을 억제한다.
3. 완전 다중공선성으로 계수가 식별되지 않는 rank-deficient 모형을 경고 후 계속 출력하던 경로를 차단했다.
4. bootstrap 진단을 결과 화면과 일반·위계 회귀 Excel 내보내기에 추가했다.
5. HC3 및 bootstrap 모형의 R²가 여전히 OLS 설명력 지수임을 결과 각주와 방법론 문서에 명확히 했다.

## SCI 리뷰어 대응 경계

- 잔차 정규성·Breusch-Pagan p값 기반 자동 선택은 분석을 구조화하는 휴리스틱이다. p값만으로 추정법을 사후 선택했다고 방어하지 말고 설계, 표본크기, 잔차 그림, HC3/bootstrap 민감도 분석을 함께 제시한다.
- HC3는 이분산에 대한 공분산 보정이며 비선형성, 누락변수, 내생성, 비독립 관측 또는 측정오차를 해결하지 않는다.
- Durbin-Watson은 관측 순서가 의미 있는 자료에서 1차 자기상관을 점검하는 도구다. 군집·패널·반복측정 자료의 독립성 문제는 다층·GEE·패널 모형으로 처리한다.
- VIF 5와 10은 진단 참고값이며 자동 변수삭제 기준이 아니다. 범주형 변수의 표시는 설계행렬 열별 VIF이므로 다자유도 변수 전체의 GVIF와 구분한다.
- 위계 블록 순서는 이론 또는 사전계획으로 정하고 결과에 맞춰 순서를 변경하지 않는다. ΔR²는 동일 표본·중첩모형에서만 비교한다.
- beta는 척도 변환 계수이며 범주형 더미의 beta를 연속형 예측변수의 표준화 효과와 동일하게 해석하지 않는다.

## 남은 한계

- 현재 엔진은 독립 관측의 연속형 결과 회귀가 대상이다. 내생성, 도구변수, survey design, 군집·종단 자료에는 해당 전용 분석을 사용해야 한다.
- BC는 BCa가 아니며 모든 자료에서 percentile보다 우월하다고 주장하지 않는다.
- 자동화 검증은 소스 결과와 Excel 구조를 확인한다. 배포 설치본의 장시간 bootstrap 진행·취소 UX와 실제 화면 배치는 릴리스 수동 QA 항목이다.
