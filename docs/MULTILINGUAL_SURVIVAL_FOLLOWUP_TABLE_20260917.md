# 검열·추적관찰 진단 표 점검

## 결과

이 표에는 추가 번역 누락이 없었다. 제품 코드와 번역표를 변경하지 않고 재현 가능한 검증 스크립트를 추가했다.

`scripts/validate_survival_followup_table_i18n.R`에서 실제 Kaplan–Meier·Cox·경쟁위험 분석 × 8개 언어 검사를 통과했다.

- 7개 열 제목 모두 한국어 및 6개 추가 언어에서 영어로 남지 않음을 확인.
- 언어에 따른 진단 수치 변경 없음.
- 전체 보고 안내 패널의 두 번째 표에 동일한 제목·수치가 표시됨을 확인.
- 데이터가 없는 경우 빈 진단 표를 반환함을 확인.

검사 로그: `tmp/survival-followup-table-i18n.log`.

이번에는 출력 변경이 없으므로 새 저장 파일을 만들지 않았다. 이 표를 포함한 전체 안내 패널의 현재·누적 5개 형식 저장 검증 기록은 `MULTILINGUAL_SURVIVAL_REPORTING_NOTES_20260917.md`에 있다. 전체 앱 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
