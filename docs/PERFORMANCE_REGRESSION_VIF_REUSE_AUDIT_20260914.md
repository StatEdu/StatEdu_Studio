# 복수 종속변수 회귀의 VIF 재사용 가능성 — 2026-09-14

## 발견

`prepare_regression_analysis_results`는 종속변수별 모형을 준비하고, 각 `coeftest_table`이 `coefficient_collinearity`를 호출한다. 예측변수의 실제 설계행렬이 같아도 VIF와 공차를 다시 계산한다. 이번에는 호출 입력과 비용을 기록했으며 캐시를 제품에 구현하지 않았다.

종속변수 4개·예측변수 12개의 완전 자료에서 같은 설계행렬을 4회 전달했다. 종속변수들의 결측 위치가 모두 같을 때도 동일했다. 결측 위치가 종속변수마다 다르면 설계행렬 4개가 서로 달랐다. 동일성 판단은 행 이름과 열 이름 및 모든 속성을 포함한 `identical(..., num.eq=FALSE)`를 사용했다.

## 조건 및 측정

번들 R 4.5.3, 시드 714, 2,000행, 연속 예측변수 12개, 종속변수 4개, 일반 OLS, 잔차 진단 활성화 조건이다. 자동 강건 추정은 끄고 부트스트랩 작업이 0개인지 확인했다. 공통 결측은 모든 종속변수의 첫 200행, 개별 결측은 종속변수마다 무작위 200행이다.

새 R 프로세스 세 개를 순차 실행했다. 각 조건에서 준비 실행, 계측 없는 전체 분석, 입력 기록과 VIF 함수 시간 계측을 추가한 전체 분석을 실행했다. VIF 입력을 먼저 강제 평가한 뒤 해당 함수 시간을 측정하여 설계행렬 생성의 지연 평가 비용을 섞지 않았다. 입력 동일성 검사와 기록 비용도 함수 시간 밖이다. 다른 R 작업을 동시에 실행하지 않았다. 로딩·자료 생성·화면·저장은 제외했다.

| 조건 | 계측 없는 전체 3회(초) | 계측 전체 3회(초) | VIF 함수 합계 3회(초) | 호출/서로 다른 행렬 |
| --- | --- | --- | --- | --- |
| 완전 자료 | 0.22 / 0.22 / 0.21 | 0.22 / 0.22 / 0.22 | 0.08 / 0.07 / 0.09 | 4 / 1 |
| 공통 결측 | 0.21 / 0.21 / 0.21 | 0.21 / 0.22 / 0.22 | 0.06 / 0.09 / 0.08 | 4 / 1 |
| 서로 다른 결측 | 0.25 / 0.23 / 0.28 | 0.28 / 0.30 / 0.27 | 0.09 / 0.08 / 0.09 | 4 / 4 |

완전 자료의 VIF 계산 합계 중앙값은 0.08초로, 직전 검토한 ANCOVA 영향력 진단의 호출당 약 0.3밀리초보다 검토 가치가 큰 중복이다. 하지만 이 표는 캐시 적용 전후 비교가 아니다. 4번 중 3번을 생략하면 전체 시간이 특정 비율만큼 줄어든다고 확정할 수 없다. 캐시 조회 및 보관 비용을 포함한 후보 측정이 필요하다.

## 후속 후보의 범위

한 번의 복수 종속변수 분석 안에서 실제 설계행렬이 정확히 같은 경우에만 VIF·공차 결과를 재사용하는 후보가 적절하다. 변수 이름만 비교하면 종속변수별 결측 처리 차이를 놓친다. 분석 사이에 전역 캐시를 유지할 필요는 없으며 입력·속성이 바뀌면 다시 계산해야 한다. 경고·메시지·오류가 발생한 계산을 캐시해 진단 조건을 생략하지 않도록 해야 한다.

종속변수에 의존하는 효과크기, 회귀계수, 표준오차 및 검정 결과는 이번 재사용 대상이 아니다. 위계적 회귀·자동 강건 추정·로지스틱·일반화 모형에 대한 효과는 이번 자료로 확인하지 않았다.
