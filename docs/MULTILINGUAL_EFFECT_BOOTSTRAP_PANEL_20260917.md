# 경로·간접·총효과 부트스트랩 진단 다국어 보완

- 진행·중단·실패·유효 반복 없음 안내, 진단 제목, 조절된 매개효과 지수 제목, 방법 및 해석 설명을 UI 언어로 표시한다.
- 알려진 원모형 부적격 사유는 번역하고, 추가된 사유 상세와 미등록 오류는 그대로 보존한다.
- 보조표의 CI 방법·상태·표준화 지수 설명을 명시적으로 번역한다. 경로명과 조절변수명을 포함한 셀은 일반 테이블의 재번역으로부터 보호한다.
- 한국어에서 남아 있던 분위수 계산 방식·간접 경로·표준화 지수 등의 열 이름도 보완했다. R type 번호·seed·반복 횟수·추정값·CI·p값은 유지한다.
- 계산 로직과 본표 생성은 변경하지 않았다. 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_effect_bootstrap_panel_i18n.R`: 실제 renderUI 표현식으로 14개 경우 × 8개 언어를 검증했다. 백분위/편향보정 방식, 구형 결과 필드 누락, 조절된 매개효과 없음, 진행/중단/실패/빈 결과/비활성화, 세 실행 차단 사유 및 사용자 상세를 포함한다.
- 정상 표에서 Adequate/Caution/Unreliable 상태와 표준화 지수 설명을 포함했다. 숫자 셀의 언어별 동일성, 경로·조절변수명, 특수문자, seed, 95%와 80% 표기, 영어 본표 HTML 유지 확인.
- 기존 `validate_sem_structural_reporting_tables.R` 통합 검증 통과.
- `tmp/effect-bootstrap-panel-i18n/entries.rds` 표시 스냅샷으로 현재·누적 HTML/PDF/Word/HWPX/Excel 변환을 검증했다. 현재 20표·누적 23표의 순서와 Excel 시트 수, PDF 일본어 문구와 표지를 확인했다. 저장 중 분석 재실행은 하지 않았다.
- 안내문만 있는 경우 대표 영어 본표와 실제 안내 HTML을 함께 넣어 Excel 저장을 검증했다.

이 검증은 해당 부트스트랩 진단 패널에 한정하며, 프로그램 전체의 다국어 완료 판정은 아니다.
