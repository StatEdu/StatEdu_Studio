# 원인별 Cox 검정 실패 경고

전체 모형 검정의 비유한 값과 범주형 전체 검정 추정 불가에 대한 근거/안내
4개 번역 항목을 추가했다. 실패한 변수명은 동적 접두문 뒤에 원문 그대로 유지한다.

## 검증

- `validate_cause_specific_failure_i18n.R`: 실제 경쟁위험 결과에 정상/통계량 결측/
  자유도 결측/p값 결측의 진단 메타데이터를 넣어 경고 조건을 8개 언어로 검사했다.
  범주형 검정의 일부 실패도 함께 검사했다. 실패 모형을 직접 적합한 검사는 아니다.
- 실패 변수 선택·사용자 문자열 보존, 번역 근거/안내, 실제 영어 CIF 본 표 유지 확인.
- Gray 실패 경고 회귀 검사 통과.
- 일본어 현재 3개 / 누적 4개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 원인별 Cox의 비례위험·영향력·공선성 경고 등은 점검이 남아 있다.
