# 종단 가중치 요약 통계 — 2026-09-17

기본·IPW·최종 가중치 요약과 생성 IPW 요약의 `min=…; median=…; max=…`에서 고정 영어 항목을 UI 언어의 최솟값·중앙값·최댓값으로 연결했다. 영어 모드와 본표는 기존 표기를 유지한다.

전체 문장이 알려진 숫자 형식일 때만 번역한다. 숫자를 다시 변환하거나 반올림하지 않고 문자열 그대로 삽입한다. 소수점 생략형, 양·음 부호, 지수 표기 및 후행 0을 보존한다. 알 수 없는 사용자 문자열과 사용자 변수명 열의 동일 문구는 원문으로 유지한다.

`validate_longitudinal_weight_summary_i18n.R`에 실제 5설정 × 8언어 요약값의 정확한 번역 형식 검사와 `-1.2300e-09`, `.5000`, `2.000E+02` 보존 검사를 추가했다. 사용자 변수명·미등록 문자열·기존 숫자 열 및 원본 결과 보존 검사도 수행한다.

실제 요약 표가 포함된 `validate_longitudinal_error_exports.R`로 기존 MI/IPW·상태·사용자 이름 검사와 함께 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel을 검증한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 별도 확인한다. 산출물은 `tmp/longitudinal-error-exports`다.

계산식·설치본·메타분석은 변경하지 않았다. 전체 브라우저·모형 조합·페이지별 시각 검토는 별도 남은 범위다.

위 검사와 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 캡처 텍스트도 통과했으며 각 언어 현재 21쪽, 누적 41쪽이다. 변경 파일의 `git diff --check`도 통과했다.
