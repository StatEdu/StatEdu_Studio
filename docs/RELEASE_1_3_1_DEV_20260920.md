# StatEdu Studio 1.3.1-dev — 2026-09-20

This is the developer continuation of public 1.3.0. VERSION_DEV is 1.3.1-dev;
VERSION and public citation/release metadata remain 1.3.0. Source launches select
the edition-specific version, and Electron package/lock metadata agree. Existing
installers are unchanged; this update does not create an installer or a public release.

## Changes reviewed

- Carry forward the public 1.3.0 code, data/settings path handling and reporting baseline.
- Clean canvas exports and covariate-inclusive/exclusive model figures.
- Single-indicator original-item panel with multiple-item drag, radio controls,
  mean/omega defaults, 80% response means, persisted constraints and diagnostic audit.
- Show editor controls only for exactly one measurement indicator; keep sidebar
  field positions stable and display fixed coefficients to at most three decimals
  without rounding the underlying parameter.
- Loading-balanced parcels from standardized one-factor CFA loadings, saved
  allocation/fit diagnostics, and common measurement layout in four orientations.
- Invalid loading diagnostics identify the item and value; they do not claim that
  negative loadings prove incorrect reverse scoring. Invalid automatic allocation
  remains blocked. Existing item values are not changed.
- SEM bootstrap worker/data-transfer and guarded metadata-cache optimizations,
  with paired fixed-index equivalence tests. See SEM_MLR_BOOTSTRAP_SPEED_20260920.md.

## Review corrections

- Fixed development source launches reading public VERSION.
- Fixed Electron lockfile version remaining at 1.3.0.
- Saved-result branding and analysis command metadata now use the active edition version.
- Updated version/menu, settings-dialog localization and CFA title assertions to
  reflect the current implementation rather than outdated literal source strings.
- Excluded local research projects, sample working folders, Python caches and
  transient UI artifacts from source publication.

## Validation

Passed focused version/edition, settings dialogs, analysis commands, custom model,
CFA, SEM, PLS model contract, metadata cache, fixed-index MLR bootstrap, structural
bootstrap performance/reproducibility and startup contract checks. Settings and
CFA checks were rerun successfully after repairing their outdated assertions.

Canvas score statistical tests and current/accumulated HTML/PDF/DOCX/HWPX/XLSX
exports passed. Live Shiny/Chrome checks passed multiple selection, drag/reorder,
preview/apply, automatic parcel allocation, four-direction geometry equivalence,
untouched neighboring groups, persistence and undo/redo. The current candidate
passed syntax parsing of 1,073 R files and 108 JavaScript files, plus repository
fixture and release-hygiene checks. These are focused checks, not a claim that the
entire Full stabilization/installer suite ran. No installer build was requested.

## Remaining limitations

- A meaningful full-application SEM menu-opening speedup has not been demonstrated.
- Loading balance does not establish unidimensionality; inspect original-item fit.
- A shared error variance for partial-response means is an approximation;
  reliability-estimation uncertainty is not propagated by the conditional bootstrap.
- Saved existing multi-indicator parcel models keep their existing assignments.
