# 복합표본 교차표 다국어 검증

## 수정

- 결측 행 제외, 특정 조합 계산 실패, 전체 표 미계산 안내를 먼저 번역한 뒤 사용자 변수 이름과 숫자를 삽입한다.
- 완전한 사례가 없는 경우의 오류 내용과 교차표 진단 제목을 한국어 및 추가 6개 언어에 연결했다.
- 완성된 교차표 진단 문장을 공통 번역기에 다시 전달할 때 변수 이름이 사라지는 문제를 확인했다. 해당 진단의 Details 열은 완성된 문장을 보존하고, 항목명·열 제목은 UI 언어로 표시하도록 수정했다.
- 알 수 없는 외부 오류는 원문을 유지한다. 모델 적합과 본표 수치는 변경하지 않는다.

## 검증

- `scripts/validate_complex_crosstab_i18n.R`: 120행, 3개 층, 30개 PSU, 가중치를 적용한 실제 교차표. 행 변수에 결측 2건, 전체 결측 변수 조합을 포함했다.
- 정상 조합과 제외 조합이 함께 있는 결과, 모든 조합이 제외되는 결과를 8개 언어로 확인했다. 본표 셀·주석, 사용자 행/열 이름 및 % 기호, 제외 건수 보존 통과.
- 언어 속성뿐 아니라 실제 번역된 결측·오류·전체 미계산 문장을 비교했다.
- 기존 `validate_complex_sample_analysis.R` 전체 통과: 빈도·교차표·집단 비교·상관·회귀·로지스틱과 설정의 회귀 검사.
- 근거: `tmp/complex-crosstab-i18n`, `tmp/complex-crosstab-regression.log`, `scripts/fill_complex_crosstab_i18n.py`.
- 일본어 결과 스냅샷으로 현재·누적 HTML/PDF/Word/HWPX/Excel 생성과 내용 대조 통과. 실제 PDF 본문·표지 검사도 통과했다. 로그: `tmp/complex-crosstab-exports.log`.

## 제한

- 대표 교차표는 기본 검정과 기본 백분율 설정이다. 추세검정, 다른 검정·백분율 옵션, 복제 가중치/FPC, 부모집단, 모든 외부 오류, 브라우저 왕복/분할은 별도 검증이 필요하다.
- 설치본을 만들지 않았다.
