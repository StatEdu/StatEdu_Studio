# 매개·조절효과 캔버스: 화살표 기반 역할 인식

- 사각형 측정변수 아이콘을 선택하고 캔버스를 클릭하면 빈 사각형이 즉시 배치된다. 대화상자는 열지 않는다. 왼쪽 데이터 변수를 사각형에 끌어 넣어 지정한다. 기존 사각형의 변수를 바꿔도 위치와 연결 ID는 유지한다. 데이터가 지정되지 않은 사각형은 분석 전에 안내한다.
- SEM과 동일한 연결 포인터 처리기를 사용한다. 변수에서 변수로 드래그하면 회귀 경로, 변수에서 회귀 경로로 드래그하면 조절 연결이 된다.
- 들어오는 경로 없이 나가는 경로가 있으면 독립변수, 양쪽 모두 있으면 매개변수, 들어오는 경로만 있으면 종속변수, 회귀 경로에 연결하면 조절변수로 판정한다. 연결되지 않은 사각형은 연결 대기로 표시하고 분석 시 안내한다.
- 직렬 매개의 순서는 배치 좌표 대신 위상 정렬로 계산한다. 다중 종속변수 지원을 유지한다. 순환 경로와 지원 범위를 넘는 조절변수 수를 차단한다.
- 왼쪽 변수를 선택한 뒤 C 아이콘을 누르면 대화상자 없이 공변량으로 지정한다. 다중 선택을 지원하며 이미 지정한 공변량을 다시 선택하고 C를 누르면 해제한다. 공변량의 자료형 정보와 기존 통제 설정을 유지한다.
- 후속 요청에 따라 매개·조절효과/CFA/SEM/PLS-SEM의 왼쪽 환경설정 영역을 복원했다. 변수 목록은 330px에서 402px로 3행(24px × 3) 늘리고, 패널 높이 530px 및 환경설정 하단 위치는 유지한다. 환경설정 내용이 길면 해당 영역에서 스크롤한다. 배치 안내문은 제거한 상태를 유지한다.
- 새 사각형에는 `autoRole`을 저장한다. 기존 파일은 읽을 수 있고, 연결 편집 또는 새 측정변수 추가 시 자동 역할 모드로 전환된다. 실행 취소·다시 실행·삭제·저장 복원 시 연결과 역할이 일치해야 한다.
- 분석 엔진과 출력 형식을 교체하지 않는다. 자동 판정한 역할과 경로를 기존 분석 명세에 전달한다. 기존 역할 방식과 같은 그래프의 명세가 완전히 일치하는지 검증한다.

검증: `scripts/validate_mm_arrow_roles.cjs`의 실제 마우스 배치/연결/조절, 실행 취소·다시 실행, 삭제 후 재판정, 공변량 자료형, 저장 복원 및 순환 거부; `scripts/validate_mm_arrow_roles.R`의 브라우저 스냅샷 분석 명세, 기존 명세와의 일치, 저장된 역할이 틀린 경우 재판정, 미연결/순환 오류, 좌표와 무관한 직렬 순서, 다중 종속변수. 기존 custom model 및 mediation note 검증과 네 편집기의 300/600 DPI 그림 저장 테스트도 통과했다.

이 변경은 소스 수정이며 설치본을 새로 생성하지 않았다.
