# 현재 Cox 분석 병목 재측정 — 2026-09-14

## 결론

현재 운영 코드의 전체 Cox 분석을 프로파일링했다. 주요 검토 대상은 VIF 보조회귀를 포함한 다중공선성 진단과 Cox 모형 적합이다. 이번에는 운영 코드를 변경하지 않았다.

## 방법

동봉 R 4.5.3, 정규 합성 공변량 10개, 50,000행, 난수 시드 42를 사용했다. 생존 시간은 첫 공변량에 의존하는 지수분포를 소수 둘째 자리로 반올림했고 사건 확률은 0.7이다. 기본 Cox 분석 옵션을 사용했다.

새 프로세스 3개를 순차 실행했다. 각 프로세스에서 한 번 예열하고 GC 후 프로파일러 없이 한 번 전체 `prepare_cox_analysis_result()`를 측정했다. 이어서 같은 분석을 5회 실행하며 Rprof의 0.02초 간격으로 호출 스택을 수집했다. 결과 비교는 프로파일러를 종료한 뒤 수행했다. 패키지 로딩, 자료 생성, HTML 렌더링, 저장 파일 생성은 측정에 포함하지 않았다.

프로파일러 없는 실행 시간은 세 번 모두 0.64초였다. 이는 예열된 분석 함수의 시간이며 프로그램 로딩이나 화면 대기 시간이 아니다. 앞선 별도 실험과 예열·호출 조건이 달라 그 수치와 비교해 새 성능 향상으로 해석할 수 없다.
