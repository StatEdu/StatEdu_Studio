# 열린 메타분석 입력 창의 실시간 번역 — 2026-09-17

모달 제목·안내문·취소 버튼을 reactive text 출력으로 연결했다. 언어 변경 시 입력 레이블·예시·형식 선택지·효과 방향 선택지·저장 버튼을 Shiny update 함수로 갱신한다. 텍스트/숫자/체크 값은 업데이트에 전달하지 않으며, 선택지는 현재 선택값을 명시적으로 유지한다. 모달 전체를 재생성하지 않는다.

실제 Chromium의 로컬 최소 앱에서 한국어로 열린 창을 영어·일본어·중국어·스페인어·프랑스어·독일어·베트남어·한국어로 바꾸며 제목, 저장/취소, 안내문, 텍스트/연도/선택 레이블, 예시를 검사했다. 사용자 연구명, 숫자 3개, 빈칸, 포함 체크 해제, negative 방향, means 형식이 유지되고 취소 후 새 창은 비어 있음을 확인했다. 언어 이벤트는 Shiny 입력으로 전달했으며 전체 설치 앱의 메뉴 조작은 아니다.

14개 형식의 실제 서버 draft 검사와 추가/편집 모달 렌더링 검사도 수행한다. 편집 창 제목·안내문·취소 문구의 8언어 출력은 서버에서 확인한다. 분석 계산과 결과 출력은 변경하지 않았고 설치본은 만들지 않았다.

위 브라우저·서버·렌더링 검사는 모두 통과했다.
