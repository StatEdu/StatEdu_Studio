# 이항 GLMM 선택 모형 재사용

## 적용

`R/analysis_longitudinal.R`에서 이항 GLMM의 선택 모형을 같은 분석의 민감도 분석에 재사용한다. 동일한 준비 데이터, 반응/시간/ID, 설명변수, 가중치, cluster, offset, exponentiate 및 무작위 기울기 설정으로 이미 적합한 모형이 대상이다. 대안 무작위 효과 구조는 기존처럼 새로 적합한다.

기존 GEE의 재사용 보호 조건을 공유하여, 첫 적합에서 경고·메시지가 발생하거나 RNG 상태가 달라지면 재사용하지 않는다. 오류와 진단 메시지를 억제하지 않는다. random_slope FALSE/TRUE를 지원하되 이번 확장은 이항 GLMM으로 한정했다. LMM 및 다른 GLMM 분포는 기존 동작을 유지한다. 전역 모형 캐시는 사용하지 않는다.

민감도 분석의 후속 처리는 AIC/BIC 읽기와 `isSingular` 검사이며 모형을 다시 추정하지 않는다. 정상 재사용에서 앱 적합 호출은 3회에서 2회로 줄어든다.

## 성능

번들 R 4.5.3, seed 939, 500명 × 6시점 = 3,000행, 두 공변량, 이항 반응과 기본 분석 옵션을 사용했다. 워밍업 후 독립 프로세스 3개를 순차 실행하고 두 번째 프로세스에서는 변경 후 코드를 먼저 측정했다. 로딩 시간은 제외했다.

| 선택 모형 | 변경 전 1 / 2 / 3 (초) | 변경 후 1 / 2 / 3 (초) | 중앙값 |
|---|---|---|---|
| random_slope FALSE | 1.31 / 1.12 / 1.29 | 0.92 / 1.05 / 0.86 | 1.29 → 0.92초, 약 29% 감소 |
| random_slope TRUE | 1.19 / 1.17 / 1.17 | 1.18 / 1.17 / 1.15 | 1.17 → 1.17초 |

FALSE에서는 세 번 모두 빨라졌다. 이 경우 대안 기울기 모형에서 발생한 singular fit 메시지 1회는 그대로 남는다. TRUE에서는 선택 모형에 실제 singular fit 메시지가 발생해 재사용하지 않았고, 메시지 2회가 유지됐다. TRUE 행의 작은 시간 변화를 최적화 효과로 해석하지 않는다.

이 결과는 해당 자료와 환경의 측정이며 모든 자료에서 같은 개선율을 보장하지 않는다.

## 검증

`scripts/validate_longitudinal_glmm_reuse.R`의 20개 조건을 통과했다. 무작위 기울기 FALSE/TRUE 각각에서 정상, 경고, 메시지, RNG 소비, 오류, 비지수화 계수, 가중치, 결측/역순 자료, factor 반응을 확인하고, 적용하지 않는 LMM과 Poisson GLMM도 확인했다.

정상 재사용 10개(기울기 TRUE 5개 포함), 재적합 유지 8개, 오류 2개였다. 모형 적합 호출 수와 반올림 전 AIC/BIC 및 특이성 판정도 비교했다. 실제 특이 적합 메시지 보존은 위 성능 자료에서 추가 확인했다.

전체 반환 결과, 경고/메시지의 클래스·본문·순서, 표준 출력, RNG 상태를 수치 허용오차 없이 비교했다. merMod는 고정효과, 무작위효과, 공분산, 적합값, 잔차, logLik, theta, devcomp, optinfo, call, model frame을 추출하여 비교한다. formula/terms 환경과 함수 표현은 정규화한다. 모든 내부 슬롯이나 외부 포인터의 동일성까지 주장하지 않는다.

비교는 `identical(..., num.eq = FALSE)`이다. 지속 검증의 참조 경로는 GLMM 선택 모형 재사용을 끄며, 추가로 변경 전 소스를 직접 로드한 비교에서도 같은 20개 조건을 검증했다. 성능 측정의 워밍업 및 측정 결과도 변경 전 소스와 직접 비교했다.

기존 GEE 재사용 검증 48개 조건을 다시 실행하여 기존 동작과 QIC 원값을 확인했다. 새 출력이나 출력 형식 변경은 없다.

## 범위와 증거

이전에 변경 전 코드에서도 재현한 종합 테스트의 Excel 셀 위치 비교 실패는 이번에 해결하거나 재실행하지 않았다. 이번 변경에 관련된 GLMM/GEE 검증을 수행했다. 전체 형식 변환과 설치 파일 빌드는 실행하지 않았다. 기존 작업 트리의 다른 변경은 유지했다.

`output/longitudinal-glmm-reuse-20260914/`에 `baseline.R`, `candidate.R`, `bench.R`, `normalize.R`, `timing-1/2/3.csv`, `validation.log`, `validation-old-source.log`, `gee-regression.log`를 보관한다. 비교용 모형 추출 코드는 `scripts/fixtures/longitudinal_mermod_normalize.R`에 있다.
