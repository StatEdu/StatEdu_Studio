# 요인분석 저장 이미지 캐시 — 2026-09-14

탐색적 요인분석(EFA)의 HTML·PDF·Excel 저장에 세션별 스크리 그림 캐시를 적용했다. 반복 저장용 HTML 생성 중앙값은 0.49초에서 0.20초로 약 59.2% 줄었다. 첫 저장과 프로세스 최대 메모리는 거의 같았다. 앞서 보류한 EFA JIT 변경은 적용하지 않았다.

## 변경

`factor_analysis_results_ui`, `saved_factor_analysis_results_html`, 직접 HTML/PDF/Excel 저장 함수에 선택적 `plot_renderer`를 전달한다. 기본값은 기존 `plot_data_uri`다. 서버에서는 기존 `correlation_export_image_cache()`로 별도의 세션 캐시를 만들어 저장 이벤트에 전달한다. 캐시 구현은 변경하거나 복제하지 않았다.

같은 결과와 그리기 문맥에서는 PNG를 재사용하고 표·문서는 매번 기존 경로로 생성한다. 새 분석 성공, 선택 초기화, 세션 종료 시 캐시를 비운다. 분석 실패 시 기존 결과와 캐시는 유지한다. 직접 그림 파일 저장은 기존 경로를 유지한다.

캐시는 결과 전체, 함수, 그림 크기·해상도, DPI, R 옵션, 로케일, 작업 폴더, Windows 그래픽 설정·폰트를 정확히 비교한다. 경고·메시지 또는 RNG 변경이 있는 그리기는 보관하지 않는다. 보관 상한은 2개 항목과 `object.size` 추정 합계 16 MiB다. 현재 분석은 스크리 그림 1개를 보관한다. 이는 전체 프로세스나 환경 참조 전체의 메모리 상한은 아니다. 임의의 표준 출력을 감지하는 범용 캐시는 아니며 실제 함수의 표준 출력 동일성은 검증했다.

통계 계산, 출력 내용, 그림 해상도·장치, 누적 결과의 스냅샷 변환은 변경하지 않았다.

## 성능

번들 R 4.5.3, Windows, seed 714, 2,000행·20변수, 주축요인법, 고정 2요인, varimax, 하위요인 신뢰도 켜짐, 정규성 검사 꺼짐, 600 dpi 조건이다. 분석과 모듈 로딩 후 첫·반복 HTML 생성을 측정했다. 방식별 새 프로세스 3개를 순차 실행했으며 2회차는 순서를 반대로 했다. 다른 R 검사·변환 및 메모리 관측은 타이밍 실행과 분리했다.

## 메모리·수명

별도의 새 프로세스 3쌍에서 실제 계산 PID의 Windows `PeakWorkingSet64`를 관측했다. 패키지 로딩·분석·첫/반복 HTML 생성·검증 자료 저장까지 포함하는 전체 프로세스 최고치다. MB는 1,000,000 bytes다.

차이는 약 0.012 MB로 사실상 비슷하다. 저장 후 캐시 항목은 1개, 추정 보관량은 2,267,560 bytes였다. 실제 서버에서 새 분석·초기화·종료 후 항목이 0개임을 확인했다. OS에 즉시 메모리가 반환되거나 모든 장시간 실행에 누수가 없음을 보장하는 검사는 아니다.

## 정확성·서버 검증

- 타이밍 3쌍과 메모리 3쌍에서 HTML 전체(내장 PNG 포함), 경고·메시지, 표준 출력, RNG가 `identical(..., num.eq=FALSE)`로 일치했다. 각 실행의 첫·반복 결과도 같고 분석 결과 직렬화 값은 저장 전후 동일했다.
- 변경 전 소스와 적용 후 캐시 경로를 12조건에서 비교했다: 기본, 보고서 모드, 사용자 CSS, 소수점 쉼표 표시, 영어, 변수 라벨, 300 dpi, 정규성 검사, 1요인, oblimin, 최대우도법, 결측 자료. 모든 HTML·PNG·조건·출력·RNG가 일치했다. 소수점 표시 옵션은 분석 완료 후 변경해 저장 단계를 비교했다.
- 기존 공통 캐시 검증에서 정확한 키 비교, FIFO·크기 제한, 인자·함수·문맥 변경, 독립 객체, 초기화 및 경고·메시지·RNG·오류 우회가 통과했다.
- 실제 앱 서버를 MockShinySession에서 실행해 요인분석 메뉴 진입과 분석, HTML 두 번·PDF·Excel 저장을 검증했다. PNG 생성은 1회였으며 재분석 후 다음 저장에서는 다시 생성했다. 초기화와 종료도 캐시를 비웠다. 이 서버 검사에서 PDF 변환은 입력 HTML 기록용 대체 함수였고, 별도 직접 저장 검사에서는 실제 PDF 변환기를 사용했다.
- 실제 직접 HTML·PDF·Excel 저장 함수에서도 PNG 생성은 정확히 1회였다.
