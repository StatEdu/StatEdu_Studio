# 공변량 모형의 핵심 효과 선택 수정

기존 해석 보조표는 표시 이름이 ` x Time`으로 끝나는 첫 행을 선택했다. 공변량×시점 행이 처치×시점보다 앞에 있을 때 잘못된 효과의 p값으로 후속 비교를 권고할 수 있었다.

ANOVA 표에 모형 내부 효과 식별자를 보관하고 `Treatment:Time` 행을 선택하도록 수정했다. 공변량의 사용자 표시 이름이 `Treatment x Time`과 같아도 구분한다. 사후비교 안내 셀도 같은 식별자를 사용한다. 추정식과 검정 통계량 계산은 변경하지 않았다. 식별자가 없는 이전 표는 정확한 `Treatment x Time` 표시만 사용하며 임의의 공변량×시점으로 대체하지 않는다.

진단 보조표의 효과명은 내부 식별자에서 조합한다. 처치·시점만 UI 언어로 번역하고 공변량 이름은 보존한다. 본표의 효과명은 영어 표기와 사용자 이름을 그대로 유지한다. 공통 출력 함수의 진단 효과명 교체는 일원 반복측정에서 제공하는 메타데이터가 있을 때만 적용한다.

검사: 실제 범주형/복수 공변량 및 옵션 6경로의 핵심 효과·p값, 동일 표시 이름을 가진 서로 다른 효과의 유의/비유의 반대 사례, 처치×시점이 없는 표, 8개 언어의 공변량 이름 보존 및 진단 효과명. 기존 WIDE/LONG 계산·Shiny 서버 및 번역 계약 검사도 포함한다.

위 검사와 공통 본표/보조표 계약 검사(`validate_multilingual_table_roles.R`)가 모두 통과했다. 복수 공변량 모형의 일본어 fixture `tmp/one-group-primary-i18n/entries.rds`로 현재·누적 HTML/Word/HWPX/Excel 내용 비교, PDF 생성 및 실제 PDF 텍스트 검사도 통과했다. 로그는 `tmp/one-group-primary.log`, `tmp/one-group-primary-regression.log`, `tmp/one-group-primary-shared.log`, `tmp/one-group-primary-exports.log`다.

이미 저장된 결과 스냅샷은 재작성하거나 재분석하지 않는다. 실제 앱 메뉴·케이스 선택을 포함한 언어 왕복, 추가 옵션과 외부 오류는 계속 남아 있다. 설치본은 생성하지 않았다.
