# LMM·GLMM 선택 모형 재사용 통합 검증

## 검증 범위

개별적으로 적용한 일반 LMM, 이항/Poisson GLMM, 무작위 절편 Gamma GLMM의 선택 모형 재사용을 현재 소스에서 함께 검증했다. 이번 작업에서 제품 코드는 추가로 변경하지 않았다.

기준 소스는 첫 GLMM 재사용 적용 전의 `output/longitudinal-glmm-reuse-20260914/baseline.R`이다. 이 기준에는 이전 GEE 개선이 이미 포함되어 있으므로, 이번 비교는 GEE까지 포함한 누적 개선율이 아니다. 두 소스의 차이는 혼합모형의 선택 적합 재사용과 적용 조건이다.

## 방법

번들 R 4.5.3, seed 939, 500명 × 6시점 = 3,000행, 두 공변량, 기본 분석 옵션. Gaussian LMM과 binomial/Poisson/Gamma GLMM 각각에서 무작위 기울기 FALSE/TRUE를 비교한다. 자료 생성에는 무작위 절편과 기울기를 포함한다.

워밍업 후 독립 R 프로세스 3개를 순차 실행한다. 두 번째 프로세스에서는 분포 실행 순서를 반대로 하고, 후보를 기준 소스보다 먼저 측정한다. 로딩 시간은 포함하지 않는다. 동일한 자료·옵션으로 두 소스를 별도 환경에 로드하여 실행한다.

## 통합 결과

24개 조건(4개 분석 × 2개 기울기 설정 × 3개 프로세스)의 워밍업 및 측정 결과 비교가 모두 통과했다. 다음은 3회 실행 시간의 중앙값이다.

| 분석 | random_slope | 기준 → 현재 (초) | 해석 |
|---|---|---|---|
| Gaussian LMM | FALSE | 0.56 → 0.29 | 3회 모두 개선 |
| Gaussian LMM | TRUE | 0.29 → 0.22 | 3회 모두 개선 |
| Binomial GLMM | FALSE | 1.05 → 0.77 | 3회 모두 개선 |
| Binomial GLMM | TRUE | 1.18 → 1.17 | 진단 발생으로 재적합 유지 |
| Poisson GLMM | FALSE | 1.17 → 0.87 | 3회 모두 개선 |
| Poisson GLMM | TRUE | 1.38 → 0.89 | 3회 모두 개선 |
| Gamma GLMM | FALSE | 1.42 → 1.04 | 3회 모두 개선 |
| Gamma GLMM | TRUE | 1.61 → 1.59 | 적용 제외, 재적합 유지 |

재사용 대상 6개 설정은 각각 3회 모두 빨라졌다. 재사용하지 않는 두 설정의 작은 시간 차이를 최적화 효과로 해석하지 않는다. 시간에는 비교용 결과 캡처와 모형 추출도 포함되며, 두 코드에 동일한 비교 절차를 사용했다. 해당 합성 자료와 환경의 측정이며 다른 자료에서 같은 개선율을 보장하지 않는다.

각 프로세스에서 진단 조건 수는 LMM 두 설정 모두 0개, binomial FALSE/TRUE는 1/2개, Poisson은 모두 0개, Gamma는 2/4개로 기준과 현재가 같았다. 개수뿐 아니라 클래스·본문·순서도 비교했다.

## 비교 내용과 한계

전체 반환 결과, 조건의 클래스/본문/순서, 표준 출력, 최종 RNG를 비교한다. merMod는 고정효과, 무작위효과, 공분산, 적합값, 잔차, logLik, theta, devcomp, optinfo, call, model frame을 추출한다. formula/terms 환경과 저장된 함수 표현만 정규화하고, 수치는 `identical(..., num.eq = FALSE)`로 허용오차 없이 비교한다. 모든 내부 슬롯·외부 포인터의 동일성까지 주장하지 않는다.

실제 진단이 발생한 이항 기울기 모형 및 적용에서 제외한 Gamma 기울기 모형도 비교 대상에 포함한다. 수치가 같더라도 진단 조건 수나 내용이 달라지면 비교는 실패하도록 구성했다. 개별 적용 단계의 오류·가중치·결측·offset·군집 등 회귀 검증을 대체하는 전수 검증은 아니다.
