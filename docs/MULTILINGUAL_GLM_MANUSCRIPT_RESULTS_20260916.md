# GLM 원고 Results·Software 다국어 보완

2026-09-16. 설치본을 생성하지 않았다.

## 변경

- 6개 언어에 회귀 추정치, 추가 계수 지수화, 카운트 분포 선택, 소프트웨어 사용 및 버전 보고의 문장/형식 7개를 추가했다.
- `generalized_manuscript_text`는 기존 영어 데이터프레임 내용을 유지하며 Results 문장의 원문, 사용자 항 이름, 추가 항 여부, 후속 문장을 속성으로 보존한다.
- 보조표에서 문장 구성요소별로 번역한 뒤 합친다. 사용자 항 이름의 마침표, 쉼표, 퍼센트 또는 `among other terms` 같은 영어 문구는 해석하거나 치환하지 않는다.
- 원고가 수정되어 저장된 원문과 달라지면 구성 정보에 의한 재작성을 건너뛴다.
- Software 문장은 전체 형식을 인식해 프로그램 이름과 버전을 그대로 삽입한다. 통계 계산과 본표는 변경하지 않는다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 생성 함수로 4개 항의 원고를 만들고 Results의 세 문장 번역, 사용자 항 이름, 버전과 사용자 편집 원고의 보존을 검사했다.
- 실제 Gaussian/binomial/count 본표의 영어 및 옵션 값 보존 검사 통과. 합성 count 데이터의 기존 음이항 반복 한도 경고가 발생했으나 렌더링 검사는 통과했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 원고 표를 현재/누적 내보내기 fixture에 추가했다.
- 현재/누적 HTML·Word·HWPX·Excel 내용 비교와 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`에서 두 PDF의 실제 텍스트 비교도 통과했다.

## 남은 범위

Methods 복합 문장과 Assumptions 상세 설명은 추가 점검 대상이다. 이전에 저장한 결과에는 새 구성 속성이 없으므로 문장별 번역 보완이 동일하게 적용된다고 보장하지 않는다. 저장 시 재분석하거나 과거 스냅샷을 재작성하지 않는다.
