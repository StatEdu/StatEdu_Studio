# Fine–Gray 수치 안정성 표

제목 및 열 이름 11개 항목을 6개 추가 언어로 보완했다. 한국어 최대 반복 횟수와
모수 수 열도 보완했다. 계산과 기존 참/거짓 번역 표현은 유지한다.

## 검증

- `validate_fine_gray_optimizer_table_i18n.R`: 실제 age/sex Fine–Gray 모형을 적합하여
  수치 안정성 표를 8개 언어로 검사했다. 별도 표시용 복사본에서 세 논리값을 FALSE로
  바꾸어 부정 표시도 확인했다. 복사본은 실패 모형을 새로 적합한 결과가 아니다.
- 열/제목 번역, 숫자·정밀도 및 실제 영어 Fine–Gray 계수 본 표 유지 확인.
  한국어 기존 부정 표현은 '아니오'이며 테스트 기대값을 이에 맞췄다.
- 수렴·정보행렬 경고 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 나머지 Fine–Gray 잔차 및 검열분포 보조표는 점검이 남아 있다.
