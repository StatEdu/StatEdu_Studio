# 이분형·Poisson GLMM 보고 점검표 — 2026-09-17

실제 이분형 및 Poisson GLMM 적합을 보고 점검표 검사에 추가했다. 군집 표준오차/작업상관 권고, 분포명을 포함한 GLMM 선택 근거, 주요 가정 문제 없음 안내의 3개 문구 형식을 8언어에 연결했다. 분포 식별자와 계산 결과는 그대로 유지한다.

`validate_longitudinal_checklist_models_i18n.R`는 기존 6경로와 GLMM 2개를 합친 8경로 × 8언어, 64개 점검표를 검사한다. 각 실제 GLMM의 계수 표 반환을 확인하고 점검표의 항목·상태·설명, 개별 권고와 연결 결과, 소프트웨어명/버전 및 원본 보존을 확인했다. 시험 과정의 특이 적합 등 경고는 유지하며 정상 수렴을 보장하는 시험으로 해석하지 않는다.

추가 GLMM 점검표가 포함된 기존 저장 검사로 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel을 검증한다. PDF 캡처 텍스트는 `validate_longitudinal_error_pdf.py`로 확인한다. 산출물: `tmp/longitudinal-error-exports`.

다른 분포·자동 분포 선택·확률기울기·모든 옵션·브라우저·페이지별 시각 검토는 별도 남은 범위다. 계산식·메타분석·설치본은 변경하지 않았다.

위 검사와 기존 MI/IPW·가중치·사용자 이름 검사, 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 모든 캡처 텍스트도 통과했다. 한국어 현재 30쪽/누적 59쪽, 일본어 현재 31쪽/누적 60쪽이다. 변경 파일의 `git diff --check`도 통과했다.
