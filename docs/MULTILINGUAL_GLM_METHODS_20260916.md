# GLM Methods 원고 다국어 보완

2026-09-16. 설치본은 만들지 않았다.

## 변경

- Methods 문장 형식 2개와 모형 명칭 7개를 6개 언어에 보완했다.
- 모형 설명을 생성할 때 원문과 방법·종속변수·독립변수·요청 분포·적합 분포를 속성으로 보존한다. 영어 문자열 자체는 유지한다.
- 원고 생성 시 Methods의 구성 정보를 보존하고 보조표에서 문장 틀과 시스템 명칭만 번역한다. 원래 변수명·라벨, 분석 행 수, 전체 행 수를 그대로 삽입한다.
- 원고 또는 모형 설명이 저장된 원문과 달라지면 해당 구성 정보에 의한 재작성을 건너뛴다.
- 추정 알고리즘과 본 결과표는 변경하지 않는다.

## 검증

- `scripts/validate_glm_multilingual.R`: 실제 Gaussian/binomial/count 분석에서 생성한 원고의 Methods 번역, 사용자 `Model-based` 라벨 보존, 사용자 편집 원고 보존을 8개 언어로 검사한다. 본표 영어 및 옵션 값 검사도 유지했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 합성 count 자료의 기존 음이항 추정 반복 한도 경고가 발생했으나 출력 계약 검사는 통과했다.
- 실제 3개 분석의 일본어 원고 표를 현재/누적 내보내기 fixture에 추가했다.
- 8개 언어 GLM 검사 통과. 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교 및 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.

## 남은 범위

새 구성 정보가 없는 이전 저장 결과의 Methods 번역은 동일하게 보장하지 않는다. 저장 시 재분석하거나 과거 스냅샷을 재작성하지 않는다. GLM의 일부 상세 진단 안내와 다른 분석 화면은 계속 점검 대상이다.
