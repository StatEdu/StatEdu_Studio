# 다국어·분할 도표 수정 현황 (2026-09-16)

## 적용 범위

소스만 수정했다. 설치본을 생성하거나 설치된 StatEdu Studio 파일을 교체하지 않았다.

번역은 `R/labels.R`의 기본 사전과 `i18n/{언어}.json`의 값을 로컬에서 조회한다. 실행 중 번역 서비스에 요청하지 않는다. 이번 점검 중 외부 번역 초안을 시험했으나 문장 누락과 통계 용어 오역이 있어 그 초안은 제품 사전에 반영하지 않았다.

## 완료한 수정

- 파일 분할 상태를 `분할 변수: sex · 총 2개 집단`으로 변경했다. 일본어·중국어·스페인어·프랑스어·독일어·베트남어 및 영어에도 집단 수임을 명시했다.
- 분할 결과 캡처는 화면에 보이는 Shiny 도표의 렌더링과 이미지 로딩이 끝난 뒤 진행한다. 숨겨져서 렌더링이 중단된 도표는 기다리지 않는다. 이미지 가져오기에 실패하면 불완전한 참조를 조용히 저장하지 않고 오류를 반환한다.
- 첫 집단과 두 번째 집단의 Q-Q 도표·잔차 도표가 각각 독립된 이미지로 보존되는 것을 검증했다.
- 공통 메뉴, 표 스타일, 코딩북, 측정수준, 데이터 표 검색·페이지 이동, 회귀 및 매개·조절 진단 문구를 6개 언어로 보완했다.
- 복합표본과 종단분석 사전에 영어로 남아 있던 일본어·중국어 설명과 선택 항목을 번역했다.
- 동일 대상 내 처치 반복측정 분석과 복합표본 설계 등 기본 사전의 언어 누락을 보완했다.
- 혼합 반복측정 결과가 한국어 이외의 모든 언어에 한국어 전용 치환을 적용하던 분기를 수정했다. 모형 개요, 권장 해석, 가정 검토의 주요 설명과 합성 진단 문구를 번역했다.
- 영어·한국어만 고르던 코딩북·공통 UI·일부 분석 보조 함수가 번역 사전을 조회하도록 연결했다.

사용자 변수명·값 라벨, 분석 수치와 내부 선택값은 변경하지 않는다. 논문용 주 분석표·그림의 영문 형식은 현재 저장소 출력 규칙을 유지한다.

## 검증

- `scripts/validate_multilingual_coverage.R`: 등록된 영어·한국어 사전 항목에 6개 언어 값이 존재하는지, 서식 자리표시자, 측정수준 내부값, 대응표본 및 혼합 반복측정 진단과 사용자 라벨·수치 보존 확인.
- `scripts/validate_i18n_contract.R`: 통과.
- `scripts/validate_multilingual_rendering.R` 및 `.cjs`: 공통 메뉴·범주형 값 라벨·캔버스 레이아웃 확인.
- `scripts/validate_language_switch_session.cjs`: 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어 왕복 후 동일 세션·선택 사례 3/6·회귀 화면·결과 화면 유지 확인. 초기 업로드 테스트는 지연된 세션 복원이 끝난 뒤 수행하도록 보완했다.
- `scripts/validate_split_plots_app.R` 및 `scripts/validate_split_plots.cjs`: 두 집단 각각 2개 도표, 집단 간 서로 다른 이미지, data URI 캡처 확인. 첫 집단 도표도 시각적으로 확인했다.
- `scripts/validate_split_plots_exports.R`: 현재·누적 결과의 HTML/PDF/Word/HWPX/Excel 생성 및 내용 확인. HTML·Office 파일에서 네 도표 보존, PDF에서도 두 집단과 내장 이미지 보존 확인.
- `scripts/validate_multilingual_exports.R` 및 `scripts/validate_multilingual_pdf.py`: 일본어 개요·부트스트랩·반복측정 진단의 현재·누적 내보내기, 사용자 라벨, 수치, PDF 표지와 실제 PDF 텍스트 확인.
- 수정 대상의 `git diff --check` 및 JavaScript 구문 검사 통과.

## 남은 범위 — 전체 번역 완료는 아님

**사전의 언어 값 누락이 없다는 검사 결과는 모든 화면 문구가 번역됐다는 뜻이 아니다.** 소스에 사전을 거치지 않는 영어·한국어 조건문과 동적으로 조합하는 상세 안내가 더 남아 있다.

- SEM/PLS-SEM 고급 옵션, 적합도·불변성·신뢰도 등의 상세 안내와 진단.
- 생존분석·메타분석의 상세 설정과 설명.
- 일반화·로지스틱·종단분석의 긴 진단·권장 보고 문장.
- 변수·검정값을 문장에 넣는 일부 오류·알림 템플릿.

이 범위는 개별 문맥에 맞는 번역, 표시 함수 연결, 동적 값 보존 검증이 추가로 필요하다. 자동 생성된 일괄 소스 변경 후보나 미검수 외부 번역 초안은 적용하지 않았다. 이번 수정만으로 전체 다국어 작업을 완료했다고 보고하지 않는다.
