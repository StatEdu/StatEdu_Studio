# 생존 보정곡선 최적화 이후 재측정 — 2026-09-14

## 범위

현재 적용된 동일 누적위험 재사용, 중복 위험도 지수 계산 재사용, 평균의 결측 제거 조건 및 큰 부트스트랩 행렬의 분위수 처리를 유지한 상태에서 다시 측정했다. 이번 작업은 진단이며 제품 코드를 변경하지 않았다.

번들 R 4.5.3, 시드 421, 600/2,000건, 3집단, 연속 공변량 1개, 사건 생성 확률 0.45, 부트스트랩 60회, 선택 시점 0·10·20의 합성 자료다. 모듈·설정 로딩 및 최초 Cox 모형 적합은 측정 밖이다. 준비 실행 후 전체 `survival_adjusted_curve()`를 프로파일러 없이 측정하고, 별도 실행을 0.01초 간격으로 프로파일링했다. 새 R 프로세스 세 개를 순차 실행했으며 다른 R 작업을 시간 측정과 동시에 실행하지 않았다.

60회 부트스트랩은 현재 분위수 함수의 1,024행 이상 최적화 경로를 사용하지 않는다. 따라서 이번 측정은 큰 부트스트랩 행렬 최적화의 재검증이나 기본 2,000회 실행 시간 측정이 아니다.

## 병목의 위치

2,000건 프로파일에서 다음 누적 표본 비율을 확인했다.

| 실행 경로 | 3회 누적 표본 비율 |
| --- | --- |
| 보정곡선 1회 계산 `survival_adjusted_curve_once` | 89.83 / 87.86 / 89.88% |
| 기저 누적위험 `survival::basehaz` | 18.91 / 17.86 / 18.80% |
| Cox 모형 재적합 `survival::coxph` | 4.26 / 3.81 / 4.34% |
| 부트스트랩 신뢰구간 `survival_bootstrap_intervals` | 4.02 / 4.05 / 4.58% |

기저 누적위험 계산은 보정곡선 경로 안에도 포함되므로 위 비율을 합산하면 안 된다. 표본 시간은 4.23/4.20/4.15초로 벽시계 시간과 다르며, 비율을 전체 경과 시간의 정확한 분할로 해석하지 않는다.

600건에서 `basehaz`의 누적 표본 비율은 41.84/31.76/31.46%였다. 내부 계산에서 사용하지 않는 표준오차를 생략할 수 있는지 확인했지만, 설치된 `survival::basehaz`는 이미 `survfit(..., se.fit=FALSE)`를 호출한다. 같은 생략을 다시 적용할 여지는 없다.

2,000건에서는 `vapply` 실행 경로가 약 73%, `mean` 경로가 약 15~19%의 누적 표본에 나타났다. 현재 소스의 시점별 생존확률 벡터 생성·복원·평균 처리가 후속 조사 대상이다. 다만 익명 함수들이 `FUN`으로 합쳐지므로 그 자체 시간 약 54~57%를 지수 계산만의 비용이라고 단정할 수 없다. 다음 후보를 정하려면 벡터 생성, 원래 관측치 순서 복원, 평균 계산을 구분한 계측이 필요하다.

중복 위험도의 가중평균으로 바꾸거나 합산 순서를 변경하는 방식은 수치의 정확한 동일성을 보장하지 못한다. 이번에는 해당 변경을 하지 않았다. 이미 검토한 집단별 결과 수집 인덱스 재사용은 비용이 작아 우선순위를 높이지 않았다.
