# GLM 동적 진단 설명 다국어 보완

2026-09-16. 설치본 생성 없이 소스만 수정.

## 변경

- 일반 번역표 조회로 처리되지 않던 GLM 동적 설명을 전문 보조표 번역 경로로 연결했다.
- 일본어·중국어·스페인어·프랑스어·독일어·베트남어에 7개 문장 형식을 추가했다: Pearson 산포비, 최대 VIF, EPV, Cook의 거리/레버리지 요약, 이분형 사건/기준 코딩, 처리 대비의 기준 범주, MI 자료 수/반복 수.
- 원문 전체 형식을 확인한 뒤 문장 틀을 번역하고 캡처한 범주명·수치를 그대로 삽입한다. 일반 번역이 먼저 범주명을 변경하지 않도록 원본 셀에서 처리한다. 사용자 식별 열은 공통 보존 함수로 복원한다.
- 한국어 보조표의 줄별 변환에서 NA가 문자열이 되는 문제를 수정했다.
- 통계 계산, 본 결과표의 영어, 옵션 값은 유지한다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 7개 실제 형식의 설명을 보조표 fixture에 추가했다. 소수, 퍼센트, 한글·마침표·쉼표가 있는 범주명, 번역 대상과 같은 범주명 `Model-based`, 사용자 Variable 열, 여러 줄과 NA를 확인했다.
- Gaussian/binomial/count 실제 분석 본표의 셀·제목·주석이 언어 변경 후 영어 기준과 동일함을 확인했다. 합성 count 데이터의 기존 음이항 반복 한도 경고는 발생했지만 출력 계약 검사는 통과했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 fixture의 현재/누적 HTML·Word·HWPX·Excel 내용 비교, PDF 생성 및 `scripts/validate_multilingual_pdf.py`의 PDF 실제 텍스트 비교 통과.

## 남은 범위

전체 GLM 번역 완료가 아니다. 분포·링크가 포함된 선택 사유, 순서형 수준 목록, MI 풀링의 복합 설명, 원고 문장 등은 추가 점검이 필요하다. 이번 내보내기 검증은 일본어 fixture 기준이며 모든 MI 계산 분기를 새로 실행한 것은 아니다.
