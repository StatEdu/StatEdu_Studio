# Importance–performance analysis

Menu: Analysis → IPA, immediately after Principal Components (Association & Measurement group).

## Supported analyses

- Direct ratings: one performance and one importance variable per attribute.
- Derived importance: performance variables plus an overall satisfaction outcome. Pearson partial correlations control all other selected performance attributes. An explicit revised-IPA option uses log-transformed performance, requiring positive scores. Original performance means remain on the horizontal axis. Negative partial correlations retain their sign; they are not automatically converted to absolute importance.
- Overall, independent groups, and matched pre/post designs work with both methods.
- Paired wide format: one respondent per row, separate pre/post columns. Optional IDs must be unique and nonmissing. Without IDs the row is the pairing key, as stated in the output.
- Paired long format: unique ID/time records and two user-selected raw time values. Respondents are matched by ID before complete-case filtering. Duplicate records are rejected, not silently aggregated.

## Statistical contracts

All selected scores use a common complete-case sample within each group, and a common matched sample across paired times. The sample table reports available/analyzed/excluded respondents. Missing group labels are excluded and counted in the note. Active select-case/split variables cannot be reused as IPA terms. Independent groups must be selected inside IPA to compare them: Split file instead runs separate analyses.

Mean-score CIs use Student's t. Independent mean differences use Welch t tests; paired differences use paired t tests. All differences are second minus first. Holm correction spans only the finite displayed direct-score tests across attributes, metrics and group pairs; intervals remain pointwise 95% intervals.

Derived-importance estimates and differences use percentile bootstrap intervals. Independent groups resample within group; paired data use the same sampled respondent indexes at both times. At least 80% and 50 replicates must be valid, otherwise CI limits are suppressed. No t-test p value is attached to partial-correlation differences. RNG state is restored after computation. Constants, singular correlation matrices, inadequate complete cases, duplicate variable roles and nonpositive log inputs receive explicit errors.

The common reference is the respondent-weighted mean of group attribute coordinates, shared across groups/times. It is a chart benchmark, not an estimate of a pooled-sample partial correlation. Custom common coordinates and supplementary within-group means are also available. Axes share limits across groups/times within each chart type. Point charts use estimate extrema; CI charts include confidence limits. Each range has 8% padding, with a small fallback only for a zero-width range. Within-group reference lines are omitted in the combined chart because they differ. Points on a reference line are explicitly classified as `On reference`. Two-group positions are linked; paired changes have arrows. Marginal 95% interval bars in individual charts are not joint confidence regions.

## Three-block setup

IPA uses the shared three-block geometry: available variables on the left, ordered importance/performance panels in the middle, and options on the right. Overall and independent-group modes place the group panel at the bottom of the middle block. At the standard 520 px height, importance and performance each use 196 px, the group panel uses 104 px, and two gaps use 12 px each. Options use Analysis, Chart, and Quadrants tabs. The former attribute-name field, single-variable score dropdowns, role dropdown and Add attribute button are removed.

Matching is strictly positional: the first importance variable matches the first performance variable, and so on. Each list supports multiselection transfer, its own add/remove arrow, double-click removal, shared drag/drop, pointer reordering and up/down controls. Numbered list labels expose correspondence. Unequal or empty required lists block analysis. Reordering changes the actual analysis mapping. Output item names use the performance variable names.

Paired wide mode conditionally adds ordered post lists; ID/time and overall-satisfaction single-variable panels appear in the options block when required. Hidden mode assignments are retained. Assigned variables leave the available list and return when removed. Invalid numeric roles, duplicate active roles and multi-variable single-role assignments are rejected. Execution/reset/save controls remain below the three blocks.

## Output and integration

The menu uses shared variable-list pointer ordering and up/down controls, the analysis command dispatcher, scoped result values, captured result exports, and accumulated-result snapshots. Rendered PNGs and report HTML are stored after computation and reused on export. Main publication tables are English; controls use the current UI language (Korean/English text supplied).

The default report is B5 portrait (176 × 250 mm), ordered as: model overview, importance/performance descriptive statistics, point-estimate IPA charts, separate IPA 95% CI charts, and appendix tables. Main tables use compact three-rule styling. Direct ratings show M (SD); derived importance shows partial r, while performance retains M (SD). All figures share item numbers; axis limits are shared within each chart type. Dashed reference lines carry three-decimal mean labels beside the lines (custom values are labeled Reference). Figures are rendered at 300 dpi.

Appendices include sample accounting, variable pairs, reference coordinates, quadrant assignments, estimates with grouped 95% CI headers, and difference tables with unadjusted/Holm p values where applicable. Appendices follow the UI language. HTML/PDF/Word/HWPX/Excel use the displayed snapshot, including images. HWPX is exposed through the Korean accumulated-results screen according to the app contract.

Validation scripts: `scripts/validate_ipa.R --exports` and `scripts/validate_ipa_pdf.py`. Fixtures/output: `tmp/ipa-validation/`. Tests cover six mode/design combinations, scrambled long-form IDs, paired-bootstrap synchronization, independently calculated t tests and residual-based partial correlations, three independent groups, missingness, invalid inputs, scope-variable rejection, RNG preservation, menu registration and Shiny handler execution. Browser verification uses the actual IPA panel/handlers with simulated data on an isolated local test server.

No installer rebuild or deployment is included.

Reference-label clearance reserves 24% of the observed x span on the left and 16% of the y span below, retaining 8% above/right. Both point and CI charts use these shared limits, keeping the mean callouts away from the lowest/leftmost markers and item labels.

Lazy menu entry now treats an unbound design input as Overall. Previously, the first observer flush could evaluate a zero-length `ipa_design` condition and disconnect the Shiny session before the controls were bound. `scripts/validate_ipa_lazy_start.R` flushes handlers with no browser inputs, then assigns variables and executes in Korean and English; the same test fails on the former conditions. Full-app browser checks cover first entry and actual report generation, not only the standalone panel harness.

Pre/post by group is available for both separate pre/post columns and a time variable. The latter uses Group + respondent ID to match observations within each group. Direct and derived importance use the existing paired calculations within groups, with pooled common axes/references by default and optional group-specific references shared by that group's times. Separate charts overlay Pre/Post within each group; Overlay shows all groups and times. Connections only join the same attribute within a group. Default colors start with contrasting blue/orange; each group keeps its color at both times and uses circles for Pre and triangles for Post (size 1.3). Comparisons report within-group changes, not a group-by-time interaction test. `scripts/validate_ipa_grouped.R` covers wide/long agreement, derived importance, pair matching, references, styles, actual Shiny execution, and current/accumulated HTML/PDF/Word/HWPX/Excel output.

Default marker size is 1.3. Every ordinary and 95% CI figure includes its number-to-attribute key in the figure notes (1 = attribute; 2 = attribute; …), using the same item order as plotted labels and Table 2. The key is included in captured current and accumulated exports.

Group marker selectors, legends and group reports use ascending raw group values, with numeric codes sorted numerically (1, 2, 10) even when stored as text or factors. Display labels and marker settings remain keyed by raw value. Paired time order remains Pre then Post.

IPA score panels accept continuous measurement types only; Group accepts binary or categorical types. Assignment buttons, double-clicks, drag/drop and execution validate metadata (falling back to inferred types when missing). Removal remains available for previously assigned variables. Bulk transfer-list synchronization before move-button clicks no longer emits activation events for every list; IPA tracks explicit activation so a remove click returns variables to the available list without losing its direction.

Separate pre/post variables pair respondents by row and do not display or pass an ID assignment. The time-variable layout alone shows a compact single-variable respondent ID panel. Its two observed nonmissing time levels are sorted and automatically displayed as Pre → Post, showing category labels with raw codes when available. A Swap order button reverses the actual analysis mapping. Changing the time variable or its levels resets this order; variables with other than two levels require correction before analysis.

Paired setup offers Select separate pre/post variables and Use a time variable under Identify pre/post. Selecting separate variables keeps only two assignment panels, Importance and Performance: a shared Pre/Post block navigator switches both panels together and preserves each block's assignments and ordering. When using a time variable, the Time assignment panel replaces Group at the bottom of the middle block; respondent ID and pre/post values remain in Analysis options. Paired mode enables Time markers and the group/time chart controls without requiring a group variable.

Chart and Group markers are separate tabs. Group-category labels are shown as label(level) in the marker selector, figure legends and separate-figure captions while raw levels remain the matching keys. Separate charts offer Overall mean (default) and Group mean reference lines; group means also drive quadrant classification. Performance and importance axis titles can be edited in the Chart tab. Changing these options invalidates the previous result and the next run captures the new presentation.

The Chart tab uses a Group marker selector to display one group's shape, common-color swatches, and size scale (0.3–4). Switching groups preserves earlier edits. One Show item connections checkbox toggles all corresponding-item connections, enabled by default. Connections follow group display order for multiple groups; paired comparisons retain their direction arrows. A group's marker style is identical in separate/overlay plots, CI plots, and legends. Captured exports preserve these settings in the rendered figures.

IPA uses the shared localized reset button, enabled when variables are assigned. Overlay figures distinguish groups by both color and plotting symbol, with matching legend symbols in ordinary and CI charts. Screen reports consume the shared result zoom preference; exported reports keep their B5 dimensions. Browser validation confirmed 155% zoom and localized reset labels for Korean, English, Japanese, Chinese, German, Spanish, French, and Vietnamese.
