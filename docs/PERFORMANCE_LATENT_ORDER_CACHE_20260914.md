# 잠재 상관의 변수별 범주 순서 재사용 — 2026-09-14

`R/analysis_correlation.R`에서 잠재 상관분석 한 번에 한정된 범주 순서 캐시를 추가했다. 사전 준비된 속성 없는 변수 벡터의 순서를 처음 사용할 때 계산하고 같은 변수의 후속 쌍에서 재사용한다. 기존 연속형 순서 생략 조건은 유지한다.

캐시는 prepare_correlation_results 호출마다 새 환경으로 생성하고 결과 객체에는 넣지 않는다. 직접 호출을 위한 선택 인자 level_cache의 기본값은 NULL이다. 준비된 벡터가 없거나 캐시 조건을 만족하지 않으면 원래 계산을 사용한다. 순서 계산에서 경고 또는 메시지가 발생하면 이를 그대로 전달하고 결과를 캐시하지 않아 후속 쌍에서도 기존처럼 계산한다. 추정식과 범주 순서 규칙은 변경하지 않았다.

## 측정

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 변경 전후 3쌍을 순차 측정했다. 두 번째 쌍은 순서를 반대로 했다. prepare_correlation_results와 correlation_latent_pair_result를 같은 전역 환경에 연결해 비교했다.

자료는 1만 행·8변수이며 모든 변수가 순서형(3범주) 또는 이분형인 두 조건이다. latent_correlations=TRUE, continuous_method=auto, 정규성 검사 TRUE를 사용했다. 각 프로세스에서 순서형 후 이분형 조건을 실행했다.

| 자료 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---|---:|---:|
| 순서형 8변수 | 1.55 | 0.96 |
| 이분형 8변수 | 1.03 | 0.53 |

전체 결과 준비 시간이 각각 약 38%, 49% 감소했다. 원자료는 순서형 변경 전 1.55/1.55/1.56초, 변경 후 0.96/0.96/0.97초, 이분형 변경 전 1.03/1.03/1.04초, 변경 후 0.53/0.53/0.53초다. 화면 렌더링·앱 로딩·내보내기는 포함하지 않는다.

## 검증

- 잠재 상관 24조건에서 전체 결과와 쌍별 추정 정보, 진단 및 난수 상태가 정확히 일치했다. 정상 추정과 추정 불가 처리가 포함됐고 HTML/의존성 3건도 동일했다.
- 범주 순서 설정, 특수 숫자 클래스, 결측·무한값·전부 결측·빈 입력의 직접 호출 12조건도 일치했다. 이 검사는 기본 level_cache=NULL 호출의 호환성을 포함한다.
- 정상·메시지·경고를 내는 순서 계산의 3조건에서 전체 결과·진단·난수 상태가 일치했다. 4변수 정상 조건의 순서 계산 호출 수는 12→4회였다. 메시지·경고 조건은 각각 12→12회로 유지되며 진단 내용과 순서가 일치했다.
- 시간 측정 6쌍의 전체 결과·진단·난수 상태가 `identical(...,num.eq=FALSE)`로 일치했다.
