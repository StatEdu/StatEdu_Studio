# 회귀분석 명령어 저장과 재실행

분석 → 회귀분석 화면의 **분석 명령어** 버튼을 사용합니다.

1. 데이터를 열고 분석에 사용할 변수 선택을 적용합니다.
2. 회귀분석에서 종속변수와 블록별 독립변수, 분석 옵션을 설정합니다.
3. **분석 명령어 → 메뉴에서 명령어 생성**을 누릅니다. 분석 실행 전에도 생성할 수 있습니다.
4. **명령어 저장**으로 UTF-8 `.stcmd` 파일을 저장합니다.
5. 다음 세션에서 데이터를 열고 변수를 선택한 뒤 **분석 명령어 → 명령어 불러오기**를 누릅니다.
6. **명령어 실행**은 편집한 설정으로 분석하고 메뉴에도 반영합니다. **메뉴에 반영**은 분석하지 않고 설정만 복원합니다.

변수명은 원래 데이터의 변수명입니다. 문자열에는 큰따옴표를, 변수 목록에는 대괄호를 사용합니다.
예를 들어 `DEPENDENTS = ["만족도"]`, `PREDICTORS = ["연령", "신뢰"]`처럼 작성합니다.
블록 회귀분석은 `BLOCK1`, `BLOCK2`, `BLOCK3`을 기록합니다. `PREDICTORS`는 블록별 변수를 순서대로 합친 목록이어야 합니다.
사용하지 않는 뒤쪽 블록은 `[]`로 둡니다. 블록 하나만 사용하면 일반 회귀분석으로 사용할 수 있습니다.
`#`로 시작하는 줄은 주석입니다. 실행 중인 부트스트랩이 있으면 완료하거나 중지한 후 실행합니다.

저장 항목은 변수와 순서, 블록 구성, 측정수준과 범주 기준값, 부트스트랩 횟수와 시드,
잔차진단과 자동 분석기법 선택, 효과크기·VIF 표시 및 표 스타일입니다.
현재 회귀 엔진의 결측치 처리는 `LISTWISE`, 부트스트랩 신뢰구간 방식은 `bias_corrected`입니다.
부트스트랩 횟수는 메뉴와 같은 1000, 5000, 10000, 20000, 50000 중에서 선택합니다.

데이터 자체와 전처리 명령은 명령어 파일에 포함되지 않습니다. 데이터 편집·계산변수·사용자 결측값 처리가
적용된 실제 분석 데이터의 해시를 기록하므로 같은 원본 파일이라도 전처리가 다르면 알려줍니다.
동일한 분석을 재현하려면 데이터와 전처리 설정을 함께 보관하세요.
다른 데이터에 같은 설정을 적용하려면 **현재 데이터에 적용**을 선택합니다.
이 경우에도 변수 존재 여부, 측정수준, 범주 기준값은 검사합니다. 측정수준과 기준값이 다르면
데이터 화면에서 맞춘 뒤 실행해야 합니다. Studio 버전이 다르면 경고를 표시합니다.

여러 명령어의 일괄 실행은 지원하지 않습니다. 파일은 데이터 형식으로 해석하며 R 코드나 셸 명령으로 실행하지 않습니다.

## 다른 분석 메뉴

빈도·기술통계, 교차표, 신뢰도, 평가자 간 일치도, 상관, 요인·주성분,
t검정·분산분석·공분산분석·반복측정·비모수검정, 로지스틱·일반화·종단·생존분석,
매개·조절효과, 복합표본 분석, CFA·CB-SEM·PLS-SEM, 메타분석에서도 **분석 명령어**를 사용할 수 있습니다.
각 메뉴의 명령어는 해당 메뉴에서 불러옵니다. 모형 편집 화면에서는 도구 모음에 버튼이 표시됩니다.

회귀분석은 기존 REGRESSION 형식을 유지하며, 추가 메뉴는 ANALYSIS 형식을 사용합니다.
STATE_ 항목은 선택한 변수·순서·모형 등이고, OPTION_ 항목은 메뉴 옵션입니다.
모든 항목의 등호는 같은 열에 정렬됩니다. 메뉴에서 명령어를 생성한 후 값을 수정하세요.
명령어 적용 시 메뉴의 변수·측정수준 검사와 기존 분석 엔진을 사용합니다.
옵션이 메뉴에 실제로 반영된 후에만 분석을 시작하며, 적용할 수 없는 옵션은 오류로 알려줍니다.
현재 화면에 없는 설정 항목이 포함된 파일은 해당 옵션 화면을 먼저 설정한 뒤 불러오세요.

일반 분석은 원자료를 포함하지 않으며, 모형 명령어에는 도형과 경로 정보가 포함됩니다.
**메타분석 명령어는 입력한 연구별 효과값을 포함합니다.**
