# 생존분석 완료·실패·저장 알림 — 2026-09-17

Kaplan–Meier, Cox, 경쟁위험 분석의 완료/실패 알림 6개와 보고 파일·경쟁위험 그림 저장 완료 알림 2개를 8개 언어로 연결했다. 보고 파일 수와 저장 경로, 외부 분석 오류 상세는 원문을 유지한다. 생존분석 문서/보고 파일/경쟁위험 그림 저장 오류에도 기존 공통 내보내기 오류 번역을 연결했다.

검증:
- `validate_survival_notices_i18n.R`: 8개 언어와 한국어 복귀에서 실제 등록된 실행 콜백 및 Shiny 저장 이벤트를 검사했다. 분석 준비 함수와 파일 저장 경계를 대체하여 성공/실패·보고 파일 저장·그림 저장 알림, 사용자 경로 및 외부 오류 상세 보존을 확인했다.
- `validate_survival_ui_smoke.R`: 실제 생존분석 결과를 이용하는 Shiny 저장 제어 및 공개/개발판 저장 정책 검사 통과.
- `validate_multilingual_coverage.R`: 통과.

분석 계산·본 표·보조표·보고 파일 내용은 변경하지 않았다. 이번 다국어 알림 검사는 실제 브라우저 클릭 또는 모든 내보내기 형식 검증을 의미하지 않는다. 개별 분석의 입력 검증 오류 상세까지 전부 번역 완료한 것은 아니다. 설치본은 만들지 않았다.
