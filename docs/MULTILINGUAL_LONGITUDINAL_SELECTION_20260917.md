# 종단 변수 선택 검증 안내 — 2026-09-17

결과변수, 대상자/군집 ID, 시점, 가중치, 예측변수/공변량 또는 고정효과 시점 선택의 Shiny 검증 문구 5종을 8언어 실행 실패 알림에 연결했다. 분석 함수가 만드는 원문 조건은 유지하고 UI 알림 경계에서만 번역한다.

계산·결과 표·저장·가중치 정상화 동작은 바꾸지 않았다. 실제 브라우저 알림 검증은 포함하지 않는다. 짧은 내부 오류와 화면상 보조표의 다른 상태 조합은 별도 점검 대상이다. 메타분석은 제외하고 설치본은 만들지 않았다.
