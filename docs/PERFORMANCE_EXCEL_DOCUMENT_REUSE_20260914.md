# Excel 저장의 HTML 문서 재사용 — 2026-09-14

`result_entry_tables()`와 `result_entry_paragraphs()`가 선택 인자 `document`를 받도록 변경했다. 생략하면 기존처럼 해당 결과의 HTML을 읽는다. 표 수집 내부의 문단 추출에는 이미 읽은 문서를 전달한다. Excel 저장은 현재 결과 하나의 문서를 읽어 표 수집과 마지막 문단 추출에 재사용한다. 저장 호출 사이에는 문서를 보관하지 않는다.

`result_entry_images()`는 다이어그램 노드를 이미지로 교체하므로 독립된 문서를 계속 읽는다. 표와 문단이 공유하는 문서는 수정하지 않는다. 테스트한 표·그림 혼합 결과의 HTML 문서 읽기 횟수는 결과당 **4회에서 2회**로 줄었다.

## 전체 Excel 저장 시간

같은 30변수 상관분석 HTML, 3개 시트, 번들 R 4.5.3을 사용했다. 이전 최적화는 양쪽 모두 활성화했다. 각 변형을 새 프로세스에서 실행하고 모듈과 설정 로딩 뒤 전체 저장을 측정했다. 프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍은 순서를 뒤집었다. 변경 함수는 같은 전역 도우미 환경을 사용했고 파일 검증은 측정 밖에서 수행했다.

| 반복 | 변경 전(초) | 변경 후(초) |
| --- | ---: | ---: |
| 1 | 2.30 | 2.14 |
| 2 | 2.29 | 2.14 |
| 3 | 2.30 | 2.14 |
| 중앙값 | 2.30 | 2.14 |

이 파일의 전체 저장 시간은 **약 7% 감소**했다. 앞선 개선율과 합산하지 않는다. 프로그램 시작이나 통계 계산 시간은 이번 측정 대상이 아니다.

## 검증

- `scripts/validate_excel_document_reuse.R`: 개별 표 9개 및 누적 결과 1개 통과. 기본 호출의 전체 표 데이터, Excel용 필드와 인쇄 방향, 개별 저장 경고와 RNG 상태도 변경 전후 동일했다.
- `verify_context.R`: 표·그림·앞뒤 문단 혼합, 다이어그램 교체, 텍스트 전용 결과 3개와 이들의 누적 결과를 추가 검증했다. 공유 문서가 수정되지 않으며 전체 표 및 문단 데이터가 동일했다. NULL 문서를 명시한 호출도 검사했다.
- 다이어그램 검사는 결정적인 PNG를 반환하는 대체 함수를 사용했다. 문서 노드 교체와 결과 순서를 검증하며 실제 다이어그램 렌더러의 재검증은 아니다.
- `verify_orientation.R`: 상관행렬 9/10변수 경계, 명시적 세로/가로, 표 클래스와 패널, 위첨자 각주를 포함한 6개 사례 통과. 기본 Word용 표 데이터도 동일했다.
- 검증한 Excel의 시트 이름과 읽어 들인 값이 동일했다. core 메타데이터 이외의 압축 내부 파일은 모두 바이트 단위로 동일했고 core도 생성·수정 시각만 정규화하면 동일했다.
- 측정 파일 6개도 기존 기준 파일과 동일성 검증을 통과했으며 저장 중 경고가 없었다.
- `git diff --check -- R/result_saved_ui.R` 통과.

분석 계산과 출력 내용을 변경하지 않는 중복 읽기 제거다. 기본 문서용 표 데이터도 검증했으나 PDF/Word/HWPX 완성 파일은 이번에 재생성하지 않았다. 설치 파일도 재빌드하지 않았다.
