# 생존분석 자료 검토 및 추정대상 제목 번역

## 변경

실제 KM·경쟁위험 결과 패널에서 비영어 UI에 영어로 남던 제목 3개를 재현하고 8개 언어 사전에 반영했다.

- Excluded rows by reason: 사유별 제외 행
- Data review messages: 자료 검토 메시지
- Estimand contract: 추정대상 명세

기존 한국어 표현을 유지했다. 계산·표 생성·저장 코드는 변경하지 않았다.

## 검증

- `validate_survival_review_titles_i18n.R`: 생존분석 fixture에 결측 시간과 세 종류의 사건 코드를 설정해 실제 KM 분석의 제외 사유 및 다중 사건 코드 검토 경고를 생성했다. 같은 자료로 경쟁위험 결과도 생성했다. 세 대응 표가 비어 있지 않은지 확인했다.
- 전체 결과 패널에서 제목 3개의 8개 언어 표시, 영어 본표 동일성, 원본 결과 객체 보존을 검증했다.
- `validate_i18n_contract.R`: UTF-8 로캘을 지정해 통과. 최초 실행은 시스템 로캘 설정 실패로 소스 읽기 단계에서 중단됐으며, 로캘을 지정한 재실행에서 해결했다.
- 제목과 대응 표의 캡처 HTML로 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검증 통과. 저장 중 분석을 다시 실행하지 않았다.
- PDF 텍스트 검증: 한국어·일본어 각각 현재 4쪽, 누적 7쪽의 모든 캡처 텍스트 보존 확인.
- 산출물: `tmp/survival-review-titles-i18n/exports`.

## 범위

이번 수정과 저장 검사는 제목 3개 및 대응 표에 한정한다. 전체 결과의 그림·주변 설명까지 다시 검증한 것은 아니다. 다중 사건 코드 경고는 생존분석의 기존 사건 코딩 방식에 관한 것으로, 사용하지 않기로 한 기존 매개·조절효과 패널과 무관하다. 해당 패널은 계속 제외한다. 문서 앱별 수동 시각 검토 및 설치본 빌드는 수행하지 않았다. 다른 생존분석 안내와 동적 오류는 후속 점검 대상으로 남는다.
