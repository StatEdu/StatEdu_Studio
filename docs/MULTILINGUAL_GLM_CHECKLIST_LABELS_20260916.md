# GLM 실제 출력 재점검: 보고 점검표·결측 요약

2026-09-16. 설치본은 생성하지 않았다.

## 발견 및 변경

실제 일본어 Gaussian/binomial/count 출력의 보조표를 추출해 확인했다. 보고 점검표 10개 항목과 결측자료 요약 9개 항목이 영어로 남아 있어 6개 언어에 번역을 추가했다. 사용자 라벨 `Model-based`와 통계 기호는 보존한다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 19개 항목을 fixture에 추가하고 실제 3개 분석의 보조표에서 해당 영어 항목명이 남지 않는지 검사했다.
- 기존 본표 영어·사용자 원문·옵션 값 보존 검사 유지. 합성 count 자료의 기존 음이항 반복 한도 경고가 발생했으나 출력 검사는 통과했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 출력 재추출에서 해당 19개 항목의 영어 잔존이 해소됨을 확인했다.
- 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교 및 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.

## 확인된 잔여 범위

- 카운트 진단표의 Selected family, Selection rule, 분산비·영점 비율 항목, AIC/BIC 비교 설명, 자동 결정 설명.
- 보고 점검표의 모형 설명 전체, 분포/링크 복합 요약.
- 결측 방법과 분석 행 수를 함께 표시하는 복합 요약.

이 목록은 현재 3개 분석 출력에 한정되며 전체 앱의 완료 여부를 나타내지 않는다.
