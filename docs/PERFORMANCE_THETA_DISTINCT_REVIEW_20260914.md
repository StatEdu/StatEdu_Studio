# 음이항 θ 추정의 중복 카운트 계산 후보 — 2026-09-14

동일한 카운트의 `digamma(theta + y)`·`trigamma(theta + y)`를 한 번 계산하고 원래 행 순서로 복원하는 실험 후보를 검증했다. **속도와 수치 동일성은 아래 범위에서 확인했지만 운영 코드에는 아직 연결하지 않았다.** 다음 단계는 MASS 네임스페이스를 수정하지 않는 제품 연결 방식과 버전 호환성 검증이다.

## 최종 후보와 전체 분석 시간

일반 숫자 벡터(이름 속성만 허용), 1,000개 이상, 유한한 비음수 정수 카운트, 고유값 수가 전체의 절반 이하일 때 재사용한다. θ가 유한한 양수가 아닌 반복과 조건 밖 입력은 기존 특수함수 식을 사용한다. 복원할 때 원래 이름을 붙인다. 가중치 곱셈·합산 순서, 초기값, 반복 제한, 허용오차, 경고·표준오차 계산은 유지한다.

| 50,000행 카운트 분석 | 기존 3회(초) | 최종 후보 3회(초) | 중앙값 변화 |
|---|---|---|---|
| Poisson 자료, Poisson 선택 | 1.27 / 1.12 / 1.22 | 0.65 / 0.77 / 0.64 | 1.22 → 0.65, 약 47% 감소 |
| 과산포 자료, 음이항 선택 | 1.39 / 1.24 / 1.18 | 0.86 / 0.89 / 0.84 | 1.24 → 0.86, 약 31% 감소 |

최종 후보는 모든 실행에서 빨라졌다. 번들 R 4.5.3의 새 프로세스 3개를 순차 실행했고 두 번째는 기존/후보 순서를 뒤집었다. 6개 정규 예측변수, 시드 915, 강건 표준오차·가정 점검 켬, VIF 끔, 완전 자료를 사용했다. 준비 실행 후 GC와 경과 시간을 측정했다. 입력 생성·모듈 로딩·화면·저장은 제외하고 전체 분석 결과 준비·스냅샷 구성·조건 수집을 포함한다. 다른 R 작업은 동시에 실행하지 않았다. 메모리는 측정하지 않았다.

## 경계와 결과 확인

- 20/999/1,000/2,000개 × Poisson/음이항/모두 다른 값/이름 속성/음수/비정수/결측/무한대/모두 0 × 가중치 유무의 72개 조건과 반복 제한 1/2/10의 3개 조건, 합계 75개에서 기존 θ 반환값·표준오차 등의 속성·오류/경고/메시지 클래스와 문자열·trace 출력·난수 상태가 정확히 일치했다.
- 비교는 `identical(..., num.eq=FALSE)`를 사용했으며 수치 허용오차는 없다. 조건 객체의 호출 환경 자체는 비교하지 않는다.
- 두 자료 × 세 프로세스의 준비 및 시간 측정에서 결과 스냅샷이 일치했다. 반환 내용에서 원래 모형 객체를 제외한 값과 별도 계수·적합값·잔차·deviance·weights·theta·SE.theta, 경고/메시지 문자열·난수 상태를 비교했다. 공식 환경만 `.GlobalEnv`로 통일했다. 모형의 모든 내부 클로저까지 동일하다고 주장하지 않는다.
- 서로 다른 프로세스 간 저장 결과도 일치했다. 실제 `glm.nb`를 이용한 별도 5,000행 검사에서 재사용 분기가 4회 실행되는 것을 확인했다.

## 초기 후보와 제품 적용 범위

최초 후보는 이름 속성이 있는 벡터를 제외했다. 실제 `glm.nb`가 행 이름이 붙은 응답을 전달하므로 전체 분석에서 재사용 분기가 실행되지 않았다. 이를 발견하고 이름을 보존하는 후보로 보완했다. 최종 결과는 `final/` 폴더에 구분해 보관했으며 초기 시간은 위 표에 포함하지 않았다. 첫 측정 스크립트의 이전 단계 저장 코드 잔여물도 제거한 뒤 새 프로세스로 전체 측정을 다시 수행했다.

실험은 별도 R 프로세스에서만 `theta.ml` 바인딩을 교체하고 각 조건 후 복구했다. 설치된 패키지 파일은 수정하지 않았다. 이 네임스페이스 교체를 제품 코드에 적용하지는 않는다. 설치된 MASS 함수 본문으로부터 후보를 생성하는 방식이므로 향후 제품 연결 시 버전·구현 확인, 미지원 입력의 기존 함수 경로, 전체 모형 계약을 추가 검증해야 한다. 고유값이 많아 재사용하지 않는 자료의 전체 분석 속도는 이번에 별도 측정하지 않았다.

`output/theta-distinct-review-20260914/`에 후보 생성기, 초기 측정, 경계 검증, 실제 분기 확인, `final/`에 최종 후보·측정 코드·CSV·결과 RDS를 보관했다. 운영 일반화 모형 소스는 이전 기준 사본과 동일한 해시임을 확인했다. 화면·출력·설치 파일은 변경하지 않았다.
