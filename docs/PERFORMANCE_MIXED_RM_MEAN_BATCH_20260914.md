# 혼합 반복측정 시점별 보정 평균 일괄 적합

2026-09-14. 사후 비교의 유의 순서 표기에 사용하는 시점별 보정 평균을 다중 반응 회귀로 함께 적합하도록 변경했다. `mixed_rm_adjusted_time_estimates()`를 추가하고 기존 시점별 호출을 대체했다. 동일한 공변량의 6개 시점을 처리할 때 6개 회귀 대신 한 회귀를 적합하고, 기준 그리드와 설계행렬도 한 번만 생성한다.

## 결과 보존

평균을 구하는 `sum(linear * beta, na.rm=TRUE)`는 각 시점에서 기존 순서대로 실행한다. 단순 원평균으로 대체하거나 대비 회귀의 계수에서 역산하지 않는다. 계수의 공통 이름 선택과 NA 처리도 유지한다.

사후 비교와 평균 적합의 안전 조건을 `mixed_rm_batch_eligible()`에 모아 공유한다. 유한한 숫자 반응, 일반 숫자/기본 대비 factor, 같은 행 수, 기본 NA 처리 및 작업 크기 제한을 유지한다. 결측값, 순서형 factor, 사용자 지정 대비 코딩, 한 시점 등의 미지원 조건에서는 기존 시점별 계산을 사용한다. 일괄 경로의 경고·메시지·오류에도 기존 계산으로 돌아간다. 데이터 변경 후에는 새로 적합하며 분석 간 캐시는 없다.

## 성능

2,000명, 4집단, 6시점, Holm 사후 비교, 가정 검정 비활성화. 조건별 기존/변경 버전 각각 새 R 프로세스 3개를 순차 실행했고 두 번째 쌍의 순서를 바꿨다. HTML 생성은 시간 측정에서 제외했다.

| 전체 분석 시간 중앙값 | 기존 | 변경 |
|---|---:|---:|
| 숫자 공변량 / 첫 실행 | 0.68초 | 0.68초 |
| 숫자 공변량 / 반복 실행 | 0.21초 | 0.18초 |
| 숫자 + 범주형 / 첫 실행 | 0.72초 | 0.70초 |
| 숫자 + 범주형 / 반복 실행 | 0.22초 | 0.21초 |

반복 분석 중앙값 기준 약 14%, 5% 감소했다. 숫자 조건의 반복 시간은 기존 0.21/0.20/0.21초, 변경 0.18/0.18/0.19초다. 범주형 조건은 기존 0.22/0.22/0.24초, 변경 0.20/0.21/0.22초다. 절대 시간 차이는 작으며 모든 데이터의 같은 개선율을 보장하지 않는다. 이전 측정들과 누적 개선율을 계산하지 않는다.

## 정밀도 검증

`scripts/validate_mixed_rm_mean_batch.R`: 숫자, factor, ordered, 미사용/단일 수준, 공선성, 거의 공선성, 반응/공변량 결측, 무한대, 상수, 공변량 없음, 큰/작은 반응, 행·열 이름, 한 시점, 사용자 대비의 17조건 × NA 정책 4개 = 68건. 반올림 전 평균 벡터와 경고·메시지·표준출력·난수 상태가 기존 시점별 함수와 `identical()` 일치했다. 기준 그리드가 한 번 생성되며 데이터 변경 후 재계산되는 것도 확인했다.

공통 적용 조건을 분리한 뒤 기존 사후 비교 검증 64건과 범주형 검증 65건도 통과했다. 관련 파일의 `git diff --check`도 통과했다.

전체 분석 12개 시나리오와 숫자/범주형 성능 측정 각 3쌍의 전체 결과는 허용오차 0, 환경 객체 제외 비교를 통과했다. 공선성과 단일 집단 시나리오는 기존과 같은 분석 오류 반환을 확인한 경우다. 일반 HTML은 정확히 일치하고, 보고서 HTML은 생성 시각만 정규화해 일치했다. 현재·누적 HTML 및 Excel 패키지 내용도 동일했다(Excel 생성 타임스탬프 제외). 기존 `scripts/validate_mixed_rm_anova.R`도 통과했으며 기존 singular fit 안내가 출력됐다.
