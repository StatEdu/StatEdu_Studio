# 순서형 변환 최적화의 경계·메모리 검증 — 2026-09-14

## 결과

고유 범주가 64개를 넘는 입력에서 추가 unique 검사가 큰 성능 저하를 만드는지 확인했다. 65범주는 중앙값이 동일했고 1,000범주는 10회 합계 0.02초 증가했다. 127개짜리 짧은 벡터는 2,000회 합계가 0.17초에서 0.19초로 늘었다. 10만 행·8변수 전체 잠재 상관분석의 최대 작업 집합 중앙값은 약 1.69MB 증가했다. 결과 비교 21쌍은 모두 동일했다.

현재 최적화를 유지한다. 이번 작업에서 분석·화면·저장 코드를 추가 변경하지 않았고 설치 파일도 재빌드하지 않았다.

## 변환 함수 경계 측정

변경 전 소스는 고유 범주 변환을 추가하기 전 스냅샷, 변경 후는 현재 운영 소스다. 각 버전을 새 프로세스에서 3회 실행하고 두 번째 묶음의 순서를 뒤집었다. 입력·수준 생성과 준비 호출, gc는 시간 측정 밖이다. 반복 블록, 새 캐시 환경 생성, 진단/표준출력 수집은 포함한다. 매 호출 새 캐시를 사용해 캐시 미적중 시의 변환 비용을 측정했다. 메모리 검사와 동시에 실행하지 않았다.

| 입력 길이 | 고유 범주 수 | 반복 수 | 변경 전 중앙값(초) | 변경 후 중앙값(초) |
|---:|---:|---:|---:|---:|
| 127 | 3 | 2,000 | 0.17 | 0.19 |
| 128 | 3 | 2,000 | 0.17 | 0.03 |
| 100,000 | 64 | 10 | 0.75 | 0.02 |
| 100,000 | 65 | 10 | 0.78 | 0.78 |
| 100,000 | 1,000 | 10 | 0.87 | 0.89 |
| 100,000 | 100,000 | 10 | 1.05 | 1.04 |

표의 시간은 반복 합계이며 단일 호출이나 전체 상관분석 시간이 아니다. 짧은 127원소 입력의 차이는 호출당 약 10마이크로초, 1,000범주의 차이는 호출당 약 2밀리초다. 작은 차이는 이 3회 측정만으로 안정적인 회귀나 개선이라고 단정하지 않는다. 64범주 이하는 빠른 경로를 사용하고 65범주 이상은 원래 ordered 변환으로 복귀한다. 모든 값이 다른 조건은 검사한 최악의 고유값 수 조건이지만 모든 입력 유형의 최악 성능을 뜻하지 않는다.

6조건 × 3개의 반복 블록에서 마지막 변환 결과와 블록 전체 진단·표준출력·난수 상태를 비교해 18쌍이 `identical(..., num.eq=FALSE)`로 일치했다. 매 반복의 결과를 별도로 저장한 것은 아니다. 상세 입력 정확성은 [직전 적용 검증](PERFORMANCE_CORRELATION_DISTINCT_ORDER_20260914.md)의 297조건을 함께 참고한다.

## 큰 표본의 최대 작업 집합

10만 행·8변수, 정규 자료를 세 범주로 변환하고 각 변수에 무작위 결측 10%를 넣었다. 시드 33, `latent_correlations=TRUE`, `continuous_method='auto'`, `normality=TRUE` 조건으로 전체 `prepare_correlation_results`를 실행했다. 각 결과에 28개 쌍이 있음을 확인했다.

변경 전후 각각 새 프로세스에서 3회 실행했다. R이 직접 기록한 PID로 실제 계산 프로세스를 찾아 약 20ms마다 `PeakWorkingSet64`를 관측했다. Windows 실행기만의 메모리가 아니다. 두 번째 묶음은 순서를 반대로 했다.

| 묶음 | 변경 전(바이트) | 변경 후(바이트) |
|---|---:|---:|
| 1 | 312,422,400 | 316,506,112 |
| 2 | 312,696,832 | 314,114,048 |
| 3 | 311,599,104 | 314,077,184 |
| 중앙값 | 312,422,400 | 314,114,048 |

중앙값 차이는 1,691,648바이트(약 1.69MB, 0.54%)다. 이번 측정은 메모리 감소를 입증하지 않는다. 프로세스 작업 집합은 bootstrap, 입력 생성, 분석, 결과 저장까지 포함하며 총 할당량이나 최대 커밋 메모리와 다르다. 종료 직전 표본을 놓칠 수 있다.

전체 분석 결과 3쌍의 반환값·진단·표준출력·난수 상태가 정규화나 허용오차 없이 동일했다. 전체 분석 실행 시간은 이번 메모리 측정에서 성능 비교값으로 수집하지 않았다.
