# 다집단 데이터 진단 보조표 다국어 보완

- 표본 수 부족·집단 크기 불균형·순서형 범주 누락·집단 경고 없음·순열 추정 불안정 안내를 UI 언어로 표시한다.
- 표본 수 경고, 최소 범주 빈도, 누락된 순서형 범주의 열 이름도 보완했다.
- 실제 집단명 및 `변수={범주…}` 목록은 번역하지 않는다. 프로그램 상태에 등록되지 않은 사용자 문구와 이미 번역된 진단 셀을 일반 테이블의 재번역에서 보호한다.
- 측정불변성·구조경로 집단 비교·MICOM의 집단 진단 표시 경로에 적용했다. 계산과 본표 생성은 변경하지 않았으며 설치본은 만들지 않았다.

## 검증

- `scripts/validate_group_data_diagnostics_i18n.R`: 실제 집단 진단 함수의 결과로 4종 표본 수 경고 및 순서형 범주 누락을 확인했다. 일반·순서형·MICOM·사용자 문구·빈 표의 5개 경우를 8개 언어에서 검증했다.
- 집단명, 사용자 변수명/범주명/특수문자, N, 완전사례 수, 최소 범주 빈도, 결측률의 정확한 표시를 확인했다.
- 기존 MICOM 점검표 다국어 회귀 검증 통과.
- `tmp/group-data-diagnostics-i18n/entries.rds` 표시 스냅샷으로 현재·누적 HTML/PDF/Word/HWPX/Excel 저장을 검증했다. 현재 4표·누적 5표의 순서와 Excel 시트 수, PDF 일본어 제목/경고와 표지를 확인했다. 저장 시 분석은 다시 실행하지 않았다.

후속 범위: 집단쌍별 비교 허용 사유와 재표집 유효성 보조표의 프로그램 문구는 추가 점검 대상이다. 다집단 분석 전체의 번역 완료 판정은 아니다.
