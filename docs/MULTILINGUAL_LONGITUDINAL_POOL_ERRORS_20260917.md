# 종단 다중대치 통합 오류 번역 — 2026-09-17

계수 표 없음, 공통 계수 항 없음, 유한한 추정값 없음의 세 안내를 8언어 카탈로그와 종단 보조표에 연결했다. 계산 함수는 변경하지 않았다. 유한한 추정값 안내에 삽입되는 항 이름은 줄바꿈, 마침표, 한글, `<&>`, `%s`까지 원문을 유지한다. 사용자 데이터 열에 동일한 오류 문장이 있는 경우에도 원문 보존을 확인한다.

`validate_longitudinal_actual_mi_ipw.R`에 실제 통합 함수를 빈 목록, 공통 항이 없는 두 표, NA 추정값 표로 실행하는 세 사례를 추가했다. 기존 다섯 MI/IPW 사례와 합쳐 8경로 × 7개 비영어 언어, 총 56개 검사를 통과했다. 영어 문구와 사용자 열 보존도 검사했다. 이는 통합 함수의 경계 입력 검사이며 실제 MI 적합으로 모든 통합 실패를 유발한 시험은 아니다.

`validate_longitudinal_error_exports.R`는 이 실제 반환 표를 기존 시험 출력과 함께 저장한다. 본표 영어와 원본 결과 보존을 검사하며 한국어/일본어의 현재·누적 HTML, PDF, Word, 직접 생성 HWPX, Excel을 대상으로 한다. PDF 텍스트 검사는 `validate_longitudinal_error_pdf.py`에서 별도로 수행한다. 산출물: `tmp/longitudinal-error-exports`.

메타분석과 설치본은 작업하지 않았다. 전체 결측 처리 옵션, 미등록 외부 오류 및 브라우저·페이지별 시각 검토는 이번 범위에 포함하지 않는다.

위 저장 검증과 8언어 본표/사용자 원문 보존 검사는 모두 통과했다. PDF 네 개의 캡처 텍스트도 통과했으며 언어별 현재 13쪽, 누적 25쪽이다. 변경 파일의 `git diff --check`도 통과했다.
