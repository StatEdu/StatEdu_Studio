# 보조변수 전체 해제 후 언어 전환 — 2026-09-17

Chrome에서 IPW 보조변수를 모두 해제한 뒤 언어를 바꾸면 마지막 선택이 복구되는 문제를 재현했다. 서버 옵션 관찰자가 NULL 입력을 무시하여 빈 선택을 저장하지 않는 것이 원인이었다.

IPW 보조변수에 한해 NULL을 빈 벡터로 저장한다. 초기 관찰에서는 복원된 설정을 지우지 않고, IPW/WGEE 외의 전략에서 입력이 숨겨져 발생한 NULL은 무시한다. 계산식·결과표·저장 형식은 변경하지 않았다.

`validate_longitudinal_clear_language_browser.cjs`에서 가중치 유지/해제 2상태 × 보조변수 2개/1개/0개 3상태 × 8언어, 총 48개 실제 Chrome 전환 검사가 통과했다. 선택값·서버 설정·활성 탭을 보존하고 가중치 해제 시 절단 입력이 사라지며 무가중치 안내가 번역되는 것을 확인했다. JavaScript 오류는 없었다.

`validate_longitudinal_auxiliary_clear.R`의 실제 Shiny 서버 검사로 설정 복원, 전체 해제, 재선택, 다른 전략에서 숨겨진 입력의 보존을 확인했다. 별도 합성 데이터 화면의 검사이며 전체 앱 메뉴·자료 교체 검증은 아니다. 분석 실행·결과표·5종 저장은 재검사하지 않았다. 시험 서버와 Chrome은 종료했다.

계산기 담당 작업의 `fill_calculator_frs_options_i18n.py`도 검토·실행하여 코딩·출력 안내 7개를 8언어 공용 사전에 병합했다. 해당 기능 검증은 계산기 담당 작업 범위다. 메타분석과 설치본은 변경하지 않았다.
