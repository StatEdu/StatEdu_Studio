# 종단 설정 언어 전환 브라우저 검사 — 2026-09-17

합성 데이터와 실제 `register_longitudinal_handlers`/설정 UI를 사용하는 별도 Shiny 시험 화면을 127.0.0.1:43921에서 실행했다. 설치 앱이나 사용자의 자료·설정 파일을 사용하지 않았다. 검사 후 해당 시험 서버와 Chrome을 종료했다.

Chrome에서 GEE 상관구조를 AR(1)로 선택하고, 결측 탭의 MI 자료 수 9·반복 횟수 7·결측 종속변수 대체를 입력했다. 일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어로 전환하며 다음을 확인했다.

- 숫자 입력 2개와 종속변수 처리 선택 유지.
- 활성 결측 탭 유지.
- 서버 설정 전체가 기준 스냅샷과 동일함: 모형·상관구조·변수 배치 포함.
- 독립변수 블록 제목이 현재 언어의 번역과 일치.
- 브라우저 JavaScript 오류 없음.

8개 전환 검사가 통과했고 추가 제품 오류는 발견하지 못했다. 최초 시험 실패는 시험용 언어 선택기가 selectize로 숨긴 원래 select를 직접 클릭하려던 검사 코드 문제였다. selectize API에 맞춰 수정한 후 통과했다.

근거: `scripts/serve_longitudinal_language_test.R`, `scripts/validate_longitudinal_language_browser.cjs`. `git diff --check`가 통과했다. 검증만 추가했으므로 종단 결과표·5종 저장 검사는 재실행하지 않았다. 전체 앱의 환경설정 메뉴 왕복, 다른 모형/IPW/가중치/체크 옵션 조합과 시각적 배치 전반을 검증한 것은 아니다.
