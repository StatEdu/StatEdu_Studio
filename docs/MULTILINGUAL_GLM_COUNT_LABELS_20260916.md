# GLM 카운트 진단표 번역

2026-09-16. 설치본은 만들지 않았다.

## 변경

한국어 및 6개 다국어 카탈로그에 카운트 진단표 항목·설명 23개를 보완했다. 요청/선택 분포, 선택 규칙, 산포비, 영점 비율, AIC/BIC/로그우도, 우도비 통계량과 비교 설명, 영점 과잉 안내를 포함한다. AIC/BIC는 보조 진단이고 자동 분포 선택은 지정된 과산포 규칙을 따른다는 기존 의미를 유지한다.

계산 로직, 수치, 본 결과표 영어, 사용자 라벨은 변경하지 않았다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 23개 항목을 fixture에 추가하고 실제 분석 보조표에 이 영어 원문들이 남지 않는지 확인했다. 본표 영어·사용자 원문·옵션 값 검사도 유지했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 합성 count 분석의 기존 음이항 반복 한도 경고가 발생했으나 출력 검사는 통과했다.
- 일본어 현재/누적 HTML·Word·HWPX·Excel 내용 비교 및 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.

## 남은 범위

카운트 진단의 개별 최종 결정 사유(음이항 사용 가능/불가, MI에서 분포 고정 등), 보고 점검표의 모형 전체 설명, 결측자료 복합 요약이 추가 점검 대상이다. 전체 다국어 작업 완료를 의미하지 않는다.
