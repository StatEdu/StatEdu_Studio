# 보정 생존곡선 기본 반복수 및 메모리 후속 검증 — 2026-09-14

운영 코드의 추가 변경 없이, 앞서 적용한 결측 없는 평균 벡터의 복사 생략을 기본 부트스트랩 반복수와 별도 메모리 실험으로 검증한다. 비교 기준은 해당 변경 직전의 실제 `R/analysis_survival.R`이며, 기존 누적위험 재사용 최적화는 양쪽에 유지한다.

## 기본 반복수 실행 조건

600건, 3집단, 연속 생존 시간, 사건 생성 확률 0.45, 나이 공변량을 사용한다. 자료 생성 시드 421, 호출 전 시드 941, 선택 시점은 0·10·20이다. `survival_adjusted_curve()`의 `bootstrap_reps` 인수를 생략해 실제 기본값 2,000회를 실행한다. 60회 결과를 비례 환산하지 않는다.

번들 Windows R 4.5.3에서 변경 전후 각각 새 프로세스 3개를 순차 실행하며 두 번째 쌍은 버전 순서를 뒤집는다. 동일 자료로 60회 준비 실행 후 GC하고, 2,000회 전체 보정곡선 계산을 프로파일러 없이 측정한다. 최초 모형 적합·자료 생성·패키지와 앱 초기화·화면·저장은 제외하고, 통계적 부트스트랩 재적합·곡선·신뢰구간·대비 계산과 진단/표준출력 수집을 포함한다.

## 별도 메모리 조건과 결과

메모리는 이전 2,000건·3집단·부트스트랩 60회 조건을 사용한다. 기본 반복수 시간 실험과 다른 자료 크기·반복수이므로 두 실험을 혼합해 해석하지 않는다. 변경 전후 각각 새 프로세스 3개를 순차 실행하며 두 번째 쌍은 역순이다. 별도 준비 실행 없이 패키지/모듈 로딩, 자료 생성, 최초 Cox 적합, 보정곡선 계산 및 결과 직렬화를 포함한다.

R의 `Sys.getpid()`가 기록한 실제 계산 프로세스에서 `PeakWorkingSet64`를 약 20ms 간격으로 관측한다. 전체 R 프로세스의 관측 최고 작업 집합이며, 특정 함수만의 할당량이나 Electron 전체 메모리 측정은 아니다. 통계적 부트스트랩 2,000회 조건의 최고 메모리는 이 실험에서 측정하지 않는다.
