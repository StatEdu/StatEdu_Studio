# 전체 후보 갱신 및 사용자 모형 캔버스 재점검

## 정적 후보 현황

`audit_multilingual_contract.R`를 최신 소스에서 다시 실행했다. 333개 파일, 원문 발생 4,221개, 언어별 사전 누락 후보의 고유 문구 572개를 수집했다. 이 숫자는 실제 미번역 개수나 완료율이 아니다. 영어 본표, 미사용 경로, 전용 번역 키 및 내장 사전을 사용하는 문구가 포함된다. 이전 점검 및 3일간 작업 기록을 대체하거나 초기화하지 않는다.

## 캔버스 후보 35개 분류

`R/setup_custom_model_canvas_i18n.R`의 후보 35개를 `validate_canvas_static_candidates.R`로 확인했다. `analysis.ui.*` 일반 키만으로는 찾지 못하지만, 실제 구현은 `custom_model_canvas.*` 전용 키와 일본어 내장 번역, 영어·한국어 소스 문구를 사용한다.

35개 × 8개 언어 = 280개 반환값이 해당 번역 출처와 일치하고 `%s` 등 치환 자리표시자를 보존했다. 이번 후보에서는 새 누락이 발견되지 않았다. 번역 출처와 표시값을 `tmp/canvas-static-candidate-review/classified.csv`에 기록했다. 원어민 번역 품질 검수는 아니다.

## 실행 검사

- `validate_structural_canvas_shell_i18n.R`: CFA·SEM·PLS-SEM의 8개 언어 제목, 캔버스 전달 문구, 개수 자리표시자, 사용자 변수·라벨, 영어 결과 이름 검사 통과.
- `validate_structural_toolbar_i18n.R`: 구조모형 도구 모음 번역, 명령 ID·컨트롤 값·기본 선택·구조 보존 검사 통과.
- `validate_custom_canvas_progress_i18n.R`: 사용자 모형 진행 카드 4종의 8개 언어 문구, 개수·제공된 진행 정보·중지 ID 보존 검사 통과.

실행 로그는 `tmp/validate_<위 검사 이름에서 validate_를 제외한 부분>-recheck.log`에 저장했다. 화면 생성 및 렌더링 검사이며 실제 브라우저에서 모든 조작을 수행한 것은 아니다.

## 범위와 후속

제품 코드·사전·결과 출력 변경이 없어 저장 파일을 재생성하지 않았다. 설치본 빌드도 수행하지 않았다. 사용자 모형 캔버스와 구조모형은 현재 사용하는 기능이므로 포함하고, 사용하지 않기로 한 기존 매개·조절효과 화면은 계속 제외한다.

35개를 정적 후보 572개에서 단순 차감하지 않는다. 고유 문구는 여러 파일에서 중복되며 다른 경로의 실제 사용 여부는 별도로 확인해야 한다. 남은 일반 분석 결과 후보는 영어 본표 예외와 실제 부록 표시를 구분하는 작업을 이어간다.
