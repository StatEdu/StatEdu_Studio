# 대응표본 이상치 안내 번역 및 공통 상태값 회귀 수정

## 변경

이상치의 발견 없음, 발견 건수, 건수와 ID 목록 안내가 비한국어 UI에서 영어로 남는 것을 재현했다. 8개 언어 사전에 3개 문구를 추가하고, 대응표본의 Outliers 열 및 Item=Outliers인 Result 셀에서 건수·ID를 분리해 번역하도록 수정했다. 영어·기존 한국어 표현과 계산은 유지한다.

추가 공통 회귀 검사에서 이전 중복 번역 방지 수정으로 한국어 일반 상태값 Adequate가 번역되지 않는 문제도 발견했다. 한국어 값 번역은 대응표본 전용 번역을 우선 사용하고, 원문과 같으면 원본에서 계산한 공통 번역값을 사용하도록 보완했다. 이미 번역한 경고 문장을 다시 번역하지 않는다.

## 검증

- `validate_paired_outliers_i18n.R`: 실제 대응자료에서 이상치 2개와 ID 9, 10을 확인했다. 같은 자료의 요약 함수로 사용자 ID 목록, 빈 ID에 따른 건수만 표시, 정상 자료의 발견 없음 분기도 생성해 결과에 적용했다.
- 4개 표시 사례 × 8개 언어에서 안내 표시, 건수, Review/Normality 및 특수문자·`%s`가 포함된 ID의 순서, 영어 본표 동일성과 원본 결과 보존을 확인했다. 사용자 ID 사례는 실제 요약 함수의 출력으로 결과 체크값을 대체한 검사이며, 분석 입력 화면에서 ID 변수를 설정한 검사는 아니다.
- `validate_paired_guards.R`, `validate_nonparametric_ties_warning_i18n.R`, `validate_i18n_contract.R`: 통과.
- `validate_multilingual_table_roles.R`: 최초 한국어 일반 상태값 검사 실패 후 수정하여 통과. 16개 부록 번역 함수의 사용자 데이터·숫자·상태값 보존, 8개 분석 결과 렌더러의 영어 본표 및 부록 언어 메타데이터를 8개 언어로 검증했다. 공유 함수 검사는 사용하지 않는 기존 매개·조절효과 화면을 다시 범위에 넣는 의미가 아니다.
- 최종 수정 후 재생성한 캡처로 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 검사 및 PDF 텍스트 보존 검사 통과.
- 산출물: `tmp/paired-outliers-i18n/exports`. 저장 단계에서는 분석을 재실행하지 않는다.

## 범위

이번 수정은 이상치 안내와 확인된 한국어 일반 상태값 회귀에 한정한다. 다른 분석명·정규성 수치 안내 등은 후속 점검 대상으로 남긴다. 문서 앱별 수동 시각 검토 및 설치본 빌드는 수행하지 않았다.
