# 생존 추천 근거 다국어화

`survival_recommendation_explanation`의 추천 이유·주요 결과·대안 선택 설명을 6개 추가 UI 언어에 연결했다. 고유 문구 34개를 번역표에 추가했다. 한국어·영어 내용, 결과 목록 순서, 추천 엔진의 내부 규칙과 이동 대상은 변경하지 않았다.

`scripts/validate_survival_recommendation_explanations_i18n.R` 검증:

- 768개 설정 조합을 추천 엔진에 전달해 실행 가능한 G01/A01/G02/A03/A04/A05/S03 규칙을 확보했다.
- 7개 규칙과 미등록·빈 규칙의 기본 안내를 8개 언어에서 검사했다.
- 각 필드의 개수·순서, 번역된 이유/설명의 실제 생성 패널 포함 여부, 결과 목록 순서를 확인했다.
- 추천 객체가 변경되지 않음을 확인했다.

실제 추천 엔진과 생성 UI의 검사이며 통계 모형 적합이나 실제 브라우저 왕복 검사는 아니다. 추천 패널 자체의 상태·섹션 제목·버튼·자료 처리 요약과 설정 검증 오류는 별도 미완료 항목이다.

로그: `tmp/survival-recommendation-explanations-i18n.log`. 분석 출력은 변경하지 않았으므로 새 내보내기 파일은 만들지 않았다. 설치본은 만들지 않았다.
