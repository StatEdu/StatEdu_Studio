# 고차요인 CFA의 두 가지 상위 수준 HTMT

고차요인 CFA/CB-SEM의 기존 1차 요인 HTMT를 유지하고, 다음 두 표를 추가한다.

1. **Top-level HTMT (original items)**: 상위 개념에 속한 원문항 전체를 하나의 지표 묶음으로 사용한다.
2. **Top-level HTMT (subscale scores)**: 각 하위요인의 원문항 동일가중 평균을 지표로 사용한다. 다른 1차 요인의 관측지표는 그대로 사용한다.

A가 3문항, B가 3개 하위요인×3문항, C가 4개 하위요인×4문항이면 첫 번째 표의 지표 수는 3/9/16, 두 번째 표는 3/3/4이다. 각 표는 A–B, A–C, B–C를 제공한다. 하위척도 점수를 처음부터 관측변수로 입력한 일반 CFA는 기존 계산 경로를 유지한다.

## 계산과 해석

- 두 새 표는 분석 대상 사례 중 모든 상위 수준 지표가 완전한 동일 사례를 사용하며 Pearson 상관의 절댓값으로 HTMT를 계산한다. 사용 N과 추가 제외 사례 수를 출력한다. FIML CFA의 분석 N과 다를 수 있다.
- 기존 원문항 1차 요인 HTMT의 표본통계/polychoric 처리와 결과는 변경하지 않는다. 순서형 문항에서 두 새 표는 **관측점수 Pearson HTMT**임을 명시한다.
- 하위요인 평균은 원자료 척도에서 계산하며 역채점을 자동 적용하지 않는다. 문항 방향과 척도를 분석 전에 맞춰야 한다.
- 고차요인 모형의 추정 잠재상관을 HTMT의 입력 상관으로 사용하지 않는다. 두 새 표는 **관측점수 기반 기술적/민감도 평가**이며, 고차 잠재상관이나 PLS 2단계 요인점수 기반 HTMT로 보고해서는 안 된다.
- 원문항을 하나의 묶음으로 합치면 하위차원 구조가 분모에 영향을 미칠 수 있다. 두 수치를 서로 대체하거나 하나가 낮다는 이유만으로 판별타당도를 확정하지 않는다.
- 선택한 .85/.90 기준을 적용하되 합격 판정으로 표현하지 않는다.
- HTMT 부트스트랩 옵션을 켜면 기존 1차 수준과 두 상위 수준 모두 같은 seed의 사례 재표집으로 구간을 제공한다. 상위 수준에는 점추정과 같은 완전사례 집합을 사용하며 평균은 고정된 동일가중 함수이므로 재표집 전 평균 생성과 재표집 내 평균 생성이 동일하다.
- 교차 구성개념 간 공유 원문항, 평균 내 하위요인 간 공유 문항, 상수 지표, 부족한 지표 수는 해당 쌍의 계산 불가 사유로 처리한다. 상위 부트스트랩에서도 불완전한 상관 블록을 유효 반복으로 세지 않는다.
- 지원 범위는 단일집단의 2차 반영형 계층이다. 혼합 관측/잠재 지표, 3차 이상 계층, 원자료 없는 저장 결과 등은 사유를 출력한다.

방법 참고: Sarstedt et al. (2019), https://doi.org/10.1016/j.ausmj.2019.05.003 는 고차요인 평가에서 지표 구성과 평가 수준의 구분을 설명한다. 여기의 자동 문항 평균 방식은 그 논문의 PLS 추정 점수 절차와 동일하다고 주장하지 않는다.

## 구현과 저장

상위 수준의 두 행렬은 기존 하위요인 HTMT와 같은 `structural-htmt-matrix` 스타일을 공유한다. 숫자와 대각선은 가운데 정렬하고, 동일한 열 너비·행 음영·가로선·여백을 적용하며 상삼각은 비워 둔다.

상위 A/B/C의 AVE/CR은 별도의 신뢰도·수렴타당도 표에 표시한다. HTMT 행렬은 하삼각과 대각선 대시를 유지한다. 기존 1차 수준 및 두 상위 수준 HTMT 각각 바로 아래에는 요인 쌍별 HTMT, 95% CI(LLCI/ULCI), 유효 반복 수, 추정 상태 표를 둔다. 미선택/진행 중/취소/계산 불가는 대시와 상태로 구분하며 기존 분석 옵션에서 부트스트랩을 선택해야 구간을 계산한다. 상세 부록에는 단측 상한과 기준 판단을 포함한 진단표를 유지한다. A는 원문항, B/C는 직접 하위요인이 CFA 지표다. 기본 표준화 산식은 AVE = mean(λ²), CR = (Σλ)² / ((Σλ)² + ΣΨ)이며 Ψ는 직접 지표의 표준화 잔차공분산행렬이다. 비표준화 모형기반 옵션에서는 잠재변수 총분산을 곱한 적재량 제곱합 및 적재량 합의 제곱을 사용한다. CR 분모는 비대각 잔차공분산도 포함한다. 두 HTMT 방식의 AVE/CR은 동일하며 관측 원문항 총점이나 하위척도 평균점수의 신뢰도와 구분한다. 임의로 α 또는 ω total 값을 복사하지 않는다. 교차적재/추가 회귀가 있는 직접 지표, 혼합/3차 지표, 부적격 해는 N/A 및 사유를 출력한다. 숫자 workbook의 Higher_Validity 시트도 동일 산식을 사용한다.

산식 검증은 직접 지표의 모형 공분산을 공통분산/잔차분산으로 분해한 독립 계산, 고차요인 잔차공분산 모형, 잠재척도 식별법 변경을 포함한다. 방법 참고: https://search.r-project.org/CRAN/refmans/semTools/html/compRelSEM.html (직접 잠재지표 수준 CR과 원문항 점수의 고차 신뢰도는 구분).

`R/setup_custom_model_canvas_structural_higher_htmt.R`에 지표 구성, 두 점추정, 부트스트랩 연결, 공통 렌더러를 둔다. 기존 HTMT 출력에 두 표를 추가하며 현재/누적 결과는 동일한 화면 캡처 기반으로 HTML, PDF, Word, HWPX, Excel에 저장한다. 숫자 중심 CFA 통합 workbook에도 두 결과, 지표 구성, 방법과 구간을 포함한다.

검증: `scripts/validate_cfa_higher_htmt.R --exports`, `scripts/validate_cfa_higher_htmt_integration.R`, `scripts/validate_cfa_higher_htmt_pdf.py`, `scripts/validate_htmt_within_cache.R`.
