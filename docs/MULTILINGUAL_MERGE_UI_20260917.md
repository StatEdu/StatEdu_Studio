# 데이터 병합 설정·언어 전환 — 2026-09-17

## 수정

- 병합 설정, 구분자, 파일 선택, 요약 표, 미리보기/완료 안내의 29개 키를 8언어 사전에 추가했다. 설정 화면은 병합 전용 키를 직접 사용한다.
- 미리보기 DT의 검색·페이지 표시에는 공통 다국어 옵션을 적용했다. 실제 데이터의 열 이름·값은 번역하지 않는다.
- 상태 문구에는 번역된 문자열 대신 메시지 키와 행/열 수를 저장해 현재 UI 언어로 다시 표시한다.
- 업로드 파일 메타데이터와 입력값을 세션에 보관한다. 언어 변경으로 파일 입력을 다시 만들 때 파일명 표시와 서버의 업로드 자료 참조를 유지한다.
- 케이스 병합의 선택 변수가 언어 전환 때 전체 선택으로 돌아가는 문제를 브라우저에서 발견하고 수정했다. 선택 상태를 설정 UI에 반영한다.

## 검증

`validate_merge_ui_i18n.R`: 8언어 설정·구분자 코드·요약 표, 사용자 파일명 보존, 미리보기/불러오기 안내의 언어 변경을 확인했다. 언어 변경으로 데이터 교체를 다시 호출하지 않는다.

`validate_merge_browser.cjs`: 격리된 전체 앱과 Chrome에서 합성 CSV 두 파일을 업로드하고 한국어→일본어→중국어→스페인어→프랑스어→독일어→베트남어→영어→한국어로 전환한다. 파일명 표시, 파일 참조 유지 후 새 미리보기 실행, 케이스/변수 병합 옵션, 선택한 일부 변수, 사용자 지시값/지시변수 이름, 미리보기 수치와 현재 언어 상태 문구를 확인한다. 케이스 병합을 실제 실행하는 대표 경로이며 모든 파일 형식의 실제 병합을 망라하지 않는다.

`validate_merge_errors_i18n.R`와 `validate_multilingual_coverage.R`도 재검증했다. 로그는 `tmp/merge-ui-i18n.log`, `tmp/merge-browser.log`, `tmp/merge-errors-i18n.log`, `tmp/merge-ui-coverage.log`에 있다.

상단 메뉴는 기존 클라이언트 번역도 적용되어 일부 언어에서 본문 제목과 정상적인 표현 차이가 있다. 메뉴가 영어/한국어로 남지 않는지와 본문 제목의 전용 키 적용을 구분해 검사한다.

## 범위 제한

이번 변경은 데이터 편집 UI와 미리보기다. 분석 본표·보조표·내보내기 경로 변경은 없다. 설치본 생성 및 설치 앱 변경 없음. 전체 앱의 다국어 완료를 의미하지 않는다. 다른 파일 형식, 파일 교체 조합, 변수 병합 모드의 전체 브라우저 경로는 별도 검증 범위다.
