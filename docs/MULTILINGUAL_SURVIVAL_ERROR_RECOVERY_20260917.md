# 추가 입력 오류와 수정 후 회복

대상은 필수 역할 중복, 시간 원점 누락, 시간 단위 누락, 관심 사건 역할 누락, 경쟁위험에서 경쟁사건 역할 누락, 대상자 내 구간 중첩의 여섯 오류다.

`validate_survival_error_recovery.R`는 생성 자료에서 실제 사전검사를 실행하여 오류 코드와 차단을 확인하고 해당 입력 수정 후 검사를 통과하는지 확인한다. `validate_survival_error_recovery_browser.cjs`는 같은 오류를 실제 개발 앱의 UI에서 만들고 각 언어로 수정한다. 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어 각각에서 번역된 오류 표시와 버튼 숨김, 수정 후 오류 문구 제거 및 추천 이동 버튼 복구를 확인한다.

번역 기대값은 실제 오류의 앱 번역 함수에서 얻는다. 이는 번역 연결 검사이며 독립적인 전문 용어 감수가 아니다. 관심 사건 복수 지정, 사용자 정의 시간 단위, 사건 이후 구간, 중복 사건 및 자료 변경의 모든 조합까지 검증한 것은 아니다. 추천만 실행하며 통계 분석 결과·내보내기 코드는 변경하지 않는다. 설치본은 만들지 않는다.

로그: `tmp/survival-error-recovery-fixture.log`, `tmp/survival-error-recovery-browser.log`, `tmp/survival-error-recovery-server.log`.

실제 사전검사 6종 및 브라우저 6종 × 8언어의 오류 생성·수정 후 회복 검사가 모두 통과했다. 이전 오류 문구 제거와 추천 이동 버튼 복구를 확인했고 페이지 오류가 없었다. 새 제품 오류는 발견되지 않았다. 테스트 브라우저와 서버를 종료했다.
