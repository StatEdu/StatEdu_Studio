# Gray 검정 추정 불가 안내

추정할 수 없는 Gray 검정의 원인 코드 접두문과 후속 안내를 6개 추가 언어로 보완했다.
실패 코드 뒤에 붙는 원인 문자열은 원문 그대로 유지한다. 경고 조건·계산은 변경하지 않았다.

## 검증

- `validate_gray_failure_i18n.R`: 실제 경쟁위험 결과에 표시 검사용 Gray 진단 정보를
  넣어 정상/일부 실패/전체 실패의 세 분기를 8개 언어로 검사했다.
  각 실패 조건을 실제로 재적합한 검사는 아니다.
- 실패한 원인만 열거하고 Review 및 사용자 <&> %s를 보존하는지 확인.
  실제 결과의 Gray 본 표 영어와 값 유지 확인.
- 기존 공변량당 사건 수 경고 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 원인별 Cox와 Fine–Gray의 나머지 안정성 경고는 점검 대상이다.
