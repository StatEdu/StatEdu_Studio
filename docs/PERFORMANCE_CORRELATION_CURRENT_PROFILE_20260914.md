## 측정 범위

시드 33의 정규 합성 자료를 사용했다. 순서형은 경계 -0.5/0.5로 세 범주로 나눴고 결측 조건에서는 변수마다 서로 다른 1,000행을 결측 처리했다. 순서형 조건은 `latent_correlations=TRUE`, `continuous_method='auto'`, 연속 조건은 지정한 Pearson/Spearman이다. 모든 조건에서 `normality=TRUE`를 사용했다.

각각 새 프로세스 3개에서 조건을 Pearson→Spearman→순서형→결측 순서로 실행했다. 각 조건은 준비 실행 1회, 별도 비프로파일 시간 측정 1회, Rprof 1회다. 표의 시간은 전체 `prepare_correlation_results`와 동일한 진단/표준출력 수집을 포함한다. bootstrap, 입력 생성, 화면 렌더링, 저장, 앱 시작은 제외한다.

프로파일 간격은 0.01초다. 표본 시간은 CPU 표본 기반이며 실제 경과 시간과 다르다. 첫 번째 최초 실행 중 코드 확인용 별도 R 호출이 겹쳤으므로 해당 묶음을 다른 R 작업 없이 다시 실행했고 표에는 재실행 결과를 사용했다.

## 병목 근거

- 결측 순서형: `factor`의 self 표본 비율은 40.85%, 44.81%, 40.20%다. 원시 스택을 확인했을 때 해당 표본 125/138/123개 모두 `correlation_ordered_vector` 호출 아래에 있었다. 따라서 단순히 같은 이름의 다른 factor 호출을 병목으로 오인한 것이 아니다.
- 완전 순서형: 같은 factor self 표본은 9/8/8개로 훨씬 적다. 주요 비용은 polycor 추정 중 `mvtnorm::pmvnorm` 경로에 있다.
- Spearman: `rank`의 self 표본 비율이 56.25%, 56.67%, 58.06%로 반복 순위 계산이 우세하다. 전체 호출 자체는 약 0.44초다.
- Pearson은 조건별 표본이 8개뿐이고 실행 시간이 약 0.1초로 짧아서 함수별 세부 비율을 우선순위 판단 근거로 삼지 않는다.

기존 ordered 캐시는 값 벡터와 범주 목록이 정확히 같은 경우에만 재사용한다. 변수별 결측이 다르면 쌍마다 완전 관측치 벡터가 달라져 캐시 적중이 줄어든다. 다음 후보는 전체 벡터가 달라도 반복되는 범주 값의 변환을 재사용하는 방식이다. 범주 순서·비어 있는 수준·숫자의 문자 변환·결측·경고를 보존하는지 별도 검증한 뒤 적용 여부를 판단해야 한다. 현재 측정은 후보의 개선율을 입증한 것은 아니다.
