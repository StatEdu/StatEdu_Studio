# 구조방정식 도구모음 다국어

- CFA·SEM·PLS 공통 도구모음의 한국어/영어 분기 68곳을 공통 번역 함수로 연결했다. 모형/결과 열기·저장, 공변량 지정, 지표 배치·정렬, 초기화 확인창, 분석 실행, 결과 표시 도구의 이름과 도움말을 포함한다.
- 추가 언어 6개 사전에 도구모음 60문구와 선택 개수·용지 변경 안내 3문구를 보완했다. 한국어·영어 원문은 유지한다. 자료: `scripts/fill_structural_toolbar_i18n.py`.
- 캔버스의 선택 개수 및 용지 변경 title/aria-label은 R에서 전달한 번역을 JavaScript에서 사용한다. 용지 규격/방향 설정이나 실제 동작은 변경하지 않았다.

## 검증

- `validate_structural_toolbar_i18n.R`: 3분석 × 8언어 통과. 번역된 본문과 도움말, 버튼 동작 ID, 입력 값, 기본 선택 상태를 검사했다. 수정 전/후 영어 HTML도 Shiny 자동 생성 탭 ID를 정규화한 뒤 동일함을 확인했다.
- `validate_structural_canvas_shell_i18n.R` 재실행 통과. 사용자 변수 정보와 본표용 영어 제목 유지.
- `validate_structural_canvas_shell_js.cjs`: 실제 JS 핸들러의 8언어 모드·선택 개수·용지 안내·오류 개수 검사 통과.
- 공통 사전 검사와 JavaScript 구문 검사 통과. 근거: `tmp/structural-toolbar-i18n.log`, `tmp/structural-toolbar-coverage.log`.

## 범위

- UI 문구만 수정하여 분석 계산·결과표·그림 내용·저장 출력은 변경하지 않았다. 이번 변경에는 5형식 결과 내보내기 검사가 해당하지 않는다.
- 실제 브라우저의 전체 캔버스 조작, 고급 분석 옵션과 모델별 결과/오류는 별도 검증이 필요하다. 초기화·저장 등의 실제 동작을 이번 렌더링 검사로 실행한 것은 아니다.
- 이전 복합표본 사용자 모형의 HWPX 변환 시간 초과는 미해결이다. 설치본을 만들지 않았다.
