# 독립표본 비모수 분석의 현재 병목 재측정

## 결론

최근 본검정·사후검정·z값·효과크기 재사용을 반영한 상태에서, 여러 집단의 Wilcoxon 사후검정이 다음 최적화 우선순위다. 추가 표 생성 시 남아 있는 요약표 및 유의성 문자 계산은 이번 자료에서 상대적으로 작았다. 이번 작업에서는 프로그램 계산 코드를 변경하지 않았다.

현재 소스 SHA256: `C7052A1DB69ABD77268FA7EB744783EC79FFE4504AF31D95845EE0683251EF1D`. `output/independent-current-profile-20260914/current.R`에 측정 소스를 보존했다.

## 방법

20,000행, 2/4/8집단, 일반 연속값/반올림한 동점값, 추가 평균·표준편차 표 끄기/켜기의 12조건을 새 R 프로세스 3개에서 순차 측정했다. 효과크기·비모수 분석·사후검정을 켰으며 결측은 넣지 않았다. 두 번째 프로세스는 집단 수와 추가 표 옵션의 순서를 뒤집었다.

각 조건에서 먼저 예열하고 추적 없는 전체 실행을 측정한 다음, 별도 실행에서 앱 함수와 앱 코드가 직접 호출하는 통계 함수를 계측했다. 두 실행은 별개이므로 단계 시간을 전체 시간으로 나누어 점유율로 해석하거나, 중첩된 함수의 시간을 합산하지 않는다. 시간은 짧은 실행의 측정 해상도와 실행 변동 영향을 받는다.

36조건 모두 예열·전체 측정·단계 계측 실행의 전체 반환값, 경고/메시지, stdout, 난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. 숫자 반올림·정규화·허용오차는 적용하지 않았다. 이번 작업은 원시 htest를 별도로 비교하는 검증이나 오류 주입 검증을 추가한 것이 아니다.

## 주요 측정값

아래는 추가 표를 켠 경우다. 전체 시간은 3회 중앙값, 단계 시간은 별도 계측 실행 3회의 범위다.

| 집단 | 입력 | 전체(초) | 사후검정 단계(초) | epsilon squared 단계(초) |
|---:|---|---:|---:|---:|
| 4 | 연속값 | 0.31 | 0.14–0.15 | 0.06–0.07 |
| 4 | 동점값 | 0.12 | 0.06–0.08 | 0.01–0.02 |
| 8 | 연속값 | 0.48 | 0.32–0.33 | 0.06–0.08 |
| 8 | 동점값 | 0.23 | 0.15–0.16 | 0.01–0.02 |

두 집단은 사후검정을 실행하지 않는다. 추가 표를 켠 전체 중앙값은 연속값 0.14초, 동점값 0.06초였다. 추가 표를 끈 일부 연속값 실행은 큰 변동을 보였다. 예를 들어 두 집단은 0.35/0.12/0.33초였으므로 이번 자료로 추가 표 옵션 자체가 전체 실행을 빠르게 한다고 해석하지 않는다.

## 호출 수 확인

- 4/8집단에서 추가 표를 켜면 core와 요약표는 각각 2회 실행되지만, 사후검정 제공 함수·효과크기 함수·epsilon squared 함수는 각각 1회 실행된다. 유의성 문자 함수는 2회 실행된다.
- `kruskal.test`는 본검정과 효과크기 계산에서 각각 실행되어 합계 2회다. 계산 목적이 다른 두 호출을 이번에는 합치지 않았다.
- 두 집단에서는 Wilcoxon 본검정과 z 함수가 각각 1회, Cliff’s delta는 2회 실행된다. 이는 앞서 성능이 불명확해 Cliff’s delta 재사용을 제외한 결정과 일치한다.
- `pairwise.wilcox.test` 내부의 개별 Wilcoxon 호출은 직접 계측하지 않았다. 앱 코드의 직접 `wilcox.test` 계측값이 0이어도 사후검정 내부에서 Wilcoxon을 실행하지 않았다는 의미가 아니다.

## 다음 검토 대상

우선 Wilcoxon 독립표본 사후검정 내부의 순위·동점 처리를 검토할 근거가 확보됐다. 이미 대응표본 경로에서 사용하는 최적화는 `paired=TRUE`에만 적용되므로 그대로 연결해도 독립표본 내부 계산이 빨라지는 것은 아니다. 독립표본용 후보는 원시 검정값·진단·경계 사례·전체 결과를 별도로 검증해야 한다. 이번 측정만으로 해당 변경의 효과나 수치 동일성을 주장하지 않는다.

재현 스크립트는 `output/independent-current-profile-20260914/profile.R`, 전체·단계 시간은 `timing-1.csv`부터 `timing-3.csv`, 호출 수는 `calls-*.csv`다. 스크립트 준비 중 반올림 대상이 전체 데이터프레임으로 들어간 오류를 수정한 후 3개 프로세스 측정을 완료했다. UI·내보내기·배포 빌드는 변경하거나 실행하지 않았다.
