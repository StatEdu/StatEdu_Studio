# 종단 결과의 실제 앱 언어 전환

실제 앱에서 GEE를 실행한 후 환경설정에서 일본어로 바꾸고 종단 메뉴로 복귀하면 보조표가 한국어로 남는 문제를 재현했다. 결과 출력에 현재 세션 언어의 반응형 의존성을 추가하고, 숨겨진 결과 출력도 갱신하도록 수정했다. 재분석 없이 기존 결과 객체를 표시한다.

화면 검증에서 추가로 발견한 `Coefficients (detailed)`와 `Recommended analysis` 제목의 번역을 8개 언어 사전에 추가했다. 본표, 변수명, 계산값은 변경하지 않았다. 파일 분할용 스냅샷 번역 연결을 조사했으나 이번 일반 결과 경로와는 별개여서 해당 코드는 추가하지 않았다.

검증:

- `validate_longitudinal_result_navigation_browser.cjs`: 별도 프로필의 실제 앱에 합성 CSV 120행을 업로드하고 GEE Gaussian 분석 실행. 8언어 전환 후 본표 모든 셀이 한국어 실행 당시의 영어 본표와 동일함을 확인했다. 가정 점검 및 새 제목 두 개가 UI 언어를 따르고, 이미 추가한 누적 결과의 iframe HTML이 그대로 유지됨을 확인했다. JavaScript 오류 없음.
- 누적 결과 추가는 비동기이므로 캡처 완료 후 기준 스냅샷을 수집한다. 환경설정 lazy 로딩으로 첫 메뉴 이동이 늦어지면 재방문한다.
- `validate_longitudinal_auxiliary_clear.R` 회귀 검사 통과.
- `validate_longitudinal_count_exports.R`에 캡처 JSON 입력을 지원하여 실제 화면 HTML을 그대로 내보내기 검사에 사용한다. 모형을 다시 적합하지 않는다.
- 한국어·일본어 × 현재/누적 결과의 HTML·PDF·Word·직접 생성 HWPX·Excel 검사 통과. HTML/문서 XML/Excel 셀에서 캡처한 제목·표 셀 등 텍스트 보존을 확인했다. `validate_longitudinal_error_pdf.py`도 4개 PDF의 캡처 텍스트 보존 검사 통과(현재 각 11쪽, 누적 각 21쪽). 페이지별 시각 검수는 수행하지 않았다.

범위: 일반 GEE 결과의 언어 갱신과 캡처 내용 보존. 파일 분할 결과의 언어 갱신, 다른 모형의 실제 실행 및 모든 보조표 문구의 완전성 검사는 후속이다. 실행 중 기존 factor 연산 경고가 있었으며 이번 작업에서 통계 엔진은 변경하지 않았다. 설치본 생성 없음.
