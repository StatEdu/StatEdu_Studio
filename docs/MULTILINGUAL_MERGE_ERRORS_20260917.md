# 데이터 병합 오류 번역 — 2026-09-17

## 수정 범위

파일 개수 부족, 변수 병합 파일 부족, ID 입력 누락, 파일 내 ID 변수 없음, ID 중복, 케이스 병합 파일 부족, 공통 변수 없음의 7개 오류와 데이터 교체 불가 안내를 8언어로 연결했다.

`merge_abort`는 오류 키와 삽입 값을 별도로 보관한다. 기본 오류 메시지는 기존 영어와 동일하며, 미리보기/실행 알림에서 현재 UI 언어로 표시한다. 사용자 변수명은 번역하거나 문자열 패턴으로 분해하지 않는다. 외부 파일 읽기 오류 등 알 수 없는 오류는 원문을 유지한다.

## 검증

`scripts/validate_merge_errors_i18n.R` 통과:

- 실제 함수 호출로 7개 오류 발생 및 8언어 번역 확인.
- 따옴표·한글·`<&> %s`를 포함한 사용자 변수명과 외부 오류 상세 보존.
- 실제 CSV 업로드 메타데이터로 서버의 미리보기/실행 오류 알림 확인. 잘못된 병합은 데이터 교체를 호출하지 않음.
- 데이터 교체 기능이 없는 경우의 8언어 알림 확인.
- 정상 left/inner/full 변수 병합과 케이스 병합의 값·행 동작 확인.
