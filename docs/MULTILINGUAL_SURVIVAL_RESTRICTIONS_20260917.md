# 생존분석 지원 제한 안내의 브라우저 검사

이번 범위는 다음 여섯 추천 분기다.

- 반복 사건 모형: 미지원
- 다상태 모형: 미지원
- 구간 검열 자료: 미지원
- 단일 행 자료에서 시간의존 공변량 선택: 해당 구조 미지원
- 지연 진입 자료의 경쟁위험 분석: 미지원
- 시작/종료 자료에서 시간의존 설정 미확인: 추가 확인 필요

`scripts/validate_survival_restriction_branches.R`는 추천 엔진에서 각 분기의 기대 문구를 생성한다. `scripts/validate_survival_restriction_branches_browser.cjs`는 생성 CSV를 로컬 개발 앱에 열고 실제 사전검사 및 추천을 실행한다. 각 상태를 일본어·중국어·스페인어·프랑스어·독일어·베트남어·영어·한국어로 왕복하며 추천명·제한 사유의 번역 연결, 분석 이동 버튼 부재, 사용자 입력 `Review 사용자 <&> %s` 보존을 검사한다.

다상태와 반복 사건은 연구 목적 선택으로 추천 분기를 확인하며 실제 다상태·반복 사건 자료를 분석하는 검사가 아니다. 동일 추천을 생성하는 모든 선택 조합 및 모든 자료 오류를 실행한 것도 아니다. 기대 문구는 앱의 번역 함수를 사용하므로 독립적인 번역 품질 감수와는 구분한다.

로그: `tmp/survival-restriction-fixture.log`, `tmp/survival-restriction-browser.log`, `tmp/survival-restriction-server.log`. 통계 분석·결과·내보내기는 변경하지 않으며 설치본은 만들지 않는다.

6개 분기 × 8언어 검사가 모두 통과했다. 페이지 오류가 없었고 제품 수정이 필요한 새 오류는 발견되지 않았다. 테스트 브라우저와 서버를 종료했다. 다음 점검 대상은 실제 입력 오류의 안내 분기다.
