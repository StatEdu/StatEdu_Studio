# ANCOVA 제외 및 오류 안내

2026-09-17

- 완전 사례 최소 4개, 집단의 관측 수준 최소 2개, 공변량 미선택, 데이터 없음의 4개 알려진 오류를 한국어와 추가 6개 언어로 표시하도록 보완했다.
- 계산 계층의 오류 메시지는 변경하지 않고 ANCOVA 결과 표시에서만 변환한다. 미등록 오류 상세는 원문 유지하며 진단표 공통 변환기에 재번역되지 않도록 Message 열을 보호한다.
- `validate_ancova_errors_i18n.R`: 실제 자료와 입력으로 3가지 분석 제외 및 데이터 없음 오류를 발생시켜 8개 언어에서 검증했다. Review, 한글, <&>, %s 변수/집단 이름과 미등록 오류 상세도 보존된다.
- 일본어 제외 진단표 3개와 사용자 오류 상세 fixture 1개를 저장해 현재 4표·누적 5표의 HTML/PDF/Word/HWPX/Excel 내용, PDF 표지, 표 순서, Excel 시트 수 검증을 통과했다. 데이터 없음의 독립 오류 블록은 UI 검사 대상이며 표 내보내기 fixture에는 포함하지 않았다. 저장 과정에서 재분석하지 않는다.
- 기존 실제 ANCOVA 3개 다중공선성 모형의 8개 언어 회귀 검사 통과: 수치와 영어 본표 유지.
- 산출물: `tmp/ancova-errors-i18n/`, `tmp/ancova-errors-test.log`, `tmp/ancova-errors-exports.log`, `tmp/ancova-errors-regression.log`.
- 설치본은 생성하지 않았다. 전체 다국어 완료를 뜻하지 않으며 모형 선택 사유의 나머지 문구는 후속 점검 대상이다.
