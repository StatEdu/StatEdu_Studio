# 경쟁위험 집단·원인별 사건 수

사건 수 표의 Role에 사건 매핑과 같은 전용 번역을 적용한다. Event value는 원자료
코드로 보호한다. 제목·사건 비율·사건 없음/5건 미만 안내의 번역 4개 항목을 추가했다.
한국어 사건 비율 및 안내도 보완했다.

## 검증

- `validate_competing_event_counts_i18n.R`: 실제 사건 집계 함수에 0/2/6건이 발생하는
  자료를 전달하여 세 검토 분기를 검사했다. 빈 표도 8개 언어에서 렌더링했다.
- 집단명·사건 코드·라벨 특수문자와 번역 문구 충돌, 수치 표시 보존 확인.
- 기존 실제 경쟁위험 개요 및 영어 CIF 본 표 회귀 검사 통과.
- 일본어 현재 1개 / 누적 2개 사건 수 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서 및 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. CIF 무결성 등 기타 보조표는 추가 점검 대상이다.
