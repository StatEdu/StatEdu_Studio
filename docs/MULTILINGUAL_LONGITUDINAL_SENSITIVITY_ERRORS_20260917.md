# 종단 민감도 분석 패키지·계수 반환 오류 — 2026-09-17

MI용 mice 패키지 필요 안내와 가중 모형의 계수 표 반환 실패 안내 두 문장을 8언어 카탈로그에 추가하고 보조표 표시 함수에 연결했다. 계산 함수, 패키지 설치 상태, 본표 영어 규칙은 변경하지 않았다.

`validate_longitudinal_actual_mi_ipw.R`의 격리된 함수 환경에서 패키지 확인 결과를 FALSE로, 모형 반환값을 빈 계수 표로 지정해 각 실제 분기를 실행했다. 정상 가중치 준비는 실제 함수로 실행한다. 두 사례는 실제 패키지 제거나 실제 엔진 장애를 일으킨 시험과 구분한다. 기존 실제 MI/IPW·통합 경계 입력 8사례와 합쳐 10경로 × 7개 비영어 언어의 70개 검사를 통과했다. 새 문구의 정확한 번역값, 사용자 데이터 열의 원문, 영어 표시도 확인했다.

`validate_longitudinal_error_exports.R`에 포함된 반환 표로 8언어 본표 영어·원문 보존을 검사하고 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel 저장을 검증한다. PDF의 캡처 텍스트는 `validate_longitudinal_error_pdf.py`에서 검사한다. 산출물은 `tmp/longitudinal-error-exports`다.

전체 옵션·외부 오류 및 브라우저·페이지별 시각 검토를 완료한 것은 아니다. 메타분석은 제외했고 설치본은 생성하지 않았다.

8언어 표시 검사와 한국어/일본어 현재·누적 5종 저장 검사는 모두 통과했다. PDF 네 개의 모든 캡처 텍스트를 확인했으며 언어별 현재 15쪽, 누적 29쪽이다. 변경 파일의 `git diff --check`도 통과했다.
