# 교차표 행 데이터프레임 변환 간소화

2026-09-15. 직전 Gamma·추세 벡터·백분율 문자열 개선을 유지한 상태에서 완성된 표시 행의 데이터프레임 변환을 간소화했다.

## 재측정과 변경

80×80 순서형 교차표에서 백분율을 모두 끈 경우와 모두 켠 경우를 각각 20회, Rprof 0.005초 간격으로 관측했다. 표본 합계는 1.66/1.95초다. 표 생성의 포함 스택 비중은 78.61/82.05%, deparse는 24.10/22.31%였다. 백분율 계산 함수는 모두 켠 조건에서 0.77%, rowSums는 0.51%에 그쳤다. 스택 비중은 중첩되며 실제 경과 시간과 구분한다.

따라서 작은 합계 계산의 재사용보다, 이미 문자형 스칼라로 완성된 각 행에 일반 `as.data.frame` 변환을 반복하던 부분을 바꿨다. 정상적인 열 이름에서는 base R의 `list2DF`를 사용한다. 빈 이름·NA 이름·중복 이름이 있으면 기존 `as.data.frame(..., stringsAsFactors=FALSE, check.names=FALSE)`로 복귀한다. 셀 문자열 생성, 합계, 열 순서와 마지막 rbind는 그대로다. 사용하지 않는 백분율 행렬 계산 등 다른 부분은 이번에 변경하지 않았다.

## 검증

`scripts/fixtures/crosstab_row_frame_reference.R`는 백분율 일괄 생성까지 적용된 직전 표시 함수다. 이를 기준으로 `scripts/validate_crosstab_row_frame.R`에서 928개 비교가 정확히 일치했다. 비교 대상은 전체 표시 데이터프레임의 값/문자열/행·열 이름/속성, 조건 클래스·본문·순서, 표준 출력과 최종 RNG다. `identical(..., num.eq=FALSE)`를 사용했으며 정규화하거나 반올림하지 않았다.

기존 백분율 옵션 16조합 및 소수점 구분자 2종, 0합계·NA/Inf·음수/소수 등 입력에 추가하여 빈 열 이름, 중복 이름, Row/Total 충돌, NA, 공백/기호, 한글·한자·그리스 문자 이름을 검사했다. 오류가 발생하는 사례는 기존 오류 클래스와 본문도 보존하는지 비교했다. 모든 가능한 사용자 자료를 전수 검사한 것은 아니다.

아래 전체 분석의 준비 및 측정 결과도 반환 객체 전체와 진단/RNG가 정확히 일치했다. 기존 `scripts/validate_crosstabs.R`이 HTML/Excel 저장 helper까지 통과했다. 표시 내용과 저장 형식은 변경하지 않았다. 전체 PDF/Word/HWPX 교차 형식 검사 및 설치 파일 빌드는 수행하지 않았다.

## 전체 분석 성능

번들 R 4.5.3, 각 셀 8명인 4·12·40·80수준 순서형 행/열 변수, 추세 켜짐 조건이다. 각 크기에서 백분율 모두 끔/모두 켬을 각각 측정했다. 80×80은 51,200행이며 충분한 기대빈도로 Monte Carlo Fisher를 사용하지 않는다.

기준/현재 모듈을 별도 환경에 읽고 양쪽 함수를 동일하게 compiler::cmpfun으로 준비했다. 독립 프로세스 3개를 순차 실행하고 각 조건 준비 비교 후 3회 측정했다. 두 번째 프로세스의 순서는 반대로 했다. 타이머는 전체 R 분석과 동일한 진단/출력 캡처를 포함하며 비교 자체는 타이머 밖이다. 앱 로딩, 브라우저 배치, 파일 저장은 제외한다.

|---|---|---|
|빈도만|0.23 / 0.22 / 0.25|0.11 / 0.11 / 0.12|
|백분율 모두|0.27 / 0.27 / 0.27|0.16 / 0.16 / 0.15|

대표 중앙값은 빈도만 0.23→0.11초(약 52%), 백분율 모두 0.27→0.16초(약 41%)다. 직전 개선이 포함된 소스와의 추가 개선이며 전체 앱의 개선율은 아니다.

작은 표의 개별 시간은 0.00~0.02초로 흔들려, 4×4에 대해서는 별도 한 프로세스에서 준비 후 100회 실행 블록을 3회 비교했다. 두 번째 블록의 순서를 뒤집었으며 블록 끝 결과를 정확 비교했다. 호출당 중앙값은 빈도만 0.0060→0.0052초, 백분율 모두 0.0062→0.0055초였다. 이 반복 조건에서는 성능 저하가 관측되지 않았지만 최초 호출이나 다른 환경까지 보장하는 수치는 아니다.
