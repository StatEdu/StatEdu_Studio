# 원인별 Cox 공선성 경고

VIF 중간/높음, 비유한 VIF, 높은 조건수 경고의 근거와 안내 7개 번역 항목을
6개 추가 언어에 보완했다. 수치 문자열과 기존 한국어/영어 및 경고 조건은 유지한다.

## 검증

- `validate_cause_specific_collinearity_i18n.R`: 실제 경쟁위험 결과의 진단 메타데이터에
  VIF 4.99/5/10/Inf와 조건수 29.99/30을 넣어 5가지 상태를 8개 언어로 검사했다.
  각 조건의 회귀 모형을 새로 적합한 검사는 아니다.
- 경고 선택과 수치 정밀도, 실제 영어 CIF 본 표 유지 확인.
- 원인별 비례위험·영향력 경고 회귀 검사 통과.
- 일본어 현재 4개 / 누적 5개 경고 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 내용·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. Fine–Gray 안정성 경고 등의 추가 점검은 남아 있다.
