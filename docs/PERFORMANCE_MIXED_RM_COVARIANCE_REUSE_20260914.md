# 혼합 반복측정 공분산 공통 행렬 재사용

2026-09-14. 동일한 일괄 회귀의 시점 대비들에서 공통인 `cov.unscaled`를 재사용한다. 첫 대비는 표준 `stats::summary.lm()`으로 계산하고, 이후 대비는 해당 대비의 잔차로 sigma를 새로 계산한 summary 객체를 표준 `stats::vcov()`에 전달한다. 계수의 NA 여부도 현재 대비에서 가져온다. 각 대비의 공분산 자체를 공유하는 것은 아니다.

## 결과 불변을 위한 처리

앞선 검토에서 차이를 만든 `resvar * cov.unscaled` 단순화는 사용하지 않는다. 기존과 동일하게 `sum(residuals^2) / df`, 제곱근, 그리고 `vcov.summary.lm()`의 sigma 제곱 순서를 유지한다. 추정값과 표준오차의 행렬 곱 순서도 유지한다.

번들 R 4.5.3의 `summary.lm()`과 같은 거의 완전 적합 판정식을 사용한다. 해당 조건이나 비정상 잔차분산·자유도에서는 표준 `vcov(lm)` 경로로 돌아간다. 기존 일괄 계산의 경고·메시지·오류 시 개별 계산으로 돌아가는 처리도 유지한다. 공통 행렬은 한 일괄 호출 안에서만 유지한다.

이 경로는 기존에 제한한 일반 유한 숫자 데이터의 무가중·무오프셋 일괄 회귀에만 적용된다. 표준 summary 계산의 의미에 의존하므로 R 런타임 변경 시 아래 정밀도·경고 검증을 다시 실행해야 한다.

## 측정

2,000명, 4집단, 6시점, 숫자 공변량 1개, Holm 사후 비교. 버전별 새 R 프로세스 3개를 순차 실행했고 두 번째 쌍의 순서를 바꿨다. HTML 생성 시간을 제외한 전체 분석 시간이다.

| 중앙값 | 기존 | 변경 |
|---|---:|---:|
| 첫 분석 | 0.78초 | 0.77초 |
| 반복 분석 | 0.26초 | 0.25초 |

반복 분석의 개별 값은 기존 0.27/0.26/0.25초, 변경 0.25/0.24/0.25초다. 중앙값 기준 약 4% 차이지만 절대 차이가 0.01초로 작고 측정 구간이 겹친다. 큰 전체 성능 향상을 주장하지 않는다. 15개 대비의 공통 역행렬 계산을 한 번으로 줄이는 국소적인 개선이다. 실제 메모리 사용량은 측정하지 않았다.

## 검증

- `scripts/validate_mixed_rm_batch_pairs.R`: 기존 48개에 매우 작거나 큰 반응, 처음/후반 대비의 거의 완전 적합을 추가한 64개 경계조건. 반올림 전 검정 목록·경고·메시지·표준출력·난수 상태가 정확히 일치. 데이터 변경 후 재계산 및 제공 공분산과 표준 공분산의 일치도 확인.
- `precision.R`: 숫자·완전 공선성·거의 공선성·매우 작은/큰 값·첫/후반 대비 완전 적합·포화 모형, 8조건 × 10입력. 변경 전후 80개 전체 대비 목록과 조건이 `identical()` 일치. 최적화 경로에서 제공한 공분산 1,950개도 각각 표준 `vcov(lm)`과 `identical()` 일치.
- 전체 분석 12개 시나리오와 성능 측정 3쌍: 허용오차 0, 환경 객체 제외 비교 통과. 공선성과 단일 집단은 기존과 같은 분석 오류를 반환한 시나리오다.
- 일반 HTML 정확히 일치. 보고서 HTML은 생성 시각만 정규화해 일치. 현재·누적 HTML 동일, Excel은 생성 타임스탬프를 제외한 패키지 내용 동일.
