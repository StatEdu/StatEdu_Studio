# Eta 집단 평균의 split/vapply 후보 검토

## 결론

제품에는 반영하지 않았다. `tapply(values, groups, mean)`을 `vapply(split(values, groups), mean, numeric(1))`로 바꾸면 같은 평균 함수를 사용하면서 tapply의 준비를 줄일 수 있는지 검토했다. 최종 결과는 검증 조건에서 일치했지만 속도 이득이 일관되지 않았고, 내부 평균값의 배열 구조도 달라졌다. 앞서 적용한 lm 적합 및 직접 관측치 집계는 유지한다.

## 정확성

216개 조건의 최종 Eta 반환값·진단·stdout·난수 상태가 `identical(..., num.eq=FALSE)`로 일치했다. treatment/sum/Helmert 대비, 2/3/6집단, 3/12/100행, 일반·인접 실수·동점·큰 수·결측·무한대·상수·ordered 자료를 포함한다. 이 중 원시 ANOVA 요약이 생성된 153개에서 요약 객체도 정확히 일치했다.

별도 100개 입력 조합을 세 성능 프로세스에서 반복 확인했다. 전체 분석 네 조건 × 세 프로세스에서 예열 및 각 5회 묶음의 모든 반복 결과도 기존 기준과 일치했다. 결과 수치에 반올림·정규화·허용오차를 사용하지 않았다.

그러나 내부 상태의 추가 검증은 실패했다. 첫 조건(treatment, 2집단, 3행, 일반 자료)에서 후속 계산에 쓰이는 `means[names(counts)]`가 기존에는 dim/dimnames가 있는 1차원 배열이고 후보에서는 names가 있는 숫자 벡터였다. 최종 결과의 불일치를 발견했다는 뜻은 아니지만 내부 구조까지 동일하다는 주장은 할 수 없다. 이 차이를 정규화하여 통과 처리하지 않았다. `validate-state.R`은 해당 불일치에서 중단되고 `inspect-state.R`이 첫 사례를 표시한다.

## 시간

10,000행·20변수·190쌍, 여섯 범주의 명목형 또는 연속형 10개/명목형 10개 혼합 자료를 사용했다. 결측 조건은 변수마다 다른 무작위 10% 결측이다. 시드 33, Pearson 지정, 정규성 및 잠재상관 비활성화 조건이다. 혼합형에는 Eta 100쌍이 있다.

소스별 환경의 상관분석 함수를 명시적으로 컴파일했다. 새 R 프로세스 세 개를 순차 실행하고 양쪽 예열 후 두 번째 프로세스의 조건 및 측정 순서를 뒤집었다. 프로파일러 없이 전체 결과 준비·진단 수집·동일성 검사를 5회 반복한 총시간을 5로 나눈 값이다.

| 자료 | 기존 3회 값(초) | 후보 3회 값(초) |
|---|---|---|
| 명목형 | 0.238 / 0.216 / 0.220 | 0.234 / 0.222 / 0.222 |
| 명목형, 결측 10% | 0.222 / 0.232 / 0.216 | 0.222 / 0.210 / 0.210 |
| 혼합형 | 0.354 / 0.334 / 0.350 | 0.350 / 0.362 / 0.344 |
| 혼합형, 결측 10% | 0.324 / 0.304 / 0.324 | 0.302 / 0.324 / 0.300 |

혼합형 두 조건은 각각 두 번 단축, 한 번 증가했다. 결측 없는 혼합형의 중앙값은 0.350→0.350초로 같았다. 결측 혼합형의 중앙값은 0.324→0.302초였지만, 두 번째 실행에서는 0.304→0.324초로 늘었다. 변경 경로를 사용하지 않는 명목형 대조 조건에서도 변동이 있었다. 이 측정만으로 안정적인 개선을 주장하지 않으며, 후보 자체가 항상 느리다고도 단정하지 않는다.
