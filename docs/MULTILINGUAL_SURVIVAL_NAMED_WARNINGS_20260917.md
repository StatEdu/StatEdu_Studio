# 생존분석 경고의 사용자 이름 보존

## 변경

- 곡선 교차 경고의 접두어를 6개 추가 언어 번역표에 연결했다.
- 곡선 교차 비교명, 원인별 Cox PH 신호 변수명, 원인별 범주형 검정 실패 변수명의 조립된 근거 셀을 후속 자동 번역에서 보호한다.
- 자동 설명은 UI 언어, 사용자 이름은 원문을 유지한다. 통계 계산과 경고 조건은 바꾸지 않았다.

## 검증

`scripts/validate_survival_named_warnings_i18n.R`는 실제 Kaplan–Meier·원인별 Cox 적합 결과를 바탕으로 경고 메타데이터를 구성했다. 별도로 실패 모형을 적합한 검증은 아니다.

- 경고 3종 × 신호 유무 × 8개 언어 검사 통과.
- `Review`, `Normality`, `사용자 <&> %s`가 경고 대상일 때 원문 보존 확인.
- 정상 대상 `None`이 경고에 포함되지 않는지 확인.
- 기존 원인별 Cox 진단 회귀 검증에서 PH 경계·영향력 집계·본 표 영어 유지 확인.
- 일본어 경고표 캡처로 현재·누적 결과 저장. 저장 시 재분석하지 않는다.
- 산출물: `tmp/survival-named-warnings-i18n/`.
- 현재 3개·누적 4개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지와 표 순서·시트 수도 확인했다.

전체 다국어 완료를 의미하지 않는다. 설치본은 만들지 않았다.
