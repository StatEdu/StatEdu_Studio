# 경쟁위험 공변량당 사건 수 경고

공변량당 관심 사건 수의 동적 근거와 모형 복잡도 재검토 안내를 6개 추가 언어로
번역했다. 기존 계산, 경고 기준, 한국어/영어 문구는 유지한다.

## 검증

- `validate_competing_epv_i18n.R`: 실제 CIF 결과를 바탕으로 진단 메타데이터의 계수 수를
  2, 사건 수를 0/19/20으로 지정했다. 원인별 Cox/Fine–Gray 두 분기에서 비율
  0/9.5/10 및 10 미만 경고 조건을 8개 언어로 검사했다.
  이 검사는 경고 조건/표시 검사이며 각 회귀 모형을 새로 적합한 것은 아니다.
- 비율의 기존 정밀도, 번역 문구 및 실제 CIF 영어 본 표 유지 확인.
- 기존 네 가지 희소 사건 경고 회귀 검사 통과.
- 일본어 현재 4개 / 누적 5개 경고 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 다른 회귀 안정성 경고는 추가 점검 대상이다.
