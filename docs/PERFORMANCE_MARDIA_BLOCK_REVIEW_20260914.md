# Mardia 블록 계산 후보 검토 — 2026-09-14

거리 행렬을 128열씩 계산하는 후보를 구현했지만 원시 통계량의 정확 동일성이 깨져 **제품에 반영하지 않았다**. 화면에 표시되는 반올림된 표가 같다는 것만으로 결과 보존을 판단하지 않았다.

## 후보

`centered %*% inv_cov`를 한 번 계산한 뒤, centered의 128행씩을 전치해 거리 행렬의 열 블록을 만들었다. 각 블록의 세제곱 합을 누적하고 n²으로 나눠 왜도를 계산했다. 대각 원소는 블록에서 추출해 원래 행 순서로 보관하고 기존 첨도 계산에 사용했다. 원래 `mean(distances^3)`의 전체 배열 평균을 블록 합산으로 바꾼 시험 구현이다.

## 정확 비교

변수 12개, 관측치 500/1,500/3,000 × 시드 930/931/932, 총 9개 입력을 검사했다.

- 9개 중 **4개**에서 원시 왜도·왜도 검정 통계량·p값이 정확히 같지 않았다.
- 최대 절대 차이: 왜도 약 1.22e-15, 왜도 χ² 약 5.68e-13, 왜도 p값 약 2.00e-15.
- 첨도·첨도 z·p값은 9개 모두 정확히 같았다. 거리 행렬 대각의 수치도 이름 속성을 제외한 비교에서 모두 같았다. 비대각 원소 전체의 직접 동일성은 검사하지 않았다.
- 표시용 표와 정규성 판정, 경고·메시지 클래스/문자열/순서, 난수 상태는 이 9개에서 같았다. 판정 경계 근처의 모든 입력에서 같다는 의미는 아니다.
- 비교는 `identical(..., num.eq=FALSE)`를 사용했다. 위 차이를 허용오차로 통과시키지 않았다.

- 번들 R 4.5.3의 새 프로세스 3개를 순차 실행했다. 프로세스별 시드는 929+id이며 공통 정규 잠재값과 독립 정규 오차를 합쳐 자료를 생성했다. 각 분석 전 시드 718로 초기화했다.
