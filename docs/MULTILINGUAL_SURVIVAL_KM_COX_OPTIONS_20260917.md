# 사건 변수 안내 및 KM·Cox 옵션

35개 문구의 6개 언어 번역을 추가하고 기존 한국어/영어 분기를 공통 번역 경로에 연결했다. 사건 변수 안내, KM 자료 구조·지연 진입 안내, Cox 자료 구조·동률 처리·층화·군집 분산·스플라인·시간가변 계수·보정 생존확률 안내를 포함한다. 이미 사전에 있는 공통 항목도 번역 함수로 연결했다.

추가로 영어로 고정되어 있던 선택 안 함, Efron 기본값, 정확법 및 입력 예시를 번역했다. Kaplan–Meier, Breslow, Tarone–Ware 등의 방법명과 HR 등의 통계 약어는 유지한다. 분석 계산과 결과 본표는 변경하지 않았다.

`scripts/validate_survival_km_cox_options_i18n.R` 검증:

- 8언어 × 17개 설정 = 136개 생성 HTML 검사 통과.
- KM·Cox 기본 설정 2개, KM 2자료구조 × 3옵션탭, Cox 3자료구조 × 3동률 처리 방식.
- 언어별 컨트롤 ID·입력값·선택값·체크 상태·다중선택·수치 범위와 조건부 표시식을 영어 화면과 비교했다.
- 사용자 변수명 `Review`, `Normality`, `None`, `사용자 <&> %s`가 공변량 선택 목록에서 유지됨을 확인했다.
- KM·Cox에서 사건 변수 안내와 주요 옵션이 현지화됨을 확인했다.

한계: 설정 인수로 값을 전달한 생성 HTML 검사이며 실제 저장 파일 복원이나 브라우저 언어 왕복 검사가 아니다. 모든 화면 문구의 언어학적 검수를 대체하지 않는다. 본표·보조표·저장 산출물 변경이 없어 이번에 내보내기를 새로 생성하지 않았다. 설치본을 만들지 않았다.
