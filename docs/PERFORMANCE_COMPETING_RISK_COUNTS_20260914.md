# 경쟁위험 그래프의 위험집단 수 집계 개선 — 2026-09-14

`R/result_survival_ui.R`의 `survival_competing_risk_table_plot`에서 다수 시점의 위험집단 수를 계산하는 경로를 개선했다. 기존에는 각 시점마다 전체 추적 시간을 비교했다. 새 경로는 집단별 추적 시간을 한 번 정렬하고 `findInterval(...,left.open=TRUE)`로 해당 시점보다 엄격히 이른 관측 수를 구해 전체 수에서 뺀다. 시점과 같은 관측은 기존 `>=` 비교처럼 위험집단에 남는다.

## 적용 범위

32개 이상 시점, 집단별 1,000개 이상 관측, 일반 data.frame의 클래스 없는 숫자 벡터이며 시점·추적 시간이 모두 유한한 경우에만 새 경로를 사용한다. 결측값·무한값·특수 자료형·작은 입력은 기존 비교를 유지한다. 입력 시점 순서, 반복 시점, 집단 순서, 정수 집계값과 팔레트는 유지한다. 분석 추정치 계산은 변경하지 않았다.

## 성능

번들 R 4.5.3, 기존 모듈 캐시, 새 프로세스에서 3쌍을 순차 측정했다. 두 번째 쌍은 순서를 반대로 했다. 변경 전후 함수를 같은 전역 환경에 연결하고 측정 전 한 번 호출했다. 합성 자료 10만 행·3집단을 사용했다.

다음은 **표 데이터 준비 3회 호출 합계**의 중앙값(초)이다. 그래프를 만드는 마지막 함수를 데이터 반환 도우미로 대체했으므로 ggplot 생성·렌더링과 수치 분석 시간은 포함하지 않는다.

| 표시 시점 수 | 변경 전 | 변경 후 |
|---|---:|---:|
| 3 | 0.04 | 0.04 |
| 32 | 0.03 | 0.02 |
| 1,000 | 0.47 | 0.03 |

1,000개 시점의 집계 준비는 약 94% 감소했다. 이는 많은 시점의 확장성 검증이며, 일반적인 소수 시점의 그래프나 전체 분석이 같은 비율로 빨라진다는 뜻이 아니다.

## 검증

- 빈 입력, 크기·시점 수의 적용 경계, 1/3집단, 동률, 역순·반복 시점, 범위 밖 시점, 결측·무한값, All/결측/한글 집단명, 문자·Date·분수 추적 시간을 포함한 59조건에서 표·팔레트·레이블·진단·난수 상태가 정확히 일치했다.
- 사용자 정의 data.frame의 열 접근 메시지까지 기존과 동일했다.
- 측정에 사용한 변경 전후 표 데이터 9쌍이 `identical(...,num.eq=FALSE)`로 일치했다.
- 일반 다집단, 단일 집단과 반복 시점, 비유한 값의 기존 경로를 포함한 위험집단 수 표 PNG 3쌍이 바이트 단위로 일치했다. 경고·메시지도 같았다. 장치는 1200×450, res=100으로 고정했다.
- 실제 `prepare_competing_risk_result`로 6,000행·3집단·32시점의 결과를 생성하고, 변경 전후 위험집단 수 표와 진단·난수 상태가 정확히 일치함을 확인했다.
