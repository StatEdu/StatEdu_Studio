# 종단 모형별 실제 앱 메뉴·언어 왕복

`validate_longitudinal_model_navigation_browser.cjs`는 독립 시험 프로필의 실제 앱에서 합성 CSV를 열고 변수 역할을 배치한 다음 환경설정과 종단 메뉴를 왕복한다. 설치 앱이나 사용자 자료는 사용하지 않는다.

대상은 LMM의 ML·REML UN·REML AR(1), GLMM의 이항·감마·계수형, 패널 고정효과·확률효과의 8개 설정이다. 각 설정에서 ja/zh/es/fr/de/vi/en/ko로 전환한다.

결과: 8개 설정 × 8언어의 64개 브라우저 검사가 모두 통과했고 JavaScript 오류는 없었다. 추가 제품 수정 없이 이전 숨겨진 설정 출력 갱신 수정이 이 범위에서도 작동함을 확인했다. 범위 내 `git diff --check`도 통과했다.

검사 항목:

- 종속변수·ID·시간·독립변수 역할과 순서
- 모형, LMM 구조, GLMM 분포 및 exp(B) 해제
- 시간 고정효과 해제, 적용 가능한 확률기울기 선택, REML에서 기울기 입력 숨김
- 모형별 점검 항목 해제와 Checks 탭 유지
- UI 언어에 맞는 독립변수 개수 제목과 JavaScript 오류 여부

이 검사는 설정 보존에 대한 브라우저 검사다. 모형을 실제 적합하거나 결과·내보내기를 검증하지 않는다. 분석 계산·결과 출력 코드는 수정하지 않았으며 메타분석은 제외하고 설치본은 생성하지 않는다.
