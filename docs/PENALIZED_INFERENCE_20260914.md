## Inference procedure and limits
LASSO/Elastic Net only, checkbox off by default. Default 50 splits (20–500 allowed), each split 50:50. Training-only CV selects alpha and lambda.1se, and nonzero model-matrix terms form the screening set. Independent test data produce OLS two-sided t p-values, multiplied by the number of selected terms. Unselected terms and failed/non-estimable splits get 1; no rerolling or deletion of failed splits. Aggregate using equation 2.2 of Meinshausen, Meier and Buehlmann (2009), fixed gamma=.5: min(1, 2 * empirical median). R quantile type 1 is used (empirical inverse CDF). Do not optimize gamma or add an unrequested second BH adjustment. Family is candidate model-matrix terms within each outcome/method, not all outcomes combined.

Reference: https://arxiv.org/abs/0811.2177 (equation 2.2; fixed gamma).
Validity depends on independent observations, correctly specified Gaussian homoskedastic linear errors, full-rank test design with residual df, and screening retaining the active terms. CV does not guarantee screening. Table 4 tests category levels as individual contrasts; Table 5 separately tests whole categorical variables as described below. Raw split p matrices, indices, tuning choices and statuses are retained in result$inference_results. Nested train/test indices, tuning choices and predictions are retained in result$validation_results. Base seed offsets: 30000 nested validation, 40000 inference; per-split seeds are fixed.

## Categorical omnibus inference added (2026-09-14)
When optional post-selection inference is enabled, additive categorical predictors receive Table 5 and diagnostic Appendix A7. Model-matrix assignments identify groups, avoiding variable-name prefix collisions. In each existing training split, selecting any contrast triggers inclusion of every contrast of that factor in a separate independent-test model, together with the other selected terms and expanded selected factors. A partial F test removes the complete factor. Full rank, all contrasts and positive residual degrees of freedom are required; missing levels are not silently dropped.

Split p-values are Bonferroni-adjusted by the number of selected categorical variables and aggregated with the same fixed gamma=.5 rule. Unselected or failed tests contribute 1; zero estimable tests display an em dash. The family is categorical variables within an outcome/method, separate from Table 4; no joint error control across both tables is claimed. The original individual-contrast inference remains unchanged. The Gaussian homoskedastic linear-model and screening assumptions still apply. Interaction formulas are not assigned omnibus tests by this additive-only implementation. No aggregate F, coefficient or CI is fabricated.

`scripts/validate_penalized_omnibus.R` verifies agreement with independent nested-model ANOVA, binary F=t², full-factor expansion, reference-level invariance of a fixed fully included test model, missing-level failure, group multiplicity/aggregation, and unchanged individual inference for both LASSO and Elastic Net. Reference-level invariance of the selection procedure is not claimed. The earlier 400-analysis simulation below evaluated individual inference, not this newly added group procedure.

Acceptance passed: live UI runs for all three methods with binary and three-level predictors; current and accumulated HTML/PDF/Word/HWPX/Excel headings, statistics and notes; PDF text equivalence and visual inspection of Table 5 (tmp/penalized-menu/omnibus-table.png). Synthetic export fixtures use 20 splits and 2 stability bootstraps only. No installer was rebuilt.

## Retuned bootstrap selection stability (2026-09-14)
Each Elastic Net bootstrap resample searches the configured alpha grid, sharing the same CV folds across candidates, and selects alpha by minimum CV MSE before extracting lambda.min and lambda.1se selections. LASSO continues with alpha=1. Standardization occurs in each glmnet fit. Bootstrap sampling and fold seeds remain deterministic across sequential and PSOCK execution. Any failed/nonfinite alpha candidate makes the complete resample unsuccessful instead of silently narrowing the search. Frequencies use successful resamples as their denominator, whose count remains displayed. The alpha column is explicitly identified as the full-data estimate; selection frequency is not a significance test. This adds computation proportional to the alpha search and does not change main full-data coefficients or post-selection inference.

`scripts/validate_penalized_retuned_stability.R` independently reconstructs resampling, every alpha CV fit and selected coefficients, verifies LASSO equivalence and serial/parallel equality, and checks failure handling. This is a numerical implementation check, not a calibration study of bootstrap selection frequencies. The earlier individual-inference stress study does not validate selection frequencies.

Elastic Net Table 3 was visually checked at tmp/penalized-menu/retuned-stability.png. Example PDF uses only two stability resamples for export testing; production remains 500. Installer not rebuilt.

## Repeated nested cross-validation (2026-09-15)
The unified menu defaults to 5 repetitions, adjustable from 1 to 20. The low-level fit function defaults to one repetition for existing callers. Every repetition independently partitions the same complete cases into 5 outer folds, with training-only inner tuning and standardization. Seeds start at the analysis seed + 30000 and increment by 100; inner fold seeds retain their existing offsets. Raw predictions, fold assignments, train/test indices and tuning choices are stored per repetition in validation_results[[key]]$runs. Repetition-specific metrics and seeds are also retained.

Table 1 reports the arithmetic mean of repetition-specific pooled held-out RMSE, MAE and R² and the number of repetitions. It does not average predictions into an ensemble or average fold-level metrics. Appendix A8 (only when repetitions exceed one) reports the mean, sample SD, minimum and maximum for each metric. These describe sensitivity to data splitting on the same observations, not independent samples or a confidence interval for population performance. No standard-error/CI calculation treating repeated folds as independent is made. Any repetition failure/nonfinite metric stops the analysis; repetitions are never discarded to improve reported performance. Coefficients, stability and post-selection inference still use their existing procedures.

`scripts/validate_penalized_repeated_cv.R` checks all three methods: direct recalculation of each metric from held-out predictions, arithmetic mean, deterministic seed sequence, disjoint train/test sets and one held-out prediction per observation per repeat, unchanged held-out predictions when only their outcomes are perturbed, single-repeat equivalence, input/failure handling and the variability output table.

## Coverage status added (2026-09-14)
Table 4 now reports descriptive per-term status: all splits failed, never selected, no estimable tests, fewer than half tested, some selected splits failed, selection varies, or tested in all splits. None of these labels certifies assumptions or adequate power. The half threshold follows the existing fixed gamma=.5 aggregation rule; it is not an arbitrary quality score. If a term has zero independent tests, the displayed p-value is an em dash; its internal p=1 contributions are retained. Residual-variance and nonfinite-statistic failures have distinct appendix reasons.

Exploratory stress study: `scripts/validate_penalized_stress.R` uses 50 independently generated datasets per condition, each analyzed by LASSO and Elastic Net with 50 splits, fixed seeds and the production alpha grid. Conditions: global null (n=100,p=10), strong equicorrelation (rho=.95,n=100,p=12,two active effects), small sample (n=24,p=8,one effect), and p>n (n=60,p=100,five effects). All errors are Gaussian and homoskedastic. It reports observed family-wise false rejection rates, exact binomial Monte Carlo intervals, power, screening frequency and failed split rates. This finite simulation is a diagnostic study, not proof of FWER control, and does not validate violations of the model assumptions. Raw replicates and summaries are saved in `tmp/penalized-stress`.

Completed study: 400 analyses (4 conditions × 50 datasets × 2 methods), 50 splits per analysis. Observed FWER was 0/50 in every condition/method; each exact 95% Monte Carlo interval extends to 7.11%, so this does not certify 5% FWER. Average power was 0% in the cancelling high-correlation condition, 14% for n=24, and 19.2% (LASSO)/16.4% (Elastic Net) for n=60,p=100. Elastic Net had 4.52% non-estimable/failed splits in the latter condition. These results support keeping inferential assumptions explicit and reporting coverage; nonsignificance must not be interpreted as proof of no effect. Full report: tmp/penalized-stress/report.md. All current/accumulated exports, PDF text checks and numerical/status tests passed after the UI change.
