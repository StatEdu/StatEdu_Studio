# Fine–Gray 잔차·검열분포 경고

고유 사건시점 부족, 잔차 시간패턴 신호, 희소 검열분포 층의 근거·안내 6개 항목을
6개 추가 언어로 번역했다. 경고 대상 변수·층 이름과 시점 수는 원문을 유지한다.

## 검증

- `validate_fine_gray_residual_warnings_i18n.R`: 실제 경쟁위험 결과에 진단 메타데이터를
  넣어 정상/고유 시점 4개/잔차·층 신호의 3개 상태를 8개 언어로 검사했다.
  중복 시점을 포함해 행 수 대신 고유 시점 수가 쓰이는지 확인했다.
  각 조건을 실제 Fine–Gray로 재적합한 검사는 아니다.
- 대상 변수·층 선택과 특수문자 보존, 실제 영어 CIF 본 표 유지 확인.
- 수렴·정보행렬 경고 회귀 검사 통과.
- 일본어 현재 2개 / 누적 3개 안내 표의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서와 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 생존분석 전체 다국어 완료를 의미하지 않으며 다른 경고와
보조표의 잔여 누락은 추가 점검 대상이다.
