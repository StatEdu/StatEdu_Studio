# 고차요인 omega-h 미보고 사유 다국어

2026-09-17

## 범위

고차요인 CFA 보조표에서 위계적 omega를 보고하지 못하는 7가지 사유와 사유를 포함하는 안내 문장을 일본어·중국어·스페인어·프랑스어·독일어·베트남어로 보완했다. 기존 한국어·영어 문구는 유지한다. 알 수 없는 사유와 빈 사유는 원문 그대로 반환한다. 통계 계산은 변경하지 않았다.

## 검증

`scripts/validate_omega_reason_i18n.R`는 실제 고차요인 CFA 적합으로 기본 표를 생성하고, 미보고 사유별 표시 fixture를 주입해 실제 renderUI 본문을 실행한다. 7가지 사유 × 8개 언어에서 완성된 안내 문장을 확인했다. 외부 오류에 포함된 한글·특수문자 및 빈 문자열 보존도 확인했다. 모든 계산 실패를 실제로 유발하는 검사는 아니며, 사유별 표시 경로 검사이다.

공통 다국어 커버리지 검사를 통과했다. 내보내기 검증 기록은 `tmp/omega-reason-exports.log`, 산출물은 `tmp/omega-reason-i18n/`에 저장한다.

일본어 현재 결과 7개 표와 누적 결과 8개 표의 HTML/PDF/Word/HWPX/Excel 내보내기가 통과했다. 실제 PDF 텍스트, HTML/Word 표 순서와 Excel 시트 수도 확인했다. 이 검사는 미보고 사유가 포함된 스냅샷의 보존 검사이며, 나머지 기존 영어 해설의 번역 완료를 의미하지 않는다.

## 남은 범위

고차요인 보조표의 적재량/omega 판정, 제목·열 이름 및 일반 해설은 별도 점검이 필요하다. 이번 변경으로 고차요인 보조표 전체 또는 전체 다국어 작업이 완료된 것은 아니다. 설치본은 생성하지 않았다.
