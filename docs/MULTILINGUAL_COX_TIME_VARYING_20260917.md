# Cox 시간가변 계수 보조표

6개 추가 언어에 시간 함수, 상호작용 B, 시간가변 계수 분석 및 시점별 위험비 제목,
동반 PH 모형 진단 설명, 시간가변 모형/곡선 범위 설명의 6개 번역 항목을 추가했다.
기존 공통 번역 경로를 사용하며 분석 계산과 본 표, 도표는 변경하지 않았다.

## 검증

- `validate_cox_time_varying_i18n.R`: 실제 Cox 시간가변 계수 모형(age)을 적합하고
  상호작용 검정 및 100/250/500 세 시점의 위험비 보조표를 8개 언어로 검사했다.
- 전체 결과 패널에서 두 설명문의 실제 번역 표시를 확인했다.
- 사용자 이름 검사에는 표시용 복사본을 사용했다(별도 적합 결과가 아님).
  모든 표 수치·시간 함수·라벨 보존 및 본 표 영어 유지 확인.
- 기존 `validate_cox_ph_i18n.R` 회귀 검사 통과.
- 대상 보조표·설명 스냅샷의 일본어 현재 4개 표 / 누적 6개 표를
  HTML/PDF/Word/HWPX/Excel로 검증했다. PDF 내용·표지, 표 순서와 Excel 시트 수 통과.
  도표 내보내기는 이번 검증 범위에 포함되지 않았다. 저장 시 재적합하지 않는다.

설치본은 생성하지 않았다. 자연 삼차 스플라인 등 다른 분기는 계속 점검해야 한다.
