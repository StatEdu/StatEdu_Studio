# LMM·패널 보고 점검표의 권고 — 2026-09-17

기존 GEE 보고 점검표 검사에 실제 LMM, 패널 고정효과, 패널 확률효과 적합을 추가했다. 시간가변 교란/역인과, 군집·Driscoll-Kraay 표준오차, 개체 효과와 예측변수의 상관, 특이 적합 시 확률효과 단순화에 관한 권고 4개의 번역 누락을 확인해 8언어로 연결했다.

`validate_longitudinal_checklist_models_i18n.R`는 기존 3경로와 추가 모형 3개를 합쳐 6경로 × 8언어, 48개 점검표를 검사한다. 항목·상태·설명, 개별 권고와 연결된 설명, 소프트웨어명/버전 및 원본 결과 보존을 확인한다. 시험 자료의 LMM 특이 적합/수렴 경고와 패널 공통 시점 부족 경고가 발생했으며, 이를 숨기거나 정상 수렴으로 간주하지 않는다. 본 검사는 그러한 반환 결과의 번역 검증이다.

추가 실제 점검표를 기존 저장 검사에 포함해 한국어/일본어 현재·누적 HTML/PDF/Word/직접 생성 HWPX/Excel을 검증한다. PDF 텍스트는 `validate_longitudinal_error_pdf.py`로 확인한다. 산출물: `tmp/longitudinal-error-exports`.

계산 코드·메타분석·설치본은 변경하지 않았다. GLMM 등 나머지 모형/분포·모든 옵션·브라우저·페이지별 시각 검토는 별도 남아 있다.

위 검사와 기존 MI/IPW·가중치·사용자 이름 검사, 현재·누적 5종 저장 검증이 모두 통과했다. PDF 네 개의 캡처 텍스트도 통과했다. 한국어 현재 28쪽/누적 55쪽, 일본어 현재 29쪽/누적 56쪽이다. 변경 파일의 `git diff --check`도 통과했다.
