# PLS 타당도 보조 설명 다국어

2026-09-17

PLS 구성개념 종류별 해석, 보조표의 역할, 부트스트랩 통계량 범위 설명과 상태·유효/요청 반복 수·최소 보고 비율을 포함한 요약을 UI 언어로 표시한다. 상태명 Insufficient/Failed/Canceled의 공통 번역 누락도 보완했다. 외부 오류 상세 및 알 수 없는 상태명은 원문으로 보존한다. 계산과 본표는 변경하지 않았다.

`scripts/validate_pls_validity_notes_i18n.R`는 부트스트랩 표시 fixture로 미사용·충분·불충분·진행 중·실패·중단·기록 없음·외부 상태의 8개 상황 × 8개 언어를 검사한다. 모든 안내와 알려진 상태명 번역, 70/100 및 80% 수치, 오류 상세의 한글/특수문자/리터럴 `%s`, 추론 가능 여부에 따른 경고 클래스를 확인했다. 실제 PLS 재표집 실행 검사는 아니다.

공통 다국어 커버리지 검사 통과. 내보내기에는 대표 본표 fixture와 실제 설명 렌더링을 함께 캡처한다. 로그·산출물은 `tmp/pls-validity-notes-*`에 저장한다.

일본어 현재 결과 8개 표와 누적 결과 9개 표의 HTML/PDF/Word/HWPX/Excel 내용 검사, 실제 PDF 텍스트, HTML/Word 표 순서 및 Excel 시트 수 검사를 통과했다.

이번 범위는 PLS 타당도 설명 영역이다. 별도의 판별타당도 가이드 표와 공통 명세 설명은 추가 점검 대상이다. 설치본은 생성하지 않았다.
