# 생존 설정 오류 안내

`survival_issue_text`에 기존 등록된 오류 24종에 일본어·중국어·스페인어·프랑스어·독일어·베트남어 번역을 추가했다. 추천 패널에서 이 함수를 호출하도록 연결했다. 기존 한국어 설명과 영어 원문을 유지한다. 다른 언어의 오류 코드 표기도 유지한다.

번역 키는 `survival.setup.issue.<code>`로 구분한다. 알 수 없는 코드는 원래 오류 설명을 그대로 표시하며 임의로 번역하지 않는다. 사전검사 객체의 변수명·건수·코드·메시지를 수정하지 않는다.

검증: `scripts/validate_survival_setup_issues_i18n.R`에서 8언어 × 등록 오류 24종의 생성 UI 표시, 미등록 오류의 `Review Normality None 사용자 <&> %s` 보존, 실제 `survival_preflight`에서 발생한 시간/사건 변수 누락 오류의 패널 표시를 확인했다. 추천 패널의 기존 80개 구성 검사도 재통과했다.

한계: 24종 모두를 실제 데이터로 발생시킨 검사는 아니다. 대부분은 합성 오류 목록으로 표시 경로를 검사했다. `invalid_time_encoding` 등 기존 번역 함수에 미등록된 오류와 실제 브라우저 검사는 남아 있다. 정적 후보 19개와 등록 오류 24종은 집계 기준이 다르다.

분석 전 설정 UI 변경으로 본표·보조표·저장 산출물 변경은 없으며 내보내기는 새로 생성하지 않았다. 설치본을 만들지 않았다.

로그: `tmp/survival-setup-issues-i18n.log`, `tmp/survival-setup-issues-panel-regression.log`.
