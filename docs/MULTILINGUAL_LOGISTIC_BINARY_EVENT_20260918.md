# 로지스틱 사건·기준 범주 안내 번역

## 발견 및 변경

정적 재검사에서 `result_logistic_ui.R`의 미등록 후보는 없었지만, 실제 일본어 캡처에 `Binary event for y is 2; reference is 1.`이 남아 있었다. 변수명·범주값을 조합하는 동적 문구라 고정 문구 중심 정적 검사에서 잡히지 않았다.

`Binary event for %s is %s; reference is %s.` 템플릿을 8개 언어에 추가하고 기존 로지스틱 문장 패턴 처리에 연결했다. 한국어 기존 표현과 사건·참조범주 선택 및 통계 계산은 유지했다.

## 검증

`validate_logistic_binary_event_i18n.R`는 기존 두 블록·완전 사례 80명 분석을 재사용한다. 실제 생성된 사건 y=2·기준=1 안내와 별도의 특수문자 이름 검사 자료를 확인한다.

- 보완 전 6개 외국어의 실제 안내와 이름 검사 자료에서 미번역 재현.
- 보완 후 8개 언어 실제 부록 표시 검사 통과.
- `사용자 <&> %s`, `사건 (50%)`, `기준 [0]`가 번역 후 보존되는지 확인. 해당 특수문자 자료는 번역 함수 검사이며 실제 적합 변수명 자료와 구분한다.
- 영어 본표의 언어 간 동일성, 전체 결과 객체, 안내문과 같은 사용자 변수명 보존 확인.
- 재사용한 기존 완전 사례·이분형 전환 검사와 순서형·다항 로지스틱 비례오즈·성능·참조범주·VIF 회귀 검사 통과.
- `validate_i18n_contract.R` 및 변경 공백 검사 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 및 PDF 텍스트 보존 검사 통과. 한국어 현재 PDF 4쪽·누적 7쪽, 일본어 현재 5쪽·누적 9쪽이다.
- 저장 검증은 `validate_longitudinal_count_exports.R`와 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이고 본문은 실제 로지스틱 결과 캡처다. 저장 시 분석을 재실행하지 않았다. 산출물: `tmp/logistic-binary-event-i18n/exports`.

전체 정적 검사 최신 집계는 333개 파일·4,236개 출현·고유 후보 507개다. 영어 본표·별도 키·사용 중단 화면 등을 포함하므로 실제 미번역 수나 완료율이 아니다.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드 및 문서 앱별 수동 시각 검토는 수행하지 않았다.
