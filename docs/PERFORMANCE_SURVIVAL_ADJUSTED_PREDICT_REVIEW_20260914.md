# Cox 보정곡선 집단 예측 묶음 검토 — 미적용 — 2026-09-14

`survival_adjusted_curve_once()`에서 집단마다 호출하던 위험도 예측을 한 번으로 묶는 후보를 시험했다. 각 집단으로 설정한 관측 자료를 이어 붙여 예측한 뒤 집단별 위험도 벡터로 분리했다. 앞서 적용한 동일 누적위험 계산 재사용은 비교 양쪽에 유지했다.

수치 동일성 검사는 통과했지만 이 조건에서 시간 이점이 작고 임시 예측 자료가 커지므로 **적용하지 않았다**. 기존 방식은 집단별로 N행을 처리하지만 후보는 한 번에 N×K행을 구성한다. 600건·3집단에서는 1,800행이다. 이는 자료 구조 비교이며 실제 전체 프로세스의 최고 메모리를 측정한 수치는 아니다.

## 전체 보정곡선 계산 측정

600건, 3집단, 사건 생성 확률 0.45, 부트스트랩 60회, 선택 시점 0·10·20의 합성 자료를 사용했다. 번들 R 4.5.3의 새 프로세스에서 모듈과 설정을 로드하고 최초 모형 적합 후 `survival_adjusted_curve()` 전체를 측정했다. 프로파일러 없이 3쌍을 순차 실행하고 두 번째 쌍은 순서를 뒤집었다. 변경 함수는 같은 전역 도우미 환경을 사용했다.

| 반복 | 기존(초) | 후보(초) |
| --- | ---: | ---: |
| 1 | 1.07 | 1.04 |
| 2 | 1.06 | 1.05 |
| 3 | 1.10 | 1.03 |
| 중앙값 | 1.07 | 1.04 |

중앙값 이점은 0.03초(약 3%)다. 더 큰 집단 수에서 같은 결과가 난다고 일반화하지 않는다. 현재 근거로는 확장된 임시 자료와 추가 분리 처리를 도입하지 않는 편이 낫다고 판단했다.

## 검증 및 보관

- `scripts/validate_survival_adjusted_predict.R`: 집단 수, 사건 비율, 동률 시간, 부트스트랩 유무, 선택 시점 변형 등 60개 검사 통과. 전체 보정곡선·신뢰구간·대비·성공 횟수와 정상 계산의 경고·메시지·RNG 상태가 정확히 일치했다. 빈 시점의 기존 오류도 동일했다.
- 측정한 3쌍의 전체 결과, 경고와 RNG를 `identical(..., num.eq = FALSE)`로 비교하여 모두 통과했다.
- 철회 후 원래 줄바꿈까지 복원하고 변경 전 소스와 SHA-256 동일성을 확인했다. `git diff --check -- R/analysis_survival.R`도 통과했다.
- 기존 동일 누적위험 재사용 최적화는 유지한다. 화면과 내보내기의 추가 검증은 미적용 후보에 대해 수행하지 않았다. 설치 파일도 재빌드하지 않았다.

자료는 `output/survival-adjusted-predict-20260914/`에 보관했다. `baseline.R`는 기존 구현, `candidate.R`는 미적용 후보다. 공통 스크립트는 후보 스냅샷을 명시적으로 읽으며 CSV의 `current`는 실험 후보를 뜻한다. `measure.R baseline|current <반복 ID>`, `summarize.R`로 재현한다.
