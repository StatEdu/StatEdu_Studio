# GLM 분포·링크 및 순서형 설명

2026-09-16. 설치본 생성 없이 소스만 변경.

## 변경

- 6개 언어(일본어·중국어·스페인어·프랑스어·독일어·베트남어)에 설명 형식 7종과 분포·링크 명칭 8개를 추가했다.
- 적합 분포/링크, 결과변수의 사용 분포, 연속형/양의 연속형/카운트/음이항 결과 설명, 순서형 수준 목록 설명을 처리한다.
- 프로그램이 생성한 분포·링크 필드에만 명칭 변환을 적용한다. 순서형 수준 목록 안의 `log`, `Model-based` 등 사용자 값은 변환하지 않는다.
- 한국어 음이항 설명이 더 일반적인 카운트 정규식에 먼저 매칭되어 영어가 남던 문제를 수정했다.
- 통계 계산 및 본표의 영어는 변경하지 않는다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 10개 실제 문장 사례로 분포와 링크의 내부 번역, 음이항 문장 분기, 사용자 수준의 한글·소수점·쉼표·퍼센트 보존을 검사했다.
- Gaussian/binomial/count 실제 분석의 본표 셀·제목·주석 및 옵션 내부 값 보존 검사 통과. 합성 count 분석의 기존 추정 반복 한도 경고는 발생했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 현재/누적 fixture의 HTML·Word·HWPX·Excel 내용 및 PDF 생성 확인. `scripts/validate_multilingual_pdf.py`로 두 PDF의 실제 텍스트 비교 통과.

## 남은 범위

분포 자동 선택의 상세 사유, 사용자 선택/실제 적합의 복합 문장, MI 풀링 및 원고 문장 등은 추가 점검 대상이다. 전체 다국어 완료를 의미하지 않는다. 이번 내보내기 검증 언어는 일본어이다.
