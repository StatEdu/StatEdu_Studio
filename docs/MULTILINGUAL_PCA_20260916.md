# 주성분분석 대표 결과 다국어 보완

적합성·고유값 보조표의 검토 항목, Bartlett 검정, 성분, 고유값, 분산 %, 누적 %, 선택 열과 선택값을 8개 언어의 전용 키로 연결했다. 분산 %가 일반 분산 문구로 번역되면서 단위가 사라지는 문제도 수정했다. 계산 엔진과 본표는 변경하지 않았다.

`scripts/validate_pca_i18n.R`는 실제 100행·5변수 자료로 상관행렬/varimax 및 공분산행렬/무회전 PCA를 실행한다. 8개 언어 모두 본표 셀·제목·주석 영어 동일성, 보조표 2개와 8개 번역 항목, % 단위·수치·사용자 변수 라벨 보존 검사를 통과했다.

일본어 실제 두 결과를 하나로 묶은 저장 fixture는 `tmp/pca-i18n/entries.rds`, 로그는 `tmp/pca-i18n-exports.log`다. 번역 계약 검사도 통과했다.

현재·누적 HTML/Word/HWPX/Excel 내용 비교와 PDF 생성·실제 PDF 텍스트 검사를 통과했다. 기존 `validate_pca_varimax_precision.R`의 50개 보관 사례와 8개 경계/대조 사례 검사도 통과했다.

다분상관, 다른 회전/성분 수 선정 기준, 경고·도표·옵션·언어 왕복은 남아 있다. 대표 결과 근거는 17개 화면, 전용 결과 검증 공백은 13개 화면으로 갱신했다. 전체 완료 판정은 하지 않았으며 설치본은 만들지 않았다.
