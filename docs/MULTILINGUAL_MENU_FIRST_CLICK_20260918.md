# 언어 변경 후 메뉴 첫 선택

분할 종단 결과에서 언어 변경 후 첫 메뉴 복귀가 빈 화면으로 끝나는 문제를 재클릭 없는 시험으로 재현했다. 다음 두 경로를 수정했다.

- `www/easyflow.js`: 중첩 메뉴의 이전 활성 하위 링크가 남으면 Shiny 탭 바인딩이 여러 선택을 발견하여 `main_menu = NULL`을 전송할 수 있다. 다른 활성 하위 탭 링크를 정리하고 최종 선택 상태를 통지한다. 이미 문서에서 분리된 링크의 지연 콜백은 실행하지 않는다.
- `R/utils.R`: 지연 로딩 UI의 숨김 상태 검사는 첫 표시 전까지만 적용한다. 이미 표시했던 패널은 Shiny의 기본 출력 중단 기능에 맡겨 언어 변경과 숨김 통지가 겹칠 때 빈 출력이나 오래된 출력을 캐시하지 않게 한다. 최초 미방문 화면의 지연 로딩은 유지한다.

검사에서는 재클릭을 허용하지 않고, 화면의 비동기 번역 완료만 기다린다. 초기 파일 입력이 재생성되는 동안 업로드가 유실되지 않도록 시험 시작 시 초기화 대기를 추가했다. 이는 제품의 파일 가져오기 변경이 아니다.

검증 도구:

- `validate_menu_first_click_browser.cjs`: 8언어 및 한국어 복귀에서 환경설정·종단·결과·케이스 선택 메뉴를 45회 선택하고 실제 Shiny 값과 활성 링크 1개를 확인한다.
- `STATEDU_TEST_SPLIT=1 STATEDU_TEST_STRICT_NAV=1`로 `validate_longitudinal_result_navigation_browser.cjs`: 실제 앱 합성자료의 2집단 GEE 결과를 8언어로 변경하고 첫 메뉴 복귀, 본표 셀·누적 스냅샷 보존 및 집단별 보조표 번역을 확인한다.
- JavaScript 구문 및 범위 내 diff 공백 검사를 수행한다.

최종 결과: 45회 메뉴 검사와 2집단×8언어 분할 결과 검사가 모두 재클릭 없이 통과했다. JavaScript 페이지 오류는 없었고 구문/diff 검사도 통과했다. 결과 번역은 비동기이므로 완료까지 대기하며, 모든 화면이 즉시 표시된다는 뜻은 아니다.

분석 계산과 보고서 형식은 변경하지 않았다. 이 검증이 모든 메뉴와 모든 분석 조합의 완료를 의미하지는 않는다. 설치본은 생성하지 않는다.
