# GLM IPW 안내 및 다중대치 주석

2026-09-16. 설치본은 만들지 않았다.

## 변경

- 6개 언어에 IPW/완전사례 동적 안내 4종과 MI 표 주석 2종을 추가했다.
- 완전사례 제외 행 수, 결측 처리 전 행 수, 관측모형/99백분위 가중치 절단, 관측모형 실패 후 절편만의 IPW 안내를 번역한다.
- MI 표의 RIV/FMI 정의와 Barnard–Rubin 자유도 보정, 통합 전 대치 자료 간 일치 조건을 번역한다.
- 동적 문장 안의 변수명, 오류 상세, 숫자는 원문대로 삽입한다. 통계 계산과 본표 영어는 유지한다.

## 검증

- `scripts/validate_glm_multilingual.R`: 8개 언어 통과. 괄호·버전·퍼센트·한글과 영어 번역 대상 단어가 들어간 사용자 변수명/오류 상세의 보존, 주석 번역, 사례 수 보존을 확인했다.
- 기존 실제 Gaussian/binomial/count 본표 영어 및 옵션 값 보존 검사 유지. 합성 count 데이터의 기존 음이항 추정 반복 한도 경고는 발생했으나 출력 검사는 통과했다.
- `scripts/validate_i18n_contract.R`: 통과.
- 일본어 현재/누적 내보내기 fixture에 안내 및 주석 텍스트를 추가했다.
- 현재/누적 HTML·Word·HWPX·Excel 내용 비교와 PDF 생성 통과. `scripts/validate_multilingual_pdf.py`의 두 PDF 실제 텍스트 비교도 통과했다.

## 범위

IPW 계산을 새로 적합하는 검증이 아닌 번역/출력 검증이다. 오류 자체를 번역하거나 변형하지 않는다. 전체 다국어 완료를 의미하지 않으며, GLM 추가 요약·상태 문구 및 다른 분석 화면의 누락을 계속 확인해야 한다.
