# Kaplan–Meier 곡선 교차 안내문

## 변경

실제 결과 패널에서 사용하는 `survival_km_crossing_note`를 공통 다국어 안내 함수에 연결했다. 일본어·중국어·스페인어·프랑스어·독일어·베트남어 번역을 추가했다.

곡선 교차 시 단일 log-rank p값만으로 요약하지 않고 사전 지정 RMST·시점별 효과를 검토하며, 작은 p값을 얻으려고 가중 검정을 사후 선택하지 않도록 안내한다. 기존 한국어·영어 내용과 분석 계산은 유지했다.

## 검증

- `scripts/validate_km_crossing_note_i18n.R`: 실제 단일·복수 집단 Kaplan–Meier 분석 × 8개 언어 통과.
- 실제 결과 패널에 번역된 안내문이 포함되는지 확인했다.
- 진단 수치와 RMST 표기 보존을 확인했다.
- 일본어 보조표·안내문 캡처로 현재·누적 결과 저장을 검증한다. 저장 시 재분석하지 않는다.
- 산출물: `tmp/km-crossing-note-i18n/`.
- 현재 2개·누적 3개 표의 HTML/PDF/Word/HWPX/Excel 검증 통과. PDF 본문·표지, 표 순서와 Excel 시트 수도 확인했다.

본 표인 집단 비교 검정은 기존 영어 표시를 유지한다. 호출되지 않는 PH 가이드 함수는 이번 변경에서 제외했다. 전체 앱의 다국어 완료를 의미하지 않으며 설치본은 만들지 않았다.
