# 메타분석 입력 창 예시 — 2026-09-17

범주형·연속형 조절변수 placeholder 예시와 OR 입력 필드 이름을 8개 언어의 번역 테이블에 연결했다. 실제 사용자가 입력한 변수명·값은 번역하지 않는다. 예시의 세미콜론, 등호, 소수점은 실제 입력 파서와 호환되도록 유지했다.

`validate_meta_dialog_examples_i18n.R`은 8개 언어 및 한국어 복귀 순서로 14개 보고 형식의 추가·수정 모달과 숫자 입력을 렌더링한다. 사용자 문자열, 포함 여부, 효과 방향, 선택 형식, 숫자값·범위가 영어 기준과 동일함을 확인한다. 각 언어의 두 예시를 실제 조절변수 파서에 입력해 범주형 2개·연속형 2개와 42.5/60 값이 정상 인식되는지 검사한다.

`validate_survival_meta_i18n.R`로 기존 메뉴·필드 번역과 14개 입력 형식의 회귀 검사를 함께 실행한다. 이는 함수 렌더링 검사이며, 열린 모달에서 저장 전 값을 입력한 뒤 실제 브라우저 언어를 바꾸는 조작 검증은 아니다. 분석 결과 출력은 변경하지 않았다. 설치본을 만들지 않았다.

두 자동 검사는 모두 통과했다.
