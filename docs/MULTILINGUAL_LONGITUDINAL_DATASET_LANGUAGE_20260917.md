# 종단 설정의 자료 교체와 언어 전환

선택 변수가 없는 경우 UI가 빈 상태 안내를 먼저 반환하여 이전 종속변수·ID·시간 및 IPW 보조변수 설정이 남는 문제를 합성 자료 Chrome 시험에서 재현했다.

`R/server_longitudinal.R`에서 빈 상태 분기 전에 기존 변수 동기화를 실행하며, 보조변수도 현재 선택 가능한 변수와 교집합으로 정리한다. 남아 있는 변수는 유지한다. 계산식과 분석 결과 표현, 저장된 결과 스냅샷은 변경하지 않는다.

검증:

- `validate_longitudinal_dataset_language_browser.cjs`: 실제 종단 핸들러/UI를 사용하는 독립 Shiny 시험 앱에서 일부 변수 제거 → 선택 변수 없음 → 전체 변수 복귀의 3상태 × 8언어, 총 24개 검사 통과. 서버 설정의 변수·보조변수 제거, 빈 UI 및 이전 선택이 되살아나지 않는 것을 확인했다. JavaScript 오류 없음.
- `validate_longitudinal_auxiliary_clear.R`: 기존 설정 복원, 명시적 보조변수 해제, 재선택 및 숨겨진 입력의 선택 보존 통과.
- `validate_longitudinal_clear_language_browser.cjs`: 기존 가중치 유지/해제 × 보조변수 전체/일부/없음 × 8언어의 48개 회귀 검사 통과.

전체 앱의 파일 열기·메뉴 이동·세션 복원 경로를 대신하는 검사는 아니다. 이번 시험은 합성 자료와 독립 UI를 사용하며 실제 분석 실행이나 내보내기는 변경하지 않았다. 메타분석은 제외했고 설치본은 만들지 않았다.
