# 국소 적합도 잔차 보조표 다국어 점검

2026-09-17

## 수정

- 국소 적합도 진단 제목, 표 번호 문구, 두 잔차행렬 제목, 큰 잔차 목록의 열과 척도 표시, 설명 및 빈 결과 안내에 UI 언어를 적용했다.
- 추가 6개 언어의 18개 번역 항목을 보강했다. 기존 공통 번역도 재사용한다.
- 잔차 목록의 실제 열 이름 `Indicator1`, `Indicator2`와 이전 번역 매핑의 공백 있는 이름이 달라 번역되지 않던 부분을 수정했다.
- 행렬의 사용자 변수 이름을 행과 열 모두 번역에서 보호한다. 목록의 사용자 변수·집단 이름도 보호한다.
- 수치 산출·표시 정밀도·표 방향 기준은 유지한다. 본표, 고차요인 결과 및 통계 계산에는 변경이 없다.

## 검증

`scripts/validate_local_residual_i18n.R`에서 실제 lavaan 적합으로 큰 잔차가 있는 결과를 생성했다. 빈 잔차 목록과 표준화 잔차 미제공 상황은 해당 진단 객체를 변형한 표시용 fixture로 검증했다. 8개 언어의 제목·설명·열 이름, `Review`/`Normality` 사용자 변수명 및 수치 보존을 확인했다. 진단 전체가 없으면 표시하지 않는 분기도 확인했다.

공통 다국어 커버리지 검사 통과. 일본어 현재 결과 7개 표와 누적 결과 10개 표를 HTML/PDF/Word/HWPX/Excel로 내보내 내용·설명과 표 순서를 검증했다. PDF 텍스트 및 Excel 시트 수 검사도 통과했다.

기록: `tmp/local-residual-validation.log`, `tmp/local-residual-coverage.log`, `tmp/local-residual-exports.log`, `tmp/local-residual-i18n/`.

설치본은 생성하지 않았다. 전체 분석의 다국어 완료를 의미하지 않는다.
