# 생존 추천 분석명·확인 안내 번역

## 변경

`survival_recommendation_text`의 등록 문구 27개를 추가 6개 언어 사전에 연결했다. 추천 분석명과 확인·미지원 안내를 포함한다. 원래 등록된 문구만 번역하므로 미등록 상세 메시지나 사용자 문장이 사전 단어와 일치해도 원문을 유지한다. 영어·한국어 문구와 추천 엔진은 변경하지 않았다.

## 검증

`scripts/validate_survival_recommendation_names_i18n.R`:

- 연구 목적 6 × 자료 형태 4 × 사건 구조 4 × 경쟁위험 목표량 4 × 시간의존 여부 2 = 768개 설정을 실제 추천 함수에 전달했다.
- 서로 다른 규칙 결과 15개를 8개 언어에서 검사했다.
- 추천 분석명·대안명·확인·경고·미지원 안내가 번역되는지 확인했다.
- 생성된 추천 패널의 주 분석명과 실행 가능 상태에서만 나타나는 분석 이동 버튼을 확인했다.
- 추천 객체와 내부 코드·이동 대상은 변경되지 않는다.
- `Review`, `Normality`, `사용자 <&> %s`, 미등록 상세 메시지와 빈 입력 보존을 확인했다.

이는 실제 추천 엔진 및 생성 UI 검사이다. 모든 통계 모형을 적합한 검사나 실제 브라우저 이동 검사는 아니다. 추천 이유·주요 결과·대안 설명과 패널 자체 제목·버튼 번역은 별도 항목으로 남아 있다.

분석 출력은 변경하지 않아 새 저장 파일을 만들지 않았다. 설치본은 만들지 않았다. 다음 항목은 `survival_recommendation_explanation`의 추천 근거다.
