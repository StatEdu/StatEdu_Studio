# Gwet AC1/AC2 평정자 쌍 위치 재사용 — 2026-09-13

`interrater_gwet_ac()`에서 각 행의 유효 평정자 값에 대해 `combn(values, 2)`를 반복하던 부분을 개선했다. 유효 평정자 수가 같으면 `combn(seq_along(values), 2)`로 만든 위치 조합을 재사용하고 해당 행의 값을 대입한다. 조합의 열 순서, 가중치 선택과 합산 순서, 기대 일치도 계산은 유지한다.

직전 평정자 수의 위치 행렬 하나만 보관한다. 유효 평정자 수가 달라지면 다시 만들며, 서로 다른 결측 패턴의 조합을 무제한 저장하지 않는다. 추가 메모리는 마지막 위치 행렬 크기에 제한된다. 값 자체를 다른 행에 재사용하지 않는다.

## 측정

동봉 R 4.5.3, 1,000행·5개 범주, 결측 없는 합성 자료의 AC2 quadratic 가중치 계산. 변경 전후 순서를 교대로 5회 측정한 함수 전체 중앙값이다.

| 평정자 수 | 변경 전 | 변경 후 |
|---|---:|---:|
| 5 | 0.04초 | 0.02초 |
| 20 | 0.13초 | 0.06초 |
| 50 | 0.48초 | 0.17초 |

50평정자에서 약 65% 감소했다. 전체 일치도 분석에는 다른 계수와 표 작성 비용도 있으므로 전체 분석의 개선율을 의미하지 않는다. 유효 평정자 수가 매 행 바뀌면 조합을 재사용할 수 없어 효과가 작을 수 있다.
