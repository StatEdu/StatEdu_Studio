# 대응분석 가정검사의 현재 비용 — 2026-09-14

## 결론

Wilcoxon 엔진 재사용까지 적용된 현재 코드를 측정했다. 10만 행·8개 대응쌍에서 전체 분석 중앙 시간은 정규 자료 0.34초, 로그정규 자료 0.47초였다. 별도 계측에서 가정검사 8회는 0.13~0.16초였다. 다음 검토 후보는 왜도·첨도의 중복 계산이다.

설치된 `psych::skew`와 `psych::kurtosi` 소스를 직접 확인했다. 앱이 사용하는 `type=2` 벡터 경로에서도 두 함수가 각각 `sdx <- sd(x, na.rm=na.rm)`를 계산하지만, 해당 분기의 결과 식은 `sdx`를 사용하지 않는다. 평균과 중심화된 제곱합도 별도로 계산한다. 이 중 사용하지 않는 표준편차 계산 제거가 좁은 후보다. 실제 제거의 전체 성능과 진단 보존은 아직 검증하지 않았으므로 **이번에는 제품 코드를 수정하지 않았다.**

## 측정 조건

- 번들 R 4.5.3, 현재 `R/analysis_paired.R`의 스냅샷 사용.
- 2천/2만/10만 행 × 16열, 8개 대응쌍. 정규 또는 로그정규 난수, 결측 없음. 데이터 seed 939, capture seed 718.
- `prepare_paired_results()` 전체 호출: `assumption_check=TRUE`, `median_iqr=TRUE`. 검정 선택·가정표·효과크기·요약표·안내 생성 포함.
- 3개의 새 R 프로세스를 순차 실행. 양쪽 분포와 크기별로 예열 후 계측 없는 전체 시간을 측정. 두 번째 프로세스는 크기와 분포 순서를 뒤집었다.
- 이후 별도 호출에서 앱의 관련 함수와 왜도·첨도 호출을 래퍼로 계측했다. 원본 소스 및 psych 네임스페이스를 수정하지 않았다.

## 전체 실행 시간

단위는 초다. 모든 정규 자료는 대응 t 검정, 모든 로그정규 자료는 Wilcoxon 검정으로 선택됐다.

| 행 수 | 분포 | 전체 1/2/3 | 중앙값 |
|---|---|---|---:|
| 2,000 | 정규 | 0.04 / 0.02 / 0.03 | 0.03 |
| 2,000 | 로그정규 | 0.01 / 0.01 / 0.03 | 0.01 |
| 20,000 | 정규 | 0.04 / 0.05 / 0.05 | 0.05 |
| 20,000 | 로그정규 | 0.06 / 0.09 / 0.07 | 0.07 |
| 100,000 | 정규 | 0.34 / 0.34 / 0.36 | 0.34 |
| 100,000 | 로그정규 | 0.36 / 0.50 / 0.47 | 0.47 |

자료 크기뿐 아니라 정규성 검사 및 선택되는 검정이 다르므로 크기 간 단순 비례 관계를 전제하지 않는다. 작은 자료의 짧은 시간은 타이머 해상도와 실행 환경 변동에 민감하다.

## 10만 행의 별도 구간 계측

| 구간 | 정규 1/2/3 | 로그정규 1/2/3 |
|---|---|---|
| 가정검사 8회 | 0.13 / 0.15 / 0.13 | 0.14 / 0.14 / 0.16 |
| 위 구간에 포함된 왜도 8회 | 0.02 / 0.06 / 0.05 | 0.03 / 0.10 / 0.01 |
| 위 구간에 포함된 첨도 8회 | 0.11 / 0.04 / 0.08 | 0.08 / 0.01 / 0.10 |
| 요약값 16회 | 0.03 / 0.00 / 0.11 | 0.05 / 0.19 / 0.14 |
| 차이값 안내 8회 | 0.06 / 0.03 / 0.00 | 0.03 / 0.00 / 0.03 |

구간은 별도 호출에서 측정했다. 계측 없는 전체 시간으로 나눠 비중을 계산하거나 합산해서 전체와 맞추지 않는다. 왜도·첨도·이상치 검사는 가정검사 안에 포함되므로 중복 합산하지 않는다. 0초는 타이머 해상도 미만이며 실행 생략을 뜻하지 않는다. 시간 변동 때문에 왜도와 첨도 중 하나를 항상 더 큰 병목이라고 단정하지 않는다.

첫 프로세스의 10만 행에서 `Rprof(interval=.01)`도 별도로 실행했다. 기록된 샘플 시간은 정규 0.23초, 로그정규 0.31초로 위 전체 경과 시간과 다르다. 정규 자료에서는 가정검사·첨도·평균 계산이 관측됐고, 로그정규 자료에서는 순위·차이값 안내·첨도·정렬·분위수도 관측됐다. 짧은 샘플이므로 세부 비율을 정밀한 성능 배분으로 해석하지 않는다.

현재 가정검사는 표에 들어갈 왜도·첨도·Shapiro-Wilk·이상치 정보를 함께 반환한다. 큰 표본에서 정규성 판단에 Shapiro-Wilk를 쓰지 않는다는 이유만으로 표시용 검사를 생략하는 것은 이번 결과 보존 요구와 맞지 않는다. 실제 코드에서 Shapiro-Wilk는 3~5,000개 유한 차이값일 때만 계산한다.
