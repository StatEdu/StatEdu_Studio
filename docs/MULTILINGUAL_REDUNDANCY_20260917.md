# PLS 형성형 중복성 분석 다국어 점검

- 제목, 미평가 안내, 계산 불가 사유, 판정 설명, 열 이름과 .70 참고값 해석 주의문을 UI 언어로 표시하도록 변경했다.
- `structural_canvas_redundancy_text`는 등록된 프로그램 문구만 번역한다. 구성개념명·기준변수명 및 미등록 사용자 설명은 보존하며, 번역된 셀을 일반 테이블에서 다시 치환하지 않는다.
- 분석 계산은 변경하지 않았다. 본표의 영어 표시도 유지한다. 설치본은 생성하지 않았다.

## 검증

- `scripts/validate_redundancy_i18n.R`: 실제 renderUI 표현식으로 15개 경우 × 8개 언어를 검증했다. 10개 미평가 사유, 사용자 사유, 사유 누락, 강한 양의 상관·약한 상관·음의 상관의 실제 중복성 계산 결과를 포함한다.
- 수치·신뢰구간·R²·N·사용자 변수명 및 특수문자 보존, 비PLS 화면의 미출력, UI 언어 전환에도 영어 본표 HTML 유지 확인.
- `validate_sem_measurement_assessment.R` 기존 검증 통과. 한국어 소스 문자열을 읽기 전에 UTF-8 locale을 지정하여 실행했다.
- 표시 스냅샷 `tmp/redundancy-i18n/entries.rds`를 이용한 현재·누적 HTML/PDF/Word/HWPX/Excel 저장 검증 통과. 현재 18표·누적 19표의 순서와 Excel 시트 수, PDF 일본어 문구와 표지를 확인했다. 저장 시 분석 재실행은 하지 않았다.
- 미평가 안내는 실제 안내 HTML과 대표 영어 본표를 함께 넣어 Excel을 포함한 저장 검증을 수행했다.

프로그램 전체 다국어 점검은 계속 필요하며, 이 기록은 중복성 분석 결과 패널에 한정한다.
