# 경쟁위험·Kaplan–Meier·생명표 방법 설명

6개 추가 언어에 방법 설명 8개 번역 항목을 추가했다. 경쟁위험 분석의 집단 비교,
원인별 Cox, Fine–Gray, 검열분포 층화 여부에 따라 문구를 구성한다.
Kaplan–Meier 일반/지연진입 및 생명표도 번역 경로를 사용한다.
원점·단위·검열분포 층화 변수는 번역 후 삽입한다. 한국어/영어의 기존 분기는 유지했다.

## 검증

- `validate_survival_noncox_method_i18n.R`: 실제 Kaplan–Meier 일반/지연진입 및
  생명표 결과 3개와 경쟁위험 메타데이터 16개 조합을 8개 언어로 검사했다.
  경쟁위험 16개는 방법 설명의 조건 조합 검사이며 16개 모형 적합 검사는 아니다.
- 선택한 분석 방법만 문장에 포함되는지, 사용자 원점/단위/변수명과 특수문자 보존,
  빈 값 기본 문구 번역 및 영어 표 유지 확인.
- 기존 Cox 동적 방법 설명 회귀 검사 통과.
- 대표 일본어 결과 현재 5개 / 누적 6개 표와 설명의 HTML/PDF/Word/HWPX/Excel 통과.
  PDF 본문·표지, 표 순서 및 Excel 시트 수 확인. 저장 시 재적합 없음.

설치본은 생성하지 않았다. 이번 범위는 동적 방법 설명이며 생존분석 전체 보조표의
번역 완료를 의미하지 않는다.
