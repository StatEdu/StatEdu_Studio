# 비모수 대응표본 동률 경고 복원 및 번역

## 원인과 수정

직전 작업에서 남긴 한국어 동률 경고 누락을 해결했다. 실제 원인은 표 렌더러가 아닌 `paired_appendix_table`의 중복 값 번역이었다. 처음에는 전체 경고가 한국어로 번역되지만 두 번째 공통 번역에서 문장 속 Wilcoxon을 검정명으로 인식해 전체 문장을 `Wilcoxon 부호순위 검정`으로 바꿨다.

값 번역은 한 번만 적용하고, 열 이름은 원본 표를 기준으로 별도 번역하도록 수정했다. 부록 역할·언어 메타데이터와 원본 사용자 데이터 보존 처리를 유지했다. 분석 계산과 비모수 표 렌더러는 변경하지 않았다.

동률 경고 문구를 8개 언어 사전에 추가했다: 절대 차이의 동률이 있어 큰 표본 Wilcoxon 근사를 사용했다는 안내.

## 검증

- `validate_nonparametric_ties_warning_i18n.R`: 실제 동률 자료와 차이가 모두 0인 제외 쌍을 함께 분석했다. 8개 언어에서 전체 경고 문장·제외 사유·Review/Normality 사용자 이름·영어 본표·원본 결과 보존을 확인했다.
- `validate_paired_guards.R`: 직전 실패했던 한국어 비모수 동률 경고, 0 차이와 동률을 결합한 경고를 포함하여 대응표본·반복측정 검사가 최종 모두 통과했다. 영어 본표 주석의 끝 구두점이 현재 문장 순서에 따라 마침표이므로 세미콜론을 강제하던 검사 조건을 보완했다. 문장 본문 및 효과크기 정의 검사는 유지했다.
- `validate_paired_guard_messages_i18n.R`: 직전 수정한 실제 제외 사유 3종의 8개 언어 검사 재통과.
- `validate_i18n_contract.R`: 통과.
- 한국어·일본어 현재·누적 HTML/PDF/DOCX/HWPX/XLSX 저장 내용 검사 통과. 화면 캡처를 사용하며 저장 중 분석을 다시 수행하지 않았다.
- PDF의 모든 캡처 텍스트 보존 확인. 산출물: `tmp/nonparametric-ties-warning-i18n/exports`.

## 범위

새 8개 언어 검사는 실제 동률 경고와 제외 쌍에 한정한다. 0 차이 건수가 포함된 모든 동적 문구의 비한국어 번역을 완료했다고 의미하지 않는다. 저장 검사는 해당 결과 패널을 대상으로 했으며 문서 앱별 수동 시각 검토와 설치본 빌드는 수행하지 않았다. 기존 매개·조절효과 화면 제외 원칙을 유지한다.
