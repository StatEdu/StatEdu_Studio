# SmartPLS 4.1.1.8 TAM-100 supplementary evidence

This public folder preserves only the manual displayed transcription used by
`scripts/validate_pls_smartpls_tam.R`. The two UI screenshots are retained
outside the repository under `STATEDU_SMARTPLS_EVIDENCE_ROOT` and are connected
to the public manifest by basename, byte length, and SHA-256. The built-in
SmartPLS example data, model, settings, and path evidence were not retained.

The reference includes six fit cells and fourteen structural-path cells. The
PLSc d_G cell is genuinely displayed as `n/a` and remains missing in the
reference instead of being invented. This is a supplementary implementation
optional check only: it does not replace the deterministic Holzinger–Swineford
first-100 result and does not complete the preserved 301-row external gate.

Software citation (SmartPLS Terms §8.1 example): Ringle, C. M., Wende, S., and Becker, J.-M. (2024). SmartPLS 4. Bönningstedt: SmartPLS GmbH. https://www.smartpls.com .

The private screenshots are excluded from the public repository under
[SmartPLS Terms §3.4](https://www.smartpls.com/terms/?locale=en-US).
