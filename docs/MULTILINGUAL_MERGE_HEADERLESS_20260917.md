# 무헤더 CSV·DAT 병합 검사 — 2026-09-17

## 검사 범위

변수명 행이 없는 합성 CSV와 공백·탭·쉼표 DAT를 생성했다. `validate_merge_headerless.R`에서 실제 파일 읽기, 첫 데이터 행 보존, 자동 변수명(CSV `V1`–`V3`, DAT `X1`–`X3`), left/inner/full 변수 병합과 케이스 병합을 검사했다. 4개 경로 모두 통과했다.

헤더 옵션을 켰을 때 첫 행이 변수명으로 처리되고, 다시 끄면 전체 데이터 행으로 읽히는 복구 동작도 확인했다. 이것은 작은 합성 CSV에 사용되는 현재 읽기 경로의 이름 검사이며, 대용량 CSV의 자동 이름 규칙을 망라한 것은 아니다.

`validate_merge_headerless_browser.cjs`는 격리된 전체 앱과 Chrome에서 8언어 × 4개 경로를 검사한다. 체크 해제 상태가 언어 전환 후 유지되는지, 파일 요약·full 병합 수치/결측·사용자 문자열·현재 언어 상태 문구가 맞는지, 헤더 옵션 변경 시 이전 미리보기를 비우고 요약 행 수를 갱신하는지 확인한다.

로그: `tmp/merge-headerless.log`, `tmp/merge-headerless-browser.log`. 합성 자료는 `tmp/merge-headerless-fixtures/`에 생성한다.

브라우저 32개 조합 모두 통과했고 pageerror는 없었다.
