# 메타분석 입력 확인과 조절변수 오류 — 2026-09-17

입력 확인 제목·연구 ID 누락 안내·범주형/연속형 셀 접두어와 조절변수 파서 오류 4종(쌍 형식, 중복 이름, 비유한/비숫자 값, 유형 간 이름 충돌)을 8개 언어로 연결했다. 입력 상세와 효과 저장 알림에서 고정 오류 전체 문자열만 번역한다. 사용자 문구나 아직 등록하지 않은 진단은 원문을 유지한다.

입력 UI 전용 `meta_input_moderator_display`를 추가하여 기존 분석 계층의 `meta_moderator_display`는 변경하지 않았다. 결과 본표/보조표/보고서·계산 및 저장된 메시지는 유지했다.

`validate_meta_input_review_i18n.R`: 실제 파서 실패 4종, 입력 확인 HTML, 빈 셀/두 유형 접두어, 사용자 연구 ID·문구·원본 자료 보존, 기존 표시 함수 불변을 8개 언어와 한국어 복귀로 검사했다. 기존 입력 상태/열 제목/선택 상태 검사 및 카탈로그 회귀 검사도 통과했다. 실제 브라우저 조작 검사는 아니다.

효과크기 변환의 나머지 검증 문구·가정 안내 및 모형 실행 오류는 후속 대상이다. 설치본을 만들지 않았다.
