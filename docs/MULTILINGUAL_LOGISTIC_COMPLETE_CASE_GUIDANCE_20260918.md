# 위계적 로지스틱 완전 사례·이분형 전환 안내 번역

## 변경

다음 두 안내가 6개 외국어에서 영어로 남는 것을 실제 분석으로 재현하고 8개 언어 사전에 반영했다.

- 위계적 모형의 모든 단계가 최종 모형의 완전 사례를 사용해 동일한 N을 갖는다는 안내.
- 최종 완전 사례에 결과 수준이 두 개만 남아 이분형 로지스틱 회귀를 사용했다는 안내.

영어·기존 한국어 표현 및 통계 계산·결측 처리·모형 전환 코드는 유지했다.

## 검증

`validate_logistic_complete_case_guidance_i18n.R`는 120명·3범주 순서형 결과와 두 블록 예측변수로 분석한다. 세 번째 결과 범주의 40명에서 두 번째 블록 예측변수를 결측으로 설정하여 최종 완전 사례가 80명·2범주가 되도록 했다.

- 실제 두 위계 단계 모두 N=80이고 이분형 로지스틱 회귀를 사용하며 두 안내가 생성되는지 확인했다.
- 보완 전 6개 외국어 번역 누락 재현, 보완 후 8개 언어 실제 안내 표시 검사 통과.
- 영어 본표의 언어 간 동일성, 전체 결과 객체와 안내문과 같은 사용자 변수명 보존 확인.
- 기존 비례오즈 미충족·다항 전환 안내 회귀 검사, `validate_i18n_contract.R`, 변경 공백 검사 통과.
- 한국어·일본어 현재/누적 HTML/PDF/DOCX/HWPX/XLSX 내용 및 PDF 텍스트 보존 검사 통과. 한국어 현재 PDF 4쪽·누적 7쪽, 일본어 현재 5쪽·누적 9쪽이다.
- 저장 검증은 `validate_longitudinal_count_exports.R`와 `validate_longitudinal_error_pdf.py`를 재사용했다. 공용 표지 제목은 Longitudinal이고 본문은 실제 위계적 로지스틱 결과 캡처다. 저장 시 분석을 재실행하지 않았다. 산출물: `tmp/logistic-complete-case-guidance-i18n/exports`.

기존 매개·조절효과 화면은 제외했다. 설치본 빌드 및 문서 앱별 수동 시각 검토는 수행하지 않았다.
