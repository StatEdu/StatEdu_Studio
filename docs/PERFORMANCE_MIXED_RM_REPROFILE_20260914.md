## 전체 분석 시간

2,000명, 4집단, Holm 사후 비교, **가정 검정 활성화** 조건이다. 조건별 새 R 프로세스 3개에서 첫 분석과 반복 분석 3회를 순차 측정했다. 반복 시간은 각 프로세스의 반복 3회 중앙값을 구한 뒤 그 3개 중앙값의 중앙값이다. HTML 생성과 프로그램 시작 시간은 제외했다.

| 조건 | 첫 분석 중앙값 | 반복 분석 중앙값 |
|---|---:|---:|
| 6시점, 숫자 공변량 1개 | 0.85초 | 0.25초 |
| 12시점, 숫자 공변량 1개 | 1.33초 | 0.73초 |
| 6시점, 숫자 + 범주형 공변량 | 0.97초 | 0.39초 |

이전 성능 보고서의 가정 검정을 끈 측정과 직접 합산하거나 누적 개선율을 계산하지 않는다. 범주형 조건은 공변량 개수도 하나 더 많으므로 위 시간 차이를 범주형 자료형만의 효과로 해석할 수 없다.

## 확인한 병목

각 조건을 추가로 10회 분석하며 샘플 프로파일을 기록하고, 별도 실행에서 함수의 입력을 먼저 평가한 뒤 시간을 측정했다. R의 지연 평가 때문에 상위 표 함수의 누적 시간에 하위 분석 계산이 포함될 수 있기 때문이다.

| 조건 | 사후 비교 함수 10회 분석 합계 | 표 합치기 합계 | 표 스타일 합계 |
|---|---:|---:|---:|
| 6시점 숫자 | 0.80초 | 0.00초 | 0.00초 |
| 12시점 숫자 | 2.95초 | 0.00초 | 0.00초 |
| 6시점 숫자 + 범주형 | 2.02초 | 0.03초 | 0.00초 |

0.00초는 타이머 해상도에서 측정되지 않았다는 뜻이며 비용이 전혀 없다는 뜻이 아니다. 이 별도 계측에는 래퍼 비용이 있으므로 첫 표의 측정값과 직접 비율을 계산하지 않는다. 샘플 프로파일의 함수별 누적 시간은 서로 겹치므로 합산하지 않는다.

호출 경로를 세어 다음을 확인했다. 수치는 **분석 1회당**이다.

| 조건 | 전체 대비 호출 수 | 일괄 처리된 대비 수 | 기존 개별 계산 수 |
|---|---:|---:|---:|
| 6시점 숫자 | 150 | 120 | 30 |
| 12시점 숫자 | 660 | 528 | 132 |
| 6시점 숫자 + 범주형 | 150 | 0 | 150 |

숫자 공변량만 선택해도 전체 시점 비교에서는 `adjusted_posthoc_covariates`가 `frame$group_data`와 공변량을 함께 포함한다. 집단 변수가 범주형이므로 현재 안전 조건에 따라 전체 비교는 개별 회귀를 사용한다. 집단별 비교는 숫자 공변량만 남아 일괄 경로를 사용한다. 사용자가 범주형 공변량을 추가하면 집단별 비교도 개별 경로를 사용한다.
