## 1. 1.3.0 공개 범위

CFA, SEM, PLS-SEM과 매개·조절효과를 공개 분석 메뉴에서 제공합니다. 메타분석과 동일 대상 내 처치 반복측정 분산분석은 공개 설치본에서 제외됩니다. Pro는 이후 버전의 계획입니다.

<a id="data"></a>

## 2. 데이터 준비

SPSS, SAS, Stata, Excel, CSV, DAT 자료를 불러오고 변수 이름·레이블, 측정 수준, 범주와 기준값을 확인합니다. 분석마다 실제 사용 표본 수와 결측 처리 정보를 확인할 수 있습니다.

<a id="descriptive"></a>

## 3. 빈도·기술통계와 교차표

빈도, 백분율, 중심·산포 통계와 교차표를 제공합니다. 선택한 설정에 따라 연관성 검정, 효과크기와 관련 진단을 출력합니다.

<a id="group"></a>

## 4. 집단 비교와 공변량 분석

독립표본 t 검정, ANOVA, ANCOVA와 비모수 집단 비교를 제공합니다. 지원되는 옵션에서 등분산 여부에 따른 방법, 사후 비교와 효과크기를 선택합니다.

<a id="paired"></a>

## 5. 대응·혼합 반복측정

대응표본 분석, 반복측정 분석, 혼합 반복측정 ANOVA와 대응 비모수 분석을 제공합니다. 선택한 설계의 시점·집단 효과와 비교 결과를 출력합니다.

<a id="correlation"></a>

## 6. 상관·신뢰도·평가자 일치

상관분석, 척도 신뢰도와 평가자 일치도를 제공합니다. 상관 방법과 일치도 지표는 변수 유형과 평가 설계에 맞춰 선택합니다.

<a id="factor"></a>

## 7. 탐색적 요인분석과 PCA

EFA와 PCA에서 요인·성분 수, 추출·회전 설정, 적재량과 설명 분산을 확인합니다. CFA는 별도 항목에서 다룹니다.

<a id="ipa"></a>

## 8. 중요도–수행도 분석(IPA)

분석 → IPA에서 직접 평가 또는 도출 중요도를 선택합니다. 직접 평가는 속성별 중요도·수행도 변수를 같은 순서로 배정하고, 도출 중요도는 수행도와 전반적 만족도 결과변수를 지정합니다. 전체·독립집단·대응 사전/사후 설계를 선택합니다. 대응 자료는 WIDE의 대응 열 또는 LONG의 ID·시점과 두 시점 값을 지정합니다. 기준선과 도표 옵션을 확인하고 실행한 뒤 분석 대상 수, 좌표, 구간과 집단/시점 차이를 검토합니다. Word/HWPX는 결과 추가 후 누적 결과에서 저장합니다.

<a id="regression"></a>

## 9. 회귀·위계적 회귀

OLS, HC3 강건 추론과 부트스트랩 회귀를 지원합니다. 위계적 분석은 블록별 모형과 설명력 변화를 비교합니다. sr², f², 공선성 및 잔차 진단은 선택한 출력에 따라 제공됩니다. 위계적 회귀는 최대 4개 블록을 지원합니다. 각 단계에서는 앞선 블록의 변수를 유지하고 다음 블록을 추가합니다.

<a id="mediation"></a>

## 10. 매개·조절효과

캔버스에서 독립·종속·매개·조절변수와 공변량의 역할 및 경로를 지정하고 직접·간접·총효과와 조건부 효과를 추정합니다. 모형 번호를 선택하는 방식이 아닙니다. 지원하지 않는 경로 구조는 실행 전 확인하여 안내합니다.

<a id="generalized"></a>

## 11. 로지스틱·GLM·규제 회귀

로지스틱 및 일반화선형모형과 Ridge, LASSO, Elastic Net을 제공합니다. 결과 척도, 분포·연결함수와 교차검증 설정에 따라 계수와 성능을 보고합니다.

<a id="longitudinal"></a>

## 12. 종단·패널·복합표본

지원 설계에서 GEE, LMM, GLMM, 고정·확률효과 모형 및 복합표본 분석을 제공합니다. 개인·군집 식별자, 시간, 가중치·층화·집락 등 해당 분석 설정을 확인합니다.

<a id="survival"></a>

## 13. 생존분석

Kaplan–Meier, 로그순위, RMST, Cox와 지원되는 경쟁위험 분석에서 생존·사건 결과를 확인합니다. 입력 형식과 사건 코딩을 먼저 검토하며 지원하지 않는 조합은 실행을 제한합니다.

<a id="cfa"></a>

## 14. 확인적 요인분석(CFA)

ML, MLR 및 순서형 자료용 WLSMV/DWLS 추정, 적재량, 적합도, 신뢰도·AVE·HTMT와 지원되는 측정동일성 비교를 제공합니다. Normal/Wishart 선택은 적용 가능한 ML 설정에 한정됩니다.

<a id="sem"></a>

## 15. 구조방정식(SEM)

측정·구조 모형의 경로, 적합도와 지원되는 직접·간접·조건부 효과를 제공합니다. 부트스트랩은 기본 5,000회이며 BC 또는 백분위 구간 등 선택한 설정을 결과에 반영합니다.

<a id="pls"></a>

## 16. PLS-SEM과 PLSc

반영형 Mode A, 형성형 Mode B와 반영형 PLSc, 경로·측정 진단 및 지원되는 예측·집단 비교를 제공합니다. 결측은 seminr::mean_replacement 방식으로 지표 평균 대체하며 각 부트스트랩 재표본에서 평균을 다시 계산합니다. 기본 반복 수는 5,000회입니다.

<a id="planning"></a>

## 17. 표본 수·검정력·효과크기

지원하는 검정의 표본 수, 검정력과 효과크기를 계산합니다. 입력한 유의수준, 효과 가정, 집단 배분과 검정 방향을 함께 기록합니다.

<a id="reporting"></a>

## 18. 표·그림과 결과 저장

1.3.0 공개판은 HTML·그림과 PDF·Word·Excel 저장을 제공합니다. 매개·조절효과/CFA/SEM/PLS-SEM의 HTML·PDF에는 결과 모형 그림을 맨 뒤에 포함합니다. 그림은 화면의 결과 배치를 유지하며 Free 300 dpi, 개발자·Pro 600 dpi 정책을 사용합니다. 현재 결과를 확인한 뒤 결과 추가로 누적합니다. HTML·PDF·Word·Excel 저장을 지원하며 한국어 UI의 누적 결과 화면에서만 HWPX 저장을 제공합니다. HWPX는 Word나 한컴 변환을 거치지 않고 직접 작성합니다. Word/HWPX는 본표·부록표·설명·그림을 선택할 수 있고 기본은 본표입니다. 저장은 화면에 캡처된 결과를 사용하며 분석을 다시 계산하지 않습니다. Free 그림은 300 dpi, 개발자판은 600 dpi 정책입니다. HTML은 표지와 표 목록 링크를 포함합니다.

<a id="validation"></a>

## 19. 검증과 보고 범위

SPSS로 일반 분석·회귀·종단 및 생존분석을, AMOS로 CFA·SEM을, SmartPLS로 PLS-SEM·PLSc와 CB-SEM을 비교했습니다. 1.3.0에 반영된 누적 검증이며 분석별 비교 조건과 남은 차이는 검증 페이지에 요약합니다.
