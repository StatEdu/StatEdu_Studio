StatEdu Studio 1.3.1 (2) TestFlight 설치·실행 검사
준비일: 2026-10-03
상태: 준비 완료, 실제 TestFlight 검사 미실행

검사 시작 조건
1. Mac에 Apple TestFlight를 설치한다. 설치 페이지: https://apps.apple.com/app/testflight/id899247664
2. App Store Connect의 앱 6818689787 → TestFlight → macOS에서 빌드 1.3.1 (2)의 현재 상태를 다시 확인한다.
   마지막 저장 기록은 MISSING_EXPORT_COMPLIANCE이며 이번 준비 과정에서 서버 상태를 새로 읽지 못했다.
   필요한 암호화 문서와 응답을 완료해 내부 테스트 가능한 상태인지 확인한다.
3. 계정과 테스트 그룹의 빌드 접근 권한을 확인한다. 다른 사람에게 초대 메일을 보내려면 별도 지시를 받는다.
4. 기존 로컬 앱과 사용자 프로젝트·설정을 보존한 뒤 TestFlight에서 StatEdu Studio를 설치한다.
   현재 /Applications/StatEdu Studio.app은 ad-hoc 서명, 내부 버전 1.3.1이며 업로드한 빌드 2의 TestFlight 설치본으로 인정하지 않는다.
5. TestFlight에 표시된 앱·버전·빌드·설치 결과와 실제 설치 앱의 Bundle ID·버전·서명·receipt 유무를 기록한다.
   receipt 존재 또는 실행 코드 해시 일치만으로 TestFlight 설치 경로를 입증하지 않는다.

검사 절차와 통과 기준
1. 최초 실행
   Finder 또는 TestFlight의 열기로 실행하고 데이터 화면까지 진입한다.
   ERR_FAILED 경고, R 종료, 무한 로딩이 없어야 한다. 실제 시작 시간과 macOS 버전을 기록한다.
2. 외부 데이터 열기
   scripts/fixtures/survival_validation.csv를 macOS 파일 선택창으로 직접 연다.
   6개 변수(id, time, status, sex, ph.ecog, age)와 72개 행을 확인하고 분석 변수 선택을 적용한다.
3. 상관분석
   time과 age를 선택해 실행한다. 표 4개와 그래프 2개, 결과 추가를 확인한다.
4. Kaplan–Meier
   시간=time, 사건=status, 사건값=1, 집단=sex로 실행한다.
   표 12개와 그래프 4개, 결과 추가를 확인한다.
5. Cox 회귀
   시간=time, 사건=status, 사건값=1, 공변량=age로 실행한다.
   표 14개와 그래프 3개, 결과 추가를 확인한다.
   위 표·그래프 개수는 기존 동일 소스 MAS 시험 기록에 따른 기준이며 계산값 검증 전체를 대신하지 않는다.
6. 결과 내보내기
   새 이름으로 HTML, PDF, XLSX, DOCX, HWPX를 다운로드 폴더에 저장한다.
   각 파일을 실제 뷰어에서 열어 선택한 표·그래프와 정상 문서 구조를 확인한다.
   내보내는 표와 그래프 선택에 맞춰 확인하며 파일 크기가 0보다 크다는 조건만으로 통과시키지 않는다.
7. 프로젝트 및 외부 파일 권한 복원
   새 .studio 프로젝트를 저장하고 앱을 완전히 종료한 후 다시 연다.
   원본 CSV와 변수 역할·설정이 복원되는지 확인한다.
   기존 1.3.1 계약상 프로젝트 열기는 이전 분석·결과 맥락을 초기화한다.
   결과 이력 복원은 프로젝트 열기와 별도로, 일반 재실행에서 확인한다.
8. 언어 및 안내서
   최초 언어를 macOS의 지원 언어 순서와 비교한다. 지원하지 않으면 영어를 기대한다.
   기존 선택이 있으면 최초 언어 검사로 계산하지 않는다. 사용자 설정을 지우지 않는다.
   영어·한국어·일본어·중국어 간체·스페인어·프랑스어·독일어·베트남어를 선택하고 각 안내서 제목·본문을 확인한다.
   프랑스어를 선택한 뒤 재실행하여 선택과 안내서 언어가 유지되는지 확인한다.
   통계 표 제목의 영어 표시는 현재 제품 사양과 비교한다.
9. 종료와 오류 기록
   앱 종료 후 내장 R이 종료되는지 확인한다. 실패가 있으면 startup.log와 오류 화면을 로컬에 보관한다.
   로그의 인증 토큰·개인 경로·bookmark·계정 정보는 공개 저장소에 넣지 않는다.

결과 기록
- 각 항목을 passed / failed / not_run으로 기록한다. not_run을 통과로 계산하지 않는다.
- TestFlight 설치 경로, 앱 버전·내부 빌드, OS, 실제 선택창 조작, 출력 열기, 실패 원인·재검사 결과를 기록한다.
- 기존 로컬 Developer ID MAS 시험 결과를 TestFlight 실행 결과로 옮겨 적지 않는다.
- macOS 13과 깨끗한 별도 Mac 검사는 해당 환경에서 실행하기 전까지 미검증으로 유지한다.
