App Store 개인정보 응답 준비 - StatEdu Studio 1.3.1
작성일: 2026-10-03
상태: 응답 미확정. App Store Connect 수집 항목과 macOS 방침 보완 문구는 게시하지 않았습니다.

확인된 앱 동작
- 일반적인 분석 과정에서 분석 자료, 결과, 프로젝트, 설정과 실행 로그는 Mac 안에서 처리·저장됩니다. 업데이트 요청에 분석 자료와 결과를 첨부하지 않습니다.
- 앱은 시작 시 또는 사용자의 업데이트 확인 시 https://studio.statedu.com/releases/latest.json 을 요청합니다. 내장 R 패키지와 Electron을 포함한 실제 앱 동작을 고려해야 합니다.

확인된 호스팅 기록
- Cafe24의 로그인된 서비스 화면에서 studio.statedu.com의 뉴매니지드 워드프레스 비즈니스 상품과 대상 FTP 접속정보를 확인했습니다.
- 사용자가 제공한 studio.statedu.com의 2026-10-02 HTTP 접근 로그 403건을 로컬에서 해석했습니다. /releases/latest.json 요청 9건은 모두 GET/200이며 IP·접속 시각·요청 주소·User-Agent를 기록합니다.
- 로그에는 명시적인 Host 필드가 없습니다. 사이트 귀속은 파일명과 앞서 확인한 호스팅 서비스에 근거합니다. 9건의 클라이언트는 curl, 브라우저 계열, Python 계열이며 실제 StatEdu 앱 요청으로 식별하지 못했습니다. 앱 실행 횟수나 사용자 수로 해석하지 않습니다.
- 운영자는 로그를 별도로 사용한 적이 없거나 사용 목적을 모른다고 답했습니다. 이 답변은 Cafe24의 목적·추적 여부·사용자 연결 여부를 확정하지 않습니다.
- 원본 IP·User-Agent·Referrer와 원본 로그는 공개 저장소에 넣지 않습니다. 저장소에는 해시와 집계 결과만 남깁니다.

보관 기간과 사용 목적의 미확정 사항
- Cafe24 관리 화면은 최근 1~7일 전의 웹 접근 로그 다운로드를 제공합니다. 전체 서버/WAF/백업 로그가 7일 후 삭제된다는 근거는 아닙니다.
- 기존 공개 방침에는 NinjaFirewall 보안 로그 90일 자동 삭제가 명시돼 있습니다. 실제 플러그인 설정을 확인하지 않았으며 이 기준이 웹 접근 로그 전체에 적용된다고 판단하지 않습니다.
- Cafe24의 기본 수집·이용 목적, 전체 보관·삭제 기준, 다른 정보와의 연결, 제3자 제공을 확인해야 합니다. 운영자가 내려받은 사본의 별도 보관·삭제 기준도 정해야 합니다.
- Cafe24 문의 초안: cafe24-log-policy-inquiry-draft.txt. 로컬에서 준비했으며 발송하지 않았습니다.

App Store 응답 판단
- Apple은 장치 밖에서 실시간 요청 처리에 필요한 범위를 넘겨 읽을 수 있도록 보관하는 것을 수집으로 정의합니다. 자동 업데이트 주소의 접근 로그가 저장되므로 현재 근거로 '데이터 수집 안 함'을 선택하지 않습니다.
- IP의 데이터 종류는 실제 이용 방식에 따라 위치, 기기 식별자, 진단 등으로 판단합니다. '기타 데이터' 또는 '대략적인 위치'를 자동으로 선택하지 않습니다.
- 실제 보안·서비스 운영 목적이라면 앱 기능 목적에 해당할 수 있습니다. 운영자가 별도 이용하지 않았다는 답변만으로 제공자의 목적을 단정하거나 통계·광고 목적을 추가하지 않습니다.
- 계정 기능이 없다는 사실만으로 '사용자와 연결되지 않음'을 확정하지 않습니다. 원시 IP 기록을 비식별 데이터로 간주하지 않습니다.
- 광고 목적의 제3자 데이터 연결 및 데이터 브로커 제공 여부를 확인해 추적 응답을 결정합니다. 현재 확정하지 않았습니다.
- 자동 시작 요청에 선택적 문의·피드백의 공개 예외를 적용하지 않습니다. 문의 경로의 자료도 Apple의 예외 조건에 맞는지 별도로 검토합니다.
- Mac 내부에서만 처리되는 분석 자료는 그 이유만으로 서버 수집 항목이 되지 않습니다.

게시 전 남은 작업
1. 호스팅 제공자의 목적·전체 보관·삭제·연결·제공 범위를 확인하고 운영자의 사본 보관 기준을 정한다.
2. 실제 NinjaFirewall 설정과 기존 방침을 대조한다.
3. 데이터 종류·목적·연결·추적 응답을 확정하고 방침 문구와 일치하는지 검토한다.
4. 확인된 macOS 방침 보완 문구를 웹사이트에 게시하고 App Store Connect 응답을 저장·게시한다.
