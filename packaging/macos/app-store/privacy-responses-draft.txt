App Store 개인정보 응답 준비 - StatEdu Studio 1.3.1
작성일: 2026-10-03
상태: 응답 미확정. App Store Connect에 수집 항목을 게시하지 않았습니다.

확인된 사항
- CSV/Excel 분석 자료, 분석 결과, 프로젝트, 설정과 실행 로그는 일반적인 분석 과정에서 Mac 안에 저장됩니다. 분석 자료와 결과를 업데이트 서버로 전송하지 않습니다.
- 앱은 시작 시 또는 사용자의 업데이트 확인 시 공개 HTTPS 버전 정책을 요청합니다.
- 내장 R 패키지와 Electron의 동작을 포함해 실제 앱의 수집 여부를 판단해야 합니다. 앱 UI에 분석 업로드 기능이 없다는 사실만으로 '데이터 수집 안 함'을 확정할 수 없습니다.
- 공개 개인정보처리방침에는 웹 보안 로그 보관에 관한 설명이 있습니다. 해당 설명이 /releases/latest.json 요청의 호스팅 접근 로그에 어떻게 적용되는지는 확인되지 않았습니다.
- 사용자는 2026-10-03에 해당 엔드포인트의 로그 저장 여부를 모른다고 답했습니다. 운영 환경을 확인하기 전까지 개인정보 응답을 확정하지 않습니다.
- 사용자는 이후 호스팅 업체가 Cafe24라고 확인했습니다. 공개 DNS의 studio.statedu.com → statedustudio.mycafe24.com 연결도 확인했습니다.
- /releases/latest.json은 이번 HTTP HEAD 요청에서 200을 반환했습니다. DNS·응답 헤더·정상 응답은 접근 로그 저장 여부를 입증하지 않습니다.
- Cafe24의 공식 뉴매니지드 워드프레스 안내에는 나의서비스관리 → 호스팅관리 → 계정관리 → 웹/FTP 로그에서 최근 7일간 웹로그를 다운로드할 수 있다고 설명돼 있습니다. 현재 사용 상품·실제 로그·제공자 전체 보관 기간은 확인되지 않았으므로 이 설명을 해당 사이트의 확정 보관 정책으로 적용하지 않습니다.

Cafe24에서 확인할 화면
- 나의서비스관리: https://hosting.cafe24.com/?controller=myservice_hosting_main
- 웹/FTP 로그: https://hosting.cafe24.com/?controller=myservice_hosting_log_webftp
- studio.statedu.com에 연결된 서비스를 선택하고 상품명을 확인한다.
- 실제 로그의 /releases/latest.json 항목에서 IP, 시각, 요청 경로, User-Agent 등의 기록 여부를 로컬에서 확인한다.
- 관리자에게 보이는 다운로드 기간과 Cafe24 서버/WAF/CDN의 전체 저장 기간은 별도로 확인한다. 운영자의 별도 보관과 로그 활용 목적도 확인한다.
- 현재 개인정보 응답은 미확정이며 방침·스토어 수집 항목은 게시하지 않는다.
- 원본 로그에는 방문자 정보가 포함될 수 있으므로 공개 Git 저장소에는 넣지 않는다.

호스팅 확인 항목
1. /releases/latest.json 요청에 IP, 시각, URL, User-Agent 또는 다른 식별 정보가 접근 로그/WAF/CDN 로그에 저장되는가?
2. 운영자 또는 호스팅 제공자가 요청 처리 이후 해당 기록에 접근할 수 있는가? 보관 기간과 삭제 기준은 무엇인가?
3. IP를 위치 추정, 사용자/기기 식별, 기술 진단, 이용량 분석 또는 광고 추적에 사용하는가?
4. 다른 계정 정보와 연결되는가? 저장 전에 비식별화하거나 연결을 차단하는가?
5. 외부 문의 링크에서 받은 지원 자료의 수집 경로와 사용 목적은 무엇인가? Apple의 선택적 공개 조건을 모두 충족하는가?

응답 판단 기준
Apple은 요청을 처리하는 데 필요한 실시간 범위를 넘겨 장치 밖에서 읽을 수 있도록 보관하는 것을 수집으로 정의합니다. 요청 후 IP를 보관하지 않는 경우와 서버 로그에 보관하는 경우를 구분해야 합니다.
보관된 IP는 사용 목적에 따라 위치, 기기 식별자, 진단 등 해당 항목을 선택해야 합니다. 운영/보안 목적은 앱 기능에 해당할 수 있지만, 실제 목적과 사용자 연결 여부 확인이 먼저입니다. '기타 데이터'를 자동으로 선택하거나 원시 IP를 비식별 데이터라고 단정하지 않습니다.
Mac 내부에서만 처리되는 자료는 그 이유만으로 서버 수집 항목이 되지 않습니다. 외부로 전송되는 파생 정보가 있다면 별도로 확인합니다.
확인 후 App Store Connect의 수집 여부, 데이터 종류, 사용 목적, 사용자 연결 여부, 추적 여부를 작성하고 개인정보처리방침과 일치하는지 검토합니다.
