Cafe24 로그 정책 확인 문의 초안
상태: 로컬 준비 완료 / 발송하지 않음

대상 상품: 뉴매니지드 워드프레스 비즈니스
대상 사이트: studio.statedu.com

안녕하세요. 해당 사이트를 사용하는 macOS 앱의 개인정보 안내와 App Store 개인정보 항목을 작성하려고 합니다. 앱은 시작 시 공개 버전 정책 파일 /releases/latest.json을 GET으로 읽으며 분석 자료나 결과를 첨부하지 않습니다. 다운로드한 웹 접근 로그에서 이 주소의 IP, 시각, 요청 주소, 응답 상태와 User-Agent 기록을 확인했습니다. 운영자는 로그를 별도로 활용한 적이 없습니다.

이 상품의 기본 설정을 기준으로 아래 사항을 확인 부탁드립니다.

1. 웹 접근 로그와 별도의 WAF·보안·백업 로그에 저장하는 항목 및 각각의 기본 이용 목적은 무엇인가요? 서비스 운영·보안 이외의 통계, 위치 추정, 사용자·기기 식별, 광고 등에 이용하나요?
2. 관리자 화면에서 다운로드 가능한 최근 7일 범위 외에 원본, 복제본, 백업과 내부 로그는 각각 얼마나 보관하나요? 자동 삭제 시점과 예외 기준은 무엇인가요?
3. IP 등은 저장 전에 익명화·절삭하나요, 아니면 원시 값을 보관하나요? 다른 서비스·계정 정보와 연결하거나 제3자·광고 사업자·데이터 브로커에 제공하나요?
4. 운영자가 생성해 FTP의 cafe24_log 폴더에 보관하는 파일은 자동 삭제되나요? 보관·삭제 책임과 제공자 측 사본의 처리 기준을 알려주세요.
5. 이 상품의 실제 로그 정책을 확인할 수 있는 공식 문서나 설정 화면을 안내해 주세요. 사이트의 NinjaFirewall 로그 90일 기준과 Cafe24 웹 접근 로그 정책은 별개인지도 확인 부탁드립니다.

원본 방문자 로그나 IP를 문의에 첨부하지 않습니다. 이 초안에는 계정 암호나 인증 정보가 포함돼 있지 않습니다.
